## “世界引擎”的完整组成

### 一、底层引擎（现成的，Godot提供）

| 模块 | 职责 |
| :--- | :--- |
| **渲染引擎** | 3D/2D渲染、光照、阴影、后处理 |
| **物理引擎** | 碰撞检测、刚体模拟、射线检测 |
| **音频引擎** | 空间音频、混响、距离衰减 |

这是Godot已经提供的，我们直接使用，不重复造轮子。


### 二、规则引擎层（自研，封装的物理与逻辑规则）

| 模块 | 职责 | 在整个世界引擎中的角色 |
| :--- | :--- | :--- |
| **ESM（环境状态管理器）** | 管理材质属性（可燃性、透水性、坚固度）、驱动状态机（燃烧、潮湿、破碎）、计算蔓延（火焰、流体） | **物理法则的执行者**——确保火会蔓延、水能导电、木头能被烧毁。这是“火会蔓延、水能导电”的技术实现 |
| **天气系统** | 驱动季节更替、天气变化、全局温度湿度，影响物理规则 | 环境变化的推手——暴风雪困住所有人、雨季洪水冲毁桥梁 |
| **体素引擎** | 方块数据的八叉树存储、网格生成、光照计算 | 建造系统的渲染基础——让玩家能自由放置和破坏方块 |


### 三、生命与生态引擎（自研，驱动生物与物件的创造和演化）

| 模块 | 职责 | 在整个世界引擎中的角色 |
| :--- | :--- | :--- |
| **生物引擎** | 基因模板的解析与实例化、生命周期管理（从幼年到成年）、种群繁衍模拟（变异与遗传） | **生命演化的驱动力**——确保生物能根据基因模板生长、繁衍、产生可控变异 |
| **物件引擎** | 支持组装式创造（玩家自由组合零件）和生长式创造（环境孕育，如树种长成弓） | **物件创造与演化的驱动力**——让道具和装备不再是静态模型，而是可以被创造和培育的 |
| **点云过渡系统** | 在生物成长和物件状态变化时，生成平滑的视觉中间态 | 视觉表现的增强层——让成长和变化看起来连续自然 |


### 四、叙事与智能引擎（自研，涌现故事的核心）

| 模块 | 职责 | 在整个世界引擎中的角色 |
| :--- | :--- | :--- |
| **司命（叙事引擎）** | 事实核心、天平系统、干预执行器、时间线推演、结局判定 | **世界的总导演**——确保角色动机碰撞出不可预测的故事，管理世界的逻辑一致性 |
| **角色智能体引擎** | 心智模型（L1-L4）、人格档案、自主行为、对话生成 | **世界的演员**——成千上万个有独立人格的AI角色，让世界充满“人味” |
| **感知系统** | 结构化语义事件、感知过滤器、感官档案 | **角色的眼睛和耳朵**——让他们只能感知自己感官范围内的事，保证信息不对称 |


### 五、创造与定制引擎（自研，赋能创作者和大玩家）

| 模块 | 职责 | 在整个世界引擎中的角色 |
| :--- | :--- | :--- |
| **场景编辑器** | 体素建造、预制件放置、建筑蓝图化 | **创作者的微观画布**——让创作者设计建筑、地牢、城镇 |
| **世界编辑器** | 地形编辑、场景拼接、生态配置、法则定义 | **大玩家的宏观宇宙**——让大玩家构建完整的世界，定义物理法则 |
| **生物编辑器** | 基因模板设计、器官组件组装、行为参数调节 | **生命创造者的工作台**——让创作者定义新物种 |
| **物件编辑器** | 蓝图化组装、材质绑定、属性配置 | **匠人的工作台**——让创作者设计武器、道具、家具 |
| **法则配置器** | 让大玩家在允许范围内自定义世界的物理法则（如重力强度、火焰蔓延速度） | **实现“这个世界没有重力”式的自定义法则** |


### 六、连接与进化引擎（自研，实现跨世界联动）

| 模块 | 职责 | 在整个世界引擎中的角色 |
| :--- | :--- | :--- |
| **世界快照系统** | 记录世界的阶段性状态，支持离线时间线补全 | **世界的存档点**——让世界的变化被持久化记录 |
| **世界映射引擎** | 管理场景之间的连接关系、跨世界数据同步、资产版权追溯 | **世界的连接器**——让一个世界的变化影响另一个世界，实现地图相互映射更新 |
| **资产市场与确权** | 链上存证、智能合约分账、Fork家谱记录 | **共有资产池的基石**——让所有创作者的贡献被记录、保护和收益化 |

## 各引擎模块与“三特性”的对应

| 世界引擎特性 | 负责的引擎模块 |
| :--- | :--- |
| **生成与模拟**（物理法则、生命演化、涌现叙事） | ESM + 天气系统 + 生物引擎 + 物件引擎 + 司命 + 角色智能体 |
| **创造与定制**（自定义法则、创造生命与物件、Fork与交易） | 场景编辑器 + 世界编辑器 + 生物编辑器 + 物件编辑器 + 法则配置器 + 资产市场 |
| **连接与进化**（世界映射、持续进化、共有资产池） | 世界快照系统 + 世界映射引擎 + 资产市场与确权 + 司命的时间线推演 |

**一句话总结**：体素引擎只是“世界引擎”中规则引擎层的一个模块。真正让这个引擎成为一个“世界引擎”的，是我们自研的全部核心系统——ESM的物理法则、司命的叙事导演、角色智能体的自主行为、生物引擎的生命演化、世界编辑器的创造工具、世界映射引擎的跨世界连接——所有系统通过事件总线协同运作，才构成了一个能生成、模拟、创造、定制、连接、进化的完整“世界引擎”。
