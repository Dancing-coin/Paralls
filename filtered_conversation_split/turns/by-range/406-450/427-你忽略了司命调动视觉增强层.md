### L3调度的分层处理

司命对L3的调度不是“每个视觉需求都亲力亲为”。它遵循与逻辑任务相同的分层原则：

| L3调度层级 | 处理方式 | 延迟要求 | 示例 |
| :--- | :--- | :--- | :--- |
| **P1级L3调度** | 规则程序根据预设触发条件自动判定，不需要LLM推理 | <200ms | 火灾蔓延→自动加载火焰粒子特效和烟雾粒子特效（这是ESM状态机的L3联动，预先配置好的）；暗杀瞬间→自动触发慢动作镜头模板（这是暗杀系统的L3联动，预先配置好的） |
| **P2级L3调度** | 需要LLM推理的定制化视觉增强——判定戏剧价值、生成镜头脚本、生成Prompt | <3000ms | 维拉对峙→司命判定戏剧价值8，触发WOW时刻导演，生成专属镜头脚本；艾瑟尔坦白→司命判定戏剧价值10，触发图片生成，生成专属Prompt |
| **P3级L3调度** | 低优先级的氛围增强——队列积压时自动丢弃，使用默认效果 | 可丢弃 | 托马斯搜索→默认使用“搜索聚光灯”通用模板；阿姆斯特朗撬锁→默认使用“紧张心跳”通用音效 |

### 高负荷下L3调度的具体降级示例

在T+65秒这个高负荷时刻，司命的Harness会做出以下L3调度决策：

**P1级（自动执行，零延迟）**：
- 火灾蔓延→自动加载火焰粒子特效、烟雾粒子特效、地毯焦黑贴图。这是ESM-L3的预设联动，不需要司命决策。
- 暗杀弹窗推送时→预设慢动作镜头模板随弹窗一起发送给L1，如果隆巴德选择执行，L1自动触发。

**P2级（LLM推理排队）**：
- 艾瑟尔坦白的图片生成Prompt——最高优先级，LLM推理中。戏剧价值10，必须触发。
- 维拉对峙的镜头脚本——排队中。戏剧价值8，值得触发。
- 暗杀后果的WOW时刻镜头——排队中。如果隆巴德选择执行，需要生成专属镜头。

**P3级（降级或丢弃）**：
- 托马斯搜索的氛围渲染→降级为通用“搜索聚光灯”模板，不消耗LLM资源。
- 阿姆斯特朗撬锁的动作细节→丢弃，使用默认UI提示。
- 沃格雷夫推理的思维可视化→丢弃，使用默认字幕特效。


### 如果L3生成服务本身过载怎么办？

| 过载场景 | 应对策略 |
| :--- | :--- |
| 图片生成API排队过长，预估时间超过3秒 | 直接降级为P3——使用通用占位图或纯文字描述，后台异步生成完成后替换 |
| WOW时刻导演的实时演算脚本过于复杂，L1渲染帧率下降 | 降级为简化版镜头——取消慢动作，仅保留推近特写；复杂粒子特效替换为简单贴图 |
| 多个L3任务同时需要LLM推理 | 司命的LLM推理任务和L3调度任务共享同一个LLM队列——按优先级排序，低优先级任务超时丢弃 |
| 种子库缓存未命中率异常高 | 动态提高P0阈值——更积极地使用通用占位图；后台触发预生成补充种子库 |


### 司命过载的终极防线：Harness的全局熔断

当Harness检测到以下任一条件时，自动启动熔断机制：

| 熔断条件 | 触发动作 |
| :--- | :--- |
| LLM推理队列积压超过5个任务 | 暂停所有P3级L3调度，仅保留P1级自动触发 |
| LLM连续超时3次 | 降级为规则程序兜底——所有干预决策和L3调度使用预设简化方案 |
| 单局L3实时生成配额已满（如5/5） | 后续所有L3调度强制降级为P0复用或P3通用模板 |
| 事件总线消息积压超过阈值 | 丢弃P3级事件，仅保留P0/P1事件 |


**一句话总结**：司命在高负荷状态下不仅要处理逻辑任务，还要调度L3视觉增强层。L3调度同样遵循Harness的四级任务分级——P1级预设触发自动执行（如火灾特效），P2级需要LLM推理的定制化视觉增强按优先级排队，P3级氛围渲染在积压时降级为通用模板或丢弃。当系统整体过载时，Harness启动熔断机制，确保核心叙事逻辑不被视觉增强拖垮。
