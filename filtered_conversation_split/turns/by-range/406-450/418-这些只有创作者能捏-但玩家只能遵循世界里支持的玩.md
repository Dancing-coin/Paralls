## 《开本》世界引擎：创作者设计 vs 玩家体验

### 一、人物定制

| 设计层（创作者） | 体验层（玩家） |
| :--- | :--- |
| 使用**形态键编辑器**定义面部参数范围（鼻梁高度、眼间距、下颌宽度等数百个滑块的上限和下限） | 在创作者定义的参数范围内，通过**捏脸界面**自由调节滑块，生成独一无二的角色外观 |
| 定义**种族模板**（精灵的尖耳、兽人的獠牙、矮人的粗壮体型），设置每个种族的形态键默认值和可调节范围 | 选择种族模板作为基础，在此基础上进行个性化微调 |
| 上传**自定义发型、纹身、伤疤**等装饰资产到资产市场 | 从市场购买装饰资产，装备到角色身上 |
| 定义**体型参数**（身高、体重、肌肉量）的可调节范围 | 在允许范围内调节体型 |
| 创建**服装蓝图**，定义服装的裁剪、材质、颜色可变参数 | 购买服装蓝图，在允许范围内自定义颜色和材质 |

**核心原则**：创作者定义“能捏什么、能捏到什么程度”，玩家在边界内自由创作。


### 二、生物生态

| 设计层（创作者） | 体验层（玩家） |
| :--- | :--- |
| 使用**基因蓝图编辑器**组装新物种——从器官组件库中选择骨架、皮肤、翅膀、感官等模块，定义其基础形态 | 在市场上发现并购买创作者设计的物种基因模板 |
| 定义物种的**行为参数**——昼夜习性、食性、社会性、攻击性、繁殖率 | 在自己的领地或小世界中**投放和培育**这些物种，观察它们按照设计的行为模式生活 |
| 设定物种的**生长曲线**——从幼年到成年的各阶段时长、形态变化参数 | 见证生物从幼崽到成年的平滑生长过程（点云过渡技术驱动） |
| 定义**变异规则**——后代的哪些参数可能发生变异、变异幅度范围 | 在培育过程中发现**自然变异个体**（如翅膀花纹与母体不同的后代），可以将珍贵变异个体在市场中交易 |
| 定义**栖息地要求**——物种只能在特定环境（如晶矿脉附近、深海、火山地带）生存和繁衍 | 在自己的领地中**营造适宜的环境**来吸引和维持特定物种的繁衍 |
| 定义物种的**产物**——如“晶尘蝶定期掉落晶尘”、“月光狐每月蜕一次发光皮毛” | **收集**生物产出的资源，用于合成或交易 |

**核心原则**：创作者定义“物种的基因和行为边界”，玩家在边界内进行培育、观察、收集和交易。玩家不能直接修改基因模板，但可以通过选择性培育来产生变异个体。


### 三、物件创造

| 设计层（创作者） | 体验层（玩家） |
| :--- | :--- |
| 使用**物件蓝图编辑器**设计零件——定义每个零件的几何形状、材质、属性加成 | 在市场上购买创作者设计的零件蓝图和成品物件蓝图 |
| 定义**合成配方**——哪些零件可以组合、组合后生成什么物件、属性如何计算 | 在**匠造工作台**上，按照配方将零件组装成完整物件（如将剑柄+刀刃+护手+宝石组合成一把剑） |
| 定义**材质属性**——铁、钢、秘银等材质对物件攻击力、耐久度、重量的影响 | 选择不同材质的零件来定制物件的最终属性 |
| 定义**外观参数**的可调节范围——颜色、磨损程度、光效等 | 在允许范围内自定义物件的外观 |
| 定义**生长式物件的培育条件**——如“月光水晶需要在满月之夜放在高塔顶端孕育” | 按照培育条件，在自己的领地中**培育**生长式物件，等待其成熟后收获 |
| 定义**物件的行为**——如“火焰附魔剑在攻击时有概率触发火焰爆炸” | 在战斗中使用这些物件，体验创作者设计的特殊效果 |

**核心原则**：创作者定义“零件、配方和属性规则”，玩家在规则内自由组合和定制。


### 四、世界建造

| 设计层（创作者） | 体验层（玩家） |
| :--- | :--- |
| 使用**场景编辑器**设计建筑——放置体素方块和预制件，定义建筑的结构和外观 | 在市场上购买创作者设计的**建筑蓝图** |
| 将建筑保存为**建筑蓝图**，在资产市场中交易 | 在自己的领地中选择空地，**使用蓝图**一键生成建筑（司命驱动建造动画） |
| 设计**预制件**——如“哥特式教堂套件”、“东方庭院套件”，包含特定风格的墙壁、屋顶、立柱等组件 | 在编辑器中直接使用预制件快速搭建建筑，无需从零设计 |
| 使用**世界编辑器**拼接场景——将多个场景（城镇、地牢、森林）拖拽到世界地图上，定义道路和传送门连接 | 在大玩家的主题世界中**探索**这些拼接好的场景，体验完整的世界 |
| 定义世界的**物理法则**——重力强度、火焰蔓延速度、昼夜循环速度 | 在遵守世界法则的前提下进行游戏 |
| 定义**建造权限**——哪些区域允许玩家自由建造、哪些区域是保护区 | 在允许建造的区域内自由建造自己的家园 |

**核心原则**：创作者/大玩家定义“世界规则和建筑蓝图”，玩家在规则内建造和探索。


### 五、总览表

| 领域 | 创作者设计 | 玩家体验 |
| :--- | :--- | :--- |
| **人物定制** | 定义形态键范围、种族模板、体型参数边界 | 在边界内捏脸、选种族、调体型、换装饰 |
| **生物生态** | 定义基因蓝图、行为参数、生长曲线、变异规则、栖息地要求、产物 | 发现、购买、培育、观察、收集、交易变异个体 |
| **物件创造** | 定义零件、合成配方、材质属性、外观参数范围、生长条件 | 购买零件、按配方组装、选材质、调外观、培育生长式物件 |
| **世界建造** | 定义建筑蓝图、预制件、世界拼接、物理法则、建造权限 | 购买蓝图一键生成、使用预制件建造、在权限内自由建造家园 |


**一句话总结**：创作者和大玩家定义“能做什么、能做到什么程度”——他们负责设计基因模板、零件蓝图、建筑图纸和世界规则；玩家在边界内自由探索、组合和创造——他们购买蓝图、培育生物、组装物件、建造家园。这种分层确保了创作者有充分的创造自由，同时玩家有清晰的玩法边界和丰富的个性化空间。
