## 用户

司命能同时调度L1，L2，L3三层

## DeepSeek

是的。司命作为《开本》运行时核心智能体，是唯一拥有跨层调度权限的系统组件。但它不是“事无巨细地操控每一帧”，而是**在需要叙事决策时，向各层发送高层指令，由各层自主执行**。

---

## 一、司命对各层的调度方式

| 调度对象 | 调度方式 | 指令类型 | 执行者 |
| :--- | :--- | :--- | :--- |
| **L1 确定性空间层** | 通过事件总线发送环境催化指令 | `CATALYZE_FIRE`、`CHANGE_WEATHER`、`LOCK_OBJECT`、`BREAK_OBJECT` | ESM（环境状态管理器）接收指令，在物理规则允许范围内执行 |
| **L2 智能体交互层** | 通过事件总线向角色智能体发送消息 | `impulse`（冲动）、`fact_reveal`（事实披露）、`opportunity`（暗杀机会） | 角色智能体接收消息后，由心智模型自主决定是否响应 |
| **L3 视觉增强层** | 通过事件总线发送视觉触发指令 | `trigger_wow`（触发WOW时刻）、`generate_image`（生成图片）、`start_pointcloud_transition`（启动点云过渡） | L3调度器接收指令后，自主选择生成策略（P0/P1/P2/P3）和执行方式 |


## 二、司命的跨层协同：以“火烧地毯”为例

| 时间 | 层级 | 事件 | 司命的调度动作 |
| :--- | :--- | :--- | :--- |
| T+0s | L1 | ESM检测到壁炉火焰蔓延到地毯边缘 | ESM通过事件总线上报`item_state_changed`事件 |
| T+0.1s | L2 | 司命接收事件，判定火灾可能成为叙事催化点 | 司命事实核心记录事件，天平系统评估火灾对游戏平衡的影响 |
| T+0.2s | L3 | 司命判定火灾值得视觉增强 | 司命向L3发送`trigger_pointcloud_transition`指令——地毯从“正常”到“焦黑”的视觉过渡 |
| T+0.3s | L1 | 司命决定催化火灾蔓延 | 司命向ESM发送`CATALYZE_FIRE`指令——让火焰蔓延到相邻的桌布 |
| T+0.5s | L2 | 司命检测到火灾可能为隆巴德创造暗杀掩护 | 司命向隆巴德发送`opportunity`——“火灾吸引了所有人的注意力，这是你行动的最佳时机” |
| T+1.0s | L3 | 司命判定火势已足够大，需要氛围渲染 | 司命向L3发送`trigger_wow`——WOW时刻导演推近火焰特写镜头，加载橙色滤镜和烟雾粒子 |
| T+1.5s | L2 | 司命检测到AI角色需要感知火灾 | 司命不直接干预，ESM自动向所有角色的感知过滤器推送“看到火焰”、“闻到烟味”的语义事件 |

在**1.5秒内**，司命向三层分别发送了**五条指令**，每条指令都通过事件总线精准投递到对应的执行系统，各系统独立执行后上报结果。


## 三、司命不直接操控的部分

| 层级 | 司命不操控的内容 | 由谁自主执行 |
| :--- | :--- | :--- |
| L1 | 逐帧渲染、物理碰撞、音频定位、粒子特效的每一帧更新 | Godot引擎、ESM、Steam Audio、粒子系统 |
| L2 | 角色对话的逐字生成、微表情的每一帧驱动、角色移动的路径规划 | 角色智能体心智模型、对话生成系统、L4执行层 |
| L3 | 图片生成的模型选择、点云插值的具体算法、粒子特效的具体参数 | L3调度器、点云过渡系统、粒子系统 |


## 四、司命的调度权限与限制

| 权限 | 说明 |
| :--- | :--- |
| ✅ **可调度L1** | 向ESM发送环境催化指令（点火、锁门、破窗、变天），但不能直接操控物理引擎的逐帧计算 |
| ✅ **可调度L2** | 向角色智能体发送impulse、fact_reveal、opportunity，但不能跳过人格过滤器强行控制角色行为 |
| ✅ **可调度L3** | 发送视觉触发指令（WOW时刻、图片生成、点云过渡），但不能干预L3的生成策略选择和降级决策 |
| ❌ **不可操控L1逐帧** | 不能直接操控渲染管线、物理引擎的碰撞检测、音频引擎的采样率 |
| ❌ **不可操控L2自主决策** | 不能强迫角色执行与人格过滤器冲突的行为 |
| ❌ **不可操控L3技术细节** | 不能干预模型选型、种子库管理、生成策略的P0/P1/P2选择 |


## 五、一句话总结

司命是《开本》唯一拥有跨L1/L2/L3调度权限的运行时核心智能体。它通过事件总线向三层发送高层指令——环境催化、叙事引导、视觉触发——各层接收指令后自主执行，并通过事件总线上报结果。但司命只做“决策”和“调度”，不做“执行”——所有的逐帧渲染、逐字对话、逐像素生成都由各层的专业系统自主完成。这是《开本》“司命是导演，不是程序员”的核心设计哲学。
