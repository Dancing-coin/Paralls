## 《开本》司命子智能体 + 模型路由优化方案

### 一、核心优化策略

| 优化方向 | 优化前 | 优化后 |
| :--- | :--- | :--- |
| **司命的角色** | 所有叙事决策集中于单一智能体 | 司命仍然是“总导演”，但大量执行层面的调度工作下放给子智能体 |
| **高并发处理** | 所有任务进入司命的消息队列，按优先级排队 | 同类任务分组后交给对应的子智能体并行处理 |
| **模型资源分配** | 所有需要推理的任务走云端大模型 | 高频、低复杂度任务走本地小模型，仅关键叙事决策走云端大模型 |


### 二、司命的子智能体架构

```
┌─────────────────────────────────────────────────────────┐
│                    司命 (总导演)                         │
│  核心叙事决策 · 全局调度 · 关键节点干预                  │
└──────────┬──────────┬──────────┬──────────┬─────────────┘
           │          │          │          │
           ▼          ▼          ▼          ▼
┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
│环境催化  │ │L3调度    │ │冲突检测  │ │平衡管理  │
│子智能体  │ │子智能体  │ │子智能体  │ │子智能体  │
│          │ │          │ │          │ │          │
│·火灾蔓延 │ │·图片生成 │ │·共谋冲突 │ │·天平评估 │
│·天气变化 │ │·WOW时刻  │ │·暗杀机会 │ │·阵营胜率 │
│·物理破坏 │ │·点云过渡 │ │·意外事件 │ │·节奏控制 │
│·门锁开关 │ │·粒子特效 │ │·连锁反应 │ │·参与度   │
└──────────┘ └──────────┘ └──────────┘ └──────────┘
```

| 子智能体 | 职责 | 决策方式 | 模型分配 |
| :--- | :--- | :--- | :--- |
| **环境催化子智能体** | 管理所有L1环境催化指令——何时点火、何时锁门、何时变天 | 规则程序 + 本地小模型 | P1规则通道 + P2本地小模型 |
| **L3调度子智能体** | 管理所有视觉增强调度——图片生成、WOW时刻、点云过渡、粒子特效 | 规则程序 + 本地小模型 | P1规则通道 + P2本地小模型 |
| **冲突检测子智能体** | 检测角色间目标冲突、共谋背叛、暗杀条件 | 规则程序 + 本地小模型（高频检测） | P0/P1规则通道 + P2本地小模型 |
| **平衡管理子智能体** | 天平系统评估、阵营胜率预测、节奏控制 | 规则程序 + 本地小模型 | P1规则通道 + P2本地小模型 |


### 三、司命与子智能体的分工

| 任务类型 | 优化前 | 优化后 |
| :--- | :--- | :--- |
| **环境催化** | 司命LLM推理 → 发送指令 | 子智能体自主决策 + 规则程序执行，司命仅在关键节点干预 |
| **L3视觉调度** | 司命LLM推理 → 生成Prompt | 子智能体自主评估戏剧价值、选择生成策略、管理种子库 |
| **冲突检测** | 司命逐一检测所有角色间冲突 | 子智能体并行检测所有角色对，有结果上报司命 |
| **平衡管理** | 司命定期评估全局平衡 | 子智能体持续监控，仅在失衡时通知司命 |
| **暗杀条件检测** | 司命逐个角色检测 | 子智能体并行监控所有角色，条件满足立即推送 |


### 四、模型路由优化：小模型承担高频低复杂度任务

| 任务类型 | 优化前模型 | 优化后模型 | 原因 |
| :--- | :--- | :--- | :--- |
| **暗杀条件检测** | 规则程序 | 规则程序（不变） | P0硬实时，不能依赖任何模型 |
| **环境催化决策** | 云端LLM | **本地小模型** | 高频触发，不需要深度叙事理解——判断“火焰是否蔓延到桌布”不需要GPT-4 |
| **L3戏剧价值评估** | 云端LLM | **本地小模型** | 高频触发，可以用轻量模型判断——对峙、坦白、发现线索等常见场景的模式识别 |
| **L3图片Prompt生成** | 云端LLM | **本地小模型** + 模板库 | 高频触发，可以基于模板库+参数填充，不需要每次从零生成 |
| **冲突检测** | 云端LLM | **本地小模型**（初筛） | 高频检测所有角色对，小模型先筛出有冲突的对，大模型仅深度分析高价值冲突 |
| **天平评估** | 云端LLM | **规则程序 + 本地小模型** | 数值计算为主，偶尔需要叙事理解时走大模型 |
| **干预决策** | 云端LLM | **云端LLM（不变）** | 低频但关键——决定是否催化新案件、是否干预阵营平衡，需要深度叙事理解 |
| **结局预测** | 云端LLM | **本地小模型** | 基于当前事实模拟投票结果，数值计算为主 |

**优化后的模型调用比例估算**：

| 模型类型 | 优化前占比 | 优化后占比 |
| :--- | :--- | :--- |
| 规则程序 | 30% | 40% |
| 本地小模型 | 20%（兜底） | 45%（主力） |
| 云端大模型 | 50% | **15%**（仅用于关键叙事决策） |

| 时间 | 事件 | 优化前处理 | 优化后处理 |

| T+2.0s | 艾瑟尔崩溃坦白 | 进入司命P2队列 | **冲突检测子智能体**+**L3调度子智能体**并行处理，<500ms |

### 六、子智能体的模型路由配置

| 子智能体 | 任务类型 | 模型分配 | 硬上限 |
| :--- | :--- | :--- | :--- |

| **L3调度子智能体** | 戏剧价值评估、图片Prompt生成 | P1规则 + P2本地小模型 | 规则<50ms，小模型<500ms |
| **冲突检测子智能体** | 暗杀条件检测、角色间冲突筛查 | P0/P1规则 + P2本地小模型 | 规则<10ms，小模型<500ms |
| **平衡管理子智能体** | 天平评估、阵营胜率预测 | P1规则 + P2本地小模型 | 规则<50ms，小模型<500ms |
| **司命核心（总导演）** | 关键干预决策、复杂冲突分析 | 云端大模型 | <3000ms |


### 七、实施路线图

| 阶段 | 内容 | 目标 |
| :--- | :--- | :--- |
| **Phase 1** | 将环境催化、L3调度、冲突检测的逻辑从司命主程序中拆分出来，作为独立的规则模块运行 | 验证子智能体架构的可行性 |
| **Phase 2** | 为每个子智能体接入本地小模型（llama 1-3B），处理高频低复杂度任务 | 将云端大模型调用量降低至30%以下 |
| **Phase 3** | 子智能体完全独立运行，司命仅处理关键叙事决策 | 司命过载风险降至最低，高并发场景下P2任务延迟<500ms |


**一句话总结**：通过引入四个子智能体（环境催化、L3调度、冲突检测、平衡管理）和优化模型路由（高频低复杂度任务走本地小模型），司命从“所有任务集中处理”升级为“总导演+专业团队并行协作”。优化后云端大模型调用量从50%降至15%，高并发场景下P2任务延迟从2000-3000ms降至<500ms，司命过载风险从中等降至低。
