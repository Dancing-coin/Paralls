## 云端硬件成本的承担方

是的，你的理解完全正确。云端服务器、GPU、CPU等硬件成本，**由大玩家和官方各自承担与其经营模式匹配的部分**。普通玩家不需要直接为云端硬件买单。

### 一、成本承担原则

| 承担方 | 承担内容 | 原因 |
| :--- | :--- | :--- |
| **官方** | 官方游戏服务器的全部云端成本（房间管理、AI推理、L3生成、离线补全、匹配服务、资产市场等） | 官方直接向玩家收取门票/买断费用，云端成本是运营成本的一部分 |
| **大玩家** | 其经营的主题世界或影院服务器所产生的全部云端成本 | 大玩家通过经营服务器获得收入（门票、会员、道具等），云端成本是其经营成本的一部分 |
| **普通玩家** | **不直接承担云端硬件成本**，除非购买云游戏模式（全部AI和渲染走云端） | 普通玩家的消费（剧本买断、门票、会员）已覆盖了官方的运营成本 |


### 二、官方承担的云端成本

| 服务 | 所需云端硬件 | 说明 |
| :--- | :--- | :--- |
| **官方游戏房间管理** | CPU实例 | 所有官方剧本的房间状态同步、事件广播 |
| **官方AI推理** | GPU实例 | 官方剧本中的角色智能体对话、司命推理 |
| **L3视觉生成** | GPU实例 | 官方剧本中的图片/视频生成 |
| **离线时间线补全** | CPU实例 | 所有玩家的小世界离线推演 |
| **匹配服务** | CPU实例 | 跨服匹配撮合 |
| **资产市场** | CPU实例 | 交易处理、区块链交互 |

**成本回收方式**：官方服务器的门票收入、剧本买断收入、会员订阅收入、资产市场交易抽成。


### 三、大玩家承担的云端成本

| 服务 | 所需云端硬件 | 说明 |
| :--- | :--- | :--- |
| **大玩家服务器房间管理** | CPU实例 | 其主题世界/影院的所有房间状态同步 |
| **大玩家AI推理** | GPU实例 | 其服务器中的角色智能体对话、司命推理 |
| **世界持续推演** | CPU实例（7×24小时） | Phase 3主题世界的时间线推进、NPC生态驱动 |
| **L3视觉生成** | GPU实例 | 其服务器中的图片/视频生成 |

**成本回收方式**：大玩家通过经营服务器获得的门票、会员、道具、直播互动等收入。大玩家可选择向官方购买**算力套餐**（官方统一采购云端资源，以大玩家算力套餐形式转售），或自行搭建服务器（P2P模式，使用自有硬件或租用云服务器）。


### 四、普通玩家承担的云端成本（仅限特殊情况）

| 场景 | 玩家承担方式 |
| :--- | :--- |
| **云游戏模式** | 玩家的硬件不满足最低配置，全部AI推理和渲染走云端时，需购买云游戏套餐（按月/按小时计费） |
| **P2P自建服务器** | 玩家用自己的电脑当主机，邀请好友联机。不涉及云端成本，但主机玩家的硬件承载算力负担 |
| **AI算力AA分摊** | P2P模式下，玩家可以选择AA分摊云端AI推理费用（如果主机玩家硬件不足以本地运行AI） |
| **个人世界扩容** | 玩家的小世界需要更多AI同伴、更大庄园、更复杂的生态模拟时，可购买个人算力扩容包 |


### 五、成本承担总览

| 角色 | 承担成本 | 不承担成本 |
| :--- | :--- | :--- |
| **官方** | 官方服务器的全部云端成本（房间管理、AI推理、L3生成、离线补全等） | 大玩家服务器的成本 |
| **大玩家** | 其经营的服务器的全部云端成本（房间管理、AI推理、世界推演、L3生成等） | 官方服务器的成本；普通玩家的基础游戏成本 |
| **普通玩家** | 个人消费（门票、买断、会员、皮肤、云游戏套餐、算力扩容包） | 官方和大玩家的服务器硬件成本 |
| **P2P主机玩家** | 自有硬件的电费和折旧（本地运行）；或AA分摊的云端AI费用 | 其他联机玩家的基础游戏成本 |


### 六、一句话总结

云端硬件成本的分担遵循“谁经营谁承担”原则：官方承担官方服务器的成本，大玩家承担其经营的服务器的成本。普通玩家不直接承担云端硬件成本，仅在硬件不达标需要云游戏模式、或需要额外算力时按需付费。大玩家可向官方购买算力套餐（官方统一采购转售），也可自行搭建服务器。
