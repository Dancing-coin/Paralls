## 《开本》全局计算架构（修正版）：硬件自适应弹性调度

### 一、核心原则修正

| 原原则 | 修正后原则 |
| :--- | :--- |
| 本地优先，云端兜底 | **先评估，再分配**——启动时检测本地硬件配置，动态决定任务分配策略 |
| 95%日常对话本地处理 | **能本地就本地，不能就上云**——无达标GPU时，全部AI推理走云端 |
| 单用户月成本3.5-10.5元 | **阶梯成本**——硬件越好，云端成本越低；硬件越差，云端成本越高，但通过模型优化和套餐设计控制在可接受范围内 |
| 桌面端为主 | **全平台覆盖**——桌面端（Windows/macOS/Linux）、移动端（iOS/Android）统一架构，根据硬件能力自适应 |


### 二、启动时硬件基准测试

客户端启动时，自动检测以下硬件指标，生成**硬件能力评级**：

| 检测项 | 检测内容 | 用途 |
| :--- | :--- | :--- |
| **GPU型号与显存** | 是否为独立显卡？显存容量？支持的计算API？ | 决定本地AI推理能力 |
| **CPU核心数与频率** | 物理核心数、主频、是否支持AVX2/AVX-512 | 决定ESM物理计算、规则引擎的本地执行能力 |
| **内存容量** | 总内存、可用内存 | 决定本地小模型的加载可行性 |
| **NPU/神经引擎** | 是否有NPU（如Apple Neural Engine、骁龙Hexagon） | 移动端的核心AI加速器 |
| **操作系统** | Windows/macOS/Linux/iOS/Android | 决定可用的推理框架 |
| **网络延迟与带宽** | 到云端服务器的Ping值、上下行带宽 | 决定云端AI体验的上限 |

**硬件能力评级**：

| 评级 | 典型配置 | AI推理策略 |
| :--- | :--- | :--- |
| **S级** | RTX 3060及以上（6GB+显存），16GB+内存 | 本地7B模型处理95%日常对话 + 云端大模型仅用于关键深度推理 |
| **A级** | GTX 1060/MX450/Apple M1（4-6GB显存），8-16GB内存 | 本地3B模型处理日常对话 + 云端大模型处理复杂推理 |
| **B级** | 集成显卡/Apple M1 Air/2-4GB显存，8GB内存 | 本地1.5B模型处理最简对话 + 大部分AI推理走云端 |
| **C级** | 无独立显卡/老旧集显，4-8GB内存 | 全部AI推理走云端；本地仅运行ESM物理和规则引擎 |
| **M级（移动端）** | iPhone 12+/骁龙8+/天玑9000+，6GB+内存 | 本地1-3B模型（NPU加速）处理日常对话 + 云端大模型补充 |
| **M0级（低端移动端）** | 老旧手机/平板，4GB以下内存 | 全部AI推理走云端；本地仅渲染和基础交互 |

#### 3.3 移动端特殊设计

**移动端专属优化**：

| 优化策略 | 说明 |
| :--- | :--- |
| **NPU优先** | iPhone的CoreML/ANE、Android的NNAPI/Hexagon——优先使用NPU运行本地小模型，功耗极低 |
| **流式云端渲染** | 移动端GPU无法承载WOW时刻的实时演算时，云端渲染后以视频流形式推送到设备 |
| **轻量UI** | 移动端UI简化——减少3D场景复杂度，降低渲染负载 |
| **离线模式** | 移动端网络不稳定时，自动切换为“轻量本地模式”——仅支持基础对话（1-3B本地模型），暂停L3生成和世界推演 |
| **电量感知** | 检测电池状态，低电量时自动降低本地AI推理频率，更多任务上云 |


### 四、云端资源池的弹性调度

无论玩家硬件配置如何，云端始终作为兜底方案。云端资源池需要根据玩家硬件能力动态调整：

| 玩家硬件评级 | 云端GPU需求 | 云端CPU需求 |
| :--- | :--- | :--- |
| **S级** | 极低——仅关键深度对话 + 图片生成 | 标准——房间同步 + 离线补全 + 世界推演 |
| **A级** | 低——日常对话补充 + 图片生成 | 同上 |
| **B级** | 中——大部分对话 + 图片生成 | 同上 |
| **C级** | **极高——全部AI推理 + 全部L3生成** | 同上 |
| **M级** | 中——日常对话补充 + 图片生成 | 同上（简化版） |
| **M0级** | **极高——全部AI推理 + 全部L3生成** | 同上（简化版） |

**云端弹性策略**：

| 策略 | 说明 |
| :--- | :--- |
| **按需扩容** | 检测到大量C级/M0级玩家在线时，自动扩容云端GPU实例 |
| **闲时缩容** | 凌晨低峰期自动缩减GPU实例，C级/M0级玩家体验不受影响（他们有预留实例保障） |
| **成本分摊** | C级/M0级玩家的云端成本由平台承担基础部分，超出基础配额的部分可购买“云端算力包” |
| **大玩家算力套餐** | 大玩家购买算力套餐后，其主题世界内的所有玩家均可享受更高质量的云端AI服务 |


### 五、修正后的单用户月度成本估算

| 硬件评级 | 本地承担 | 云端承担（平台） | 平台月度成本/用户 |
| :--- | :--- | :--- | :--- |
| **S级** | 95%对话 + 规则引擎 + ESM | 5%深度对话 + L3生成 | ¥3-8 |
| **A级** | 70%对话 + 规则引擎 + ESM | 30%对话 + L3生成 | ¥5-12 |
| **B级** | 30%对话 + 规则引擎 + ESM | 70%对话 + L3生成 | ¥8-18 |
| **C级** | 规则引擎 + ESM | 100%对话 + L3生成 | ¥15-30 |
| **M级** | 50%对话(NPU) + 规则引擎 | 50%对话 + L3生成 | ¥5-15 |
| **M0级** | 规则引擎 | 100%对话 + L3生成 | ¥12-25 |

**成本控制策略**：
- **基础服务免费**：平台承担所有玩家的基础云端AI服务成本，作为平台运营支出
- **高级服务付费**：超出基础配额的深度对话、高频L3生成、世界推演等，由玩家或大玩家购买套餐
- **硬件越好，体验越优，平台成本越低**——激励玩家使用更好硬件，降低平台整体云端成本
