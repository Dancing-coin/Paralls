### 💻 一、PC端硬件分级参考

根据几款热门三端游戏的官方配置，以及微软最新发布的Windows 11游戏PC配置指南，可以提炼出以下几个关键硬件档位：

| 级别 | CPU | 内存 | 显卡 | 代表游戏体验 |
| :--- | :--- | :--- | :--- | :--- |
| **主流入门** | 四核心处理器 (如R5 5600 / i5-12400) | 16GB | GTX 1660 Super / RX 6600 | 1080P中等画质流畅运行多数现代游戏 |
| **基础体验** | 六代i5 / R5系列 | 8GB | GTX 1050 / GTX 750Ti | 《原神》最低要求，1080P低画质运行 |
| **推荐体验** | i7 / R5 3600X及以上 | 16GB | RTX 2060 / RTX 3060 / RX 6600 | 2K中高画质，主流3A大作流畅运行 |
| **高性能** | 高主频多核处理器 | 32GB | RTX 5070 / 5080 | 4K高画质光追，未来3A大作 |
| **移动端入门 (安卓)** | 骁龙7系 / 天玑1000 / 麒麟990 | 4GB | - | 《原神》《崩铁》低画质运行 |

### 🎯 四、《开本》硬件准入门槛

基于以上参考，我们可以为《开本》设定以下**最低硬件门槛**，低于此配置的玩家将无法启动游戏或仅能使用“云游戏”模式（全部AI推理和渲染走云端）：

| 平台 | 最低配置要求 | 说明 |
| :--- | :--- | :--- |
| **PC端** | **CPU**: 四核心处理器 (如i5-7500/R5 1400) <br>**内存**: 8GB<br>**显卡**: GTX 1050 / RX 560 (独立显卡) <br>**存储**: 50GB以上可用空间<br>**操作系统**: Windows 10 64位 | 与主流三端游戏保持一致。低于此配置的PC将无法本地运行，需使用云游戏模式 |
| **移动端** | **处理器**: 骁龙845 / 天玑1000 / 麒麟990及以上<br>**内存**: 4GB及以上<br>**存储**: 20GB以上可用空间<br>**操作系统**: Android 10.0 / iOS 14.0及以上 | 与《原神》等主流手游对齐。低于此配置的手机将无法本地运行 |
| **主机端** | **PS5 / Xbox Series X\|S** | 仅支持本世代主机。上世代主机性能不足，无法承载《开本》的AI计算和3D渲染需求 |
| **云游戏模式** | 无硬件限制（需稳定网络） | 不满足以上最低配置的设备，可通过云游戏模式体验，但全部AI推理和渲染走云端，需额外付费或订阅 |

### 📈 五、硬件评级与游戏体验

在满足最低配置的基础上，我们将根据实际硬件性能划分为三个体验等级：

| 评级 | PC端 | 移动端 | 游戏体验 |
| :--- | :--- | :--- | :--- |
| **A级** | RTX 2060及以上 / RX 6600及以上 | 骁龙8 Gen1 / 天玑9000及以上 | 全部AI推理本地处理，3D高画质，WOW时刻实时演算，体验最佳 |
| **B级** | GTX 1050Ti - RTX 2060 | 骁龙845 - 骁龙888 | 部分AI推理云端补充，3D中画质，WOW时刻降质演算，体验良好 |
| **C级** | 低于最低配置 | 低于最低配置 | 全部AI推理和渲染走云端，仅限云游戏模式，体验受网络质量影响 |

### 💡 六、最低配置的设定思路

1. **与主流游戏对齐**：不随意拔高或降低门槛，而是与市面上最热门的三端游戏保持一致，确保硬件厂商已经为这个级别的设备提供了足够的市场保有量。
2. **云游戏兜底**：不满足最低配置的设备并非完全无法体验《开本》，而是通过云游戏模式提供替代方案。这既保证了付费用户的覆盖面，又避免了为低端硬件做无尽的兼容性适配。
3. **阶段性调整**：随着《开本》的开发进度和硬件市场的变化，最低配置要求可以动态调整。例如Phase 1的配置要求可以略低于Phase 3，因为Phase 3的持续运行世界对硬件要求更高。
4. **不兼容集显**：PC端最低配置明确要求独立显卡，集成显卡无法承载《开本》的3D渲染和本地AI推理需求。

### 💡 七、最低配置与云端成本的关系

| 最低配置要求 | 预期覆盖玩家比例（占游戏PC/手机用户） | 云端AI成本（平台承担） | 总成本评估 |
| :--- | :--- | :--- | :--- |
| GTX 1050 / 骁龙845 | 约70-80% | 中等 | **推荐方案**：覆盖主流用户，云端成本可控 |
| GTX 1060 / 骁龙855 | 约50-60% | 较低 | 云端成本低，但用户覆盖面窄 |
| GTX 750Ti / 骁龙835 | 约85-90% | 较高 | 云端成本高，但用户覆盖面广 |

**推荐方案**：采用 **GTX 1050 / 骁龙845** 作为最低配置门槛，与《原神》《永劫无间》等主流三端游戏保持一致。这个门槛覆盖了绝大多数核心游戏玩家，同时云端成本可控。低于此配置的玩家可通过云游戏模式体验，但需承担额外的云端费用或订阅云游戏套餐。

### 🚀 下一步行动建议

1. **确定最终硬件门槛**：与开发团队确认，选择哪个级别的配置作为《开本》的正式最低硬件门槛。
2. **采购测试设备**：按照最低配置和推荐配置采购测试样机，确保实际游戏体验达到预期。
3. **开发硬件检测工具**：在客户端启动时自动检测硬件配置，根据评级推荐最佳体验方案或引导用户使用云游戏模式。
4. **设计云游戏方案**：为无法满足最低配置的用户设计完整的云游戏体验方案，包括定价策略和服务等级协议（SLA）。
5. **定期回顾更新**：每半年回顾一次硬件市场变化和主流游戏的最低配置要求，动态调整《开本》的硬件门槛。
