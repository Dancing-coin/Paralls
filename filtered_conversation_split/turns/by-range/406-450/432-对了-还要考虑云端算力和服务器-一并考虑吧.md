# 《开本》云端算力与服务器全局优化方案

基于我们之前讨论的CPU/GPU异构计算优化，现在将云端算力和服务器架构一并纳入，构建一个端到端的全局计算资源调度体系。

## 一、核心设计原则

- **本地优先，云端兜底**：95%日常交互由本地处理，仅5%高价值任务上云。
- **弹性伸缩，按需付费**：云端资源按剧本类型和玩家规模动态分配，闲时自动缩容。
- **任务分级，就近计算**：P0/P1任务严格本地执行，P2任务可上云但需硬上限保障，P3任务异步批处理。
- **成本可控，体验无损**：通过本地小模型、种子库缓存、预计算等手段，将单局AI成本控制在可接受范围内。

## 二、云端GPU集群：AI推理的主力与弹性补充

### 2.1 云端GPU的核心任务

| 任务类型 | 说明 | 为什么需要云端 |
| :--- | :--- | :--- |
| **司命核心决策** | 复杂的叙事干预、冲突分析、结局判定 | 需要大模型（GPT-4/Claude）的深度推理能力 |
| **角色深度对话** | 关键情感交流、复杂谎言编织、长篇叙事 | 本地小模型无法处理的高复杂度对话 |
| **L3图片/视频生成** | 线索特写、记忆闪回、结局CG | 需要专用生成模型（Stable Diffusion等） |
| **离线批处理** | 种子库优化、剧本测试、世界推演 | 大批量计算，无实时性要求 |
| **多人在线推理** | 当房间内AI角色数量超过本地GPU容量时 | 本地最多同时运行2-3个7B模型，超出部分上云 |

### 2.3 实时推理的延迟保障

| 保障策略 | 说明 |
| :--- | :--- |
| **预留实例** | 保证最低GPU容量始终在线，应对突发流量 |
| **模型预热** | 热门剧本的Prompt模板和上下文预加载到GPU显存 |
| **请求队列优先级** | P2级推理请求优先于P3级批处理请求 |
| **跨区域部署** | GPU集群分布在多个地理区域，就近服务玩家 |
| **降级策略** | 云端推理超时时自动降级为本地小模型兜底 |

## 三、云端CPU与内存：逻辑计算与状态管理

### 3.1 云端CPU的核心任务

| 任务类型 | 说明 | 为什么需要云端 |
| :--- | :--- | :--- |
| **房间状态管理** | 多人在线时的状态同步、事件广播 | 需要中心化服务器 |
| **世界持续推演** | Phase 3主题世界的时间线推进、NPC生态 | 7×24小时持续运行，超出本地能力 |
| **离线时间线补全** | 玩家离线时的小世界状态更新 | 需要在服务器端运行 |
| **多人匹配与社交** | 跨服匹配、好友系统、公会系统 | 中心化服务 |
| **资产市场与交易** | 剧本购买、蓝图交易、区块链交互 | 需要中心化服务保障交易安全 |

### 3.3 负载特征与成本优化

| 服务类型 | 负载特征 | 成本优化策略 |
| :--- | :--- | :--- |
| **房间管理** | 峰值集中在晚间和周末 | 自动扩缩容，闲时缩至最小实例 |
| **世界推演** | 持续运行，但不同世界可独立调度 | 优先级队列——付费主题世界优先推演，免费世界闲时推演 |
| **匹配服务** | 与在线玩家数正相关 | 与房间管理共用Pod，无需独立扩缩 |
| **资产市场** | 交易请求低频但需高可靠 | 预留最小实例，数据库读写分离 |
| **离线时间线补全** | 玩家登录时集中触发 | 预计算+缓存——常见离线时长（1天/3天/7天）的结果提前算好 |

## 四、本地-云端协同架构

### 4.1 任务分配策略

| 任务类型 | 本地处理 | 云端处理 | 决策依据 |
| :--- | :--- | :--- | :--- |
| **角色日常对话** | ✅ 本地7B模型 | ❌ | 高频低复杂度，本地即可 |
| **角色深度情感对话** | ❌ | ✅ 云端大模型 | 低频高复杂度，需深度推理 |
| **暗杀条件检测** | ✅ 本地规则引擎 | ❌ | P0硬实时，不能上云 |
| **司命叙事干预** | 本地小模型初筛 | ✅ 云端大模型终判 | 高频初筛+低频深度 |
| **ESM物理计算** | ✅ 本地CPU | ❌ | 毫秒级实时，不能上云 |
| **L3图片生成** | 本地缓存复用 | ✅ 云端生成 | 优先本地种子库，miss时上云 |
| **L3 WOW时刻演算** | ✅ 本地GPU实时 | ❌ | 需要毫秒级响应 |
| **L3视频生成** | ❌ | ✅ 云端离线 | 分钟级，无实时要求 |
| **世界持续推演** | ❌ | ✅ 云端 | 7×24小时运行 |
| **离线时间线补全** | ❌ | ✅ 云端 | 玩家离线时执行 |
| **房间状态同步** | ❌ | ✅ 云端 | 中心化服务 |
| **AI同伴离线行为** | ❌ | ✅ 云端CPU | 玩家离线时执行 |

## 五、成本优化模型

### 5.1 单用户月度成本估算（混合方案）

| 服务 | 使用量 | 单价 | 月度成本 |
| :--- | :--- | :--- | :--- |
| 本地7B模型日常对话 | 95%对话 | 几乎零成本（电费） | ¥0 |
| 云端大模型深度对话 | 30次/月 | ¥0.05-0.15/次 | ¥1.5-4.5 |
| 云端图片生成 | 10次/月 | ¥0.1-0.3/次 | ¥1-3 |
| 云端视频生成（离线） | 1次/月 | ¥1-3/次 | ¥1-3 |
| 房间状态同步 | 30小时/月 | 几乎零成本 | ¥0 |
| 离线时间线补全 | 30次/月 | 几乎零成本（预计算+缓存） | ¥0 |
| **总计** | — | — | **¥3.5-10.5/月** |

### 5.2 云端GPU成本控制

| 策略 | 说明 | 预计节省 |
| :--- | :--- | :--- |
| **预留实例+竞价实例混合** | 基础容量用预留实例，峰值用竞价实例 | 30-50% |
| **模型量化与蒸馏** | 云端大模型使用量化版本，降低GPU内存占用 | 20-30% |
| **请求批处理** | 多个玩家的L3生成请求合并批处理 | 15-25% |
| **种子库缓存命中** | 优先返回已生成内容，减少实时生成 | 40-60% |
| **闲时缩容** | 凌晨低峰期自动缩减GPU实例 | 20-30% |

### 5.3 平台承担 vs 玩家承担

| 成本类型 | 承担方 | 说明 |
| :--- | :--- | :--- |
| 本地7B模型推理 | 玩家（硬件折旧+电费） | 玩家自己的显卡承担，平台零成本 |
| 云端大模型深度对话 | **平台承担**（基础服务） | 作为平台基础服务，计入运营成本 |
| 云端图片/视频生成 | **平台承担**（基础配额）+ 玩家购买额外配额 | 基础配额内的L3生成为免费服务，超出部分可付费扩容 |
| 房间状态同步 | 平台承担 | 基础网络成本 |
| 离线时间线补全 | 平台承担 | 预计算+缓存，成本极低 |
| 世界持续推演 | **大玩家承担**（算力套餐） | 主题世界的大玩家购买算力套餐，覆盖7×24小时推演成本 |
