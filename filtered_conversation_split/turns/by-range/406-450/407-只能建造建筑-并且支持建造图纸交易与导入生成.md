## 用户

只能建造建筑，并且支持建造图纸交易与导入生成。

## DeepSeek

基于你的明确需求，我们的建造系统将从“体素沙盒”的宏大构想中精准抽离，聚焦于**建筑的建造、图纸化交易与智能生成**。这将把《开本》的建造玩法从一个“装扮家园”的层面，升级为一个“创作者设计蓝图、玩家一键生成、生态内自由交易”的完整闭环。

以下是这个方案的完整设计：

### 一、核心体验：从“搭积木”到“建筑蓝图大师”

玩家不再需要逐个方块地堆砌，而是可以像一位建筑大师一样，设计、交易并一键生成精美的建筑。

| 维度 | 说明 |
| :--- | :--- |
| **核心理念** | 玩家设计或获取“建筑图纸”，消耗资源，一键在领地中生成建筑。 |
| **创造方式** | 在专用的建造模式下，使用预制组件（墙壁、屋顶、立柱等）进行蓝图设计。 |
| **核心资产** | **建筑图纸**，它记录了建筑的全部设计数据，是一种可交易、可复制的数字资产。 |
| **实现方式** | 玩家使用**图纸**→系统校验材料→司命驱动生成动画→建筑落成。 |

### 二、技术蓝图：定义“建筑图纸”标准

一张建筑图纸，本质上是一个包含完整建造信息的序列化数据包。

*   **`BuildingBlueprint` (建筑蓝图)**
    *   `blueprint_id`: 唯一标识符。
    *   `components`: 一个列表，包含构成建筑的所有零件（如石砖x100，木梁x20）。
    *   `placement_grid`: 每个零件在3D网格中的精确位置和旋转信息。
    *   `metadata`: 建筑名称、风格标签（如“哥特式”）、尺寸和预览图。

### 三、核心玩法：蓝图建造、交易与生成

这是一个围绕图纸资产展开的全新玩法循环：

1.  **蓝图建造模式**：玩家在自己的领地进入一个类似“上帝模式”的编辑界面。从庞大的组件库中选择零件，在3D网格中进行放置、旋转、堆叠。系统会实时校验结构的物理合理性并渲染效果。
2.  **图纸交易市场**：完成设计后，玩家可以将建筑打包成“建筑图纸”。这份图纸可以在**资产市场**中出售。创作者可以为图纸定价，并在后续交易中持续获得版税收入。
3.  **图纸导入与生成**：玩家在市场购买图纸后，在自己的领地选择一片空地并“使用”图纸。系统会校验是否有足够的材料（如木材、石料）。确认后，**司命**将接管建造过程，驱动建筑动画（如地基铺设、墙体升起），最终完成建筑。
4.  **众筹建城**：一个宏大的建筑计划（如建造一座巫师塔），可以由大玩家发起，社区玩家共同捐赠物资，达成目标后，建筑在广场上拔地而起。

### 四、与《开本》现有系统的无缝集成

*   **司命 (Siming)**：驱动建筑生成动画，管理和校验建造条件（如平整度）。在离线时间线中，它会记录“建筑已开始动工”，并为你补全建造日志。
*   **ESM (环境状态管理器)**：管理建筑材料（木材、石料）的物理状态。建筑的墙壁和门都支持物理破坏，可被焚烧或摧毁。
*   **AI同伴**：她会对你的新建筑发表看法，并可能在你离线时帮忙维护。建筑的外观和功能也能为她的自主行为提供新的环境。
*   **L3视觉增强**：在建筑落成的瞬间，系统会为你生成一张专属的纪念图。

### 五、创作者经济闭环

这是一个全新的“设计-交易-收益”经济飞轮：

1.  **创作者**：使用蓝图编辑器设计建筑，将其打包为“建筑图纸”，上传至资产市场。
2.  **交易**：其他玩家在市场中浏览、预览并购买心仪的建筑图纸。
3.  **收益**：图纸销售所得，创作者与平台按智能合约自动分账。若该图纸被用于商业用途，创作者还能获得额外版税。
4.  **增值**：创作者为热门建筑推出配套的主题装饰包，实现持续收益。

这个系统将让《开本》的创造生态从“个人打扮”升级为“建筑设计蓝图”的创作、交易与分享，为玩家带来前所未有的创造自由和商业价值。
