# 《开本》L3视觉增强层完整设计

## 一、核心定位

L3视觉增强层是《开本》世界引擎的“视觉表现中枢”，负责一切物体状态切换、生物成长、物件培育的平滑视觉呈现，以及关键时刻的视觉高光。它不是孤立的美术特效层，而是通过事件总线与L1、L2深度协同的智能视觉系统。

**核心原则**：
- **一切视觉变化由L2决策、L3执行**——L3不主动触发任何效果，只接收L2的指令
- **点云过渡是通用基础**——任何需要平滑视觉变化的场景，都由点云过渡系统提供底层支撑
- **视觉障眼法是补充手段**——当数据不足以支撑平滑过渡时，用符合世界观的叙事化方式掩盖跳变
- **分层复用，P0优先**——预生成和缓存优先，实时生成仅用于高价值节点


## 二、L3层内部模块

| 模块 | 职责 | 技术实现 |
| :--- | :--- | :--- |
| **点云过渡系统** | 在两个端点状态之间生成无限多的平滑中间态，驱动一切视觉变化的连续呈现 | 4DGS + 变形场 + GDGS插件 + Godot实时渲染 |
| **WOW时刻导演** | 在关键时刻触发实时演算的戏剧化镜头——镜头调度、滤镜切换、慢动作、粒子特效 | 司命镜头脚本 + Godot实时演算 + 粒子系统 |
| **图片生成服务** | 线索特写、角色立绘、建筑效果图、生物图鉴、纪念照 | P0/P1/P2分层策略 + 预生成 + 实时生成API |
| **视频生成服务（离线）** | 生物生态纪录片、建筑漫游视频、结局CG | 异步生成 + 种子库复用 |
| **资产预览系统** | 在市场中展示建筑蓝图效果图、生物基因模板预览动画 | 预生成 + 实时演算 |
| **视觉障眼法系统** | 当数据不足以支撑平滑过渡时，用粒子爆发、结茧/能量场、沙化/光化、全息投影等手法掩盖跳变 | 粒子特效 + 动态着色器 + UI动画 |


## 三、与L2层各系统的协同

### 3.1 与司命的协同

| 协同场景 | 司命的角色 | L3的角色 |
| :--- | :--- | :--- |
| **建筑落成** | 判定建造条件满足，发送`building_completed`事件 | 触发WOW时刻导演——实时演算建筑从地基升起的动画，随后生成建筑纪念图 |
| **生物成长里程碑** | 管理成长时间线，发送`growth_milestone`事件（如“小猫睁眼”、“银杏第一次落叶”） | 生成纪念照或图鉴更新；若玩家在凝神模式下观察，加载高精度点云快照 |
| **物件培育完成** | 判定培育条件满足，发送`item_cultivation_complete`事件 | 播放培育完成的粒子特效（如“水晶在月光下凝结”），生成纪念图 |
| **稀有变异出现** | 判定变异条件触发，发送`rare_mutation`事件 | 生成变异个体与母体的对比照，标记为“珍贵发现” |
| **案件高潮** | 判定暗杀、对峙、坦白等关键时刻 | 触发WOW时刻导演——实时演算戏剧化镜头（推近面部特写、慢动作、滤镜切换） |
| **离线时间线补全** | 玩家登录时补全离线期间的关键事件 | 若有建筑落成、生物成长等里程碑，在登录简报中附带L3生成的纪念图 |


### 3.2 与ESM的协同

| 协同场景 | ESM的角色 | L3的角色 |
| :--- | :--- | :--- |
| **物体燃烧** | 驱动燃烧状态机，实时计算燃烧进度（0.0→1.0） | 点云过渡系统根据燃烧进度，在“完好”和“烧毁”端点之间实时渲染中间态 |
| **物体潮湿/干燥** | 驱动潮湿状态机，计算湿度变化 | 点云过渡系统根据湿度参数，在“干燥”和“潮湿”贴图之间平滑过渡 |
| **物体破碎** | 判定受力超过阈值，驱动破碎状态机 | 点云过渡系统在“完整”和“破碎”端点之间生成中间态；碎片飞溅的粒子特效同步播放 |
| **天气变化** | 驱动天气状态机，更新全局温度、湿度、风力 | L3根据天气参数调整滤镜（暴风雪色调、雨后晴空色调）；粒子特效同步（雪花、雨滴） |
| **生物物理状态** | 更新生物的碰撞体大小（随体型增长） | 点云过渡系统同步更新生物的视觉体型，与碰撞体匹配 |


### 3.3 与事件总线的协同

| 协同场景 | 事件总线角色 | L3的角色 |
| :--- | :--- | :--- |
| **事件订阅** | L3订阅关键事件类型：`item_state_changed`、`growth_milestone`、`building_completed`、`rare_mutation`、`case_climax`等 | 收到事件后，根据事件类型和优先级触发对应的视觉增强 |
| **生成请求路由** | 将L2的生成请求转发给L3 | L3的调度器接收请求，执行P0/P1/P2策略判定，返回生成内容或降级方案 |
| **生成结果分发** | 将L3的生成结果（图片URL、视频URL）推送给L1客户端 | L1在对应位置渲染呈现 |


### 3.4 与角色智能体的协同

| 协同场景 | 角色智能体的角色 | L3的角色 |
| :--- | :--- | :--- |
| **AI同伴感知建筑变化** | 通过感知过滤器接收`building_completed`事件，驱动对话和行为 | L3生成的建筑纪念图可作为同伴对话中的“展示物” |
| **AI同伴感知生物成长** | 通过感知过滤器接收`growth_milestone`事件，产生情感反应 | L3生成的成长纪念照可作为同伴回忆的素材 |
| **AI同伴的微表情驱动** | 心智模型输出情绪参数（恐惧、愤怒、悲伤等） | L1的形态键系统根据情绪参数实时驱动面部表情——这不是L3的职责，但L3的WOW时刻导演可以在关键时刻给AI同伴特写镜头 |


### 3.5 与生物引擎的协同

| 协同场景 | 生物引擎的角色 | L3的角色 |
| :--- | :--- | :--- |
| **生物从幼年到成年** | 管理成长时间线，输出当前成长进度（0.0→1.0） | 点云过渡系统根据成长进度，在两个阶段端点之间实时渲染平滑中间态 |
| **生物繁殖** | 判定繁殖条件满足，生成新个体的基因数据 | 新个体生成时，L3播放粒子特效（如“蛋壳碎裂”、“花粉散落”）；点云过渡驱动新个体从幼体到成体的初始生长动画 |
| **生物变异** | 判定变异触发，输出变异参数 | L3生成变异个体的外观——点云过渡在母体外观基础上，按变异参数偏移，生成独特的变异外观 |


### 3.6 与物件引擎的协同

| 协同场景 | 物件引擎的角色 | L3的角色 |
| :--- | :--- | :--- |
| **零件组装成物件** | 接收玩家组装操作，计算最终属性 | 组装完成时播放粒子特效（如“零件聚合光效”）；点云过渡驱动零件从分离到聚合的动画 |
| **物件培育** | 管理培育时间线，输出培育进度 | 点云过渡系统在“种子”和“成品”端点之间实时渲染连续变化 |
| **物件附魔/升级** | 判定升级条件满足 | 视觉障眼法系统触发元素爆发特效，掩盖模型切换 |


## 四、与L1层各系统的协同

| 协同场景 | L1的角色 | L3的角色 |
| :--- | :--- | :--- |
| **3D场景渲染** | 渲染所有可见物体、角色、环境 | L3生成的点云中间态在L1的场景中实时渲染；L3生成的图片以画中画形式叠加在L1画面之上 |
| **空间音频** | 提供方向性声音 | L3的WOW时刻导演触发时，音频系统同步切换BGM和音效 |
| **UI系统** | 显示HUD、背包、笔记面板 | L3生成的图片自动保存至笔记面板；L3生成的纪念图在UI中弹出展示 |
| **凝神模式** | 暂停时间，允许自由视角 | L3加载高精度点云快照，供玩家仔细观察 |


## 五、完整协同示例

### 示例一：建筑落成

```
玩家使用建筑蓝图 → L1发送事件 → 事件总线 → L2物件引擎校验材料
    ↓
L2司命判定条件满足 → 发送building_completed事件
    ↓
事件总线 → L3 WOW时刻导演触发
    ↓
L3指令 → L1实时演算：建筑从地基升起、墙体逐层堆叠
    ↓
L3指令 → L1粒子特效：庆祝彩带、魔法光效
    ↓
L3指令 → L1音频：切换为庆祝BGM
    ↓
L3图片生成服务：生成建筑纪念图
    ↓
L3结果 → L1 UI：纪念图弹出展示，保存至笔记面板
    ↓
事件总线 → L2角色智能体：AI同伴感知建筑落成，发表评论
```

### 示例二：生物变异

```
L2生物引擎判定变异触发 → 输出变异参数
    ↓
事件总线 → L3稀有变异事件
    ↓
L3点云过渡系统：在母体外观基础上按变异参数偏移，生成变异外观
    ↓
L3图片生成服务：生成变异个体与母体的对比照
    ↓
L3结果 → L1 UI：对比照弹出，标记为“珍贵发现”
    ↓
L3粒子特效：变异个体周围出现特殊光效（如金色光晕）
    ↓
事件总线 → L2角色智能体：AI同伴感知稀有变异，产生情感反应
    ↓
L2司命：记录变异事件，计入离线时间线
```

### 示例三：物体燃烧（跳跃式变体的视觉障眼法）

```
ESM驱动窗帘燃烧 → 燃烧进度0.0→1.0
    ↓
点云过渡系统：在“完好”和“烧毁”端点之间实时渲染平滑中间态
    ↓
当燃烧进度达到0.8时，ESM判定窗帘即将完全烧毁
    ↓
L3视觉障眼法系统触发：
  - 窗帘区域爆发出大量火焰粒子（遮蔽视野，持续1秒）
  - 在粒子最浓密的瞬间，底层模型切换为“烧毁残骸”静态模型
  - 粒子消散后，窗帘已变成焦黑残骸
    ↓
事件总线 → L2角色智能体：AI同伴感知火灾，驱动避险行为
```


## 六、L3层的资源管理

| 资源类型 | 管理策略 |
| :--- | :--- |
| **点云端点快照** | 按物体类型和状态类型存储，凝神模式下加载高精度版本，日常使用标准精度版本 |
| **预生成图片** | 角色立绘、场景概念图、通用线索图——剧本加载时预生成，零延迟调用 |
| **实时生成图片** | P0完美调用优先（种子库精确匹配），P1微调次之，P2实时生成仅用于高价值节点，超时则降级为P3通用占位 |
| **离线生成视频** | 生物生态纪录片、建筑漫游视频——异步生成，分钟级，不计入实时配额 |
| **粒子特效模板** | 火焰、烟雾、水滴、碎片、魔法光效等——预制模板，参数可调，所有模块共享 |
| **视觉障眼法模板** | 元素爆发、结茧/能量场、沙化/光化、全息投影——预制模板，司命按需调用 |


## 七、一句话总结

L3视觉增强层是《开本》世界引擎的视觉中枢，由点云过渡系统提供一切平滑视觉变化的通用基础，由WOW时刻导演提供关键时刻的戏剧化镜头，由图片/视频生成服务提供可复用的视觉资产，由视觉障眼法系统在数据不足时用叙事化方式掩盖跳变。L3通过事件总线与L2的司命、ESM、生物引擎、物件引擎、角色智能体深度协同，确保世界的每一次变化——从窗帘燃烧到生物变异、从建筑落成到物件培育——都是平滑、自然、充满叙事感的视觉体验。
