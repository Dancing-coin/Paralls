## 一、人物定制：捏脸系统与动作库

### 1.1 捏脸系统

**需求**：玩家能自由定制角色外观（面部、体型、肤色等），且这些修改能实时映射到角色智能体的微表情和动作上。

**技术方案**：采用 **Blend Shape（形态键）** 技术。通过在3D模型中预设数百个形态键（如“鼻梁高度”、“眼间距”、“下颌宽度”等），玩家通过滑块调节这些参数，系统实时混合对应的形态键权重，生成独一无二的面孔。这套系统与我们已有的角色智能体心智模型完美衔接——司命驱动的微表情（如撒谎时的嘴角抽动、愤怒时的眉头紧锁）直接作用于这些形态键之上。

**开源灵感**：

- **humanizer**：一个专为Godot 4.3设计的3D角色创建器插件，基于MakeHuman程序和MPFB2插件。提供超过一千个形态键，支持调节体重、身高、性别、种族、年龄等参数，可生成无尽种类的独特角色。这是最接近我们“捏脸系统”需求的开源方案。

- **SnekStudio**：免费开源的Godot VTuber软件，支持50种面部形态键和手部追踪，可接收VMC协议导入实时追踪数据。其形态键系统可作为捏脸模块的参考。

- **Godot ARKit插件**：利用苹果ARKit的全套面部形态键（52种标准表情），将数据直通Godot引擎，无需中间DCC软件。插件作为autoload单例运行，所有形态键数据全局可访问。这套系统可直接用于角色的实时面部动画驱动。

- **MakeHuman**：完全免费的开源3D人物建模软件，专为简化虚拟人创建而设计。humanizer插件正是基于MakeHuman开发的，两者结合使用效果更佳。

### 1.2 动作库

**需求**：角色需要丰富的动作库，且动作能根据情境和人设自动选择。

**技术方案**：我们已设计的**标准化角色动作模板库**（拾取、投掷、开门、坐下、躲藏等）通过IK（逆向运动学）适配不同体型的角色。动作选择由角色智能体的心智模型驱动——高胆量者走路大步流星，低胆量者步态谨慎。这套系统与捏脸系统无缝衔接：无论玩家如何定制角色外观，动作模板和IK系统都能自动适配。

**开源灵感**：

- **Godot Voxel**：Zylann/godot_voxel是Godot生态中最成熟的体素方案，提供完整的C++模块，支持体素渲染、编辑和地形生成。

## 二、生物生态：有机生长与繁殖

### 2.1 生物的生长与生命周期

**需求**：生物不是静态模型，而是能从小到大的“有机生长”，且这个生长过程是平滑连续的。

**技术方案**：我们已设计的**阶段式成长系统**（如小猫从“新生儿→幼崽→半大→成年”）与**点云过渡技术**（在两个阶段模型之间生成平滑的视觉中间态）相结合。司命管理成长时间线，ESM管理生物的物理状态（体型、体重、碰撞体）。

**开源灵感**：

- **Genesis**：一个用Godot构建的免费开源沙盒进化模拟器，实时展示特征如何通过自然选择代代相传。特别适合教学或独立探索进化概念，为《开本》的生物遗传与变异系统提供直接参考。

- **Thrive**：开源的进化模拟游戏，用Godot引擎开发，以科学精确的方式模拟生命进化。玩家控制一个单细胞生命体，经历整个进化过程。最新版本v1.0.1已升级至Godot 4.6，增加了多细胞修复、身体计划遵循等功能。其进化机制（自然选择、适应性演化）和生态环境构建可为《开本》的生物生态模块提供深度参考。

- **CellBorn**：一个AI驱动的微生物RTS与模拟游戏，用Godot从头构建。每个生物——玩家自己的细胞、捕食者、病毒、细菌——都在一个活的、反应性的生态系统中运行。其AI驱动生态的理念与《开本》的智能体驱动生态高度契合。

### 2.2 繁殖与种群演化

**需求**：生物能根据基因模板繁殖后代，后代可能产生可控的随机变异。

**技术方案**：我们设计的**生物引擎**中的“种群繁衍引擎”通过解析基因模板，在满足条件时自动生成新个体。变异算法基于父代的基因参数进行可控随机偏移，确保后代既有遗传特征又有独特差异。

**开源灵感**：

- **Tribes-Evolved**：一个用Godot制作的2D程序化进化模拟项目，开源。虽然维度不同，但其进化算法和种群模拟逻辑可直接参考。

- **Thrive**：其微生物阶段到多细胞阶段的完整进化链（从单细胞→多细胞→复杂生物），以及跨物种适应性演化机制，可为《开本》的物种设计提供完整的科学框架。


## 三、物件创造：组装、安装与属性定义

### 3.1 物件组装系统

**需求**：道具、武器、家具等物件不是“买来就用”的成品，而是由玩家或创作者通过“零件组装”的方式自由创造。一把剑的属性由剑柄、剑刃、护手等零件的材质和形状共同决定。

**技术方案**：**组装式创造**通过“匠造工作台”实现——一个基于物理体积的蓝图网格，玩家将任意零件（如剑柄、刀刃、宝石）拖拽到网格上，系统自动计算最终物件的属性（攻击力、耐久度、重量）和外观。

**开源灵感**：

- **expressobits/inventory-system**：专为Godot 4设计的模块化库存系统，支持多人游戏，将逻辑与UI分离，使用物品作为独立资源。其物品作为独立资源的理念可直接用于我们的“零件组装”系统——每个零件都是一个独立的Item资源，组合后生成新的复合Item。

- **Pandora**：专为Godot Engine打造的RPG数据管理插件，可管理物品、法术、能力、角色、怪物和战利品表等元素。其物品和能力的模块化管理思路可为物件组装系统提供参考。

### 3.2 生长式创造

**需求**：有些物件不是“造”出来的，而是“长”出来的——如一颗树种最终长成一把弓，一株魔法植物凝结出水晶。

**技术方案**：司命驱动一个缓慢的生长过程，点云过渡技术在“种子”和“成品”之间生成连续的视觉变化。ESM管理生长过程中的环境条件（光照、水分、土壤）。

**开源灵感**：

- **Genesis**和**Thrive**：它们的生物演化机制（从简单到复杂、从单一功能到多功能）与物件“生长”的理念相通——将物件的“生长”视为一种受控的“演化”，由基因模板（蓝图）决定最终形态和属性。

### 3.3 合成系统

**需求**：多个物品可以合成为新物品。

**技术方案**：合成配方不是硬编码的，而是基于物品的**材质标签**和**属性标签**动态匹配。例如，`木材`+`金属`+`锋利`可合成各种刀具。创作者可以在编辑器中使用**可视化蓝图**定义合成规则，也可以上传自定义配方到资产市场供其他玩家使用。

**开源灵感**：

- **Godot游戏数据模型系列教程**：godotneers/game-data-video项目提供了创建合成系统的完整示例，包含物品数据库、库存对话框和合成逻辑的实现。

- **Material Maker**：一个基于Godot引擎的开源程序化纹理和材质创作工具，支持通过可视化编程创建PBR材质。拥有近250个节点，可导出至Godot、Unity、Unreal等引擎。其基于节点图的材质创建流程可直接用于物件的属性可视化编辑。


## 四、世界建造：场景、建筑与蓝图交易

### 4.1 场景与建筑建造

**需求**：创作者能设计建筑，大玩家能拼接场景构建世界。建筑可保存为“蓝图”在市场中交易，其他玩家购买后可一键生成。

**技术方案**：我们已设计的**场景建造系统**支持体素建造和预制件放置。建筑完成后可保存为“建筑蓝图”（Building Blueprint），包含所有组件的位置、材质、属性信息。蓝图在资产市场中交易，购买后由司命驱动建造动画，在领地中一键生成。

**开源灵感**：

- **In Game Building System (C#)**：一个全面的建造模拟游戏入门套件，专为Godot 4设计。包含网格和自由形式两种建造方式，非常适合建筑模拟游戏。其建造机制（网格对齐、自由放置、拆除）可直接作为《开本》建造系统的原型。

- **Starter Kit City Builder**：Godot 4.3的城市建造基础模板，包含建筑和拆除结构、平滑相机控制等功能。其城市场景拼接和相机控制机制可为大玩家的世界编辑器提供参考。

- **Goshapes**：Godot 4的曲线建模和关卡构建工具，通过Path3D节点创建自定义方块网格（地形、建筑等），提供直观的曲线式关卡创建方式。

- **FloorArchitect**：Godot插件，用于生成类似《以撒的结合》或《月光骑士》风格的地下城房间布局。其程序化生成房间布局的逻辑可为世界编辑器的自动填充功能提供灵感。

### 4.2 世界映射与进化

**需求**：不同世界地图可以相互映射更新，世界随玩家行为持续进化，形成共有资产池。

**技术方案**：我们已设计的**世界快照系统**记录世界的阶段性状态，**世界映射引擎**管理跨世界数据同步和资产版权追溯。**区块链确权系统**确保所有贡献者的版权得到保护和收益化。

## 六、与《开本》现有系统的集成

| 现有系统 | 在新模块中的角色 |
| :--- | :--- |
| **司命** | 管理生物成长时间线、物件生长过程、建筑建造动画、离线时间线中的建造进度 |
| **ESM** | 管理方块材质属性、生物物理状态（碰撞体随体型变化）、物件物理属性（木质可燃烧） |
| **角色智能体** | AI同伴对新建成的建筑发表看法、对培育出的新物种产生情感反应 |
| **事件总线** | 广播方块放置/破坏事件、生物成长里程碑事件、物件合成完成事件 |
| **L3视觉增强** | 建筑落成时生成纪念图、新物种诞生时生成图鉴、生物成长关键阶段生成纪念照 |
| **资产市场** | 建筑蓝图、基因模板、零件蓝图、合成配方的交易与版税分账 |


**一句话总结**：《开本》世界引擎的建造与设计系统由四大模块构成——人物定制（Blend Shape捏脸+动作库）、生物生态（阶段成长+点云过渡+基因模板+种群繁衍）、物件创造（组装式匠造+生长式创造+材质标签合成）、世界建造（体素建造+蓝图交易+世界映射）。每个模块都有成熟的开源项目可供参考。所有系统通过司命、ESM、角色智能体和事件总线无缝集成，形成完整的“世界引擎”创造生态。
