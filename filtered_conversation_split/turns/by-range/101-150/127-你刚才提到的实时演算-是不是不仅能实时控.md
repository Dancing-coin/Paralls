## 实时演算的完整能力：角色、镜头、场景的三位一体

实时演算的本质是**用代码实时驱动游戏引擎的所有元素**，而非播放预先录制的视频。这意味着它拥有对游戏世界的**完全控制权**。

### 一、角色控制：从身体到表情的全栈驱动

我们已讨论过角色的表情和动作映射，实时演算是这些映射的**执行引擎**。

| 控制维度 | 实现方式 | 在《开本》中的应用 |
| :--- | :--- | :--- |
| **身体动作** | 动画状态机 + 程序化动画 + IK（逆向运动学） | AI角色根据心智状态自动行走、坐下、拍桌、逃跑；手部IK让角色能精准指向某个线索物品 |
| **面部表情** | 骨骼动画 + 形态键混合 | 系统读取角色的压力值、情绪标签，实时混合出“紧张”、“愤怒”、“恐惧”等复杂表情 |
| **口型同步** | 音频分析驱动的自动口型系统 | 无论是AI的TTS语音还是玩家的实时语音，角色口型都能实时匹配 |
| **眼神注视** | IK驱动的眼球追踪 | 角色会自动注视正在说话的对象、正在查看的物品，或因为心虚而回避他人目光 |

### 二、镜头控制：司命的导演工具箱

实时演算让镜头不再是固定的，而是由系统实时调整的**叙事工具**。

| 镜头技法 | 实现方式 | 在《开本》中的应用 |
| :--- | :--- | :--- |
| **景别切换** | 虚拟摄像机位置和FOV的动态调整 | 线索特写时，镜头自动推近；对峙时，使用过肩镜头或双人镜头；情绪高潮时，给角色面部大特写 |
| **运镜** | 摄像机路径动画 + 程序化抖动 | 手持跟拍的轻微抖动增加临场感；平稳的推轨镜头用于正式场景；突然的快速变焦强调震惊 |
| **焦点控制** | 景深(DOF)实时调整 | 背景虚化聚焦角色；焦点从一个人物转移到另一个人物，引导玩家注意力 |
| **滤镜与色调** | 后处理效果的动态混合 | 恐怖时刻画面偏冷偏暗，饱和度降低；回忆闪回时添加柔光或特定色调；愤怒时画面边缘微微泛红 |
| **分屏与画中画** | 多摄像机同步渲染 | 同时展示两个不同场景中角色的行动，增强戏剧张力 |

### 三、场景变化：为叙事服务的动态舞台

实时演算让场景不再是静态的背景，而是可以随剧情推进而变化的**动态舞台**。

| 场景控制 | 实现方式 | 在《开本》中的应用 |
| :--- | :--- | :--- |
| **灯光变化** | 动态光源的实时开关、颜色、强度调整 | 关键证据浮现时，一束“神光”打在物品上；对峙时灯光闪烁；恐怖时刻灯光突然熄灭只剩烛光 |
| **天气与环境** | 粒子系统 + 天空盒动态切换 | 暴风雨逐渐逼近作为外部压力；雨停日出象征真相大白 |
| **物理交互** | 刚体物理模拟 | 角色拍桌时桌上的杯子震动；摔倒时撞翻椅子；门被踹开时门板飞出去 |
| **场景破坏与变换** | 预制件的显隐和替换 | 书架旋转露出密道；壁炉火焰熄灭后出现隐藏空间；被砸碎的花瓶散落一地 |
| **时间流逝** | 全局时间系统 | 从黄昏到深夜，室外的光线逐渐变暗，室内烛光成为唯一光源，增加紧张感 |

## 三者在《开本》中的协同：一场由司命导演的实时演出

角色、镜头、场景并非独立运作，而是由**司命**统一调度，协同呈现一个完整的叙事时刻。

### 以“发现凶手”的WOW时刻为例：

| 时间 | 角色表现 | 镜头控制 | 场景变化 | 玩家体验 |
| :--- | :--- | :--- | :--- | :--- |
| **T+0s** | 玩家点击关键证据 | 镜头缓缓推近到证据上 | 环境音减弱，一束光线聚焦在证据上 | “这个细节...不对！” |
| **T+0.5s** | 玩家的角色表情从困惑变为震惊（自动映射） | 焦点从证据转移到玩家角色脸上 | 背景开始虚化 | 沉浸感加深 |
| **T+1s** | AI凶手察觉到玩家发现了证据，表情闪过一丝恐惧（系统驱动） | 镜头切到凶手，捕捉那转瞬即逝的微表情 | 凶手身边的灯光微微闪烁 | “他慌了！” |
| **T+1.5s** | 凶手下意识地后退半步（自动映射） | 镜头拉远，框住两人对峙的画面 | 两人之间的空间被强调，其他人虚化成背景 | 戏剧张力达到顶点 |
| **T+2s** | 玩家可以选择“公开指认”或“私下质问” | 镜头缓慢环绕两人旋转 | 时间仿佛放慢（子弹时间） | 玩家的决策成为故事的分水岭 |

在这个片段中，实时演算让角色、镜头和场景完美配合，创造出比预渲染视频更具冲击力的体验——因为这一切都是**实时发生的、独一无二的**，而不是播放一个固定文件。

## 对《开本》的开发意义

1. **一切皆可动态**：不需要为每种可能性预先生成视频，系统根据司命的创作实时演出。
2. **完美的适应性**：玩家的任何装扮、任何选择、任何涌现的剧情，都能被实时演算无缝呈现。
3. **降低生成成本**：WOW时刻不再完全依赖AI视频生成，而是用实时演算作为“保底”和“加速”，只在需要极高视觉复杂度时才调用L3生成。
4. **强化推理线索**：角色的表情、动作、镜头的焦点引导，本身就是推理信息，而非单纯的视觉效果。

这正是《开本》追求的——**一个活着的、被实时导演的戏剧舞台**。
