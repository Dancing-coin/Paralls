# 开本 (Paralls) —— 智能体驱动3D沉浸式动态叙事平台


## 一、产品定位与核心愿景

### 1.1 产品名称

**开本 / Paralls**

### 1.2 核心定义

智能体驱动的3D沉浸式动态叙事平台。首款产品形态为多人动态剧本杀，玩家与AI智能体共同参演谋杀谜案，通过自由探索、实时对话、空间互动来影响剧情走向。

### 1.3 核心承诺

**同一个剧本，每一次游戏都不同。**

### 1.4 核心创新

- 从“固定剧本”到“动态涌现叙事”
- 从“文字描述”到“3D世界实时交互”
- 从“人类DM主持”到“AI司命+角色智能体”
- 从“一次性体验”到“无限平行世界”


## 二、世界观总称

**开本宇宙** —— 所有平行世界的集合体。玩家每次“开本”，都是开启一个新的平行世界。

### 2.1 平行世界架构

每个平行世界拥有唯一编号（如UNV-001），是一个完整且自洽的世界观框架，包含：物理法则、历史线、核心冲突、种族文化。

一个平行世界可以容纳无数个剧本，每个剧本都是该世界某段时空中的一个故事切片。

### 2.2 平行世界创建权限

| 阶段 | 权限持有者 |
| :--- | :--- |
| 当前 | 仅官方 |
| 未来 | 高阶创作者（大玩家/Fork开发者）可申请创建 |

### 2.3 商业生态

平行世界的使用权可作为资产在市场上交易。创作者不仅从自己世界内的剧本获益，其他创作者在某平行世界中创作新剧本，需向该世界创作者支付版税。


## 三、剧本杀世界搭建维度（七维体系）

### 3.1 维度总览

- **世界观与时代维度**：所属平行世界（UNV编号）、时代背景、特殊世界规则
- **角色维度**：共同部分（角色档案）+ 区分部分（扮演者类型：人类 vs AI，权限完全一致）+ 关系网络
- **案件与叙事维度**：固定历史、案件生成规则池、线索系统、结局条件
- **场景与空间维度**：场景基础、集体机制（用餐/住宿/活动）、可交互物品、特殊空间机制
- **规则与机制维度**：基础规则、特殊机制（时间循环/多重时间线/暗杀/伪装/状态/能力/迷宫）、信息规则
- **AI智能体与司命维度**：角色智能体配置、司命配置、动态知情人配置
- **体验与呈现维度**：视觉风格、音频风格、难度与标签

### 3.2 贯穿维度：社交关系网络

| 层级 | 内容 | 更新方式 |
| :--- | :--- | :--- |
| 固定关系 | 血缘/婚姻/职业/恩仇/秘密/利益关系及强度 | 创作者在编辑器中逐对设定 |
| 动态关系 | 信任值/怀疑值/好感度/恐惧值/依赖度 | 事件总线实时更新 |
| 结构属性 | 小团体/孤立者/核心枢纽/三角关系/秘密共享链 | 司命实时分析 |

### 3.3 剧本杀类型支持

- **推理流派** (4种)：本格 / 变格 / 新本格 / 叙诡
- **核心玩法** (8种)：硬核推凶 / 故事还原 / 阵营对抗 / 情感沉浸 / 恐怖惊悚 / 机制对抗 / 欢乐轻松 / 立意深思
- **题材背景** (10种)：古风 / 民国 / 现代 / 未来科幻 / 奇幻仙侠 / 西方古典 / 日式 / 克苏鲁怪诞 / 赛博朋克 / 架空世界
- **世界动态性** (3种)：线性叙事 / 分支叙事 / 涌现叙事
- **空间交互深度** (3种)：静态场景 / 可交互场景 / 动态机关场景
- **伪装与博弈深度** (3种)：轻度 / 中度 / 重度
- **特殊机制** (7种，可多选)：时间循环 / 多重时间线 / 暗杀机制 / 角色特殊状态 / 动态阵营切换 / 盲凶模式 / PvPvE混合
- **难度等级** (3种)：新手 / 进阶 / 烧脑


## 四、核心AI系统

### 4.1 角色智能体

**完整心智模型架构**：

基因种子 → 人生记忆 → 品格层 → 行为层 → 决策系统（四层心智模型：感知→理解→规划→执行）→ 记忆系统

**五维人格参数**：胆量、心机、共情、理性、社交

**品格层**：诚实、忠诚、正义感、仁慈、责任感 + 价值优先级

**人格过滤器（三重验证）**：人设过滤器 → 逻辑过滤器 → 得失过滤器

**伪装系统**：伪装深度（零/浅层/中度/深度）、伪装必须有物理道具支撑、伪装压力与破绽机制

**知情人系统**：固定NPC知情人、动态NPC知情人、智能体参与者知情人、玩家参与者知情人

### 4.2 司命 (Siming)

**核心定位**：开本运行时核心智能体。在开本宇宙中被称为“司命”——掌管每个平行世界的命运、因果与戏剧性的意识。

**技术架构**：Harness编排框架 + 大模型(LLM) + 规则程序(Rule Engine)

**五个子系统**：

| 子系统 | 职责 |
| :--- | :--- |
| **事实核心** | 存储并守护不可变事实，事实锁定时间线管理，逻辑一致性检查 |
| **天平系统** | 监测线索分布、阵营胜率、玩家参与度、游戏节奏 |
| **冲突与案件生成器** | 检测角色间冲突，条件满足时生成新案件 |
| **高阶知识图谱引擎** | 维护所有参与者的知识状态和高阶知识 |
| **干预执行器** | 四层干预阶梯（冲动/环境/NPC/节奏），通过干预原则过滤器 |

**干预原则过滤器**：间接性、不可见性、逻辑自洽、公平性

**暗杀催化机制**：动机监测→可玩性评估→条件排列→弹窗确认→催化后克制


## 五、核心游戏机制

### 5.1 信息共享机制

公开对话 / 私密对话(耳语模式) / 展示物品 / 带人查看 / 留影石/相机拍摄

### 5.2 三种知识形态

| 类型 | 定义 |
| :--- | :--- |
| **公共知识** | 每个人都知道，且知道别人也知道 |
| **共有知识** | 多人私下共享，其他人不知道 |
| **高阶知识** | A知道（或不确定）B知道某事 |

### 5.3 暗杀机制

**触发条件**：致命动机 + 信息空窗期 + 独处窗口 + 能力匹配 + 代价评估

**暗杀能力等级**：L0-L4

**暗杀必然留下的痕迹**：尸体、凶器、打斗痕迹、时间线矛盾、潜在目击者

### 5.4 迷宫与时空机制

- **迷宫机制**：空间重映射、感知欺骗、司命动态调控
- **时空机制**：多重时间线（时间线标签、双重记忆、分歧点）、时间循环（记忆碎片、循环规则、保留物证）

### 5.5 集体机制

集体用餐、集体住宿、密道/密室

### 5.6 留影石/相机系统

适用于不同时代背景的证据记录工具

### 5.7 默认规则

- 初始死者必须为NPC
- 局内死亡仅通过暗杀机制（暗杀发起人必须为玩家）
- NPC不可主动发起暗杀
- 关键NPC强制智能体驱动


## 六、玩家体验与交互界面

### 6.1 人类玩家与AI智能体权限完全一致

移动、对话、物品交互、信息共享、暗杀、伪装管理、投票、说谎/欺骗——所有权限完全相同。

### 6.2 开本时的两份档案

### 6.3 玩家辅助面板（可关闭）

玩法指引 / 机制速查 / 决策建议 / 行为后果预估

### 6.4 强制沉浸设置

- **变声器**：不可关闭，根据角色档案自动配置
- **文字润色**：可关闭，AI将玩家输入润色为符合角色语言风格的表达

### 6.5 移动与控制系统

行走/奔跑/潜行/蹲伏，第一/第三人称切换，聚焦观察、环顾四周

### 6.6 交互动作系统

- **对角色**：公开交谈、耳语、展示物品、移交物品、跟随、邀请跟随、观察、搜身、救治、攻击/暗杀、唤醒扶起
- **对物品**：拾取、检查调查、使用、推拉、打开关闭、隐藏躲藏、破坏、修复
- **对场景**：坐下、点燃熄灭、窃听、标记、攀爬翻越
- **全局行动**：呼喊、制造噪音、留下标记、加速移动、潜行移动、假装受伤、自首坦白、伪装调整、查看环境、等待

### 6.7 OOC行为处理

系统层面拦截、司命OOC评分监控、游戏世界自然反应、GM工具箱处理严重违规。玩家选择偏离人设的战略行为是游戏策略的一部分，不被视为OOC。

### 6.8 “凝神”能力（单人/AI模式专属）

在纯单人模式或纯AI队友模式下，玩家可获得时间暂停能力来慢慢体验。凝神状态下可以360度环顾四周、凝视获取线索、沉浸式记录、整理思路，但不能移动、不能交互、不能推进逻辑判定。


## 七、AI系统架构

### 7.1 感知系统

**核心原则**：智能体不截图，而是接收与人类同源的结构化语义事件流。

- **视觉感知**：结构化“可见对象列表”
- **听觉感知**：结构化“可听事件列表”（含清晰度分级）
- **事件感知**：环境变化、物品状态变化、公共事件
- **感知过滤器**：为每个角色计算“此刻应该感知到什么”

### 7.2 动作的阶段化感知

意图阶段→执行阶段→完成阶段，智能体在意图阶段即刻反应。

### 7.3 模型路由架构

三层架构：L1规则引擎（50-150ms）、L2本地小模型（200-800ms）、L3云端大模型（800-3000ms）

任务分级与硬上限：P0致命300ms / P1紧急1500ms / P2重要3000ms / P3普通2500ms / P4背景0ms

兜底机制：L3超时→L2兜底；L2超时→L1预设回应

人格对延迟的调节：高理性延迟+20-50%，低理性延迟-30-50%

### 7.4 技术架构（三层）

| 层级 | 名称 | 技术选型 | 核心职责 |
| :--- | :--- | :--- | :--- |
| **L1** | 确定性空间层 | Godot 4.x | 3D场景渲染、物理碰撞、空间音频、玩家交互、事件埋点 |
| **L2** | 智能体交互层 | Python, llama.cpp, 云端LLM API, XTTS, Whisper | 角色智能体心智模型、司命叙事引擎、对话生成、模型路由 |
| **L3** | 视觉增强层 | 图片/视频生成工作流 API | 线索特写、记忆闪回、公共事件渲染、结局CG |

- **竞争维度**：策展眼光、服务品质、世界观深度、独占内容质量
- **合作维度**：内容流通、流量互导、联合活动、资源共享、资产互补

### 15.5 大玩家与创作者协同

通用分账模式（默认）、深度定制模式（创作者自主发行）、KOL联合发行模式（流量×内容）

### 15.6 大玩家规则制定权

准入规则、身份规则、经济规则、时间规则、社交规则、内容规则、司命干预强度、资产规则、处罚规则


## 十六、主题世界模式（持续运行时空）

### 16.1 核心模式

大玩家构建完整世界观，世界服务器永不重置，司命持续推演时间线。玩家可以以两种身份参与：

| 身份 | 特点 |
| :--- | :--- |
| **穿越旅人** (无身份) | 低门槛、无责任、高自由度，随时来随时走，体验单局剧本杀 |
| **原住居民** (有身份) | 长期投入、与世界共成长，经营资产、参与世界事件、建立长期羁绊 |

### 16.2 剧本化身（官方史诗系列）

由5-8个单局剧本组成的系列包，玩家固定扮演一位指定的传奇角色，局与局之间通过世界快照和变量规则继承。不是单局超长剧本，而是系列连续剧。

### 16.3 本地经营与大玩家服务器的协同

- **本地经营**：买断到本地，完全私密，完全自主控制访问权限
- **大玩家服务器**：在线社区，由大玩家设定规则，需支付持续服务费


## 十七、实现路线图（三阶段）

| 阶段 | 核心特征 | 关键交付 | 可融入的游戏类型 |

## 十八、可创造的全新游戏类型

- **“活剧本”史诗**：不是写死的故事，而是由玩家每一次选择实时编织的个人正史
- **AI同伴跨世界羁绊**：带着同一个有记忆、有情感、会成长的AI同伴，穿越无数平行世界
- **动态涌现的生存博弈**：由智能体的独立意志和玩家的策略选择，自然涌现的生存危机与合作背叛
- **“世界公民”模拟器**：在一个由智能体社会构成的、持续运行的平行世界中真正地“生活”
- **集体叙事创作**：一群玩家与AI智能体共同即兴演出，在同一个世界中实时编织出多条交织的故事线
