## 用户

本地经营与大玩家服务器的不同在于 别的真人玩家的加入是否需要你的许可。

## DeepSeek

你的洞察非常精准。本地经营与大玩家服务器最根本的区别，正在于**社交访问的控制权**。

---

### 一、核心区别：谁来控制访问权限？

| 维度 | 大玩家服务器 | 本地经营（离线模式） |
| :--- | :--- | :--- |
| **访问控制权** | 大玩家设定，所有符合世界规则的角色都可自由进入和互动 | **玩家自己控制**，其他真人玩家的加入需要你的许可 |
| **社交属性** | 开放世界，公共社交 | 私人空间，仅限受邀者进入 |
| **资产可见性** | 你的庄园、资产对服务器内所有玩家可见（可参观） | 你的世界仅对受邀者可见 |
| **交互权限** | 其他玩家可自由访问你的庄园，与你互动 | 你的许可决定一切：谁可以进入、可以做什么 |


### 二、本地经营模式下的社交权限设计

当玩家将世界买断到本地后，你就是这个世界的**唯一主宰**。但这并不意味着这个世界是孤独的——你依然可以邀请朋友进入，只是你需要精确控制他们的权限。

#### 2.1 邀请机制

| 邀请方式 | 说明 |
| :--- | :--- |
| **好友邀请** | 从全球好友列表中邀请特定好友进入你的世界 |
| **临时访客码** | 生成一个一次性或限时有效的访客码，分享给朋友 |
| **白名单** | 设定常驻访客白名单，白名单内的好友可随时进入（无需每次审批） |
| **密码房** | 设定世界密码，知道密码的朋友可自行进入 |

#### 2.2 权限控制

你可以为每位访客设定精细的权限：

| 权限级别 | 说明 |
| :--- | :--- |
| **游客** | 可自由移动、观察、与你和你的同伴聊天，但**不能交互任何物品**，不能打开箱子、不能采摘作物 |
| **帮手** | 可进行基础交互（采摘、浇水、喂动物），但**不能修改建筑**、不能带走物品 |
| **居民** | 可完整互动：建造、改造、使用物品。但**不能带走非赠予物品** |
| **共同经营者** | 几乎与你同等的权限，可邀请其他访客、管理白名单。但**不能变卖资产**（资产所有权始终属于你） |

#### 2.3 访客的可见性

你可以选择让你的世界对特定访客**完全可见**或**部分可见**：
- **完全可见**：访客可以看到你世界的全貌、你的所有资产和同伴。
- **部分可见**：你可以设定“私密区域”（如你的私人房间、宝藏库），访客无法进入或看到这些区域。


### 三、大玩家服务器模式下的社交权限

在大玩家服务器上，社交权限由**大玩家设定**。你作为“原住居民”，需要遵守这个世界的规则。

| 权限类型 | 说明 |
| :--- | :--- |
| **公开区域** | 所有玩家可自由进入和交互（如广场、市集、酒馆） |
| **半公开区域** | 你的庄园外观对所有玩家可见，但进入需要你的许可（如敲门、按门铃） |
| **私密区域** | 你的私人房间、储物室，仅你自己和你设定的“家人”可进入 |
| **交互权限** | 其他玩家可参观你的庄园，但不能随意拿走物品（除非你设定为“可赠予”或“可交易”） |

**大玩家的调控**：大玩家可以设定服务器的全局社交规则，例如：
- 是否允许PVP（玩家之间互相攻击）
- 是否允许偷窃（在某些高自由度世界，可能允许，但会有严厉的惩罚机制）
- 是否允许强行进入他人领地


### 四、两种模式的社交体验对比

| 维度 | 大玩家服务器 | 本地经营 |
| :--- | :--- | :--- |
| **社交广度** | 高。可结识大量陌生玩家，形成社区 | 低。仅限于你邀请的少数朋友 |
| **社交深度** | 中等。需要时间建立信任 | 高。与亲密朋友深度互动 |
| **意外邂逅** | 高。可能遇到不期而遇的访客、商人 | 低。所有访客都是你主动邀请的 |
| **安全与私密** | 中等。需遵守大玩家的规则，有一定风险 | 极高。你拥有完全的控制权 |
| **商业交易** | 便利。可在公共市场中交易 | 不便。只能与受邀者交易 |


### 五、两种模式的自由切换

你的核心资产（庄园、同伴、道具）可以在两种模式间自由迁移：

| 切换方向 | 操作方式 |
| :--- | :--- |
| **大玩家服务器 → 本地** | 将你在服务器上的资产打包下载，后续可在本地继续经营。**离开服务器后，你的公开资产在该服务器上消失**（或转为“托管”状态） |
| **本地 → 大玩家服务器** | 将本地资产上传至某大玩家服务器（需该服务器允许），你的资产将出现在该世界中，并遵守该服务器的社交规则 |
| **跨服务器迁移** | 将资产从服务器A迁移到服务器B（需服务器B支持） |

**迁移的限制**：
- 服务器限定资产（如该服务器的赛季奖励、服务器专属称号）不能带出该服务器
- 买断制资产（皮肤、道具、同伴）可在所有支持的世界中通用


### 六、总结

你精准地抓住了核心：**本地经营与大玩家服务器的本质区别，就是社交访问的控制权在谁手中。**

- **在大玩家服务器上**：你是一个公共社区的一员，享受社交的广度和意外的邂逅，但需要遵守社区的规则。
- **在本地经营中**：你是自己世界的绝对主宰。你可以邀请朋友来玩，但谁能来、能做什么，都由你决定。你的世界，就是你的私人城堡。

这两种模式并非优劣之分，而是**不同的社交偏好**。有些玩家渴望公共社区的热闹，有些玩家珍视私人空间的宁静。《开本》同时提供这两种选择，让每个玩家都能找到最适合自己的方式来经营自己的平行世界。
