## 核心逻辑：从“单局剧本”到“持续叙事流”

在剧本杀中，故事是一个**封闭的圆环**——有开端、有高潮、有结局。一局结束，故事闭环。

在种田经营中，故事是一条**无限延伸的线**——没有预设结局，只有持续涌现的事件和关系。司命不再是“一局游戏的导演”，而是“一个世界的说书人”。

| 维度 | 单局剧本制 | 持续叙事流（种田经营） |
| :--- | :--- | :--- |
| **时间** | 固定时长，有终点 | 永续运行，无终点 |
| **事件** | 由初始案件触发，向结局收敛 | 由时间推进、玩家行为、外部生态持续触发，无限发散 |
| **司命角色** | 编排一局戏的起承转合 | 编织一个世界的日常生活与意外惊喜 |
| **玩家目标** | 完成某个挑战或达成某个结局 | 经营、建设、陪伴、体验——目标由玩家自己定义 |


## 一、司命如何在一个永续世界里注入事件？

司命不再等待“一局游戏开始”，而是持续运行在后台，像一位不知疲倦的说书人，为你的庄园生活注入源源不断的剧情。

### 1. 节律性事件：时间的呼吸

| 事件类型 | 触发方式 | 例子 |
| :--- | :--- | :--- |
| **每日晨间简报** | 每次登录时，司命推送今日简报 | “今天天气晴朗，田里的麦子长势喜人。不过邻居家的鸡又跑过来了，你的同伴小青正在院子里追鸡。” |
| **季节事件** | 按世界内时间触发 | 春天的播种节、夏天的暴雨洪涝、秋天的丰收祭、冬天的第一场雪 |
| **节日事件** | 按世界内日历触发 | 元宵灯会、七夕乞巧、中秋赏月、除夕守岁 |

### 2. 关系事件：羁绊的涟漪

| 事件类型 | 触发方式 | 例子 |
| :--- | :--- | :--- |
| **同伴生日** | 按世界内日历触发 | 你的同伴小青的生日快到了，她无意中提到“以前姐姐每年都会给我煮长寿面”，你可以选择为她准备一份惊喜 |
| **羁绊里程碑** | 你与某同伴的信任值/好感度达到阈值 | 你们一起经历了100个日夜，同伴主动提议为你们的庄园起个名字 |
| **同伴之间的矛盾** | 两个同伴的人格冲突积累到临界点 | 你的两个同伴因为菜地规划吵起来了，需要你调解 |
| **外来者闯入** | 司命随机触发 | 一个受伤的旅人昏倒在庄园门口，你的同伴在照顾他时，似乎对他产生了不一样的情愫 |

### 3. 事件链：从日常到传奇

单个事件不是孤立的。司命可以将多个事件串联成一条**事件链**——一个在持续时空中自然展开的“剧本”。

**例子：流浪商人事件链**

| 阶段 | 事件 | 触发条件 |
| :--- | :--- | :--- |
| **开端** | 一个神秘的流浪商人出现在庄园门口，想用一件“宝物”换一顿饭 | 司命随机触发 |
| **发展** | 商人留下来帮你做了几天活，你的某个同伴发现他举止可疑 | 商人在庄园停留3天 |
| **转折** | 一天深夜，商人悄悄离开了，但留下了一张藏宝图 | 商人的身份被同伴识破后 |
| **高潮** | 藏宝图指向庄园后山的一个隐藏洞穴，里面发现了前任庄园主留下的宝藏和一本日记 | 你决定去寻宝 |
| **余韵** | 日记揭示了庄园的一段隐秘历史，司命据此生成后续事件链（如庄园后人的来访、宝藏的归属争议等） | 你读完日记后 |

这不是一个预设的单局剧本，而是司命根据一个随机事件，实时编织的一条故事线。它在你的日常经营中自然发生，不打断你的生活，但让你的生活多了一层传奇色彩。


## 二、玩家如何与这个持续叙事流互动？

**你不需要“开本”**——你只需要进入你的庄园，世界就在运行。

**司命的叙事引导**：
- 每次登录时，司命推送“今日简报”，告知你世界的变化和待处理的事件
- 重要事件发生时，司命会以“书信”、“访客”、“同伴告知”等符合世界观的方式通知你

**你的自主权**：
- 你可以自由选择何时处理事件。一封信可以放几天再回，一个访客可以请他在客房住下
- 你不处理的事件，司命会让它在世界中自然发酵（访客失望离去、同伴替你处理、或事情变得更加复杂）


## 三、这与单局剧本杀的关系

种田经营不是要替代单局剧本杀，而是提供了另一种与《开本》世界互动的方式：

- **单局剧本杀**：你今天想当一次侦探，进入一个悬疑本，2小时后真相大白。这是一次完整的、有终点的体验。
- **种田经营**：你有一个永续的庄园，每天登录看看，种种田、酿酿酒、和同伴聊聊天。偶尔司命给你一个惊喜——一个神秘访客、一张藏宝图、一段尘封的历史。你可以花几天、几周、甚至几个月来慢慢体验这个故事。

两者可以并存。你的庄园里，也可以招待从剧本杀世界里来的“访客”——比如你在《白蛇传·浮生》里结识的小青，她来你的庄园做客，住上几天，帮帮忙、聊聊天。


## 四、总结

种田经营的核心是：**一个永续运行的世界 + 司命持续注入的事件流 + 玩家的自由经营与陪伴**。

它不是在玩“一个游戏”，而是在经营“一种生活”。司命不是这场生活的导演，而是它的说书人——在你平淡的日常中，悄然编织惊喜、温暖和传奇。

这正是《开本》追求的终极形态之一：**不是给你一个精彩的故事，而是给你一个能长出无数故事的世界。**
