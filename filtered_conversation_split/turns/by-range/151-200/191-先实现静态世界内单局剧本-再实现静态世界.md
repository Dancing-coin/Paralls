## 用户

先实现静态世界内单局剧本，再实现静态世界内连续单局剧本，再实现持续运行世界内连续单局剧本和持续运行并存

## DeepSeek

你的分阶段路线，正是《开本》从“产品”走向“生态”的必经之路。这不是三个独立的产品，而是同一个系统在不同成熟度下的三种运行形态。每一步都建立在下一步的技术积累之上，最终自然过渡到持续运行的完全体。

---

## 分阶段实现路径

### 第一阶段：静态世界内单局剧本（当前MVP）

**核心特征**：每一局剧本是独立、封闭的时空。开局时世界初始化，结束时世界销毁或归档。玩家之间无跨局状态继承。

**关键交付**：

| 模块 | 交付内容 |
| :--- | :--- |
| **L1 确定性空间层** | 3D场景加载、空间音频、物品交互、玩家移动与控制 |
| **L2 智能体交互层** | 角色智能体心智模型（感知→理解→规划→执行）、人格过滤器、对话生成、司命核心（事实数据库+逻辑检查+知识图谱+基础天平） |
| **L3 视觉增强层** | 静态细节图、预生成角色立绘、线索特写实时生成 |
| **L4 剧本与规则层** | 案件规则引擎、线索系统、T0-T2事实锁定、投票与结局判定 |
| **L5 平台与工具层** | 剧本编辑器Alpha、房间管理、状态同步 |
| **商业模式** | 剧本买断制、服务器门票制、创作者分账 |

**技术储备**：
- Godot 3D场景渲染与物理交互
- LLM对话生成与TTS语音合成
- 事件总线基础架构
- 剧本JSON配置解析

**关键约束**：
- 每局结束，所有角色状态和关系数据清空
- 无跨局记忆，无玩家资产累积
- 司命仅在一局范围内运作


### 第二阶段：静态世界内连续单局剧本

**核心特征**：同一平行世界内的多个剧本可以构成**系列**。前作结局通过“世界状态快照”影响续作开局。但每局依然是独立运行的，世界本身不持续运转。

**新增交付**：

| 模块 | 新增内容 |
| :--- | :--- |
| **种子库系统** | 剧本种子库、结局快照存储、变量衔接规则配置 |
| **续集承接逻辑** | 司命读取前作快照→匹配续集分支→注入变量→生成个性化开局 |
| **关系继承机制** | 角色对玩家的信任值/好感度跨剧本继承、AI记忆按时间线约束 |
| **角色智能体资产化** | 玩家可“带走”剧本中建立羁绊的AI角色，成为私人智能体 |
| **跨剧本身份** | 玩家在同一系列中可以继承前作角色身份，或选择新身份 |

**技术储备**：
- 种子库与快照数据结构设计
- 司命个性化开局算法
- 智能体记忆时间线约束逻辑
- 智能体资产绑定与跨剧本加载

**关键突破**：
- **从“单局”到“系列”**：玩家开始在同一世界中积累故事和羁绊
- **智能体资产化**：AI陪伴经济的雏形出现
- **创作者新范式**：续集创作从“写死剧本”变为“维护种子库+变量规则”

**商业模式扩展**：
- 系列剧本套票（买断整套系列）
- 角色智能体买断（带走你喜欢的AI角色）
- 智能体皮肤与化身销售


### 第三阶段：持续运行世界内单局剧本与持续运行并存

**核心特征**：大玩家主题世界服务器上线。同一世界内，**穿越旅人**可以随时进入体验单局剧本，**原住居民**可以长期生活、经营资产、参与世界事件。司命持续推演世界时间线，注入节律性事件和随机事件链。

**新增交付**：

| 模块 | 新增内容 |
| :--- | :--- |
| **世界持续运行引擎** | 司命升级为“世界说书人”：时间推演、季节更替、NPC生态、随机事件生成、事件链编织 |
| **双层玩家身份** | 穿越旅人（无身份，单局体验）vs 原住居民（有身份，长期经营） |
| **资产与经营系统** | 原住居民可拥有庄园、商铺等持久资产；可在本地或服务器经营 |
| **世界编辑器** | 大玩家构建完整世界观，定义物理法则、历史线、核心冲突 |
| **算力与托管系统** | 大玩家算力套餐、玩家本地买断+算力租赁、离线托管 |
| **跨世界旅行** | 玩家可携带私人智能体和买断资产跨世界使用（受世界压制） |

**技术储备**：
- 司命持续推演引擎（时间线、季节、NPC生态）
- 事件链生成算法
- 持久化世界状态存储与恢复
- 玩家身份与权限系统（穿越旅人/原住居民）
- 资产买断与离线托管技术
- 跨世界智能体能力压制与化身系统

**关键突破**：
- **从“单局”到“永续”**：世界不再重置，玩家的投入被永久记录
- **从“玩家”到“居民”**：玩家可以在世界中拥有身份、资产和长期羁绊
- **从“经营剧本”到“经营世界”**：大玩家成为世界创造者与守护者

**商业模式扩展**：
- 原住居民身份买断（永久居民/季节性居民）
- 大玩家服务器会员订阅
- 算力租赁（玩家本地托管或AA分摊）
- 大玩家世界税（世界内交易抽成）
- 世界内资产交易（庄园、商铺、坐骑等）
- 创作者在世界内发布剧本的分成


## 三阶段的技术累积关系

```
Phase 1: 单局剧本
    │
    │ 积累：3D交互、智能体、司命基础、事件总线
    │
    ▼
Phase 2: 连续单局剧本
    │
    │ 新增：种子库、快照继承、关系跨局、智能体资产化
    │
    ▼
Phase 3: 持续运行世界
    │
    │ 新增：司命持续推演、双层身份、资产经营、世界编辑器
    │
    ▼
完全体：单局体验 + 持续运行 并存
```

每个阶段都是下一个阶段的技术基础和商业验证。Phase 1验证“智能体驱动的动态剧本杀是否成立”，Phase 2验证“玩家是否愿意为跨局羁绊付费”，Phase 3验证“大玩家是否愿意经营一个世界，玩家是否愿意在其中长期生活”。

---

## 最终形态：一个世界，两种体验

在Phase 3完全体中，玩家进入一个主题世界时，看到的不是“剧本列表”，而是一个**活的世界地图**：

- 点击地图上的一个**事件标记**（如“金山寺之围”），可以以穿越旅人身份立即进入一场单局剧本杀
- 点击自己的**庄园图标**，可以回到自己的家，经营、建设、与AI同伴聊天
- 在世界上遇到**其他玩家**，可以交易、合作、竞争
- 参与**世界级事件**，与原住居民一起改变世界的历史走向

这就是你构想的终极形态：**一个能承载单局精彩，也能沉淀长期羁绊的活的世界。**
