以下是一个从初始剧本种子、到不同玩家玩出的故事线、再到续集种子如何承接的完整例子。我们以《白蛇传·浮生》及续集《白蛇传·金山劫》为例。

## 一、初始剧本种子：《白蛇传·浮生》

创作者在剧本编辑器中，为《白蛇传·浮生》配置了如下种子：

| 种子模块 | 内容 |
| :--- | :--- |
| **角色** | 许仙（可真人可AI）、白素贞（AI）、小青（AI）、法海（AI）、神秘香客（AI） |
| **核心冲突** | 药铺一名病人离奇死亡，死因可疑 |
| **死因池** | 蛇毒致死、药方被调换、佛门法器所伤 |
| **动机池** | 法海借除妖行私刑、白素贞失控伤人、许仙为保护妻子下药、小青未经姐姐同意动手、香客为五百年前的旧怨复仇 |
| **凶手候选** | 所有AI角色（真人玩家许仙不能是初始案件的凶手） |
| **关键分支点** | 1) 是否发现法海私下收集的证据？2) 是否揭穿白素贞的蛇妖身份？3) 许仙选择保护妻子还是指认妻子？ |
| **结局条件** | 正义伸张、真凶逃脱、冤案、许仙主动认罪替妻顶罪（隐藏结局） |


## 二、不同玩家玩出的故事线

### 玩家A的故事线（情感向）

1.  **开局**：玩家A扮演许仙，性格偏向共情和信任。
2.  **探索**：许仙发现了指向白素贞的蛇鳞线索，但选择私下询问而非公开指认。
3.  **冲突**：白素贞（AI）因许仙的信任而坦白自己是蛇妖，但坚称自己不是凶手。两人决定联手找出真凶。
4.  **真相浮现**：许仙和小青（AI）发现法海私下收集了大量“妖物证据”，法海承认死者是“意外”——他在用佛门法器逼问死者关于白素贞的事时失手致其死亡。
5.  **结局**：法海被指认为真凶，白素贞的蛇妖身份未暴露。许仙与白素贞的关系更加牢固。

**玩家A的世界状态快照**：
- 故事线ID：`timeline_justice_fahai`
- 白素贞：存活，蛇妖身份未暴露，对许仙忠诚度+10
- 小青：存活，对许仙信任值+5
- 法海：被定罪，入狱
- 许仙与白素贞关系：极大增强，形成“守护者”羁绊

### 玩家B的故事线（推理向）

1.  **开局**：玩家B扮演许仙，性格偏向理性和怀疑。
2.  **探索**：许仙发现蛇鳞后，立即在公开讨论中质问白素贞。
3.  **冲突**：白素贞被迫当众承认自己是蛇妖，众人哗然。法海趁机指认白素贞就是凶手。小青怒斥法海诬陷。
4.  **真相浮现**：在多重线索汇聚下，许仙发现真正的凶手是神秘香客——他是五百年前被白素贞所伤之人的后代，想以此嫁祸白素贞。
5.  **结局**：香客被指认为真凶。但白素贞的蛇妖身份已经暴露，她和许仙的关系产生了裂痕。

**玩家B的世界状态快照**：
- 故事线ID：`timeline_justice_xiangke`
- 白素贞：存活，蛇妖身份暴露，对许仙信任值-3（因被当众揭穿）
- 小青：存活，对许仙怀疑值+5（认为你害了姐姐）
- 法海：未被定罪，但对白素贞的敌意加深
- 许仙与白素贞关系：出现裂痕，“真相至上”的代价


## 三、续集种子：《白蛇传·金山劫》

创作者为续集配置了如下种子：

| 种子模块 | 内容 |
| :--- | :--- |
| **通用续集分支** | 分支1：法海卷土重来（承接法海被定罪的故事线）；分支2：身份危机（承接白素贞身份暴露的故事线）；分支3：人与妖的战争（承接任何结局，作为通用升级冲突） |
| **变量衔接规则** | 规则1：若白素贞身份未暴露，她在续集中可自由行动；若已暴露，她开局时处于“被追捕”状态。<br>规则2：若法海被定罪，他在续集中是“越狱复仇者”；若未被定罪，他是“官方除妖师”。<br>规则3：若许仙与白素贞关系为“守护者”羁绊，续集中许仙开局获得“白素贞的信任”Buff；若关系有裂痕，开局需完成一个“和解”任务。 |
| **动态关系继承** | 小青对许仙的信任值直接继承；白素贞对许仙的忠诚度直接继承。 |
| **冲突与动机模块** | 通用冲突：水漫金山、法海围攻雷峰塔。<br>特殊冲突（仅故事线1）：法海越狱后，发誓要当众揭露白素贞身份。<br>特殊冲突（仅故事线2）：白素贞被全城通缉，许仙面临选择——帮助她逃脱，还是将她交给官府？ |
| **跨角色记忆** | 所有AI角色的记忆按前作时间线继承。例如，无论哪条故事线，法海都记得前作中发生的一切。 |


## 四、司命的个性化开局

### 玩家A的续集《金山劫》开局

1.  **读取快照**：司命读取玩家A的世界状态快照（`timeline_justice_fahai`）。
2.  **匹配分支**：匹配到通用分支1“法海卷土重来”。
3.  **注入变量**：
    - 激活规则1：白素贞身份未暴露 → 开局时可自由行动。
    - 激活规则2：法海被定罪 → 他是“越狱复仇者”。
    - 激活规则3：许仙与白素贞为“守护者”羁绊 → 许仙开局获得“白素贞的信任”Buff。
4.  **注入关系**：小青对许仙信任值初始为5；白素贞对许仙忠诚度初始为10。
5.  **注入专属冲突**：激活特殊冲突“法海越狱后，发誓要当众揭露白素贞身份”。

**玩家A的开局叙事**：
> 法海从狱中逃脱，他找到了能证明白素贞蛇妖身份的铁证。他放出话：三日后，在金山寺当众揭穿。白素贞握着许仙的手：“这一次，我们依然要一起面对。”小青在一旁默默守护。

### 玩家B的续集《金山劫》开局

1.  **读取快照**：司命读取玩家B的世界状态快照（`timeline_justice_xiangke`）。
2.  **匹配分支**：匹配到通用分支2“身份危机”。
3.  **注入变量**：
    - 激活规则1：白素贞身份已暴露 → 开局时处于“被追捕”状态。
    - 激活规则2：法海未被定罪 → 他是“官方除妖师”。
    - 激活规则3：许仙与白素贞关系有裂痕 → 开局需完成“和解”任务。
4.  **注入关系**：小青对许仙怀疑值初始为5；白素贞对许仙忠诚度初始为7（下降但仍有感情基础）。
5.  **注入专属冲突**：激活特殊冲突“白素贞被全城通缉，许仙面临选择”。

**玩家B的开局叙事**：
> 白素贞的蛇妖身份已全城皆知。法海带领官兵四处搜捕。白素贞躲在破庙中，许仙去找她时，她眼中含着失望：“那日你在众人面前质问我的时候，可曾想过我的感受？”小青挡在姐姐面前，冷冷地看着许仙。

## 五、总结：一个剧本，两个世界

| 维度 | 玩家A的续集 | 玩家B的续集 |
| :--- | :--- | :--- |
| **前作结局** | 法海被定罪，白素贞身份未暴露 | 香客被定罪，白素贞身份暴露 |
| **续集分支** | 法海卷土重来 | 身份危机 |
| **开局状态** | 白素贞自由，许仙获得信任Buff | 白素贞被追捕，许仙需完成和解任务 |
| **核心冲突** | 对抗越狱的法海，守护秘密 | 帮助白素贞逃脱，修复关系裂痕 |
| **情感基调** | 并肩作战的守护 | 信任破碎后的救赎 |

同一个续集种子，因为前作的不同结局，生成了完全不同的故事开端。这正是《开本》动态叙事的核心魅力——**不是剧本决定故事，而是你的选择决定剧本**。
