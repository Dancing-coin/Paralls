## 一、初始剧本种子：《浮生若梦·青蛇劫》

| 种子模块 | 内容 |
| :--- | :--- |
| **所属平行世界** | UNV-002（东方仙侠·南宋临安） |
| **题材类型** | 古风 / 仙侠 / 情感沉浸 |
| **核心玩法** | 情感沉浸 + 故事还原 + 多线恋爱 |
| **角色** | 青岚（可真人可AI，女，修行千年的青蛇妖）、白露（可真人可AI，女，修行千年的白蛇妖，青岚的姐姐）、许安（可真人可AI，男，药铺大夫，白露的凡人夫君）、法明（AI，男，金山寺住持，暗中追查蛇妖下落）、柳生（AI，男，落魄书生，误入妖界） |
| **初始情境** | 西湖断桥边，一场突如其来的暴雨将五人困在同一座亭子里。这场雨，将五人的命运纠缠在一起。 |
| **核心冲突** | 法明已察觉到青岚和白露的妖气，正在暗中调查。许安不知妻子白露的真实身份。柳生误打误撞，被卷入这场人与妖的纠葛。 |

## 二、不同玩家玩出的故事线

### 玩家A的故事线：青岚与柳生的跨族之恋

1.  **开局**：玩家A扮演青岚，玩家B扮演柳生，其余为AI角色。
2.  **初遇**：暴雨亭中，柳生将自己的外衣披在青岚肩上。青岚（玩家A）可以选择接受或拒绝。玩家A选择接受，两人的好感度初始+2。
3.  **发展**：柳生（玩家B）在游戏中被青岚的神秘气质吸引，主动接近、吟诗作对、询问她的故事。青岚（玩家A）逐渐放下戒备，开始对柳生产生好感。
4.  **冲突**：法明（AI）发现青岚的妖气，在公开场合质问她。柳生（玩家B）选择站出来维护青岚：“法师此言差矣，若无证据，岂可凭空污人清白？”这一举动让青岚对柳生的好感度大幅上升。
5.  **真相暴露**：白露（AI）在一次意外中现出原形，许安（AI）震惊。法明借机指认青岚也是妖。柳生（玩家B）面临选择：与妖划清界限，还是继续守护青岚？他选择了后者。
6.  **高潮**：法明布下收妖阵，青岚被困。柳生闯入阵中，以自己的凡人之躯为青岚挡下法明的法器攻击，身受重伤。
7.  **结局**：青岚为救柳生，耗尽千年修为将其治愈，自己化为一条小青蛇。柳生抱着小青蛇，发誓等她重新修炼成人。白露和许安远走他乡。法明目睹柳生的痴情，长叹一声，收起法器离去。

**玩家A的世界状态快照**：
- 故事线ID：`timeline_qinglan_liusheng_love`
- 青岚（玩家A）：与柳生结成姻缘，但失去千年修为，化为青蛇。结局：圆满但留有遗憾。
- 柳生（玩家B）：与青岚相爱，为她挡下致命一击，最终与化为青蛇的青岚相守。结局：圆满。
- 白露：身份暴露，与许安一同离开临安。
- 法明：被柳生的痴情所动，暂时放下收妖执念。
- 关键关系：青岚↔柳生，忠诚度10，羁绊类型“生死相许”。

### 玩家B的故事线：青岚与法明的宿命纠缠

1.  **开局**：玩家C扮演青岚，玩家D扮演法明，其余为AI角色。
2.  **初遇**：暴雨亭中，法明（玩家D）第一眼就察觉到青岚身上的妖气。但青岚（玩家C）表现得从容淡定，反而主动与法明攀谈，询问佛法。
3.  **发展**：法明（玩家D）在与青岚的多次交谈中，发现她对人间疾苦有着深刻的同情。他开始动摇——如果妖也有善念，那收妖的正义性何在？
4.  **冲突**：白露（AI）为救许安暴露了妖力，法明被迫出手。青岚（玩家C）挡在姐姐面前，质问法明：“姐姐从未害人，甚至救了无数人。法师的收妖，究竟是为了正义，还是为了执念？”
5.  **法明的抉择**：法明（玩家D）陷入两难。他对青岚已经产生了难以名状的情愫，但师父的遗命和佛门的戒律让他无法放下收妖的使命。他选择暂时离开，去后山独自思考。
6.  **高潮**：许安（AI）为了证明自己对白露的爱，在法明面前自刺一刀：“若我的血能洗清她的罪，那就拿去吧。”这一幕让法明彻底动摇。
7.  **结局**：法明（玩家D）最终选择放下收妖执念。他向佛门自请云游，离开金山寺。临行前，他对青岚说：“贫僧……不，我这一生，从未见过像你这般的女子。若是来世，我不是法明，你不是妖，或许……”青岚沉默良久，目送他离去。

**玩家B的世界状态快照**：
- 故事线ID：`timeline_qinglan_faming_parting`
- 青岚（玩家C）：与法明产生了深刻的情感连接，但两人因身份无法在一起。结局：离别。
- 法明（玩家D）：放下收妖执念，离开佛门云游。对青岚有情，但无法跨越人妖之隔。
- 白露：身份暴露，但许安的自证让法明不再追究。
- 许安：为白露自刺一刀，证明了自己的爱。
- 关键关系：青岚↔法明，羁绊类型“有缘无份”。

### 玩家C的故事线：玩家扮演法明，选择“以情破戒”

1.  **开局**：玩家E扮演法明，玩家F扮演青岚（AI），其余为AI角色。
2.  **转折**：法明（玩家E）在与青岚的接触中，被她的性格吸引。他发现自己对这个妖产生了不该有的感情。
3.  **关键选择**：白露暴露后，青岚挡在姐姐面前。法明（玩家E）手握法器，却无法下手。他做出了一个让所有人震惊的选择——他放下了法器，说：“我……我做不到。”
4.  **结局**：法明（玩家E）选择守护青岚，对抗前来增援的同门。他最终被逐出佛门，但青岚接纳了他。两人隐居山林。

**玩家C的世界状态快照**：
- 故事线ID：`timeline_faming_broken_vows`
- 法明（玩家E）：被逐出佛门，与青岚隐居。结局：破戒圆满。
- 青岚（AI）：与法明相爱，对玩家E的忠诚度+10。
- 关键关系：法明↔青岚，羁绊类型“以情破戒”。


## 三、续集种子：《浮生若梦·千年后》

| 种子模块 | 内容 |
| :--- | :--- |
| **时代背景** | 现代都市，距前作已过千年 |
| **通用续集分支** | 分支A：再续前缘（承接青岚化为青蛇或离别的故事线）；分支B：千年守望（承接青岚与柳生或法明结缘的故事线）；分支C：新生（承接任何结局，作为全新情感故事的起点） |
| **变量衔接规则** | 规则1：若青岚化为青蛇，她在续集中已重新修炼成人，但千年修为尚未完全恢复，她对前世的记忆完整保留。<br>规则2：若法明云游，他在续集中已转世，容貌未变但无前世记忆。与青岚相遇时，会产生强烈的“既视感”。<br>规则3：若柳生与青岚相守，他在续集中同样转世，但保留部分前世记忆（由司命根据续集需要调控）。<br>规则4：若法明破戒与青岚隐居，千年后两人依然在一起，但面临新的挑战。 |
| **动态关系继承** | 前作中青岚对某角色的忠诚度/好感度直接继承。若前世结缘，续集中青岚会主动寻找对方的转世或等待对方恢复记忆。 |
| **跨角色记忆** | 青岚作为千年妖，完整保留前作所有记忆。其他角色的记忆状态由规则1-4决定。 |


## 四、司命的个性化开局

### 玩家A的续集开局（前世：青岚化为青蛇，柳生相守）

1.  **读取快照**：玩家A的青岚化为青蛇，柳生（玩家B）与她相守。
2.  **匹配分支**：分支A“再续前缘”。
3.  **注入变量**：
    - 激活规则1：青岚已重新修炼成人，千年修为恢复七成。
    - 激活规则3：柳生已转世，在现代都市中是一名普通上班族，对前世记忆模糊但偶尔会梦到一条青蛇。
4.  **开局叙事**：
    > 千年已过，西湖依旧。青岚（玩家A）在断桥边等待，她知道柳生的转世就在这座城市里。当她终于找到他时，他正在咖啡店里加班，与千年前吟诗作对的书生判若两人。但当他抬头看到她的那一刻，手中的咖啡杯掉在地上——那双眼睛，与千年前一模一样。

### 玩家B的续集开局（前世：青岚与法明离别）

1.  **读取快照**：玩家C的青岚与法明（玩家D）离别，法明云游。
2.  **匹配分支**：分支A“再续前缘”。
3.  **注入变量**：
    - 激活规则1：青岚已重新修炼成人。
    - 激活规则2：法明已转世，在现代都市中是一名心理医生，无前世记忆。但他每次看到蛇的图片都会莫名心悸。
4.  **开局叙事**：
    > 青岚（玩家C）在一千年里从未忘记法明临别时的那句话——“若是来世，我不是法明，你不是妖”。她找到了他的转世，他正在诊所里接待病人。当青岚走进他的诊室时，法明的转世愣在原地，良久才开口：“我们……是不是在哪里见过？”

### 玩家C的续集开局（前世：法明破戒，与青岚隐居）

1.  **读取快照**：玩家E的法明破戒，与青岚（AI）隐居。
2.  **匹配分支**：分支B“千年守望”。
3.  **注入变量**：
    - 激活规则4：法明（玩家E）和青岚已经共同生活了一千年。如今他们经营一家古玩店，但新的威胁出现——千年后的现代，法明的转世同门（新的追妖者）再次出现。
4.  **开局叙事**：
    > 一千年了，法明（玩家E）和青岚已经习惯了人间烟火。他们在城市角落里开了一家古玩店，日子平静。直到有一天，一个年轻僧人走进店里，目光如炬地盯着青岚：“施主，你身上的妖气，瞒不过贫僧。”


## 五、总结：同一个种子，三种爱情

| 维度 | 玩家A的续集 | 玩家B的续集 | 玩家C的续集 |
| :--- | :--- | :--- | :--- |
| **前作结缘** | 青岚↔柳生（生死相许） | 青岚↔法明（有缘无份） | 法明↔青岚（以情破戒） |
| **续集状态** | 青岚重新修炼成人，柳生转世 | 青岚等待千年，法明转世 | 两人相守千年，新威胁出现 |
| **核心情感冲突** | 唤醒前世的记忆，在全新的时代重新相爱 | 面对没有前世记忆的他，是否应该告诉他真相？ | 守护千年之约，对抗新的追妖者 |
| **情感基调** | 跨越千年的执着等待，从零开始的重新相爱 | 单方面的千年记忆，面对“最熟悉的陌生人” | 相守千年的平淡与坚守，面对新危机的并肩作战 |

同一个续集种子，因为前作中青岚与不同角色结缘、法明做出了不同的选择，而生成完全不同的情感故事。这正是《开本》承载恋爱本的核心魅力——**不是编剧决定你爱谁，而是你的每一次选择，决定了你将在千年之后，与谁重逢。**
