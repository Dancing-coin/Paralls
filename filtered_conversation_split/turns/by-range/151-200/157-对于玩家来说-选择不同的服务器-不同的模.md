## 用户

对于玩家来说，选择不同的服务器，不同的模式岂不是很大的认知负担，官方应该为玩家主动分忧，不单从推荐算法的角度来，用户使用路径上也要做到轻松决策甚至不用决策

## DeepSeek

我们不应让玩家面对复杂的服务器列表和模式选择，而应提供“一键开本，系统为你安排一切”的极简体验。服务器、模式、队友——这些概念对玩家透明，只在需要时以“增值服务”的形式出现。

以下是实现路径：

---

### 一、玩家使用路径的极简设计

**默认流程：**

```
首页 → [我想玩] → 系统智能匹配 → 进入游戏
```

玩家在首页只看到一个核心按钮：**「开始游戏」**。

点击后，系统基于以下信息自动决策：
- 该玩家的历史偏好（推理风格、社交偏好、题材喜好）
- 当前在线好友和常用组队伙伴
- 服务器负载和网络延迟
- 该玩家拥有的资产（买断剧本优先推荐）

**可选的轻量自定义：**

在「开始游戏」按钮旁，提供两个可折叠的轻量选项，而非复杂的服务器列表：

| 轻量选项 | 说明 |
| :--- | :--- |
| **想玩什么类型？** | 古风推理 / 科幻阵营 / 恐怖沉浸 / 随便推荐 |
| **想和谁玩？** | 仅好友 / 带我的AI伙伴 / 匹配真人 / 随便都行 |

玩家只需在5秒内做出模糊偏好选择，其余由系统完成。

---

### 二、后台自动决策引擎

当玩家点击「开始游戏」，系统在后台完成以下决策：

| 决策步骤 | 说明 |
| :--- | :--- |
| **1. 剧本匹配** | 根据玩家偏好、历史数据、当前热门，从全域剧本池中推荐最合适的剧本 |
| **2. 服务节点选择** | 自动选择提供该剧本的最优服务器（官方旗舰/大玩家影院/主题世界/自建），考虑网络延迟、负载、算力成本 |
| **3. 队友组队** | 根据玩家偏好，匹配真人玩家或智能体，确保水平、风格、角色偏好契合 |
| **4. 模式透明化** | 玩家进入游戏后，可在角落看到“本房间由XX服务器提供”，但不影响体验 |

**对玩家而言，整个流程只需点击一次按钮。** 他们不需要知道服务器是谁运营的、是什么模式，只需要享受游戏。

---

### 三、服务器与模式对玩家的呈现方式

服务器品牌不应成为玩家的认知负担，而应作为**增值服务的自然曝光**。

| 呈现方式 | 说明 |
| :--- | :--- |
| **游戏内的轻量标识** | 在游戏房间的角落，以水印或小标签形式显示“本房间由【XX影院】提供”，点击可了解该服务器 |
| **体验后的推荐** | 游戏结束后，系统提示：“你喜欢刚才的体验吗？这是由【XX主题世界】提供的，他们还有更多类似剧本。” |
| **主动探索入口** | 在玩家的个人中心，提供“探索更多服务器”的入口，供有兴趣的玩家深入了解，但不作为默认路径 |
| **大玩家品牌露出** | GM主持、独家皮肤、定制场景等，本身就是大玩家的品牌广告，无需在入口处强调 |

---

### 四、特殊场景的处理

| 场景 | 处理方式 |
| :--- | :--- |
| **玩家想和朋友玩特定剧本** | 使用“组队邀请”功能，发起人选择剧本，系统自动选择最优服务节点，好友一键加入 |
| **玩家想带自己的AI伙伴** | 在偏好中勾选“携带我的智能体”，系统在组队时自动加载该玩家的私人智能体 |
| **玩家想继续上次的故事** | 首页提供“继续上次”的快捷入口，直接回到上次中断的剧本和服务器 |
| **玩家想切换服务器** | 在游戏内的设置菜单中，提供“切换服务器”选项，但默认隐藏，需要时主动查找 |

---

### 五、对生态的长期价值

这种极简设计不仅降低了玩家门槛，还实现了生态的健康循环：

-   **优秀的大玩家自然获得更多流量**：系统根据服务质量、玩家评分、算力稳定性等指标，自动将更多玩家分配给优质服务器。大玩家无需自己打广告，服务品质就是最好的广告。
-   **新大玩家有机会被发现**：系统会给新服务器一定的流量扶持，让它们通过优质服务积累口碑，而不是被埋没在列表里。
-   **玩家永远获得最优体验**：系统持续优化分配策略，确保玩家每次都能享受到当前最优的服务质量。

最终，《开本》对玩家呈现的是**一个统一的、高品质的剧本杀世界**，而背后的服务器生态则在静默中高效运转。玩家无需成为选择服务器和模式的专家，他们只需要做一件事——享受故事。
