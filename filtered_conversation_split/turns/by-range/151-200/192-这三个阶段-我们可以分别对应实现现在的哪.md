## DeepSeek

我们分三个阶段来实现《开本》的完整形态，每个阶段都能承载不同类型的游戏体验，并对现有游戏进行根本性的升级。

---

### Phase 1：静态世界内单局剧本

这一阶段的核心是**单局动态叙事**——每一局都是独立时空，开局初始化，结局归档。

**可融入/复刻的游戏类型**：

| 游戏类型 | 代表作品 | 《开本》如何升级 |
| :--- | :--- | :--- |
| **谋杀之谜/剧本杀** | 《死穿白》、《年轮》、线下剧本杀 | 从固定剧本→动态涌现凶手和案件；从文字→3D沉浸；从人类DM→AI司命实时导演；从一次性体验→同一剧本无限重玩 |
| **社交推理** | 《Among Us》、《鹅鸭杀》、《狼人杀》 | 从固定机制→可自定义规则和阵营；从简单任务→3D场景内自由探索和搜证；从玩家对抗→AI智能体填补角色空缺，保障随时可开局 |
| **密室逃脱** | 《The Room》、《锈湖》系列 | 从固定谜题→司命动态生成谜题组合；从单人→多人合作密室；从预设机关→3D可交互场景内自由探索 |
| **法庭推理** | 《逆转裁判》、《弹丸论破》 | 从固定证据链→动态生成的线索和证词矛盾；从单机→多人分饰控辩双方；AI智能体扮演证人和被告，其撒谎/崩溃完全由人格驱动 |

**典型例子：升级《Among Us》**

传统《Among Us》：地图固定、任务固定、投票机制固定。玩家做的是重复劳动，重玩价值依赖社交关系。

《开本》版：在同一艘太空飞船上，每一次开局，内鬼是谁、杀人手法、关键线索位置、紧急任务内容都由司命动态生成。AI智能体扮演部分船员，他们的嫌疑值和信任值会因玩家行为而动态变化。你可以质问AI船员，它可能会紧张到露出马脚，也可能冷静地把嫌疑引向他人。一局结束后，这艘飞船的故事归档，下次再来，完全不同的案件。


### Phase 2：静态世界内连续单局剧本

这一阶段的核心是**跨局状态继承**——前作结局通过快照影响续作开端，但每局仍独立运行。

**可融入/复刻的游戏类型**：

| 游戏类型 | 代表作品 | 《开本》如何升级 |
| :--- | :--- | :--- |
| **系列侦探故事** | 《福尔摩斯》系列、《金田一》系列 | 从独立案件→案件之间的人物关系和角色成长被继承；从固定人物→你在前作中建立的羁绊影响续作；从同一侦探→你可以扮演不同角色体验系列 |
| **恋爱模拟** | 《恋与制作人》、《光与夜之恋》 | 从固定剧情线→你的每个选择都影响续作的初始关系；从单男主线→多线并行且互相影响；AI角色对你的记忆和态度跨剧本继承，形成真正的“恋爱长跑” |
| **选择导向的叙事游戏** | 《底特律：变人》、《直到黎明》 | 从预设分支树→动态生成的分支和结局；从一次性选择→选择后果跨越多个剧本延续；角色生死、关系、秘密全部跨局继承 |
| **卡牌/战棋剧情模式** | 《火焰纹章》、《三角战略》 | 从固定剧情→你的战斗结果影响后续剧情走向；角色战死则永久死亡，无法在续作中使用；与同伴的羁绊从战斗中自然生长 |

**典型例子：升级《恋与制作人》**

传统《恋与制作人》：预设的剧情线，玩家在固定节点做出选择。不同“周目”之间完全独立，角色对你的“记忆”是写死的。

《开本》版：你与AI角色“白起”在第一个剧本中初遇。你在关键时刻选择相信他，他记住了。第二个剧本中，开局时他对你的信任值直接就是8/10，会主动向你求助。第三个剧本，你们已经是并肩作战的伙伴，他甚至会为了救你而牺牲自己。你选择是否要开启跨剧本的“复活任务”将他带回来——这个任务是真正漫长的、跨越多个世界的旅程，而不是一个付费按钮。


### Phase 3：持续运行世界内单局剧本与持续运行并存

这一阶段的核心是**世界永续运行**——司命持续推演时间线，玩家可以以单局身份短暂体验，也可以以居民身份长期生活。

**可融入/复刻的游戏类型**：

| 游戏类型 | 代表作品 | 《开本》如何升级 |
| :--- | :--- | :--- |
| **种田经营** | 《星露谷物语》、《牧场物语》 | 从固定NPC日程→AI同伴拥有完整人格和自主行为；从预设事件→司命持续注入随机事件和事件链；从单机→你的庄园可对好友开放，可在大玩家世界中展示 |
| **生活模拟** | 《模拟人生》、《动物森友会》 | 从简单AI→邻居、访客、商人都由智能体驱动，有记忆、有情绪、有自己的目标；从固定世界→司命持续推演世界变化（季节、经济、历史事件）；从单机→多人在线共享同一个持续运行的世界 |
| **策略经营** | 《文明》系列、《十字军之王》 | 从固定AI对手→对手由司命驱动，有独特人格和策略风格；从预设历史→世界历史由所有玩家的行为共同书写；从单局→世界永续运行，文明真正跨越千年 |
| **MMORPG** | 《魔兽世界》、《最终幻想14》 | 从固定任务链→司命动态生成世界事件和随机任务；从固定NPC→所有NPC都由智能体驱动，能记住你、与你建立关系；从所有人同一条主线→每个玩家有自己独一无二的世界故事线 |
| **开放世界RPG** | 《荒野大镖客2》、《塞尔达传说》 | 从预设随机事件→司命根据你的身份、历史、关系动态生成事件；从固定NPC生态→完整的智能体社会，每个NPC都有自己的人生；从单机→多人在线共存，各自扮演不同身份 |

**典型例子：升级《星露谷物语》**

传统《星露谷物语》：NPC有固定日程和对话树。你每天种田、送礼、刷好感。好感满了解锁固定的剧情事件。世界是静态的——每年都一样。

《开本》版：你在UNV-003“桃源乡”主题世界拥有一个庄园。你的AI同伴“小青”有自己的想法——她今天不想浇水，想去河边采花。你不在线时，世界仍在运转——作物在生长，商队在行进，季节在更替。你上线时，司命推送“今日简报”：邻居家的小孩子偷了你两颗萝卜，小青正在院子里追着教育他。一个流浪商人路过，想用一颗稀有种子换一顿午饭。你可以选择接受，开启一个持续数周的事件链——这颗种子长出了一棵奇异的树，引来了远方的探险家，带来了宝藏和新的故事。同时，你随时可以切换到“穿越旅人”模式，在这个世界的另一处，参与一场单局剧本杀——而这场剧本杀的结果，可能会影响整个世界的走向。
