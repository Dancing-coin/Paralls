## 用户

玩家有哪些消费模式？

## DeepSeek

在《开本》中，玩家的消费模式并非为了“变强”或“跳过”体验，而是为了**进入更广阔的故事世界**，并**在其中留下独一无二的个人印记**。所有消费都遵循“付费是门票，探索是乐园”的原则。

以下是完整的玩家消费模式体系：

### 一、 体验前置消费：为了进入故事世界

这类消费是玩家进入某个故事世界或服务器的“钥匙”。

| 消费模式 | 说明 | 特点 |
| :--- | :--- | :--- |
| **剧本买断制** | 一次性付费，永久拥有该剧本的**所有可能性分支**和**全部结局**的体验权。 | 永久拥有，可反复游玩探索不同分支，不受时间限制。 |
| **服务器门票制** | 支付单次入场费用，进入特定大玩家服务器中指定的剧本房间。 | 单次体验，适合尝试新服务器或新剧本，无需长期承诺。 |
| **会员订阅制** | 按月/季/年付费，在有效期内畅玩会员池内所有剧本，或享受特定服务器的无限次入场权。 | 长期畅玩，适合高频玩家，可享受会员专属剧本、优先排队等特权。 |
| **众筹支持制** | 在剧本开发阶段进行资助，以获得“探索者”资格、限定外观或首发体验权。 | 支持创作者，获得稀缺性回报，参与创作过程。 |

### 二、 个性化与表达消费：为了在故事中留下印记

这类消费让玩家在故事世界中展现独一无二的自我，属于体验中的“增值服务”，不影响核心玩法公平。

| 消费模式 | 说明 | 特点 |
| :--- | :--- | :--- |
| **角色皮肤与外观** | 购买角色服装、发型、妆容等外观资产。 | 视觉个性化，买断后永久拥有，可在所有支持该资产的服务器中使用。 |
| **场景主题与特效** | 购买个人房间、大厅或特定场景的装饰主题和视觉特效。 | 环境个性化，打造专属空间。 |
| **声线模组** | 为玩家自己或其拥有的智能体更换不同风格的声音。 | 听觉个性化，增强角色扮演的沉浸感。 |
| **动作与表情包** | 购买独特的角色动作、舞蹈、微表情等。 | 互动个性化，丰富社交表达。 |
| **个人资料装饰** | 购买称号、头像框、成就徽章等，用于装饰个人全球档案。 | 社交展示，彰显身份、品味与成就。 |

### 三、 智能体相关消费：为了与AI伙伴的羁绊

这是《开本》最具特色的消费模式，将AI从一个“功能”升维为一种“情感资产”。

| 消费模式 | 说明 | 特点 |
| :--- | :--- | :--- |
| **智能体角色买断** | 直接购买由官方或创作者设计的、具有完整人格和背景故事的AI角色。 | 获得一个稳定的AI伙伴，可命名、微调，成为专属资产。 |
| **智能体“收编”** | 在游戏中遇到高度默契的系统AI，支付费用将其“收编”为私人智能体。 | 基于情感连接和共同经历的付费，具有很强的纪念意义。 |
| **智能体外观定制** | 为自己拥有的智能体购买服装、配饰等外观。 | 打扮自己的AI伙伴，将其打造成独一无二的存在。 |
| **智能体“世界化身”** | 为智能体购买适配不同平行世界的合规外观和技能组，使其能跨越世界观使用。 | 扩展智能体的使用范围，使其能陪伴玩家探索更多故事。 |

### 四、 社交与增值服务消费：为了更深度的连接

这类消费主要围绕大玩家提供的增值服务和社交功能展开。

| 消费模式 | 说明 | 特点 |
| :--- | :--- | :--- |
| **专业GM主持服务** | 付费聘请专业GM（游戏主持人）主持一局游戏，提供更沉浸、更专业的引导和氛围营造。 | 升级服务体验，适合追求极致沉浸感的玩家或新手团队。 |
| **私密房间租赁** | 租赁一个不受打扰的私人游戏房间，用于朋友聚会或私密活动。 | 保障隐私和专属空间。 |
| **大玩家社群会员** | 加入特定大玩家创建的专属社群，享受其提供的独家内容、活动和社交网络。 | 归属感消费，为氛围和圈子付费。 |
| **直播间互动道具** | 在观看大玩家直播时，购买礼物或道具，以触发游戏内的特定效果（不影响公平性）。 | 娱乐打赏，增强直播互动性和趣味性。 |

### 五、 数据与衍生品消费：为了留住记忆

将游戏中的美好瞬间转化为可永久收藏的纪念品。

| 消费模式 | 说明 | 特点 |
| :--- | :--- | :--- |
| **本局故事报告与CG** | 购买由AI自动生成的、记录本局游戏关键剧情和高光时刻的精美战报和插画。 | 纪念品消费，将一次性的体验固化为可长期回味的艺术品。 |
| **云存档扩容** | 购买额外的云存储空间，用于保存更多的游戏录像、故事报告和智能体数据。 | 保障数字资产安全，满足重度用户的存储需求。 |

### 六、 平台基础服务消费

| 消费模式 | 说明 | 特点 |
| :--- | :--- | :--- |
| **AI算力套餐** | 在P2P自建服务器模式下，购买官方算力包，以支持更高质量的AI队友和司命服务。 | 按需使用，灵活付费，保障自建服务的体验质量。 |

### 消费者权益保障

为确保这些消费模式的健康运行，我们为玩家提供以下保障：
*   **买断资产永久权**：所有买断的剧本、皮肤、智能体等数字资产，均绑定玩家全球账户，永久有效，可跨服使用。
*   **2小时无理由退款**：剧本买断后2小时内，若游戏时长不足2小时，可无条件退款。
*   **全平台资产跨服**：核心买断资产不受单一服务器经营状况影响，可在全平台官方与大玩家服务器中自由使用。
