## 一、核心区别：谁来控制世界

| 维度 | 本地经营 (P2P自建) | 大玩家服务器 |
| :--- | :--- | :--- |
| **访问权限** | **完全由你控制**。你可以邀请任何人，也可以拒绝任何人。未经你的许可，没有人能进入你的世界。 | **由大玩家设定**。大玩家决定服务器是公开还是邀请制，设定准入规则（付费、会员、等级等）。 |
| **规则制定** | **完全由你决定**。你可以自定义世界的规则（时间流速、事件密度、资源产出等）。 | **由大玩家设定**。大玩家制定服务器的核心规则，所有玩家在此框架内活动。 |
| **社交可见性** | **完全隐藏**。你的世界不出现在任何公共列表中，只能通过你的邀请进入。 | **取决于大玩家策略**。可以是公开的（出现在大厅中），也可以是隐藏的（仅会员可见）。 |
| **资产权限** | 你的资产在你的世界里完全自由使用。你邀请的玩家可以携带他们自己的资产进入，但你的世界资产不会被他人带走。 | 你的资产在服务器内自由使用。跨服使用需遵循服务器的资产兼容规则。 |
| **AI算力来源** | 你的本地硬件为主，或AA分摊算力费用。 | 大玩家购买的商业级AI算力套餐。 |
| **世界持久性** | 你的电脑关机，世界暂停。下次开机继续。 | 服务器24小时运行，世界持续运转。 |
| **商业模式** | 无商业行为，纯私密社交。或你与好友AA算力费。 | 大玩家通过门票、会员、道具、众筹等变现。 |


## 二、大玩家的规则制定权

大玩家对自己的服务器拥有完整的规则制定权，这是他们提供差异化服务的基础。

| 规则维度 | 大玩家可设定内容 | 例子 |
| :--- | :--- | :--- |
| **准入规则** | 谁可以进入服务器 | 仅会员、仅受邀、付费入场、等级限制、特定时间段开放 |
| **身份规则** | 原住居民名额、获取条件、权限 | 限定500名永久居民，需众筹支持或完成特定任务才能获得 |
| **经济规则** | 世界内的交易税率、货币规则 | 所有交易抽税5%用于世界维护基金 |
| **时间规则** | 世界时间流速、事件触发频率 | 现实1天=世界1季，或现实1天=世界1天 |
| **社交规则** | 玩家间互动限制、领地保护 | PvP是否开启、领地是否不可侵犯 |
| **内容规则** | 剧本策展偏向、禁止内容类型 | 仅策展本世界原创剧本、禁止OOC行为 |
| **司命干预强度** | 随机事件密度、暗杀催化频率 | 轻度（仅季节事件）/ 中度（含随机访客）/ 重度（含史诗事件链） |
| **资产规则** | 哪些外部资产可带入，哪些本服资产可带出 | 本服独占皮肤不可带出；通用买断资产可自由带入 |
| **处罚规则** | 违反服务器规则的后果 | 警告、暂时封禁、永久驱逐 |


## 三、两种模式的社交互动对比

| 场景 | 本地经营 | 大玩家服务器 |
| :--- | :--- | :--- |
| **朋友来访** | 你邀请朋友进入你的庄园，朋友看到你的建设成果，一起聊天、交易 | 你在大玩家服务器中拥有庄园，朋友也在同一服务器，你们互相串门 |
| **陌生人互动** | 不存在。你的世界只有你和被邀请的人。 | 存在。你可以在公共区域遇到其他玩家，交易、合作、竞争。 |
| **大型世界事件** | 仅限司命生成的单机事件。 | 全服玩家共同参与的大型事件（如史诗战争、节日庆典）。 |
| **展示与竞争** | 你的庄园是你的私密花园，只与好友分享。 | 你的庄园可以参加服务器评比，成为排行榜上的明星庄园。 |


## 四、玩家的身份转换

玩家可以在两种模式之间自由切换：

-   **在本地经营自己的庄园**：私密、自由、完全掌控。
-   **带着自己的资产进入大玩家服务器**：参与社群、展示自己、体验大型事件。
-   **在大玩家服务器中拥有原住居民身份**：长期投入，与世界共成长。
-   **从大玩家服务器中买断资产带回本地**：将在线积累的成果永久保存。

这种自由切换，确保了玩家既能在私密空间中享受宁静，又能在公共世界中找到归属。而大玩家通过设定有吸引力的规则和服务，吸引玩家主动选择进入他们的世界。
