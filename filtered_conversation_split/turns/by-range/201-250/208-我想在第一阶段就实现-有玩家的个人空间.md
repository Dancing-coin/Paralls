## 用户

我想在第一阶段就实现，有玩家的个人空间，可以把喜欢的角色智能体带回来。

## DeepSeek

你的需求非常明确：Phase 1 就要让玩家能把喜欢的角色智能体“带回家”。这完全可行。我们不需要实现 Phase 2 完整的跨局记忆和跨世界旅行，只需要在 MVP 阶段提供一个**轻量版的个人空间和带走机制**。

---

## Phase 1 可实现的版本

### 一、个人空间（轻量版）

| 要素 | MVP 实现 |
| :--- | :--- |
| **空间形式** | 一个预设的 3D 场景（如“观书人的书房”或“宁静的小院”），由官方提供 1-2 个模板 |
| **空间容量** | 初始可容纳 2-3 名智能体，后续可扩容 |
| **交互方式** | 玩家进入个人空间后，可自由走动，与已带回的智能体进行**基础对话**（闲聊、回忆共同经历、情感互动） |
| **外观定制** | 玩家可更换空间的基础风格（如从“书房”换成“小院”），后续开放更多主题 |

**不包含**（推迟到 Phase 2+）：
- 智能体在个人空间内的自主行为（如走动、做自己的事）
- 智能体私房钱与独立经济行为
- 智能体跨世界能力
- 完整的长期记忆系统（仅保留本局关系快照）

---

### 二、带走机制（轻量版）

在 Phase 1 单局剧本结束后，玩家可以将建立了深厚羁绊的 AI 角色“带走”，存入个人空间。

| 要素 | MVP 实现 |
| :--- | :--- |
| **触发时机** | 剧本结束后，在结局展示界面 |
| **带走条件** | 该 AI 角色与玩家的信任值/好感度达到一定阈值（如 ≥7），且该角色在结局中存活 |
| **带走形式** | 玩家点击“邀请同行”按钮 → 进入一段简短的告别叙事（基于该角色人格生成的文字+语音） → 角色同意 → 该角色出现在玩家的个人空间中 |
| **数据保存** | 保存该角色的**基本快照**：人格参数、本局关键记忆摘要、与玩家的最终关系数据。这些数据在个人空间内可被调用（用于基础对话） |
| **数量限制** | 初始免费槽位 2 个，扩容需付费 |

**不包含**（推迟到 Phase 2+）：
- 完整的“坦白与契约”叙事仪式（Phase 2 扩展）
- 智能体主动表达“想跟你走”的意愿（Phase 2 扩展）
- 带走后的智能体可进入其他剧本（Phase 2 扩展）
- 智能体在个人空间内的自主行为和经济系统（Phase 3）


### 三、对 MVP 开发的影响

| 新增模块 | 工作量评估 | 说明 |
| :--- | :--- | :--- |
| **个人空间场景** | 1 个预设 3D 场景（美术+搭建） | 可复用现有 3D 管线 |
| **个人空间基础交互** | 移动+与智能体对话 | 复用已有对话生成服务 |
| **带走触发与数据保存** | 结局界面的“邀请同行”按钮 + 角色快照存储 | 数据量小，仅存储摘要 |
| **个人中心扩展** | 显示已带回的智能体列表 | 简单 UI |


### 四、与 Phase 2 的关系

Phase 1 的轻量版个人空间和带走机制，是 Phase 2 “智能体资产化”的**基础功能验证**。它在 MVP 阶段就能满足玩家的核心情感需求，同时为 Phase 2 的完整版（跨剧本使用、长期记忆、智能体经济）积累数据。
