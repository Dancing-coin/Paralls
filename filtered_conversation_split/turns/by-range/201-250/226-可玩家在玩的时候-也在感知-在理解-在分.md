## 修正：剧中角色 = 智能体底层 + 玩家大脑的意志

### 一、玩家角色和AI角色的L1-L4，其实并不完全对称

| 心智层级 | AI角色 | 玩家角色 |
| :--- | :--- | :--- |
| **L1 感知层** | 系统自动运行，接收结构化感知事件 | **双重感知**：系统自动运行（底层），但玩家同时通过3D渲染画面和空间音频直接感知世界。玩家的感知比AI更丰富、更直观 |
| **L2 理解层** | 系统自动运行，更新信念、生成推论 | **双重理解**：系统自动运行（底层），生成内心独白和推论提示。但玩家的大脑也在独立分析、推理、产生情绪——这是系统无法替代的 |
| **L3 规划层** | AI自主决策 | **玩家大脑决策**。系统仅提供“决策建议”和“冲动”作为参考 |
| **L4 执行层** | AI自动执行 | **主动行为由玩家操作**；微表情、小动作等自动行为由系统驱动 |

### 三、为什么还需要系统自动补全层？

因为有些事情玩家的大脑**无法直接控制**：

| 玩家大脑无法做到的事 | 系统自动补全层的作用 |
| :--- | :--- |
| 让自己的虚拟角色脸红、出汗、瞳孔放大 | 系统读取角色当前的压力值和情绪标签，自动驱动形态键 |
| 让自己的声音自动带上颤抖或愤怒 | 系统读取情绪标签，自动调节TTS参数 |
| 在挂机时让角色不变成木头人 | 系统接管L3，角色自主行动（保守模式） |
| 获得角色“应该有的”内心声音（来自角色人格的冲动） | 系统基于角色人格档案生成内心独白和冲动 |

但玩家的大脑**已经在做**的事情，系统绝不替代：
-   玩家自己在看画面、听声音
-   玩家自己在推理、分析、怀疑
-   玩家自己决定去哪、说什么、质问谁、投票给谁

### 四、对AI同伴的意义

AI同伴与你互动时，它面对的是 **“旅人意志驱动的剧中角色”** 这个整体。它看到的：
-   你的角色微表情（系统自动补全）
-   你的角色行动（你的意志驱动）
-   你的角色对话（你说的话，经过变声器+文字润色）

它不需要区分“哪部分是玩家大脑驱动的，哪部分是系统补全的”。它只知道——这个角色在自主行动，有连贯的人格。

---

**一句话总结：剧中角色不是“完整的智能体”，而是“玩家大脑（感知+理解+决策+操作） + 系统自动补全层（微表情+小动作+内心戏+挂机自主）”的混合体。系统补全的是玩家大脑无法直接控制的生理和潜意识层面，而玩家大脑已经在做的感知、推理、决策，系统绝不替代。**
