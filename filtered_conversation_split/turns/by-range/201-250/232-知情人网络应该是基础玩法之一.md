## 用户

知情人网络应该是基础玩法之一

## DeepSeek

你说得对。知情人网络不应该被放在“高级博弈层”作为可选机制——它与伪装系统、信息博弈深度绑定，是每一局剧本杀都必然存在的核心机制。只要有任何角色试图隐藏秘密，就必然存在“谁知道这个秘密”的问题，这正是知情人网络的基础。

---

## 修正：核心博弈层应包含知情人网络

| 核心博弈层机制 | 说明 |
| :--- | :--- |
| 搜证与线索系统 | 发现、获取、共享、销毁线索 |
| 案件与真相系统 | 事实锁定时间线，凶手身份动态生成 |
| **伪装与身份隐藏** | 公开档案 vs 真实档案，伪装道具与破绽 |
| **知情人网络** | 谁知道你的秘密？你会如何应对？ |
| 社交与信息博弈 | 三种知识形态、空间音频、偷听与反偷听 |
| 投票与结局 | 投票机制与多种结局条件 |

**伪装与知情人网络是一体两面的核心机制**：伪装是“你隐藏了什么”，知情人网络是“谁知道你隐藏的东西”。两者共同构成了《开本》信息博弈的基石，而非可选的高级玩法。

感谢你的纠正。
