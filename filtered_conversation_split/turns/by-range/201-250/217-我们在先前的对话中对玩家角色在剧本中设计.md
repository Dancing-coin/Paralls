## 玩家角色功能总览

### 一、核心身份与档案系统

| 功能 | 说明 | 来源 |
| :--- | :--- | :--- |
| **开本通行证 (Paralls ID)** | 玩家的全球唯一身份标识，绑定所有资产、战绩、社交关系 | 跨服架构设计 |
| **全球档案** | 包含基本信息、战绩总览、成就徽章、收藏品展示的公开主页，全平台通用 | 跨服架构设计 |
| **真实身份档案** | 仅自己可见：完整身份、人生记忆摘要、核心秘密、真实不在场证明、伪装道具清单、固定知情人、暗杀能力等级、特殊技能 | 角色维度设计 |
| **公开档案（可编辑）** | 对外展示的身份面具：姓名、身份、背景、与死者关系、案发时行踪。可隐藏特定条目 | 角色维度设计 |
| **建议伪装身份档案** | 开本时系统生成的假身份说明书，扮演者可编辑 | 角色维度设计 |
| **角色状态栏** | 显示角色名、压力值（0-10进度条+颜色变化）、当前情绪（图标+文字）、体力/伤势、特殊状态图标（中毒/醉酒/致幻/PTSD等） | 玩家交互界面设计 |

### 二、穿梭与带走机制

| 功能 | 说明 | 来源 |
| :--- | :--- | :--- |
| **世界穿梭能力** | 玩家作为“观书人”可在不同平行世界间穿梭，这是玩家独有的核心技能 | AI陪伴设计 |
| **邀请同行** | 通过交互动作轮盘选择“邀请同行”，向建立了深厚羁绊的AI角色发出邀请 | 带走机制设计 |
| **坦白机制** | 带走智能体时，必须向它坦白自己的真实身份——一位能穿梭不同“平行世界”的“观书人” | 带走机制设计 |
| **个人空间** | 一个3D场景（如“观书人的书房”），可容纳被带回的智能体，进行基础对话和互动 | 个人空间设计 |
| **已带回智能体列表** | 在个人中心查看所有已带回的AI角色 | 个人中心设计 |

### 三、交互与行动系统

| 功能 | 说明 | 来源 |
| :--- | :--- | :--- |
| **对角色可执行的动作** | 公开交谈、耳语、展示物品、移交物品、跟随、邀请跟随、观察、搜身、救治、攻击/暗杀、唤醒/扶起 | 交互动作系统设计 |
| **对物品可执行的动作** | 拾取、检查/调查、使用、推/拉、打开/关闭、隐藏/躲藏、破坏、修复 | 交互动作系统设计 |
| **对场景可执行的动作** | 坐下、点燃/熄灭、窃听、标记、攀爬/翻越 | 交互动作系统设计 |
| **全局行动菜单** | 呼喊、制造噪音、留下标记、加速移动、潜行移动、假装受伤、自首/坦白、伪装调整、查看环境、等待 | 全局行动菜单设计 |
| **移动姿态切换** | 正常行走、奔跑、潜行、蹲伏，不同姿态影响脚步声和被感知范围 | 移动与控制系统设计 |
| **视角控制** | 第一人称/第三人称切换、聚焦观察、环顾四周（Alt键）、快速回头 | 移动与控制系统设计 |
| **交互准星** | 屏幕中央准星对准目标时高亮，区分可交互类型（物品/角色/暗杀目标/拾取物） | 移动与控制系统设计 |

### 四、信息与社交系统

| 功能 | 说明 | 来源 |
| :--- | :--- | :--- |
| **五种信息共享方式** | 公开对话（清晰区全员可见）、私密对话/耳语（1米内指定对象）、展示物品（视野内全员可见）、带人查看（需物理移动到证据位置）、留影石/相机拍摄 | 信息共享机制设计 |
| **留影石/相机** | 适用于不同时代背景的证据记录工具。拍摄次数有限，可被目击，产出的留影/照片可移交、展示、销毁 | 留影石/相机系统设计 |
| **偷听机制** | 当非对话参与者进入耳语清晰区时，对话双方屏幕出现“有人靠近”提示，偷听者可听到内容 | 空间音频设计 |
| **笔记与推理面板** | 自由笔记、线索列表（自动记录）、时间线视图、关系网络图、嫌疑人评分、证据链构建 | 笔记与推理面板设计 |
| **背包面板** | 分类管理：线索、工具、武器/凶器、伪装道具、消耗品、留影/照片 | 背包面板设计 |
| **辅助面板（可关闭）** | 玩法指引（当前阶段规则提示）、机制速查、决策建议（基于局势生成符合人设的行动选项）、行为后果预估 | 辅助面板设计 |

### 五、沉浸式设置

| 功能 | 说明 | 来源 |
| :--- | :--- | :--- |
| **强制变声器** | 不可关闭，根据角色档案自动配置专属变声参数，保护AI语音身份，同时让玩家声线契合角色人设 | 沉浸式设置设计 |
| **文字润色（可选）** | 可关闭，AI将玩家输入的文字润色为符合角色语言风格的表达 | 沉浸式设置设计 |

### 六、特殊能力

| 功能 | 说明 | 来源 |
| :--- | :--- | :--- |
| **“凝神”能力（单人/AI模式专属）** | 时间暂停能力。可360度环顾四周、凝视获取线索（准星对准角色/物品浮现内心独白式分析）、沉浸式记录（拍照）、整理思路（翻阅笔记），但不能移动、不能交互、不能推进逻辑判定 | 凝神能力设计 |

### 七、社交与匹配

| 功能 | 说明 | 来源 |
| :--- | :--- | :--- |
| **多种匹配模式** | 纯真人模式、纯智能体模式、智能体优先模式、真人优先模式、混合模式、携友组队模式、携带私人智能体模式、携友+携智能体混合模式 | 匹配系统设计 |
| **全局好友与公会系统** | 独立于服务器的社交层，好友列表、聊天功能、公会系统全球化 | 跨服架构设计 |
| **跨服状态与邀请** | 全球好友列表实时显示好友状态，可跨服发送组队邀请，或点击“去找Ta”跳转到好友所在服务器 | 跨服架构设计 |

### 八、资产与消费

| 功能 | 说明 | 来源 |
| :--- | :--- | :--- |
| **买断资产永久权** | 所有买断的剧本、皮肤、智能体等数字资产，绑定玩家全球账户，永久有效，跨服使用 | 玩家消费模式设计 |
| **资产跨服使用** | 核心买断资产不受单一服务器经营状况影响，可在全平台官方与大玩家服务器中自由使用 | 跨服架构设计 |
| **云存档与扩容** | 基础免费云空间（有容量和时限），超出可付费扩容 | 资产保障设计 |
| **P2P自建服务器** | 玩家可在自己的电脑上运行剧本，资产存储在本地硬盘，实现真正的“永久保存” | P2P自建服务器设计 |

### 九、OOC行为处理

| 功能 | 说明 | 来源 |
| :--- | :--- | :--- |
| **OOC区分** | 战略偏离（玩家选择偏离人设的战略行为）不被视为OOC，是游戏策略的一部分 | OOC处理设计 |
| **OOC评分监控** | 司命对玩家言行进行实时OOC评分 | OOC处理设计 |
| **游戏世界自然反应** | 当玩家对NPC说OOC内容时，NPC根据人设做出困惑回应，或信任值下降 | OOC处理设计 |

**总结**：玩家角色在《开本》剧本中拥有约**40+项完整功能**，涵盖身份档案、交互动作、信息管理、社交博弈、沉浸设置、特殊能力等维度。这些功能确保了玩家在3D世界中既能自如行动和社交，又能深度参与推理博弈，同时保留了完整的沉浸感和策略深度。
