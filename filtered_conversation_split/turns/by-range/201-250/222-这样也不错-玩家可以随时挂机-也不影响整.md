## 挂机兼容性：由智能体底层驱动带来的独特优势

### 一、传统游戏的挂机困境

| 游戏类型 | 玩家挂机时发生什么 | 对其他玩家的影响 |
| :--- | :--- | :--- |
| **传统剧本杀/桌游** | 游戏完全停滞，所有人等待 | 体验被彻底打断 |
| **在线多人游戏** | 角色原地不动，变成“死人” | 队友被迫少人，可能直接输掉 |
| **MMORPG副本** | 角色跟随或原地发呆 | 队友愤怒，可能被踢出队伍 |

**传统游戏中的挂机是一种“故障状态”**——系统无法理解玩家为什么不动，只能让角色变成一个僵硬的木偶。

### 二、《开本》的挂机：角色从未停止“活着”

在《开本》中，当玩家暂时离开（未操作超过一定时间），**角色的底层智能体接管L3规划层的决策权**，角色不会变成木头人，而是继续以一个符合人设的、独立个体的方式存在。

| 挂机阶段 | 发生什么 |
| :--- | :--- |
| **检测到玩家未操作** | 系统开始计时（如30秒无操作） |
| **进入“自主模式”** | 角色的L3规划层从“玩家决策”切换为“AI自主决策”。底层L1/L2/L4层从未停止运行，切换是无缝的 |
| **角色自主行为** | 角色会根据当前情境、人设、情绪状态，自主决定行动：继续调查、与人交谈、回避威胁、甚至发呆思考 |
| **其他玩家的感知** | 其他玩家可能察觉这个角色“似乎心不在焉”，或“好像在沉思”——这是完全符合叙事的。他们不知道玩家是否挂机，只知道这个角色在自主行动 |
| **玩家回归** | 玩家触碰任意按键，L3规划层瞬间交还控制权。玩家可以看到挂机期间发生了什么（系统会生成一个简短的“挂机期间简报”） |

### 三、自主模式下的角色行为

当玩家挂机时，角色会进入自主模式，但其行为会受到一些限制：

| 行为类型 | 自主模式下是否允许 | 说明 |
| :--- | :--- | :--- |
| **基础移动** | ✅ | 在场景中自然走动、靠近感兴趣的区域 |
| **观察环境** | ✅ | 查看物品、观察其他角色 |
| **被动对话** | ✅ | 如果有人主动搭话，会做出符合人设的简短回应 |
| **主动发起关键对话** | ❌ | 不会主动推进剧情关键对话，避免玩家错过重要情节 |
| **展示/使用关键物品** | ❌ | 不会主动展示或使用背包中的重要线索 |
| **暗杀/高风险行动** | ❌ | 绝不会在自主模式下执行暗杀或其他不可逆的高风险行为 |
| **投票** | ❌ | 投票阶段若玩家未回归，角色会弃权或跟随信任值最高的角色 |
| **微表情和小动作** | ✅ | 持续运行，角色依然鲜活 |

**核心原则：自主模式下的角色是“谨慎的自我保护者”——它不会做出玩家可能后悔的重大决定，但它足以维持角色的鲜活感和叙事的连贯性。**

### 四、玩家回归时的无缝衔接

当玩家回归时：

| 要素 | 处理方式 |
| :--- | :--- |
| **控制权交还** | 玩家触碰任意按键，瞬间恢复对L3规划层的完全控制 |
| **挂机期间简报** | 屏幕边缘出现一个可展开的“你不在时发生了什么”简报，概括角色在自主模式下的经历（听到的对话、观察到的异常、自身状态变化） |
| **记忆同步** | 自主模式下角色经历的所有事件，已自动写入记忆系统，玩家回归后可以翻阅 |
| **其他玩家的视角** | 其他玩家不会收到任何“某玩家已回归”的系统提示——他们只知道这个角色刚才似乎在沉思，现在又活跃起来了 |

### 五、对其他玩家的体验影响

| 情境 | 传统游戏 | 《开本》 |
| :--- | :--- | :--- |
| 有人挂机5分钟 | 队友愤怒、催促、可能退出 | 角色自主行动，可能被理解为“他在独自调查”或“她需要独处一会儿” |
| 推理讨论中有人挂机 | 关键信息缺失，讨论卡住 | 自主模式下的角色会做出简短回应（“我在听”、“让我想想”），不至于冷场 |
| 即将投票时有人挂机 | 投票无法进行 | 角色会弃权或跟随信任的角色，游戏可以继续 |
| 有人全程挂机 | 被踢出、被举报 | 如果完全挂机（从头到尾未操作），GM可介入处理。但偶尔的短时间挂机完全不影响 |

### 六、与“凝神”能力的关系

| 状态 | 触发方式 | 角色表现 | 区别 |
| :--- | :--- | :--- | :--- |
| **凝神（主动暂停）** | 玩家按专用键主动触发 | 世界进入子弹时间，所有角色冻结。玩家可观察、拍照、笔记 | 玩家主动使用，是一种策略工具 |
| **挂机自主模式** | 玩家长时间未操作，自动触发 | 世界继续运转，角色自主行动但保守 | 系统自动启用，是一种体验保障 |

### 七、为什么这不会破坏游戏性？

| 可能的风险 | 《开本》的应对 |
| :--- | :--- |
| **有人利用自主模式“挂机通关”** | 自主模式不会执行关键行动（暗杀、展示证据、主动推进关键对话），无法替代玩家完成核心推理 |
| **自主模式的AI决策不符合玩家意图** | 自主模式下的决策是保守的、非关键的。玩家回归后可立即纠正方向，且挂机期间的记忆已写入，不会丢失信息 |
| **其他玩家无法判断某人是否挂机** | 这正是设计意图——在叙事层面，“挂机”被自然化为“角色在沉思/休息/独自调查”。其他玩家需要通过社交互动来判断这个角色是否“心不在焉”，这本身就是推理乐趣的一部分 |

---

**一句话总结：在《开本》中，玩家挂机不是“故障”，而是角色从“被操控”短暂切换到“自主活着的状态”。这得益于每个角色底层都是完整的智能体——无论方向盘在玩家手中还是暂时交还给AI，角色本身从未停止“活着”。**
