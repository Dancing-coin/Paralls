## 深度沉浸机制

### 一、移动姿态与感知博弈

| 姿态 | 移动速度 | 脚步声 | 被感知距离 | 策略用途 |
| :--- | :--- | :--- | :--- | :--- |
| **正常行走** | 标准 | 标准 | 标准 | 日常移动 |
| **奔跑** | 1.5倍 | 大 | 更远 | 快速移动，但脚步声会暴露位置 |
| **潜行** | 0.5倍 | 极小 | 更近 | 接近目标不被发现，暗杀前置动作 |
| **蹲伏** | 0.3倍 | 极小 | 更近 | 降低被视觉发现概率，可进入低矮空间 |

**表面材质影响**：木地板、石板地、草地、楼梯等不同表面产生不同的脚步声，可被其他玩家和AI识别。

### 二、“凝神”能力的深度细节

| 要素 | 说明 |
| :--- | :--- |
| **触发方式** | 通过手柄或键盘上的专用按键即时触发，再次按下则恢复，无需打开任何菜单 |
| **视觉变化** | 画面色调转为低饱和度的电影质感，边缘出现轻微色散与光晕，空气中悬浮的微尘清晰可见 |
| **音效变化** | 所有环境音被抽离成空灵的混响，只留下玩家自己沉稳的心跳声 |
| **凝视获取线索** | 将准星对准特定角色或物品，系统会浮现其名称、状态和基于你当前所知信息的“内心独白”式分析 |
| **色盲辅助** | 为色盲玩家提供专属的色彩滤镜方案，确保所有视觉线索清晰可见 |
| **教程引导** | 通过专门的教程关卡，让玩家在安全环境中学习使用“凝神”，感受作为“观书人”的独特魅力 |

### 三、环境交互的沉浸细节

| 交互类型 | 沉浸细节 | 策略影响 |
| :--- | :--- | :--- |
| **开关门** | 需要动画时间，开关门的声音可被附近角色听到 | 暗杀前需确认无人注意，关门可制造私密对话空间 |
| **光源交互** | 点燃/熄灭蜡烛、开关电灯，改变场景光照和氛围 | 黑暗掩护潜行，但突然熄灯会引起他人怀疑 |
| **窃听** | 靠近门/墙时，可尝试听清另一侧的模糊声音 | 获取信息但有被撞见风险 |
| **隐藏/躲藏** | 进入柜子、窗帘后，降低被感知概率 | 可偷听、可躲避追查、可制造不在场证明 |
| **碰撞与物理** | 无法穿墙、无法穿过家具，撞倒物品会产生噪音 | 慌乱中可能留下痕迹 |

### 四、服装与世界合理性质疑

| 情况 | 系统处理 | 游戏内后果 |
| :--- | :--- | :--- |
| **穿着符合世界设定** | 正常进入，无任何影响 | 无 |
| **穿着不符合世界设定** | 系统弹出OOC警告：“此装扮与本世界设定严重不符，你将在局内面临来自其他角色的合理质疑。” | NPC会主动提出疑问，其他玩家可能借此在推理中质疑你。你的信任值可能因此下降。 |
| **故意利用服装制造“异乡人”人设** | 这是允许的叙事策略 | 可能触发特殊对话或隐藏剧情 |

### 五、AI角色对玩家行为的反应

| 玩家行为 | AI角色的可能反应 |
| :--- | :--- |
| 玩家穿不符合时代的服装 | “这位公子/小姐，你这身打扮...是从何而来？为何如此怪异？” |
| 玩家频繁出现在某处 | “你似乎对这间书房特别感兴趣。” |
| 玩家在对话中表现出异常 | “你的声音在发抖，你在隐瞒什么？” |
| 玩家撞倒物品发出噪音 | 附近的AI角色会看向声源方向，或走过去查看 |
