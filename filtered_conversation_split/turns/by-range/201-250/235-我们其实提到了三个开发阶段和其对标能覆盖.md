## 用户

我们其实提到了三个开发阶段和其对标能覆盖的游戏类型，请问这三个阶段，我们分别的核心系统有哪些，非核心系统有哪些？ 请你从专业全能的游戏策划角度来分析

## DeepSeek

从专业游戏策划的角度来看，我们的三阶段开发路线中，核心与非核心系统的划分标准是：**核心系统是构成该阶段“最小可玩闭环”所必需的，缺失则该阶段核心体验无法成立；非核心系统是增强体验、扩展玩法、优化服务的，缺失会影响体验丰富度但不影响核心玩法跑通。**

---

## Phase 1：静态世界内单局剧本

### 核心系统（MVP最小闭环）

| 系统 | 为什么是核心 |
| :--- | :--- |
| **3D场景与基础交互** | 玩家必须在3D世界中移动、拾取、检查物品。这是“3D沉浸”的物理基础 |
| **空间音频** | 清晰区/模糊区/静默区/耳语模式。这是信息博弈和社交推理的底层载体 |
| **角色智能体心智模型** | 五维人格、品格层、人生记忆、三重过滤器。AI角色必须有独立人格才能驱动动态叙事 |
| **司命（核心版）** | 事实核心（时间线管理+逻辑检查）+知识图谱（一阶/二阶）。确保案件逻辑不自相矛盾 |
| **案件与规则引擎** | T0-T2事实锁定、案件框架随机生成、线索系统、投票与结局判定。这是剧本杀的核心玩法骨架 |
| **对话生成系统** | LLM驱动的实时对话生成+TTS语音合成。玩家与AI角色的自由对话是沉浸感的核心来源 |
| **模型路由与延迟保障** | 三层模型+L1规则引擎兜底。保证AI反应不慢于人类常规，快可调慢、慢不可忍 |
| **感知系统** | 结构化语义事件替代截图、感知过滤器按角色感官过滤、动作阶段化感知。AI角色的“眼睛和耳朵” |
| **事件总线** | L1-L2-L3通信中枢。三层架构解耦的基础 |
| **信息共享执行系统** | 五种共享方式+三种知识形态管理+偷听检测。信息博弈的基础规则 |
| **房间与状态管理** | 房间创建/加入/销毁、角色锁定、T0-T2事实坍缩。多人游戏的基础 |
| **基础UI与交互面板** | 状态栏、背包、档案、笔记推理、投票界面。玩家操控角色的接口 |

### 非核心系统（Phase 1可缺失）

| 系统 | 为什么非核心 | 缺失的影响 |
| :--- | :--- | :--- |
| **暗杀机制** | 核心案件由初始案件驱动，局内暗杀是增强不是必须 | 缺少“案中案”的戏剧性，但不影响基础探案 |
| **伪装系统（完整版）** | 基础的身份隐藏可通过对话实现，伪装道具和压力系统是深化 | 伪装博弈深度降低，但不影响基础推理 |
| **迷宫与时空机制** | 丰富的空间和时空玩法是锦上添花 | 场景缺乏复杂机关和时空诡计 |
| **智能体带走与个人空间（轻量版）** | Phase 1可做轻量版 | 缺少“带走羁绊”的情感闭环 |
| **多种匹配模式** | 简单的创建/加入房间即可满足 | 缺少精细化的队友选择 |
| **L3视觉增强（完整版）** | 基础线索特写和立绘即可 | 缺少WOW时刻的视觉冲击 |
| **剧本编辑器（对外）** | 内部工具制作首个剧本即可 | 无法引入外部创作者 |
| **大玩家控制台** | Phase 1只有官方服务器 | 无法引入大玩家经营 |
| **全局好友与跨服社交** | 单服内游戏即可 | 缺少跨服社交网络 |
| **深度沉浸机制** | 微表情、小动作、内心戏是体验增强 | AI角色表现力降低，但不影响推理 |
| **玩家辅助面板** | 玩法指引和决策建议是辅助 | 新手上手难度增加 |
| **留影石/相机** | 额外证据记录手段 | 减少一种信息共享方式 |
| **凝神能力** | 单人模式的体验增强 | 单人模式体验打折扣 |
| **挂机自主模式** | 玩家短暂离开的体验保障 | 挂机时角色僵硬 |


## Phase 2：静态世界内连续单局剧本

### 新增核心系统（Phase 2必须新增）

| 系统 | 为什么是核心 |
| :--- | :--- |
| **种子库系统** | 剧本种子库（动机池、线索池、结局条件）+世界状态快照存储。这是“续集承接”的数据基础 |
| **续集承接逻辑** | 变量衔接规则+动态关系继承+跨剧本记忆。如果缺失，Phase 2的“连续单局”核心价值无法成立 |
| **智能体资产化** | 带走机制（完整版）+个人空间+跨剧本使用。这是Phase 2“AI陪伴经济”的基础 |
| **暗杀机制（完整版）** | Phase 1核心博弈已包含基础案件，Phase 2需要局内暗杀来增强动态叙事深度 |
| **伪装系统（完整版）** | Phase 1核心博弈已包含基础身份隐藏，Phase 2需要伪装道具和压力系统深化博弈 |

### 升级为核心的系统（Phase 1非核心→Phase 2核心）

| 系统 | Phase 1状态 | Phase 2状态 | 升级原因 |
| :--- | :--- | :--- | :--- |
| **司命（完整版）** | 仅事实核心+知识图谱 | +天平系统+冲突与案件生成器+干预执行器+暗杀催化 | 需要主动催化叙事涌现 |
| **知识图谱（完整版）** | 一阶/二阶 | +三阶知识+不确定态 | 支撑更深层的信息博弈 |

### Phase 2非核心系统

| 系统 | 为什么非核心 |
| :--- | :--- |
| **世界持续运行引擎** | Phase 2世界仍是“静态”的，司命不需要持续推演时间线 |
| **双层玩家身份** | 穿越旅人+原住居民的区分在Phase 3才需要 |
| **资产经营系统** | 庄园、商铺等持久资产在Phase 3才需要 |
| **世界编辑器** | 大玩家在Phase 3才需要创建完整世界观 |
| **跨世界旅行** | 跨世界使用智能体在Phase 3才需要 |
| **治理代币与IP议会** | Phase 3生态成熟后才需要DAO治理 |
| **完整的区块链确权与分账** | Phase 2可先用中心化分账过渡 |


## Phase 3：持续运行世界（单局与永续并存）

### 新增核心系统（Phase 3必须新增）

| 系统 | 为什么是核心 |
| :--- | :--- |
| **世界持续运行引擎** | 司命持续推演时间线（季节/天气/经济/社会事件）。这是Phase 3“世界永不重置”的基础 |
| **双层玩家身份系统** | 穿越旅人（无身份，单局体验）+原住居民（有身份，长期经营）。这是Phase 3“一个世界两种体验”的基础 |
| **资产经营系统** | 庄园、商铺、领地等持久资产管理+离线经营模拟。这是原住居民的核心玩法 |
| **算力与托管系统** | 大玩家算力套餐+玩家本地买断+算力租赁+离线托管。这是Phase 3商业模式的技术基础 |

### 升级为核心的系统（Phase 2非核心→Phase 3核心）

| 系统 | Phase 2状态 | Phase 3状态 | 升级原因 |
| :--- | :--- | :--- | :--- |
| **智能体能力系统** | 跨剧本记忆 | +跨世界压制+化身系统+同伴经营AI+私房钱 | 跨世界旅行需要能力压制；庄园经营需要AI同伴的自主工作能力 |
| **大玩家控制台** | Alpha版（策展+微调） | 完整版（世界构建+双层身份+GM指令舱） | 需要支持大玩家经营主题世界 |

### Phase 3非核心系统

| 系统 | 为什么非核心 |
| :--- | :--- |
| **特定游戏类型模板** | 种田经营、策略经营、生活模拟等模板是基于核心系统的内容扩展，可以后续逐步添加 |
| **治理代币与IP议会** | DAO治理在生态足够繁荣后才有实质意义 |
| **移动端助手** | 轻量管理工具，提升便利性但不影响核心玩法 |
| **Web管理后台** | 官方运营工具，对玩家体验无直接影响 |
| **完整的区块链确权与分账** | 智能合约分账是商业闭环的重要一环，但中心化分账可先过渡 |
