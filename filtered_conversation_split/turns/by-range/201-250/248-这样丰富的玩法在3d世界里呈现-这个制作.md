### 二、核心共建模块详解

#### 1. 建筑共建：让每个玩家成为建筑师

**官方提供**：
- 建筑基础模板库（城墙、兵营、农田、市场、铁匠铺等）
- 3D场景编辑器（在剧本编辑器中扩展建筑建造功能）
- 建筑属性配置器（建造时间、消耗资源、产出、升级路径）

**创作者参与方式**：

| 创作内容 | 说明 | 商业模式 |
| :--- | :--- | :--- |
| **建筑皮肤** | 为官方基础建筑创作不同风格的皮肤（哥特式、东方风、矮人风等） | 在资产市场出售，买断制 |
| **奇观模型** | 创作独一无二的史诗级建筑（空中花园、巨龙雕像、先王陵墓等） | 高价买断或限定发售 |
| **建筑功能扩展包** | 为建筑增加新的功能升级路径（如“带秘密地下室的铁匠铺”） | 买断制 |
| **全套城邦风格包** | 一整套统一风格的建筑皮肤（如“精灵森林城邦包”） | 整套出售 |

**玩家参与方式**：

| 参与方式 | 说明 |
| :--- | :--- |
| **领地内自由建造** | 在自己的领地内自由放置建筑、装饰物、道路，就像玩《模拟城市》一样 |
| **建筑升级与定制** | 消耗资源升级建筑，更换建筑皮肤 |
| **上传建筑方案** | 将自己设计的城邦布局保存为模板，发布到资产市场供其他玩家购买 |
| **评选与展览** | 参与全服建筑评选，最美城邦获得司命颁发的“金砖奖” |


#### 2. 地图共建：从官方基础到玩家共创

| 层级 | 建设者 | 内容 |
| :--- | :--- | :--- |
| **世界大地图** | 大玩家 | 使用地图编辑器，绘制世界地形、划定城邦边界、配置资源分布 |
| **战场地图** | 创作者 | 创作精致的小型战术地图（如“灰谷矿区”、“烈焰峡谷”），供玩家在战争中选用 |
| **领地内部布局** | 玩家 | 在自己的领地内自由设计地形微调、道路规划、防御工事布局 |


#### 3. 文化与事件共建：让世界充满故事

| 建设内容 | 建设者 | 说明 |
| :--- | :--- | :--- |
| **世界历史主线** | 大玩家 | 设定世界的核心冲突、重大历史事件的时间线 |
| **支线剧情包** | 创作者 | 创作可触发的事件链（如“失踪的商队”、“宫廷阴谋”），包含事件文本、触发条件、后果选项 |
| **随机事件模板** | 创作者 | 创作司命可调用的随机事件池（如“流星坠落”、“瘟疫爆发”），每条事件可配置触发概率和影响参数 |
| **文化内容** | 创作者 | 创作节日庆典、宗教仪式、诗歌传说等文化内容，增强世界的文化深度 |
| **玩家自创事件** | 玩家 | 在领地内举办活动（如“丰收庆典”、“骑士比武”），邀请其他玩家参与 |


#### 4. 兵种与战争共建

| 建设内容 | 建设者 | 说明 |
| :--- | :--- | :--- |
| **兵种基础模板** | 官方 | 提供基础兵种（步兵、骑兵、弓兵等）的属性和模型 |
| **兵种皮肤** | 创作者 | 为兵种创作不同风格的皮肤（如“圣殿骑士”、“暗影刺客”） |
| **独特兵种** | 创作者 | 创作全新兵种（如“矮人火枪手”、“精灵弓箭手”），定义其属性和克制关系 |
| **战术地图** | 创作者 | 创作可供玩家在战争中选用的战场地图 |


### 三、共建生态的商业闭环

| 参与者 | 贡献方式 | 收益方式 |
| :--- | :--- | :--- |
| **官方** | 提供基础框架、模型库、编辑器 | 从所有交易中抽取平台服务费（20%-30%） |
| **大玩家** | 运营主题世界，配置世界规则，审核内容 | 服务器门票、会员订阅、世界内交易税 |
| **创作者** | 创作建筑皮肤、奇观、兵种、事件包、地图 | 资产市场销售（80%归创作者）、被大玩家策展选用获得分成 |
| **玩家** | 购买使用、上传建筑方案、参与评选 | 建筑方案被其他玩家购买获得收益；参与评选获得奖励 |


### 四、与现有系统的复用

| 现有系统 | 在SLG共建中的复用 |
| :--- | :--- |
| **资产市场** | 建筑皮肤、兵种皮肤、奇观模型、事件包、战场地图的交易 |
| **剧本编辑器（扩展）** | 扩展为“世界编辑器”，支持地形绘制、资源分布、建筑放置 |
| **Fork与版本管理** | 创作者可以Fork官方的建筑模板、兵种模板进行二次创作 |
| **智能合约分账** | 自动分配建筑皮肤、兵种皮肤等资产的销售收益 |
| **推荐算法** | 推荐优质建筑方案、热门兵种皮肤给大玩家和玩家 |


### 五、最终效果：从“官方制作”到“全民共建”

| 传统SLG开发 | 《开本》SLG共建 |
| :--- | :--- |
| 官方做所有建筑模型 → 成本高、风格单一 | 官方提供基础模板 → 创作者提供海量风格化皮肤 |
| 官方设计所有兵种 → 数量有限 | 官方提供基础兵种 → 创作者创作独特兵种和皮肤 |
| 官方写所有剧情 → 内容消耗快 | 大玩家+创作者提供事件包 → 内容持续更新 |
| 官方画所有地图 → 几张地图反复用 | 大玩家画世界地图 + 创作者画战场地图 → 地图无限扩展 |
| 玩家只能玩 → 被动消费 | 玩家可以建造、创作、出售 → 主动参与 |

---

**一句话总结**：《开本》的IP创作生态让SLG世界从“官方单方面制作”变成“全民共建”。官方提供基础框架和编辑器，创作者提供海量风格化内容（建筑、兵种、事件、地图），玩家在自己的领地上自由建造和布局。所有人都在资产市场中获得收益——这正是《开本》区别于传统SLG的核心生态优势。
