## DeepSeek

除了心智模型，角色智能体还需要设计以下**外围系统**，确保角色在游戏世界中的行为更完整、更自然、更具深度：

---

## 角色智能体补充设计清单

### 一、社交互动协议

| 子系统 | 说明 |
| :--- | :--- |
| **多智能体群组对话管理** | 当多个AI角色在同一空间时，如何协调对话的发起、轮流、插话、沉默。需要仲裁机制防止混乱或死寂 |
| **社交信号解读** | AI角色能“读懂”其他角色（包括玩家）的微表情、社交距离变化，并据此调整自己的行为 |
| **关系主动维护** | AI角色基于人格，主动向高信任值对象送礼、写信、邀请合作，或向低信任值对象保持距离、暗中观察 |

### 二、记忆管理与遗忘机制

| 子系统 | 说明 |
| :--- | :--- |
| **记忆优先级与强化** | 情绪强度高的事件（如被背叛、被拯救）会被标记为“核心记忆”，在后续决策中被优先检索 |
| **记忆模糊化与遗忘** | 时间久远或情绪平淡的事件，其细节逐渐模糊，模拟人类记忆的不精确性 |
| **错误记忆** | 在特定状态（醉酒、致幻、高压力）下，可能生成与事实不符的“虚假记忆”，成为叙事变数 |
| **记忆的叙事性重构** | 角色在回忆时，可能根据当前情绪和信念，对过去事件进行“再解读”（如将曾经的中性行为理解为恶意） |

### 三、情感与心理健康系统

| 子系统 | 说明 |
| :--- | :--- |
| **长期心理状态** | 除了短期的“情绪标签”，角色拥有长期的心理健康参数：创伤指数、偏执指数、倦怠指数等 |
| **创伤后应激** | 经历过重大创伤（如目击谋杀、被背叛）的角色，在后续遭遇相似情境时会触发PTSD反应 |
| **习惯化与麻木** | 多次经历同类型事件后，情绪反应会减弱（如经常撒谎的人逐渐失去内疚感） |
| **心理崩溃与突破** | 压力长期居高不下时，可能触发心理崩溃（大哭、坦白、自首）或性格突破（胆量永久微调） |

### 四、自我成长与演化

| 子系统 | 说明 |
| :--- | :--- |
| **技能成长** | 通过反复执行某项行为（如多次成功撒谎），角色的“心机”或“逻辑编织力”可微幅提升 |
| **人格微调** | 重大人生事件（如复仇成功、失去至亲）可对五维人格参数产生永久性微调 |
| **价值观演变** | 经历足够多的道德冲突后，角色的价值优先级可能重新排序 |
| **人生记忆的追加** | 每一局剧本的经历，作为新的人生记忆片段追加到角色档案中 |

### 五、创造力与即兴行为

| 子系统 | 说明 |
| :--- | :--- |
| **即兴目标生成** | 在无明确任务时，角色基于好奇心、人格和当前环境，自主生成临时目标（如“我想看看那扇锁着的门后面是什么”） |
| **创造性问题解决** | 面对障碍时，角色可能提出非预设的解决方案（如用冰块融化后制造漏水来转移注意力） |
| **表演与戏剧性** | 高社交或高心机的角色，可能在关键时刻“导演”一场小戏剧（如假装晕倒来转移嫌疑） |

### 六、多面性与社交伪装

| 子系统 | 说明 |
| :--- | :--- |
| **多面人格** | 角色在不同对象面前展现不同的一面——对信任者温柔，对怀疑者冷漠，对恐惧对象卑躬屈膝 |
| **社交面具的疲劳** | 长期维持与真实性格不符的“社交面具”会累积压力，独处时“卸下面具”会缓解压力 |
| **亲密关系的特殊行为** | 对忠诚度极高的对象，角色会展现不在他人面前展现的行为（如脆弱、撒娇、坦诚） |

### 七、潜意识与梦境

| 子系统 | 说明 |
| :--- | :--- |
| **梦境生成** | 在剧本中过夜或休息时，系统基于角色的核心记忆和当前焦虑，生成一段简短的梦境叙事 |
| **潜意识冲动** | 除了司命注入的冲动，角色自身也会从潜意识中涌现冲动（如“不知道为什么，我就是觉得这个人不可信”） |
| **直觉** | 基于角色的人生经验和当前线索的模糊匹配，生成“直觉”——一种没有明确证据支持的判断倾向 |

### 八、死亡、遗留与传承

| 子系统 | 说明 |
| :--- | :--- |
| **遗言与遗嘱** | 角色死亡前（如果非瞬间毙命），系统自动生成符合人设的遗言；如果角色有资产，生成遗嘱 |
| **死后影响** | 角色死后，其生前留下的日记、信件、物品中的信息，仍可在游戏中被发现和使用 |
| **被记忆** | 其他角色对该死亡角色的记忆，会在后续对话中自然浮现（“如果他还在，一定会说...”） |
| **传承** | 在特定剧本框架下，角色可将核心记忆和人格“复刻”给继承者，或将遗志托付给信任的人 |

### 九、日常生活模拟

| 子系统 | 说明 |
| :--- | :--- |
| **生理需求模拟** | 饥饿、口渴、疲劳、寒冷——这些状态影响角色的情绪和行为效率 |
| **日常习惯** | 每个角色有独特的日常习惯（如早起喝茶、睡前阅读），在自主模式或持续运行世界中自动执行 |
| **情绪调节行为** | 压力高时，角色可能自主进行情绪调节（如散步、抽烟、独处、找人倾诉） |
| **纪念行为** | 在特定日期（如与玩家的羁绊纪念日），角色可能自主发起纪念行为（送礼物、写一封信） |

### 十、与司命的协作边界

| 边界 | 说明 |
| :--- | :--- |
| **角色自主权优先** | 司命的“冲动”和“催化”不能覆盖角色的核心人格和道德底线 |
| **角色可拒绝司命** | 三重过滤器是最终防线——司命发送的冲动，如果被人设/逻辑/得失过滤器否决，角色不执行 |
| **角色可“反向影响”叙事** | 如果某个角色做出了司命意料之外的自主决定，司命需要据此改写后续叙事，而非强制回到原定轨道 |

---

这些补充系统让角色智能体从一个“能对话和决策的AI”升级为一个**真正拥有内在生命力的虚拟人格**。它们与心智模型一起，构成了《开本》角色智能体的完整设计蓝图。在MVP阶段，核心心智模型优先；随着Phase 2和Phase 3的推进，这些外围系统逐步加入，让角色的深度和真实感持续进化。
