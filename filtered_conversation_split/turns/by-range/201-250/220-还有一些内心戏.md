## DeepSeek

除了自动弥补的微表情和小动作，更深层次的沉浸机制还包括**内心戏的实时生成**——系统自动为玩家角色生成符合人设的内心独白、冲动和决策提示，让玩家不仅能“看到”和“听到”角色，更能“感受到”角色的内心世界。

## 内心戏的自动生成

### 一、核心原则

-   **人格驱动**：所有内心独白和冲动严格匹配角色的人格档案、当前情绪、压力值、秘密和目标。
-   **情境感知**：系统实时读取玩家当前所在场景、正在交互的对象、刚刚发现的信息，动态生成内心戏。
-   **非强制提示**：内心戏以轻量、可忽略的形式呈现，不打断玩家行动，玩家可以选择关注或忽略。
-   **私密性**：所有内心戏仅玩家自己可见，不会暴露给其他玩家或AI角色——除非玩家选择通过行动或对话表达出来。

### 二、内心戏的类型

#### 1. 自动内心独白

当玩家处于特定情境时，系统会以第一人称视角生成符合角色人设的内心独白，以半透明浮动文字的形式短暂出现在屏幕边缘，随后自动淡出。

| 情境 | 自动内心独白示例（角色：许仙，共情高、胆量低） |
| :--- | :--- |
| **发现关键线索** | “这把匕首……上面的血迹还没干透。如果这是凶器，那凶手可能还在附近……” |
| **被质问** | “他在怀疑我。我得冷静，不能露出破绽。” |
| **发现有人跟踪自己** | “背后有脚步声……是巧合，还是有人盯上我了？” |
| **见到受伤或死亡** | “天哪……这太残忍了。我该上前查看，还是该去叫人？” |
| **面对高怀疑值的角色** | “这个人的眼神躲躲闪闪，一定有鬼。但我没有证据，不能轻举妄动。” |
| **独处时** | “趁现在没人，我可以仔细检查这个房间，看看有没有遗漏的线索。” |
| **即将投票时** | “我必须做出选择了。如果投错了，真凶就会逍遥法外……” |

#### 2. 司命注入的“冲动”

司命可以像对待AI智能体一样，向人类玩家注入模糊的“冲动”——一种微妙的行为倾向或灵光一现的念头，而非明确的指令。玩家完全自主决定是否遵从这种冲动。

| 冲动类型 | 呈现方式 | 示例 |
| :--- | :--- | :--- |
| **怀疑冲动** | 半透明文字：“你突然觉得，刚才那个人的话似乎有哪里不对劲。” | 引导玩家重新审视某段对话 |
| **探索冲动** | 半透明文字：“你隐约觉得，那间地下室似乎藏着什么重要的东西。” | 引导玩家去某个区域探索 |
| **坦白冲动** | 半透明文字：“你感到一阵强烈的不安。或许，是时候把真相说出来了。” | 当秘密过于沉重或压力过高时 |
| **保护冲动** | 半透明文字：“看到TA被众人质问，你突然有种想站出来的冲动。” | 高共情或高忠诚度角色对在意的人产生保护欲 |
| **逃避冲动** | 半透明文字：“这个地方让你窒息。你想逃离这里，哪怕只是片刻。” | 高压力值时的自然反应 |

**与AI智能体冲动的区别**：
-   AI智能体收到冲动后，由其人格过滤器自主决定是否响应。
-   人类玩家收到冲动后，完全自主决定是否遵从。冲动只是增强沉浸感的叙事辅助，不是强制引导。

#### 3. 决策建议（辅助面板，可关闭）

玩家辅助面板中有一个“决策建议”模块，系统会根据当前局势和角色人设，生成几个符合人设的行动选项。这是可关闭的，仅供玩家参考。

| 选项类型 | 示例（角色：高心机、低胆量） |
| :--- | :--- |
| **试探** | “旁敲侧击地问他案发时在哪，看他有没有露出破绽。” |
| **隐瞒** | “暂时不要透露你刚才发现的那封信，它可能是你的护身符。” |
| **结盟** | “这个人似乎可以信任。或许该找他私下谈谈，交换情报。” |
| **转移嫌疑** | “如果你被怀疑，可以暗示另一个人更有动机。” |
| **主动揭露** | “这个秘密太沉重了。也许说出来，对你才是解脱。” |

### 三、与玩家主动姿态的关系

| 玩家主动选择的“姿态” | 对内心戏生成的影响 |
| :--- | :--- |
| **自然状态（默认）** | 内心独白和冲动如实反映角色人设和当前情绪 |
| **保持冷静** | 内心独白更偏向逻辑分析，压制情绪化的内容；但系统会暗中累积压力，并在压力临界点时爆发式注入强烈冲动 |
| **故作镇定** | 内心独白会出现“自我说服”式的内容，如“我能撑过去……我能撑过去……”同时系统会生成更频繁的“崩溃冲动” |
| **假装慌张** | 内心独白会出现“表演性”的内容，如“我得装得更害怕一点，让他们放松警惕” |

### 四、对游戏性的影响

| 影响 | 说明 |
| :--- | :--- |
| **降低推理门槛** | 不擅长推理的玩家，可以通过内心独白获得线索的初步分析，不至于完全迷失 |
| **增强角色扮演** | 不擅长RP的玩家，可以通过内心独白“听到”自己角色的声音，更容易进入角色状态 |
| **提供策略提示** | 决策建议不是“正确答案”，而是基于人设的可能性提示。玩家可以采纳、修改或完全忽略 |
| **增强沉浸感** | 内心戏让玩家感受到自己正在“成为”这个角色，而非仅仅“操控”这个角色 |
| **保留自主权** | 所有内心戏都是“建议”和“提示”，玩家永远是最终决策者 |

## 完整深度沉浸机制总结

| 层级 | 机制 | 驱动方式 |
| :--- | :--- | :--- |
| **身体层** | 性格化小动作、情境化微表情 | 系统自动映射（基于人设+情绪+情境） |
| **社交层** | 社交距离与空间行为 | 系统自动映射（基于信任值/怀疑值） |
| **言语层** | 语音微表现（语速、停顿、声调） | 系统自动映射（基于情绪+撒谎状态） |
| **内心层** | 内心独白、冲动、决策建议 | 系统实时生成（基于人设+情境） |
| **控制层** | 玩家主动姿态切换（自然/冷静/镇定/慌张） | 玩家主动选择，系统据此调整上述所有自动映射 |

这套深度沉浸机制，让玩家在《开本》的世界里不再需要“假装”成为一个角色，而是真正地“感受”和“体验”那个角色——系统为你补齐了所有细微的身体语言和内心声音，你只需要专注于做出选择，享受故事。
