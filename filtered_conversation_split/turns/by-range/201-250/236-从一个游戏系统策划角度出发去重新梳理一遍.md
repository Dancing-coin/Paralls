## 用户

从一个游戏系统策划角度出发去重新梳理一遍。以下是参考资料：基础系统：支撑游戏基本运行但不属于游戏可玩内容的系统模块，例如游戏设置系统。养成系统：具有养成属性的系统，例如角色养成、装备养成等系统模块。战斗系统：包含怪物系统、技能系统、枪械系统等系统模块。玩法系统：包含战场玩法、副本关卡玩法等。经济系统：游戏资源产出、交易和消耗相关的系统，如拍卖行、寄售系统等。社交系统：游戏中人人交互，如好友、帮会等。

# 《开本》系统策划文档

## 八、设计哲学总结

| 设计原则 | 说明 |
| :--- | :--- |
| **玩法系统是绝对核心** | 30个玩法系统占总量的32%，是《开本》区别于所有传统游戏的核心竞争力 |
| **社交系统依附玩法生长** | 社交不是强制加好友，而是从共同冒险中自然涌现的羁绊 |
| **养成系统围绕“人”展开** | 不是传统的装备数值养成，而是智能体羁绊、记忆、经济的深度养成 |
| **经济系统服务创作生态** | 区块链确权、智能合约分账、众筹、双轨邀请，让创作者和传播者都能获益 |
| **战斗系统弱化** | 仅保留叙事驱动的暗杀机制和特殊状态，不引入传统RPG战斗数值对抗 |
| **基础系统为沉浸体验护航** | 变声器、文字润色、深度沉浸、挂机自主——所有基础系统都服务于“有人在味”的体验 |
