# 角色智能体设计方案

## 一、核心定位

角色智能体是《开本》中所有AI角色的驱动核心。它不是一个预设对话树或行为状态机，而是一个拥有**完整心智模型、独立人格、自主决策能力**的虚拟生命。

**核心原则**：
- 角色智能体与人类玩家权限完全一致
- 每个智能体的行为由其人格档案、动态状态和当前感知共同决定，而非预设脚本
- 司命只催化不控制，所有行为最终由角色自身的心智模型决定


## 二、SIMA 2的启示

谷歌DeepMind的SIMA 2向我们证明了AI作为“游戏搭子”的可行性。其核心设计理念对我们启发巨大：

| SIMA 2核心理念 | 在《开本》中的应用 |
| :--- | :--- |
| **“感知-推理-行动-反思”闭环** | 四层心智模型（感知→理解→规划→执行） |
| **多模态交互能力** | 结构化语义感知替代截图，同时支持语音、文本交互 |
| **从指令到目标的跃升** | 不写行为树，直接告诉AI“你的目标是隐藏间谍身份”，它自主推演子目标 |
| **实时决策与适应** | 模型路由系统保证硬上限，人格参数驱动决策而非预设策略 |


## 三、完整心智模型架构

```
                ┌──────────────┐
                │   基因种子    │  出身、天赋、早年事件
                └──────┬───────┘
                       ↓
                ┌──────────────┐
                │   人生记忆    │  关键事件、长期状态、创伤、重大选择
                └──────┬───────┘
                       ↓
                ┌──────────────┐
                │   品格层      │  道德取向、价值优先级、自我认知
                └──────┬───────┘
                       ↓
                ┌──────────────┐
                │   行为层      │  五维人格参数（胆量/心机/共情/理性/社交）
                └──────┬───────┘
                       ↓
                ┌──────────────┐
                │   决策系统    │  四层心智模型（感知→理解→规划→执行）
                └──────┬───────┘
                       ↓
                ┌──────────────┐
                │   记忆系统    │  开本后实时更新的记忆库（含公共/共有/高阶知识）
                └──────────────┘
```

**关键原则**：人生经历 → 品格 → 人格是单向推导关系。不是先决定“胆量7”，而是先生成人生经历，再从经历中自然推导出性格。


## 四、人格档案

### 4.1 基因种子

| 要素 | 说明 | 例子 |
| :--- | :--- | :--- |
| **出身** | 家庭背景、社会阶层 | 官宦世家、贫苦农户、孤儿 |
| **天赋** | 与生俱来的能力倾向 | 过目不忘、体弱多病、天生神力 |
| **早年关键事件** | 1-3个定义童年的重大事件 | 5岁时父母双亡、10岁时被师父收养 |
| **时代/地域** | 出生和成长的时代与地点 | 南宋临安、维多利亚时代的伦敦 |

### 4.2 人生记忆

由基因种子模拟生成，记录性格是如何一步步形成的：

- 关键事件：改变人生轨迹的事件
- 长期状态：持续多年的生活环境
- 关键人物：对角色影响深远的人
- 重大选择：角色自己做出的定义自身的决定
- 创伤：留下心理阴影的事件

### 4.3 品格层

| 维度 | 低分端 | 高分端 |
| :--- | :--- | :--- |
| **诚实** | 谎言是本能，毫无心理负担 | 撒谎会带来强烈的自我谴责 |
| **忠诚** | 随时可以背叛任何人 | 一旦承诺，死也要做到 |
| **正义感** | 只在乎自己的利益 | 对不公义的行为无法坐视 |
| **仁慈** | 对弱者毫无怜悯 | 不忍伤害无辜，哪怕自身难保 |
| **责任感** | 遇事先推脱逃避 | 是自己的责任，无论如何都要扛 |

**价值优先级**：当道德取向发生冲突时，角色按价值优先级排序选择。

### 4.4 行为层：五维人格参数

| 维度 | 低分倾向 (0-3) | 中分倾向 (4-6) | 高分倾向 (7-10) |
| :--- | :--- | :--- | :--- |
| **胆量** | 胆小如鼠，遇事先躲 | 谨慎行事，评估风险 | 胆大包天，敢孤身犯险 |
| **心机** | 天真单纯，心直口快 | 有点城府，懂得藏拙 | 老谋深算，步步为营 |
| **共情** | 冷酷无情，漠视他人 | 有所触动，但有底线 | 菩萨心肠，愿为他人牺牲 |
| **理性** | 冲动易怒，感情用事 | 能冷静思考，但会受影响 | 绝对理智，只计算利弊 |
| **社交** | 孤僻寡言，回避交流 | 正常社交，视对象而定 | 长袖善舞，主动攀谈引导 |

**关键设计**：理智不是默认值，每个角色的决策是五个维度、目标层级、恐惧层级、当前情绪状态共同作用的结果。低理性+高胆量+低心机的角色，可能想到什么说什么，冲动行事——“不合理”但完全符合人设。


## 五、四层决策心智模型

| 层级 | 职责 | 核心功能 |
| :--- | :--- | :--- |
| **L1 感知层** | 接收并过滤外界刺激 | 语义感知替代视觉截图，与人类同源计算 |
| **L2 理解层** | 解读感知数据的含义，更新信念 | 真实性评估、相关性评估、推论生成、不确定态管理 |
| **L3 规划层** | 基于当前信念和目标，生成行动方案 | 恐惧/目标/社交/好奇四重动机驱动，人格过滤 |
| **L4 执行层** | 选择最优方案，生成具体行为 | 对话输出、动作输出、状态更新 |

### 5.1 决策流程

```
[外部刺激/定时触发]
    ↓
L1 感知层：接收结构化事件，过滤噪音
    ↓
L2 理解层：解读信息，生成推论，更新信念（更新信任值/怀疑值/情绪状态）
    ↓
L3 规划层：基于动机（恐惧/目标/社交/好奇）生成候选行动，人格过滤，优先级排序
    ↓
L4 执行层：生成对话文本/情绪参数/动作指令/状态更新
    ↓
[影响世界，触发新的感知] → 循环
```

### 5.2 决策频率

- **被动响应**：收到外部刺激后立即启动决策（目标延迟1-3秒）
- **主动行动**：每30-60秒自动评估是否应主动发起行动
- **应急反应**：突发威胁立即打断当前计划，紧急决策

### 5.3 行动动机来源

| 动机来源 | 优先级 | 说明 |
| :--- | :--- | :--- |
| **恐惧驱动** | 最高 | 当恐惧层级中的某一项被触发时，采取避险行动 |
| **目标驱动** | 高 | 为达成目标层级中的目标而主动行动 |
| **社交驱动** | 中 | 基于信任/怀疑值，维护或改善与他人的关系 |
| **好奇驱动** | 低 | 对新信息的探索欲，在无明确任务时保持活跃 |


## 六、人格过滤器（三重验证）

所有AI角色的行为必须通过三道过滤器的验证：

| 过滤器 | 检查内容 | 不通过时的处理 |
| :--- | :--- | :--- |
| **人设过滤器** | 这个角色“会”这么做吗？ | 生成符合人设的替代行为 |
| **逻辑过滤器** | 这个行为在故事里“合理”吗？（能力/时空/信息逻辑） | 阻止行为，或转移给更合理的角色执行 |
| **得失过滤器** | 这么做对角色自己“有利”吗？（目标层级+恐惧层级计算） | 如无利可图，需有更大的利益或恐惧驱动才会执行 |


## 七、动态状态管理

| 状态参数 | 范围 | 影响 | 变化因素 |
| :--- | :--- | :--- | :--- |
| **压力值** | 0-10 | 高压力降低“理性”维度，增加冲动行为概率 | 被质疑、秘密接近暴露、时间紧迫 |
| **信任值** | 针对每个对象 | 影响信息分享意愿和合作倾向 | 对方的言行一致性、是否帮助过自己 |
| **怀疑值** | 针对每个对象 | 影响对他人信息的采信度 | 对方的行为反常、被他人指证 |
| **情绪标签** | 当前主导情绪 | 影响决策偏向和语言风格 | 由事件触发（如被背叛→愤怒） |


## 八、伪装系统

### 8.1 伪装能力来源

- 基因种子 + 人生记忆（如长期生活在欺骗环境中 → 撒谎无心理负担）
- 品格层（诚实度低者伪装更自然）
- 行为层（高心机者擅长编织复杂谎言）

### 8.2 伪装深度

| 等级 | 描述 | 典型角色 |
| :--- | :--- | :--- |
| **零伪装** | 公开档案完全真实 | 福尔摩斯 |
| **浅层伪装** | 仅隐瞒1-2项关键信息 | 老管家隐瞒案发时曾进入书房 |
| **中度伪装** | 身份真实，但不在场证明伪造 | 玛丽·萨瑟兰 |
| **深度伪装** | 整个身份都是伪造的 | 艾琳·艾德勒 |

### 8.3 伪装必须有物理道具支撑

- 外貌伪装和身份伪装必须依赖具体道具（假发、假证件、化妆品等）
- 道具是物理存在于游戏世界中的物品，可被搜查、发现、销毁
- 道具的存在被多重记录（NPC记忆+搜证线索+时间消耗），销毁代价极高

### 8.4 伪装压力系统

| 压力来源 | 说明 |
| :--- | :--- |
| **道德冲突压力** | 高诚实度角色撒谎时产生巨大的内心冲突 |
| **逻辑维持压力** | 随着谎言网络扩大，维持逻辑自洽的难度递增 |
| **外部质询压力** | 被多人同时质疑、被出示关键证据时压力急剧上升 |
| **时间压力** | 谎言维持时间越长，被拆穿风险越大 |

压力积累到临界点，角色可能崩溃坦白、逃跑或做出极端行为。


## 九、知情人系统

### 9.1 知情人分类

| 类型 | 身份 | 知情方式 |
| :--- | :--- | :--- |
| **固定NPC知情人** | 剧本创作者预设 | 剧本配置时写入NPC记忆库 |
| **动态NPC知情人** | 游戏过程中因目击而获知 | 司命根据L1感知层判定，注入NPC记忆 |
| **智能体参与者知情人** | 其他AI角色 | 通过自己的心智模型推理得出 |
| **玩家参与者知情人** | 其他真人玩家 | 通过搜证和观察自行推理得出 |

### 9.2 设计原则

- NPC知情人知情不完整、不主动、可被影响
- 伪装者有多种反制策略：收买/威胁/博取同情/灭口/销毁证据
- 司命控制知情传播速度，确保体验不过快或过慢


## 十、自主行为系统

| 行为类型 | 触发条件 | 例子 |
| :--- | :--- | :--- |
| **自主移动** | 基于目标层级，需要去某处或找某人 | 福尔摩斯决定去旅馆房间重新检查现场 |
| **主动对话** | 基于关系网络和当前局势，有信息需要传达或试探 | 华生主动找信任的玩家私下分享疑虑 |
| **物品交互** | 基于目标或叙事需要，与环境互动 | 玛丽试图在无人时销毁可能暴露自己的物品 |
| **观察与跟踪** | 基于怀疑值，对可疑对象进行观察 | 小青跟踪法海，看他是否去挖自己埋的东西 |
| **应急反应** | 突发公共事件时的人设驱动反应 | 听到尖叫时，胆大的冲过去，胆小的躲起来 |


## 十一、感知系统

### 11.1 核心原则

智能体不截图，而是接收与人类同源的**结构化语义事件流**。人类通过3D渲染和空间音频感知，AI通过同一套物理计算的语义化结果感知。

### 11.2 感知通道

| 感知通道 | 人类 | AI智能体 |
| :--- | :--- | :--- |
| **视觉** | 眼睛看3D渲染画面 | 结构化“可见对象列表”（含距离、状态、特征、可执行交互） |
| **听觉** | 耳朵听空间音频 | 结构化“可听事件列表”（含清晰度分级：clear/muffled/distant/barely_audible） |
| **环境** | 感受到环境变化 | 结构化“环境事件”通知 |

### 11.3 感知过滤器

为每个角色独立计算“此刻应该感知到什么”：
- **感官启用检查**：盲人角色视觉禁用，听觉增强
- **空间范围检查**：不在感知范围内的事件绝不推送
- **物理遮挡检查**：门/墙对声音和视觉的衰减
- **角色状态修正**：醉酒/致幻/专注时感知精度降低

### 11.4 动作的阶段化感知

| 阶段 | 事件类型 | 智能体反应 |
| :--- | :--- | :--- |
| **意图阶段** | `action_intent` | 即刻反应，不必等动作完成 |
| **执行阶段** | `action_executing` | 可中途干预 |
| **完成阶段** | `action_completed` | 得知结果 |


## 十二、与司命的协作

| 消息方向 | 消息类型 | 说明 |
| :--- | :--- | :--- |
| 司命 → 角色 | `impulse` (冲动) | 模糊的行为倾向，如“你开始怀疑XX”。角色自主决定是否响应 |
| 司命 → 角色 | `fact_reveal` (事实披露) | 告知角色其本应知道的事实 |
| 司命 → 角色 | `opportunity` (机会提示) | 暗杀等高风险行为的机会窗口信息 |
| 角色 → 司命 | `action_report` (行为报告) | 角色执行任何交互后上报 |
| 角色 → 司命 | `request_intervention` (请求干预) | 角色陷入困境时可请求建议（仅限AI角色） |

**核心原则**：司命只催化，不控制。角色的所有行为最终由其自身的心智模型决定。


## 十三、技术实现要点

| 要点 | 说明 |
| :--- | :--- |
| **模型路由** | P0致命威胁走L1规则引擎（<300ms）；P1-P3走L2小模型（200-800ms）或L3大模型（800-3000ms） |
| **人格对延迟的调节** | 高理性延迟+20-50%，低理性延迟-30-50%，高压力下本能反应增加 |
| **对话生成** | LLM上下文组装+流式生成+TTS情绪注入+动作先行 |
| **感知系统** | 基于事件总线的结构化事件推送，不依赖多模态视觉模型 |
| **记忆系统** | 向量数据库存储人生记忆和对话历史的语义索引 |
