## DeepSeek

你的判断非常精准。在一个城邦级别的SLG中，不可能、也不应该让每个国民都运行完整的智能体。正确的架构是：**群体模拟作为基础层，智能体作为交互层，两者通过“记忆注入”机制无缝切换**。

## 分层角色驱动架构

### 一、角色分层

| 层级 | 角色类型 | 驱动方式 | 数量级 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| **L1 关键角色** | 国家领袖、核心官员、贵族将领、行会首领、重要商人 | **完整智能体** | 数十至数百 | 始终运行完整心智模型，拥有独立人格、记忆、目标，可随时与玩家深度对话 |
| **L2 交互角色** | 被玩家主动接触的普通国民、执行特定任务的士兵、被征税的商人 | **按需注入智能体** | 从群体中临时提取 | 平时以群体模拟方式存在；被玩家接触时，系统根据其群体属性即时生成临时记忆和人格，注入智能体与玩家对话 |
| **L3 群体角色** | 农民、矿工、基础士兵、普通市民 | **群体模拟（无智能体）** | 成千上万 | 由群体行为算法驱动，只产生统计数据（产出、消费、迁徙、情绪均值），不生成个体对话 |

---

### 二、群体模拟引擎

**职责**：驱动L3群体角色的集体行为，产出统计数据。

| 模拟维度 | 说明 |
| :--- | :--- |
| **人口动态** | 各阶层人口数量、增长率、死亡率（受战争/饥荒/瘟疫影响） |
| **经济生产** | 各行业的资源产出、消耗、库存，基于人口和建筑等级计算 |
| **阶层情绪** | 各阶层的平均忠诚度、满意度、不满指数。受税率、战争胜负、粮食价格等影响 |
| **派系力量** | 各派系（主战/主和、重商/重农）的支持率分布 |
| **迁徙与逃散** | 战乱或暴政时，部分人口可能逃往其他城邦 |

**关键原则**：群体模拟输出的是**统计数据**，而非个体行为。例如，它不是“张三决定逃跑”，而是“农民阶层中有15%的人口因饥荒向邻国逃散”。

---

### 三、按需注入智能体

**核心机制**：当玩家与某个L2角色互动时，系统从群体模拟中“提取”一个代表，即时生成其临时人格和记忆，注入智能体。

**注入流程**：

1.  **玩家发起交互**：玩家点击某个普通国民，或系统事件触发了一个需要交互的角色
2.  **生成临时档案**：系统根据群体模拟数据，即时生成该角色的临时身份：阶层、职业、经济状况、当前情绪倾向
3.  **注入记忆**：系统为该角色生成一段简短的“背景记忆”，基于当前城邦的整体状况。例如：“我是城东的铁矿工坊主，最近铁价暴涨让我赚了不少，但听说国王要对A城邦禁运，我担心原料供应会断。”
4.  **启用智能体**：一个轻量级智能体被激活，加载临时档案和记忆，与玩家进行对话
5.  **回收或保留**：对话结束后，如果该角色后续仍有交互价值，系统将其标记为L2角色，保留其记忆；否则回收，其行为结果（如“被玩家说服支持某项政策”）更新回群体模拟的派系数据中

**记忆来源**：

| 记忆类型 | 生成方式 | 例子 |
| :--- | :--- | :--- |
| **阶层共性记忆** | 基于群体模拟数据自动生成 | “最近粮食价格涨得厉害，我们这些种地的倒是赚了点” |
| **城邦历史事件** | 基于该城邦最近发生的重大事件生成 | “上个月A城邦的军队路过我们村，把粮仓抢了一半” |
| **个人经历记忆** | 首次注入时随机生成基础经历，后续交互中累积 | “我家世代打铁，这把剑是我父亲打造的” |
| **与玩家的互动记忆** | 与玩家对话后保留 | “上次你说的那个提议，我和商会的人商量过了…” |

### 四、司命的统一调度

| 司命职责 | 说明 |
| :--- | :--- |
| **群体模拟驱动** | 持续计算各阶层人口、经济产出、情绪均值、派系力量 |
| **注入时机判断** | 当玩家与群体成员互动时，判断是否需要注入智能体（简单问答用模板，复杂对话注入智能体） |
| **关键角色升级** | 当某个L2角色因叙事需要变得重要（如“带头抗议的商人”），司命将其升级为L1角色，分配更多算力 |
| **行为结果回流** | 玩家与L2角色的交互结果，回流更新群体模拟的派系和情绪数据 |
| **算力负载均衡** | 监控全局智能体数量，在算力紧张时优先回收低优先级的L2智能体 |

---

### 五、对玩家体验的影响

| 情境 | 玩家感知 |
| :--- | :--- |
| **与关键角色互动** | 贵族、将军、核心官员拥有完整的个性和记忆，可以深度对话、协商、讨价还价 |
| **与普通国民互动** | 随机接触的国民拥有符合其身份的临时记忆，可以反映民意、提供情报，但对话深度有限 |
| **观察群体行为** | 通过统计数据、视觉表现（城市繁荣度、流民数量）感受国民整体状态，无需逐个对话 |
| **关键事件中的国民** | 带头抗议的商人、被征兵的儿子——这些临时角色被司命升级为关键角色，获得完整的叙事权重 |

### 六、开发优先级

| 阶段 | 交付 |
| :--- | :--- |
| **Phase 3.1 SLG基础** | L1关键角色智能体 + L3群体模拟引擎。先让传统SLG跑通 |
| **Phase 3.2 经济与内政** | L2按需注入机制。普通国民被接触时临时注入智能体 |
| **Phase 3.3 全面战争** | 司命的注入时机判断优化、算力负载均衡、行为结果回流 |


**一句话总结**：《开本》SLG中的角色驱动采用三层架构——关键角色始终运行完整智能体，普通国民以群体模拟方式存在，仅在需要交互时按需注入智能体。这既保证了“每个人有自己的考量”的叙事深度，又控制了算力成本。这正是《开本》智能体架构相比传统SLG的核心技术优势。
