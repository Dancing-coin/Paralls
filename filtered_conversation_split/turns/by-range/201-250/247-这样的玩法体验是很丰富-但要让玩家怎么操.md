### 二、四大政务面板

这些面板在国王视角下以半透明悬浮窗形式存在，可随时展开/折叠，互不遮挡。

**1. 政务面板（经济与内政）**

| 子面板 | 功能 | 操作方式 |
| :--- | :--- | :--- |
| **财政总览** | 国库收入/支出、各税种占比、外汇储备 | 查看数据曲线，调整税率滑块 |
| **资源调配** | 粮食、木材、石料、铁矿的产消存 | 拖动资源分配给不同城邦/项目 |
| **建筑与科技** | 建造/升级建筑队列，科技树选择 | 点击建筑放置，点击科技解锁 |
| **人口与阶层** | 各阶层人口、满意度、迁徙趋势 | 查看统计图表 |
| **朝会/议会** | 召集贵族讨论重大决策 | 对话式交互：听取各方意见→做出选择 |

**2. 军事面板**

| 子面板 | 功能 | 操作方式 |
| :--- | :--- | :--- |
| **军队总览** | 各部队兵力、位置、将领、士气、补给 | 地图上查看，点击部队查看详情 |
| **兵种配置** | 训练新兵、升级兵种、调整部队编成 | 拖拽兵种图标到部队槽位 |
| **行军命令** | 调动部队到指定位置 | 在地图上点击部队→点击目标地点→选择行军姿态（急行军/正常/潜行） |
| **要塞与防御** | 建造/升级城墙、箭塔、陷阱 | 在地图上选择位置放置 |
| **[御驾亲征]** | 切换到战术指挥面板 | 点击按钮，画面推入战场 |

**3. 外交面板**

| 子面板 | 功能 | 操作方式 |
| :--- | :--- | :--- |
| **关系总览** | 各城邦的关系等级、条约状态 | 查看关系网络图 |
| **派遣使节** | 选择使节→选择目标城邦→选择任务（结盟/贸易/抗议/宣战/求和） | 下拉菜单选择 |
| **条约管理** | 查看、签订、撕毁条约 | 查看文本→确认/取消 |
| **联姻提议** | 向目标城邦提议联姻 | 选择你的王室成员→选择对方王室成员 |

**4. 情报面板**

| 子面板 | 功能 | 操作方式 |
| :--- | :--- | :--- |
| **间谍网络** | 查看已派遣的间谍、其位置和状态 | 地图上查看间谍标记 |
| **派遣间谍** | 选择间谍→选择目标城邦→选择任务（窃取情报/策反/破坏/散布谣言） | 下拉菜单选择 |
| **情报报告** | 阅读间谍发回的报告 | 点击报告卡片查看详情 |
| **反间谍** | 搜查国内间谍、处决叛徒 | 查看嫌疑人列表→下令调查/逮捕 |


### 三、战术指挥面板（御驾亲征）

当玩家点击“御驾亲征”后，画面从世界地图推入战场。这是一个独立的操作界面。

```
┌─────────────────────────────────────────────────────────┐
│                   战术指挥面板                           │
│                                                         │
│  ┌─────────────────────────────────────────────────┐   │
│  │             战场地图 (3D战术视角)                  │   │
│  │  地形、部队、战争迷雾、要塞                        │   │
│  │  你的部队(蓝) vs 敌军(红)                         │   │
│  └─────────────────────────────────────────────────┘   │
│                                                         │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐  │
│  │ 部队编组  │ │ 阵型选择  │ │ 指令面板  │ │ 将领面板  │  │
│  └──────────┘ └──────────┘ └──────────┘ └──────────┘  │
│                                                         │
│  ┌─────────────────────────────────────────────────┐   │
│  │              战争日志 (实时战况推送)              │   │
│  │  "左翼骑兵遭遇敌军枪兵，陷入苦战！"               │   │
│  │  "你的将军洛萨擅自率部冲锋，高喊'为了荣耀！'"   │   │
│  └─────────────────────────────────────────────────┘   │
│                                                         │
│  [退出御驾亲征] ←── 切换回国王视角                     │
└─────────────────────────────────────────────────────────┘
```

**战术面板的四个核心子面板**：

**1. 部队编组**
- 查看当前战场所有己方部队（以卡片形式显示：兵种、兵力、士气、将领名）
- 拖拽编组：将多个部队编为一个临时军团
- 点击部队卡片选中，地图上该部队高亮

**2. 阵型选择**
- 预设阵型：一字长蛇、方阵、锥形阵、鹤翼阵、伏击阵
- 点击阵型→地图上预览→确认后全军调整站位
- 自定义阵型：手动拖动各部队到指定位置，保存为自定义阵型

**3. 指令面板（对选中部队下达命令）**

| 指令 | 操作 | 效果 |
| :--- | :--- | :--- |
| **移动** | 点击目标位置 | 部队移动到指定位置 |
| **冲锋** | 点击敌军目标 | 部队向指定敌军发起冲锋 |
| **齐射** | 点击敌军目标 | 远程部队向指定敌军集中射击 |
| **驻守** | 点击当前位置 | 部队原地坚守，防御加成 |
| **撤退** | 点击安全位置 | 部队有序撤退（士气损失较小） |
| **全军突击** | 一键指令 | 所有部队向最近敌军发起总攻 |
| **全军撤退** | 一键指令 | 所有部队向后方撤退 |

**4. 将领面板**
- 查看己方各将领的状态（当前行为、士气、是否受伤）
- 对AI将领下达高级指令：防守此点、牵制敌军、寻找战机、保护王帐
- **AI将领会基于自己的人格选择是否完美执行，还是不服从甚至擅自行动**


### 四、两种视角的无缝切换

| 切换方向 | 触发方式 | 效果 |
| :--- | :--- | :--- |
| 国王视角 → 战术面板 | 点击“御驾亲征”按钮 | 画面推入战场，显示你所在的部队位置 |
| 战术面板 → 国王视角 | 点击“退出御驾亲征” | 画面拉回世界地图，军队继续按指令行动（由AI将领接管） |
| 战术面板内切换部队 | 点击地图上其他己方部队 | 视角切换到该部队所在位置 |


### 五、操作辅助与自动化

| 辅助机制 | 说明 |
| :--- | :--- |
| **AI将领委任** | 对于不想微操的玩家，可将部队委任给AI将领，自己只下达宏观目标（“防守东境”、“进攻灰谷”） |
| **预设战术** | 玩家可保存常用的阵型和指令序列，一键执行 |
| **司命战术建议** | 在关键时刻，司命以“斥候报告”形式提供战术建议（“陛下，敌军左翼薄弱，可集中骑兵突破”） |
| **暂停与减速** | 单人模式下可使用“凝神”暂停时间；多人模式下可协商开启“战术会议”暂停 |


**一句话总结**：《开本》SLG为玩家提供“国王视角”的四大政务面板（经济、军事、外交、情报）和“御驾亲征”时的战术指挥面板，两种视角无缝切换。玩家既可以委托AI将领处理大部分事务，也可以在关键时刻亲自上阵，体验从宏观决策到微观指挥的完整权力感。
