## 用户

谁来做创作审核

## DeepSeek

在《开本》的IP创作生态中，创作审核绝不能成为堵死创作的官僚关卡。我们采用 **“分层审核 + 自动化辅助 + 市场自净化”** 的三级体系，让不同层级的内容由最合适的角色来审核。

---

## 创作审核体系

### 一、审核分层

| 内容层级 | 审核主体 | 审核标准 | 说明 |
| :--- | :--- | :--- | :--- |
| **平台基础合规** | **官方自动化 + 人工抽检** | 法律法规、色情暴力、侵权盗用 | 所有上传内容必须过这一关，否则无法进入市场 |
| **世界观一致性** | **大玩家（主题世界运营者）** | 是否符合该世界的设定、风格、物理法则 | 创作者若想将资产上架到某主题世界的“官方推荐”或“世界内商店”，需通过大玩家审核 |
| **通用资产市场** | **官方 + 社区评分** | 基础质量、描述真实性、无恶意代码 | 不绑定特定世界的通用资产，由官方基础审核 + 社区评分自净化 |
| **玩家自用内容** | **无需审核** | — | 玩家在自己的P2P服务器、个人空间内使用的内容，完全自由 |


### 二、各审核主体的具体职责

#### 1. 官方平台：底线守护者

| 审核手段 | 说明 |
| :--- | :--- |
| **AI自动扫描** | 上传时自动扫描模型、贴图、文本中的违规内容（色情、暴力、敏感词），以及代码中是否包含恶意逻辑 |
| **内容指纹比对** | 与已有资产库比对，检测是否直接盗用或抄袭他人作品，保护原创者权益 |
| **举报响应** | 玩家可在游戏内便捷举报违规内容，官方客服团队在规定时效内（如24小时）响应 |
| **违规处罚** | 轻度违规下架整改，中度违规封禁创作者权限，重度违规（如恶意代码）永久封禁账号并追责 |

#### 2. 大玩家：世界观的守门人

| 审核场景 | 说明 |
| :--- | :--- |
| **世界内商店上架** | 创作者若想将建筑皮肤、兵种皮肤等资产上架到某主题世界的专属商店，需提交申请。大玩家或其指定的审核团队，依据该世界的设定（如“这是一个低魔中世纪世界，不允许出现科技感外观”）进行审核 |
| **事件包接入** | 创作者提交的支线剧情包、随机事件池，若需接入该主题世界的司命系统，需经大玩家审核，确保事件逻辑与该世界的历史线和核心冲突不矛盾 |
| **精选推荐** | 大玩家可将审核通过且质量上乘的资产，推荐到该主题世界的“精选”栏位，获得额外曝光 |

**大玩家可设置审核团队**：大玩家可以指定信任的玩家或智能体作为审核员，分担审核工作。审核员的行为受司命监控，防止腐败。

#### 3. 社区与市场：自净化机制

| 机制 | 说明 |
| :--- | :--- |
| **评分与评价** | 所有上架资产都有玩家评分和评价系统。低分资产会被市场自然淘汰 |
| **使用量排行** | 热门资产获得更多曝光，冷门低质资产沉入底部 |
| **举报与仲裁** | 玩家举报后，若创作者不服，可申请官方仲裁。仲裁结果在链上存证 |
| **Fork追溯** | 抄袭作品可通过区块链上的Fork家谱追溯到原始出处，保护原创者 |


### 三、审核流程

```
创作者上传资产
    │
    ▼
[官方AI自动扫描] ←── 违规？→ 驳回 + 通知整改/封禁
    │ 通过
    ▼
[创作者选择发布范围]
    ├── 仅自用：直接发布，无需后续审核
    ├── 通用市场：进入官方人工抽检池
    └── 某主题世界：提交给该世界的大玩家审核
            │
            ▼
        [大玩家审核] ←── 不符合世界观？→ 驳回 + 说明理由
            │ 通过
            ▼
        [上架到该世界商店 / 接入司命系统]
            │
            ▼
        [社区评分与评价持续监控]
            │
            ▼
        [被举报？] → [官方复核] → [处理 + 链上存证]
```


### 四、审核的激励与约束

| 角色 | 激励 | 约束 |
| :--- | :--- | :--- |
| **官方** | 维护平台生态健康，保障商业闭环 | 审核效率受社区监督，过度审核会导致创作者流失 |
| **大玩家** | 守护自己主题世界的品质和口碑，优质内容吸引更多玩家 | 过于严苛会导致内容供给不足；审核腐败（收钱放行）会被司命标记、玩家举报、官方追责 |
| **创作者** | 通过审核获得市场准入和收益 | 违规创作会被下架、封禁，损失声誉和收入 |
| **玩家** | 享受高质量、合规的内容 | 虚假评价、恶意举报会被系统标记降低信誉分 |


**一句话总结**：《开本》的创作审核是分层分责的——官方守底线，大玩家把风格，社区做净化。AI自动化处理大部分基础审核，人工仅在关键节点介入。这样既保证了生态的安全和品质，又不会成为创作的瓶颈。
