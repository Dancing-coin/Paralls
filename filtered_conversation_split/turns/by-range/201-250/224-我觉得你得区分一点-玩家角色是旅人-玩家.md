## 旅人 vs 剧中角色：两层身份的精确定义

### 一、概念区分

| | **旅人（玩家本身）** | **剧中角色（旅人的投影）** |
| :--- | :--- | :--- |
| **本质** | 玩家本人，来自“开本宇宙”之外的高维存在 | 旅人在当前平行世界中的**意识投影**，是旅人意志的载体 |
| **身份** | “观书人”——穿梭于无数平行世界的永恒观察者与参与者 | 剧本中具体的角色——许仙、福尔摩斯、法海、一个自定义的庄园主 |
| **存在范围** | 超越所有平行世界，存在于“开本宇宙”的Meta层 | 仅存在于当前剧本/世界的时空内 |
| **记忆** | 拥有所有世界、所有剧本的完整记忆 | 仅拥有该角色在当前世界内应该拥有的记忆（按时间线约束） |
| **能力** | 穿梭世界、带走智能体、凝神（暂停时间） | 该角色在当前世界设定下的能力（暗杀、开锁、医术等） |
| **社交身份** | 开本通行证 (Paralls ID)、好友列表、全球资产 | 当前剧本中的角色名、身份、与其他角色的关系 |

### 三、各功能的归属

| 功能 | 属于旅人 | 属于剧中角色 |
| :--- | :--- | :--- |
| **移动、对话、交互** | ❌ | ✅ 剧中角色的身体执行 |
| **微表情、小动作** | ❌ | ✅ 剧中角色的智能体底层自动驱动 |
| **内心独白** | ❌ | ✅ 剧中角色的L2理解层生成 |
| **冲动** | ❌ | ✅ 司命→剧中角色的L1感知层 |
| **决策建议** | ❌ | ✅ 剧中角色的L3规划层生成 |
| **凝神（时间暂停）** | ✅ 旅人的超能力 | ❌ |
| **穿梭世界** | ✅ 旅人的超能力 | ❌ |
| **带走智能体** | ✅ 旅人决定 | ❌ 剧中角色执行“邀请同行” |
| **坦白身份** | ✅ 旅人向智能体坦白 | ❌ |
| **购买皮肤/资产** | ✅ 旅人的全球资产 | ❌ |
| **挂机自主模式** | ✅ 旅人暂时离开 | ✅ 剧中角色接管自主行为 |

### 四、叙事层面的意义

**1. 旅人向智能体坦白时**

> “我其实不属于这个世界。我是来自世界之外的旅人，能穿梭于无数平行时空。但我需要在这个世界里，借用这个身体、这个身份来行动。你看到的‘我’，是我投射在这个角色身上的意志。”

这不是玩家在扮演两个角色，而是**同一个旅人，通过剧中角色这个“化身”来表达自己**。

**2. 凝神时**

旅人发动了超越世界规则的能力——时间暂停。剧中角色（许仙）不会觉得自己“暂停了时间”，而是旅人以高维视角凝视这个世界。剧中角色的内心独白可能不会感知到时间暂停，但旅人可以自由观察、拍照、笔记。

**3. 挂机时**

旅人的意志暂时离开，但剧中角色这个“容器”并未死去。底层智能体接管，角色继续以符合人设的方式自主行动——保守、谨慎、不做出重大决定。

**4. 带走智能体时**

旅人决定带走这个AI同伴。剧中角色（如许仙）向智能体（如小青）发出“邀请同行”。当小青问“你要带我去哪里”，旅人通过许仙之口坦白：“我要带你去世界之外——去我的个人空间，去下一个平行世界。”

### 五、对玩家体验的影响

| 传统RPG | 《开本》 |
| :--- | :--- |
| 玩家=角色，二者完全等同 | 玩家=旅人，角色=旅人的投影 |
| 玩家只能通过角色的眼睛看世界 | 旅人拥有超越角色的能力和视角（凝神、穿梭、带走） |
| 角色的能力就是玩家的能力 | 旅人的能力（穿梭、凝神）和角色的能力（暗杀、开锁）是分开的 |
| 挂机=角色僵硬 | 挂机=旅人暂时离开，角色仍在自主活着 |
| AI同伴记住的是“玩家” | AI同伴记住的是“剧中角色”这个具体的人——他的选择、他的性格、他对同伴的态度 |

---

**一句话总结：旅人是玩家自己，是穿梭于无数平行世界的永恒观察者；剧中角色是旅人在当前世界中的意识投影，是旅人意志的载体。旅人拥有超越世界规则的能力（穿梭、凝神、带走），剧中角色拥有该世界设定的能力和人格。两者通过统一的智能体底层连接——旅人投射意志控制角色的决策，但角色的身体、微表情、内心声音由底层智能体自动补全。**
