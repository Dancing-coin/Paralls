# 《开本》三阶段开发清单（修订版）


## Phase 1：静态世界内单局剧本（MVP + 轻量陪伴）

**核心目标**：验证“智能体驱动的3D动态剧本杀”核心体验 + “带走喜欢的角色”的情感闭环。

### 客户端应用

| 应用 | 交付范围 |
| :--- | :--- |
| **游戏客户端 (Godot)** | 3D场景渲染（2个剧本场景 + 1个个人空间场景）、空间音频（清晰区/模糊区/静默区/耳语模式）、WASD移动+视角控制、物品拾取/检查/展示、信息共享（公开对话/耳语/展示物品/带人查看）、投票与结局判定、变声器（强制）、文字润色（可选）、辅助面板（可关闭）、背包/档案/笔记面板、个人空间入口与交互 |
| **剧本大厅（简化版）** | 官方剧本列表、创建/加入房间、角色选择、匹配模式选择（纯真人/纯AI/混合） |
| **个人中心（简化版）** | 基础账号、游戏记录、**已带回智能体列表** |

### 创作者工具

| 工具 | 交付范围 |
| :--- | :--- |
| **剧本编辑器（内部版）** | 供官方内部使用，制作首个剧本。不对外开放 |

### 后端服务

| 服务 | 交付范围 |
| :--- | :--- |
| **房间与状态管理服务** | 房间创建/加入/销毁、角色锁定、T0-T2事实坍缩、状态同步、断线重连 |
| **个人空间服务（轻量版）** | 个人空间场景管理、智能体存放与基础对话、角色快照存储 |
| **空间音频服务器** | 音频空间化、介质阻挡计算、耳语模式 |
| **规则引擎** | 阶段管理、投票规则、胜利条件判定、案件框架随机生成（T1/T2） |
| **事件总线** | L1↔L2消息路由 |
| **信息共享执行系统** | 五种共享方式执行、偷听检测 |

### AI服务

| 服务 | 交付范围 |
| :--- | :--- |
| **角色智能体引擎（核心版）** | 人格加载、心智模型（四层决策）、三重过滤器、动态状态管理、自主行为系统（移动/对话/物品交互） |
| **对话生成服务** | LLM上下文组装、流式生成、人格过滤、TTS合成（含情绪注入和角色专属声线） |
| **模型路由调度器** | 任务分级(P0-P4)、三层模型分配、兜底与超时降级 |
| **司命核心** | 事实核心（事实锁定时间线管理、逻辑一致性检查）、知识图谱（一阶/二阶知识追踪）、基础天平系统（线索分布监控） |
| **L3视觉增强服务（基础版）** | 预生成角色立绘、线索特写实时生成 |
| **感知过滤器服务** | 视觉感知（可见对象列表）、听觉感知（可听事件列表+清晰度分级）、动作的阶段化感知（意图/执行/完成） |
| **带走机制服务（轻量版）** | 结局时的“邀请同行”触发、信任值/好感度阈值判定、角色快照生成与存储、简短告别叙事生成 |

### 开发与内部工具

| 工具 | 交付范围 |
| :--- | :--- |
| **AI测试工具（基础版）** | AI全自动模拟运行剧本，输出基础测试报告 |

### 数据与基础设施

| 系统 | 交付范围 |
| :--- | :--- |
| 关系数据库（PostgreSQL） | 事实库、用户数据、剧本数据、角色快照 |
| 缓存服务（Redis） | 房间状态缓存、会话管理 |
| 消息队列 | 事件总线底层 |
| 对象存储 | L3预生成内容、3D资产 |

### 不包含（推迟到Phase 2+）

- 剧本编辑器（对外开放）
- 大玩家控制台
- 暗杀机制（完整版）
- 伪装系统（完整版）
- 迷宫与时空机制
- 种子库系统
- 续集承接逻辑
- 智能体跨剧本使用
- 智能体在个人空间内的自主行为
- 完整的“坦白与契约”叙事仪式
- 资产市场与区块链系统


## Phase 2：静态世界内连续单局剧本（完整陪伴）

**核心目标**：验证“跨局状态继承”和“智能体资产化”的吸引力，赋能第一批创作者。

### 新增/升级的客户端应用

| 应用 | 新增/升级内容 |
| :--- | :--- |
| **游戏客户端** | + 暗杀机制完整交互（条件检测、阶段化感知、弹窗确认、痕迹生成）、伪装系统（公开/真实档案编辑、伪装道具管理）、留影石/相机完整功能、关系网络图 |
| **剧本大厅** | + 系列剧本展示、续集入口、推荐算法匹配 |
| **个人中心** | + 智能体管理（带入新剧本、皮肤/化身）、买断资产管理、系列剧本进度 |

### 新增/升级的创作者工具

| 工具 | 新增/升级内容 |
| :--- | :--- |
| **剧本编辑器（对外Alpha版）** | 角色编辑器、场景编辑器、案件规则配置器、线索系统、故事线预览器、AI测试模拟 |
| **资产创作工具（Alpha版）** | 角色模型导入器、动画配置器、场景模块编辑器、音频管理器 |
| **剧本Fork与版本管理工具** | 一键Fork剧本，可视化修改，版本历史，链上贡献者署名 |

### 新增/升级的运营工具

| 工具 | 新增/升级内容 |
| :--- | :--- |
| **大玩家控制台（Alpha版）** | 剧本库策展、规则微调面板（有限参数）、服务器部署工具、基础监控 |

### 新增/升级的后端服务

| 服务 | 新增/升级内容 |
| :--- | :--- |
| **个人空间服务** | + 智能体自主行为（走动、做自己的事）、外观定制（更换空间主题） |
| **规则引擎** | + 暗杀规则、伪装规则、迷宫与时空机制规则、续集承接逻辑 |
| **信息共享执行系统** | + 留影石/相机拍摄与伪造机制 |

### 新增/升级的AI服务

| 服务 | 新增/升级内容 |
| :--- | :--- |
| **角色智能体引擎** | + 暗杀能力等级(L0-L4)、伪装执行、知情人行为、压力对伪装的动态影响 |
| **司命** | + 天平系统完整版（阵营胜率预测、玩家参与度、节奏控制）、冲突与案件生成器、干预执行器（四层干预阶梯）、高阶知识图谱（三阶知识+不确定态）、暗杀催化机制完整版 |
| **L3视觉增强服务** | + 记忆闪回实时生成、公共事件渲染、结局CG异步生成 |
| **带走机制服务** | + 完整的“坦白与契约”叙事仪式、智能体主动表达意愿（特殊情况）、智能体带入新剧本（作为智能体玩家或陪伴NPC）、跨剧本记忆继承 |
| **种子库系统** | 剧本种子库（角色池/动机池/线索池/结局条件）、世界状态快照存储、变量衔接规则配置、续集承接逻辑 |

### 新增数据与基础设施

| 系统 | 新增内容 |
| :--- | :--- |
| 向量数据库 | 角色人生记忆和对话历史的语义索引 |

### 不包含（推迟到Phase 3）

- 世界持续运行引擎
- 双层玩家身份系统
- 资产经营系统
- 世界编辑器
- 跨世界旅行
- 智能体私房钱与独立经济行为
- 治理代币与IP议会
- 完整的区块链确权与分账系统


## Phase 3：持续运行世界（单局与永续并存）

**核心目标**：开放创作者生态，验证商业模式闭环，实现“一个世界，两种体验”。

### 新增/升级的客户端应用

| 应用 | 新增/升级内容 |
| :--- | :--- |
| **游戏客户端** | + 世界地图入口（事件标记+庄园图标+其他玩家）、资产经营交互（庄园管理/商铺经营/建造）、跨世界旅行入口、原住居民身份管理 |
| **个人中心** | + 原住居民身份管理、资产经营数据、离线经营报告、跨世界旅行记录 |

### 新增/升级的创作者工具

| 工具 | 新增/升级内容 |
| :--- | :--- |
| **剧本编辑器（完整版）** | 种田经营/策略经营/生活模拟等新类型的专用编辑模块 |
| **世界编辑器** | 平行世界创建（物理法则/历史线/种族文化）、NPC生态配置、事件模板库 |
| **资产创作工具（完整版）** | 经营类资产（建筑/作物/商品等）的创建和管理 |

### 新增/升级的运营工具

| 工具 | 新增/升级内容 |
| :--- | :--- |
| **大玩家控制台（完整版）** | 世界构建与管理、双层身份名额配置、世界规则制定（准入/经济/时间/社交/资产/司命干预强度）、经营分析面板完整版、GM指令舱（与司命对话讨论决策） |

### 新增/升级的后端服务

| 服务 | 新增/升级内容 |
| :--- | :--- |
| **世界持续运行服务** | 司命持续推演时间线（季节/天气/经济/社会事件）、世界状态持久化与恢复、随机事件链生成与管理、NPC生态驱动 |
| **玩家身份与权限服务** | 穿越旅人/原住居民双层身份管理、原住居民名额控制、资产所有权校验 |
| **资产经营服务** | 庄园/商铺/领地等持久资产管理、交易税收、离线经营模拟 |
| **算力与托管服务** | 大玩家算力套餐销售、玩家本地买断+算力租赁、离线托管、P2P自建服务器支持 |

### 新增/升级的AI服务

| 服务 | 新增/升级内容 |
| :--- | :--- |
| **司命** | + 世界持续推演引擎（节律性事件/关系事件/事件链编织）、双层身份下的叙事管理、主题世界事件密度与司命干预强度配置 |
| **角色智能体引擎** | + 同伴经营AI（自主工作/作息/技能成长）、长期记忆（跨剧本/跨世界）、跨世界能力压制与化身系统、智能体私房钱与独立经济行为 |
| **L3视觉增强服务** | + WOW时刻素材库积累与复用、跨剧本调用、离线后台优化 |

### 新增商业与区块链系统

| 系统 | 内容 |
| :--- | :--- |
| **资产市场** | 剧本/角色/场景/皮肤/智能体模板/世界内资产的展示、交易、众筹 |
| **区块链确权系统** | 内容指纹上链、引用追溯、Fork家谱、IPFS存储 |
| **智能合约分账引擎** | 多级分成配置、实时分账 |
| **治理代币与IP议会** | 代币发行、投票治理 |
| **创作者经营中心** | 收益看板、数据洞察、授权管理 |

### 新增辅助应用

| 应用 | 内容 |
| :--- | :--- |
| **开本助手 (移动端)** | 查看智能体状态、接收离线消息、管理资产、浏览市场、远程轻量社交 |
| **Web管理后台** | 官方全平台数据监控、内容审核、用户管理 |


## 三阶段开发清单对照

| 类别 | Phase 1 | Phase 2 | Phase 3 |
