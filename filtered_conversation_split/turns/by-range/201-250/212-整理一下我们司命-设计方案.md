# 司命 (Siming) 设计文档

## 一、核心定位

司命是 **《开本》运行时核心智能体**，是“开本宇宙”得以动态运转的心脏。

| 维度 | 说明 |
| :--- | :--- |
| **系统身份** | 运行时唯一拥有全局视野的智能体，独立于角色智能体运行 |
| **权限等级** | 高于角色智能体（可向角色发送消息），但**不直接控制玩家** |
| **核心使命** | 维护事实逻辑、催化叙事涌现、守护游戏平衡 |
| **行动原则** | 间接、不可见、逻辑自洽、公平 |
| **世界观称谓** | 司命——掌管每个平行世界的命运、因果与戏剧性的意识 |
| **本质定义** | 集编剧与导演于一身的世界主宰，实时创作并改写剧本 |
| **技术实现** | Harness编排框架 + 大模型(LLM) + 规则程序(Rule Engine) |


## 二、技术架构

### 2.1 三层结构

```
┌─────────────────────────────────────────┐
│          Harness (编排框架)              │
│  ┌─────────────────────────────────┐   │
│  │       大模型 (LLM)              │   │
│  │  - 复杂叙事推理                  │   │
│  │  - 动机分析与催化决策            │   │
│  │  - 干预策略生成                  │   │
│  └─────────────┬───────────────────┘   │
│                │                        │
│  ┌─────────────┴───────────────────┐   │
│  │     规则程序 (Rule Engine)      │   │
│  │  - 事实逻辑硬性检查              │   │
│  │  - 时间线管理                    │   │
│  │  - 天平系统数值计算              │   │
│  │  - 干预原则过滤                  │   │
│  └─────────────────────────────────┘   │
└─────────────────────────────────────────┘
```

- **Harness**：负责请求路由、任务分级、兜底机制、延迟控制
- **大模型**：处理模糊复杂的叙事推理和创意决策
- **规则程序**：处理所有硬逻辑、数值计算和安全校验，保证可解释性和确定性

### 2.2 协作流程

1. 事件总线推送事件至Harness
2. Harness判断任务级别（P0-P4）：
   - P0致命 → 规则程序直接处理（<300ms）
   - P1-P3 → 大模型推理 + 规则程序校验
3. 决策生成后，规则程序进行逻辑和公平性校验
4. 通过校验后，由Harness发送至相应角色智能体或环境


## 三、内部架构（五个子系统）

```
┌─────────────────────────────────────────────┐
│                 司命 (Siming)                 │
│                                              │
│  ┌──────────┐ ┌──────────┐ ┌──────────────┐ │
│  │ 事实核心 │ │ 天平系统 │ │ 冲突与案件   │ │
│  │          │ │          │ │ 生成器       │ │
│  └────┬─────┘ └────┬─────┘ └──────┬───────┘ │
│       │             │              │         │
│  ┌────┴─────────────┴──────────────┴───────┐ │
│  │           高阶知识图谱引擎              │ │
│  └────────────────┬───────────────────────┘ │
│                   │                          │
│  ┌────────────────┴───────────────────────┐ │
│  │           干预执行器                    │ │
│  │  (冲动发送 / 环境催化 / NPC引导 / 节奏) │ │
│  └────────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

### 3.1 事实核心 (Fact Core)

- **职责**：存储并守护游戏中所有不可变事实与已锁定事实
- **功能**：
  - 事实锁定时间线管理（T0→T1→T2→T3）
  - 逻辑一致性检查：任何角色言论、行为与事实库冲突时，标记并阻止
  - 矛盾记录：两个角色说法矛盾时，标记为“待解决矛盾”，成为推理线索
  - 信息泄露防护：确保角色智能体不能说出其未知的信息
- **写权限**：仅司命拥有对事实库的写权限

### 3.2 天平系统 (Balance System)

- **职责**：实时监测游戏态势，防止出现碾压性优势或僵局
- **监测指标**：
  - 线索分布均衡度：关键线索是否过度集中于某一方
  - 阵营胜率预测：基于当前已揭露事实模拟投票结果
  - 玩家参与度：是否有玩家被边缘化
  - 游戏节奏：推理进度过快或过慢
- **输出**：失衡警报 + 干预建议，发送给干预执行器

### 3.3 冲突与案件生成器 (Conflict & Case Generator)

- **职责**：检测角色间动态冲突，条件满足时生成新案件
- **触发条件检测**：
  - 目标冲突：两个角色的目标层级产生不可调和矛盾
  - 机会窗口：某个角色获得作案机会（独处、凶器在旁）
  - 秘密濒临暴露：角色的核心秘密即将被揭穿
- **生成流程**：
  1. 动机评估（调用角色的目标/恐惧层级）
  2. 能力评估（物理空间中的可行性）
  3. 人格过滤（该角色真的会这么做吗？）
  4. 叙事价值评估（是否让故事更有趣而非更混乱）
  5. 通过后锁定为新事实

### 3.4 高阶知识图谱引擎 (Higher-Order Knowledge Engine)

- **职责**：维护所有参与者“知道什么”以及“知道别人知道什么”的动态模型
- **数据结构**：
  - 节点：游戏中的事实
  - 边：角色对事实的知识状态（未知/疑似/确认/公开）
  - 高阶边：A知道B知道X / A不确定B是否知道X
- **知识传播规则**：
  - 公开对话/展示 → 清晰区内所有角色标记为“公开”
  - 私密对话/耳语 → 仅对话对象标记为“确认”
  - 带人查看 → 跟随者标记为“确认”
  - 偷听 → 偷听者标记为“疑似”
- **推理接口**：角色智能体决策时，可调用图谱获取其视角下的高阶知识

### 3.5 干预执行器 (Intervention Executor)

- **职责**：将天平系统的失衡警报转化为具体干预行动
- **四层干预阶梯**（由弱到强）：

| 等级 | 手段 | 强度 | 示例 |
| :--- | :--- | :--- | :--- |
| **Lv1** | 智能体冲动 | 最温和 | 向NPC发送“你突然想去地下室看看” |
| **Lv2** | 环境催化 | 中等 | 风吹开窗帘露出线索、天气突变困住众人 |
| **Lv3** | NPC引导 | 较强 | 向NPC发送确凿信息，唤醒其本应知道的记忆 |
| **Lv4** | 节奏控制 | 全局 | 触发新事件延长或缩短游戏阶段 |

- **审核机制**：所有干预方案需通过干预原则过滤器，通过后才能执行


## 四、干预原则过滤器

所有干预行为在发送前，必须通过四重原则检查：

| 原则 | 检查内容 | 不通过示例 |
| :--- | :--- | :--- |
| **间接性** | 是否直接控制玩家？ | 强制玩家移动、禁用玩家选项、替玩家做决定 |
| **不可见性** | 是否会被玩家感知为“系统干预”？ | 弹出系统提示、凭空出现物品 |
| **逻辑自洽** | 是否有合理的故事内解释？ | 让胆小如鼠的NPC去挑战凶手 |
| **公平性** | 是否偏袒某一方？ | 在凶手即将暴露时删除证据 |


## 五、暗杀催化机制

### 5.1 催化原则

只要检测到符合逻辑的动机，且催化不破坏游戏可玩性，司命就主动催化暗杀机会。

### 5.2 动机监测清单

| 动机类型 | 检测信号 | 强度判定 |
| :--- | :--- | :--- |
| **仇恨** | 人生记忆中存在对某角色的仇恨事件 | 仇恨对象在场即触发 |
| **灭口** | 某角色掌握了指向自己的关键证据 | 证据暴露风险越高，动机越强 |
| **自保** | 自己被怀疑值持续上升，即将被指认 | 怀疑值≥7时动机激活 |
| **保护他人** | 忠诚度≥8的对象面临威胁 | 威胁越紧迫，动机越强 |
| **秘密濒临暴露** | 核心秘密被他人掌握且即将公开 | 公开倒计时越短，动机越强 |

### 5.3 可玩性评估（催化前必检）

| 评估维度 | 不通过条件 | 处理 |
| :--- | :--- | :--- |
| **阵营平衡** | 暗杀发生后，某一方胜率预测超过90% | 不催化 |
| **玩家体验** | 目标是唯一掌握关键线索的玩家 | 不催化，或先催化其他事件补充线索 |
| **节奏控制** | 游戏开始不足10分钟，或距投票不足3分钟 | 不催化 |
| **频率控制** | 同一角色已被催化过2次暗杀 | 不催化 |

### 5.4 催化流程

```
[司命持续扫描]
    │
    ├── 检测到符合逻辑的动机 ✅
    ├── 可玩性评估通过 ✅
    │
    ▼
[催化阶段一：条件排列]
    │ 环境催化 → 创造独处空间
    │ NPC引导 → 调离目击者
    │ 信息延迟 → 延长证据空窗期
    │ 空间巧合 → 提供隐蔽路径
    │
    ▼
[催化阶段二：指引推送]
    │ 向潜在暗杀者推送暗杀机会面板
    │ 告知条件状态、风险、窗口时间
    │
    ▼
[催化阶段三：弹窗确认]
    │
    ├── [ 执行暗杀 ] → 暗杀启动 → 阶段化感知 → 后果链
    └── [ 放弃 ] → 同目标同动机不再催化
```

### 5.5 催化后克制机制

| 克制手段 | 说明 |
| :--- | :--- |
| **冷却期** | 一次暗杀催化后（无论执行与否），引擎进入冷却 |
| **防御催化** | 连续催化偏向同一方时，为劣势方催化防御条件 |
| **上限控制** | 单局总暗杀事件（含初始案件）不超过3起 |
| **复盘透明** | 游戏结束后，玩家可看到催化了哪些机会，但不暴露未触发的暗杀 |


## 六、与角色智能体的协作协议

| 消息方向 | 消息类型 | 说明 |
| :--- | :--- | :--- |
| 司命 → 角色 | `impulse` (冲动) | 模糊的行为倾向，角色自主决定是否响应 |
| 司命 → 角色 | `fact_reveal` (事实披露) | 告知角色其本应知道的事实 |
| 司命 → 角色 | `opportunity` (机会提示) | 暗杀等高风险行为的机会窗口信息 |
| 角色 → 司命 | `action_report` (行为报告) | 角色执行任何交互后上报 |
| 角色 → 司命 | `request_intervention` (请求干预) | 角色陷入困境时可请求建议（仅限AI角色） |

**核心原则：司命只催化，不控制。角色的所有行为最终由其自身的心智模型决定。**


## 七、自监控与动态调节

| 监控指标 | 阈值 | 过载处理 |
| :--- | :--- | :--- |
| **干预频率** | 每10分钟不超过3次Lv2+干预 | 暂停主动干预，进入观察模式 |
| **玩家困惑度** | 玩家重复搜索同一区域、大量疑问词出现 | 增加Lv1冲动引导 |
| **AI负载** | 引擎CPU/API调用延迟超标 | 降低干预精度 |
| **暗杀频率** | 单局催化超过2次 | 暂停暗杀机会排列，进入冷却 |


## 八、运行时位置

司命不直接与客户端交互，所有消息经由事件总线。与角色智能体处于同一层级，但拥有对事实库和知识图谱的独占写权限。

```
┌─────────────────────────────────────┐
│            游戏客户端 (Godot)        │
└──────────────┬──────────────────────┘
               │ 事件流
┌──────────────▼──────────────────────┐
│           事件总线                   │
└──┬──────┬──────┬──────┬─────────────┘
   │      │      │      │
   ▼      ▼      ▼      ▼
┌────┐ ┌────┐ ┌────┐ ┌─────────────┐
│玩家│ │AI  │ │AI  │ │ 司命        │
│    │ │角色│ │角色│ │ (核心智能体)│
└────┘ └────┘ └────┘ └─────────────┘
```


## 九、创作者可配置参数

| 参数 | 说明 | 可选值 |
| :--- | :--- | :--- |
| **干预强度** | 控制司命主动催化的程度 | 轻度（仅逻辑检查）/ 中度（平衡调控）/ 重度（主动催化冲突） |
| **暗杀催化开关** | 是否允许司命催化暗杀机会 | 开启 / 关闭 |
| **节奏偏好** | 倾向快节奏还是慢节奏 | 偏快 / 平衡 / 偏慢 |
| **结局偏好** | 是否倾向某种结局类型 | 无偏好 / 倾向悲剧 / 倾向正义 |
| **动态知情人敏感度** | NPC目击可疑行为的基准概率 | 低 / 中 / 高 |
