## 驱动架构：一个模型，两种驾驶模式

### 一、统一底层：所有角色都是智能体

在《开本》中，角色不是一个“空壳”等着被填入AI或玩家指令，而是一个**完整的智能体**，拥有完整的心智模型：

- **人格档案**：五维人格参数、品格层、人生记忆、目标层级、恐惧层级
- **感知系统**：视觉、听觉、触觉、热感，按感知档案过滤
- **理解层**：对感知信息的解读、信念更新、推论生成
- **记忆系统**：实时记录所有经历和已知信息

**无论是AI角色还是玩家角色，这套底层是完全相同的。**

### 二、唯一的区别：L3规划层的“方向盘”属于谁

| 心智层级 | AI智能体 | 玩家角色 |
| :--- | :--- | :--- |
| **L1 感知层** | 系统自动运行，接收结构化感知事件 | **同左**，系统自动运行 |
| **L2 理解层** | 系统自动运行，更新信念、生成推论 | **同左**，系统自动运行 |
| **L3 规划层** | AI自主决策，生成行动方案 | **方向盘交给玩家**。系统不再生成决策，而是生成“建议”（内心独白、冲动、决策建议），供玩家参考 |
| **L4 执行层** | AI自动生成对话、动作、表情 | **玩家主动操作**（移动、对话、交互）。微表情、小动作、社交距离等**自动行为仍由系统驱动** |
| **深度沉浸机制** | 微表情、小动作、内心戏全部自动运行 | 微表情、小动作、社交距离、语音微表现**自动运行**，内心戏以“提示”形式呈现给玩家 |

### 三、谁在驱动深度沉浸机制？

深度沉浸机制（微表情、小动作、社交距离、内心独白、冲动、语音微表现）的驱动源是：

**司命不直接驱动这些。** 司命只负责全局叙事管理和催化（向角色发送“冲动”是司命的能力之一，但微表情和小动作不是司命驱动的）。

**驱动深度沉浸机制的是角色自身的“底层智能体心智模型”**——更具体地说，是心智模型中的**L2理解层**和**L4执行层**的自动部分。

具体分工如下：

| 沉浸机制 | 驱动源 | 说明 |
| :--- | :--- | :--- |
| **性格化小动作** | **角色智能体的L4执行层（自动部分）** | 根据人格档案中的五维参数，自动从动画库中选择匹配的待机动作和习惯动作 |
| **情境化微表情** | **角色智能体的L2理解层→L4执行层** | L2理解层更新当前情绪标签和压力值→L4执行层自动映射为形态键混合 |
| **社交距离与空间行为** | **角色智能体的L2理解层→L4执行层** | L2理解层读取当前对话对象的信任值/怀疑值→L4执行层自动调整站位和朝向 |
| **语音微表现** | **角色智能体的L2理解层→TTS引擎** | L2理解层的情绪标签和压力值→TTS引擎自动调节语速、音调、停顿 |
| **内心独白** | **角色智能体的L2理解层→呈现给玩家** | L2理解层生成推论和信念更新后，以第一人称半透明文字呈现给玩家 |
| **冲动** | **司命→角色智能体→呈现给玩家** | 司命发送impulse消息→角色智能体接收后，以第一人称半透明文字呈现给玩家（玩家可选择遵从或忽略） |
| **决策建议** | **角色智能体的L3规划层→呈现给玩家** | 系统模拟“如果由AI自主决策会怎么选”，将候选行动方案呈现给玩家参考（可关闭） |

### 四、司命的角色：只负责冲动和全局叙事

司命在玩家沉浸机制中的唯一直接贡献，是向玩家注入**“冲动”**——一种模糊的行为倾向或灵光一现的念头。这是司命作为“世界导演”催化叙事的手段之一。

但冲动**不是强制指令**。玩家完全自主决定是否遵从。冲动只是增强沉浸感的叙事辅助，让玩家感受到“我的角色似乎有了某种直觉”。

### 六、一句话总结

**玩家角色和AI角色的底层是同一个智能体模型。深度沉浸机制由角色自身的L2理解层和L4执行层（自动部分）驱动，司命只负责向玩家发送“冲动”作为叙事催化。玩家投射意志，将L3规划层的方向盘握在手中，但角色的身体、微表情、内心声音——所有这些让角色“活起来”的细节——都由底层智能体为你自动补全。**
