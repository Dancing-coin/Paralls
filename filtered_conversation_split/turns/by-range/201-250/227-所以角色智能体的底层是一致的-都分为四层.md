## 用户

所以角色智能体的底层是一致的，都分为四层

## DeepSeek

在《开本》中，**每一个角色——无论由人类玩家还是AI驱动——都共享同一套四层心智模型底层（L1-L4）**。唯一的区别在于，人类玩家的大脑已经在独立执行感知、理解和决策，所以系统只需要补全玩家无法直接控制的潜意识与生理层面。

### 🤖 统一底层：所有角色都是智能体

无论是AI扮演的NPC，还是人类玩家投射意志的角色，在系统内部都是一个**完整的智能体实例**，拥有：

-   **L1 感知层**：接收结构化感知事件（视觉、听觉、触觉等）。
-   **L2 理解层**：解读信息、更新信念、生成推论、更新情绪状态。
-   **L3 规划层**：基于目标、恐惧、人格生成行动方案。
-   **L4 执行层**：生成具体的对话、动作、表情。

### 🎮 人类玩家的特殊性：大脑接管高层

当这个角色由人类玩家控制时，情况变为：

| 心智层级 | 人类玩家角色 |
| :--- | :--- |
| **L1 感知层** | **双重感知**：系统仍在底层运行结构化感知，但玩家主要通过3D渲染画面和空间音频直接感知世界。 |
| **L2 理解层** | **双重理解**：系统仍在底层生成内心独白和推论，但玩家的大脑也在独立推理、分析、产生情绪。 |
| **L3 规划层** | **玩家大脑决策**。系统仅提供“决策建议”和“冲动”作为参考，方向盘在玩家手中。 |
| **L4 执行层** | **主动行为由玩家操作**（移动、对话、交互）；微表情、小动作、社交距离等**自动行为仍由系统驱动**。 |

### ✨ 系统自动补全层：玩家无法直接控制的“生理本能”

有些事情玩家的大脑无法直接控制自己的虚拟角色，例如：

-   让角色脸红、出汗、瞳孔放大。
-   让声音自动带上颤抖或愤怒。
-   挂机时让角色不变成木头人。
-   获得角色“应该有的”内心声音。

因此，系统自动补全层负责驱动这些**深度沉浸机制**，包括：

-   **微表情与小动作**：由角色的L2理解层输出的情绪/压力值，驱动L4执行层自动映射。
-   **社交距离与空间行为**：根据信任值/怀疑值自动调整站位。
-   **内心独白与冲动**：L2理解层生成的推论以第一人称提示呈现；司命注入的“冲动”也以此形式呈现。
-   **挂机自主模式**：玩家暂时离开时，L3规划层交还给AI自主决策，角色保持鲜活但行为保守。
-   **决策建议**：系统模拟“如果由AI自主决策会怎么选”，供玩家参考（可关闭）。

### 💎 对整体体验的益处

这个统一底层带来了诸多好处：

-   **沉浸感**：角色不僵硬，有符合人设的潜意识反应。
-   **新手友好**：不擅长表演或推理的玩家，也能获得系统辅助。
-   **OOC自然约束**：角色身体会“出卖”违背人设的意图，比规则惩罚更优雅。
-   **叙事连续性**：挂机不掉线，角色仍在故事中自主活着。
-   **高效开发**：AI和玩家角色共用代码、资产和测试管线。

### 🔗 与司命的关系

**深度沉浸机制由角色自身的L2和L4层驱动，而不是司命。** 司命仅在向角色发送“冲动”时参与其中，且冲动对玩家完全是建议性的，玩家可自主决定是否遵从。

**一句话总结：所有角色共享同一套四层智能体底层。人类玩家角色是“玩家大脑（接管感知、理解、决策） + 系统自动补全层（驱动微表情、小动作、内心戏、挂机自主）”的混合体。这个设计让《开本》中的每个角色都真正“活着”，同时赋予玩家完全的自主权。**
