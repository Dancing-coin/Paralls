## DeepSeek

以下是《开本》项目需要实现的**全部应用与程序清单**，按类别和层级整理。

---

## 一、客户端应用

| 应用名称 | 定位 | 说明 |
| :--- | :--- | :--- |
| **游戏客户端 (Godot)** | 玩家体验终端 | 3D场景渲染、空间音频语音、玩家移动与控制、物品交互、信息共享、L3视觉增强呈现、投票与结算、变声器、文字润色、凝神能力 |
| **剧本大厅** | 剧本发现与匹配 | 浏览官方/大玩家/个人剧本，推荐算法匹配，组队邀请，匹配模式选择 |
| **个人中心** | 玩家资产管理 | 我的剧本、我的智能体、皮肤/道具、云存档管理、好友列表、成就与战绩 |


## 二、创作者工具

| 应用名称 | 定位 | 说明 |
| :--- | :--- | :--- |
| **剧本编辑器** | 可视化剧本创作 | 角色编辑器（人格/背景/能力）、场景编辑器、案件规则配置器、线索系统、故事线预览器、AI测试模拟 |
| **资产创作工具** | 美术/音频资产生产 | 角色模型导入器、动画配置器、场景模块编辑器、音频管理器 |
| **剧本Fork与版本管理** | 协作创作 | 基于已有剧本创建平行版本，版本历史管理，合并冲突解决，链上贡献者署名 |


## 三、运营工具

| 应用名称 | 定位 | 说明 |
| :--- | :--- | :--- |
| **大玩家控制台** | 服务器经营者后台 | 剧本库策展、规则微调面板、一键部署工具、服务器状态监控、GM工具箱、经营分析面板 |
| **GM指令舱** | GM与司命协作 | 向司命建议剧情走向、调整NPC行为权重、触发事件、处理严重OOC |
| **经营分析面板** | 数据分析 | 服务器收入统计、剧本流行度排行、玩家留存率、付费转化率、AI成本监控 |


## 四、后端服务

| 服务名称 | 定位 | 说明 |
| :--- | :--- | :--- |
| **房间与状态管理服务** | 游戏运行基础 | 房间创建/加入/销毁、角色锁定与T0-T2事实坍缩、多端状态同步、断线重连 |
| **空间音频服务器** | 沉浸式语音 | 音频空间化、介质阻挡计算、耳语模式、环境噪音管理、偷听检测 |
| **规则引擎** | 游戏流程控制 | 阶段管理、投票规则、胜利条件判定、剧本参数解析、案件框架随机生成 |
| **事件总线** | 系统间消息中枢 | L1↔L2↔L3消息路由、事件持久化、重放机制 |
| **信息共享执行系统** | 信息规则落地 | 五种共享方式执行、偷听检测、留影石/相机完整功能、三种知识形态管理 |
| **感知过滤器服务** | 角色感知计算 | 为每个角色计算“此刻应该感知到什么”，输出结构化语义事件 |


## 五、AI服务

| 服务名称 | 定位 | 说明 |
| :--- | :--- | :--- |
| **角色智能体引擎** | 驱动单个AI角色 | 人格数据库加载、心智模型（四层决策）、三重过滤器、动态状态管理、自主行为系统 |
| **对话生成服务** | 智能体对话 | LLM上下文组装、流式生成、人格过滤、TTS语音合成（含情绪注入和角色专属声线） |
| **模型路由调度器** | 延迟保障 | 任务分级（P0-P4）、三层模型分配（L1规则引擎/L2小模型/L3大模型）、兜底与超时降级、人格延迟调节 |
| **司命 (叙事引擎)** | 运行时核心智能体 | 事实核心、天平系统、冲突与案件生成器、高阶知识图谱引擎、干预执行器、暗杀催化、结局判定 |
| **L3视觉增强服务** | 关键时刻视觉强化 | 图片/视频生成、预生成与缓存、素材库管理、与故事线种子的绑定和复用 |
| **玩家智能体服务** | AI玩家 | 与人类玩家权限完全一致的智能体玩家，可匹配、可被邀请、可携带 |


## 六、商业与区块链系统

| :--- | :--- | :--- |

| **区块链确权系统** | 版权保护 | 内容指纹上链、引用关系追溯、Fork家谱记录、创作者署名、链上IPFS存储 |
