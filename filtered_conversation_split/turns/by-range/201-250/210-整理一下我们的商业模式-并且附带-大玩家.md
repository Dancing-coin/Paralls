# 《开本 / Paralls》商业模式

## 一、平台商业模式

### 1.1 核心价值主张

《开本》是一个**智能体驱动的3D沉浸式动态叙事平台**。我们为创作者提供AI驱动的创作工具和分发网络，为大玩家提供世界经营的技术底座和流量支持，为玩家提供无限平行世界中的动态故事和AI陪伴体验。

### 1.2 平台收入来源

| 收入来源 | 说明 | 计费模式 |
| :--- | :--- | :--- |
| **交易抽成** | 从资产市场所有交易中抽取服务费 | 剧本/角色/皮肤/智能体模板等交易额的20%-30% |
| **大玩家算力套餐** | 向大玩家销售AI算力套餐 | 月度订阅或按量付费，分为基础版、高级版、无限版 |
| **官方服务器收入** | 官方运营旗舰影院和核心IP主题世界 | 门票、会员订阅、道具销售，100%归官方 |
| **会员订阅** | 面向玩家的高级功能订阅 | 月费制，包含专属剧本、优先匹配、更多L3生成配额等 |
| **云服务与扩容** | 向玩家和大玩家提供云存储和算力扩容 | 按需付费 |

### 1.3 平台核心资产

| 资产 | 说明 |
| :--- | :--- |
| **司命叙事引擎** | 全球最先进的实时动态叙事AI，是平台的技术护城河 |
| **角色智能体引擎** | 人格驱动的AI角色系统，支撑AI陪伴经济的核心技术 |
| **创作者生态** | 无限供给的剧本、角色、世界内容 |
| **大玩家网络** | KOL和社群运营者构成的分布式流量和服务节点 |
| **玩家社群** | 通过跨服社交和资产绑定形成的高粘性用户基础 |


## 二、大玩家参与模式

### 2.1 大玩家定位

大玩家是《开本》生态中的 **“剧院经营者”或“世界创造者”** ，通过运营服务器提供沉浸式娱乐服务来获得商业回报。

### 2.2 两种经营模式

| 模式 | 影院模式 | 主题世界模式 |
| :--- | :--- | :--- |
| **定位** | 灵活策展，多题材轮换 | 深度绑定单一世界观，品牌沉淀 |
| **适合人群** | 流量型KOL、初创团队 | 品牌型KOL、成熟团队 |
| **投入** | 低（策展+服务） | 高（定制场景、独占内容） |
| **收入潜力** | 稳定，天花板明显 | 高，可形成IP壁垒 |

### 2.3 大玩家收入来源

| 收入来源 | 说明 |
| :--- | :--- |
| **门票/入场券** | 玩家进入服务器或特定剧本房间的费用 |
| **会员订阅** | 月费制，畅玩服务器内基础内容 |
| **虚拟道具/皮肤售卖** | 服务器专属商店的道具、皮肤、特效 |
| **直播间互动玩法** | 观众送礼触发游戏内事件（不影响公平性） |
| **众筹/冠名赛事** | 发起主题活动，粉丝众筹支持 |
| **私域流量返利** | 通过人脉邀请链接吸引新玩家，获得跨服消费返利 |

### 2.4 大玩家成本结构

| 成本类型 | 说明 |
| :--- | :--- |
| **AI算力套餐** | **核心运营成本**，月度订阅或按量付费 |
| **剧本授权费** | 从资产市场采购剧本，可买断或分成 |
| **美术/场景资产** | 购买或租赁3D场景、皮肤等 |
| **营销推广** | 品牌建设、活动运营、KOL互相推广 |
| **服务器基础云费** | 基础计算和网络资源 |

### 2.5 大玩家核心能力

- 策展眼光：挑选和组合剧本的能力
- 社群运营：建立和维护玩家社群的能力
- 品牌建设：打造独特服务器文化和个人IP的能力
- 商业经营：灵活运用多种变现手段的能力


## 三、创作者参与模式

### 3.1 创作者定位

创作者是《开本》生态中的 **“内容生产者”** ，使用官方工具创作剧本、角色、场景、机制包等数字资产，通过资产市场获得持续收益。

### 3.2 创作内容类型

| 内容类型 | 说明 |
| :--- | :--- |
| **剧本** | 包含角色、案件规则、线索系统、结局条件的完整故事框架 |
| **角色智能体模板** | 拥有完整人格档案、人生记忆、语言风格的AI角色 |
| **场景资产** | 3D场景模板、可交互物品、机关 |
| **玩法机制包** | 暗杀系统、经济系统、生存系统等可复用的玩法模块 |
| **平行世界** | 完整的世界观框架（物理法则、历史线、种族文化） |
| **外观皮肤** | 角色服装、场景主题、特效、声线模组 |

### 3.3 创作者收入来源

| 收入来源 | 说明 | 分成比例 |
| :--- | :--- | :--- |
| **剧本销售/订阅** | 买断制或订阅制的剧本使用权 | 创作者70% / 平台30% |
| **资产市场交易** | 角色模板、场景、皮肤等的售卖 | 创作者80% / 平台20% |
| **众筹收入** | 剧本开发阶段的支持资金 | 众筹发起者（扣除平台手续费） |
| **Fork授权费** | 其他创作者基于其作品进行二次创作的授权费 | 原作者70% / 平台30% |
| **大玩家剧本使用分成** | 大玩家服务器运营其剧本时按门票收入分成 | 默认创作者40% / 大玩家60% |
| **跨媒介授权** | 小说、漫画、影视改编的版权收入 | 协商分成 |

### 3.4 创作者成本结构

| 成本类型 | 说明 |
| :--- | :--- |
| **平台服务费** | 使用剧本编辑器高级功能的订阅费 |
| **AI算力使用费** | 创作过程中的LLM调用、AI测试模拟等 |
| **资产采购费** | 从市场购买或租赁其他创作者的资产 |
| **Fork授权费** | 基于他人作品创作时的授权支出 |

### 3.5 创作者成长路径

| 阶段 | 创作方式 | 收入模式 |
| :--- | :--- | :--- |
| **新人** | 使用免费资产和AI辅助工具，发布免费章节验证创意 | 众筹 + 平台扶持 |
| **成熟** | 购买独家资产，制作精品剧本 | 剧本买断 + 资产市场 |
| **工作室** | 建立品牌，持续产出系列作品 | 订阅 + Fork授权 + 跨媒介 |
| **大师** | 创建原创平行世界，吸引其他创作者入驻 | 世界版税 + IP投资 |

### 3.6 创作者核心价值

- 零代码创作：可视化编辑器+AI辅助，无需编程能力
- 光速反馈：众筹即市场验证，AI测试模拟即时反馈
- 持续版税：一次创作，长期收益，智能合约自动分账
- 清晰成长路径：从新人到大师的完整阶梯


## 四、玩家参与模式

### 4.1 玩家定位

玩家是《开本》生态中的 **“体验者”和“世界公民”** 。他们消费故事、建立羁绊、拥有数字资产，并通过社交裂变和内容二创参与生态共建。

### 4.2 玩家消费模式

| 消费类型 | 消费项目 | 模式 |
| :--- | :--- | :--- |
| **体验前置** | 剧本买断、服务器门票、会员订阅、众筹支持 | 买断/单次/月费 |
| **个性化** | 角色皮肤、场景主题、声线模组、动作表情 | 买断制 |
| **智能体相关** | 智能体角色买断、智能体收编、外观定制、世界化身 | 买断/养成 |
| **社交增值** | 大玩家社群会员、私密房间租赁、直播互动道具 | 订阅/单次 |
| **数据纪念** | 本局故事报告与CG、云存档扩容 | 单次/扩容 |
| **算力服务** | P2P自建服务器时的AI算力套餐 | 按需付费 |

### 4.3 玩家参与生态的方式

| 参与方式 | 说明 | 可能获得的收益 |
| :--- | :--- | :--- |
| **体验与消费** | 游玩剧本，购买皮肤和智能体 | 沉浸体验、情感羁绊 |
| **社交裂变** | 通过双轨邀请制邀请好友 | 好友消费返利、抽卡券 |
| **内容二创** | 创作同人剧本、角色皮肤、攻略视频 | 资产市场售卖、视频收益分成 |
| **众筹支持** | 用真金白银支持喜欢的创作者 | 限定外观、首发体验权、创作者署名感谢 |
| **评分与反馈** | 为剧本和服务器评分评论 | 影响推荐算法，让好内容被更多人发现 |

### 4.4 玩家权益保障

| 保障 | 说明 |
| :--- | :--- |
| **买断资产永久权** | 所有买断的剧本、皮肤、智能体等数字资产，绑定玩家全球账户，永久有效，可跨服使用 |
| **2小时无理由退款** | 剧本买断后2小时内，若游戏时长不足2小时，可无条件退款 |
| **全平台资产跨服** | 核心买断资产不受单一服务器经营状况影响 |
| **P2P永久保存** | 玩家可在自己的电脑上运行剧本，资产存储在本地硬盘 |
