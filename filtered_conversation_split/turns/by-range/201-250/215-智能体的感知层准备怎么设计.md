## DeepSeek

# 智能体感知层设计方案

## 一、核心设计原则

| 原则 | 说明 |
| :--- | :--- |
| **语义替代视觉** | 智能体不截图，不依赖多模态视觉模型，接收与人类同源计算的结构化语义事件流 |
| **物理真实性** | 智能体只能感知其身体感官在物理上能够接收到的信息，绝不拥有上帝视角 |
| **角色一致性** | 感知能力严格匹配角色设定（盲人无视觉、聋子无听觉、醉酒者感知模糊） |
| **空间限制** | 只在感知范围内的信息才会被传递，超出范围的事件绝不推送 |
| **状态影响** | 角色的当前状态（醉酒、致幻、专注、高压力）会影响感知的精度和范围 |
| **同源计算** | 人类通过3D渲染和空间音频感知，AI通过同一套物理计算的语义化结果感知 |


## 二、感知档案：每个角色的感官定义

每个角色在开本时，系统根据其角色设定生成一份**感知档案**，定义了该角色所有感官的能力边界。

    "hearing": {

### 感官类型总览

| 感官 | 说明 | 典型角色 |
| :--- | :--- | :--- |
| **视觉** | 看到物体、角色、文字、光线变化 | 所有正常角色 |
| **听觉** | 听到对话、脚步声、环境音、异常声响 | 所有正常角色（盲人增强） |
| **触觉** | 触摸物品纹理、温度、形状，感知他人接触 | 盲人核心感官 |
| **热感** | 感知近距离热源和冷源 | 盲人、某些特殊能力角色 |
| **嗅觉** | 闻到血腥、香水、烟雾、药物等气味 | 猎犬、药剂师、盲人 |
| **特殊感官** | 回声定位、灵力感知、电磁感应等 | 特殊设定角色 |


## 三、感知过滤流程

事件总线上运行着所有原始事件。感知过滤器（Perception Filter）为每个角色独立运行，是其专属的“感官防火墙”。

```
[事件总线上的原始事件]
    │
    ▼
┌─────────────────────────────────────────┐
│         感知过滤器（Per-Character）       │
│                                          │
│  Step 1: 感官启用检查                    │
│     ├─ 角色有视觉？→ 无，跳过所有视觉事件   │
│     ├─ 角色有听觉？→ 无，跳过所有听觉事件   │
│     └─ ...                              │
│                                          │
│  Step 2: 空间范围检查                    │
│     ├─ 事件发生位置在角色的该感官范围内？    │
│     ├─ 是 → 继续                         │
│     └─ 否 → 丢弃该事件                   │
│                                          │
│  Step 3: 物理遮挡检查                    │
│     ├─ 声源与角色之间有墙？→ 声音被衰减     │
│     ├─ 热源被物体遮挡？→ 热感减弱或消失     │
│     └─ 视觉被遮挡？→ 视觉事件不生成        │
│                                          │
│  Step 4: 注意力与状态修正                 │
│     ├─ 角色醉酒？→ 感知延迟+模糊化          │
│     ├─ 角色专注某物？→ 非专注方向感知减弱    │
│     ├─ 角色高压力？→ 忽略次要感知           │
│     └─ 角色致幻？→ 可能生成虚假感知事件     │
│                                          │
│  Step 5: 生成角色专属感知事件              │
│     └─ 输出给该角色的L1感知层              │
└─────────────────────────────────────────┘
```


## 四、视觉感知通道

智能体接收结构化的“可见对象列表”，而非像素画面。

### 4.1 可见对象列表

| 字段 | 说明 | 例子 |
| :--- | :--- | :--- |
| `object_id` | 唯一标识 | `char_03`, `item_12` |
| `object_type` | 类型 | `character`, `item`, `door`, `window`, `container` |
| `object_name` | 可读名称 | “福尔摩斯”、“染血的烛台”、“书房的门” |
| `position` | 相对于智能体的位置（米） | `{x: 3.5, y: 0, z: 2.1}` |
| `distance` | 距离 | `3.5m` |
| `state` | 当前状态 | 角色：“站立，正在说话”；门：“关闭”；物品：“在地板上” |
| `visible_actions` | 可对此对象执行的交互 | `["交谈", "观察", "搜身"]` |
| `notable_features` | 值得注意的特征 | 角色：“面色苍白，右手有血迹”；物品：“上面刻着字母R” |
| `last_update` | 最后更新时间戳 | `2026-05-20T19:05:23Z` |

### 4.2 视觉更新机制

| 触发条件 | 事件类型 | 推送内容 |
| :--- | :--- | :--- |
| 新对象进入视野 | `object_entered` | 完整对象信息 |
| 对象离开视野 | `object_exited` | 对象ID + 离开原因 |
| 对象状态变化 | `object_state_changed` | 对象ID + 变化的字段 |
| 心跳全量同步 | `vision_sync` | 当前视野内所有对象（每2-3秒一次） |

### 4.3 视觉约束条件

| 约束 | 说明 |
| :--- | :--- |
| **视野角度** | 默认前方120度锥形视野，背后和侧面不可见 |
| **距离限制** | 默认清晰视觉15米，30米外无法辨别细节 |
| **光照影响** | 黑暗环境中视觉范围大幅缩小，仅能感知光源附近 |
| **遮挡** | 被墙壁、门、大型家具遮挡的物体不可见 |
| **角色状态** | 醉酒→视觉模糊、重影；致幻→可能看到不存在的东西 |


## 五、听觉感知通道

智能体接收结构化的“可听事件列表”。

### 5.1 听觉事件格式

| 字段 | 说明 | 例子 |
| :--- | :--- | :--- |
| `source_id` | 声源对象ID | `char_02` |
| `source_name` | 可读名称 | “华生医生” |
| `sound_type` | 类型 | `speech`, `footstep`, `door_open`, `item_drop`, `scream`, `explosion` |
| `content` | 如果是说话，内容是文本 | “我昨晚在书房看到了一个人影...” |
| `clarity` | 清晰度 | `clear` / `muffled` / `distant` / `barely_audible` |
| `distance` | 距离 | `5m` |
| `direction` | 方向 | `front-left`, `behind`, `above` |
| `emotion` | 说话者的情绪 | `nervous`, `angry`, `calm` |
| `timestamp` | 时间戳 | `2026-05-20T19:05:30Z` |

### 5.2 清晰度判定规则

| 清晰度 | 条件 | 智能体获得的信息 |
| :--- | :--- | :--- |
| `clear` | 清晰区内，无遮挡 | 完整对话文本 + 情绪 + 说话者身份确认 |
| `muffled` | 模糊区 或 门后 | 关键词片段 + 模糊情绪 + 说话者身份“疑似” |
| `distant` | 远距离或墙后 | 仅知“有人在说话”或“有脚步声”，无内容 |
| `barely_audible` | 极远 | 仅知“有动静”，无法判断类型 |

### 5.3 听觉约束条件

| 约束 | 说明 |
| :--- | :--- |
| **距离衰减** | 随距离增加，清晰度逐步下降 |
| **物理阻挡** | 门/墙/书架等介质对声音的衰减效果 |
| **环境噪音** | 雨声、风声、多人说话等噪音环境下，听觉半径缩短 |
| **角色状态** | 专注时忽略非注意方向的声音；醉酒时听觉迟钝 |


## 六、触觉与热感通道

对于盲人角色或有特殊能力的角色，触觉和热感是核心感知通道。

### 6.1 触觉事件

| 触发条件 | 事件类型 | 感知输出示例 |
| :--- | :--- | :--- |
| 玩家主动接触角色 | `touch_event` | “有人轻轻拍了拍你的左肩。” |
| 角色主动伸手触摸 | `touch_probe` | “你摸到了墙壁，表面粗糙冰冷，是石墙。” |
| 手持物品 | `touch_item` | “你握着的匕首刀柄上刻有花纹，似乎是某种家族纹章。” |
| 感受到震动 | `vibration_event` | “地板传来沉重的脚步声，似乎有人正在靠近。” |

### 6.2 热感事件

| 触发条件 | 事件类型 | 感知输出示例 |
| :--- | :--- | :--- |
| 靠近热源 | `thermal_hot` | “你感觉到前方2米处有强烈的热辐射，可能是壁炉或篝火。” |
| 靠近冷源 | `thermal_cold` | “右侧传来明显的冷风，可能有一扇打开的窗户。” |
| 人体热量 | `thermal_body` | “你能感知到房间里还有两个人，分别在左前方和右后方。” |


## 七、事件感知通道

除了感官通道，智能体还接收环境中发生的“非接触事件”。

| 事件类型 | 触发条件 | 智能体收到的信息 |
| :--- | :--- | :--- |
| **环境变化** | 灯光熄灭、窗户被风吹开 | `environment_changed: {type: "lights_out", location: "大厅"}` |
| **物品被移动** | 有人拾取或移动了物品 | `item_moved: {item: "烛台", from: "桌上", to: "某人背包"}`（仅当智能体当时在场景中且可视时） |
| **公共事件** | 尖叫、尸体被发现 | `public_event: {type: "scream", location: "书房", time: "19:05"}` |
| **状态变化** | 角色受伤、角色死亡 | `character_state_changed: {character: "玛丽", state: "injured"}` |


## 八、动作的阶段化感知

每个可被感知的动作被拆分为三个阶段，智能体在**意图阶段即刻反应**，而非等待动作完成。

| 阶段 | 事件类型 | 人类看到 | 智能体收到 |
| :--- | :--- | :--- | :--- |
| **意图阶段** | `action_intent` | 准备动作（举起刀、蓄力、伸手） | `{actor, action, phase: "intent", target}` |
| **执行阶段** | `action_executing` | 动作进行中 | `{actor, action, phase: "executing", progress: 0.5}` |
| **完成阶段** | `action_completed` | 动作结果 | `{actor, action, phase: "completed", result}` |

### 意图阶段的感知条件

| 动作类型 | 意图可见性 | 说明 |
| :--- | :--- | :--- |
| 公开对话 | 必然可见 | 开口说话本身就是意图 |
| 展示物品 | 必然可见 | 举起物品的动作很明显 |
| 拾取物品 | 必然可见 | 伸手弯腰的动作 |
| 开关门 | 必然可见 | 伸手推拉的动作 |
| 暗杀（近距离） | 近距离可见 | 拔刀动作在2米内可察觉 |
| 暗杀（无声） | 几乎不可见 | L3+专家的暗杀可能无明显意图阶段 |
| 下毒 | 不可见 | 细微动作，仅极高观察力者可察觉“疑似” |


## 九、注意力机制

人类玩家可能因为看别处而漏掉关键画面。智能体也需要模拟这种“注意力的有限性”。

| 注意力状态 | 感知效果 |
| :--- | :--- |
| **专注某对象**（正在对话、正在检查物品） | 对该对象的感知增强；对其他对象的意图阶段感知延迟或遗漏 |
| **警惕状态**（压力高、知道有威胁） | 对所有方向的意图阶段感知增强，反应更快 |
| **放松状态** | 正常感知范围，对细微动作可能忽略 |
| **醉酒/致幻** | 感知概率降低，可能收到错误信息或幻觉事件 |

### 注意力判定逻辑

- 智能体当前正在对话 → 注意力集中在对话对象
- 智能体正在检查物品 → 注意力集中在物品
- 智能体正在移动 → 注意力在前方
- 智能体处于空闲 → 注意力均匀分布


## 十、本能反应规则引擎（L1快速通道）

对于致命威胁，智能体使用预置的**本能反应规则**，不经过完整心智模型，直接响应。

| 威胁类型 | 人格参数 | 本能反应 |
| :--- | :--- | :--- |
| 近距离暗杀意图 | 胆量 ≥ 7 | 反击或闪避 |
| 近距离暗杀意图 | 胆量 4-6 | 呼救或逃跑 |
| 近距离暗杀意图 | 胆量 ≤ 3 | 僵住或尖叫 |
| 被出示关键证据 | 心机 ≥ 7 | 冷静否认 |
| 被出示关键证据 | 心机 ≤ 3 | 慌乱、语无伦次 |
| 发现尸体 | 胆量 ≥ 7 | 靠近检查 |
| 发现尸体 | 胆量 ≤ 3 | 尖叫、后退、逃跑 |

**本能反应延迟**：150-300ms，接近人类本能反应时间。后续LLM推理在1-2秒内生成更复杂的后续行为。


## 十一、感知公平性保证

| 公平性维度 | 人类 | AI智能体 | 一致性保证 |
| :--- | :--- | :--- | :--- |
| **接收速度** | 视觉信号→大脑，约100-200ms | 语义事件→决策引擎，<50ms | 通过可配置的“反应延迟”平衡 |
| **信息精度** | 人眼可看到细节但可能遗漏 | 语义描述精准但不会“过度精确” | 通过注意力机制和模糊区模拟人类的信息不完整性 |
| **可反应窗口** | 人类自己的反应时间决定 | 基于人格的反应时间决定 | 高胆量AI反应快，低胆量AI反应慢 |
| **信息遗漏** | 玩家自己没注意到 | 注意力机制和状态影响 | 都可能遗漏信息 |


## 十二、感知系统的运行时配置

| 参数 | 说明 | 默认值 |
| :--- | :--- | :--- |
| **基础感知延迟** | 从事件发生到被处理的模拟延迟 | 100-300ms |
| **注意力分散度** | 高则更易遗漏非注意方向的感知 | 由当前状态动态决定 |
| **意图识别敏感度** | 对`action_intent`事件的识别概率 | 由距离、注意力、状态共同决定 |
| **反应速度** | 从识别威胁到执行反应的决策时间 | 由胆量和理性参数推导 |
| **视觉距离** | 默认清晰视觉距离 | 15米 |
| **听觉距离** | 默认清晰听觉距离 | 10米（室内）/ 20米（室外） |


## 十三、与事件总线和司命的集成

```
[L1 原始事件] → [事件总线] → [感知过滤器(Per-Character)] → [L2 角色智能体感知层]
                                    ↑
                              [感知档案] + [当前状态]
```

- **感知过滤器**从事件总线订阅事件，为每个角色独立运行
- **司命**拥有全局视角，可以看到所有原始事件，但仅用于逻辑检查和叙事催化，绝不直接注入角色感知
- **司命的干预**必须通过符合感知规则的合法途径（如让一个NPC恰好进入角色的感知范围）
