**Fork开发者SDK不是传统意义上的“软件开发工具包”。** 我们不开放引擎源码，只开放**平行世界和剧本的Fork**。

因此，Fork开发者SDK应该重新定义为：

## Fork开发工具（剧本与世界Fork工具）

**核心原则**：Fork开放的是**剧本内容和世界观规则**，不是游戏引擎源码。开发者不需要写代码，而是使用可视化工具和配置接口进行二次创作。

| 工具 | 定位 | 说明 |
| :--- | :--- | :--- |
| **剧本Fork工具** | 基于已有剧本创建平行版本 | 一键Fork官方或社区剧本，修改角色设定、案件规则、场景布局、故事走向。所有修改在可视化编辑器中完成 |
| **世界Fork工具** | 基于已有平行世界创建衍生世界 | 继承原世界的物理法则、历史线、种族文化，在此基础上扩展或修改 |
| **版本管理工具** | 管理Fork版本 | 版本历史记录、与原版的差异对比、合并冲突解决 |
| **Fork家谱记录** | 链上记录贡献者署名 | 每次Fork在链上记录原作者和所有贡献者，形成完整的创作家谱树 |
| **Fork授权与分账配置** | 商业规则设置 | 配置Fork版本的商业授权条款（买断/分成），智能合约自动执行分账给上游创作者 |

**Fork开发者的工作方式**：在剧本编辑器或世界编辑器中点击“Fork”，系统创建一份副本，开发者通过可视化界面修改参数和资产，无需编写代码。
