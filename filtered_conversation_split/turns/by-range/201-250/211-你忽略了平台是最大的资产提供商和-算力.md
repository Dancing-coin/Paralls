# 《开本 / Paralls》商业模式（修订版）


## 一、平台商业模式

### 1.1 平台的双重核心身份

《开本》平台兼具**技术基建方**和**资产供给方**的双重角色：

| 身份 | 说明 | 核心交付 |
| :--- | :--- | :--- |
| **技术基建方** | 为所有参与者提供技术底座 | 司命叙事引擎、角色智能体引擎、创作工具、资产市场、事件总线、空间音频服务、匹配系统、跨服架构、区块链确权与分账 |
| **资产供给方** | 生态中最大的内容资产生产者和云服务商 | 官方平行世界、官方剧本、官方角色智能体模板、官方3D场景与皮肤、AI算力套餐、云存储与云服务器 |

### 1.2 平台收入来源

| 收入来源 | 说明 | 计费模式 |
| :--- | :--- | :--- |
| **官方资产销售** | 官方出品的平行世界、剧本、角色智能体、3D场景、皮肤等数字资产的售卖与租赁 | 买断/租赁/分成 |
| **AI算力套餐** | 向大玩家、创作者、P2P玩家销售AI推理算力 | 月度订阅或按量付费 |
| **云服务与扩容** | 向玩家和大玩家提供云存储、云服务器、资产托管服务 | 按需付费/包月 |
| **交易抽成** | 从资产市场所有创作者间交易中抽取服务费 | 剧本/角色/皮肤等交易额的20%-30% |
| **官方服务器收入** | 官方运营旗舰影院和核心IP主题世界 | 门票、会员订阅、道具销售，100%归官方 |
| **会员订阅** | 面向玩家的高级功能订阅 | 月费制 |

### 1.3 平台作为资产提供商的具体资产

| 资产类型 | 说明 | 商业模式 |
| :--- | :--- | :--- |
| **官方平行世界** | 首批UNV-001等核心世界观 | 创作者入驻需支付版税；大玩家经营官方世界需授权 |
| **官方剧本** | 每个平行世界至少1-2个免费剧本 + 多个付费精品剧本 | 买断/门票分成 |
| **官方角色智能体** | 精心设计的核心IP角色（如福尔摩斯、白素贞） | 玩家可买断带走，创作者可购买授权用于自己的剧本 |
| **官方3D场景资产** | 维多利亚庄园、南宋临安、赛博都市等 | 租赁/买断，创作者可购买用于自己的剧本 |
| **官方皮肤与外观** | 角色服装、场景主题、特效、声线模组 | 买断制 |
| **官方玩法机制包** | 暗杀系统、经济系统、生存系统等 | 买断制 |

### 1.4 平台作为云服务商的具体服务

| 服务类型 | 说明 | 计费模式 |
| :--- | :--- | :--- |
| **AI算力套餐（基础版）** | 适合P2P自建玩家，基础AI响应质量 | 月费/按量 |
| **AI算力套餐（高级版）** | 适合大玩家商业运营，高并发、低延迟 | 月费/包年 |
| **AI算力套餐（无限版）** | 顶级主题世界，无限算力池 | 包年/定制 |
| **云存储扩容** | 玩家数字资产、游戏录像的额外存储空间 | 按需付费 |
| **云服务器租赁** | 大玩家或P2P玩家租赁官方云服务器 | 按需付费/包月 |
| **资产托管服务** | 离线经营、世界持续运行托管 | 按需付费 |

### 1.5 平台核心护城河

| 护城河 | 说明 |
| :--- | :--- |
| **司命叙事引擎** | 全球最先进的实时动态叙事AI |
| **角色智能体引擎** | 人格驱动的AI角色系统，支撑AI陪伴经济 |
| **官方IP宇宙** | 官方核心平行世界和角色资产，生态的引力中心 |
| **创作者生态** | 无限供给的UGC内容 |
| **大玩家网络** | 分布式流量和服务节点 |
| **玩家资产绑定** | 跨服社交和永久数字资产形成的高粘性 |


## 二、大玩家参与模式

### 2.1 大玩家定位

大玩家是《开本》生态中的 **“剧院经营者”或“世界创造者”** ，通过运营服务器提供沉浸式娱乐服务来获得商业回报。

### 2.2 两种经营模式

| 模式 | 影院模式 | 主题世界模式 |
| :--- | :--- | :--- |
| **定位** | 灵活策展，多题材轮换 | 深度绑定单一世界观，品牌沉淀 |
| **适合人群** | 流量型KOL、初创团队 | 品牌型KOL、成熟团队 |
| **投入** | 低（策展+服务） | 高（定制场景、独占内容） |
| **收入潜力** | 稳定，天花板明显 | 高，可形成IP壁垒 |

### 2.3 大玩家收入来源

| 收入来源 | 说明 |
| :--- | :--- |
| **门票/入场券** | 玩家进入服务器或特定剧本房间的费用 |
| **会员订阅** | 月费制，畅玩服务器内基础内容 |
| **虚拟道具/皮肤售卖** | 服务器专属商店的道具、皮肤、特效 |
| **直播间互动玩法** | 观众送礼触发游戏内事件（不影响公平性） |
| **众筹/冠名赛事** | 发起主题活动，粉丝众筹支持 |
| **私域流量返利** | 通过人脉邀请链接吸引新玩家，获得跨服消费返利 |

### 2.4 大玩家成本结构

| 成本类型 | 说明 |
| :--- | :--- |
| **AI算力套餐** | **核心运营成本**，向平台采购 |
| **剧本授权费** | 从资产市场采购官方或创作者剧本，可买断或分成 |
| **美术/场景资产** | 从平台或市场购买/租赁3D场景、皮肤等 |
| **营销推广** | 品牌建设、活动运营、KOL互相推广 |
| **服务器基础云费** | 可自建或向平台租赁云服务器 |


## 三、创作者参与模式

### 3.1 创作者定位

创作者是《开本》生态中的 **“内容生产者”** ，使用官方工具创作数字资产，通过资产市场获得持续收益。

### 3.2 创作者收入来源

| 收入来源 | 说明 | 分成比例 |
| :--- | :--- | :--- |
| **剧本销售/订阅** | 买断制或订阅制的剧本使用权 | 创作者70% / 平台30% |
| **资产市场交易** | 角色模板、场景、皮肤等的售卖 | 创作者80% / 平台20% |
| **众筹收入** | 剧本开发阶段的支持资金 | 众筹发起者（扣除平台手续费） |
| **Fork授权费** | 其他创作者基于其作品进行二次创作的授权费 | 原作者70% / 平台30% |
| **大玩家剧本使用分成** | 大玩家服务器运营其剧本时按门票收入分成 | 默认创作者40% / 大玩家60% |
| **跨媒介授权** | 小说、漫画、影视改编的版权收入 | 协商分成 |

### 3.3 创作者成本结构

| 成本类型 | 说明 |
| :--- | :--- |
| **平台服务费** | 剧本编辑器高级功能的订阅费 |
| **AI算力使用费** | 创作过程中的LLM调用、AI测试模拟等，向平台采购 |
| **官方/社区资产采购费** | 从市场购买或租赁官方或其他创作者的资产 |
| **Fork授权费** | 基于他人作品创作时的授权支出 |
| **云存储费** | 资产存储和版本管理 |


## 四、玩家参与模式

### 4.1 玩家定位

玩家是《开本》生态中的 **“体验者”和“世界公民”** 。消费故事、建立羁绊、拥有数字资产，并通过社交裂变和内容二创参与生态共建。

### 4.2 玩家消费模式

| 消费类型 | 消费项目 | 模式 |
| :--- | :--- | :--- |
| **体验前置** | 官方/创作者剧本买断、大玩家服务器门票、会员订阅、众筹支持 | 买断/单次/月费 |
| **个性化** | 官方/社区皮肤、场景主题、声线模组、动作表情 | 买断制 |
| **智能体相关** | 官方/创作者角色智能体买断、收编、外观定制、世界化身 | 买断/养成 |
| **社交增值** | 大玩家社群会员、私密房间租赁、直播互动道具 | 订阅/单次 |
| **数据纪念** | 本局故事报告与CG、云存档扩容 | 单次/扩容 |
| **算力与云服务** | P2P自建服务器时的AI算力套餐、云存储扩容 | 按需/包月 |

### 4.3 玩家参与生态的方式

| 参与方式 | 说明 | 可能获得的收益 |
| :--- | :--- | :--- |
| **体验与消费** | 游玩剧本，购买皮肤和智能体 | 沉浸体验、情感羁绊 |
| **社交裂变** | 通过双轨邀请制邀请好友 | 好友消费返利、抽卡券 |
| **内容二创** | 创作同人剧本、角色皮肤、攻略视频 | 资产市场售卖、视频收益分成 |
| **众筹支持** | 用真金白银支持喜欢的创作者 | 限定外观、首发体验权 |

### 4.4 玩家权益保障

| 保障 | 说明 |
| :--- | :--- |
| **买断资产永久权** | 所有买断资产绑定全球账户，永久有效，跨服使用 |
| **2小时无理由退款** | 剧本买断后2小时内可退款 |
| **全平台资产跨服** | 不受单一服务器经营状况影响 |
| **P2P永久保存** | 可在本地运行剧本，资产存储在本地硬盘 |
