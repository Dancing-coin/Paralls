# 《开本》游戏系统策划案 (玩家视角)


## 一、基础系统
支撑游戏基本运行，但不属于可玩内容的系统模块。

| 系统名称 | 说明 |
| :--- | :--- |
| **游戏设置系统** | 音频音量、画质分档、键鼠/手柄键位自定义、语言切换、色盲/高对比度等无障碍辅助 |
| **账号系统** | 玩家身份注册/登录，用于保存游戏进度和个人数据 |
| **房间管理** | 创建/加入/销毁游戏房间，角色选择与锁定，断线重连 |
| **状态同步** | 角色位置、物品状态、对话状态在网络环境下的实时同步 |
| **客户端性能适配** | 自动检测硬件并推荐画质，支持低配设备的“极简模式” |
| **反作弊系统** | 服务端权威验证暗杀条件、物品位置等关键逻辑；AI检测恶意挂机或脚本操作 |
| **举报系统** | 游戏内便捷举报入口，针对恶意行为、言语攻击等 |


## 二、养成系统
具有养成属性的系统模块。在《开本》中，不是传统的“升级、加点、强化”，而是围绕角色羁绊和记忆展开的深度养成。

| 系统名称 | 说明 |
| :--- | :--- |
| **智能体带走与养成** | 剧本中建立深厚羁绊后，可邀请心仪的AI角色离开，成为你的私人伙伴。可命名、微调行为参数 |
| **智能体外观定制** | 为私人伙伴解锁和穿戴不同服装、更换声线模组 |
| **智能体记忆与成长** | 你的伙伴会记住与你在无数冒险中的经历、对你的情感羁绊（信任、依赖）会不断加深；你甚至可以在它牺牲后，开启一场跨剧本的漫长复活任务 |
| **玩家个人空间** | 一个可自定义的3D家园，你的AI伙伴们在这里生活、与你互动 |
| **玩家资产收集** | 买断的剧本、主题皮肤、特殊道具等数字资产，永久收集和展示 |


## 三、战斗系统
包含暗杀、击杀、特殊状态等与对抗直接相关的系统模块。

| 系统名称 | 说明 |
| :--- | :--- |
| **暗杀能力体系** | 角色拥有L0-L4暗杀等级，决定可用手法和痕迹多寡，由角色设定决定 |
| **暗杀条件判定** | 必须满足致命动机、独处窗口、能力匹配、代价评估等条件才可执行 |
| **暗杀阶段化感知** | 暗杀分意图、执行、完成三阶段，目标在意图阶段即可察觉并本能反应（反击/逃跑/呼救） |
| **暗杀痕迹系统** | 暗杀后必然留下尸体、凶器、打斗痕迹等物证，以及时间线矛盾等逻辑证据 |
| **简易击杀与报告** | 快节奏模式下，靠近目标一键击杀，有冷却时间；发现尸体可报告触发会议 |
| **角色特殊状态** | 中毒、醉酒、致幻等状态，会影响感知精度、行为倾向和决策质量 |


## 四、玩法系统
构成《开本》核心游戏可玩内容的系统模块群。

### 4.1 核心推理玩法

| 系统名称 | 说明 |
| :--- | :--- |
| **案件生成系统** | 每次游戏从动机、凶器、手法等随机池中动态抽取，锁定一个独一无二的案件 |
| **事实锁定时间线** | 案件真相在游戏开始的瞬间锁定，但故事如何展开完全由玩家行为决定 |
| **线索与搜证** | 20-30条线索散落在3D场景中，需要玩家主动探索、拾取、检查 |
| **伪装与身份** | 每个人拥有真实身份和可编辑的公开身份；伪装需要依赖物理道具，撒谎会有破绽 |
| **知情人网络** | 你的秘密被谁知晓？你可以收买、威胁或博取同情，在“谁知道什么”的动态网络中生存 |
| **信息共享与博弈** | 通过公开对话、私密耳语、展示物品、带人查看等方式主动选择分享信息，并防范偷听 |
| **投票与结局** | 会议投票指认真凶；结局由玩家的集体行为决定，而非预设 |

### 4.2 AI与叙事玩法

| 系统名称 | 说明 |
| :--- | :--- |
| **AI角色心智模型** | AI角色拥有独立人格、记忆和目标，会自主决策、撒谎、结盟或背叛 |
| **司命导演系统** | 维护故事逻辑，根据局势主动催化冲突、创造巧合，管理游戏节奏和平衡 |
| **动态对话系统** | 与AI角色进行完全自由的、符合其人格和情境的实时对话 |
| **内心戏与深度沉浸** | 你的角色会自动流露符合人设的微表情、小动作和内心独白；挂机时行为由AI自主接管 |
| **视觉高光时刻** | 发现关键线索或情绪高潮时，自动生成符合场景和氛围的图片/视频进行呈现 |

### 4.3 主题世界与长期世界玩法

| 系统名称 | 说明 |
| :--- | :--- |
| **系列剧本承接** | 前一部剧本中的结局和关键选择，会影响下一部续作的初始状态和角色关系 |
| **双层身份系统** | 选择成为“穿越旅人”体验单局精彩，或成为“原住居民”在持续运行的世界中生活 |
| **资产经营玩法** | 在主题世界中拥有庄园、商铺等资产，进行经营、建设、交易 |
| **世界级事件** | 参与全服玩家共同经历的大型事件，你的行为会被写入这个世界的永久历史 |
| **跨世界旅行** | 携带你的AI伙伴和资产穿梭不同世界，其能力会按规则自动适配 |

### 4.4 匹配与组队玩法

| 系统名称 | 说明 |
| :--- | :--- |
| **多模式匹配** | 选择仅匹配真人、纯AI队友、优先匹配AI、带好友组队、带自己的私人AI伙伴等多种方式开局 |
| **智能复盘** | 游戏结束后，生成专属故事报告，记录高光时刻和完整时间线 |
| **凝神能力** | 单人模式下，可主动暂停时间，自由观察、拍照、整理线索，辅助推理 |


## 五、经济系统
游戏资源产出、交易和消耗相关的系统，在这里指玩家视角下的“游戏内经济”。

| 系统名称 | 说明 |
| :--- | :--- |
| **智能体私房钱** | 你的AI伙伴拥有独立经济能力，会用它的积蓄为你购买礼物或在游戏中替你买单 |
| **玩家个人资产** | 你购买的剧本使用权、获得的皮肤/道具等，都永久属于你，可在任何服务器或本地使用 |


## 六、社交系统
游戏中人人交互相关的系统模块。

| 系统名称 | 说明 |
| :--- | :--- |
| **好友系统** | 全球好友列表，可跨服查看状态、私信、组队邀请 |
| **公会/旅团系统** | 创建或加入公会，拥有专属频道，参与公会活动 |
| **剧本招募板** | 在公共空间发布组队请求，寻找特定风格或水平的队友 |
| **公共社交空间** | 旅人酒馆、AI同伴咖啡馆等3D社交区域，供玩家交流、展示 |
| **评分与评价** | 对剧本、其他玩家、AI伙伴的表现进行评分和评价 |
