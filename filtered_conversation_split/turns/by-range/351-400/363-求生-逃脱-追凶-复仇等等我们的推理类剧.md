## 用户

求生，逃脱，追凶，复仇等等我们的推理类剧本杀应该具备多种游戏目标，而不只是搜证追凶

## DeepSeek

要让《开本》的推理类剧本杀具备多种游戏目标，核心在于将“目标系统”从剧本创作的附属品升级为**核心可配置模块**。这意味着，剧本不再是一个统一的“找出真相”的故事，而是一个为每位玩家定制了**秘密目标**的博弈场。

下面，我将基于《开本》现有的系统架构，为你设计一个完整的**多目标系统**。

### 一、核心设计：目标矩阵

在同一局游戏中，每个玩家的核心目标都可能不同。以下是部分可供配置的**初级目标**示例，它们可以由创作者在剧本中预设，也可以在开局时由司命根据角色人设动态分配：

| 目标类型 | 目标描述 | 代表角色 |
| :--- | :--- | :--- |
| **追凶者** | 你的核心目标是找出并指认杀害死者的真凶。 | 侦探、正义的同伴 |
| **生存者** | 你预感到了危险，你的首要目标是在规定时间内存活下来。 | 被威胁的目击者、连环杀手的目标 |
| **逃脱者** | 你被困于此，你的目标是找到离开此地的关键道具或密道。 | 囚犯、被软禁的贵族 |
| **复仇者** | 你的目标是亲手杀死（或公开揭露）那个对你造成过伤害的人。 | 背负血海深仇的角色 |
| **守护者** | 你的目标是确保另一位特定角色（恋人、家人）能存活到最后。 | 保镖、恋人、父母 |
| **敛财者** | 你不在乎真相，你的目标是找到并私藏庄园里的值钱物品。 | 破产商人、珠宝大盗 |
| **旁观者** | 你的目标是记录下这里发生的一切，并确保你的笔记能流传出去。 | 战地记者、史官、作家 |
| **破坏者** | 你不关心谁是真凶，但你必须销毁所有指向你自己的证据。 | 伪造身份的冒牌货 |

### 二、动态目标的注入与博弈

单一的目标很容易完成，真正的博弈乐趣在于，系统要驱动不同的目标在游戏中**产生冲突与合作**。

*   **目标的冲突与合作**：例如，在同一局《东方快车》中，一名玩家是追凶者（侦探），另一名玩家是守护者（保护自己的妹妹），他们必须合作搜证；而另一名玩家是复仇者，他正在利用混乱悄悄接近杀父仇人（非死者），则可能与所有人对立。当守护者发现复仇者的计划时，他的目标可能动态切换为“阻止复仇者”。

*   **目标驱动的人物反转**：目标的冲突能创造出震撼的戏剧效果。例如，一名守护者玩家拼尽全力保护自己心爱的大小姐活到了最后。他以为胜利在望，却收到司命的一条新指令：“**你已暴露。你在剧本中看到的所有忠诚与爱意，都源于一个被掩盖的事实——大小姐正是当年的灭门主谋。你的初始目标‘守护’已失败，新目标已解锁：复仇。**”

### 三、系统的支撑与协同

我们的**角色智能体心智模型**和**事件总线**为多目标系统提供了完美支撑。角色的人格参数会驱动他们以不同方式完成目标（如高理性者会制定周密计划，高胆量者会不计后果地动手）。

实现目标的手段也远不止“搜证”。我们的**阴谋系统**、**环境致死机制**、**蓄意破坏**以及**知情人网络**，为玩家提供了丰富的手段。例如，复仇者可以下毒或制造“意外”摔死，生存者可以制造停电来掩护自己逃跑。

### 四、体验示例：《无人生还·孤岛审判》的新变体

让我们回到你改编的《无人生还》。加入多目标系统后，体验将完全不同：

游戏开始时，玩家A（扮演隆巴德上尉）收到指令：“目标：生存者。士兵岛上的一切都不合理，你的首要目标是在暴风雨结束前存活。次要目标：找到并私藏别墅里的贵重物品。”
同时，玩家B（扮演沃格雷夫法官）收到指令：“目标：审判者。你有权揭示所有人的罪行，但你必须确保自己能看到审判结束。若有需要，可亲手惩罚罪大恶极者。”

在这种设定下，游戏不再是所有人集体推理谁是凶手。隆巴德可能会偷偷收集所有食物和武器，准备脱离集体独自求生；沃格雷夫则可能在角落静静观察，当出现暴民试图动用私刑时，他突然站出来主持秩序。当生存、逃脱、复仇、追凶等目标交织在一起时，**谁先死、谁活到最后、谁是真正的“赢家”**，每一局都会诞生完全不同的故事。
