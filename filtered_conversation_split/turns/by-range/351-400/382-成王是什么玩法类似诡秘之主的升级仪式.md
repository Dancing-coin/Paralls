# 《开本》“成王”玩法设计

## 一、“成王”的定义

“成王”（G24）在《开本》30种游戏目标中定义为：

> **在混乱中成为最后的掌控者——所有人都死了或臣服于你，你成为这座孤岛/宅邸/车厢的唯一主宰。**

它和“全灭”的区别在于：全灭者追求的是所有人都死——他是审判者，不是统治者。成王者追求的是所有人都臣服——他不需要杀所有人，他需要的是掌控。杀了所有人是手段之一，但不是唯一手段，甚至不是最优手段。

你提到《诡秘之主》的升级仪式，这个联想非常精准。“成王”和“诡秘之主”的序列晋升仪式共享同一个核心逻辑：**不是数值达标，而是完成一段特定的、不可复制的叙事。**


## 二、“成王”的核心机制：仪式化叙事

### 2.1 仪式条件

“成王”不是一个可以通过重复刷行为达成的数值目标。它是一套由司命监控的、必须在单局内完成的**仪式条件**。每次开局，司命从仪式池中随机抽取一套条件，确保每一局的“成王”路径都不同。

| 仪式要素 | 设计 | 示例 |
| :--- | :--- | :--- |
| **见证者** | 需要有至少一名其他角色目睹你的关键行为——他不需要臣服于你，但他必须承认你做了什么 | “隆巴德上尉目睹了你与麦肯锡的对峙，他没有干预。” |
| **牺牲** | 你需要放弃某种重要的东西——可能是你最珍贵的物品，可能是你最在乎的盟友，可能是你的一部分道德底线 | “你将父亲留给你的怀表投入火炉——那是你唯一能证明自己不是罪人的东西。” |
| **逆转** | 你需要在看似必败的绝境中完成逆转——不是在公平对决中获胜，而是在所有人都以为你要输的时候，让局势彻底翻转 | “当所有人投票指认你为凶手时，你站起来，揭露了真正的真相——不是你的清白，而是所有人的共谋。” |
| **承认** | 你需要被至少一名其他角色公开承认为“掌控者”——他不需要对你臣服，但他必须说出那句话 | 沃格雷夫对你说：“你赢了。这座岛是你的。” |


### 2.2 仪式监控

司命在后台持续监控成王者的行为，判断是否满足仪式条件。监控不是数值检测，而是**叙事模式识别**——司命在识别你的行为是否构成了一个“成王”的故事。

| 监控维度 | 司命在识别什么 |
| :--- | :--- |
| **权力转移** | 谁在做出最终决定？当其他人开始等待你的命令时，权力已经转移 |
| **恐惧与尊敬** | 其他人是在害怕你，还是在尊敬你？恐惧带来臣服，尊敬带来追随 |
| **不可逆性** | 你的行为是否改变了不可逆的局势？一旦你做了某件事，就再也回不去了 |
| **叙事闭合** | 是否有人公开承认你是掌控者？那句话一出口，仪式完成 |


### 2.3 仪式失败

成王者可能在仪式完成前死亡，或被其他玩家先一步达成目标。如果成王者失败，司命会生成一段“未完成的仪式”叙事，记录在本局的故事报告中——这可能成为续集的伏笔。

如果仪式条件在终局时仍未满足（如没有人公开承认他是掌控者），成王者失败。即使他杀了所有人，也只是“全灭”，不是“成王”。


## 三、“成王”的玩法体验

### 3.1 单人模式：你扮演沃格雷夫，目标“成王”

你的目标不是追凶，不是全灭——是成王。你要让所有人承认你才是这座岛的主宰。

你开始观察每个人。隆巴德有暗杀能力，是个威胁——但他崇拜强者。如果你在他面前击败麦肯锡，他会追随你。布伦特不会臣服于任何人——但她渴望被认可。如果你承认她“保护维拉”的行为是正义的，她会认可你。艾瑟尔正在崩溃——你只需要在她最脆弱的时候握住她的手，她就会成为你的第一个追随者。

你选择了不去杀人。你选择了让每个人在关键时刻看到——你才是唯一能让所有人活下来的人。你在暴风雪最猛烈时组织所有人一起修好了庇护所。你在阿姆斯特朗试图逃脱时没有阻止他，而是在他失败后把他从地下室里拉上来。你在投票环节为艾瑟尔辩护，让所有人想起她曾经是唯一一个在唱片播放后流泪的人。

最终，在暴风雨即将结束的黎明，隆巴德对你说：“我见过很多军官。只有一个让我愿意为他死。”他站起来，站在你身后。艾瑟尔握住你的手。布伦特低下头：“主说，审判是祂的事。但你在祂到来之前，做了祂的工作。”

你走出别墅，站在露台上，暴风雨刚刚过去。你完成了仪式。你成了王。

### 3.2 多人模式：成王者与其他玩家的博弈

如果你是成王者，另一位玩家是隆巴德（生存）。你不知道隆巴德的秘密目标是生存。你只知道他是一个强大的潜在盟友——或致命的威胁。

隆巴德同样不知道你的目标是成王。他只看到你在一步步获得所有人的信任，他开始怀疑你不是在追凶——你在策划更大的事情。他需要做出选择：追随你，获得庇护？还是在你成为不可战胜的存在之前，先下手为强？

如果你是成王者，另一位玩家是维拉（嫁祸）。维拉正在试图让布伦特被指认为凶手。维拉的行为正在制造混乱——这对你既是机会，也是威胁。混乱让你更容易展示掌控力，但如果你不控制维拉，她可能毁掉你精心建立的秩序。


## 四、“成王”与其他目标的区别

| 目标 | 核心驱动力 | 对其他人态度 | 终局状态 |
| :--- | :--- | :--- | :--- |
| **全灭** | 审判 | 消灭所有罪人 | 无人幸存 |
| **成王** | 掌控 | 让所有人臣服或追随 | 幸存者臣服于成王者 |
| **生存** | 活命 | 自保优先 | 活到暴风雨结束 |
| **追凶** | 正义/解谜 | 找出真相 | 真凶被指认 |


## 五、为什么“成王”特别适合《开本》？

“成王”不是传统游戏中的“赢得比赛”——它是“活成一段传奇”。《开本》的所有核心系统——司命的叙事催化、角色智能体的独立人格、高阶知识图谱的信息不对称、ESM的环境物理规则——都在支撑同一个目标：让每一局“成王”都是一段独一无二的、不可复制的仪式。

就像《诡秘之主》中，每一个序列的晋升都是一段故事，而不是一个数值。《开本》中的“成王”，也是如此——你需要的不是刷够“威望值”，而是完成一段只有你自己知道的、被司命默默监控的叙事仪式。当隆巴德对你说“你赢了”时，那不是系统的通知，那是一个拥有独立人格的AI角色，基于他自己的心智模型，在那一刻做出的真实决定。
