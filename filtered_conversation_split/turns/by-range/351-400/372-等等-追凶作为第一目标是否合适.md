## 用户

等等，追凶作为第一目标是否合适？

## DeepSeek

你的质疑非常精准。将“追凶”作为所有角色的第一层公共目标，确实存在深层矛盾——它强行统一了所有人的核心驱动力，消解了角色之间的动机差异，让那些不想追凶、只想生存或复仇的角色变得“出戏”。

正确的设计应该是：**追凶是可选目标，而非强制目标。**


## 一、为什么“追凶”不适合作为所有人的第一目标？

| 问题 | 说明 |
| :--- | :--- |
| **消解动机差异** | 不是所有人都想找出真相。有人只想活命（生存），有人想亲手惩罚罪人（复仇），有人想逃离孤岛（逃脱），有人想赎罪（坦白）。强制所有人以追凶为首要目标，等于抹平了这些差异 |
| **角色与目标的内在矛盾** | 如果隆巴德的第一目标是追凶，他为什么还要扼杀布伦特？如果维拉的第一目标是追凶，她为什么还要嫁祸布伦特？追凶与这些角色的秘密目标存在直接冲突——而冲突应该是角色扮演的一部分，不是设计缺陷 |
| **伪装系统的失效** | 如果所有人都公开宣称“我要找出真凶”，那伪装系统就失去了意义。真正的凶手也会假装追凶——但这是他被迫的表演，而非他的真实动机 |
| **弱化多目标博弈的深度** | 我们刚设计完30种游戏目标，就是为了让不同角色有不同的核心驱动力。如果第一层就用追凶统一了所有人，那么多目标系统的价值就被削弱了 |


## 二、修正方案：以“生存”或“审判”为公共框架

《无人生还》的核心张力不是“谁杀了人”——而是“我们都被困在这里，我们都有罪，我们都可能死”。因此，更适合作为公共框架的目标是：

**方案A：生存框架**

> **公共目标**：在暴风雨结束前，尽可能多地存活下来。死的人越多，幸存者面临的威胁越大——因为凶手可能就在你们中间。

- 所有人都有生存的动机
- 但每个人对“如何生存”的理解不同——有人选择合作追凶，有人选择独自躲藏，有人选择先发制人
- 追凶成为生存的手段，而非强制目标

**方案B：审判框架**

> **公共目标**：揭露唱片中指控的所有罪行的真相。每个人都被指控犯有谋杀罪——在暴风雨结束前，你们必须面对自己的过去。

- 所有人都有面对审判的压力
- 但每个人对“如何面对审判”的反应不同——有人选择忏悔，有人选择抵抗，有人选择逃避，有人选择先审判别人
- 追凶成为审判的一部分，而非强制目标


## 三、修正后的目标层级结构

| 层级 | 目标类型 | 说明 |
| :--- | :--- | :--- |
| **第一层：公共目标** | 生存（或审判） | 所有人共享。确保游戏有最基本的共同驱动力。不强制追凶 |
| **第二层：阵营目标** | 可变 | 同一阵营成员共享。可以是“罪人阵营”（互相掩护）、“审判者阵营”（确保正义降临）等 |
| **第三层：个人目标** | 秘密 | 只有玩家自己知道。可以是追凶、复仇、逃脱、守护、坦白等30种目标中的任意一种 |

**追凶不再是强制目标——它成为个人目标池中的一个选项。** 那些适合追凶的角色（如沃格雷夫法官、阿姆斯特朗医生）可以分配追凶目标；那些不适合追凶的角色（如隆巴德、维拉）可以分配生存、复仇、嫁祸等目标。

## 五、修正后的设计原则

| 原则 | 说明 |
| :--- | :--- |
| **公共目标只提供框架，不指定路径** | 所有人都想活下来——但“如何活下来”是每个人自己的选择。有人选择合作，有人选择对抗，有人选择逃避 |
| **追凶是手段，不是目的** | 追凶是某些角色为了达成个人目标而选择的手段，而非所有人的强制义务。沃格雷夫追凶是为了审判，维拉追凶是为了掩护自己的嫁祸计划，隆巴德可能根本不关心真相 |
| **角色与目标的匹配由人格驱动** | 谁适合什么目标，由角色的人格档案决定。沃格雷夫的正义感10让他天然适合追凶，隆巴德的胆量9让他天然适合生存，艾瑟尔的共情8让她天然适合坦白 |
| **公共目标也需要伪装** | 即使所有人都公开宣称“我们要活下去”，但每个人的真实动机仍然是隐藏的。这正是伪装系统和知情人网络发挥作用的空间 |


## 六、一句话总结

“追凶”不适合作为所有角色的第一层公共目标——它强行统一了所有人的核心驱动力，消解了多目标博弈的深度。正确的设计是：以“生存”或“审判”为公共框架，追凶作为可选个人目标之一，由角色的人格档案驱动分配。这样，每一局中不同角色的核心驱动力都不同，但都在同一个公共框架下共存——这正是《开本》多目标博弈的核心魅力。
