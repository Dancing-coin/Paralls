# 《开本》全目标玩法系统完整设计

## 一、核心问题诊断

我们当前设计的系统，确实在“追凶”目标上最为完整——案件生成、线索管理、投票机制、伪装系统、知情人网络、暗杀机制、阴谋系统、证据链协同，几乎全部围绕“找出真相”这一核心循环。

但当我们试图支持“生存”、“逃脱”、“复仇”、“守护”、“全灭”等其他目标时，发现许多系统需要重新设计——不是修补，而是在底层架构上支持“目标中立”的通用系统。

### 当前系统对各类目标的支持度

| 目标类型 | 当前支持度 | 缺失的关键系统 |
| :--- | :--- | :--- |
| **追凶** | ★★★★★ 完整 | — |
| **逃脱（凶手）** | ★★★★☆ 较完整 | 伪装、知情人已有，但逃脱路径规划缺失 |
| **生存** | ★★★☆☆ 部分 | 威胁感知、庇护所、资源管理、时间压力系统未设计 |
| **守护** | ★★☆☆☆ 基础 | 威胁评估、保护措施、牺牲机制未设计 |
| **全灭** | ★★☆☆☆ 基础 | 死亡顺序策划、多种致死手段整合、意外管理未设计 |
| **嫁祸** | ★★☆☆☆ 基础 | 证据转移、嫌疑引导未系统化 |
| **逃脱（空间）** | ★☆☆☆☆ 极少 | 密道机关、道具组合、障碍破坏、时间窗口未设计 |
| **复仇** | ★☆☆☆☆ 极少 | 目标确认、复仇手段选择、道德代价未设计 |
| **共谋/背叛** | ★☆☆☆☆ 极少 | 共谋系统仅初步设计，信任门槛、背叛机制未完整 |
| **坦白/救赎/殉道/成王/记录等** | ☆☆☆☆☆ 无 | 全部缺失 |


## 二、补全设计：通用玩法系统架构

### 2.1 核心原则

**所有系统必须目标中立。** 每个系统不预设“玩家要做什么”——它只提供通用的能力，由玩家的个人目标和AI角色的心智模型驱动具体使用方式。

| 系统 | 目标中立的设计 |
| :--- | :--- |
| **搜证系统** | 不只是“收集线索指认凶手”——任何玩家都可以搜索场景，寻找对自己目标有用的信息。生存者搜索武器，逃脱者搜索钥匙，复仇者搜索仇人的行踪 |
| **对话系统** | 不只是“审讯嫌疑人”——任何玩家都可以与任何角色自由对话，试探、套话、结盟、威胁、欺骗 |
| **暗杀系统** | 不只是“凶手灭口”——任何满足条件的角色都可以执行暗杀。生存者可以先发制人，复仇者可以手刃仇人，全灭者可以逐个处决 |
| **阴谋系统** | 不只是“掩盖罪行”——任何需要隐秘行动的目标都可以使用。逃脱者可以制造混乱掩护逃跑，嫁祸者可以伪造现场，守护者可以设置陷阱保护对象 |


### 2.2 新设计的通用系统

#### 2.2.1 威胁感知系统

| 要素 | 设计 |
| :--- | :--- |
| **威胁源识别** | 司命基于角色的个人目标和当前局势，向角色推送威胁信号——不是系统提示，而是角色直觉。AI角色通过内心独白感知威胁，人类玩家通过同样的内心独白文字获得提示 |
| **威胁等级评估** | 每个角色对其他角色的威胁等级由司命后台计算——暗杀能力、敌对目标、距离、行动模式。威胁等级影响角色的压力值和决策倾向 |
| **威胁可视化** | 在笔记面板中，角色可查看“威胁评估”视图——基于自己已知的信息，标注谁可能是威胁。这个视图不是客观真相，而是角色的主观判断，可能出错 |

**适用目标**：生存、守护、全灭、复仇、逃脱

#### 2.2.2 庇护所与防御系统

| 要素 | 设计 |
| :--- | :--- |
| **可防御空间** | 场景中存在可锁定的房间、可堵住的门、可设置陷阱的走廊。ESM管理这些空间的物理状态——门的锁是否完好、窗户是否能打开 |
| **防御工事** | 玩家可以拖拽家具堵门、用绳子设置绊索、在门口堆放杂物制造噪音预警。这些操作由物品交互系统支持 |
| **庇护所持久性** | 庇护所不是永久的——门锁可能被撬开（ESM物理破坏），窗户可能被暴风雪击碎（天气系统），杂物可能被清理 |
| **安全时间窗口** | 某些时段庇护所更安全（白天众人都在客厅时），某些时段更危险（深夜众人分散时）。司命管理这些节奏 |

**适用目标**：生存、守护

#### 2.2.3 资源管理与消耗系统

| 要素 | 设计 |
| :--- | :--- |
| **可收集资源** | 食物、药品、工具、武器——散落在场景各处。物品流转追踪器记录资源的归属和消耗 |
| **资源有限性** | 资源总量固定，争夺不可避免。生存者需要囤积，守护者需要为守护对象储备，全灭者可能破坏资源来加速他人死亡 |
| **资源消耗** | 食物随时间消耗（饥饿值驱动），药品用于治疗伤势，工具的耐久度在使用中降低 |
| **资源争夺** | 玩家可以偷窃他人的资源（潜行+物品交互），可以用资源交换信息或结盟，可以破坏资源以削弱他人 |

**适用目标**：生存、守护、全灭、逃脱

#### 2.2.4 时间压力系统

| 要素 | 设计 |
| :--- | :--- |
| **倒计时机制** | 暴风雨结束的时间、救援到达的时间、黎明破晓的时间——司命管理全局倒计时。倒计时对所有玩家公开 |
| **阶段性威胁升级** | 随着时间推移，威胁逐渐升级——暴风雪加剧导致庇护所不再安全，暗杀者的耐心耗尽导致更激进的行动，食物耗尽导致生存危机 |
| **时间窗口** | 某些行动只能在特定时间执行——密道只在深夜开启，庇护所的防御在暴风雪最猛烈时最薄弱，逃脱的最佳时机是守卫换班的间隙 |

**适用目标**：生存、逃脱、全灭、追凶（投票的截止时间）

#### 2.2.5 密道、机关与逃脱系统

| 要素 | 设计 |
| :--- | :--- |
| **隐藏密道** | 场景中存在隐藏的密道、暗门、通风管道。开启条件由ESM管理——需要特定钥匙、需要破解密码、需要特定时间、需要多人协作 |
| **道具组合** | 逃脱者可以从场景中收集多种道具，进行组合使用。组合配方在每次开局时随机变化 |
| **障碍与破坏** | ESM管理出口的可达性。密道的门可能因年久失修而卡住，窗户可能被封死。其他玩家也可以主动破坏出口——全灭者或复仇者可能封死逃生路线 |
| **伪装与欺骗** | 逃脱者需要在行动时保持低调。潜行移动姿态降低被感知概率，制造噪音将其他人的注意力引开 |

**适用目标**：逃脱（空间）、生存

#### 2.2.6 复仇系统

| 要素 | 设计 |
| :--- | :--- |
| **目标确认** | 复仇者开局时知道自己的仇恨来源——但不知道仇人具体是谁（只知罪行，不知身份）。需要通过对话、搜证、观察微表情来确认。一旦确认，压力值急剧变化 |
| **复仇手段选择** | 暗杀（暗杀系统）、环境致死（ESM物理规则）、公开揭露（投票环节）、陷害嫁祸（阴谋系统）。每种手段有不同的风险和道德代价 |
| **道德代价** | 复仇行为产生道德代价——高共情者复仇后感到空虚，低共情者感到解脱。道德代价影响后续行为和结局叙事 |

**适用目标**：复仇

#### 2.2.7 守护系统

| 要素 | 设计 |
| :--- | :--- |
| **威胁评估** | 守护者需要持续评估周边威胁——谁可能对守护对象不利？通过观察微表情、偷听对话、阅读笔记来收集情报 |
| **保护措施** | 陪同守护对象（清晰区内随时干预）、转移守护对象到安全区域、警告潜在威胁者、主动消除威胁（先发制人）、伪造守护对象的死亡 |
| **牺牲机制** | 守护者可以在关键时刻牺牲自己——为守护对象挡刀（在暗杀的阶段化感知中主动介入）、替守护对象顶罪（投票环节） |

**适用目标**：守护

#### 2.2.8 全灭系统

| 要素 | 设计 |
| :--- | :--- |
| **死亡顺序策划** | 全灭者需要制定策略——先杀谁、后杀谁。先杀威胁最大的人，还是先杀最脆弱的人？ |
| **多种致死手段整合** | 全灭者可以调用所有致死手段——暗杀、环境致死、蓄意破坏、心理逼迫、嫁祸。全灭系统提供统一的“手段选择”界面 |
| **意外管理** | 目标的反击、目击者的出现、司命的催化。全灭者需要实时调整计划 |
| **终局验证** | 全灭者需要在终局时确认所有目标都已死亡。如果有人幸存，全灭者失败 |

**适用目标**：全灭

#### 2.2.9 嫁祸系统

| 要素 | 设计 |
| :--- | :--- |
| **证据转移** | 嫁祸者可以将凶器、物证放置在他人的物品或活动区域（物品流转追踪器记录，但转移过程可能被目击） |
| **嫌疑引导** | 嫁祸者在对话中埋下对目标不利的暗示，在搜证时将线索指向目标 |
| **不在场伪造** | 嫁祸者需要确保自己在嫁祸行为发生时有可靠的不在场证明 |

**适用目标**：嫁祸

#### 2.2.10 共谋与背叛系统

| 要素 | 设计 |
| :--- | :--- |
| **共谋邀约** | 发起者使用耳语模式向潜在共谋者发出邀请。被邀者是否接受取决于信任值 |
| **信任门槛** | 信任值≥7→接受；信任值4-6→犹豫；信任值≤3→拒绝，甚至告密 |
| **条件协商** | 共谋者可就行动方案、分工、分赃进行协商（LLM驱动的自由对话） |
| **背叛机制** | 共谋者可在任何阶段背叛——告密、反水、独吞成果。由人格档案中的诚实度和忠诚度决定背叛概率 |

**适用目标**：共谋、背叛、反水


## 三、司命的角色跃升：从“追凶导演”到“目标中立的叙事催化者”

| 司命职责 | 当前设计（追凶导向） | 全目标升级 |
| :--- | :--- | :--- |
| **事实核心** | 管理案件事实、时间线矛盾 | 管理所有类型的目标相关事实——生存者的资源消耗、逃脱者的密道状态、复仇者的仇人身份确认、全灭者的死亡清单 |
| **天平系统** | 管理追凶方vs逃脱方的线索平衡 | 管理所有目标的完成概率——某目标过于容易或过于困难时催化干预 |
| **冲突与案件生成器** | 生成新案件 | 生成所有类型的冲突——生存者与全灭者的对抗、守护者与复仇者的对抗、共谋者内部的背叛 |
| **干预执行器** | 催化暗杀机会 | 催化所有类型的关键事件——庇护所的破坏、密道的意外发现、仇人身份的意外暴露、共谋者之间的猜忌 |
| **结局判定** | 投票指认真凶 | 多目标结局判定——生存者是否存活、逃脱者是否成功、复仇者是否完成复仇、全灭者是否完成全灭 |


## 四、重玩价值的通用设计

| 变量 | 每次开局的变化 | 支持的目标 |
| :--- | :--- | :--- |
| **目标分配** | 同一角色在不同局中可能分配不同目标 | 所有目标 |
| **目标组合** | 不同角色之间的目标组合每次都不同 | 所有目标 |
| **环境条件** | ESM管理的物理状态、天气、资源分布每次都不同 | 生存、逃脱、全灭 |
| **密道与机关** | 出口位置、开启条件、所需道具每次都不同 | 逃脱 |
| **仇人身份** | 复仇者的仇人从角色池中随机锁定 | 复仇 |
| **庇护所状态** | 门的锁、窗的完整性、可用家具每次都不同 | 生存、守护 |
| **资源分布** | 食物、药品、工具的位置和数量每次都不同 | 生存、全灭 |


## 五、一句话总结

要让《开本》支持全部30种游戏目标，核心是进行“目标中立”的底层架构升级——所有玩法系统不再预设“玩家在追凶”，而是提供通用的能力（搜证、暗杀、阴谋、对话、资源管理、庇护所、密道探索），由玩家的个人目标和AI角色的心智模型驱动具体使用方式。司命从“追凶导演”跃升为“目标中立的叙事催化者”，管理所有类型目标的冲突、平衡和结局判定。重玩价值来自目标分配的随机性、目标组合的多样性，以及ESM物理规则驱动的环境变化。
