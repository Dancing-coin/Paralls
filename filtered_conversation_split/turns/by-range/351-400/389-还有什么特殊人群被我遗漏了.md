# 《开本》可扮演的特殊人群

你总结的侦探、罪犯、特工三种身份确实覆盖了核心，但《开本》的系统中还能支撑更多特殊人群。以下是完整的特殊人群清单：


## 一、你已总结的三种

| 身份 | 核心玩法 | 核心系统支撑 |
| :--- | :--- | :--- |
| **侦探** | 搜证、推理、审讯、还原真相 | 线索系统、案件引擎、笔记推理、凝神能力 |
| **罪犯** | 伪装、撒谎、销毁证据、逃脱制裁 | 伪装系统、知情人网络、暗杀与阴谋、ESM物理销毁 |
| **特工** | 信息操纵、环境利用、嫁祸、伪装渗透 | 高阶知识图谱、阴谋系统、伪装系统、感知系统 |


## 二、你遗漏的特殊人群

### 1. 守护者（保镖、护卫、监护人）

| 维度 | 说明 |
| :--- | :--- |
| **核心玩法** | 威胁评估、贴身保护、牺牲抉择 |
| **核心系统支撑** | 威胁感知系统、庇护所机制、暗杀阶段化感知（可在P0级介入保护）、牺牲机制 |
| **典型角色** | 贴身保镖守护证人、姐姐保护年幼的弟弟、老管家守护家族的秘密 |
| **与其他身份的关系** | 守护者是罪犯的天敌、侦探的盟友。当守护对象就是罪犯时，守护者面临最艰难的道德抉择 |

### 2. 记录者（记者、史官、作家、侦探助手）

| 维度 | 说明 |
| :--- | :--- |
| **核心玩法** | 观察、记录、整理、保存、传播 |
| **核心系统支撑** | 笔记系统（完整的时间线、关系图、证据链）、L3视觉增强（自动生成事件插画）、留影石/相机 |
| **典型角色** | 战地记者被困在暴风雪山庄、史官记录宫廷阴谋、华生医生记录福尔摩斯的推理 |
| **与其他身份的关系** | 记录者是所有人的潜在威胁——他们记录的东西可能成为证据，也可能成为被灭口的原因 |

### 3. 伪装者（冒名顶替者、卧底、间谍）

| 维度 | 说明 |
| :--- | :--- |
| **核心玩法** | 身份伪造、信息渗透、双重忠诚、暴露风险管理 |
| **核心系统支撑** | 伪装系统（深度伪装+物理道具）、知情人网络（知道秘密的人）、高阶知识（谁知道我是假的）、压力系统（伪装维持的压力） |
| **典型角色** | 冒名顶替的遗产继承人、潜入黑帮的卧底警察、假冒贵族的女仆 |
| **与特工的区别** | 特工的核心是“信息操纵”，伪装者的核心是“身份伪造”。特工可以不伪装身份只操纵信息，伪装者必须维持一个虚假的身份 |

### 4. 逃脱者（囚犯、人质、被困者）

| 维度 | 说明 |
| :--- | :--- |
| **核心玩法** | 环境观察、道具收集与组合、机关破解、时机把握 |
| **核心系统支撑** | 密道与机关系统、道具组合系统、ESM物理规则（障碍破坏）、潜行移动姿态 |
| **典型角色** | 被冤枉入狱的囚犯、被连环杀手困在地下室的人质、暴风雪中被困的旅人 |
| **与其他身份的关系** | 逃脱者可能是罪犯（畏罪潜逃），也可能是无辜者（逃离真凶的追杀） |

### 5. 审判者（私刑者、复仇者、自封的法官）

| 维度 | 说明 |
| :--- | :--- |
| **核心玩法** | 目标确认、罪责认定、刑罚执行、道德代价 |
| **核心系统支撑** | 复仇系统（目标确认+手段选择+道德代价）、暗杀系统、环境致死机制、阴谋系统 |
| **典型角色** | 《无人生还》的沃格雷夫法官、为女儿复仇的父亲、替天行道的义贼 |
| **与罪犯的区别** | 罪犯逃避法律，审判者自认高于法律。罪犯的目标是“不被发现”，审判者的目标是“让罪人付出代价” |

### 6. 生存者（末日幸存者、大逃杀参与者）

| 维度 | 说明 |
| :--- | :--- |
| **核心玩法** | 资源管理、威胁规避、庇护所争夺、最后生还 |
| **核心系统支撑** | 威胁感知系统、庇护所系统、资源管理系统、时间压力系统 |
| **典型角色** | 孤岛上的十个小士兵、末日避难所的最后幸存者、大逃杀中的参与者 |
| **与其他身份的关系** | 生存者可能是无辜者（只想活命），也可能是罪犯（为了活命什么都干得出来） |

### 7. 操纵者（幕后黑手、阴谋家、策士）

| 维度 | 说明 |
| :--- | :--- |
| **核心玩法** | 暗中引导、借刀杀人、信息操控、代理人战争 |
| **核心系统支撑** | 高阶知识图谱、共谋与背叛系统、司命催化（操纵者可利用司命的催化为自己服务）、知情人网络 |
| **典型角色** | 莫里亚蒂式的犯罪顾问、宫廷中操纵王位继承的太后、在不在场的情况下策划整场阴谋的天才 |
| **与特工的区别** | 特工执行信息操纵，操纵者策划信息操纵。操纵者本人可能从未亲手做过任何事，但所有人的行为都在他的计算之中 |


## 三、特殊人群的身份组合

同一角色可能兼具多种特殊人群的特征。司命基于角色人格档案分配目标时，会考虑这种组合：

| 角色 | 身份组合 | 目标分配 |
| :--- | :--- | :--- |
| 沃格雷夫法官 | 审判者 + 侦探 | 追凶（侦探面）或 全灭（审判者面） |
| 隆巴德上尉 | 生存者 + 罪犯 | 生存（确保自己活命，必要时可杀人） |
| 维拉·克莱索恩 | 伪装者 + 罪犯 | 嫁祸（她需要维持无辜的伪装，同时把嫌疑引向布伦特） |
| 阿姆斯特朗医生 | 逃脱者 + 罪犯 | 逃脱（他无法承受审判的压力，必须逃离孤岛） |
| 华生医生 | 记录者 + 侦探助手 | 记录（记录福尔摩斯的推理，确保真相被保存） |
| 艾琳·艾德勒 | 特工 + 伪装者 | 逃脱（她以伪装身份渗透案件，需要在暴露前获取情报并安全撤离） |


## 四、一句话总结

《开本》可扮演的特殊人群远不止侦探、罪犯、特工三种。完整的特殊人群图谱包括：**侦探、罪犯、特工、守护者、记录者、伪装者、逃脱者、审判者、生存者、操纵者**——共十种。每种人群都有独特的核心玩法、专属系统支撑、以及与其他身份的关系网络。同一角色可能兼具多种身份特征，司命基于角色人格档案分配目标时，会考虑这种身份组合。
