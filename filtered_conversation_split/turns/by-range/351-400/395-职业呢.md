## 三、职业的跨人群重叠

同一职业可能属于不同人群，取决于其持有者的行为模式：

| 职业 | 可归属的人群 | 区分方式 |
| :--- | :--- | :--- |
| **私家侦探** | 调查者 / 操控者 | 如果他只为搜集真相，是调查者；如果他同时为雇主操控信息，是操控者 |
| **卧底警察** | 操控者 / 伪装者 / 调查者 | 三者兼具——操控信息流向、维持虚假身份、还原真相 |
| **战地记者** | 记录者 / 生存者 / 调查者 | 记录真相 + 在战火中生存 + 主动搜集情报 |
| **黑客** | 隐匿者 / 调查者 / 审判者 | 入侵系统窃取数据（隐匿者）、追踪犯罪（调查者）、曝光不义（审判者） |
| **保镖** | 守护者 / 生存者 | 保护义务 + 自保本能 |
| **律师** | 守护者 / 操控者 | 为当事人辩护（守护者）、操控法庭信息流向（操控者） |


## 四、一句话总结

十一种特殊人群映射到四个时代，每种人群对应数十种具体职业。同一职业可能横跨多个人群，取决于角色在游戏中的目标分配和行为模式。职业是人群在特定世界观中的具象化——《开本》的平行世界架构让同一人群在不同世界中披上不同的职业外衣，但其核心的行为性质、社会关系和信息立场始终不变。
