## DeepSeek

# 《开本》游戏系统整体框架

## 一、核心玩法类型

| 玩法类型 | 核心体验 | 典型剧本模式 | 关键系统支撑 |
| :--- | :--- | :--- | :--- |
| **搜证推理** | 通过搜集线索、分析证据、逻辑推理找出真相 | 谋杀之谜、密室逃脱、法庭推理 | 案件生成引擎、线索系统、物品流转追踪器、接触痕迹管理器 |
| **社交博弈** | 通过对话、欺骗、结盟、背叛达成个人目标 | 阵营对抗、生存博弈、心理战 | 伪装系统、知情人网络、高阶知识图谱、空间音频 |
| **策略经营** | 通过资源管理、战略决策达成长期目标 | SLG战争、种田经营、城邦建设 | ESM环境状态管理器、群体模拟引擎、资源与商品体系 |
| **生存挑战** | 在有限资源和持续威胁下坚持存活 | 暴风雪山庄、末日求生、大逃杀 | 暗杀系统、环境致死机制、庇护所系统、资源管理系统 |
| **叙事扮演** | 以角色身份体验故事，做出选择影响结局 | 恋爱本、情感本、史诗系列 | 角色智能体心智模型、司命叙事引擎、记忆系统 |


## 二、游戏目标体系

### 2.1 目标层级

| 层级 | 定义 | 分配方式 | 知情范围 |
| :--- | :--- | :--- | :--- |
| **个人目标** | 每个角色的秘密目标。是角色人格的延伸，不是系统强加的任务 | 司命基于角色人格档案在T2时刻分配 | 仅自己知道 |
| **共同目标** | 部分角色因共同利益而共享的目标。形成阵营 | 司命基于角色关系和随机因素分配 | 阵营内部知道 |
| **隐藏目标** | 游戏过程中因特定事件触发而注入的新目标 | 司命在游戏过程中动态注入 | 仅自己知道 |

### 2.2 个人目标分类

**核心对抗类**：

| 目标 | 描述 | 典型人格驱动 |
| :--- | :--- | :--- |
| **追凶** | 在投票环节指认真凶 | 正义感高、理性高 |
| **逃脱** | 作为真凶不被指认 | 心机高、胆量中 |
| **生存** | 在规定时间内存活 | 胆量中、共情低 |
| **守护** | 确保指定角色存活 | 忠诚高、共情高 |
| **全灭** | 确保所有人死亡 | 正义感极高、共情极低 |
| **复仇** | 亲手惩罚指定角色 | 胆量高、共情低 |

**竞争对抗类**：

| 目标 | 描述 | 典型人格驱动 |
| :--- | :--- | :--- |
| **嫁祸** | 让指定角色被指认为凶手 | 心机高、共情低 |
| **独吞** | 私藏场景中的关键财物 | 心机高、胆量中 |
| **抢先** | 在其他玩家之前完成特定行动 | 胆量高、理性中 |
| **阻止** | 阻止指定玩家完成其目标 | 心机高、理性高 |
| **反杀** | 在被暗杀时反杀暗杀者 | 胆量极高、理性中 |

**社交心理类**：

| 目标 | 描述 | 典型人格驱动 |
| :--- | :--- | :--- |
| **共谋** | 与指定角色建立秘密联盟 | 社交高、心机中 |
| **背叛** | 在关键时刻背叛盟友 | 心机高、忠诚低 |
| **坦白** | 主动坦白罪行寻求解脱 | 共情高、压力高 |
| **恐吓** | 利用信息勒索其他角色 | 心机高、共情低 |
| **孤立** | 让指定角色被所有人孤立 | 心机极高、共情低 |

**探索解谜类**：

| 目标 | 描述 | 典型人格驱动 |
| :--- | :--- | :--- |
| **逃脱** | 找到离开封闭场景的方法 | 理性高、胆量中 |
| **寻宝** | 找到场景中隐藏的特定物品 | 理性中、胆量中 |
| **解谜** | 破解场景中的机关或谜题 | 理性极高 |
| **测绘** | 记录并绘制完整地图 | 理性高、胆量低 |
| **收集** | 收集所有与某主题相关的物品 | 理性中、共情中 |

**叙事扮演类**：

| 目标 | 描述 | 典型人格驱动 |
| :--- | :--- | :--- |
| **救赎** | 通过保护他人或揭露真相来赎罪 | 共情高、正义感中 |
| **殉道** | 主动牺牲自己保护他人 | 忠诚极高、胆量中 |
| **成王** | 成为最后的掌控者 | 胆量极高、心机极高 |
| **记录** | 记录下发生的一切 | 理性高、胆量低 |

**隐藏特殊类**：

| 目标 | 描述 | 注入时机 |
| :--- | :--- | :--- |
| **觉醒** | 发现自己的真实身份，初始目标被推翻 | 发现关键线索或达到特定压力值时 |
| **反水** | 发现真凶是自己最在乎的人，切换为守护凶手 | 发现真凶身份的瞬间 |
| **灭口** | 目击者看到了不该看的东西，让他闭嘴 | 被目击的瞬间 |
| **继承** | 关键角色死前将秘密托付给你 | 被托付的瞬间 |
| **揭开世界之谜** | 发现案件指向更大的世界秘密 | 满足极稀有的触发条件时 |


### 三、任务系统

任务是达成目标的具体路径。每个目标对应一组可选任务，玩家通过执行任务推进目标。

| 任务类别 | 具体任务 | 依赖系统 |
| :--- | :--- | :--- |
| **信息获取** | 搜查场景、检查物品、观察角色、偷听对话、询问证人 | 线索系统、感知过滤器、空间音频 |
| **物品操作** | 拾取物品、使用物品、组合物品、销毁物品、藏匿物品 | 物品流转追踪器、ESM |
| **社交互动** | 公开对话、私密耳语、展示证据、移交物品、邀请同行、威胁恐吓 | 对话生成系统、知情人网络 |
| **策略行动** | 暗杀、环境致死、蓄意破坏、伪造现场、布置陷阱 | 阴谋系统、暗杀系统、ESM |
| **推理分析** | 比对时间线、构建证据链、标记嫌疑人、排除不可能 | 笔记系统、司命事实核心 |
| **移动探索** | 进入新区域、发现密道、攀爬翻越、潜行移动 | 场景交互系统、ESM |
| **决策投票** | 公开指认、投票表决、认罪坦白、提出动议 | 投票系统、结局判定 |
| **资源管理** | 收集资源、分配物资、建造设施、交易物品 | 资源与商品体系、ESM |


### 四、阵营系统

| 维度 | 选项 | 说明 |
| :--- | :--- | :--- |
| **阵营可见性** | 明面阵营 / 暗面阵营 | 所有人知情 / 仅阵营内部知情 |
| **阵营稳定性** | 固定阵营 / 动态阵营 | 成员不变 / 成员可流动 |
| **阵营形成方式** | 预设阵营 / 招募形成 / 自发结盟 | 剧本预设 / 成员招募 / 玩家自主 |
| **阵营内部结构** | 统一阵营 / 派系分化 | 意见一致 / 存在分歧 |


### 五、角色与目标的匹配规则

| 规则 | 说明 |
| :--- | :--- |
| **人格驱动** | 目标由角色的人格档案决定。高正义感者适合追凶或审判，高胆量者适合生存或复仇，高共情者适合守护或坦白 |
| **负荷均衡** | 每局所有玩家的目标负荷值总和大致相当，避免出现“一人忙碌、他人摸鱼”的不平衡 |
| **冲突设计** | 同一局中至少50%的玩家拥有主动型目标，确保足够的博弈驱动力。部分目标之间存在天然的冲突或合作 |
| **动态注入** | 隐藏目标在游戏过程中因特定事件触发而注入，初始目标可能被推翻 |


### 六、司命在玩法系统中的角色

| 职责 | 说明 |
| :--- | :--- |
| **目标分配** | T2时刻基于角色人格档案分配个人目标；管理共同目标的阵营分配 |
| **动态注入** | 监控游戏进程，在满足条件时注入隐藏目标 |
| **平衡监控** | 监控所有玩家的目标完成概率，必要时进行隐形干预 |
| **阵营管理** | 追踪阵营状态变化，催化阵营冲突或合作 |
| **目标失效处理** | 当目标因角色死亡、目标已死等原因失效时，自动注入替代目标 |

**一句话总结**：《开本》的玩法框架由“玩法类型→目标体系→任务系统→阵营系统”四层构成。六种核心玩法类型定义了游戏的基本体验，30种游戏目标让每个角色拥有独特的驱动力，八类任务提供了达成目标的具体手段，四种维度的阵营系统让玩家在合作与对抗中形成复杂的社交博弈。司命在所有层级中扮演分配、监控、催化和平衡的角色。
