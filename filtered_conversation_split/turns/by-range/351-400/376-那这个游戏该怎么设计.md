# 《无人生还·罪与罚》游戏设计


## 一、核心设计理念

《无人生还》的核心张力不是“隐瞒罪行”，而是“如何面对已经被公开揭露的罪行”。每个人都是已知的罪人，每个人都必须在这座孤岛上面对自己的过去。司命不分配“隐藏秘密”的目标，而是分配“如何面对罪行”的目标。

## 四、开局前固定剧情（T0-T1）

1939年8月，英国德文郡海岸外的士兵岛。八个人被不同的邀请函召集到岛上。暴风雨如期而至。晚餐后，留声机播报揭露了八人各自的罪行。所有人都知道彼此是罪人。所有人都被困在暴风雨中。

沃格雷夫放下酒杯，环顾所有人：“唱片指控了我们所有人。如果有谁是无辜的，现在可以为自己辩护。”没有人说话。“那么，”他说，“正义终将到来。”


## 五、可玩性设计：玩家如何玩

### 单人模式：1真人 + 7 AI智能体

**你的角色由意向志愿系统分配。** 开局前，你看到八张角色卡片，每张只有人格侧写和玩法倾向，没有具体目标和秘密。你按志愿顺序选择最感兴趣的三个角色，系统根据你的偏好和本局随机种子分配给你其中一个。

| 你扮演的角色 | 你的秘密目标 | 你的核心玩法 |
| :--- | :--- | :--- |
| **沃格雷夫** | 追凶——找出所有命案的真凶 | 观察每个人的行为，收集线索，在投票环节指认真凶。你的审判者身份让你天然具有号召力——你可以招募愿意忏悔的人加入你的阵营 |
| **维拉** | 嫁祸——让布伦特被指认为凶手 | 在对话中埋下对布伦特不利的暗示，在搜证时将嫌疑指向布伦特。你需要确保其他玩家相信布伦特是凶手——但你自己不能暴露 |
| **隆巴德** | 生存——确保自己活到暴风雨结束 | 收集武器、占据安全位置、评估每个人的威胁等级。你可以与麦肯锡结盟——但记住，他可能随时背叛你 |
| **布伦特** | 救赎——保护维拉 | 你不知道维拉正在嫁祸给你。你要在投票时为维拉辩护，在有人威胁她时站出来。你的救赎能否被维拉接受——取决于她的选择 |
| **麦肯锡** | 生存——确保自己和隆巴德存活 | 与隆巴德形成求生者阵营。你们可以互相作证、协同监视、在必要时联手反制威胁 |
| **阿姆斯特朗** | 逃脱——找到离开孤岛的方法 | 探索密道、收集工具、破解机关。你需要在所有人发现你消失之前完成逃脱。如果被罪人阵营发现——他们可能会阻止你 |
| **托马斯** | 守护——确保艾瑟尔存活 | 时刻注意妻子的状态，阻止任何可能威胁她的人。如果她死了——你的目标自动切换为复仇 |
| **艾瑟尔** | 坦白——在投票前主动坦白罪行 | 你需要选择坦白的时机——太早可能被利用，太晚可能无法解脱。如果你向沃格雷夫坦白，他会招募你加入审判者阵营 |

**AI角色的行为**：七个AI角色由心智模型驱动，根据各自的秘密目标自主行动。你会看到沃格雷夫在观察所有人，隆巴德和麦肯锡在低声交谈，艾瑟尔在独处时流泪。他们不知道你的目标，你也不知道他们的。只能通过行为推断。

**凝神能力**：单人模式下，你可以随时暂停时间，仔细观察每个人的微表情、检查线索、整理推理笔记。


### 多人模式：2-4真人 + 4-6 AI智能体

**多人模式下，目标系统被激活。** 每个真人玩家都有自己的秘密个人目标。你不知道其他人的目标，只能通过行为推断。

**目标冲突示例**：

如果你扮演维拉（嫁祸布伦特），另一位玩家扮演布伦特（保护维拉）。他不知道你在陷害他，他在用生命保护你。你的每一次嫁祸行为都可能在良心上遭受拷问。你可以在最后关头选择放弃嫁祸——司命会注入新的目标：“觉醒”。

如果你扮演隆巴德（生存），另一位玩家扮演麦肯锡（与隆巴德同盟）。你们是求生者阵营，可以互相作证、共享线索。但他可能在关键时刻背叛你——如果他收到司命的隐藏目标：“反水”。


## 六、司命的催化与动态平衡

- **艾瑟尔坦白后**：若她向沃格雷夫坦白，则被招募进入审判者阵营；若她向托马斯坦白，托马斯可能代替她承担罪行，她自动获得“守护托马斯”的新目标
- **布伦特发现真相后**：布伦特若发现维拉一直在嫁祸自己，她的救赎目标自动失效。司命注入新目标：“觉醒”——重新审视自己的伪善
- **托马斯若失去艾瑟尔**：他的目标从“守护”自动切换为“复仇”，司命为他随机指定一名他认为与艾瑟尔之死有关的角色作为复仇对象
- **罪人阵营若成员死亡**：当罪人阵营只剩一名成员时，阵营自动解散。该成员可能被沃格雷夫招募进入审判者阵营

- **若罪人阵营过于强势**：司命催化该阵营内部矛盾——如让阿姆斯特朗意外发现麦肯锡的旧军报文件，意识到他当年签发了“必死”任务命令
- **若审判者阵营过于强势**：司命为隆巴德推送暗杀机会——“布伦特独自在书房。这是你消除精神威胁的唯一机会”
- **若逃脱计划即将成功**：司命让隆巴德或麦肯锡意外发现地下室的通道，迫使阿姆斯特朗在逃脱被阻止和放弃逃脱之间做出选择


## 七、重玩价值

| 变量 | 每次开局的变化 |
| :--- | :--- |
| **凶手身份** | 从8名角色中随机锁定。每次开局的真凶可能不同 |
| **个人目标分配** | 基于角色人格档案随机分配，同一角色在不同局中可能有不同目标 |
| **阵营组合** | 罪人阵营和审判者阵营的成员构成每次都不同 |
| **目标变化** | 因角色死亡、背叛、觉醒等因素，个人目标可能在游戏过程中变化 |
| **死亡顺序** | 童谣的框架不变，但每局谁先死、谁活到最后、如何死——都不同 |
| **环境条件** | ESM管理的暴风雨强度、庇护所状态、逃生路线可行性每次都不同 |


## 八、一句话总结

《无人生还·罪与罚》的核心不是“隐藏罪行”——罪行已被公开揭露。核心是“如何面对已经被揭露的罪行”。每个人都因共同处境被困在孤岛上，但每个人的目标各不相同。有人在追凶，有人在嫁祸，有人在生存，有人在逃脱，有人在守护，有人在坦白。他们的目标形成阵营，阵营内部可能分化，阵营之间可能冲突。每一次开局，这些目标交织出的故事都完全不同——这才是《开本》改编《无人生还》的真正可玩性所在。
