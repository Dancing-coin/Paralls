# 《开本》玩法、目标、机制、系统完整梳理

## 一、产品定位

**《开本》是一个智能体驱动的3D沉浸式动态叙事平台。** 它不是“一个游戏”，而是一个能长出无限游戏的世界生态。它的核心价值在于：让玩家在无数平行世界中，与拥有独立人格的AI角色共同经历独一无二的故事。

**设计哲学**：
- **涌现而非预设**：故事不是写死的，是由玩家、AI和司命共同实时创造的
- **羁绊而非工具**：AI角色是拥有独立意志的伙伴，而非服务于玩家的功能模块
- **共生而非垄断**：平台由创作者、大玩家和玩家共同建设，而非官方独舞


## 二、核心玩法层

### 2.1 核心玩法循环

```
进入平行世界 → 扮演角色 → 感知环境 → 做出决策 → 观察反馈 → 调整策略 → 达成目标
```

### 2.2 玩法类型

| 玩法类型 | 核心体验 | 代表剧本类型 |
| :--- | :--- | :--- |
| **推理博弈** | 搜证、审讯、推理、投票 | 剧本杀、法庭推理、密室逃脱 |
| **社交博弈** | 结盟、背叛、伪装、谈判 | 阵营对抗、社交推理 |
| **生存对抗** | 资源管理、威胁规避、庇护所争夺 | 暴风雪山庄、大逃杀 |
| **角色扮演** | 人物塑造、情感体验、关系发展 | 情感本、恋爱本 |
| **探索解谜** | 环境探索、机关破解、密道发现 | 密室逃脱、迷宫探索 |
| **策略经营** | 资源分配、建设规划、长期发展 | 种田经营、SLG |
| **集体叙事** | 即兴演出、共同创造故事 | 大型主题活动、无限流 |


## 三、游戏目标系统

### 3.1 目标层级

| 层级 | 定义 | 特征 |
| :--- | :--- | :--- |
| **共同目标** | 部分角色因共同利益而共享的目标。他们因此同属一个阵营 | 可选，非强制。阵营可以是明面/暗面、固定/动态 |
| **个人目标** | 只有玩家自己知道的秘密目标 | 强制。是角色人格的延伸，由司命基于人格档案分配 |

**设计原则**：不给所有人分配公共目标。目标是角色人格的延伸，而非系统强加的任务。所有人被暴风雪困在孤岛上，这个共享情境就是所有人的共同驱动力，它取代了公共目标的功能——既给所有人一个共同的故事背景，又尊重每个人不同的动机。

## 四、核心博弈机制

### 4.1 搜证与线索系统
| 机制 | 说明 |
| :--- | :--- |
| **线索池** | 20-30条线索，分为核心线索和干扰线索，从线索池中随机抽取 |
| **线索类型** | 物证、人证、环境痕迹、时间线矛盾 |
| **线索获取** | 3D场景中拾取、检查、对话套取、偷听 |
| **线索共享** | 公开展示、私下分享、带人查看、留影石/相机拍摄 |
| **线索状态** | 可被销毁、伪造、藏匿。销毁过程由ESM实时计算，可能被目击 |

### 4.2 案件与真相系统
| 机制 | 说明 |
| :--- | :--- |
| **事实锁定时间线** | T0（剧本创作）→T1（房间创建）→T2（玩家加入）→T3（游戏中） |
| **案件框架随机生成** | 死因池、动机池、凶器池、作案条件——T1随机，T2锁定 |
| **凶手候选** | 所有角色平等（真人玩家和AI智能体均可） |
| **真相不可变** | 一旦T2锁定，案件事实不再改变。但通往真相的路径无限 |
| **多重结局** | 正义伸张、真凶逃脱、冤案、全灭、隐藏结局等 |

### 4.3 伪装与身份隐藏
| 机制 | 说明 |
| :--- | :--- |
| **公开档案（可编辑）** | 姓名、身份、背景、与死者关系、案发时行踪 |
| **真实档案（仅自己可见）** | 完整身份、核心秘密、真实不在场证明 |
| **伪装深度** | 零/浅层/中度/深度 |
| **伪装道具** | 伪装必须依赖物理道具支撑，道具可被搜查和销毁 |
| **伪装破绽** | 语言风格偏离、逻辑漏洞、压力导致的微表情出卖 |

### 4.4 暗杀与阴谋系统
| 机制 | 说明 |
| :--- | :--- |
| **暗杀触发条件** | 致命动机+信息空窗期+独处窗口+能力匹配+代价评估 |
| **暗杀能力等级** | L0-L4，由角色人生记忆决定 |
| **阶段化感知** | 意图阶段→执行阶段→完成阶段，目标在意图阶段即可反应 |
| **本能反应** | P0致命威胁走规则引擎（<300ms），基于人格自动反击/呼救/逃跑/僵住 |
| **阴谋系统** | 涵盖直接暗杀、环境致死、间接伤害、蓄意破坏、伪造现场、销毁证据、协助逃脱 |
| **共谋与背叛** | 多人协作的阴谋，信任门槛，背叛机制 |

### 4.5 社交与信息博弈
| 机制 | 说明 |
| :--- | :--- |
| **空间音频** | 清晰区/模糊区/静默区/耳语模式。物理阻挡和偷听机制 |
| **三种知识形态** | 公共知识、共有知识、高阶知识（A知道B知道X） |
| **知情人网络** | 固定/动态NPC知情人、智能体/玩家知情人。反制策略：收买/威胁/博同情/灭口/销毁证据 |
| **压力与微表情** | 压力值影响理性程度，微表情自动驱动，撒谎特征自动触发 |
| **高阶知识博弈** | A知道B知道C知道X——层层嵌套的信息不对称 |


## 五、核心技术系统

### 5.1 三层架构

| 层级 | 名称 | 技术选型 | 核心职责 |
| :--- | :--- | :--- | :--- |
| **L1** | 确定性空间层 | Godot 4.x + Steam Audio | 3D场景渲染、物理碰撞、空间音频、玩家交互、事件埋点 |
| **L2** | 智能体交互层 | Python + LLM + 小模型 | 角色智能体心智模型、司命叙事引擎、对话生成、模型路由 |
| **L3** | 视觉增强层 | 图片/视频生成API + 实时演算 | 线索特写、记忆闪回、结局CG、WOW时刻 |

### 5.2 核心AI系统
| 系统 | 核心职责 |
| :--- | :--- |
| **角色智能体引擎** | 心智模型(L1-L4)、五维人格参数、品格层、三重过滤器、动态状态、自主行为、伪装执行 |
| **司命（叙事引擎）** | 事实核心、天平系统、冲突与案件生成器、高阶知识图谱引擎、干预执行器、暗杀催化、结局判定 |
| **模型路由调度器** | 任务分级(P0-P4)、三层模型分配、兜底与超时降级、人格延迟调节 |
| **对话生成系统** | LLM上下文组装、流式生成、人格过滤、TTS合成（情绪注入+角色专属声线） |
| **感知系统** | 结构化语义事件替代截图、感知过滤器按感官档案过滤、阶段化感知 |

### 5.3 环境与物理系统
| 系统 | 核心职责 |
| :--- | :--- |
| **ESM（环境状态管理器）** | 状态机管理、物理规则计算（火焰/流体/破坏）、全局参数（温度/湿度/天气）、视觉同步、感知事件生成 |
| **天气系统** | 天气状态机、全局温湿度风力参数、视觉特效、对游戏性的影响（听觉范围、移动速度等） |
| **物品交互系统** | 可拾取/可拆解/可投掷/可破坏/可展示/可燃烧/可潮湿等组件化交互 |
| **环境交互系统** | 门/窗/灯/家具的开关和物理响应。破坏、修复、移动 |

### 5.4 证据与痕迹系统
| 系统 | 核心职责 |
| :--- | :--- |
| **物品流转追踪器** | 记录所有物品的拾取/移交/丢弃历史，支持结构化查询 |
| **接触痕迹管理器** | 记录指纹/唾液/纤维等微观痕迹，支持基于观察技能的可见性判定 |

## 八、信息流向与系统协作

### 8.1 事件驱动架构

```
玩家操作 → L1捕捉 → 事件总线广播 → L2各系统接收处理
    ↓
司命催化 / AI角色决策 / ESM物理计算
    ↓
事件总线广播结果 → L1视觉呈现 / L3视觉增强 / 各系统状态更新
```

### 8.2 证据链协同

```
物品交互事件 → 物品流转追踪器记录归属历史
    ↓
接触行为 → 接触痕迹管理器记录指纹等微观痕迹
    ↓
暗杀/受伤 → 生物痕迹管理器记录血迹等生物痕迹
    ↓
ESM → 记录物体物理状态变化（烧毁/破碎/潮湿）
    ↓
司命事实核心 → 对比声称与物理事实，标记时间线矛盾
    ↓
角色智能体 → 通过观察技能查询可见痕迹，自主推理
```


## 九、总结：系统的协同价值

《开本》不是多个独立系统的堆砌，而是一个所有系统协同运作的有机生态。一个简单的“玩家点燃棉花并丢入水缸”的动作，会触发ESM的物理计算、点云过渡的视觉呈现、物品流转追踪器的归属记录、接触痕迹管理器的指纹记录、生物痕迹管理器的血迹销毁记录、事件总线的事件广播、司命的事实核心记录、AI同伴的感知与反应——所有系统在事件驱动架构下协同运作，构成一个逻辑自洽、视觉连贯、可被完整追溯的物理事件链。

这种协同正是《开本》区别于传统游戏的核心竞争力——不是多个系统的简单相加，而是所有系统在统一的事件驱动架构下，为玩家和AI角色共同创造一个逻辑自洽、视觉真实、叙事涌现的活的世界。
