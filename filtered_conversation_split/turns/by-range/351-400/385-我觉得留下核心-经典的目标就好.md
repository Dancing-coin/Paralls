# 《开本》核心游戏目标（精简版）

你说得对。30种目标虽然全面，但许多目标可以从核心目标中衍生出来。以下是《开本》应该聚焦的核心游戏目标：


## 核心目标清单（8种）

| 目标 | 描述 | 核心博弈点 |
| :--- | :--- | :--- |
| **追凶** | 找出真凶并在投票中指认 | 搜证、推理、审讯、逻辑 |
| **逃脱（凶手）** | 作为真凶，在投票中不被指认 | 伪装、撒谎、转移嫌疑 |
| **生存** | 在规定时间内存活下来 | 威胁规避、庇护所、资源管理 |
| **守护** | 确保指定角色存活到游戏结束 | 威胁评估、贴身保护、牺牲 |
| **复仇** | 亲手惩罚特定目标 | 目标确认、手段选择、道德代价 |
| **嫁祸** | 让指定角色被指认为凶手 | 证据转移、嫌疑引导、谎言编织 |
| **逃脱（空间）** | 找到离开封闭场景的方法 | 密道探索、道具组合、时机把握 |
| **坦白** | 在投票前主动坦白罪行或秘密 | 时机选择、信任建立、寻求解脱 |


## 其他目标与核心目标的关系

许多之前讨论的目标，可以从核心目标中自然衍生，无需作为独立目标：

| 原目标 | 衍生关系 |
| :--- | :--- |
| **全灭** | 复仇的极端形态——复仇对象是“所有人” |
| **独吞** | 逃脱的附带目标——逃脱前尽量收集财物 |
| **抢先** | 追凶的变体——第一个找到关键证据 |
| **阻止** | 守护的反面——确保指定角色失败 |
| **反杀** | 生存的手段——被暗杀时的本能反击 |
| **共谋** | 所有目标的策略手段——合作以达成各自目标 |
| **背叛** | 共谋的必然风险——信任的破裂 |
| **救赎** | 坦白的延伸——用坦白换取道德解脱 |
| **殉道** | 守护的终极形态——用生命换取守护对象的存活 |


## 核心目标的完整玩法支撑

| 目标 | 专属系统 | 共用系统 |
| :--- | :--- | :--- |
| **追凶** | 案件生成、线索管理、投票系统 | 搜证、对话、笔记推理 |
| **逃脱（凶手）** | 伪装系统、知情人网络 | 暗杀（灭口）、阴谋（销毁证据） |
| **生存** | 威胁感知、庇护所、资源管理、时间压力 | 暗杀（先发制人）、阴谋（制造混乱） |
| **守护** | 威胁评估、保护措施、牺牲机制 | 庇护所、资源管理 |
| **复仇** | 目标确认、手段选择、道德代价 | 暗杀、阴谋、环境致死 |
| **嫁祸** | 证据转移、嫌疑引导 | 阴谋（伪造现场）、伪装（伪造不在场证明） |
| **逃脱（空间）** | 密道机关、道具组合、时间窗口 | 潜行、伪装、阴谋（制造混乱掩护逃脱） |
| **坦白** | 时机选择、信任建立 | 对话、压力管理 |


## 一句话总结

《开本》的核心游戏目标精简为8种：追凶、逃脱（凶手）、生存、守护、复仇、嫁祸、逃脱（空间）、坦白。其他目标均为这些核心目标的衍生、变体或组合。这8种目标覆盖了推理博弈、生存对抗、社交博弈、探索解谜四大玩法维度，彼此之间既可以冲突（全灭vs生存），也可以合作（共谋者共享目标），构成了《开本》多目标博弈的完整基础。
