## 用户

目前看来我们只相对完整的设计了追凶这一游戏目标的相关玩法系统

## DeepSeek

你的观察非常准确。在之前的对话中，我们确实围绕“追凶”这一目标设计了最完整的玩法系统——案件生成、线索管理、投票机制、伪装系统、知情人网络、暗杀机制、阴谋系统等，几乎都是为“找出真相”这一核心循环服务的。

但《开本》的推理类剧本杀不应只有“追凶”。以下是为其他核心游戏目标补全的玩法系统设计。


## 非“追凶”目标的玩法系统设计

### 一、“生存”目标

**目标描述**：在限定时间内存活下来。你不需要找出真相，你只需要活命。

**核心玩法循环**：感知威胁 → 规避风险 → 寻找庇护 → 坚持到时限

| 玩法系统 | 在“生存”目标中的作用 |
| :--- | :--- |
| **威胁感知系统** | 司命会通过内心独白、环境音效、视觉线索（如微表情变化）向生存者传递威胁信号。“你感到背后有人在注视着你。”“走廊尽头的脚步声突然停了。”——这些不是系统提示，而是角色直觉 |
| **庇护所机制** | 场景中存在可锁定的房间、可躲藏的柜子、可设置陷阱的走廊。生存者可以占据庇护所，但庇护所可能被破坏——门锁被撬开（ESM物理破坏判定）、窗户被暴风雪击碎（天气系统驱动） |
| **资源管理系统** | 生存者可以收集食物、药品、防御工具。资源有限，必须策略性分配。资源可能被其他玩家偷走（物品流转追踪器记录），也可能因环境变化而损坏（ESM驱动） |
| **时间压力系统** | 生存者可以看到倒计时——暴风雨结束的时间、救援到达的时间、或黎明破晓的时间。随着时间推移，威胁逐渐升级——暴风雪加剧导致庇护所不再安全，暗杀者的耐心耗尽导致更激进的行动 |
| **逃生路线规划** | 生存者可以探索场景中的密道、可破坏的窗户、可攀爬的露台。ESM管理这些出口的状态——有的可能被锁死、被冰雪封住、或被凶手预先破坏。生存者需要在有限的时间内找到可行的逃生路线 |

**与其他目标的博弈**：
- vs“全灭”：全灭者会主动追杀生存者。生存者需要在躲避追捕的同时寻找反制机会
- vs“守护”：守护者可能与生存者形成自然联盟——守护者需要保护另一个目标，生存者可以提供帮助以换取保护
- vs“追凶”：追凶者需要生存者的证词。生存者可以用信息交换庇护

**重玩价值**：每次开局，庇护所的状态、资源的分布、逃生路线的可行性都不同。ESM的物理规则和司命的环境催化确保每次生存挑战都独一无二。


### 二、“逃脱”目标

**目标描述**：找到离开当前封闭场景的方法。你的目标不是找出真相，而是活着离开。

**核心玩法循环**：探索环境 → 收集道具 → 破解机关 → 找到出口 → 成功脱出

| 玩法系统 | 在“逃脱”目标中的作用 |
| :--- | :--- |
| **密道与机关系统** | 场景中存在隐藏的密道、暗门、通风管道。开启条件由ESM管理——需要特定钥匙（物品流转追踪器）、需要破解密码（解谜系统）、需要特定时间（如暴风雪减弱的窗口期）、需要多人协作（两个开关同时按下） |
| **道具组合系统** | 逃脱者可以从场景中收集多种道具——绳子、钩子、撬棍、打火机等。道具可以组合使用——绳子+钩子=抓钩，可以攀爬高窗。组合配方在每次开局时随机变化，确保新鲜感 |
| **障碍与破坏系统** | ESM管理出口的可达性。密道的门可能因年久失修而卡住（需要撬棍），窗户可能被封死（需要工具破坏），唯一的出口可能在暴风雪最强的时候开启（需要等待时机）。其他玩家也可以主动破坏出口——全灭者或复仇者可能封死逃生路线 |
| **伪装与欺骗** | 逃脱者需要在不惊动其他人的情况下行动。潜行移动姿态降低被感知概率，伪装成其他角色的盟友以获取关键道具，或制造噪音（全局行动）将其他人的注意力引开 |
| **时间窗口系统** | 每个出口都有特定的开启条件——暴风雪减弱的短暂窗口、守卫换班的间隙、某一盏灯熄灭的瞬间。司命管理这些时间窗口，逃脱者需要抓住稍纵即逝的机会 |

**与其他目标的博弈**：
- vs“阻止”：阻止者可能知道逃脱者的目标，并专门破坏逃脱路线
- vs“全灭”：全灭者会将出口封死——逃脱者需要在全灭者完成封锁之前找到出路
- vs“追凶”：追凶者需要逃脱者的帮助——逃脱者可以要求追凶者协助打开某个机关，作为交换提供信息

**重玩价值**：每次开局，出口的位置、开启条件、所需道具都不同。司命从密道池中随机生成逃脱路线，ESM管理出口的物理状态。


### 三、“复仇”目标

**目标描述**：找到并亲手惩罚（暗杀、环境致死、或公开揭露）对你造成过伤害的人。你的目标不是赢——你的目标是让那个人付出代价。

**核心玩法循环**：确认目标身份 → 收集目标信息 → 寻找行动窗口 → 执行复仇 → 处理后事

| 玩法系统 | 在“复仇”目标中的作用 |
| :--- | :--- |
| **目标确认系统** | 复仇者开局时知道自己的仇恨来源——但不知道仇人具体是谁（只知罪行，不知身份）。他需要通过对话、搜证、观察微表情来确认仇人的身份。一旦确认，压力值会急剧变化——仇恨得到确认时的愤怒，或发现仇人是自己最信任的人时的痛苦 |
| **复仇手段选择** | 复仇者可以使用多种手段完成复仇：暗杀（暗杀系统，需满足五重条件）、环境致死（利用ESM的物理规则——推下楼梯、锁入冰库、制造火灾）、公开揭露（在投票环节公开仇人的罪行，使其被法律或众人制裁）、陷害嫁祸（将仇人的罪行转嫁到另一个人身上，让仇人体验被冤枉的痛苦） |
| **道德代价系统** | 复仇行为会产生道德代价。高共情者完成复仇后会感到空虚和愧疚（压力值不降反升），低共情者完成复仇后会感到解脱和满足（压力值大幅下降）。道德代价影响后续行为——空虚者可能寻求救赎，满足者可能变得更加危险 |
| **后事处理** | 复仇完成后，复仇者需要处理后续问题——隐藏证据、伪造不在场证明、应对追凶者的调查。如果选择公开揭露而非暗杀，则不存在后事处理问题，但复仇者需要面对公众审判的压力 |

**与其他目标的博弈**：
- vs“守护”：守护者可能在保护复仇者的目标——他们之间产生直接对抗
- vs“追凶”：复仇者可能成为追凶者的嫌疑人——因为复仇者确实有动机和行动
- vs“救赎”：复仇者可能在完成复仇后发现仇人已经悔改——此时复仇者面临艰难的道德选择

**重玩价值**：每次开局，复仇者的仇人身份不同（从角色池中随机锁定），复仇手段的选择因ESM物理规则和角色能力而异，道德代价由复仇者的人格参数决定。


### 四、“守护”目标

**目标描述**：确保另一位指定角色存活到游戏结束。如果他们死了，你失败。

**核心玩法循环**：确认守护对象 → 评估威胁 → 采取保护措施 → 应对突发危机 → 坚持到终局

| 玩法系统 | 在“守护”目标中的作用 |
| :--- | :--- |
| **威胁评估系统** | 守护者需要持续评估周边威胁——谁是潜在的暗杀者？谁对守护对象有敌意？守护者可以通过观察微表情（司命驱动）、偷听对话（空间音频）、阅读笔记（其他玩家可能无意中留下的信息）来收集威胁情报 |
| **保护措施系统** | 守护者可以采取多种保护措施：陪同守护对象（清晰区内随时可干预暗杀）、转移守护对象到安全区域（庇护所机制）、警告潜在威胁者（对话中暗示“我知道你在做什么”）、主动消除威胁（先发制人——如果守护者拥有暗杀能力）、伪造守护对象的死亡（使守护对象暂时脱离危险） |
| **牺牲机制** | 守护者可以在关键时刻牺牲自己来保护守护对象——为守护对象挡刀（在暗杀的阶段化感知中，守护者可以主动介入P0本能反应）、替守护对象顶罪（在投票环节主动承认罪行）、用自己的生存换取守护对象的逃脱 |
| **信任管理** | 守护者需要向守护对象证明自己的可靠性——但又要保护自己的秘密目标不被其他玩家发现。守护对象可能并不信任守护者（他们可能是陌生人或曾经的敌人），守护者需要通过行动建立信任 |

**与其他目标的博弈**：
- vs“复仇”：复仇者的目标可能是守护者的守护对象——直接对抗
- vs“全灭”：全灭者会试图杀死所有人，包括守护对象——守护者需要阻止全灭者的每一次行动
- vs“追凶”：如果守护对象是真凶，守护者需要在不暴露守护对象的前提下配合追凶者——这需要极高的博弈技巧

**重玩价值**：每次开局，守护对象的身份不同，威胁来源不同，保护措施的有效性因ESM物理规则和环境变化而异。


### 五、“全灭”目标

**目标描述**：确保所有人都死。你是审判者，你的目标不是逃脱，而是让罪人一个接一个地接受惩罚。

**核心玩法循环**：确认目标名单 → 策划死亡顺序 → 创造行动窗口 → 执行审判 → 处理意外 → 确保无人幸存

| 玩法系统 | 在“全灭”目标中的作用 |
| :--- | :--- |
| **死亡顺序策划** | 全灭者需要制定策略——先杀谁？后杀谁？先杀威胁最大的人（如拥有暗杀能力的复仇者或守护者），还是先杀最脆弱的人（降低其他人的警惕）？死亡顺序会影响游戏进程——如果先杀了所有人都怀疑的人，恐慌会加剧 |
| **多种致死手段** | 全灭者可以利用所有可用的致死手段：暗杀（暗杀系统）、环境致死（ESM物理规则——推下楼梯、锁入冰库、制造火灾）、蓄意破坏（破坏庇护所、破坏逃生路线、破坏通讯设备）、心理逼迫（利用童谣制造恐怖氛围，逼迫目标在恐惧中自杀）、嫁祸（制造意外假象，让其他人以为目标死于意外或自杀） |
| **意外管理系统** | 全灭者的计划可能出现意外——目标的反击（反杀）、目击者的出现、司命的催化（司命可能为平衡游戏而引入新的变数）。全灭者需要实时调整计划 |
| **终局验证** | 全灭者需要在终局时确认所有目标都已死亡。如果有人幸存，全灭者失败。如果有人假死（如我们之前讨论的阿姆斯特朗医生假死），全灭者需要识破并补刀 |

**与其他目标的博弈**：
- vs“生存”：直接对抗。生存者会试图躲避全灭者
- vs“守护”：守护者会保护全灭者的目标——全灭者需要先解决守护者
- vs“追凶”：追凶者可能在全灭者的策划下成为替罪羊——全灭者可以利用追凶者的调查能力来误导其他人

**重玩价值**：每次开局，全灭者的身份不同（可能是法官，可能是隆巴德，可能是任何人），致死手段的选择因ESM物理规则和角色能力而异，意外事件由司命催化。


## 六、目标玩法系统总览

| 目标类型 | 核心玩法循环 | 专属系统 | 与其他目标的博弈焦点 | 重玩价值来源 |
| :--- | :--- | :--- | :--- | :--- |
| **追凶** | 搜证→推理→投票 | 案件生成、线索管理、投票系统、伪装系统、知情人网络 | 与“逃脱”对抗，与“守护”合作 | 凶手随机、线索组合随机 |
| **生存** | 感知威胁→规避风险→寻找庇护 | 威胁感知、庇护所、资源管理、时间压力 | 与“全灭”对抗，与“守护”合作 | 庇护所状态、资源分布随机 |
| **逃脱** | 探索→收集道具→破解机关→找到出口 | 密道与机关、道具组合、障碍与破坏、时间窗口 | 与“阻止”对抗，与“全灭”对抗 | 出口位置、开启条件随机 |
| **复仇** | 确认目标→寻找窗口→执行复仇→处理后事 | 目标确认、复仇手段选择、道德代价 | 与“守护”对抗，与“追凶”博弈 | 仇人身份随机、复仇手段随机 |
| **守护** | 确认对象→评估威胁→采取保护→应对危机 | 威胁评估、保护措施、牺牲机制、信任管理 | 与“复仇”对抗，与“全灭”对抗 | 守护对象、威胁来源随机 |
| **全灭** | 策划顺序→创造窗口→执行审判→处理意外 | 死亡顺序策划、多种致死手段、意外管理 | 与“生存”对抗，与“守护”对抗 | 全灭者身份随机、死亡顺序随机 |


## 七、一句话总结

《开本》的推理类剧本杀围绕“追凶”构建了最完整的玩法系统，但“生存”、“逃脱”、“复仇”、“守护”、“全灭”等目标同样拥有专属的玩法循环和系统支撑。这些目标不是“追凶”的附属品或简化版——它们是独立的、完整的、具有独特博弈结构的核心玩法。当这些目标在同一局中共存时，玩家之间的博弈不再是简单的“好人抓坏人”，而是一场每个人都在为自己的目标而战的多维博弈。
