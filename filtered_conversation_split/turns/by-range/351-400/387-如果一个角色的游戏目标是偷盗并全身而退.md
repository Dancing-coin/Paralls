## DeepSeek

# 《开本》对“偷盗并全身而退”目标的玩法支持分析

## 一、目标拆解

“偷盗并全身而退”可以拆解为两个阶段：

| 阶段 | 核心动作 | 对应的核心目标 |
| :--- | :--- | :--- |
| **偷盗** | 发现目标物品、规划行动路线、实施窃取、藏匿赃物 | 独吞（G07，从核心目标中衍生） |
| **全身而退** | 避免被怀疑、转移嫌疑、或直接逃离现场 | 嫁祸（转移嫌疑）或 逃脱（空间） |


## 二、现有系统支持度评估

### 2.1 已可支持的部分（★★★★★）

| 系统 | 如何支持“偷盗” |
| :--- | :--- |
| **物品流转追踪器** | 自动记录物品从“原位置→窃贼手中→藏匿点”的完整流转历史。即使窃贼不公开承认，系统已在后台记录。其他玩家可通过搜查发现物品不在原处 |
| **接触痕迹管理器** | 窃贼触碰物品时自动留下指纹、纤维等微观痕迹。其他玩家可通过“观察”技能发现这些痕迹，形成推理链 |
| **感知系统** | 窃贼在行动时，附近角色的感知过滤器会收到“听到脚步声”、“看到人影”等语义事件——取决于窃贼的移动姿态和与被感知者的距离 |
| **ESM环境状态管理器** | 物品从“在原位”变为“被移走”，场景状态同步更新。门、窗、抽屉的开关状态同样被ESM记录 |
| **司命事实核心** | 记录物品的“应有位置”和“实际位置”的矛盾。如果窃贼声称“我没去过那个房间”，但物品流转追踪器显示物品被移动——矛盾标记 |

### 2.2 需要扩展的部分（★★★☆☆）

| 系统 | 当前状态 | 需要扩展的内容 |
| :--- | :--- | :--- |
| **搜证系统** | 当前只支持“搜索线索”，线索是预设的 | 需要支持“搜索任意物品”——玩家可以主动检查场景中的任何物品是否还在原处，而不仅仅是搜索预设线索 |
| **威胁感知系统** | 新设计，尚未实现 | 窃贼需要感知“谁可能发现我”——谁在附近、谁的视线朝向这边、谁正在走过来 |
| **嫁祸系统** | 初步设计，尚未完整 | 窃贼需要将赃物放置在他人的物品区域，或将嫌疑引向他人。需要完整的“证据转移”和“嫌疑引导”机制 |

### 2.3 当前不支持的部分（★★☆☆☆）

| 缺失 | 说明 |
| :--- | :--- |
| **物品价值系统** | 当前所有物品是平等的“线索”或“道具”。没有“价值”概念。如果窃贼目标是“偷走最值钱的东西”，系统需要支持物品的价值属性 |
| **偷盗技能等级** | 类似暗杀能力L0-L4，应该有一个“盗窃能力”等级，影响窃贼的痕迹控制、行动速度和被发现概率 |
| **赃物藏匿机制** | 窃贼需要将偷来的物品藏在某处。藏匿点的安全性由ESM管理——可能被其他玩家无意中发现 |


## 三、完整的“偷盗并全身而退”玩法流程

### 3.1 偷盗阶段

**行动前**：窃贼需要确认目标物品的位置、评估周边威胁、规划行动路线和逃离路线。威胁感知系统推送“谁在附近”、“谁的视线朝向目标物品”等信息（不是系统提示，而是角色直觉）。

**实施偷盗**：窃贼选择移动姿态——潜行降低被感知概率，但移动速度慢；正常行走速度快，但脚步声可能被他人听到。拾取物品时，物品流转追踪器记录归属转移。接触痕迹管理器在物品表面留下指纹。

**藏匿赃物**：窃贼可以选择将赃物藏在身上（背包中）、藏在房间的某处、或藏在他人房间（用于嫁祸）。ESM记录物品位置变化。

### 3.2 全身而退阶段

**方案A：嫁祸**。窃贼将赃物放在嫁祸目标的房间或物品区域。在对话中暗示“某人最近行为可疑”。在搜证时主动引导他人去发现“嫁祸目标的可疑之处”。嫁祸系统需要支持证据转移和嫌疑引导。

**方案B：逃脱**。窃贼找到离开场景的方法（密道、窗户、伪装混出）。利用制造混乱（如纵火、断电）吸引注意力，趁乱脱身。逃脱系统需要支持密道机关、道具组合、时间窗口。

**方案C：伪装**。窃贼伪装成无辜者，在投票或讨论中为自己辩护。利用不在场证明（共谋者可以帮忙作证）。伪装系统和知情人网络为此提供支持。


## 四、与核心目标的关系

| 核心目标 | 在“偷盗并全身而退”中的角色 |
| :--- | :--- |
| **嫁祸** | 全身而退方案A——将嫌疑引向他人 |
| **逃脱（空间）** | 全身而退方案B——带着赃物逃离封闭场景 |
| **逃脱（凶手）** | 如果偷盗过程中被发现，窃贼可能成为“凶手”嫌疑人——他需要为自己辩护 |
| **生存** | 窃贼需要在行动中确保自己的安全 |


## 五、结论

“偷盗并全身而退”作为《开本》8种核心目标的衍生组合，在现有系统架构下**高度可支持**。核心系统（物品流转追踪器、接触痕迹管理器、感知系统、ESM）已构成了完整的“偷盗-发现”博弈闭环：窃贼必然留下痕迹，但痕迹是否被发现取决于其他玩家的观察能力和行动选择。

需要扩展的部分主要集中在：物品价值系统（让“偷什么”有策略意义）、嫁祸系统的完整落地（让“栽赃”有操作空间）、搜证系统从“搜索线索”扩展到“搜索任意物品”。这些扩展不需要底层架构重构，只需要在现有系统上增加配置项和交互选项。
