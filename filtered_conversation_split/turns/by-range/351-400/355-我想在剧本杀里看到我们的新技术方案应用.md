## 推演总结：新技术方案在剧本中的呈现

| 技术方案 | 在剧情中的呈现 |
| :--- | :--- |
| **精确事件框架** | 伊芙琳的每一次操作——从柴堆中取出凶器、移动到厨房、用火钳放入火炉——都被精确记录（坐标、时间、动作、影响范围） |
| **分层感知过滤器** | 阿瑟在门缝中只看到模糊的背影和火钳，听到金属碰撞声，闻到隐约的金属加热气味——他的感知是部分且不完整的。与之对比，伊芙琳作为操作者拥有完整感知 |
| **ESM物理规则驱动** | 银制拆信刀在800°C火焰中被加热——血迹烧毁、指纹烧毁、刀身氧化变色。这些不是剧本写死的剧情，而是ESM基于材质属性实时计算的结果 |
| **点云过渡视觉** | 刀身颜色从银白→浅黄→深褐的连续变化，由点云过渡管理器在两个端点快照之间实时插值生成 |
| **接触痕迹/生物痕迹销毁** | 指纹在15-30秒内烧毁，血迹在30-60秒内烧毁。销毁过程有时间窗口——如果阿瑟提前进入厨房，可能看到血迹尚未完全烧毁的凶器 |
| **司命的催化与平衡** | 司命没有直接告诉阿瑟“去厨房看”，而是让阿瑟在走廊巡逻时恰好经过书房门口——这是Lv2环境催化。伊芙琳的压力值管理贯穿全程——销毁证据后降低，被质问后升高，最终崩溃坦白 |
| **全AI角色的自主博弈** | 每个角色的行为都由心智模型自主驱动。阿瑟选择跟踪而不是直接质问（忠诚10驱动他先向主人报告），维多利亚选择先保留医学证据再观察，伊芙琳选择厨房而非壁炉销毁证据（心机7比胆量4优先） |

**最关键的设计**：凶器被销毁了——血迹和指纹不可恢复。但它依然成为定罪的间接证据：氧化变色的刀身形态与凶器描述吻合，阿瑟的目击链条完整，维多利亚的地毯血迹和柴堆翻动痕迹构成时间线闭环。销毁证据的行为本身——匆忙、不彻底、留下目击者——比证据本身更致命。这正是《开本》推理的核心魅力：不是所有证据都能被完美销毁，不是所有罪行都能被完美掩盖。
