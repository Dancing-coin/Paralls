## 用户

那，目标系统可以设置共同目标而非全部角色必须存在一个公共目标。还有阵营划分的机制，存在共同目标就同属于一个阵营，阵营可以是明面的可以是暗面的也可以是动态存在的，可以是固定存在的。阵营之内可以划分派系，取决于角色是否达成合作。

## DeepSeek

你的判断完全正确。在《开本》中，目标系统不应该强制所有角色共享一个公共目标，而应该是**部分角色因共同利益而形成阵营**，阵营内共享一个目标，阵营之间可能是对立、合作或互不干涉的关系。

这种设计，正是我们之前讨论的“共谋系统”和“背叛机制”的自然延伸。现在，让我为你完整梳理这套“共同目标与动态阵营”的设计框架。


## 《开本》共同目标与动态阵营系统

### 一、核心概念区分

| 概念 | 定义 | 例子 |
| :--- | :--- | :--- |
| **公共目标**（已放弃） | 所有人强制共享的目标。我们已确认这不合适 | 所有人必须“追凶”——这消解了角色差异 |
| **共同目标**（新设计） | 部分角色因共同利益而共享的目标。他们因此同属一个阵营 | 麦肯锡、阿姆斯特朗、托马斯三人都是“罪人”，他们共享“掩护彼此”的共同目标 |
| **阵营** | 因共同目标而聚合的角色群体。可以是明面的、暗面的、固定的、动态的 | “罪人阵营”——他们知道彼此的身份，但外人不知道他们是一伙的 |
| **派系** | 阵营内部因策略或利益分歧而分化的小群体 | 罪人阵营中，阿姆斯特朗想逃脱、托马斯想守护妻子——两人在具体行动上可能产生分歧 |


### 二、阵营的四种形态

| 形态 | 说明 | 玩家知情权 | 博弈特征 |
| :--- | :--- | :--- | :--- |
| **明面固定阵营** | 开局时所有人公开知道阵营划分。阵营成员固定，不会改变 | 完全知情 | 直接对抗。如“法官vs罪人”——所有人都知道谁是法官、谁是罪人 |
| **暗面固定阵营** | 阵营成员知道彼此，但外人不知道。阵营成员固定 | 只有阵营内部知情 | 秘密合作。如“罪人阵营”——三个罪人暗中互相掩护，其他玩家不知道他们的联盟 |
| **暗面动态阵营** | 阵营成员在游戏过程中可能变化。有人可能加入、退出、背叛 | 只有当前阵营内部知情 | 最高博弈难度。如“审判者阵营”——法官招募愿意合作的人，但合作者可能随时反水 |
| **明面动态阵营** | 所有人都能看到阵营成员的变化。阵营边界透明，但成员可流动 | 所有人知情 | 策略性联盟。如“生存者阵营”——所有想活命的人公开合作，但成员可能因死亡或背叛而退出 |


### 三、以《无人生还·罪与罚》为例的阵营设计

#### 3.1 共同目标与阵营分配

| 阵营 | 成员 | 共同目标 | 阵营形态 |
| :--- | :--- | :--- | :--- |
| **罪人阵营** | 麦肯锡、阿姆斯特朗、托马斯·罗杰斯 | 掩护彼此——确保至少两名罪人存活到暴风雨结束 | 暗面固定阵营 |
| **审判者阵营** | 沃格雷夫（可能招募其他人） | 揭露所有罪行——确保所有被唱片指控的罪行都被公开承认或受到惩罚 | 暗面动态阵营（沃格雷夫可以在游戏中招募成员） |
| **无阵营** | 维拉、隆巴德、布伦特、艾瑟尔 | 无共同目标——她们各自为战 | — |

**为什么这样设计？**

-   **罪人阵营**：麦肯锡、阿姆斯特朗、托马斯三人都有一个共同点——他们的罪行是可以通过“互相掩护”来减轻嫌疑的。麦肯锡可以作证阿姆斯特朗不在案发现场，阿姆斯特朗可以解释托马斯的可疑行为。他们的共同目标是“保护彼此不被揭露”。

-   **审判者阵营**：沃格雷夫作为法官，他的目标不是简单的追凶——他想要一场完整的审判。他可以招募那些想要坦白罪行、寻求救赎的人加入他的阵营（如艾瑟尔）。但加入审判者阵营意味着公开承认罪行——这对罪人阵营来说是不可接受的。因此两个阵营之间存在直接冲突。

-   **无阵营**：维拉、隆巴德、布伦特、艾瑟尔的个人目标都不需要与他人合作。维拉想嫁祸布伦特，隆巴德想独自生存，布伦特想保护维拉，艾瑟尔想坦白——她们的目标各不相同，无法形成共同目标。

#### 3.2 阵营内部的派系分化

即使在同一阵营内部，也可能因策略分歧而产生派系。

| 阵营 | 派系A | 派系B | 分歧点 |
| :--- | :--- | :--- | :--- |
| **罪人阵营** | 托马斯·罗杰斯（想保护妻子） | 阿姆斯特朗（想独自逃脱） | 托马斯需要所有人合作掩护，但阿姆斯特朗想趁乱逃走——如果他逃走了，剩下的罪人就更难掩护彼此 |
| **审判者阵营** | 沃格雷夫（想审判所有人） | 艾瑟尔（想坦白自己的罪行） | 沃格雷夫想要完整的审判——他需要罪人在投票中被指认。但艾瑟尔只想自己坦白，她可能不愿意指认其他罪人 |

#### 3.3 阵营的动态变化

在游戏过程中，阵营可能发生变化。

| 变化类型 | 触发条件 | 例子 |
| :--- | :--- | :--- |
| **成员死亡** | 阵营成员被暗杀或自杀 | 麦肯锡死后，罪人阵营只剩下阿姆斯特朗和托马斯——他们的掩护能力大幅下降 |
| **成员背叛** | 阵营成员的个人目标与共同目标产生不可调和的冲突 | 阿姆斯特朗选择独自逃脱——他不再掩护托马斯。罪人阵营瓦解 |
| **新成员加入** | 某角色被招募 | 沃格雷夫发现艾瑟尔有坦白倾向，主动邀请她加入审判者阵营 |
| **阵营解散** | 共同目标已不可能完成 | 当只剩下一个罪人时，罪人阵营自动解散——他不再需要掩护任何人 |


### 四、共同目标的博弈优势与风险

| 优势 | 风险 |
| :--- | :--- |
| 阵营成员可以互相作不在场证明 | 如果一名成员暴露，整个阵营都可能被牵连 |
| 阵营成员可以共享线索和信息 | 阵营内部可能存在内鬼——有人可能为了自保而出卖同伙 |
| 阵营成员可以协同行动（如一起搜证、一起监视某人） | 协同行动本身可能暴露阵营的存在——其他人会注意到“为什么你们总是出现在同一个地方” |
| 共同目标的完成可以带来额外的成就感 | 如果共同目标失败，所有阵营成员都会受到影响 |


### 五、司命对动态阵营的管理

| 司命职责 | 说明 |
| :--- | :--- |
| **阵营状态追踪** | 实时监控每个阵营的成员状态、目标完成进度、内部派系分歧 |
| **阵营冲突催化** | 当两个阵营的目标产生直接冲突时，司命催化关键事件——如让罪人阵营的成员意外发现审判者阵营的秘密 |
| **阵营变化记录** | 记录阵营的每一次变化（成员加入/退出/背叛），作为结局叙事和续集承接的依据 |
| **平衡干预** | 如果一个阵营过于强势，司命可能催化该阵营内部的矛盾——如让派系分歧加剧，或让其中一名成员收到一封匿名信，揭露另一个成员的秘密 |


### 六、总结

在《开本》中，目标系统不再需要强制所有人共享一个公共目标。取而代之的是：

1.  **共同目标**——部分角色因共同利益而聚合，形成阵营
2.  **阵营**——可以是明面的、暗面的、固定的、动态的
3.  **派系**——同一阵营内部可能因策略分歧而分化
4.  **动态变化**——阵营成员可能死亡、背叛、加入、退出

这种设计让《开本》的社交博弈更接近真实世界的利益博弈——不是所有人都在同一条船上，而是每个人都有各自的利益，只有利益重叠时才形成合作，利益冲突时产生对抗。这正是我们追求的“有人味的游戏”的核心体现。
