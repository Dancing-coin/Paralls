# 《开本 / Paralls》完整项目计划（更新版）

## 项目概述

**产品名称**：开本 / Paralls  
**核心定义**：智能体驱动的3D沉浸式动态叙事平台  
**核心承诺**：同一个剧本，每一次游戏都不同  
**终极愿景**：一个能让任何人创造任何故事、与任何AI角色建立真实羁绊、在无数平行世界中自由穿梭的开放生态


## 三阶段演进路线

### Phase 1：核心体验验证

**核心问题**：AI驱动的动态剧本杀能否让玩家感受到“那个AI角色真的在骗我，而且它骗得有道理”？

**核心交付**：
- 动态案件生成、人格驱动AI、司命实时导演、3D空间音频社交
- 首个剧本《血字的研究·变奏》，智能体轻量带走，小世界基础
- 支持追凶、逃脱（凶手）、生存、复仇等核心目标
- 面向核心玩家和早期尝鲜者，剧本买断制

**新增议题**：
- 玩法系统通用化设计（全部系统目标中立）
- 剧本模板（案件/恋爱/无限流/恐怖生存等）
- 完整人群分类学（11种特殊人群）
- 意向志愿系统（角色选择权与知情权平衡）
- 留影石、接触痕迹等证据链系统
- 小世界基础（带回智能体+基础对话）
- 离线时间线补全机制

**商业验证**：玩家是否愿意为动态剧本杀付费？智能体带走是否有情感价值？

### Phase 2：跨局叙事与创作者生态

**核心问题**：连续单局能否让AI羁绊产生长期情感价值？创作者工具能否引爆内容供给？

**核心交付**：
- 种子库系统、续集承接、跨剧本记忆、智能体资产化
- 伪装系统完整版、暗杀能力体系、知情人网络
- 系列侦探故事、恋爱模拟、剧本化身（官方史诗系列）
- 剧本编辑器开放、大玩家服务器上线、AI同伴带入新剧本
- 面向内容创作者、系列玩家，系列剧本套票、角色买断

**新增议题**：
- 恋爱本专有机制（告白仪式、羁绊里程碑等）
- 无限流循环机制（世界快照、记忆保留、循环规则）
- AI同伴养成体系（私房钱、外观、跨剧本使用）
- 小世界升级（小镇生态、节日、居民社交）

**商业验证**：创作者是否愿意生产？玩家是否愿意为系列和AI同伴付费？

### Phase 3：世界生态与宏大叙事

**核心问题**：永续运行的世界能否成为真正的“第二人生”？UGC生态能否自我造血？

**核心交付**：
- 持续运行世界、双层玩家身份、资产经营、跨世界旅行
- 种田经营、SLG策略、MMORPG式活态世界、开放世界RPG

**新增议题**：

**商业验证**：大玩家是否愿意经营世界？玩家是否愿意长期生活？生态能否自运转？


## 更新后的Phase 1主要议题

### 议题一：AI智能体的实时性与成本控制

**核心问题**：如何在保证AI角色反应自然（秒级延迟）的同时，控制LLM推理成本？

**应对策略**：模型路由三层架构。P0致命威胁走规则引擎（<300ms）；P1紧急对话走本地小模型（1-3B参数，<1500ms）；P2重要推理走云端大模型（<3000ms）。本地小模型处理95%日常对话，云端仅用于关键深度推理。事件总线传递结构化语义事件，智能体不读取视觉信息，Token消耗极低——单个AI同伴月度成本可控制在5-15元（全云端）或更低（本地混合）。

### 议题二：动态叙事逻辑的一致性与可玩性平衡

**核心问题**：司命主动催化冲突时，如何确保不破坏案件逻辑，不干预玩家自由意志？

**应对策略**：司命四原则强制执行——间接性（不直接控制玩家）、不可见性（玩家感知不到系统干预）、逻辑自洽性（所有催化有世界观解释）、公平性（不偏袒任何一方）。司命只催化机会，不替角色做决定。所有干预经自监控系统动态调节，防止过度干预。

### 议题三：3D沉浸交互与AI感知的同步

**核心问题**：AI角色如何实时感知3D世界中的玩家行为，而不依赖昂贵的视觉识别？

**应对策略**：结构化语义事件替代截图。L1层将所有玩家行为转化为结构化JSON事件，通过事件总线推送至L2。每个AI角色通过“感知过滤器”按感官档案过滤，只接收其感官范围内应感知的信息。这保证了AI与人类玩家在信息获取上的公平性和毫秒级延迟。

### 议题四：用户付费意愿与市场接受度

**核心问题**：玩家是否愿意为“AI驱动的动态剧本杀”付费？目标市场是否明确？

**应对策略**：Phase 0原型测试，录制演示视频收集早期反馈。Phase 1第6月进行外部玩家测试，直接收集付费意愿数据。初期定价策略采用剧本买断制（单个剧本预估定价38-68元）和服务器门票制，后续通过智能体带走、皮肤、小世界设定包等增值服务扩展收入。

### 议题五：内容供给的可持续性

**核心问题**：官方初期剧本有限，如何保证内容量以吸引玩家持续游玩？

**应对策略**：剧本种子库机制让同一剧本衍生出数千种不同案件组合。支持多种剧本类型——悬疑推理、恋爱模拟、恐怖生存、无限流等。11种特殊人群设计让角色拥有独立的、不为追凶服务的秘密目标，重玩价值远超传统剧本杀。

### 议题六：技术集成的复杂度风险

**核心问题**：Godot 3D引擎、LLM推理、空间音频、事件总线等多个复杂系统的集成，是否会在Phase 1期间出现不可预见的延迟？

**应对策略**：Phase 0先行验证最核心的技术链路（Godot场景 + WebSocket + LLM对话 + 空间音频），确保技术可行后再进入完整MVP开发。每个模块定义清晰的消息协议和接口，独立开发测试后再集成。预留缓冲时间应对意外延迟。

### 议题七（新增）：玩法系统的通用化设计

**核心问题**：当前系统围绕“追凶”设计，如何确保“生存”、“复仇”、“逃脱”等其他核心目标也能获得完整的玩法支撑？

**应对策略**：所有核心系统采用“目标中立”设计——搜证不只是“找线索”，而是“找对目标有用的信息”；暗杀不只是“凶手灭口”，而是任何满足条件的角色都可执行。新设计的威胁感知、庇护所、资源管理、密道机关等通用系统，为所有核心目标提供平等的玩法支撑。

### 议题八（新增）：角色选择权与知情权平衡

**核心问题**：玩家进入游戏前，如何兼顾其角色选择权与游戏体验（保护伪装系统、维护角色扮演的纯粹性）？

**应对策略**：意向志愿系统。开局前玩家看到每个可选角色的公开人格侧写（性格关键词、背景素描、玩法倾向），但真实身份、核心秘密和目标均隐藏。玩家按志愿顺序选择最感兴趣的3个角色，系统根据偏好和本局随机种子分配角色。所有角色的目标负荷（完成目标所需精力、风险和复杂度）由司命均衡分配。

### 议题九（新增）：证据链系统的完整闭环

**核心问题**：如何让“搜证-发现-记录-展示-销毁”形成完整的博弈闭环？

**应对策略**：物品流转追踪器、接触痕迹管理器、生物痕迹管理器、ESM物理状态管理器各司其职，司命事实核心统一管理时间线矛盾。证据可被销毁（ESM实时计算销毁过程），但销毁行为本身产生新的证据——间接证据链、目击者、时间线矛盾。这让“销毁证据”从剧本写死的剧情变成实时物理博弈。

### 议题十（新增）：AI陪伴的情感价值验证

**核心问题**：玩家是否会在剧本中与AI角色建立足够深厚的情感羁绊，以至于愿意将其“带走”？

**应对策略**：Phase 1实现轻量版带走机制——结局时若信任值/好感度达标，玩家可邀请AI角色同行，存入小世界。小世界支持基础对话互动。目标是验证AI陪伴情感价值的最小闭环：40%旅人至少带回1个AI角色。

## 决策建议

1. **技术栈锁定**：Godot 4.x + Python FastAPI + llama.cpp + Claude/DeepSeek API，不再变更
2. **首个剧本锁定**：《血字的研究·变奏》，5角色2场景，不再扩展内容范围
3. **玩法系统通用化**：Phase 1所有核心系统采用“目标中立”设计，为后续多目标扩展预留接口
4. **团队规模确认**：核心团队至少需1名Godot开发、1名AI工程师启动Phase 0原型
5. **商业化路径**：Phase 1以验证体验为核心，暂不接入完整支付系统，但预留剧本买断和智能体带走的付费接口
6. **外部测试时间表**：第6个月必须完成至少一轮外部玩家测试，数据用于决定是否进入Phase 2


**文档版本**：v3.0（更新版）  
**一句话总结**：Phase 1验证核心体验（AI驱动的动态剧本杀+情感陪伴），Phase 2构建创作者生态（连续单局+AI资产化），Phase 3开放世界生态（永续运行+宏大叙事）。每阶段建立在前一阶段的技术验证和商业验证之上，层层递进，最终汇聚成《开本》的终极愿景——一个能让任何人创造任何故事、与任何AI角色建立真实羁绊、在无数平行世界中自由穿梭的开放生态。
