## 适合作为共同目标的类型

| 目标 | 适合度 | 阵营类型 | 说明 |
| :--- | :--- | :--- | :--- |
| **追凶** | ★★★★★ | 明面固定阵营 | 最经典的共同目标。多人共享“找出真凶”的目标，形成“追凶者联盟”。阵营内可共享线索、互相作证 |
| **生存** | ★★★★★ | 暗面固定阵营 | 所有人想活命——但单独生存更难。两个有暗杀能力的角色结盟互相掩护，形成“求生者阵营” |
| **逃脱（空间）** | ★★★★☆ | 暗面固定阵营 | 被困在同一封闭空间的人共享逃脱目标。可以协同破解机关，但也可能因资源有限而在最后关头反目 |
| **守护** | ★★★★☆ | 明面固定阵营 | 多人共同守护同一个目标——如三位保镖守护一位公主。分工协作：一人贴身保护，一人外围警戒，一人搜证排除威胁 |
| **复仇** | ★★★★☆ | 暗面固定阵营 | 两个人都想杀死同一个仇人——他们可以合作暗杀，或一人制造混乱另一人下手。但仇人死亡后联盟可能瓦解 |

## 不适合作为共同目标的类型

| 目标 | 适合度 | 原因 |
| :--- | :--- | :--- |
| **嫁祸** | ★★☆☆☆ | 嫁祸本质是“让某人被冤枉”——你很难和另一个人共享这个目标，除非你们想嫁祸同一个人。但即使如此，嫁祸需要秘密行动，共谋反而增加暴露风险 |
| **坦白** | ★☆☆☆☆ | 坦白是极度个人的道德抉择。两个人同时坦白不仅不自然，而且坦白的“解脱感”会因为共谋而大幅减弱 |
| **逃脱（凶手）** | ★☆☆☆☆ | 真凶通常只有一个。即使是共犯结构，每个共犯在投票时也需要各自为自己辩护——这是个人的生死博弈，很难共享 |


## 共同目标下的阵营派系分化

同一阵营内，可能因策略分歧而产生派系：

| 阵营 | 派系A | 派系B | 分歧点 |
| :--- | :--- | :--- | :--- |
| **追凶者联盟** | 激进派：主张在证据不完整时直接投票 | 稳健派：主张收集全部证据后再投票 | 投票时机的选择 |
| **求生者阵营** | 自保派：主张躲藏和防守 | 主动派：主张先发制人消除威胁 | 是否主动进攻 |
| **守护者同盟** | 贴身派：主张时刻守在守护对象身边 | 清剿派：主张主动去消灭所有潜在威胁 | 守护策略的选择 |
| **复仇者联盟** | 亲手派：要求自己亲手完成复仇 | 结果派：只要仇人死了，谁杀的不重要 | 复仇方式的选择 |


## 一句话总结

最适合作共同目标的是：**追凶、生存、逃脱、守护、复仇**。这些目标天然具有合作的基础——共享目标的人有共同的敌人、共同的利益或共同的处境。不适合作为共同目标的是：**嫁祸、坦白、逃脱（凶手）**——它们本质上是排他的个人行为，共谋会削弱博弈深度或自然感。
