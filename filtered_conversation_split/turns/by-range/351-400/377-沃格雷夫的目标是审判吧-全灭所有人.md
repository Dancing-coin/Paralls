# 《无人生还·罪与罚》游戏设计（修正版）

## 一、核心修正：沃格雷夫的目标是“全灭”

沃格雷夫——正义感10，理性10，胆量9，共情2——他不是来追凶的。他是来审判所有人的。在他的认知中，八个人都是罪人，所有人都应该接受惩罚。他的目标不是找出“某一个凶手”，而是确保所有罪人都为自己的罪行付出代价。

“全灭”在《开本》30种游戏目标中定义为：确保所有人都死。你是审判者，你的目标不是逃脱，而是让罪人一个接一个地接受惩罚。你可以使用暗杀、环境致死、蓄意破坏、心理逼迫等手段——但必须遵循你的审判原则。

## 四、沃格雷夫的“全灭”玩法设计

### 4.1 沃格雷夫的手段

| 手段 | 说明 | 依赖系统 |
| :--- | :--- | :--- |
| **心理逼迫** | 利用童谣制造恐怖氛围，让罪人在恐惧中崩溃自杀。沃格雷夫不需要亲自动手——他只需要创造一个让罪人无法承受的环境 | 司命催化、压力管理系统 |
| **利用他人** | 沃格雷夫可以暗中操纵其他角色互相残杀。他不直接动手——他让隆巴德的生存本能去杀人，让维拉的嫁祸计划制造混乱，让罪人内部的猜忌瓦解他们的联盟 | 知情人网络、高阶知识图谱 |
| **环境致死** | 利用ESM的物理规则——在暴风雪最猛烈时破坏庇护所，在某人必经的楼梯上制造松动，在食物中下毒 | ESM环境状态管理器、阴谋系统 |
| **亲自执行** | 如果以上手段都不足以完成全灭，沃格雷夫可以亲自执行最终审判。他的暗杀能力是L0，但他可以利用理性10策划完美的环境致死方案 | 阴谋系统、ESM |

### 4.2 沃格雷夫的审判原则

沃格雷夫的共情只有2，他不会因罪人的死而产生任何愧疚。但他的理性10约束了他的手段——他不会无差别屠杀，不会滥杀无辜（他认定所有人都有罪，但如果有证据证明某人无辜，他会重新评估），也不会使用不体面的方式（他会选择配得上“法官”身份的审判方式）。

### 4.3 沃格雷夫的隐藏行动

沃格雷夫的全灭目标意味着他必须在暗中行动，同时维持公开的“追凶者”形象——不参与追凶，只观察和引导。他不会主动提供线索，但他会在关键时刻用一句话引导怀疑方向。他会利用自己退休法官的权威来影响投票，使罪人之间互相猜忌。

### 4.4 沃格雷夫与其他目标的博弈

| 博弈关系 | 说明 |
| :--- | :--- |
| **全灭 vs 生存** | 沃格雷夫的目标与隆巴德、麦肯锡的生存目标直接冲突。沃格雷夫可能会优先解决拥有暗杀能力的生存者 |
| **全灭 vs 守护** | 沃格雷夫需要确保托马斯和艾瑟尔都死。如果艾瑟尔先坦白，她可能被纳入审判者阵营——但这不等于沃格雷夫会放过她 |
| **全灭 vs 嫁祸** | 维拉的嫁祸计划可能导致布伦特被投票指认——这正是沃格雷夫想看到的：罪人互相残杀 |
| **全灭 vs 逃脱** | 阿姆斯特朗想逃脱。沃格雷夫必须在他逃脱之前阻止他——否则全灭目标无法完成 |
| **全灭 vs 坦白** | 艾瑟尔想坦白。沃格雷夫可能利用她的坦白来揭露其他罪人的罪行，但不代表他会放过她 |


## 五、玩家体验示例

### 5.1 单人模式：你扮演沃格雷夫

你坐在客厅的壁炉前，看着其他人。隆巴德在检查窗户的锁，维拉在低声与布伦特交谈，阿姆斯特朗在喝威士忌——他的手在抖。所有人都知道自己是罪人。所有人都知道暴风雨不会很快结束。

你的内心独白：“我曾判处一个无辜的人死刑。今天，我不会再犯同样的错误。这八个人——每个人都有罪。童谣预言了他们的死亡。我不会杀人。我只是创造让罪人自食其果的条件。”

当隆巴德扼杀布伦特时，你没有阻止。当艾瑟尔崩溃自杀时，你没有安慰。当麦肯锡认罪后跳楼时，你只是看着。你在等待。等待最后一个罪人倒下。然后你走向暴风雨，没有回头。

### 5.2 多人模式：你是隆巴德，另一位玩家是沃格雷夫

你不知道沃格雷夫的目标是全灭。你只知道他坐在壁炉前，安静地观察所有人。他看起来像是一个无害的老人。但你注意到了——每次有人在走廊尽头消失，沃格雷夫的眼睛都会微微亮起。每次有人崩溃大哭，沃格雷夫的嘴角都会闪过一丝微笑。

你开始怀疑他不是在追凶。他是在等待什么。当你在某天深夜看到他从阿姆斯特朗的房间方向走来，手里拿着什么——你意识到，他可能是这座岛上最危险的人。而你的生存目标，正在与他正面冲突。


## 六、重玩价值

| 变量 | 每次开局的变化 |
| :--- | :--- |
| **沃格雷夫的目标** | 在多数开局中，沃格雷夫被分配“全灭”目标。但在某些随机局中，他可能被分配“追凶”目标——此时他不再主动杀人，而是试图通过投票来审判罪人 |
| **全灭的执行方式** | 每次开局，沃格雷夫使用的全灭手段不同——他可能通过心理逼迫让罪人自杀，可能暗中操纵隆巴德去杀人，可能在暴风雪最猛烈时破坏庇护所 |
| **其他角色的应对** | 隆巴德可能察觉到沃格雷夫的阴谋，维拉可能在嫁祸过程中意外协助了沃格雷夫的审判，阿姆斯特朗的逃脱计划可能与沃格雷夫的全灭计划产生意外冲突 |

**一句话总结**：沃格雷夫的目标不是追凶——是“全灭”。他以审判者自居，用心理逼迫、暗中操纵、环境致死等手段，确保所有被唱片指控的罪人都受到惩罚。其他角色的生存、守护、逃脱、嫁祸、坦白目标，在这场审判中与他产生复杂的博弈。每一局，沃格雷夫的全灭方式都不同，罪人们的应对也不同——这正是《开本》改编《无人生还》的真正可玩性所在。
