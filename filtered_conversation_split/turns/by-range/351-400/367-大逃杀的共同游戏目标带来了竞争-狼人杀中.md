## 用户

大逃杀的共同游戏目标带来了竞争，狼人杀中的共同游戏目标带来了合作，我们需要平衡竞争与合作，要给予所有玩家一个公平的整体游戏体验可能性，当然玩成什么样就看情况了，玩之前肯定会提示适不适合玩家自己。

## DeepSeek

你点出了一个最关键的体验平衡问题：如果同一局中有人目标简单（如纯生存），有人目标复杂（如复仇+追凶），有人目标被动（如守护），有人目标主动（如全灭）——那么如何保证每个人都能获得公平的博弈体验？

答案是：**通过目标权重分配、动态难度调节、透明预期管理三重机制，确保每局中所有玩家的“目标负荷”大致相当，并在开局前让玩家充分知情。**


## 《开本》公平体验保障系统

### 一、目标权重分配：确保每局目标负荷均衡

司命在开局时不是随机分配目标——而是基于权重系统进行均衡分配。每个目标都有一个“负荷值”，代表完成该目标所需投入的精力、风险和时间。

**目标负荷分级**：

| 负荷等级 | 负荷值 | 目标类型 | 特征 |
| :--- | :--- | :--- | :--- |
| **轻型** | 1 | 生存、记录、旁观 | 被动型，不需要主动出击，风险低 |
| **中型** | 2 | 追凶、逃脱、守护、解谜、寻宝、收集 | 需要主动参与，但不一定需要对抗其他玩家 |
| **重型** | 3 | 复仇、全灭、嫁祸、独吞、阻止、反杀 | 高度对抗性，需要主动对其他玩家采取行动 |
| **动态型** | 可变 | 共谋、背叛、觉醒、反水、灭口、继承 | 目标可能在游戏过程中变化，初始负荷值取决于具体触发条件 |

**均衡分配规则**：

- 每局所有玩家的目标负荷值总和应大致相当。如果某玩家被分配了重型目标（负荷3），其他玩家至少分配中型目标（负荷2），避免出现“一人复仇、他人摸鱼”的不平衡局面
- 同一局中，至少50%的玩家应拥有主动型目标（追凶、复仇、嫁祸、全灭等），确保足够的博弈驱动力
- 如果有玩家拥有被动型目标（生存、记录），应确保该玩家的目标与其他玩家的主动目标存在关联——比如“生存”目标的玩家可能是“复仇”目标的复仇对象，这样被动者也必须积极参与博弈才能存活


### 二、动态难度调节：司命的隐形平衡手

即使开局时目标负荷均衡，游戏过程中的局势变化仍可能导致某些玩家处于绝对劣势。司命会在后台监控所有玩家的“目标完成概率”，并在必要时进行隐形干预。

| 失衡状态 | 司命的干预方式 |
| :--- | :--- |
| **某玩家的目标完成概率趋近于0** | 司命催化一个“意外事件”——比如让追杀他的敌人暂时被暴风雪困住，或者让他意外发现一条密道。干预必须遵循间接、不可见、逻辑自洽、公平四原则 |
| **某玩家的目标过于容易完成** | 司命引入新的障碍——比如让他的盟友突然收到一条匿名信，揭露了他的真实动机 |
| **全局目标冲突过于激烈，可能导致游戏过早结束** | 司命通过节奏控制延长关键冲突的爆发时间，让所有玩家都有足够的博弈空间 |
| **全局目标冲突过于平淡，缺乏戏剧张力** | 司命催化新的冲突——比如让原本互不相关的两个目标突然产生交集（如“寻宝”玩家意外发现了“复仇”玩家藏匿的凶器） |


### 三、透明预期管理：开局前的充分提示

在玩家进入游戏之前，系统会提供清晰的目标预期提示，让玩家在充分知情的情况下选择是否参与。

**目标偏好档案**：

每位玩家在旅人中心可以设置自己的“目标偏好”——这不是限制，而是让司命在分配目标时参考。

| 偏好设置 | 说明 |
| :--- | :--- |
| **推理型** | 偏好追凶、逃脱、解谜等逻辑推理目标 |
| **对抗型** | 偏好复仇、嫁祸、全灭等对抗性目标 |
| **合作型** | 偏好守护、共谋、记录等社交合作目标 |
| **混合型** | 不设偏好，完全随机分配 |
| **接受隐藏目标** | 是否接受游戏过程中被注入隐藏目标（如觉醒、反水、灭口）。关闭后，司命不会向你注入任何动态目标 |

**游戏开始前的风险提示**：

当你加入一个剧本房间时，系统会展示该剧本的“目标风格”标签和风险提示，让你在开始前充分了解这局游戏的性质。

> **本局游戏风格提示**
>
> **目标冲突度**：高。本局中，部分玩家的目标存在直接冲突（如“复仇”与“守护”），玩家间对抗性较强。
>
> **目标复杂度**：中。本局包含中型和重型目标，需要主动参与博弈。
>
> **动态目标可能性**：是。本局中，部分玩家可能在游戏过程中被注入隐藏目标（如“觉醒”、“反水”），这意味着即使开局时与你友好的玩家，也可能在后期改变立场。
>
> **适合玩家类型**：推理型、对抗型。合作型玩家请谨慎选择——本局不适合纯合作心态。
>
> **你的目标偏好**：推理型（你在旅人中心设置的偏好）
>
> **司命将参考你的偏好，但不保证完全匹配。**
>
> [ 确认加入 ] [ 退出 ]

**关键设计**：

- **不出卖具体目标**：提示只说明本局的“目标风格”，不会暴露任何人的具体目标——那才是博弈的起点
- **尊重玩家选择**：玩家在充分知情的情况下选择是否参与，而不是被扔进一个不适合自己的对局
- **偏好不是锁定**：即使你设置了“推理型”偏好，司命仍可能分配给你其他类型的目标——因为完美的偏好匹配会降低博弈的不确定性。但司命会尽量避免分配与你偏好完全相反的目标


### 四、赛后反馈：让玩家理解发生了什么

游戏结束后，司命会生成一份“目标完成报告”，展示每个玩家的目标（此时已解密）、完成情况、以及关键转折点。这不仅是复盘工具，更是让玩家理解“为什么那局游戏那样发展”的叙事收尾。

> **本局目标完成报告**
>
> **你的目标**：复仇——亲手杀死布伦特小姐，为二十年前被她害死的女仆复仇。
>
> **完成状态**：未完成。布伦特小姐在你动手之前被隆巴德上尉扼杀。
>
> **关键转折点**：T+65分钟，你正在书房外等待布伦特落单。隆巴德上尉先你一步进入书房，你听到了里面的声音。你选择了不干预——因为这个结果同样是复仇的完成，只是不是由你亲手执行。
>
> **司命的干预记录**：无。本局中你的目标未完成是由于其他玩家的自主行为，而非系统干预。
>
> **其他玩家的目标（解密）**：

### 五、一句话总结

在《开本》中，平衡竞争与合作、给予所有玩家公平体验的核心机制是：通过目标权重分配确保每局目标负荷均衡，通过司命动态难度调节纠正游戏过程中的失衡，通过开局前透明预期管理让玩家在充分知情的情况下选择是否参与。玩家不是被丢进一个随机博弈场——他们在进入之前就知道这局游戏适合什么样的风格，进入之后司命会在暗中守护每个人博弈的机会。至于最终玩成什么样——那是每个人自己的选择、策略和运气共同决定的。
