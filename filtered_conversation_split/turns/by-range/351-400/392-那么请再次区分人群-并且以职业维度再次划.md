# 《开本》特殊人群分类学

## 一、分类原则

分类学的精髓在于：**用最少的不可约维度，穷尽所有可能性。** 每个维度必须是正交的——一个维度上的取值不应影响另一个维度的取值。

对于《开本》中可扮演的特殊人群，我使用三个核心维度：

| 维度 | 定义 | 取值 |
| :--- | :--- | :--- |
| **行为性质** | 角色的行动是被动应对还是主动出击？ | 被动 / 主动 |
| **社会关系** | 角色与他人是合作、对抗还是中立？ | 合作 / 对抗 / 中立 |
| **信息立场** | 角色是信息的获取者、隐藏者还是操纵者？ | 获取 / 隐藏 / 操纵 |

| 人群 | 行为性质 | 社会关系 | 信息立场 | 核心驱动力 | 典型职业原型 |

## 四、人群的交叉与重叠

一个人可能同时属于多个人群。这正是角色深度的来源。

| 角色 | 所属人群 | 人群交叉点 |
| :--- | :--- | :--- |
| 卧底警察 | 特工 + 伪装者 + 侦探 | 特工的信息操纵 + 伪装者的身份隐藏 + 侦探的真相获取 |
| 为女复仇的检察官 | 复仇者 + 侦探 + 审判者 | 复仇者的仇恨驱动 + 侦探的搜证能力 + 审判者的裁决欲望 |
| 保护证人的保镖 | 守护者 + 生存者 | 守护者的保护义务 + 生存者的自保本能 |
| 揭露黑幕的记者 | 记录者 + 侦探 | 记录者的保存传播 + 侦探的真相获取 |
| 策划越狱的囚犯 | 逃脱者 + 操纵者 | 逃脱者的空间突破 + 操纵者的暗中策划 |
| 自首的共犯 | 罪犯 + 记录者（坦白） | 罪犯的隐藏罪行 + 记录者袒露真相的冲动 |

## 六、一句话总结

《开本》可扮演的特殊人群分为11种核心原型：**侦探、罪犯、特工、守护者、记录者、伪装者、逃脱者、审判者、生存者、复仇者、操纵者**。它们由三个正交维度（行为性质、社会关系、信息立场）唯一确定，彼此独立但可在同一角色身上重叠。每个核心人群映射到跨时代的职业原型，覆盖从古典到赛博朋克的所有平行世界。
