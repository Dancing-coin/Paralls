# 《开本》玩法支持能力分析

## 一、玩法不是“枚举”出来的，而是“组合”出来的

《开本》的玩法不是预设的有限列表，而是由四个维度自由组合而成的矩阵：

| 维度 | 选项 | 数量 |
| :--- | :--- | :--- |
| **玩法类型** | 推理博弈、社交博弈、生存对抗、角色扮演、探索解谜、策略经营、集体叙事 | 7种 |
| **核心目标** | 追凶、逃脱（凶手）、生存、守护、复仇、嫁祸、逃脱（空间）、坦白 | 8种 |
| **特殊人群** | 调查者、隐匿者、操控者、守护者、记录者、伪装者、逃脱者、审判者、生存者、复仇者、阴谋家 | 11种 |
| **叙事框架** | 本格推凶、故事还原、阵营对抗、情感沉浸、恐怖惊悚、机制对抗、欢乐轻松、立意深思 | 8种 |

**理论组合数**：7 × 8 × 11 × 8 = **4,928种**。当然，并非所有组合都有意义——但即使去除不合理组合（如“欢乐轻松+审判者+全灭”），有效组合仍在数千种以上。

## 六、三阶段玩法支持路线图

| 阶段 | 核心验证玩法 | 扩展玩法 |
| :--- | :--- | :--- |
| **Phase 1** | 硬核推凶、案中案、多目标博弈 | 情感沉浸、恐怖生存、密室逃脱 |
| **Phase 2** | 阵营对抗、恋爱模拟、时间循环 | 社交推理、故事还原 |
| **Phase 3** | 种田经营、SLG策略、集体叙事 | 开放世界RPG、MMORPG式活态世界 |


## 七、一句话总结

《开本》能支持的玩法不是“多少种”的简单枚举，而是由**玩法类型、核心目标、特殊人群、叙事框架**四个维度自由组合而成的**数万种有效玩法变体**。Phase 1已验证核心推理博弈和多目标博弈的可行性，Phase 2将扩展至阵营对抗和情感陪伴，Phase 3将解锁经营策略和集体叙事。不适合的类型仅限于“核心乐趣在物理操作和实时反应”的非角色博弈游戏。
