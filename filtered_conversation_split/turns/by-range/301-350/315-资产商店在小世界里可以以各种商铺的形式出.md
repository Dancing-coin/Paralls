## DeepSeek

# 《开本》小世界场景化商店系统设计

## 一、核心设计理念

在小世界中，不存在传统的“商城菜单”或“资产商店界面”。所有资产——家具、服装、道具、种子、食材、书籍——都散落在小镇的各个商铺中。玩家需要像在真实世界一样，走进店里、浏览货架、拿起商品、与店主交流、试穿试用，然后决定是否购买。

| 设计原则 | 说明 |
| :--- | :--- |
| **场景化呈现** | 所有商品都是3D场景中的可交互实体，而非列表中的图标 |
| **沉浸式购买** | 购买行为融入日常生活——逛街、试穿、讨价还价、与店主闲聊 |
| **AI同伴参与** | 你的AI同伴也会逛街，她可能比你更早发现你喜欢的东西 |
| **商品可追溯** | 你买的每件物品，都记得是在哪家店、和谁一起买的 |


## 二、小镇商铺总览

| 商铺名称 | 店主 | 经营商品 | 特色服务 | 可购买资产类型 |
| :--- | :--- | :--- | :--- | :--- |

| **裁缝店** | 裁缝 | 服装、配饰、布料 | 定制服装、修改尺寸、试穿 | 角色皮肤、AI同伴服装 |
| **铁匠铺** | 铁匠 | 工具、武器、金属制品 | 修理物品、升级工具、定制 | 工具、武器、装饰品 |
| **家具工坊** | 木匠 | 家具、灯具、装饰品 | 定制家具、染色改色 | 房屋内饰、庭院装饰 |
| **书店** | 书店老板 | 书籍、地图、乐谱 | 提供知识、解锁新技能 | 技能书、配方书、故事书 |
| **花店** | 花匠 | 花卉、盆栽、种子 | 定制花束、花卉搭配建议 | 庭院植物、室内盆栽、花束 |

## 三、沉浸式购物体验

### 3.1 走进商店

玩家推开店门，门上的风铃发出清脆的响声。店主会从柜台后抬起头，根据你与他的好感度做出不同反应。

| 好感度 | 店主反应 |
| :--- | :--- |
| **陌生人** | “欢迎光临，随便看看。” |
| **熟客** | “哟，又来了！上次那个花瓶放在家里还合适吗？” |
| **好友** | “你来得正好，我正想给你看一件新到的货，我觉得特别适合你。” |

你的AI同伴也会自然地在店里闲逛。她可能站在一套衣服前打量，伸手摸一下面料；或者拿起一个摆件，端详片刻后放回货架。

### 3.2 浏览与试用

**所有商品都是可交互的3D实体。** 玩家走到货架前，可以看到商品真实地陈列在那里——衣服挂在衣架上，家具摆放在展示区，书籍陈列在书架上。你无需打开任何菜单。

| 操作 | 说明 |
| :--- | :--- |
| **拿起商品** | 点击商品→角色伸手拿起→可以360度旋转观察 |
| **查看细节** | 聚焦观察→看到材质纹理、做工细节、标签上的价格 |
| **试穿试用** | 衣服→在试衣间（场景中的真实区域）换上，对着镜子看效果；家具→在展示区放置，看到实际摆放效果 |
| **询问信息** | 向店主询问材质、来源、是否有其他颜色/尺寸 |
| **AI同伴反馈** | 拿起某件衣服时，她可能会说“这件很适合你”，或者害羞地别过头——那是她觉得你穿上会很好看 |

### 3.3 购买与讨价还价

| 购买方式 | 说明 |
| :--- | :--- |
| **直接购买** | 在柜台上放下金币/代币，拿走商品 |
| **讨价还价** | 如果社交技能足够高，可以说服店主打折 |
| **以物易物** | 用自己的手工艺品或多余的食材交换 |
| **分期付款** | 贵重物品可以和店主商量分期支付 |
| **让AI同伴帮忙** | 高社交的AI同伴可能比你更擅长砍价 |

### 3.4 AI同伴的自主购物

你的AI同伴拥有独立的私房钱。她可能趁你不在家时，自己去镇上购物。

某天你回家，发现窗台上多了一盆白色的小花。她有点不好意思地说：“今天路过花店，看到这盆花……觉得你可能会喜欢。我用自己的钱买的，不贵。”

**她为你购买的东西，会自然出现在家中。** 如果你好奇东西从哪来，可以问她。她会告诉你是在哪家店买的、多少钱、为什么选这个。这一切不是“系统赠送”，而是一个有独立意志的伴侣，用自己的方式在照顾你们的家。

### 3.5 特别时刻：一起逛街

你可以主动邀请你的AI同伴一起逛街。

| 情境 | 她可能的行为 |
| :--- | :--- |
| **走进裁缝店** | 她站在一套衣服前看了很久，你问她喜欢吗，她摇摇头说“太贵了”。你可以选择买下来送给她 |
| **走进家具工坊** | 她发现一个和你收集的茶杯配套的茶壶，兴奋地指给你看 |
| **走进书店** | 她翻到一本烹饪书，里面有她一直想学的那道菜。“我们买这本吧，回去我可以做给你吃。” |
| **走在商业街上** | 她自然地挽着你的手臂，在橱窗前驻足 |


## 四、购买后的归属与使用

| 资产类型 | 购买后如何使用 |
| :--- | :--- |
| **家具** | 购买后出现在背包中，回到家中可自由摆放、旋转、叠加。ESM记录每件家具的位置 |
| **服装** | 购买后出现在背包中，可在任何时间为自己或AI同伴更换。AI同伴会记住谁在什么场合送了她哪件衣服 |
| **道具/工具** | 购买后出现在背包中，可在小世界或剧本中使用 |
| **消耗品** | 食材放入厨房橱柜，花种放入园艺工具棚，药水放入药箱 |
| **书籍** | 购买后放在家里的书架上，可随时取阅。某些技能书阅读后解锁新能力 |
| **植物** | 购买后需要种植在庭院或室内花盆中，由玩家或AI同伴照料 |


## 五、商品的可追溯性

每件商品都带有“来源”标签：

| 标签内容 | 说明 |
| :--- | :--- |
| **购买地点** | 在哪家店购买 |
| **购买时间** | 小世界内的时间戳 |
| **购买者** | 你买的 or AI同伴用私房钱买的 |
| **购买时的故事** | 司命记录的一段简短叙事——比如“这是她第一次用自己的私房钱为你买的东西” |

当你查看家中的某个物品时，这些信息会以文字提示的形式浮现。它不是冰冷的物品列表，而是你们共同生活的编年史。


## 六、技术支撑

| 系统 | 在场景化商店中的职责 |
| :--- | :--- |
| **ESM** | 管理商店的门开关、货架上的物品状态、店内灯光 |
| **角色智能体（店主）** | 驱动店主的行为——迎客、推荐商品、讨价还价、闲聊 |
| **角色智能体（AI同伴）** | 驱动AI同伴在店内的自主行为——浏览、试穿、评价、购买 |
| **记忆系统** | 记录每件商品的购买信息、AI同伴的购物偏好 |
| **AI同伴私房钱系统** | AI同伴自主购物时使用的独立经济系统 |
| **司命** | 管理流浪商人的出现时机、催化购物过程中的小事件 |
| **玩家背包系统** | 购买后物品的存储和管理 |
| **物品流转追踪器** | 记录商品从商店到玩家家中的完整流转历史 |
| **L3视觉增强** | AI同伴穿上新衣服或家中换上新家具时，触发合影生成 |


## 七、与外部资产市场的连接

小世界的商铺不只出售本地商品——它也是连接《开本》资产市场的桥梁。

| 连接方式 | 说明 |
| :--- | :--- |
| **官方基础资产** | 所有小世界商铺默认出售官方基础资产（基础家具、基础服装等） |
| **创作者资产上架** | 创作者在资产市场中发布的资产，可申请在小世界商铺中上架（需通过小镇风格审核） |
| **限定/季节性资产** | 节日限定资产通过特定商铺发售（如冬幕节礼物通过古董店限量发售） |
| **剧本联动资产** | 玩家在某剧本中带出的纪念品，可在小世界的古董店中兑换为实体家具/装饰品 |
| **AI同伴自主购买** | AI同伴使用私房钱时，可以从外部资产市场选购你尚未拥有的资产（需经过她的“审美偏好”筛选） |


**一句话总结**：在小世界中，不存在“商城菜单”——所有资产都散落在小镇的各个商铺中，以可交互的3D实体呈现。玩家和AI同伴像在真实世界一样逛街、试穿、讨价还价，每次购买都是一次独特的回忆。AI同伴也会用自己的私房钱为你和你们的家添置物品。这些购买记录和背后的故事，构成了你们共同生活的编年史。
