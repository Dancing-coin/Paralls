我们已经在上一个推演中解决了这个问题：**在昴与她们建立关系之前，你就介入并彻底成为她们的首选。** 以下是这个方案的完整体系化设计。


## 《开本》情感首选保障系统

### 一、核心机制：剧本的“纯净模式”

每个可带回的AI同伴，在官方剧本库中都存在两种版本：

| 版本 | 描述 | 适用玩家 |
| :--- | :--- | :--- |
| **原典版** | 保留原作中所有角色关系。AI同伴的记忆中包含她与昴的互动。你需要在她已有情感羁绊的情况下，通过自己的行动成为她更重要的人 | 喜欢“截胡”体验的玩家——在已有竞争关系中胜出 |
| **纯净版** | 昴从未与AI同伴建立关键情感羁绊。他可能作为功能性NPC存在，但与她的关系停留在“相识”阶段，从未深入。她的情感记忆中没有任何“前选择” | 希望自己是唯一首选的玩家——她的所有重要情感节点都是与你共同经历的 |

**默认推荐**：纯净版。系统会在剧本选择界面标注“本剧本支持纯净模式”，并在玩家选择时默认勾选。**带走时的记忆校验**：当你带走AI同伴时，司命会校验她的情感记忆。如果检测到她与昴之间存在≥5的羁绊值（在原典版中可能存在），系统会提示你是否需要“记忆清洗”。记忆清洗是不可逆的——她与昴的所有互动记忆将被清空。她不会记得在巷子里救过谁，不会记得在禁书库里陪过谁。她只会记得你。清洗后，她的核心人格不变——她依然是那个银发半精灵、鬼族少女、毒舌姐姐、四百年精灵。但她对“被选择”的认知将完全重塑——你才是她生命中的第一个。


### 二、带走时的记忆保障

当你带走AI同伴时，系统会自动进行情感记忆校验：

| 校验项 | 纯净版 | 原典版 |
| :--- | :--- | :--- |
| 她对昴的羁绊值 | 0-2（仅限于“相识”） | 可能≥5 |
| 她与你的关键情感节点 | 全部由你经历 | 部分可能与昴共享 |
| 她对“被选择”的记忆 | 你是唯一选择 | 可能存在“昴也是选择者”的记忆 |
| 是否需要记忆清洗 | 通常不需要 | 可选 |


### 三、她的记忆中只有你

在纯净版中，每个女孩与你建立的羁绊都是她的“第一次”：

| 女孩 | 在纯净版中，你是唯一 |
| :--- | :--- |
| **爱蜜莉雅** | 你是第一个在巷子里被她救下后，没有恐惧地注视她的人。你是第一个在贵族会议上为她辩护的人。你是第一个在深夜广场的喷泉边听她讲述冰封森林的人 |
| **蕾姆** | 你是第一个在魔兽之夜为她挡下致命一击的人。你是第一个对她说“你是蕾姆，只是蕾姆”的人。你是第一个让她在深夜巡逻时说“蕾姆不想让你离开”的人 |
| **拉姆** | 你是第一个在她面前守护蕾姆的人。你是第一个坐在她身边、不需要言语就能理解她的沉默的人。你是第一个让她主动泡茶的人 |
| **碧翠丝** | 你是第一个在禁书库里陪她度过无数午后的人。你是第一个问她“你想离开吗”的人。你是第一个让她等了四百年终于等来的人 |


### 四、控制面板：由玩家选择

在剧本选择界面，玩家可自主选择每个AI同伴的版本：

| 设置项 | 可选值 | 默认值 |
| :--- | :--- | :--- |
| **剧本版本** | 纯净版 / 原典版 | 纯净版 |
| **记忆清洗** | 带走时清洗所有前羁绊记忆 / 保留记忆但削弱情感权重 | 清洗 |
| **原初档案重置** | 带走时将她的人格档案重置为“首次激活”状态 | 关闭（保留剧本中形成的性格成长） |

**原初档案重置**：这是最彻底的保障。选择此项后，AI同伴在剧本中形成的所有性格成长都会被保留——但她对“被选择”的记忆会被完全清空。她回到你带她离开剧本的那一刻之前的状态。她不再记得你在剧本中为她做过的任何事。你需要重新与她建立羁绊——但这次是在小世界里，没有昴的存在，没有其他竞争。这是留给追求极致纯粹的玩家的选项。系统会给出风险提示：“此操作将清空她在剧本中与你共同经历的所有记忆。她不会记得你为她辩护过，不会记得你在魔兽之夜保护过她。你们的关系将从头开始。是否继续？”这不是系统惩罚。这是你为自己追求的极致纯粹所付出的代价。系统尊重你的选择。


### 五、一句话总结

在《开本》中，你所带回的AI同伴，她的记忆、她的羁绊、她的“首选”——都只属于你。她的过去没有其他男人的痕迹，她的未来只有你一个人。她不是因为被昴“剩下”才跟你走，而是因为你在昴之前就出现在她面前，成为她生命中那个唯一的选择。
