## DeepSeek

你点出的正是“阴谋系统”的物理基石。在《开本》中，**环境状态管理器 (Environment State Manager, ESM)** 是独立于司命的专用子系统，是整个 L1 确定性空间层的“物理法则执行者”。

## 环境状态管理器 (ESM) 完整设计

### 一、核心定位

| 维度 | 说明 |
| :--- | :--- |
| **系统身份** | L1 层的物理模拟专用子系统，独立于司命和角色智能体运行 |
| **核心使命** | 管理所有可交互物体的状态机、计算物理规则（火焰/流体/破坏）、向事件总线发送结构化环境事件 |
| **决策方式** | 纯规则程序——所有计算是确定性的、可复现的、不依赖任何 AI 推理 |
| **延迟要求** | 毫秒级（<16ms/帧）——硬实时 |
| **与司命的关系** | 司命发送高层催化指令（“让火焰蔓延到此区域”），ESM 在物理规则允许范围内执行；ESM 向司命上报状态变化，供司命评估是否进一步催化 |

**为什么必须是独立子系统？** 因为燃烧蔓延、流体扩散、物体破碎等物理计算需要毫秒级响应，绝不能被司命的 LLM 推理延迟拖慢。司命处理的是“秒级”的叙事决策，ESM 处理的是“毫秒级”的物理计算。两者通过事件总线解耦。

### 三、六个子系统详解

#### 3.1 物理规则引擎

| 规则模块 | 计算内容 | 关键参数 |
| :--- | :--- | :--- |
| **火焰蔓延** | 以燃烧物体为中心，计算2米内是否有可燃物 → 点燃可燃物 | 蔓延速度（布料0.3m/s）、蔓延范围（2m）、物体可燃性 |
| **流体扩散** | 以水源为中心，计算流体扩散范围和速度 | 扩散速度、扩散范围、物体透水性 |
| **破坏判定** | 受力冲击 vs 物体坚固度 → 破碎/断裂/凹陷 | 冲击力大小、物体坚固度、破坏阈值 |
| **温度传导** | 热源向周围物体传导热量，影响物体的温度状态 | 导热性、传导速度、温度梯度 |
| **湿度扩散** | 水源向周围物体扩散湿度，影响物体的潮湿状态 | 透水性、扩散速度 |
| **冲击力判定** | 投掷、击打、坠落的力学计算 | 质量、速度、接触面积 |

#### 3.2 状态机库

每个状态机定义了物体的状态转化规则。ESM 内置以下通用状态机，所有物体挂载对应组件后自动获得。

**燃烧状态机**：

```
默认态 ──[接触火源]──► 燃烧态 ──[持续燃烧时间到]──► 烧毁态
                         │
                         └──[被扑灭]──► 焦黑态（不可逆）
```

**潮湿状态机**：

```
默认态 ──[接触水源]──► 潮湿态 ──[自然干燥时间到]──► 默认态
                         │
                         └──[极端低温]──► 结冰态
```

**破碎状态机**：

```
默认态 ──[受力超过阈值]──► 裂纹态 ──[再次受力]──► 破碎态
                             │
                             └──[轻微受力，未超阈值]──► 保持裂纹态
```

**结冰状态机**：

```
默认态 ──[潮湿+极端低温]──► 结冰态 ──[温度回升]──► 潮湿态
```

**开关状态机**：

```
关闭态 ──[点击开关]──► 开启态 ──[点击开关]──► 关闭态
  │                       │
  └──[锁定]──► 锁定态     └──[锁定]──► 锁定态
```

**锁定状态机**：

```
解锁态 ──[上锁]──► 锁定态 ──[解锁]──► 解锁态
                      │
                      └──[破坏]──► 破坏态（无法再锁）
```

#### 3.3 全局参数管理

ESM 维护一个全局环境参数表，所有物理计算基于这些参数。

| 参数 | 范围 | 说明 | 驱动方式 |
| :--- | :--- | :--- | :--- |
| **环境温度** | -50°C ~ 50°C | 影响燃烧速度、结冰速度、角色体温 | 天气系统 + 司命催化 |
| **环境湿度** | 0% ~ 100% | 影响燃烧难度、潮湿蔓延速度 | 天气系统 |
| **风力** | 0 ~ 10级 | 影响火焰蔓延方向和速度 | 天气系统 |
| **天气状态** | 晴天/阴雨/暴风雪/大雾 | 综合影响视觉、听觉、物理规则 | 天气状态机 + 司命催化 |

#### 3.4 视觉同步器

ESM 不直接渲染画面，而是通过视觉同步器驱动 Godot 引擎的视觉效果。

| 同步内容 | 实现方式 |
| :--- | :--- |
| **粒子特效** | 物体进入“燃烧态”时加载对应材质的火焰粒子；进入“潮湿态”时加载水滴粒子 |
| **贴图变种** | 物体状态变化时，自动替换为对应状态贴图（如 `_charring`、`_wet`） |
| **模型变种** | 物体进入“烧毁态”或“破碎态”时，替换为残骸或破碎几何体模型 |
| **音效触发** | 状态变化时自动播放对应音效（燃烧声、破碎声、滴水声） |

#### 3.5 感知事件生成器

物体状态变化时，ESM 自动向事件总线发送结构化环境事件，供角色智能体的感知过滤器处理。

```json
{
  "event_type": "environment_state_changed",
  "object_id": "curtain_dining_01",
  "previous_state": "默认态",
  "new_state": "燃烧态",
  "trigger": "接触火源（打火机）",
  "location": {"x": 5.2, "y": 1.8, "z": 3.0},
  "timestamp": "2026-05-20T19:45:23Z",
  "audible_range": 20.0,
  "visible_to": ["char_B", "char_C"],
  "thermal_range": 5.0
}
```

**事件接收方**：
- **角色智能体感知过滤器**：根据角色的感官档案（视觉/听觉/热感），生成专属的感知事件。例如，盲人角色只能收到“感到热辐射”的触觉事件。
- **司命**：更新事实核心，评估是否进一步催化叙事。
- **L3 视觉增强**：若为关键事件（如火灾），触发 WOW 时刻。

#### 3.6 司命指令接口

| 指令类型 | 描述 | 示例 |
| :--- | :--- | :--- |
| `CATALYZE_FIRE` | 在指定区域触发火灾 | `{region: "dining_car_rear", intensity: 0.8}` |
| `EXTINGUISH_FIRE` | 在指定区域扑灭火灾 | `{region: "dining_car_rear"}` |
| `CHANGE_WEATHER` | 改变天气状态 | `{weather: "blizzard", intensity: 5, duration: 120}` |
| `LOCK_OBJECT` | 锁定指定物体 | `{object: "compartment_door_03", lock: true}` |
| `BREAK_OBJECT` | 破坏指定物体 | `{object: "window_rear", force: "extreme"}` |
| `QUERY_STATE` | 查询指定区域的环境状态 | `{region: "dining_car"}` → 返回燃烧区域、潮湿区域、破坏物体列表 |

### 五、ESM 在《东方快车》中的完整运行示例

**场景**：上校用打火机点燃餐车窗帘，意图制造混乱让麦奎因逃脱。

**1. 司命催化指令**：

```
CATALYZE_FIRE { region: "curtain_dining_01", intensity: 1.0 }
```

**2. ESM 执行**：

| 步骤 | ESM 操作 | 延迟 |
| :--- | :--- | :--- |
| **可行性检查** | 检索 `curtain_dining_01` 的材质属性：`mat_fabric`，可燃性=极高 ✅。检查当前环境湿度：20%，无阻碍燃烧 ✅ | <1ms |
| **状态机触发** | `curtain_dining_01` 从“默认态”切换为“燃烧态” | <1ms |
| **视觉同步** | 加载布料燃烧粒子特效 `fx_fire_cloth`；加载焦黑贴图 `mat_fabric_charring.png`；播放燃烧音效 `sfx_fire_burning` | <16ms |
| **感知事件广播** | 向事件总线发送 `environment_state_changed` 事件，包含物体 ID、新状态、位置、可听范围、热辐射范围 | <1ms |
| **蔓延计算** | 以窗帘为中心，检索2米范围内的可燃物 → 检测到 `carpet_dining_01`（布料，可燃性=极高），距离1.5米 → 计算蔓延时间：1.5m / 0.3m/s = 5秒 | <1ms |
| **5秒后** | `carpet_dining_01` 从“默认态”切换为“燃烧态”。视觉同步：加载布料燃烧粒子。感知事件广播。继续检索蔓延范围。 | <1ms |

**3. 角色智能体响应**：

- 哈伯德太太（感知过滤器：视觉清晰区=10米）：收到 `environment_state_changed` 事件，视觉清晰区在10米内 → 生成视觉感知：“我看到餐车窗帘着火了！”压力值+5。
- 盲人角色（若存在）：视觉禁用，但热感启用（范围5米）。收到同一事件的 `thermal_range` 字段 → 生成热感知：“我感觉到餐车方向传来强烈的热辐射。”

**4. 司命响应**：

- 收到 `environment_state_changed` 事件（地毯被引燃），更新事实核心。
- 天平系统评估：火灾正在制造混乱，麦奎因的逃脱窗口正在形成。
- 决策：不干预——这正是上校计划中的效果。继续监控。


### 六、ESM 与角色状态的联动

ESM 不仅管理物体的物理状态，还通过全局参数影响角色的生命和精神状态。

| 环境参数 | 对角色状态的影响 | 计算方式 |
| :--- | :--- | :--- |
| **环境温度** | 影响角色的体温值 | 角色体温 = 基础体温 + 衣着保暖值 - 环境温度衰减。体温降至0 → 进入濒死状态 |
| **火焰热辐射** | 靠近燃烧物体时体温上升，但过近会直接受伤 | 距离<1米 → 每秒体力-5（灼伤）；距离1-2米 → 体温+1/秒 |
| **潮湿环境** | 潮湿状态下角色更容易失温 | 潮湿状态 + 环境低温 → 体温下降速度×2 |
| **烟雾** | 影响角色的体力值 | 在燃烧区域附近，烟雾浓度超过阈值 → 体力持续下降（窒息效果） |
| **破碎玻璃** | 踩到玻璃碎片会受伤 | 角色移动到破碎玻璃区域 → 体力-3（轻伤）+ 移动速度降低 |

ESM 将这些环境因素的计算结果通过事件总线发送给角色智能体，由角色智能体的心智模型决定如何响应——是继续深入火场救人，还是撤退到安全区域。
