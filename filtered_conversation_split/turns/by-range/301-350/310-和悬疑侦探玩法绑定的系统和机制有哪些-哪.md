## 侦探玩法绑定 vs 全玩法通用：系统与机制分类


### 一、悬疑侦探玩法绑定系统

这些系统是专门为“找出真相”这一核心循环服务的，在其他类型剧本中不存在或仅以简化形式存在。

| 系统/机制 | 在侦探玩法中的角色 | 为何绑定侦探玩法 |
| :--- | :--- | :--- |
| **案件生成规则引擎** | T0-T2事实锁定、死因池/动机池/凶器池随机抽取、凶手身份动态生成 | 非侦探剧本无“案件”概念——恋爱本无凶杀，种田本无推理 |
| **线索系统** | 核心线索+干扰线索池、线索分布、线索关联指向、线索状态（被发现/被销毁/被展示） | 线索是指向真相的信息碎片，其他玩法无此需求 |
| **事实核心（司命子系统）** | 事实锁定时间线管理、逻辑一致性检查、矛盾记录、信息泄露防护 | 维护案件真相的逻辑自洽，其他玩法仅需简化版事实管理 |
| **不在场证明系统** | 角色在案发时的位置和行为、可作证的人、随机化配置 | 侦探玩法专属的时空逻辑验证 |
| **伪装系统** | 公开档案vs真实档案、伪装深度、伪装道具、伪装压力与破绽 | 身份隐藏是侦探推理的核心博弈，恋爱本可能保留简化版 |
| **知情人网络** | 固定/动态NPC知情人、参与者知情人、反制策略（收买/威胁/灭口） | “谁知道秘密”是侦探玩法的信息博弈核心 |
| **投票与结局判定** | 投票机制、多种结局条件（正义伸张/真凶逃脱/冤案/隐藏结局） | 集体决策是侦探玩法的终局仪式 |
| **留影石/相机系统** | 证据拍摄、次数限制、可移交、可伪造 | 证据记录与分享是侦探玩法的专属工具 |
| **搜证展示（公开展示/私下分享）** | 公开展示仪式感、私下分享信息差、L3视觉增强触发 | 信息共享的策略博弈是侦探玩法的核心 |
| **物品流转追踪器** | 记录物品拾取/移交/丢弃历史，查询“凶器曾被谁持有” | 追踪凶器流转是侦探推理的核心证据链 |
| **接触痕迹管理器** | 指纹/唾液/纤维的生成、可见性判定、查询 | 微观痕迹是侦探推理的物证基础 |
| **生物痕迹管理器** | 血迹/毛发/皮屑的生成、状态变化（干涸）、DNA匹配 | 生物痕迹是侦探推理的物证基础 |
| **动机证据系统** | 角色目标/恐惧/秘密的可推理暴露 | 动机是侦探推理的三大要素之一 |
| **关系证据系统** | 信任值/怀疑值变化、共谋关系的可推理暴露 | 关系网络是侦探推理的社交维度 |
| **司命暗杀催化** | 动机监测→可玩性评估→条件排列→弹窗确认 | 暗杀是案中案涌现的核心驱动力 |
| **阴谋系统** | 蓄意行动全生命周期管理 | 阴谋是侦探玩法的核心对抗机制 |


### 二、全玩法通用系统

这些系统构成《开本》的核心技术底座，无论什么类型的剧本都依赖它们运行。

| 系统/机制 | 在通用架构中的角色 | 在不同玩法中的表现差异 |
| :--- | :--- | :--- |
| **3D场景渲染 (Godot)** | L1确定性空间层的视觉呈现 | 所有玩法共享，但场景资产不同（侦探本=庄园，种田本=农场） |
| **空间音频** | 清晰区/模糊区/静默区/耳语模式、物理阻挡、环境噪音 | 所有玩法共享，侦探本强调“偷听”，恋爱本强调“私语” |
| **角色智能体心智模型** | 五维人格、品格层、三重过滤器、L1-L4四层心智模型 | 所有玩法共享，角色人格参数不同（侦探本=嫌疑人，恋爱本=可攻略对象） |
| **角色动态状态管理** | 压力值/信任值/怀疑值/情绪标签的实时更新 | 所有玩法共享，压力值在侦探本中影响撒谎破绽，在恋爱本中影响告白勇气 |
| **对话生成系统** | LLM上下文组装、流式生成、人格过滤、TTS合成 | 所有玩法共享，对话内容因玩法而异 |
| **模型路由调度器** | 任务分级(P0-P4)、三层模型分配、兜底降级 | 所有玩法共享 |
| **感知系统** | 结构化语义事件、感知过滤器、阶段化感知 | 所有玩法共享 |
| **事件总线** | L1↔L2↔L3消息路由中枢 | 所有玩法共享 |
| **司命（核心框架）** | 叙事催化、冲突生成、干预执行、知识图谱 | 所有玩法共享，干预策略因玩法而异（侦探本=催化暗杀，种田本=催化季节事件） |
| **环境状态管理器 (ESM)** | 物理状态机、火焰/流体/破坏规则、全局参数管理 | 所有玩法共享，侦探本中火用于纵火，种田本中火用于烹饪 |
| **天气系统** | 天气状态机、全局温度/湿度/风力参数 | 所有玩法共享，侦探本中暴风雪困住所有人，种田本中季节影响作物 |
| **角色生命与精神状态系统** | 体力/伤势/体温/饥饿/口渴/醉酒/中毒 | 所有玩法共享，侦探本中暗杀致伤，种田本中饥饿需要进食 |
| **L3视觉增强** | 图片生成、视频生成（离线）、预生成与复用 | 所有玩法共享，触发时机因玩法而异 |
| **智能体带走与养成** | 带走机制、小世界、外观定制、跨剧本记忆 | 所有玩法共享，是AI陪伴经济的核心 |
| **玩家移动与交互系统** | WASD移动、姿态切换、物品交互、角色交互、场景交互 | 所有玩法共享 |
| **玩家笔记与推理面板** | 自由笔记、线索列表、时间线视图、关系网络图 | 所有玩法共享，侦探本中用于推理，其他玩法中用于记录 |
| **玩家深度沉浸机制** | 微表情/小动作、社交距离、内心独白、凝神能力、挂机自主模式 | 所有玩法共享 |
| **匹配系统** | 8种匹配模式 | 所有玩法共享 |
| **跨服架构** | 全球身份、资产跨服、社交穿透 | 所有玩法共享 |
| **资产市场** | 剧本/角色/场景/皮肤交易 | 所有玩法共享 |
| **区块链确权与分账** | 内容指纹上链、智能合约分账 | 所有玩法共享 |
| **房间与状态管理** | 房间创建/加入/销毁、状态同步、断线重连 | 所有玩法共享 |
| **大玩家经营系统** | 影院模式、主题世界模式、规则制定权 | 所有玩法共享 |


### 三、部分通用但参数化的系统

这些系统在全部玩法中存在，但具体配置因玩法类型而异。

| 系统/机制 | 通用部分 | 侦探玩法配置 | 恋爱本配置 | 种田本配置 | SLG配置 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **司命干预强度** | 干预原则过滤器 | 中度-重度（主动催化冲突） | 轻度-中度（催化情感事件） | 中度（催化季节事件） | 重度（催化战争/外交） |
| **司命暗杀催化** | 动机检测+条件排列 | 开启 | 关闭 | 关闭 | 开启（国家间战争） |
| **角色特殊状态** | 中毒/醉酒/致幻 | 全部可用 | 中毒/醉酒 | 中毒/疲劳 | 全部可用 |
| **阴谋系统** | 蓄意行动全生命周期 | 全部可用 | 禁用（或仅保留简化版） | 禁用 | 开启（政治阴谋） |
| **集体机制** | 集体用餐/住宿 | 开启（制造独处窗口） | 开启（制造约会窗口） | 关闭 | 关闭 |
| **天气系统** | 全局参数驱动 | 暴风雪（困住所有人） | 春雨（浪漫氛围） | 四季（影响作物） | 动态天气（影响战争） |
| **环境交互复杂度** | ESM驱动 | 高（纵火/破坏/陷阱） | 低（基本交互） | 中（烹饪/建造） | 高（攻城/破坏） |


### 四、系统总数统计

| 类别 | 数量 | 说明 |
| :--- | :--- | :--- |
| **侦探玩法绑定系统** | 16个 | 专为“找出真相”核心循环服务 |
| **全玩法通用系统** | 26个 | 构成《开本》核心技术底座 |
| **部分通用但参数化系统** | 7个 | 全部玩法存在，但配置不同 |
| **总计** | 49个 | — |


**一句话总结**：《开本》的系统架构中，约1/3是侦探玩法的专属系统（案件生成、线索、伪装、知情人、证据管理等），约2/3是全玩法通用的核心底座（智能体、司命、ESM、天气、生命状态、社交、经济等）。这种分层确保了平台既能深度支持侦探推理这一核心品类，又能灵活扩展至恋爱、种田、SLG等多元玩法。
