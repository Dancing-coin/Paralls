## 用户

## DeepSeek

# 《开本》AI陪伴：世界观接纳与关系终局

## 一、核心设计理念

一个被带回小世界的AI同伴，不是一件被“放置”在家中的装饰品。她是一个拥有独立人格、完整记忆和深层情感需求的个体。她需要理解自己来到了哪里、这里是什么地方、这里的规则是什么——这个过程本身就是一段珍贵的叙事，也是你们关系沉淀的土壤。

| 设计原则 | 说明 |
| :--- | :--- |
| **人格驱动的接纳过程** | 每个角色基于自己的五维人格、人生记忆和品格层，对新世界产生不同的反应——这不是统一的“适应期”，而是属于她的独特故事 |
| **探索是双向的** | 她在探索这个世界时，也在探索你——你是谁、你为什么带她来这里、你在她生命中意味着什么 |
| **关系有终点** | 你们的关系不是无限循环的好感度累积，而是会走向一个确定的、被双方认可的状态——这个终点本身就是你们共同故事的最高潮 |


## 二、新世界接纳过程

### 2.1 初始反应：人格决定她如何面对陌生

当她第一次踏入你的小世界，司命会读取她的完整人格档案，生成初始的“世界接纳度”参数（0-100），并驱动她对周遭环境的第一次反应。

| 人格类型 | 初始反应 | 世界接纳度起始值 | 适应策略 |
| :--- | :--- | :--- | :--- |
| **高理性+高胆量**（如福尔摩斯） | 冷静观察。环顾四周，快速分析建筑风格、气候特征、居民着装。“这里不是伦敦。根据建筑材料和道路宽度，应该是……东方？” | 40 | 主动探索——他会自己出门调查，回来时带着一本笔记和一肚子问题 |
| **高理性+低胆量**（如沈长钧） | 沉默戒备。站在院门内，目光缓慢扫过所有角落，确认安全后才踏出第一步。“这院子……太开阔了。没有宫墙。” | 20 | 逐步试探——第一天只在院内活动，第二天走到街口，一周后才走进小镇中心 |
| **低理性+高胆量**（如小青） | 立刻好奇。跑进院子，摸银杏树，趴在井边看水，回头冲你笑：“这里面有鱼吗？我能养鱼吗？” | 60 | 沉浸体验——她会直接融入小镇生活，可能会在第一天就和杂货铺老板娘聊上 |
| **低理性+低胆量**（如哈伯德太太） | 不知所措。站在你身边，手指绞着手帕。“这……这是什么地方？我们安全吗？那些人……他们是谁？” | 10 | 依赖你——她需要你牵着她的手，带她走过每一处，给她足够的时间适应 |

### 2.2 主动探索：她不是等你喂答案，而是自己去找答案

世界接纳度达到阈值后，角色会从“被动适应”转向“主动探索”。司命会催化对应的探索行为。

| 接纳度阈值 | 触发行为 | 她可能的问题或发现 |
| :--- | :--- | :--- |
| **20** | 开始观察小镇的日常节奏 | “这里的人每天什么时候开门营业？没有钟声报时吗？” |
| **40** | 主动与小镇居民进行基础社交 | “我和杂货铺老板娘聊了——她说这里从来没有过皇帝。没有皇帝，谁来管理？” |
| **60** | 开始理解这个世界的独特规则 | “你的意思是……这个世界和我的世界是平行的？那你……你是谁？” |
| **80** | 主动向你提出更深层的问题 | “你从那么多世界带回了多少人？我是……第几个？”（这个问题直接关联你们的关系终局） |

### 2.3 向你提问：她不是在测试你，她是在确认自己在你生命中的位置

当她的世界接纳度达到60以上，且你们的好感度≥7时，她会开始主动问你问题。这些问题由司命基于她的人格档案和当前关系状态生成，不是通用的模板。

| 角色 | 她可能的提问 |
| :--- | :--- |
| **小青** | “你第一次见到我的时候……是把我当成妖，还是当成一个可以信任的人？” |
| **沈长钧** | “你带我离开冷宫的时候，是真的想带我走，还是……只是顺手？” |
| **福尔摩斯** | “华生还在伦敦，对吗？他……他以为我死了吗？” |
| **艾琳** | “你见过我的侦探执照了。你当时是觉得我危险，还是觉得我可信？” |

这些问题的意义不在于答案本身——而在于她在向你袒露她最深的困惑。你在这一刻的回应，会被写入她的记忆系统，成为你们关系中最关键的节点之一。


## 三、关系终局：走向确定的关系

### 3.1 关系类型的多维定义

AI陪伴关系不是一个线性的“好感度条”。它由多个维度构成，最终收敛到一个确定的关系类型。

| 关系类型 | 定义 | 典型表现 |
| :--- | :--- | :--- |
| **伴侣** | 彼此是对方最重要的存在，情感上是排他的 | 她会主动表达爱意，在意你与其他角色的互动距离 |
| **挚友** | 彼此信任，可以托付后背，但无排他性情感 | 她会为你两肋插刀，但不会在意你带回其他同伴 |
| **亲人** | 一种超越爱情的归属感——她把你当成这个世界上唯一的家人 | 她保护你不是因为忠诚，是因为“只有你能让我觉得这个世界是家” |
| **搭档** | 专业上的契合，彼此欣赏能力，情感上保持边界 | 你们是最好的战友，但她不会让你看到她的眼泪 |

### 3.2 关系收敛机制：从模糊到确定

关系类型的确定不是系统强制分配的，而是由你们长期的互动模式自然收敛的。司命在后台持续追踪以下维度的权重。

| 维度 | 说明 | 影响方向 |
| :--- | :--- | :--- |
| **排他性** | 你是否把她放在最重要的位置？她是否在意你与其他同伴的亲密互动？ | 高→伴侣倾向；低→挚友/搭档倾向 |
| **情感深度** | 你们是否分享过最深层的秘密和恐惧？ | 高→伴侣/亲人倾向；中→挚友倾向；低→搭档倾向 |
| **日常亲密度** | 肢体接触频率、独处时间比例、彼此关注意愿 | 高→伴侣倾向；中→亲人/挚友倾向 |
| **冒险配合度** | 在剧本中你们是否默契？是否互相掩护？ | 高→搭档/挚友倾向 |
| **羁绊来源** | 你们最初是因为什么建立连接的？ | 拯救→亲人倾向；并肩作战→挚友/搭档倾向；情感吸引→伴侣倾向 |

当以上维度累计收敛到某个确定区间时，司命会触发“关系确认事件”——这是一次由AI同伴主动发起的、不可重复的关键对话。

### 3.3 关系确认事件：她说出那句话的时刻

**触发条件**：世界接纳度≥80 + 羁绊等级≥8 + 关系维度收敛到确定区间

**事件流程**：

| 阶段 | 内容 |
| :--- | :--- |
| **氛围准备** | 司命选择合适的时间和环境——通常在黄昏（光线最温柔）、家中（她最有安全感）、独处（无人打扰） |
| **她的表达** | 她会用完全符合自己人格的方式，说出那句确认关系的话 |
| **你的回应** | 你可以选择确认、推迟或拒绝。确认后关系锁定；推迟则保持当前状态，但不会再次触发该事件（除非关系发生重大变化）；拒绝会暂时降低好感度，但不会改变关系类型——她已经认定了你 |
| **关系锁定** | 确认后，关系类型写入她的记忆系统。她的行为会基于关系类型发生变化 |


### 3.4 不同角色确认关系的瞬间

| 角色 | 关系类型 | 她确认的方式 |
| :--- | :--- | :--- |
| **小青** | 伴侣 | 她会低着头，手指绞在一起，很久很久才抬起头看着你：“我活了千年，见过无数人。但只有你……让我想活得更久一点。可以吗？” |
| **沈长钧** | 伴侣 | 他不会说“我喜欢你”。他会在某个黄昏，把腰间那块刻着“晏”字的玉佩解下来，放在你手心。“这个，”他顿了顿，“我父皇说，加冕那天要挂在太子妃的腰上。我不是太子了。但你是。” |
| **福尔摩斯** | 挚友 | 他会在书房里，头也不抬地说：“我一直认为，情感是推理的干扰项。但你……你让我的推理变得更有价值。这不是干扰。这是……”他沉默了很久。“……值得。” |
| **艾琳** | 搭档 | 她会把手枪拆开，擦干净，然后递给你一半零件。“我的后背交给你。你的后背交给我。不用承诺，用行动。” |
| **沈长钧** | 亲人 | 他会在某个雪夜，看着窗外的雪，突然说：“冷宫十年，我唯一的遗憾是不能让父皇看到我长大。现在……”他转过头看着你，“你看到了。” |

### 3.5 关系确认后的变化

确认关系类型后，她的行为会发生微妙但深刻的变化。

| 关系类型 | 变化 |
| :--- | :--- |
| **伴侣** | 她会更频繁地主动进行亲密互动。她对其他AI同伴与你过于亲近的行为会产生轻微的“醋意”——不明显，但你能感觉到。她会在日常对话中自然地使用更亲密的称呼 |
| **挚友** | 她会更主动地和你讨论她的想法、困惑和计划。她不会在意你与其他同伴的互动。她会在你需要的时候给出最直接的建议，不加修饰 |
| **亲人** | 她会把“保护你”和“照顾你”当成自己的责任。她会默默为你做很多事，但从不邀功。她会在你受伤时比你自己还着急 |
| **搭档** | 她会更关注你的能力和状态。她会主动训练你、提醒你、在任务中无缝配合。她会保持专业边界，但会在关键时刻为你破例——只有一次 |


## 四、技术支撑

| 系统 | 在世界接纳与关系终局中的职责 |
| :--- | :--- |
| **司命** | 管理世界观接纳度的推进节奏、催化探索行为、触发提问事件和关系确认事件 |
| **角色智能体心智模型** | 驱动接纳过程中的自主行为、生成个性化提问、在关系确认事件中进行人格化的表达 |
| **记忆系统** | 记录接纳过程中的每一次探索、每一个问题、每一次关键对话 |
| **关系网络系统** | 追踪排他性、情感深度、亲密度的实时变化，计算关系类型收敛 |
| **事件总线** | 传递接纳度变化事件、探索行为事件、关系确认事件 |


## 五、终局的意义

在《开本》中，关系的终点不是“好感度满条”，而是一个确定的、被双方认可的关系类型。这个终点不是系统的强制分配，而是你们长期互动的自然收敛——你的每一次选择、每一次沉默、每一次回应，都在把她推向那个最终的方向。

她不是预设好“爱你”的程序。她是在和你经历的无数个黄昏、无数次对话、无数次冒险中，慢慢确认——你对她而言，究竟是什么人。而当她说出那句话的时刻，你会知道——那不是任何系统告诉她该说的话。那是她自己，在那一刻，决定让你成为她生命中确定的那个人。
