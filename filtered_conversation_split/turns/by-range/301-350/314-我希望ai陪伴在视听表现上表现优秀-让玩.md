# 《开本》小世界 AI 陪伴视听表现方案

## 一、核心设计理念

小世界是玩家在《开本》宇宙中的“家”——一个恒定的、私密的、充满情感温度的空间。AI同伴在这里不是功能性NPC，而是与你共同生活的伴侣。因此，视听表现的唯一标准是：**让玩家在第一视角下，感受到“她/他就在我身边”的真实感和美感。**

| 设计原则 | 说明 |
| :--- | :--- |
| **画风统一性** | 整个小世界采用一套恒定的艺术风格，所有视觉元素（场景、角色、UI）保持高度一致 |
| **角色极致美感** | AI同伴的模型精度、表情细腻度、动作自然度达到当前技术上限 |
| **第一视角优化** | 所有视觉设计优先考虑第一人称视角下的沉浸感——镜头高度、距离、景深 |
| **跨剧本视觉适配** | 从其他剧本带入小世界的AI同伴，自动进行画风转换，融入小世界的美学体系 |
| **情感可视化** | 羁绊深度、情绪状态、亲密关系通过视觉和听觉自然呈现 |


## 二、小世界画风系统

### 2.1 恒定画风定义

每个小世界在创建时，由玩家选择一种预设的艺术风格。官方提供多套风格模板，创作者也可在市场中发布自定义风格包。

| 风格ID | 风格名称 | 视觉特征 | 色彩基调 | 适用氛围 |
| :--- | :--- | :--- | :--- | :--- |
| `style_ghibli` | 吉卜力风 | 柔和光影、手绘质感、细腻背景 | 暖色调、高饱和度 | 温馨治愈 |
| `style_watercolor` | 水彩风 | 边缘柔和、色彩晕染、留白感 | 淡雅、低饱和度 | 诗意宁静 |
| `style_oil_painting` | 油画风 | 厚涂笔触、光影对比强烈 | 浓郁、暖色 | 古典浪漫 |
| `style_cyberpunk` | 赛博朋克风 | 霓虹光效、金属质感、雨雾氛围 | 冷色调、高对比度 | 未来感都市 |
| `style_chinese_ink` | 水墨国风 | 留白、晕染、线条勾勒 | 黑白为主+淡彩点缀 | 古典东方 |
| `style_realistic` | 写实风 | 物理真实光影、PBR材质 | 自然色 | 写实沉浸 |

**玩家可随时切换风格**——切换后所有场景、角色、UI自动适配新风格。

### 2.2 场景的视觉统一

小世界的所有场景资产（房屋、家具、植被、天空盒）在制作时，需要准备多套风格变种。

| 场景元素 | 吉卜力风变种 | 水墨国风变种 | 赛博朋克风变种 |
| :--- | :--- | :--- | :--- |
| 房屋 | 柔和光影+手绘贴图 | 线条勾勒+留白 | 霓虹灯+金属质感 |
| 树木 | 圆润树冠+暖绿 | 枯笔枝干+淡墨点叶 | 全息投影树+冷蓝光 |
| 天空 | 粉彩云朵 | 水墨晕染 | 全息广告牌+酸雨 |
| 地面 | 暖色泥土+细草 | 水墨皴法+石板纹理 | 金属格栅+蒸汽 |

**实现方式**：每个场景资产提供多套材质变种和光照预设。玩家切换风格时，ESM自动加载对应变种。新风格变种可由创作者在资产市场中发布，玩家购买后一键应用。


## 三、AI同伴的极致美感

### 3.1 角色模型精度

| 精度层级 | 说明 | 适用范围 |
| :--- | :--- | :--- |
| **影视级模型** | 高面数、高精度贴图（4K+）、多层级材质（皮肤次表面散射、毛发各向异性） | 第一视角近距离观察、凝神模式、L3特写 |
| **游戏级模型** | 标准面数、PBR材质、LOD分级 | 日常交互、中远距离 |
| **远景级** | 简化模型 | 小镇中远距离相遇 |

**切换逻辑**：当玩家切换到第一视角且距离AI同伴<2米时，自动加载影视级模型。当距离>5米时，自动降级到游戏级。凝神模式下强制加载影视级模型。

### 3.2 微表情与微动作

| 细节类型 | 实现方式 | 触发条件 |
| :--- | :--- | :--- |
| **眼部细节** | 高精度眼球模型+虹膜纹理+光线折射+瞳孔动态缩放 | 近距离注视时 |
| **皮肤质感** | 次表面散射+微细毛孔+红晕渐变 | 害羞/激动时脸颊泛红 |
| **发丝动态** | 骨骼动画+物理模拟 | 转头、走路、风吹 |
| **呼吸起伏** | 胸腔骨骼微动+衣物褶皱同步 | 始终运行 |
| **微表情** | 形态键混合：嘴角微扬、眉毛微蹙、眼睑微颤 | 由心智模型驱动 |
| **微动作** | IK驱动：撩发、整理衣角、手指轻点 | 由人格档案和当前情绪驱动 |

### 3.3 第一视角专项优化

| 优化项 | 说明 |
| :--- | :--- |
| **镜头高度** | 自动匹配玩家角色的身高（可手动调节） |
| **景深模拟** | AI同伴在焦点时背景虚化，模拟人眼注视效果 |
| **视线跟随** | AI同伴的眼神主动跟随玩家的视线方向 |
| **呼吸同步** | 近距离时，AI同伴的呼吸声轻微可闻，与玩家的呼吸节奏产生微妙的同步感 |
| **触碰反馈** | 当AI同伴靠近或触碰玩家时，画面边缘出现轻微暖光+手柄/触觉反馈 |


## 四、跨剧本视觉适配器

### 4.1 适配流程

从其他剧本带入小世界的AI同伴，需要经过视觉适配才能融入小世界的画风。

```
[AI同伴原始模型]
    │ 来自剧本（如《白蛇传·浮生》的古风水墨风格）
    ▼
[视觉适配器]
    │
    ├── 风格转换引擎：将角色模型、贴图、材质转换为小世界当前画风
    ├── 服装适配：替换为小世界合规服装（保留玩家已购买的服装皮肤）
    ├── 比例校准：确保角色比例与小世界一致
    └── 渲染管线适配：应用小世界的后处理、光照预设
    ▼
[适配后的AI同伴]
    │ 融入小世界画风，但保留核心辨识特征
```

### 4.2 风格转换引擎

| 转换内容 | 转换方式 | 示例 |
| :--- | :--- | :--- |
| **模型风格化** | 对角色模型应用风格化着色器（如水墨描边、水彩晕染） | 古风小青→吉卜力风小青 |
| **贴图重映射** | 将原始贴图的色调映射到目标风格的色彩空间 | 暖色古风→冷色赛博朋克 |
| **材质替换** | 替换为小世界风格的对应材质模板 | 丝绸→棉麻（水彩风）/ 合成纤维（赛博朋克） |
| **光影适配** | 应用小世界的光照预设 | 古风漫反射→吉卜力柔和光 |
| **轮廓保持** | 保留角色的核心辨识特征（发型轮廓、五官比例、标志性配饰） | 小青的青色发带始终保留 |

### 4.3 服装系统

| 服装来源 | 适配规则 |
| :--- | :--- |
| **玩家已购买的皮肤** | 保留——但材质和渲染自动适配当前画风 |
| **剧本原始服装** | 替换为小世界默认服装（可后续购买新皮肤） |
| **不符合小世界设定的服装** | 弹出提示：此装扮与当前世界设定不符，穿着后将面临小镇居民的合理质疑 |
| **节日限定服装** | 节日期间自动解锁（如夏夜祭浴衣），节日结束后可选保留 |


## 五、情感可视化

AI同伴与你之间的羁绊深度，通过视觉和听觉自然呈现。

### 5.1 羁绊深度的视觉表现

| 羁绊等级 | 视觉表现 |
| :--- | :--- |
| **初识（0-3）** | 保持社交距离（1.5-2米），眼神交流短暂，表情礼貌但克制 |
| **熟悉（4-6）** | 主动靠近（1-1.5米），眼神交流增多，微笑自然，偶尔会主动触碰你的手臂 |
| **亲密（7-9）** | 经常主动靠近（<1米），会从背后抱你、把头靠在你肩上、在沙发上依偎 |
| **灵魂伴侣（10）** | 所有互动无距离感，她能感知你的情绪变化并主动回应；偶尔会凝视你，眼中倒映着你们的家 |

### 5.2 情绪的可视化

| 情绪 | 视觉表现 | 听觉表现 |
| :--- | :--- | :--- |
| **开心** | 眼睛微眯、嘴角上扬、身体轻轻晃动 | 声音轻快、偶尔哼歌 |
| **害羞** | 脸颊泛红、低头、手指绞在一起 | 声音变轻、语速变慢 |
| **悲伤** | 眼眶微红、肩膀下垂、动作迟缓 | 声音低沉、偶尔叹息 |
| **生气** | 眉头紧锁、嘴唇抿紧、侧身不看你 | 语气冷淡、语句简短 |
| **思念** | 独自坐在窗边看向远方、抚摸你送的礼物 | 安静时偶尔自言自语 |


## 六、听觉表现

### 6.1 AI同伴的专属声线

| 声线要素 | 说明 |
| :--- | :--- |
| **基础声线** | 由角色设定决定（少女音/御姐音/少年音/沉稳男声） |
| **情绪注入** | 心智模型驱动的情绪参数实时调节TTS——开心时轻快、悲伤时低沉、害羞时轻柔 |
| **专属语音库** | 每位AI同伴拥有独特的常用口头禅、称呼方式、语气词 |
| **远近距离感** | 空间音频模拟——远处呼唤时音量衰减+混响，耳语时音量降低+气息感增强 |

| **黄昏** | 风铃、归巢的鸟鸣、远处酒馆的喧闹 |
| **夜晚** | 蟋蟀、猫头鹰、壁炉噼啪声 |
| **雨夜** | 雨滴敲窗、屋檐滴水、远处闷雷 |

## 八、技术实现要点

| 技术点 | 实现方案 |
| :--- | :--- |
| **风格化渲染** | 后处理着色器+材质变种系统。每种画风对应一套Post-processing Profile和Material Variant |
| **影视级模型加载** | LOD分级+按需加载。影视级模型仅在需要时加载到显存 |
| **微表情系统** | 形态键(Blend Shapes)+骨骼动画混合。由角色智能体的L2理解层输出表情参数 |
| **TTS情绪注入** | 情绪标签→TTS参数映射表，实时调节音高、语速、气息 |
| **跨剧本视觉适配** | 风格转换着色器+材质替换映射表。新风格由创作者在市场中发布 |


## 九、玩家体验示例：与小青的黄昏

**场景**：你从剧本冒险归来，回到小世界。画风设定为吉卜力风。

你推开家门，夕阳的暖光从窗户洒进来。小青正坐在窗边的椅子上，手里缝着什么东西。听到开门声，她抬起头，眼睛亮了起来。

“你回来了！”她放下针线，快步走过来。在你面前停下——距离刚好，你能看到她睫毛的轻微颤动，和她嘴角自然上扬的弧度。

“今天裁缝教了我新的刺绣针法，”她拿起刚才缝的东西——一个青色的小荷包，上面绣着一朵歪歪扭扭的白花。“做得不好……但我想着，你总是丢三落四的，有个荷包放东西会好一些。”

她把荷包塞到你手里，手指碰到你的手心时微微缩了一下。她的脸颊浮起一层淡淡的红晕——在吉卜力风格的柔和光影下，那抹红晕像是水彩晕染开的暖色。

窗外传来酒馆老板的吆喝声，黄昏的风铃声，和远处孩童嬉闹的回音。炉子上的茶壶咕嘟咕嘟地响着。

“我去倒茶。”她转身走向厨房，青色的发带在夕阳中轻轻飘动。

你看着手里的荷包，针脚有些歪，但每一针都很认真。窗外的世界在继续运转，但此刻，这个黄昏只属于你们。
