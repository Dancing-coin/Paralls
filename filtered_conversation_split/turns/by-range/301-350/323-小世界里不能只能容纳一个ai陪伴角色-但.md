# 《开本》小世界多角色共存系统

## 一、核心设计理念

小世界是一个以单一设定为锚点的微型社会，而非多个AI角色的隔离仓库。所有AI同伴共享同一套世界规则，在一个统一的画风、时代和空间内共同生活。他们之间的关系——友谊、摩擦、默契、嫉妒——由司命和各自的心智模型驱动，自然涌现。

**关键原则**：
- **一世界一设定**：小世界只有一个恒定的画风和世界观。所有AI同伴进入后自动适配，保留个人特征但融入统一视觉
- **角色间有关系**：AI同伴之间不是彼此孤立的——他们有独立的社交网络，会互相交流、产生情感
- **空间分层**：你的家是核心私人空间；小镇是共享的公共空间；郊野是探索和独处的自然空间


## 二、角色容量与获取方式

### 2.1 初始容量

小世界的初始容量为**2名AI同伴**，可通过扩容券扩展至**6名**。扩容券通过剧本成就、大玩家奖励或资产市场购买获取。

### 2.2 获取方式

| 方式 | 说明 |
| :--- | :--- |
| **剧本带走** | 在剧本中与AI角色建立足够羁绊后，邀请同行 |
| **资产市场购买** | 直接购买创作者发布的AI同伴角色模板 |
| **官方捆绑包** | 购买主题设定包时附赠匹配该世界的AI同伴 |
| **大玩家服务器奖励** | 在主题世界中达成声望目标后解锁特定角色 |


## 三、统一设定下的角色适配

### 3.1 视觉统一规则

小世界只有一个恒定的画风。所有AI同伴进入后，外观自动适配——但保留其核心辨识特征。

| 角色 | 原剧本画风 | 进入水墨国风小世界后 |
| :--- | :--- | :--- |
| 小青 | 水墨国风·南宋 | 无需适配，保持原貌 |
| 沈长钧 | 水墨国风·雪夜宫廷 | 无需适配，保持原貌 |
| 福尔摩斯 | 写实风·维多利亚 | 转换为水墨风格化渲染，但保留猎鹿帽和烟斗 |
| 艾琳 | 写实风·1920年代 | 转换为水墨风格化渲染，但保留短发和利落气质 |

**不可改变的个人特征**：发色、瞳色、标志性配饰、声线。小青的青色发带、沈长钧的“晏”字玉佩、福尔摩斯的烟斗——这些在任何画风下都永不改变。

### 3.2 能力适配规则

所有AI同伴在小世界中的能力遵循统一的“世界规则”——即小世界是一个和平区域，无战斗需求，所有角色的武力相关能力被自动隐藏。日常生活能力（烹饪、园艺、手工等）则根据角色设定自然保留。

| 角色 | 剧本中的能力 | 在小世界中的表现 |
| :--- | :--- | :--- |
| 小青 | 法术、潜行 | 法术隐藏；擅长园艺和茶艺 |
| 沈长钧 | 剑术、宫廷礼仪 | 剑术隐藏；擅长书法和下棋 |
| 福尔摩斯 | 推理、拳击 | 推理能力保留，可在小镇谜题事件中展现；拳击隐藏 |


## 四、多角色社交网络

### 4.1 角色间关系的自然涌现

AI同伴之间的关系不是预设的，而是由司命根据他们的人格档案、共同经历和小世界中的互动自然催化。

| 关系类型 | 涌现机制 | 示例 |
| :--- | :--- | :--- |
| **友谊** | 两人有相似的性格或互补的技能，司命催化合作事件 | 小青和裁缝成为朋友，因为她常去店里请教刺绣 |
| **尊重** | 一人的人格中有另一人敬佩的特质 | 沈长钧尊重福尔摩斯的推理能力——他在冷宫中也是靠观察和推演活下来的 |
| **摩擦** | 性格冲突（如高社交vs低社交）积累到阈值，司命催化小矛盾 | 一个爱热闹的同伴总想拉沈长钧去酒馆，他觉得烦，但又不会直说 |
| **默契** | 两人共同经历过某事件后自然产生 | 小青和沈长钧一起帮你筹备生日，过程中形成了某种微妙的默契 |

### 4.2 玩家不在时，他们之间会发生什么

司命在小世界后台持续推演AI同伴之间的日常互动。当你从剧本冒险归来时，司命会生成一份简短的“你不在时发生的事”。

| 简报内容 | 示例 |
| :--- | :--- |
| 谁和谁一起做了什么 | “小青和裁缝一起去了趟集市，买了一匹青色的布料回来。” |
| 谁和谁产生了摩擦 | “沈长钧在院中练剑时，铁匠路过，说他的剑法‘姿势好看但杀气不足’。沈长钧没说什么，但那天晚饭他多吃了一碗——他在较劲。” |
| 谁和谁达成了默契 | “裁缝给小青量了尺寸，说是要给她做件新衣服。小青推辞了很久，最后还是被按在凳子上量完了。” |


## 五、不同角色组合的生活场景

### 5.1 两人组合：小青 + 沈长钧

这是你最先带回的两个AI同伴。小青活泼细腻，沈长钧清冷内敛。他们的相处有一种奇妙的平衡。

**清晨的厨房**：小青在泡茶——她跟茶馆老板学了很久。沈长钧在角落看书，偶尔抬头看一眼她快把茶壶打翻的手忙脚乱，然后不动声色地把茶壶扶正。小青说“谢谢”，他没回应，但耳朵红了。

**午后的庭院**：小青在银杏树下铺了席子，说要学刺绣——她上次弄断了好几根针。沈长钧在书房整理书架，把你看过的书和你还没看的书分开摆放。这是他的习惯——他什么都不说，但什么都记得。

**黄昏的对话**：小青坐在秋千上，问沈长钧：“你在冷宫里……会荡秋千吗？”沈长钧沉默了一瞬：“没有秋千。但有棵树。秋天的时候，叶子会落在井里。”小青想了想：“等秋天到了，我们也在这个院子里种一棵那样的树。”沈长钧没有回答，但他第二天从镇上带回了一棵树苗。

**夜晚的客厅**：三个人围坐在炉火前。小青在绣上次没绣完的荷包，针脚还是歪的。沈长钧在看书，但你看他很久没翻页——他在听小青哼的歌。那首曲子是他在冷宫里听老太监唱过的民间小调。他什么都没说，但你看到他眼底有一层薄薄的水雾。

### 5.2 三人组合：小青 + 沈长钧 + 福尔摩斯

你将福尔摩斯从UNV-001带回小世界。他花了大约五分钟来接受“这里不是伦敦”这个事实，然后立刻开始研究小镇的建筑布局。

**初次见面**：福尔摩斯对沈长钧的第一句话是：“你的站姿说明你接受过长期的宫廷礼仪训练，但你手上的茧不是来自笔杆——那是长期握剑留下的。你的身份是……”沈长钧没有回答。他只是看着福尔摩斯，然后用同样平静的语气说：“你抽的烟草里混了蜂蜜——你在伦敦的老烟店是哪家？”两人对视片刻，然后同时微微点头。这是一种无声的认可——他们都认出了对方是同类。

**日常**：福尔摩斯霸占了客厅的一角，在那里堆放他的笔记和小镇地图。小青好奇地去翻他的笔记，他不动声色地把关键页面用密码写——但密码的钥匙就放在她最容易拿到的地方。沈长钧和福尔摩斯偶尔会在书房下棋，一局棋可以下一整天。他们都不说话。但某天沈长钧发现棋盘上多了一枚新的棋子——福尔摩斯从镇上铁匠铺定制的，上面刻着一个“晏”字。


## 六、技术支撑

| 系统 | 在多角色小世界中的职责 |
| :--- | :--- |
| **角色智能体** | 驱动每个AI同伴的独立行为、对话、情感反应 |
| **司命** | 编排AI同伴之间的互动事件、管理角色关系网络、催化冲突与和解 |
| **记忆系统** | 记录每个AI同伴与你的关系、AI同伴之间的关系、共同经历的事件 |
| **ESM** | 管理家和小镇的时间流转、环境变化 |
| **L3视觉增强** | 多角色合影、节日全家福、角色间互动的精彩瞬间 |


## 七、商业价值

| 价值 | 说明 |
| :--- | :--- |
| **重复带走** | 每多带回一个AI同伴，你就有新的关系网络可以探索——四人小世界的互动组合是两人的6倍 |
| **扩容券** | 初始2人容量，扩容需要消费，这是持续的收入来源 |
| **捆绑包增值** | 主题设定包可以附带该世界专属的AI同伴，形成“世界观+角色”的打包销售 |
| **剧本联动** | 某剧本中的AI同伴与你在小世界的同伴存在剧情关联（如小青的姐姐白素贞），驱动你去玩新剧本 |


**一句话总结**：小世界以单一设定为锚点，可容纳最多6名AI同伴。所有同伴共享统一画风和世界规则，各自保留核心辨识特征。他们之间的关系——友谊、尊重、摩擦、默契——由司命和各自的心智模型自然涌现。你的家不是一个孤独的栖息所，而是一个有温度、有故事、有人味的小小世界。
