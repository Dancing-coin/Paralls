## 阴谋系统完整设计

### 一、阴谋的生命周期

一个完整的阴谋不再是单次弹窗确认，而是由多个阶段构成的叙事弧线。

| 阶段 | 行为 | 描述 | 风险 |
| :--- | :--- | :--- | :--- |
| **意图** | 暗自发愿或密谋 | 单人产生念头，或多人私下达成共识 | 隔墙有耳、被试探出动机 |
| **筹备** | 获取工具或制造条件 | 窃取凶器、踩点目标路线、贿赂守卫 | 工具被他人发现、目击踩点 |
| **执行** | 实施蓄意行动 | 直接攻击或触发环境机制 | 当场目击、目标反抗、计划失误 |
| **收尾** | 掩盖痕迹或伪造现场 | 清洗血迹、布置意外假象、栽赃嫁祸 | 逻辑矛盾、物证残留 |
| **反制** | 被察觉后的对抗 | 灭口目击者、销毁证据、伪证辩护 | 新案件引发更大危机 |


### 二、共谋机制：多人协作的阴谋

| 机制 | 描述 | 实现方式 |
| :--- | :--- | :--- |
| **私下邀约** | 发起者使用耳语模式向潜在共谋者发出邀请 | 耳语对话 + 高阶知识图谱记录“A邀请B共谋” |
| **信任门槛** | 被邀者是否接受共谋，取决于其对发起者的信任值 | 信任值≥7 → 接受；信任值4-6 → 犹豫，要求更多信息；信任值≤3 → 拒绝，甚至告密 |
| **条件协商** | 共谋者可就行动方案、分工、分赃进行协商 | LLM驱动的自由对话，结果写入双方的临时目标层级 |
| **背叛机制** | 共谋者可在任何阶段背叛——告密、反水、独吞成果 | 由人格档案中的诚实度和忠诚度决定背叛概率 |
| **出卖与顶罪** | 共谋者被捕后可选择出卖同伙或独自顶罪 | 由恐惧值和忠诚度决定 |


### 三、连锁阴谋：一个阴谋触发另一个阴谋

| 连锁类型 | 触发条件 | 示例 |
| :--- | :--- | :--- |
| **灭口连锁** | 阴谋被目击者发现 → 执行者决定灭口 | 上校纵火被女仆看到 → 上校面临暗杀女仆的弹窗 |
| **嫁祸连锁** | 阴谋执行后，执行者伪造证据指向他人 | 上校纵火后，将打火机放在另一角色行李中 |
| **反制连锁** | 受害者察觉阴谋 → 受害者先发制人 | 麦奎因察觉上校可能出卖自己 → 麦奎因先向上校下手 |
| **竞争连锁** | 两个独立阴谋同时针对同一目标或资源 | A想偷文件，B想烧文件 → 两人在目标地点意外相遇 |


### 四、事后的反制与追查

| 机制 | 描述 | 实现方式 |
| :--- | :--- | :--- |
| **谎言与伪证** | 阴谋执行后被质疑时，角色可以撒谎或伪造不在场证明 | 由心机值和逻辑编织力决定谎言质量；压力值影响破绽 |
| **栽赃与嫁祸** | 将凶器、物证放置在他人的物品或活动区域 | 物理道具的转移 + 目击风险 |
| **收买与威胁** | 用利益或恐吓让目击者闭嘴 | 对话选项 + 信任值/恐惧值变化 |
| **自首与减罪** | 在证据确凿前主动坦白，换取宽大处理 | 由人格中的责任感、恐惧值、当前压力值决定 |
| **诬告与反咬** | 被指控时反过来指控对方 | 公开对峙，由高心机和高社交的角色更擅长此道 |
| **逃跑与隐匿** | 在罪行暴露前逃离现场或躲藏 | 潜行移动 + 场景中的躲藏点 |


### 五、阴谋的痕迹与推理

所有阴谋行为在实时演算引擎驱动下必然留下可被推理的痕迹。

| 痕迹类型 | 描述 | 反制难度 |
| :--- | :--- | :--- |
| **物理痕迹** | 血迹、指纹、工具划痕、被破坏的物品 | 高——无法完全消除，只能转移或伪造 |
| **时间线矛盾** | 行动时间与声称的时间不符 | 中——可伪造不在场证明，但逻辑漏洞可能被发现 |
| **行为异常** | 角色表现出异常的紧张、回避、过度热情 | 低——由微表情系统自动驱动，高压力时难以控制 |
| **物证关联** | 凶器归属、工具来源、购买记录 | 中——可销毁物证，但销毁行为本身可能被目击 |
| **动机暴露** | 角色的秘密或目标被他人推理发现 | 中——可伪装动机，但长期伪装压力极大 |


### 六、司命对阴谋全生命周期的催化

| 阶段 | 司命的催化职责 |
| :--- | :--- |
| **意图阶段** | 检测角色的非法目的动机；对满足条件的角色推送意图冲动或弹窗确认 |
| **筹备阶段** | 通过环境催化创造获取工具的机会（如“打火机被遗忘在餐桌上”）；向潜在共谋者推送“可信任”的信号 |
| **执行阶段** | 排列条件、检测独处窗口；弹窗确认执行方案；在执行过程中管理目击判定和意外事件 |
| **收尾阶段** | 生成物证痕迹和时间线矛盾；向调查者推送细微的异常感知 |
| **反制阶段** | 检测阴谋暴露风险；向暴露者推送“灭口”或“自首”的弹窗；向受害方推送“反击”或“检举”的弹窗 |


### 七、完整案例：上校纵火放走凶手的阴谋全生命周期

**意图阶段**：麦奎因坦白后被控制，将被移交警方。上校的L2理解层判断麦奎因是“正义的执行者”，L3规划层生成“让麦奎因逃脱”的新目标。司命检测到非法目的动机，评估可玩性后通过。向上校推送意图冲动：“麦奎因将被绞死。或许，你可以为他创造逃脱的机会。”

**筹备阶段**：上校检查自身物品栏——打火机在手。他观察餐车环境——窗帘是布料，地毯是布料，火势可能蔓延。他与麦奎因通过耳语进行秘密协商，达成默契。

**执行阶段**：司命检测到暴风雪加剧、列车暂停、众人注意力分散的独处窗口，条件排列完成。向上校推送执行弹窗：“暴风雪正掩护，餐车窗帘可燃。点燃它，火焰将制造足够混乱，为麦奎因创造逃脱窗口。”上校选择点火。ESM（环境状态管理器）响应：窗帘状态机触发“燃烧”，火势按规则蔓延。事件总线广播火灾事件。麦奎因在混乱中逃脱。

**收尾阶段**：ESM生成物证——窗帘烧焦残骸、打火机上的指纹。司命记录时间线矛盾——上校在火灾时声称在灭火，但他是第一个到达火灾点的人。司命向波洛推送细微的异常感知：“上校的反应太快了——他似乎在等这一刻。”

**反制阶段**：波洛质问上校，上校选择谎言——“我只是在尽军人的职责。”波洛的怀疑值上升。同时，女仆私下找到波洛：“我看到上校在窗帘附近站了很久，但他没有呼救——直到火焰变大。”

**最终，波洛面临选择**：公开揭发上校的纵火罪？还是沉默，让真相永远埋在雪夜中？他选择了沉默。这一切构成了《东方快车·雪夜杀机》中最具戏剧张力的案中案。


**一句话总结**：完整的阴谋系统覆盖意图、筹备、执行、收尾、反制五个阶段，支持多人共谋、连锁触发和事后博弈。所有阴谋行为在实时演算引擎驱动下必然留下可被推理的痕迹，而司命在阴谋全生命周期中进行催化和管理。这让《开本》中的“犯罪”成为一个深度叙事博弈系统——不仅是“谁杀了谁”，而是“谁策划了什么”、“谁参与了共谋”、“谁在事后反制”、“真相如何被掩盖或揭露”的完整戏剧。
