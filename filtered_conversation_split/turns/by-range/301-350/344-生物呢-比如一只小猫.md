## 《开本》动物成长系统设计——以小猫为例

### 一、动物与植物的成长差异

动物的成长比植物更复杂，不仅涉及体型变化，还涉及骨骼比例调整、毛色变化、行为能力的渐进解锁。

| 维度 | 植物 | 动物 |
| :--- | :--- | :--- |
| **形态变化** | 高度、枝叶密度、花果 | 体型、骨骼比例、毛色、眼睛比例 |
| **阶段数量** | 3-6阶段 | 3-5阶段 |
| **行为变化** | 无（静态） | 从踉跄到稳健到敏捷 |
| **交互能力** | 被动（浇水施肥） | 主动（跟随、叼回物品、蹭腿） |
| **情感表达** | 无 | 丰富（呼噜、摇尾、蹭头） |


### 二、小猫的成长阶段与美术资产

以一只从幼崽到成年的小猫为例，总成长周期约14-21天，分为四个阶段。

| 阶段 | 阶段名称 | 预计时长 | 体型特征 | 3D模型需求 | 贴图需求 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 新生儿 | 1-3天 | 眼睛未睁，耳朵折叠，身体圆短，比例头大身小 | `kitten_newborn.glb` | 稀疏绒毛，粉嫩皮肤透出 |
| 2 | 幼崽 | 4-7天 | 眼睛睁开，耳朵竖起，开始爬行，体型略拉长 | `kitten_young.glb` | 绒毛渐密，开始显色 |
| 3 | 半大 | 5-7天 | 四肢比例趋近成年，动作灵活，开始跳跃 | `kitten_adolescent.glb` | 毛色完全显现，眼睛颜色稳定 |
| 4 | 成年 | 持续 | 体型成熟，肌肉线条清晰，动作敏捷 | `cat_adult.glb` | 完整毛色，光泽感 |


### 三、体型渐变的平滑处理

阶段切换是基础方案。如果需要更平滑的成长体验，可以在底层架构中预留体型渐变着色器接口，不增加额外美术资产，仅通过调整骨骼缩放和毛发密度来填充阶段之间的过渡。

| 渐变参数 | 新生儿→幼崽 | 幼崽→半大 | 半大→成年 |
| :--- | :--- | :--- | :--- |
| **整体缩放** | 1.0 → 1.3 | 1.3 → 1.8 | 1.8 → 2.2 |
| **头部比例** | 0.4（占身体）→ 0.35 | 0.35 → 0.28 | 0.28 → 0.22 |
| **耳部缩放** | 0.6 → 0.85 | 0.85 → 1.0 | 1.0 → 1.0 |
| **腿部长度** | 0.4 → 0.65 | 0.65 → 0.9 | 0.9 → 1.0 |
| **毛发密度** | 0.2 → 0.5 | 0.5 → 0.8 | 0.8 → 1.0 |

这些渐变参数的调整只需要一个顶点着色器根据成长进度（`growth_progress`，0.0到1.0）进行线性插值。同一只小猫的不同成长瞬间，不需要不同的模型——只需要不同的参数值。


### 四、行为能力的渐进解锁

小猫的成长不仅体现在外观，还体现在它能做什么。行为能力的解锁与成长阶段挂钩。

| 行为 | 新生儿 | 幼崽 | 半大 | 成年 |
| :--- | :--- | :--- | :--- | :--- |
| **睁眼** | ❌ | ✅ | ✅ | ✅ |
| **爬行** | 仅蠕动 | ✅ 踉跄 | ✅ | ✅ |
| **行走** | ❌ | ✅ 不稳 | ✅ 稳健 | ✅ 优雅 |
| **跳跃** | ❌ | ❌ | ✅ 短距 | ✅ 高远 |
| **跟随玩家** | ❌ | ❌ | ✅ | ✅ |
| **叼回小物品** | ❌ | ❌ | ✅ | ✅ |
| **捕猎（模拟）** | ❌ | ❌ | ❌ | ✅ |
| **呼噜声** | ❌ | ✅ | ✅ | ✅ |


### 五、完整成长时间线

第1天：你从镇上带回一只刚出生的小猫。爱蜜莉雅用旧围巾给它做了窝，它团成小小的一团，眼睛还没睁开。爱蜜莉雅问：“它会活下来吗？”你说：“会的。”

第3天：登录时，爱蜜莉雅正蹲在猫窝前。小猫的眼睛睁开了一条缝——蓝色的，和她的发带一样。她轻声对猫说：“你醒了。”

第7天：小猫开始爬行了。爬得歪歪扭扭，总是撞到家具腿。爱蜜莉雅跟在它后面，用冰魔法在桌角上包了一层软冰——这样它撞到也不会疼。帕克趴在窗台上看着这一人一猫，用尾巴遮住眼睛：“忙死了。”

第14天：小猫已经能在院子里追蝴蝶了。爱蜜莉雅坐在秋千上看着它，它在草丛里扑来扑去，然后叼回一片银杏叶放在你脚边。这是它第一次给你“礼物”。

第21天：成年。小猫已经变成了一只优雅的成年猫。它在窗台上晒太阳，尾巴懒洋洋地垂下来。它的眼睛不再是初生时的蓝色——变成了琥珀色，和秋天的银杏叶一样。


### 六、与现有系统的集成

| 系统 | 在动物成长中的职责 |
| :--- | :--- |
| **司命** | 登录时根据离线时长计算成长阶段，生成成长里程碑叙事 |
| **ESM** | 管理动物的物理状态，计算行为能力的解锁条件 |
| **AI同伴心智模型** | 驱动AI同伴与动物的互动——照料、玩耍、担忧 |
| **记忆系统** | 记录成长日志和里程碑，AI同伴可在对话中提及 |
| **离线时间线补全** | 生成AI同伴在离线期间照料动物的记录 |


**一句话总结**：小猫的成长从闭眼的幼崽开始，经历睁眼、爬行、跳跃、跟随、叼回礼物等多个阶段，每个阶段对应不同的3D模型和行为能力。AI同伴——比如爱蜜莉雅——会用自己的方式照料它、保护它、为它的成长而感动。当成年后的猫在窗台上晒太阳时，你会记得它第一天来这个家时，眼睛还没睁开的样子。
