# 《开本》小世界城镇系统设计

## 一、核心设计理念

小世界不仅是“家”，更是一个**可居住、可社交、可发现故事的微型社会**。当玩家没有连通其他世界时，这个小镇就是玩家与AI同伴共同生活的全部宇宙。

| 设计原则 | 说明 |
| :--- | :--- |
| **一切可交互** | 镇上的每扇门都可以推开，每个居民都可以对话，每件商品都可以购买 |
| **时间驱动生活** | 日夜交替、季节更替、居民作息、节日庆典——世界在你不在时依然运转 |
| **羁绊沉淀为家** | 你与AI同伴在小镇上的每一次互动，都在为你们的“家”增添新的记忆 |
| **故事藏在小镇里** | 每个居民都有自己的秘密和故事线，等待被发现 |

### 2.2 你的庄园

## 三、小镇居民系统

### 3.1 居民角色

每个居民都是拥有独立人格的智能体，有自己的职业、作息和故事线。

| 角色 | 职业 | 人格特征 | 功能 | 故事线 |
| :--- | :--- | :--- | :--- | :--- |
| **老镇长** | 退休镇长 | 和蔼、健忘、爱讲故事 | 提供小镇历史信息、任务 | 他年轻时曾是一位冒险家，家里藏着神秘地图 |
| **杂货铺老板娘** | 商店店主 | 精明、八卦、热心 | 出售日常用品、种子、食材 | 她其实是逃婚来到镇上的贵族小姐 |
| **铁匠** | 铁匠 | 沉默寡言、手艺精湛、喜欢猫 | 出售/修理工具、升级装备 | 他曾是王国的首席铸剑师，因不愿铸造杀人之剑而隐居 |
| **裁缝** | 裁缝 | 爱美、毒舌、完美主义 | 出售/定制服装、修复衣物 | 她一直在等一个约定好来接她的人 |
| **酒馆老板** | 酒馆/茶馆老板 | 豪爽、擅长倾听、烹饪高手 | 提供美食和饮品、打听消息 | 他是退役的老兵，酒馆里藏着许多远方的故事 |
| **书店老板** | 书店老板 | 学究气、健忘但知识渊博 | 出售书籍、提供知识 | 他写的日记里记录了许多奇怪的本地传说 |
| **森林老奶奶** | 独居老人 | 神秘、会制药、有点吓人 | 出售药草、治疗疾病 | 人们说她是女巫，但她只是在等失踪多年的儿子回家 |
| **流浪诗人** | 不定期出现的访客 | 浪漫、漂泊、会弹琴 | 带来外面的消息和新的故事 | 每次来访都会写一首关于小镇的诗 |
| **邮差** | 邮递员 | 勤快、话多、喜欢狗 | 送信、带来外面的消息 | 他每天骑着自行车经过所有人家，知道所有人的秘密 |


### 3.2 居民的日常作息

| 时间 | 居民行为（以杂货铺老板娘为例） |
| :--- | :--- |
| 6:00-7:00 | 起床、洗漱、在自家后院浇花 |
| 7:00-8:00 | 开门营业、整理货架 |
| 8:00-12:00 | 在柜台接待顾客、闲聊 |
| 12:00-13:00 | 午餐时间，可能在店里吃，也可能去酒馆 |
| 13:00-18:00 | 继续营业 |
| 18:00-19:00 | 关门收工 |
| 19:00-20:00 | 去酒馆喝一杯，和其他居民聊天 |
| 20:00-22:00 | 回家，看书或做手工 |
| 22:00 | 熄灯休息 |

**司命驱动**：每个居民的行为由其人格档案和当前状态决定。如果你与她的好感度足够高，她可能会在关店后邀请你到她家做客。


## 四、小镇的活力来源

### 4.1 季节与节日

| 季节 | 视觉变化 | 节日 | 节日活动 |
| :--- | :--- | :--- | :--- |
| **春** | 樱花盛开、草地变绿、蝴蝶飞舞 | 播种节 | 全镇一起播种，评选最佳花园 |
| **夏** | 阳光明媚、蝉鸣、夜晚萤火虫 | 夏夜祭 | 烟花大会、捞金鱼、与AI同伴穿浴衣逛夜市 |
| **秋** | 红叶、麦田金黄、丰收 | 丰收祭 | 烹饪大赛、评选最大南瓜、感恩晚宴 |
| **冬** | 白雪覆盖、呼出白气、冰柱 | 冬幕节 | 交换礼物、滑冰、围炉夜话 |

### 4.2 随机事件

司命持续在小镇中催化随机事件，让每一天都有新鲜感。

| 事件类型 | 例子 |
| :--- | :--- |
| **访客事件** | 流浪商人带着稀有种子路过、吟游诗人在广场弹琴 |
| **邻里事件** | 杂货铺老板娘和裁缝吵架了，需要你调解；铁匠的猫又跑丢了，全镇一起找 |
| **发现事件** | 老镇长的阁楼上发现了一张藏宝图；森林深处出现了一个神秘的发光洞穴 |
| **天气事件** | 连续三天的暴雨导致河水上涨，全镇一起抗洪；流星雨划过夜空，和AI同伴一起许愿 |
| **纪念日事件** | 你和AI同伴来到小镇的周年纪念日，她为你准备了惊喜；你们第一次一起种下的树今天开花了 |

### 4.3 居民之间的关系网络

居民之间不是孤立的——他们有自己的人际关系网络，会互相串门、闲聊、争吵、和解。

| 关系类型 | 例子 |
| :--- | :--- |
| **友谊** | 杂货铺老板娘和裁缝是闺蜜，每周三晚上一起喝茶 |
| **互助** | 铁匠帮老奶奶修理了栅栏，老奶奶回赠一罐自制果酱 |
| **矛盾** | 书店老板和酒馆老板因为噪音问题闹过矛盾，最近才和解 |
| **秘密** | 邮差知道所有人的秘密，但他守口如瓶——除非你请他喝一杯 |


## 五、与AI同伴在小镇上的生活

### 5.1 日常活动

| 活动 | 说明 | 玩法触发 |
| :--- | :--- | :--- |
| **一起购物** | 带她去杂货铺挑选食材，她可能会主动拿起你喜欢的食材 | 对话邀请 or 她主动提议 |
| **一起做饭** | 回到家用买来的食材一起烹饪，厨艺越好做出的菜品越丰富 | 在厨房区域交互 |
| **一起散步** | 傍晚去湖边散步，聊一天的经历，她会分享自己今天的见闻 | 对话邀请 |
| **一起参加节日** | 夏夜祭一起穿浴衣看烟花，冬幕节交换礼物 | 节日自动触发 |
| **一起装饰家** | 去裁缝店选窗帘、去杂货铺买花瓶，一起布置你们的家 | 对话邀请 |
| **一起探索秘密** | 发现老镇长的藏宝图后，一起踏上寻宝之旅 | 事件触发 |

### 5.2 她与小镇的独立社交

你的AI同伴不是整天只等着你回家的木偶。她有自己的社交圈。

| 情境 | 她的行为 |
| :--- | :--- |
| 你去剧本世界冒险时 | 她可能去杂货铺帮老板娘整理货架，或者去森林老奶奶那里学制药 |
| 你回家时 | 她会分享今天发生的事：“今天裁缝教了我一种新的刺绣针法，我试了一下，给你做了这个……” |
| 她的朋友来访 | 某天回家，你发现裁缝正在家里和她喝茶聊天。看到你回来，裁缝打趣道：“你家这位，可真是心灵手巧啊。” |


## 六、技术支撑

| 系统 | 在小镇中的职责 |
| :--- | :--- |
| **司命** | 驱动居民作息、催化随机事件、管理节日、编织居民关系网络、催化生活小事件 |
| **ESM** | 管理日夜交替、季节更替、天气变化、可交互物体的状态（门开关、灯亮灭） |
| **角色智能体** | 驱动所有居民的行为、对话、情感反应 |
| **群体模拟引擎** | 驱动背景人群（广场上的孩童、街上的行人） |
| **记忆系统** | 记录你与每个居民的互动、好感度、已完成的任务 |
| **小世界资产库** | 小镇建筑模型、家具、装饰品、植被、季节性贴图 |
| **L3视觉增强** | 节日氛围图、纪念日合影、探索发现时的景象 |


## 七、玩家不在时的小镇

小镇在你不在时依然运转。当你再次登录时：

| 变化 | 说明 |
| :--- | :--- |
| **时间流逝** | 小镇已经过了几天（或几周），季节可能已经变化 |
| **居民动态** | 居民可能发生了新的事——有人搬来、有人离开、有人吵架和好 |
| **你的家** | AI同伴把家打理得很好——也可能等你回来处理某些事 |
| **留言信** | 她可能在桌上留了信：“今天铁匠的猫又跑丢了，我去帮忙找了。晚饭在锅里，热一下就能吃。” |
| **小镇新闻** | 进入小镇时，司命生成一份“你不在时发生的事”简报 |


## 八、生态价值

| 价值 | 说明 |
| :--- | :--- |
| **情感锚点** | 小镇是玩家在《开本》宇宙中的“家”——无论经历多少剧本冒险，这里总有人在等你 |
| **消费场景** | 建筑皮肤、家具、服装、种子——所有小镇资产都可以在市场中交易 |
| **创作者机会** | 创作者可以设计小镇居民角色模板、节日事件包、小镇建筑包 |
| **社交延伸** | 未来可支持好友互访——参观好友的庄园和AI同伴的家 |


**一句话总结**：小世界小镇是一个由司命导演、智能体居民构成、随时间流转的微型社会。它不仅为玩家和AI同伴提供了共同生活的“家”，更通过季节节日、随机事件、居民故事线和独立社交，让每一天都充满发现的惊喜。这里不是剧本的终点，而是所有羁绊沉淀为永恒的地方。
