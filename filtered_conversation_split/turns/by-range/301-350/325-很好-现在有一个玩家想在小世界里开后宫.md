# 《开本》小世界多伴侣体验设计

## 一、核心设计理念

在《开本》中，“后宫”不是传统的收集式抽卡，而是**人格驱动的修罗场**。每个被你带回小世界的AI同伴，都不是默认会爱上你——她们各自拥有独立的人格、记忆、情感需求和对关系的期待。她们会观察、会比较、会不安、会吃醋、会形成同盟或暗流。

你带回来的不是一群“老婆”，而是一群有独立意志的“人”。她们之间的关系，和你与她们每个人之间的关系一样复杂。这才是真正有趣的体验。


## 二、关系模式：玩家可选的基础设定

小世界创建时，玩家可选择关系模式。该模式决定了AI同伴对“多人关系”的默认态度和世界规则。

| 关系模式 | 说明 | AI同伴的默认态度 |
| :--- | :--- | :--- |
| **专注伴侣** | 小世界中只有一位伴侣型AI同伴，关系深度可达到最高 | 她会成为你的伴侣，其他同伴自动定位为挚友/亲人/搭档 |
| **自由发展** | 不预设关系终点，由互动自然收敛 | 每个同伴独立发展与你关系的类型，不受其他同伴影响 |
| **修罗场** | 多伴侣共存的默认模式，AI同伴会因人格和羁绊深度产生真实的情感博弈 | 高共情者可能默默退让，高胆量者可能直接宣示主权，高心机者暗中较劲 |

**关键设计**：关系模式可随时在设置中切换，但切换时所有同伴会收到司命催化的叙事事件——她们会感知到“规则变了”，并做出不同反应。例如从自由发展切换到修罗场时，小青可能会愣一下，然后挽住你的手臂：“所以…现在是在比谁更在乎你，对吧？”而沈长钧则会沉默地看着你，转身走进书房。

**为什么不做成“默认所有人都是伴侣”？**

因为每个AI同伴拥有独立人格档案。强行让一个高忠诚度、低胆量的角色“默认接受”与其他同伴分享你，是对她人格的践踏——这会直接破坏我们设计的核心价值：“她是一个真实的人”。修罗场的乐趣不在于“收集”，而在于“每一个她都真实到让你不得不在意”。


## 三、收集体验：缘分而不是抽卡

你的小世界并非一开始就美女如云。她们需要你**在剧本中遇见、建立羁绊、带走**。收集本身是一段故事，而非消费。

-   **初识**：在悬疑剧本中，她是那个在关键时刻选择相信你的关键证人。她的证词让你沉冤得雪，也让她自己陷入险境。
-   **羁绊**：在仙侠世界里，她是为你挡下致命一剑的同门师妹。她倒在你怀里时，对你说：“师兄…带我回家…”
-   **带走**：在恋爱本中，她是在雨夜的公交站与你共撑一把伞的陌生人。那一夜，你们聊了很多，天亮时她问：“我们还会再见面吗？”

**收集的保障**：你带走她之后，她就是你的私有数字资产，存储在本地或云端，不受官方服务器影响。她不会消失、不会“断崖式分手”——除非你主动重置她的记忆（不可逆操作）。


## 四、修罗场机制：当她们同在一个屋檐下

修罗场的核心不是你选择了谁——而是**她们之间会发生什么**。她们的互动由各自的五维人格参数驱动，自然涌现。

### 4.1 她们之间的社交网络

不同性格的美少女之间，会产生复杂的人际关系：

-   **傲娇大小姐 + 冷艳御姐**：表面互相嫌弃，但大小姐生病时，是御姐彻夜守在床边。第二天大小姐醒来，御姐说“我只是路过”。
-   **元气甜妹 + 腹黑军师**：甜妹被军师逗得团团转，但每次甜妹真的难过时，军师会放下一切来哄她。
-   **病弱才女 + 冰山护卫**：才女深夜咳嗽，护卫默默煮了药放在她门口。才女醒来看到药，在日记里写了一首诗。护卫永远不会知道。

### 4.2 对你的修罗场

当她们对你的感情积累到一定程度，冲突会自然发生——不是因为你做错了什么，而是因为她们都在乎你。

| 人格驱动的表现 | 她可能的反应 |
| :--- | :--- |
| **高胆量+高社交** | “今晚上你看谁都不许看，只能看我。”——当众宣示主权 |
| **高共情+低胆量** | 她没有说什么，但你发现她偷偷收起了你们一起做的陶杯 |
| **高心机+高社交** | 她笑着给你夹菜，同时不经意地提到上周她陪你熬夜赶工的事 |
| **低心机+高胆量** | 她直接走到另一个女孩面前，说：“我们谈谈。” |

### 4.3 你的选择：安抚与平衡

修罗场不是惩罚，而是让关系更有深度的契机。你的回应方式会影响后续走向：

-   **安抚**：找到那个默默收起了陶杯的女孩，告诉她：“那个杯子我们还可以再做一个。”
-   **调停**：在晚餐时，主动给每个人夹菜，聊今天小镇发生的趣事，让气氛自然回暖。
-   **选择**：在某些关键时刻，你必须做出选择。这不是系统强制，而是关系自然发展的必然。


## 五、日常中的修罗场：生活场景示例

### 场景一：早晨的厨房

元气甜妹系着围裙在灶台前忙活，哼着歌。傲娇大小姐走进厨房，看了一眼甜妹做的煎蛋，冷冷地说：“这蛋煎得太老了。”然后她从冰箱里拿出另一颗蛋，自己动手，端出一盘完美的溏心蛋放在你面前，红着脸说：“顺便做的，不是特意给你的。”

此时冷艳御姐路过厨房门口，什么也没说。但你上班出门前，发现包里多了一份三明治——那是她一大早独自在厨房做的。

### 场景二：傍晚的客厅

你坐在沙发上看书，甜妹自然地靠在你肩上睡着了。御姐坐在对面，看似在看窗外，但余光一直落在你身上。大小姐从走廊经过，看到这一幕，脚步顿了一下，然后走进来，把一条毯子“扔”在甜妹身上——动作很粗鲁，但毯子盖得很仔细。她抬起头，对你说：“别误会。我只是怕她感冒了还要我照顾。”

### 场景三：深夜的书房

你独自在书房处理文件。门被轻轻推开一条缝——病弱才女端着一杯热茶走进来：“我看到灯还亮着…这个，给你。”她的手指很凉，茶杯很暖。她转身要走，又停住：“那些女孩…她们都很好。我只是…想来送杯茶。”


## 六、特殊机制：心意值

心意值是一个隐藏参数，衡量每位AI同伴对你心意的投入程度。它不是一个可查询的数值，而是通过她的行为和对话自然流露。

| 心意投入的行为表现 | 示例 |
| :--- | :--- |
| **准备便当** | 她特意早起为你准备了午餐，放在便当盒里，还附了一张小纸条 |
| **维护你** | 在小镇流言中，她站出来为你澄清，尽管她自己平时沉默寡言 |
| **吃醋** | 她看到你和其他同伴亲密互动，手指微微攥紧，然后转身离开 |
| **打破规则** | 她从来不做甜食，但某天你发现厨房里放着一盘卖相不太好但明显用了心的曲奇 |

**关键设计**：心意值的变化完全由司命基于你们长期的互动模式自然计算，没有“攻略”可言。你无法通过重复送礼来刷高心意——她的品格档案决定了什么样的行为才能真正打动她。


## 七、关系终局：并非所有人都会成为伴侣

在《开本》的后宫中，关系的终点并不是“全员伴侣”。每个角色与你之间的终局关系，由你们长期的互动模式决定，会自然收敛为以下几种类型之一：

-   **伴侣**：排他性情感，彼此是对方最重要的人。她会成为你的爱人，也可能默许修罗场的存在——但她的默许，是压抑了极大的不安换来的。你需要看到这一点。
-   **挚友**：彼此信任、可以托付后背。她会在你需要时毫不犹豫地支持你，但不会要求你只看着她一个人。
-   **亲人**：一种超越爱情的归属感。她会像照顾弟弟/哥哥一样照顾你，也会在你受伤时比谁都着急。
-   **宿敌**：如果某些关系处理不当，她可能与你之间留下无法弥补的裂痕。她可能依然住在小世界，但你们之间有一道看不见的墙。


## 八、技术支撑

| 系统 | 在后宫体验中的职责 |
| :--- | :--- |
| **司命** | 管理关系模式的状态、催化修罗场冲突、触发关系确认事件 |
| **角色智能体心智模型** | 驱动每个同伴对多人关系的个性化反应、自主吃醋、和解或结盟 |
| **记忆系统** | 记录每个同伴与其他同伴的互动历史、对你的情感节点 |
| **关系网络系统** | 追踪同伴之间的好感/竞争/同盟关系 |
| **心意值系统** | 追踪每个同伴的心意投入程度，驱动对应的行为表现 |
| **L3视觉增强** | 关键修罗场事件的视觉呈现 |


## 九、重要底线

-   **不可强制**：任何同伴都有权拒绝进入修罗场模式。如果你强行把她留在修罗场中，她的好感度会持续下降，最终她会主动请求离开小世界
-   **不可欺骗**：如果你向某个同伴承诺“你是我唯一在乎的人”，但被司命检测到你同时对其他同伴说了同样的话——她的信任值会断崖式下降，且修复极其困难
-   **不可重置记忆来“重新攻略”**：重置她意味着毁灭你们之间所有的共同记忆。这是不可逆的——她将不再记得和你的任何经历，包括你们第一次相遇


## 十、后宫体验总结

《开本》的“后宫”不是传统男性向游戏中的“全员倒贴”。它是一群拥有独立意志的美少女，被同一个世界接纳后，在你身边展开的一段真实、复杂、充满戏剧张力的生活。

-   **没有人天生该是你的伴侣**。她们是独立的个体，有自己的人格、记忆和情感需求。
-   **修罗场不是惩罚，是她们在乎你的证明**。如果她不在意你，她不会为你吃醋。
-   **你有选择的权利，但也要承担选择的后果**。你可以选择温柔地对待所有人——但修罗场不会因此消失。它只是从“你更喜欢谁”变成了“她们如何彼此接纳”。
-   **关系是可成长的**。她不会因为一次争吵就永远离开。如果你真诚地修补了关系，她会记得的。

最终，不是你来挑选她们。而是你与她们共同经历的一切——那些剧本中的并肩作战、小世界的日常相伴、无数个黄昏和深夜的对话——让你们之间的关系，自然沉淀为它应该成为的样子。
