## 一、重新评估：全云端方案的真实成本

### 1.1 智能体的数据消费量

智能体通过事件总线接收的是结构化JSON数据，而非画面或原始音频。每次交互需要处理的信息量取决于事件的复杂度。

| 交互类型 | 输入token估算 | 输出token估算 | 触发频率 |
| :--- | :--- | :--- | :--- |
| **被动感知事件**（如“你看到玩家走进院子”） | 100-300 | 0-50（仅更新状态，通常无需回应） | 每分钟数次 |
| **简短互动**（如“她跟你打招呼”“你让她帮忙倒茶”） | 200-500 | 100-300 | 每5-10分钟一次 |
| **日常对话**（如闲聊小镇见闻、讨论今天的天气） | 500-1500 | 200-800 | 每15-30分钟一次 |
| **深度对话**（如袒露心事、讨论你们的关系、回忆过去） | 2000-5000 | 500-2000 | 每1-2小时一次 |
| **司命催化事件**（如她的生日惊喜、羁绊里程碑） | 3000-8000 | 1000-3000 | 每天1-3次 |

### 1.2 每日Token消耗估算（2小时在线）

假设玩家每天在线2小时，AI同伴在此期间活跃互动。

| 交互类型 | 单次token | 次数/天 | 日token消耗 |
| :--- | :--- | :--- | :--- |
| 被动感知（状态更新） | 200 | 30次 | 6,000 |
| 简短互动 | 500 | 8次 | 4,000 |
| 日常对话 | 1,500 | 4次 | 6,000 |
| 深度对话 | 5,000 | 1次 | 5,000 |
| 司命催化事件 | 8,000 | 1次 | 8,000 |
| **每日总计** | — | — | **约29,000 tokens** |

### 1.3 月度成本估算

| 模型方案 | 单价（每百万tokens） | 日消耗 | 月成本（30天） |
| :--- | :--- | :--- | :--- |
| GPT-4o | $2.50 / $10.00 | 29,000 tokens | ¥6-25 |
| Claude 3.5 Sonnet | $3.00 / $15.00 | 29,000 tokens | ¥7-32 |
| DeepSeek-V3 | ¥1.00 / ¥4.00 | 29,000 tokens | **¥1-4** |
| 开源模型API（如Qwen） | ¥0.50-2.00 | 29,000 tokens | ¥0.5-2 |

**结论：全云端方案，单个AI同伴的月度成本在1-32元之间，取决于模型选择和对话深度。** 对于大多数日常对话，使用DeepSeek或开源模型API即可满足需求，月度成本可控制在5元以内。只有在深度情感对话时切换到高端模型才会触发较高单价，但这类对话频次低，对总成本影响有限。

### 1.4 为什么之前的估算严重偏高？

之前的估算假设AI同伴“每5分钟进行一次生成，每次消耗1万tokens”——这个假设建立在“AI需要处理视觉信息”的错误前提上。实际上：

- **事件总线传递的是结构化JSON**，不是画面描述。一次“玩家进入院子”的事件只需要约150个token的上下文。
- **AI同伴大部分时间处于“静默感知”状态**——她收到事件，更新内部状态，但不需要生成回应。这些静默感知的token消耗极低。
- **深度对话频率远低于假设**——在日常陪伴中，大部分互动是简短交流，而非每次都进行深度推理。


## 二、混合方案：本地小模型 + 云端大模型

全云端方案成本并不高，但使用本地小模型可以进一步优化体验——更低延迟、离线可用、隐私保护。

### 2.1 分工策略

| 交互类型 | 使用模型 | 延迟 | 成本 |
| :--- | :--- | :--- | :--- |
| 被动感知（状态更新） | 本地小模型（1-3B） | <50ms | 几乎为零 |
| 简短互动 | 本地小模型（1-3B） | <100ms | 几乎为零 |
| 日常对话 | 本地小模型（7-8B） | <500ms | 几乎为零 |
| 深度情感对话 | 云端大模型 | <3000ms | 按量付费 |
| 司命催化事件 | 云端大模型 | <3000ms | 按量付费 |

### 2.2 本地小模型技术方案

| 模型规格 | 显存占用 | 适用硬件 | 能力 |
| :--- | :--- | :--- | :--- |
| Qwen2.5-1.5B（4-bit量化） | ~1.5GB | 集成显卡/老旧显卡 | 状态更新、简短回应 |
| Qwen2.5-7B（4-bit量化） | ~5GB | GTX 1060 6GB及以上 | 日常对话、情感陪伴 |
| Llama-3.1-8B（4-bit量化） | ~6GB | RTX 2060 8GB及以上 | 复杂日常对话 |

**技术栈**：llama.cpp + Open-LLM-VTuber（可复用其对话框架）

### 2.3 云端模型切换策略

| 对话类型 | 推荐模型 | 月度预估调用量 | 月成本 |
| :--- | :--- | :--- | :--- |
| 深度情感对话 | Claude 3.5 Sonnet | 30次/月 | ¥3-6 |
| 司命催化事件 | GPT-4o | 30-90次/月 | ¥2-8 |
| **云端总计** | — | — | **¥5-14/月** |

## 四、推荐方案

| 玩家硬件条件 | 推荐方案 | 月成本 |
| :--- | :--- | :--- |
| 有6GB+显存显卡 | **本地7B模型（日常）+ 云端大模型（关键对话）** | ¥5-14 |
| 有16GB+统一内存（Apple Silicon） | **本地7B模型（日常）+ 云端大模型（关键对话）** | ¥5-14 |
| 低配硬件/移动端 | **纯云端DeepSeek（日常）+ 云端高端模型（关键对话）** | ¥2-6 |
| 无网络环境 | **纯本地7B模型** | 几乎为零 |


**一句话总结**：全云端方案的成本比我之前估算的低得多——单个AI同伴月度成本可控制在5元以内（使用DeepSeek等国产模型）。如果玩家有6GB以上显存，本地部署7B模型处理95%的日常互动，云端仅用于深度情感对话，月度总成本可控制在15元以内。这个成本完全在我们的商业模式可承载范围内，我们作为平台方可以直接承担，作为提供给玩家的基础服务。
