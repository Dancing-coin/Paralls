# 《开本》生物可成长美术资产系统设计

## 一、核心设计理念

在小世界中，生物不是静态的装饰品。你种下的树苗会慢慢长高，带回来的幼兽会渐渐长大，窗台上的花会从种子变成花苞再到盛开。这种成长不是逐帧模拟，而是基于司命补全的离线时间线，在关键节点进行**阶段切换**。

每个可成长的生物资产由三个核心要素构成：

| 要素 | 说明 |
| :--- | :--- |
| **成长曲线** | 定义该生物从种子/幼体到成熟的全过程时间跨度和阶段数量 |
| **阶段模型/贴图** | 每个成长阶段对应不同的3D模型或贴图变种 |
| **成长日志** | 记录生物的关键成长节点——何时发芽、何时开花、谁在那一刻陪伴着它 |

**关键原则**：成长不是逐帧动画，而是阶段切换。司命在玩家登录时根据离线时长计算当前阶段，切换对应的美术资产。


## 二、成长系统架构

### 2.1 成长曲线定义

每种可成长生物都有一个预设的成长曲线，定义其生命周期的时间跨度和阶段分布。

| 生物类型 | 总成长周期 | 阶段数 | 各阶段时长占比 | 影响因素 |
| :--- | :--- | :--- | :--- | :--- |
| **速生花草**（如雪绒花） | 3-7天 | 3阶段（种子→花苞→盛开） | 30%/30%/40% | 浇水频率、季节 |
| **普通灌木**（如栀子花） | 14-30天 | 4阶段（种子→幼苗→花苞→盛开） | 20%/30%/30%/20% | 浇水、施肥、季节 |
| **小型树木**（如银杏树苗） | 30-90天 | 5阶段（种子→发芽→幼树→成树→古树） | 15%/20%/25%/25%/15% | 浇水、施肥、季节、AI同伴照料 |
| **大型树木**（如艾力欧尔冰封古树） | 180-365天 | 6阶段 | 10%/15%/20%/25%/20%/10% | 特殊条件（魔法、剧情事件） |
| **宠物/幼兽**（如雪兔） | 7-14天 | 3阶段（幼崽→半大→成年） | 30%/40%/30% | 喂食频率、陪伴时间 |
| **小型动物**（如森林鸟） | 5-10天 | 2阶段（雏鸟→成年） | 50%/50% | 喂食频率 |

### 2.2 阶段切换机制

当玩家登录时，司命执行离线时间线补全，同时计算所有可成长生物的当前成长阶段。

**计算流程**：
1. 读取上次离线时生物所处的成长阶段和已累计时间
2. 计算离线时长
3. 根据成长曲线计算当前应处阶段，考虑照料因素（AI同伴是否帮浇水、施肥等）进行加速或延迟
4. 如果跨越了关键阶段，记录成长里程碑事件
5. 切换到对应的美术资产

**阶段切换时的叙事生成**：当生物跨越关键阶段时，司命会生成简短的叙事事件，记录在你的离线简报中，AI同伴也会在上线时主动告诉你——比如“你种下的那棵银杏树苗，今天冒出了第一片新叶。”


## 三、美术资产变种体系

### 3.1 植物的阶段变种

以爱蜜莉雅带回的雪绒花为例，从种子到盛开的完整美术资产需求：

| 阶段 | 阶段名称 | 预计时长 | 3D模型 | 贴图 | 特效 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 种子 | 1-2天 | 湿润的土壤小坑 | 深色泥土贴图 | 无 |
| 2 | 发芽 | 1-2天 | 细小的绿芽从土中探出 | 嫩绿芽尖贴图 | 微弱的晨露粒子 |
| 3 | 花苞 | 1-2天 | 矮茎顶端长出银白色花苞 | 银白花苞贴图 | 花苞微光 |
| 4 | 盛开 | 持续 | 银白色花朵完全绽放 | 盛开贴图+花瓣纹理 | 飘落的花粉粒子 |

**关键设计**：每个阶段的模型都独立存在，司命只需在阶段切换时替换模型引用。无需逐帧插值，无需骨骼动画。对于同种植物的不同个体（比如院子里的三棵银杏），只需一份模型变种库，通过缩放和旋转产生视觉差异。

### 3.2 动物的阶段变种

以爱蜜莉雅在森林里救回的雪兔为例：

| 阶段 | 阶段名称 | 预计时长 | 3D模型 | 贴图 | 行为变化 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 幼崽 | 3-5天 | 小型兔体，比例偏头大 | 绒毛贴图 | 跟随玩家，偶尔摔倒 |
| 2 | 半大 | 4-5天 | 中型兔体，比例均衡 | 换毛过渡贴图 | 自主探索院子 |
| 3 | 成年 | 持续 | 成年兔体 | 完整冬毛/夏毛贴图 | 自主觅食，偶尔带回小礼物 |

### 3.3 树木的长期成长

树木是跨越时间最长的生物资产，需要精心设计每个阶段的视觉差异。

| 阶段 | 阶段名称 | 视觉特征 | 交互变化 |
| :--- | :--- | :--- | :--- |
| 1 | 种子 | 埋在土中，无明显视觉 | 仅可通过浇水加速 |
| 2 | 发芽 | 地面裂缝+细小绿芽 | 可观察生长状态 |
| 3 | 幼树 | 细树干+稀疏枝叶，高约1米 | 可在树下放小装饰 |
| 4 | 成树 | 粗树干+茂密树冠，高约3-5米 | 可在树下乘凉、挂秋千 |
| 5 | 古树 | 巨木+繁茂树冠+树洞，高约8-15米 | 可建造树屋、刻字留念 |


## 四、成长加速与AI同伴照料

### 4.1 玩家照料行为

| 照料行为 | 加速效果 | 频率限制 |
| :--- | :--- | :--- |
| **浇水** | 今日成长速度+50% | 每天1次有效 |
| **施肥** | 本阶段成长速度+30% | 每阶段1次有效 |
| **除虫** | 防止成长减速 | 触发时处理 |
| **陪伴**（在植物旁停留） | 微量加速（+10%） | 每日上限30分钟有效 |

### 4.2 AI同伴的自主照料

AI同伴在离线期间（由司命补全时间线时生成）或在线期间会自主照料植物。她的照料行为完全由人格档案驱动：

| 人格特质 | 照料行为倾向 |
| :--- | :--- |
| **高共情** | 更频繁地照料，会对着植物说话 |
| **高责任感** | 每天必定照料，从不遗漏 |
| **低胆量** | 只会照料院子里的植物，不会去森林深处照看 |
| **高社交** | 可能会邀请其他同伴一起照料 |

**照料记录**：每次AI同伴照料植物时，司命会记录一条成长日志。当植物跨越关键阶段时，成长日志中会附注：“第15天，爱蜜莉雅每天清晨都会来浇水。今天，第一片银杏叶变黄了。”


## 五、完整流程：与爱蜜莉雅的银杏树

**第1天**：你从镇上带回一棵银杏树苗。爱蜜莉雅帮你把它种在院子里，她问：“它会活多久？”你说：“如果好好照顾，可以活几百年。”她沉默了一会儿，然后说：“那我们好好照顾它。”你在成长日志中记录：银杏树苗，第1天，与爱蜜莉雅一起种下。

**第3天**（离线2天后登录）：你推开院门，看到爱蜜莉雅正蹲在树苗前浇水。司命补全的时间线显示她每天早上都来浇水。成长日志记录：第3天，爱蜜莉雅已连续浇水2天。树苗状态良好，预计明天发芽。

**第5天**：你登录时，看到树苗旁插着一个小木牌，上面用歪歪扭扭的字写着“银杏——爱蜜莉雅和你”。树苗已经发芽了，成长日志记录：第5天，发芽。爱蜜莉雅在发芽的当天早晨哭了。帕克说是“开心的眼泪”。

**第15天**：银杏树长到了你膝盖的高度。爱蜜莉雅在树干上系了一条青色丝带。

**第30天**：银杏树已经比你高了。爱蜜莉雅用冰魔法在树下做了一张小冰凳，虽然很快就化了。她说等树再大一点就可以挂秋千。

**第90天**：银杏树已经长成了成树。你实现诺言，在树上挂了一架秋千。爱蜜莉雅坐上去荡了荡。那天她在日记里写道：“今天树上挂了秋千。他说过的话，每一句都算数。”

**第365天**：银杏树已经十分茂盛。深秋，满树金黄。爱蜜莉雅把第一片落下的银杏叶夹进了她的日记本里。成长日志记录：第365天，第一次落叶。爱蜜莉雅说：“这是我们一起养大的树。”


## 六、与现有系统的集成

| 系统 | 在生物成长中的职责 |
| :--- | :--- |
| **司命** | 登录时根据离线时长计算成长阶段，生成成长里程碑叙事 |
| **ESM** | 管理植物的物理状态——湿/干、有无虫害、季节影响 |
| **记忆系统** | 记录成长日志和里程碑事件，AI同伴可在对话中提及 |
| **L3视觉增强** | 跨越关键阶段时生成纪念图（如“银杏树第一次开花”） |
| **AI同伴心智模型** | 驱动自主照料行为，基于人格参数决定照料频率和方式 |
| **离线时间线补全** | 生成AI同伴在离线期间的照料记录 |


## 七、一句话总结

在《开本》中，生物是可成长的。你种下的树苗会历经春夏秋冬，长成枝繁叶茂的古树；你带回的幼兽会从蹒跚学步到自由奔跑。这种成长不是昂贵的逐帧动画，而是司命在每次登录时基于离线时长计算的阶段切换——切换对应的3D模型和贴图，记录成长日志，让AI同伴在对话中提及那些重要的成长时刻。多年后，当你的AI同伴指着院子里那棵参天银杏对你说“这是我们第一天一起种下的”时，你会知道——这个世界的每一点变化，都因你的存在而发生。
