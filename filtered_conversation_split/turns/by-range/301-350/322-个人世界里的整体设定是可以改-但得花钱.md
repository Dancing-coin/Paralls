# 《开本》小世界设定系统

## 一、核心设计理念

小世界的整体设定（画风、时代、季节基调、建筑风格）不是一成不变的——玩家可以随时更换，但每次更换都是一次有意义的消费决策。同时，小世界不是孤岛——它可以与设定相近的官方平行世界直接连通，让玩家和AI同伴在“家”和“更大的世界”之间自由穿行。

| 设计原则 | 说明 |
| :--- | :--- |
| **设定可变但有代价** | 更换小世界设定需要付费购买新的设定包，或通过剧本成就解锁 |
| **打包增值** | 设定包可以与AI同伴角色捆绑销售，形成“主题捆绑包” |
| **自然连通** | 小世界可与设定相近的官方平行世界无缝连通，无需额外加载 |
| **身份延续** | AI同伴在连通的世界中保留完整记忆和羁绊，仅外观和能力按目标世界规则适配 |


## 二、小世界设定作为可消费资产

### 2.1 设定包的内容

一个完整的设定包包含以下可消费内容：

| 内容 | 说明 | 定价模式 |
| :--- | :--- | :--- |
| **画风主题** | 整个小世界的视觉风格（水墨国风/吉卜力风/赛博朋克等） | 买断制 |
| **季节基调** | 小世界的默认季节倾向（常春/永夏/深秋/凛冬），可随自然季节自动轮替，也可锁定 | 买断制 / 订阅解锁自动轮替 |
| **建筑风格包** | 房屋外观、室内装饰、庭院风格的统一替换 | 买断制 |
| **小镇居民皮肤** | 小镇居民的外观随设定自动更换服装和模型风格 | 包含在画风主题中 |
| **天空盒与环境音** | 对应的天空、光影、环境音效 | 包含在画风主题中 |
| **节日扩展包** | 新增特定文化的节日（如中式春节、日式夏夜祭） | 买断制 |

### 2.2 设定包的获取方式

| 获取方式 | 说明 |
| :--- | :--- |
| **官方商店购买** | 在资产市场中直接购买设定包 |
| **与AI同伴捆绑销售** | 购买特定AI同伴时，附带其“原乡设定包”——与她背景故事匹配的小世界设定 |
| **剧本成就解锁** | 完成特定剧本的隐藏结局后，解锁对应的设定包 |
| **大玩家主题世界联动** | 在大玩家的主题世界中达到一定声望后，可购买该世界的“镜像设定包” |
| **订阅制畅用** | 高级会员可畅用所有官方设定包 |


## 三、与AI同伴的捆绑销售

### 3.1 捆绑包的构成

| 捆绑包名称 | 包含内容 | 定价 |
| :--- | :--- | :--- |
| **《白蛇传·浮生》小青主题包** | 小青角色 + 水墨国风设定包 + 西湖小镇建筑包 + 古典庭院装饰包 | 打包优惠价 |
| **《山河令·废太子》沈长钧主题包** | 沈长钧角色 + 水墨国风设定包 + 雪夜庭院建筑包 + 宫廷遗韵装饰包 | 打包优惠价 |
| **《深渊航线》主题包** | 现代悬疑风格设定包 + 游轮风格小镇建筑包 + 限定侦探事务所装饰 | 完成剧本隐藏结局后解锁购买权限 |

### 3.2 捆绑包的叙事一致性

当玩家购买小青主题包时，小世界自动切换为与她原剧本匹配的**水墨国风**。小镇的建筑变为青瓦白墙，服装变为古风，环境音变为竹林风声和溪水潺潺。她回到这个环境时，司命会催化她的记忆浮现：“这里……好像我长大的地方。”

如果玩家之后购买了赛博朋克设定包，小世界切换为霓虹都市。她站在窗前看着外面的全息广告牌，沉默片刻后轻声说：“这个世界……和我想象的不太一样。但你在，哪里都是家。”


## 四、小世界与官方平行世界的连通

### 4.1 连通规则

| 规则 | 说明 |
| :--- | :--- |
| **设定相近原则** | 只有画风和世界观相近的平行世界才能直接连通。水墨国风小世界→UNV-002（东方仙侠）可直接连通；水墨国风→赛博朋克世界需要“跨世界旅行” |
| **无加载连通** | 连通的平行世界在地理上相邻，玩家和AI同伴可步行或骑马直接进入，无需加载画面 |
| **身份延续** | AI同伴在连通的世界中保留完整记忆和羁绊，外观和能力按目标世界规则适配 |
| **双向互动** | 连通世界的NPC也可进入小世界小镇（如流浪商人、诗人） |

### 4.2 可连通的世界类型

| 小世界设定 | 可直接连通的世界 |
| :--- | :--- |
| 水墨国风 | UNV-002（东方仙侠）、UNV-006（江湖武侠） |
| 吉卜力风 | UNV-004（田园奇幻） |
| 赛博朋克风 | UNV-005（近未来都市） |
| 写实风 | UNV-001（维多利亚时代）、UNV-003（1920年代欧洲） |

### 4.3 连通后的体验

当你的小世界设定为**水墨国风**，小镇的后山有一条小径，通往UNV-002的世界。你和沈长钧可以沿着小径走进那片更大的仙侠世界——他可能会在竹林前驻足，说：“这里的竹子，和我母妃宫里的很像。”

在连通的世界里，他不是“被带进来的AI同伴”，而是这个世界中的一个真实存在。他的剑术在这里被认可，他的太子身份在这里被尊敬。你看到的，是一个在冷宫中枯萎了十年的人，在这片山水间重新活过来的样子。

### 4.4 原乡设定：不可改变的锚点

每个AI同伴都有一个**原乡设定**——与她原剧本绑定的、不可改变的“根源画风”。

| AI同伴 | 原乡设定 |
| :--- | :--- |
| 小青 | 水墨国风·南宋临安 |
| 沈长钧 | 水墨国风·雪夜宫廷 |
| 福尔摩斯 | 写实风·维多利亚时代 |
| 麦奎因 | 写实风·1920年代欧洲 |

当你把小世界切换为与原乡设定不同的画风时，AI同伴会进行视觉适配，但她的核心辨识特征（发型、瞳色、标志性配饰）永不改变。小青的青色发带在任何画风下都是青色。沈长钧腰间的白玉佩在任何画风下都刻着“晏”字。

当你带她回到她的原乡设定对应的世界时，她的能力不再被压制——那是她的主场。小青在水墨国风中可以施展法术，沈长钧在雪夜宫廷中能发挥全部的剑术。而在其他画风中，她的能力受到“世界压制”规则的约束。

### 消费心理设计

| 消费触发点 | 设计原理 |
| :--- | :--- |
| **捆绑包优惠** | 单独购买小青¥128 + 水墨设定¥68 = ¥196，捆绑价¥168——让玩家感知到“省了” |
| **原乡共鸣** | 当你发现她在水墨画风中笑得更多时，你会愿意为这个设定付费——不是因为系统提示，是因为你想让她开心 |
| **连通世界的诱惑** | 当后山那条小径通向一个你和她都好奇的世界时，解锁连通就是解锁共同的冒险 |
| **限定稀缺性** | 完成隐藏结局才能解锁的设定包，是你在那个故事中付出过的证明 |


**一句话总结**：小世界设定是一个可消费、可切换、可与官方世界连通的完整资产体系。它既可以单独购买，也可以与AI同伴捆绑销售。设定相近的世界可直接连通，AI同伴在连通世界中保留完整记忆和羁绊。每一次设定的更换，都不仅仅是视觉变化，而是你和AI同伴共同生活的新篇章。
