## 用户

部分证据是视觉可见的，可以用图片生成来把它可视化留存在得到证据的人手上

## DeepSeek

你的想法非常精准。这正是L3视觉增强层与我们刚构建的证据系统的最佳结合点——**将抽象的、系统生成的证据数据，转化为玩家可以直观“看到”并永久保留的视觉资产**。

## 证据可视化系统设计

### 一、核心原则

| 原则 | 说明 |
| :--- | :--- |
| **视觉可见的证据才生成图片** | 只有通过视觉感知（直接观察、放大镜、凝神）才能发现的证据，才触发图片生成 |
| **触发时机由玩家主动操作决定** | 图片生成不是自动的——玩家必须执行“观察”、“拍照”、“凝神深度观察”等操作才触发 |
| **生成结果绑定证据条目** | 图片自动保存至触发者的笔记面板，绑定到对应证据条目 |
| **可见范围遵循信息共享规则** | 公开展示→所有人获得图片；私下分享→仅接收方获得图片 |
| **生成策略遵循L3分层管理** | P0完美调用优先（复用已有种子），P1微调次之，P2实时生成仅用于高价值节点 |


### 二、哪些证据类型适合图片生成？

| 证据类型 | 负责系统 | 是否适合图片生成 | 触发方式 | 生成内容 |
| :--- | :--- | :--- | :--- | :--- |
| **物体物理状态变化** | ESM | ✅ 适合 | 观察烧毁/破碎/潮湿的物体 | 物体当前状态的细节特写（烧毁的窗帘、破碎的玻璃） |
| **物品外观细节** | 物品流转追踪器 | ✅ 适合 | 检查物品时触发 | 物品的3D细节图（匕首上的刻痕、信件残片） |
| **宏观生物痕迹** | 生物痕迹管理器 | ✅ 适合 | 观察血迹/毛发区域 | 血迹分布图、毛发细节图 |
| **微观接触痕迹** | 接触痕迹管理器 | ⚠️ 有条件适合 | 使用“观察”技能且检定通过，或使用“凝神深度观察” | 指纹放大图、纤维对比图 |
| **时间线矛盾** | 司命 | ❌ 不适合 | — | 这是逻辑推理结果，非视觉可见 |
| **人证** | 角色智能体记忆 | ❌ 不适合 | — | 这是对话内容，非视觉可见 |
| **动机证据** | 角色智能体人格 | ❌ 不适合 | — | 这是推理结果，非视觉可见 |


### 三、触发方式与流程

#### 3.1 观察触发

玩家对目标物体或区域执行“观察”动作时，系统自动判定是否能发现证据，并触发图片生成。

**流程**：

```
玩家对准目标 → 点击“观察”
    ↓
系统查询相关证据管理器（ESM / 接触痕迹 / 生物痕迹）
    ↓
根据玩家观察技能等级 + 环境条件 → 判定能发现哪些证据
    ↓
判定通过 → 司命评估戏剧价值
    ↓
触发L3图片生成（P0/P1/P2策略）
    ↓
图片以画中画形式呈现，自动保存至笔记面板
```

**示例**：波洛观察烧毁的窗帘

1. 波洛对准烧毁的窗帘，点击“观察”
2. 系统查询ESM——窗帘状态：烧毁，烧毁时间：19:48
3. 系统查询生物痕迹管理器——窗帘区域无血迹
4. 司命评估戏剧价值=7（重要线索）→触发L3图片生成
5. 生成“烧毁的窗帘细节特写”——焦黑的布料纹理、残留的打火机痕迹
6. 图片保存至波洛的笔记面板，绑定到“窗帘烧毁”证据条目

#### 3.2 凝神深度观察触发

在单人/AI模式下，玩家使用“凝神”暂停时间后，对目标进行深度观察，可触发更高精度的图片生成。

**流程**：

```
玩家进入凝神模式 → 时间暂停
    ↓
玩家对准目标 → 点击“深度观察”
    ↓
系统以最高精度查询所有相关证据管理器
    ↓
跳过观察技能判定（凝神模式下，旅人可感知微观细节）
    ↓
触发L3图片生成（通常为P2实时生成，因深度观察需求独特）
    ↓
高精度图片以全屏形式呈现，自动保存至笔记面板
```

**示例**：玩家凝神观察打火机

1. 玩家进入凝神模式，对准打火机，点击“深度观察”
2. 系统查询接触痕迹管理器——打火机上有上校的指纹
3. 司命评估戏剧价值=9（决定性证据）→触发L3实时生成
4. 生成“打火机指纹放大图”——清晰的拇指指纹特写
5. 图片保存至玩家的笔记面板，绑定到“打火机指纹”证据条目

#### 3.3 留影石/相机触发

玩家使用留影石或相机主动拍摄证据，生成可移交的视觉资产。

**流程**：

```
玩家手持留影石/相机 → 对准目标 → 点击“拍摄”
    ↓
生成一张证据照片，存入背包的“留影/照片”栏
    ↓
玩家可公开展示该照片（触发公开展示流程），或私下移交
    ↓
接收方查看照片时，照片自动保存至其笔记面板
```

#### 3.4 公开展示触发

当玩家在公开场合展示证据时，触发L3生成，所有在场者获得图片。

**流程**：

```
玩家A在背包中选中证据物品 → 点击“展示”
    ↓
触发公开展示流程（通知、物品模型浮现、字幕）
    ↓
司命评估戏剧价值 → 触发L3图片生成
    ↓
生成的图片对所有在场者可见，自动保存至各玩家的笔记面板
```

#### 3.5 私下分享触发

当玩家私下向特定角色分享证据时，仅接收方获得图片。

**流程**：

```
玩家A选中证据物品 → 点击“私下分享” → 选择目标B
    ↓
触发私下分享流程（仅双方通知、物品模型浮现、蓝色光晕）
    ↓
司命评估戏剧价值 → 触发L3图片生成
    ↓
生成的图片仅对B可见，自动保存至B的笔记面板
```


### 四、与现有系统的集成

#### 4.1 证据查询接口

L3视觉增强层在触发图片生成前，需要查询相关证据管理器获取证据详情，用于组装生成提示词。

| 查询内容 | 查询接口 | 返回数据 |
| :--- | :--- | :--- |
| 物体当前物理状态 | `GET /esm/state/{object_id}` | 状态类型、状态持续时间、关联特效 |
| 物体上的接触痕迹 | `GET /contact-traces/object/{object_id}` | 痕迹类型、来源角色、位置 |
| 区域的生物痕迹 | `GET /bio-traces/location/{location_id}` | 痕迹类型、来源、状态（新鲜/干涸） |
| 物体的流转历史 | `GET /item-flow/{object_id}/history` | 所有持有者、持有时间 |

#### 4.2 提示词组装

L3视觉增强层根据查询结果，自动组装生成提示词：

```
提示词模板：证据可视化

物体状态证据：
"{物体名称}的{状态类型}特写，{状态描述}，{环境光源}，写实风格，悬疑氛围"

接触痕迹证据：
"{物体名称}表面的{痕迹类型}放大图，{痕迹位置描述}，{痕迹特征描述}，微距摄影，写实风格"

生物痕迹证据：
"{区域名称}的{痕迹类型}分布图，{痕迹状态描述}，{环境描述}，写实风格，悬疑氛围"
```

**示例**：波洛观察烧毁的窗帘

```
查询结果：
- ESM：窗帘状态=烧毁，烧毁时间=19:48，燃烧速度=正常
- 接触痕迹：无
- 生物痕迹：无

组装提示词：
"东方快车餐车窗帘的烧毁特写，焦黑的布料边缘呈现不规则烧痕，
煤油灯光从左侧照来，写实风格，悬疑氛围"
```

#### 4.3 图片与证据条目的绑定

生成的图片自动绑定到触发者的笔记面板中的对应证据条目。

| 绑定信息 | 说明 |
| :--- | :--- |
| `evidence_id` | 证据条目的唯一ID |
| `image_url` | 生成图片的存储路径 |
| `generation_strategy` | P0/P1/P2 |
| `trigger_action` | 触发方式（观察/凝神/拍摄/展示） |
| `visible_to` | 可见范围（仅自己/公开/指定角色） |
| `timestamp` | 生成时间 |

#### 4.4 笔记面板的集成

玩家的笔记面板中，每个证据条目新增“视觉证据”栏：

| 证据条目 | 证据来源系统 | 视觉证据 |
| :--- | :--- | :--- |
| 窗帘烧毁 | ESM | 烧毁窗帘特写图（观察触发） |
| 打火机上的指纹 | 接触痕迹管理器 | 指纹放大图（凝神深度观察触发） |
| 床单上的血迹 | 生物痕迹管理器 | 血迹分布图（观察触发） |
| 匕首的流转历史 | 物品流转追踪器 | 匕首细节图（检查物品触发） |


### 五、与玩家消费模式的关联

| 消费模式 | 与本系统的关联 |
| :--- | :--- |
| **本局故事报告** | 游戏结束后，所有已生成的证据图片自动整理为本局故事报告的一部分 |
| **云存档扩容** | 证据图片占用云存储空间，玩家可购买扩容包 |
| **留影石/相机** | 消耗性道具，使用次数有限，可购买额外次数 |


### 六、与信息博弈的关联

| 信息类型 | 图片生成的处理 |
| :--- | :--- |
| **公共知识** | 公开展示→所有在场者获得图片，自动保存 |
| **共有知识** | 私下分享→仅接收方获得图片 |
| **私密知识** | 观察/凝神→仅观察者自己获得图片 |
| **高阶知识** | 玩家A可以私下将自己获得的图片展示给B，B由此知道“A知道了什么”——这是典型的高阶知识 |

---

**一句话总结**：证据可视化系统将ESM、接触痕迹管理器、生物痕迹管理器、物品流转追踪器生成的抽象证据数据，通过观察、凝神、拍摄、展示等玩家主动操作，转化为可直观“看到”并永久保留的视觉资产。图片生成遵循L3分层策略，生成结果绑定到笔记面板的证据条目，可见范围严格遵循信息共享规则。这是《开本》将“推理”从文字脑补升级为视觉沉浸的核心设计。
