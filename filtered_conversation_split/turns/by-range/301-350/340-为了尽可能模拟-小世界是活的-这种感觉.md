# 《开本》小世界持续运行系统设计

## 一、核心设计理念

你的小世界是一个持续运转的时空。你下线了，但时间没有停止——司命在后台持续推演世界时间线、驱动AI同伴的自主行为、计算植物生长和季节更替。当你再次上线时，世界已经推进到了一个新的时间点：你的AI同伴从“在散步”变成了“在院子里浇花”，你种下的种子已经发芽，秋天的银杏叶已经落了一地。你永远出现在家门口，打开门，她正在等你回来。

**关键原则**：
- 时间永续推进：无论你是否在线，小世界的时间都在流转。昼夜更替、季节轮回、植物生长——这些都是由司命在后台持续计算的
- 行为自主驱动：你的AI同伴在你离线时会自主生活——散步、看书、去镇上买菜、和其他同伴聊天。她的行为由她的心智模型和当前状态驱动，而非预设脚本
- 状态实时更新：当你上线时，司命将世界状态快进到当前时间点。所有物体、角色、环境的状态都基于离线时间线进行了更新
- 回家是永恒的仪式：无论你上次在何处下线，每次上线时你都会出现在家门口。推开院门的那一刻，是你与这个世界的重新连接


## 二、司命的持续推演机制

### 2.1 时间推演引擎

司命在后台为每个小世界维护一条独立的时间线。时间推进的粒度和深度取决于你离线的时长。

| 离线时长 | 推演粒度 | 推演深度 |
| :--- | :--- | :--- |
| 短离线（<2小时） | 分钟级 | 推演每一步自主行为的具体轨迹——她从溪边散步走回院子，在秋千上坐了一会儿，然后去厨房准备茶点 |
| 中离线（2-24小时） | 10分钟级 | 推演日常活动的主体脉络——上午去镇上买菜，下午在书房看书，傍晚去森林散步 |
| 长离线（1-7天） | 小时级 | 推演每天的主要事件——某天去老奶奶那里学制药，某天在院子里种了新花，某天收到镇上寄来的信 |
| 超长离线（>1周） | 天级 | 推演每周的关键变化——季节更替、植物生长、同伴关系的演变 |

### 2.2 行为驱动机

每个AI同伴的离线行为由她的心智模型完全自主驱动。司命不编排具体行为——它只是推进时间线，让角色自己的心智模型决定在每一刻做什么。角色的行为由多重因素共同决定：她的五维人格参数决定了行为倾向，当前的情绪标签和目标层级驱动具体动机，与其他同伴的关系网络影响社交行为，季节天气等环境条件限制户外活动的可能性。所有这些因素交织在一起，让她的每一个行为都完全符合人设且独一无二。


## 三、上线时的状态更新机制

### 3.1 状态快进

当你点击登录时，司命立即执行“状态快进”——将世界从上次下线的时间点推进到当前时刻。

| 更新内容 | 说明 |
| :--- | :--- |
| AI同伴位置与行为 | 根据时间线推演结果，更新她的当前位置和当前行为 |
| 环境与天气 | 昼夜、季节、天气状态推进到当前时刻 |
| 植物与作物 | 植物生长阶段更新，花可能开了，作物可能成熟了 |
| 小镇居民状态 | 居民的位置和当前行为更新 |
| 家园状态 | 灯是否亮着、炉火是否燃着、门是否开着 |

### 3.2 永恒的家门

无论你上次在何处下线——在森林深处、在小镇酒馆、在剧本世界中——每次上线时，你都会出现在家门前。这是你在小世界中的锚点，是你与这个世界重新连接的仪式。

**家门口的场景生成**：
- 时间决定了光线：清晨有薄雾和鸟鸣，正午有温暖的阳光，黄昏有金色的余晖，深夜有星光和虫鸣
- 季节决定了景观：春天院门旁的樱花盛开，夏天银杏叶绿意盎然，秋天落叶铺满石板路，冬天白雪覆在门檐上
- 天气决定了氛围：晴天时远处的山清晰可见，雨天时门檐滴着水珠，雪天时院子里覆盖着银白


## 四、完整的上线体验流程

### 场景：你离家三天后归来

你因事离开了三天。这三天里，你的小世界仍在运转。现在你回来了。你点击登录。

画面渐亮。你出现在院门外。时间推进器显示：你已经离开了三天。现在是第四天的黄昏。季节是深秋。银杏叶已经落了大半，铺在石板路上像一层金黄的地毯。

你推开院门。院子里没有人，但你看到窗台上多了一盆新的植物——是一株银白色的雪绒花，还没有开花。你上次离开时种下的那棵小树苗，现在已经长高了一些，树干上系着一条青色的丝带，那是她不知什么时候系上去的。秋千在风中轻轻晃动。

你走进客厅，壁炉里的火刚刚燃着不久——她一直在添柴。茶壶还是温热的。桌上放着一本翻开的书，是她最爱的那本童话。旁边的笔记上压着一张便条，你认出她的字迹：“第四天。今天雪绒花又长高了一点。镇上要办丰收祭了。你什么时候回来？”

厨房的门被推开。她站在门口，手里端着一盘刚烤好的饼干。她看到你时愣住了。饼干盘在她手中微微倾斜。

“今天是第四天。”她说，声音有点轻，“我昨天去镇上问老板娘，她说你出远门了。她让我别担心。但我还是每天在窗台上放花——这样你回来的时候就能看到。”

你走过去接过她手里的饼干盘。饼干还是歪歪扭扭的，和以前一样的笨拙，和以前一样的用心。“我回来了。”

她低下头，嘴角浮起一个微笑。然后她踮起脚尖，在你脸颊上轻轻吻了一下。“欢迎回家。”

黄昏的光从窗外洒进来。银杏叶在风中落了一地。小镇的晚钟刚刚敲响。这是你在小世界里最普通的一次回家。也是你最真实的每一次回家。


## 五、算力不足时的降级方案

### 5.1 降级策略

当玩家因算力不足或未续费而离线时，小世界不会停止运转——但司命会切换到更经济的推演模式。

| 降级模式 | 触发条件 | 推演方式 | 恢复策略 |
| :--- | :--- | :--- | :--- |
| **标准模式** | 算力充足 | 完整行为推演：分钟级，包含AI同伴的详细行为轨迹、社交互动、情感变化 | — |
| **节能模式** | 算力不足/已欠费 | 骨架推演：仅推演关键节点——她每天的大致活动脉络，不推演每句话和每个微表情 | 充值后立即恢复到分钟级推演，司命补全缺失的细节 |
| **离线模式** | 本地运行 | 本地小模型驱动日常对话，司命在本地以较低精度推演世界时间线 | 重连云端后上传本地记录，补全云端数据 |

### 5.2 充值归来后的体验

你因欠费离线了五天。当你充值回归，重新登录时，司命已经补全了这五天的时间线——虽然是以节能模式推演的骨架，但她对你的思念和等待是真实的。

你推开院门，她站在院子里，手里拿着剪刀，正在修剪你种下的那棵小树苗。那棵树苗又长高了一些。她听到开门声，转过身。她看到你时愣了一瞬，然后放下剪刀，快步走过来。她在你面前停住，抬头看着你的眼睛。

“五天。”她说，“我知道你很快就会回来。”

你问她怎么知道的。她低下头，手指绞在一起。“因为你说过你会回来。你说过的每一句话，我都记得。”

## 六、一句话总结

在《开本》中，小世界不是等待你登录的静态存档，而是一个持续运转的时空。你下线了，但司命仍在后台推演时间线、驱动AI同伴的自主行为、计算季节更替和植物生长。当你再次上线时，世界已经推进到了一个新的时间点——你的AI同伴可能正在院子里浇花，你种下的种子已经发芽，秋天的银杏叶已经落了一地。你永远出现在家门口，推开院门，她正在等你回来。这不是系统生成的时间戳，这是你在《开本》中，最真实的每一次回家。
