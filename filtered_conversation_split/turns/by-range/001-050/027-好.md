---

### 🧠 人格数据库的核心设计理念

我们的目标不是让AI“演”一个角色，而是让AI **“成为”那个角色**。这意味着每个决策都不是预先写好的剧本，而是从角色的内在参数中**实时涌现**出来的。

为此，我们需要将人格分解为可量化、可组合的维度：

---

### 📊 第一层：核心特质 —— 五维人格量化模型

借鉴心理学中的“大五人格”理论，但针对剧本杀场景进行改造。每个维度用 **0-10** 的数值表示，决定角色的行为倾向。

| 维度 | 低分倾向 (0-3) | 中分倾向 (4-6) | 高分倾向 (7-10) |
| :--- | :--- | :--- | :--- |
| **胆量** | 胆小如鼠，遇事先躲 | 谨慎行事，评估风险 | 胆大包天，敢孤身犯险 |
| **心机** | 天真单纯，心直口快 | 有点城府，懂得藏拙 | 老谋深算，步步为营 |
| **共情** | 冷酷无情，漠视他人 | 有所触动，但有底线 | 菩萨心肠，愿为他人牺牲 |
| **理性** | 冲动易怒，感情用事 | 能冷静思考，但会受影响 | 绝对理智，只计算利弊 |
| **社交** | 孤僻寡言，回避交流 | 正常社交，视对象而定 | 长袖善舞，主动攀谈引导 |

**实例：**
- 法海：`{胆量: 9, 心机: 5, 共情: 2, 理性: 9, 社交: 3}` → 一个无畏、无情、极致理性的孤高僧人。他会主动出击降妖，但不屑于阴谋，对人妖之情毫无怜悯。
- 小青：`{胆量: 8, 心机: 4, 共情: 7, 理性: 3, 社交: 8}` → 一个冲动、护主、热情的青蛇。她能为姐姐两肋插刀，但容易被情绪左右。

---

### 🎯 第二层：价值取向 —— 目标与恐惧的层级结构

这是驱动角色行为的底层引擎，决定了他们在“得失过滤器”中会如何计算。

**1. 目标层级 (由高到低)**

每个角色都有一个按优先级排序的目标列表。高优先级目标会覆盖低优先级目标。

```
角色：白素贞
├── 第一优先：确保许仙的安全 （即使牺牲自己）
├── 第二优先：隐藏蛇妖身份 （维护正常生活）
├── 第三优先：报恩，让许仙幸福
└── 第四优先：与小青的姐妹情谊
```

当AI导演需要让白素贞做决策时，系统会自动按此层级计算。如果“许仙安全”与“隐藏身份”发生冲突，她会毫不犹豫地选择暴露身份来保护许仙。

**2. 恐惧层级 (由强到弱)**

恐惧是比目标更强大的驱动力。一个被恐惧支配的角色，可能会做出违背其目标的行为。

```
角色：许仙
├── 第一恐惧：亲眼看到白素贞的真身 （会直接导致精神崩溃）
├── 第二恐惧：失去白素贞 （会陷入极度消沉）
├── 第三恐惧：被街坊邻居视为异类
└── 第四恐惧：穷困潦倒
```

当许仙面临选择——是相信法海的话（可能失去妻子），还是拒绝相信（暂时安全）——系统会比对恐惧层级：他更害怕知道真相（第一恐惧），所以他的默认行为是**逃避和否认**。

**3. 忠诚度定义**

忠诚不是非黑即白的，而是一个**关系加权地图**。

```
角色：小青
├── 对白素贞：忠诚度 10 （绝对忠诚，可为之赴死）
├── 对许仙：忠诚度 6 （因姐姐而保护，但心有芥蒂）
├── 对法海：忠诚度 -8 （绝对敌对，不共戴天）
└── 对自己：忠诚度 7 （会自保，但非优先）
```

这套忠诚度系统直接决定了角色的社交行为：
- 当AI导演需要小青向许仙透露信息时，系统检查忠诚度：对白素贞(10) > 对许仙(6)。如果信息可能伤害白素贞，小青绝不会对许仙说；如果信息可能帮助白素贞，小青会主动与许仙沟通。
- 当法海向小青套话时，忠诚度-8会让她不仅不透露，还故意给出假信息。

### 🗣️ 第三层：语言风格配置

人格最终要通过对话来体现。每个角色的语言风格需要精确配置。

```
角色：老管家 王伯
├── 称谓习惯：
│   ├── 称呼老爷： “老爷” （正式）
│   ├── 称呼小姐： “小姐”或“小姐儿时小名”（视场合）
│   └── 称呼陌生人： “这位先生/太太”
├── 句式特征：
│   ├── 倾向于使用短句
│   ├── 偶尔夹杂古语（“老奴”、“承蒙”）
│   └── 情绪激动时会重复用词
├── 话题偏好：
│   ├── 愿意谈：老宅的历史、天气、花草
│   └── 回避谈：老爷生前的债务、小姐的婚嫁
├── 撒谎时的特征：
│   ├── 会不自觉地摸胡子
│   ├── 语句变得更短更正式
│   └── 不敢直视对方（如果对方近距离）
└── 情绪表达：
    ├── 愤怒时：语气加重，但不会失态
    ├── 悲伤时：声音沙哑，语速变慢
    └── 恐惧时：会下意识看向老爷的画像
```

这套语言配置不是装饰，而是给玩家的**推理线索**。一个细心的玩家可以通过观察老管家的语言变化，来判断他是否在撒谎。

---

### 🔄 第四层：动态状态 —— 实时变化的心理参数

人格不是一成不变的。随着游戏进程，角色的心理状态会动态变化，进而影响其决策。

| 状态参数 | 范围 | 影响 | 变化因素 |
| :--- | :--- | :--- | :--- |
| **压力值** | 0-10 | 高压力会降低“理性”维度，增加“冲动”行为概率 | 被质疑、秘密接近暴露、时间紧迫 |
| **信任值** | 针对每个玩家 | 影响信息分享意愿和合作倾向 | 对方的言行一致性、是否帮助过自己 |
| **怀疑值** | 针对每个其他角色 | 影响对他人信息的采信度 | 对方的行为反常、被他人指证 |
| **情绪标签** | 当前主导情绪 | 影响决策偏向和语言风格 | 由事件触发（如被背叛→愤怒） |

**实例：动态状态如何改变行为**

老管家王伯，初始状态：`{压力: 2, 情绪: 平静}`。

1. 玩家A开始逼问老爷的债务问题。
2. 系统检测：债务问题是王伯的“回避话题”。
3. 状态更新：压力值+3（升至5），情绪变为“紧张”。
4. 行为变化：语言风格配置中的“撒谎特征”被激活——他开始摸胡子，语句变短。
5. 玩家A如果继续施压，压力升至8，情绪变为“恐惧”，王伯可能会做出违背其“保护小姐秘密”目标的冲动行为——比如失口说出一个关键信息，或者以身体不适为由仓皇逃离。

### 🧬 完整决策流程：人格数据库如何驱动行为

让我们通过一个完整流程，展示人格数据库的各个组件如何协同工作：

```
[事件触发] 
→ 法海告诉许仙：“你娘子是蛇妖。”

[许仙的决策流程]

1. 接收信息，进行信任值判断
   → 对法海的信任值：6（有一定信赖，因是得道高僧）
   → 对白素贞的信任值：9（深爱且信赖）
   → 初步判断：倾向于不信法海

2. 但法海提供了“证据”（逻辑过滤器介入）
   → 系统检查“事实数据库”：法海说的雄黄酒事件确有记录
   → 许仙的逻辑判断：理性维度(4)，无法完全否定法海

3. 恐惧层级介入
   → 第一恐惧：“看到白素贞真身”被触发
   → 第二恐惧：“失去白素贞”同样被触发
   → 两股恐惧形成强烈对冲

4. 人格特质驱动行为
   → 胆量(3)：不敢直面真相，也不敢当面质问白素贞
   → 心机(5)：选择旁敲侧击
   → 社交(6)：他会找人倾诉

5. 生成具体行为
   → 许仙找到药铺的老郎中（他信任的中立角色）
   → 以“最近娘子身体不适，想开些安神药”为由套话
   → 对话中，他的压力值+2（因为第一次对妻子撒谎）
   → 语言风格变化：语句变短，不时走神

[AI导演记录]
→ 许仙压力值更新：2→5
→ 情绪标签更新：困惑+不安
→ 对白素贞怀疑值更新：0→2
→ 这个状态变化被记录，可能触发后续剧情
```

### 💎 这套人格数据库的意义

现在我们看到的，不再是一个简单的角色设定，而是一个**有内在逻辑的虚拟人格**。这套数据结构化的人格系统，不仅能让AI驱动出逼真的行为，还天然支持我们之前讨论的整个生态构想：

- **创作者友好**：剧本创作者通过配置这些数据表，就能创造出性格迥异的角色，无需编写复杂的AI代码。
- **可复用与可交易**：一个精心设计的“老管家王伯”人格包，可以被其他创作者引用到完全不同的剧本中。
- **动态叙事涌现**：智能体的行为不是预设的，而是在人格、局势、他人行为的互动中实时生成的。这意味着每一个游戏实例都是独一无二的，这正是你想要的“无限体验”的基石。
