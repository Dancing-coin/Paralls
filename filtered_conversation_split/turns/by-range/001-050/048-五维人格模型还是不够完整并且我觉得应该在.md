## 一、五维人格的不足与扩展

我们之前的五维模型（胆量、心机、共情、理性、社交）主要描述的是**行为倾向**——在面对情境时倾向于如何反应。但它缺少对**行为动机的深层解释**：为什么这个角色会这样？

我们需要向下扩展，构建一个更完整的心智模型。

| 层级 | 内容 | 作用 |
| :--- | :--- | :--- |
| **行为层** | 五维人格参数（胆量/心机/共情/理性/社交） | 决定“怎么做” |
| **品格层** | 道德取向、价值优先级、自我认知 | 决定“什么能做，什么不能做” |
| **根基层** | 人生记忆（关键事件、创伤、成就、关系） | 解释“为什么会变成这样” |

---

## 二、品格层：道德取向与价值优先级

品格层为角色划定行为的“红线”和“最高追求”，是比五维人格更底层的约束。

### 1. 道德取向维度

| 维度 | 低分端 | 高分端 |
| :--- | :--- | :--- |
| **诚实** | 谎言是本能，毫无心理负担 | 撒谎会带来强烈的自我谴责 |
| **忠诚** | 随时可以背叛任何人 | 一旦承诺，死也要做到 |
| **正义感** | 只在乎自己的利益 | 对不公义的行为无法坐视 |
| **仁慈** | 对弱者毫无怜悯 | 不忍伤害无辜，哪怕自身难保 |
| **责任感** | 遇事先推脱逃避 | 是自己的责任，无论如何都要扛 |

这些维度为角色提供了**道德底线**。一个正义感极高但诚实度低的角色，可能会为了“匡扶正义”而撒谎陷害坏人。一个忠诚度极高但仁慈度低的角色，会为了守护主人而毫不犹豫地伤害无辜。

### 2. 价值优先级

当不同道德取向发生冲突时，角色如何选择？这由价值优先级决定。

| 优先级 | 价值取向 | 例子 |
| :--- | :--- | :--- |
| 1 | 忠诚 | 法海：对佛法的忠诚高于一切，哪怕违背仁慈 |
| 2 | 正义感 | 福尔摩斯：真相高于一切，哪怕伤害委托人的感情 |
| 3 | 自我保全 | 老管家：活下去是第一位的，其他都可以妥协 |
| 1 | 亲情/爱情 | 白素贞：许仙的安全高于天道规矩，高于自身安危 |
| 2 | 自由 | 小青：不被束缚高于安稳生活 |

价值优先级解释了角色在道德困境中的选择。它不是固定的，极端情况下可能被颠覆（比如巨大的恐惧打破了原有的优先级）。

### 3. 自我认知

| 维度 | 内容 |
| :--- | :--- |
| **自我评价** | 角色如何看待自己（“我是一个正直的人” vs “我本性卑劣”） |
| **理想自我** | 角色想成为什么样的人（可能与现实自我有差距） |
| **核心创伤** | 角色内心深处最脆弱、最容易被触痛的点 |
| **执念** | 角色无法放下的执念（可能是目标层级中的最高目标） |

## 三、根基层：人生记忆与“基因种子”

品格层回答“角色是什么样的人”，而人生记忆回答“他为什么是这样的人”。

### 1. 什么是人生记忆

人生记忆是角色**在游戏开本之前**所经历的所有关键事件。它不是一份事件列表，而是**塑造了角色性格、品格、三观的因果链**。

| 记忆要素 | 说明 | 例子 |
| :--- | :--- | :--- |
| **关键事件** | 改变角色人生轨迹的事件 | 父母双亡、被恩人救起、第一次杀人、被背叛 |
| **长期状态** | 持续多年的生活环境 | 在贫困中长大、被严格的家规束缚、在江湖漂泊 |
| **关键人物** | 对角色影响深远的人 | 严厉的父亲、温柔的姐姐、背叛自己的挚友 |
| **重大选择** | 角色自己做出的、定义自身的决定 | 选择报恩、选择隐瞒、选择复仇 |
| **创伤** | 留下心理阴影的事件 | 亲眼目睹亲人被杀、被长期欺骗 |

### 2. 用“基因种子”模拟人生，生成人生记忆

你说得对，为了让每个角色都有真实可追溯的成长经历，我们不应该让剧本创作者手写所有人生记忆，而是用一个**基因种子**来自动生成。

**基因种子的构成：**

| 基因要素 | 说明 | 例子 |
| :--- | :--- | :--- |
| **出身** | 家庭背景、社会阶层 | 官宦世家、贫苦农户、孤儿 |
| **天赋** | 与生俱来的能力倾向 | 过目不忘、体弱多病、天生神力 |
| **早年关键事件** | 1-3个定义童年的重大事件 | 5岁时父母双亡、10岁时被师父收养 |
| **时代/地域** | 出生和成长的时代与地点 | 南宋临安、维多利亚时代的伦敦东区 |

**模拟人生生成流程：**

```
[基因种子] 
  → [童年生成] 基于出身+天赋+早年事件，生成0-12岁的成长经历
  → [少年生成] 基于童年输出+时代背景，生成13-18岁的经历和首次重大选择
  → [成年生成] 基于少年输出+天赋，生成成年后的职业、人际关系、关键事件
  → [人格映射] 基于完整的人生经历，推导出角色的品格层参数
  → [行为层映射] 基于品格层，推导出角色的五维人格参数
  → [秘密与目标生成] 基于以上，生成角色的核心秘密、目标层级和恐惧层级
```

**为什么是单向推导：人生经历 → 人格**

这是关键的设计原则。我们不是先决定“这个角色胆量7”，然后随便编一些经历来凑。而是先生成人生经历，再从经历中自然推导出性格。

- 一个在街头靠偷窃活下来的孤儿，自然会生成高胆量、低信任、高心机的参数
- 一个被严密保护在深闺中的小姐，自然会生成低胆量、高共情、低心机的参数

这让每个角色的人生与性格之间的因果关系真实可追溯。

### 3. 剧本创作者的角色

引入基因种子系统后，剧本创作者的工作从“手写一切”变为**“设定种子+审核结果”**。

| 创作者操作 | 说明 |
| :--- | :--- |
| **设定基因种子** | 为每个角色设定出身、天赋、早年关键事件（也可以选择“随机生成”） |
| **模拟人生** | 系统自动运行人生模拟，生成完整的人生记忆和人格参数 |
| **审核与微调** | 创作者查看生成结果，可以微调某些关键事件或人格参数，但修改会被记录为“手动覆写” |
| **多次生成选取** | 创作者可以多次运行模拟，从多个版本中选择最满意的 |

## 四、完整的心智模型架构

结合之前的设计，现在一个Paralls智能体的完整心智模型为：

```
                ┌──────────────┐
                │   基因种子    │  出身、天赋、早年事件
                └──────┬───────┘
                       ↓
                ┌──────────────┐
                │   人生记忆    │  关键事件、长期状态、创伤、重大选择
                └──────┬───────┘
                       ↓
                ┌──────────────┐
                │   品格层      │  道德取向、价值优先级、自我认知
                └──────┬───────┘
                       ↓
                ┌──────────────┐
                │   行为层      │  五维人格参数（胆量/心机/共情/理性/社交）
                └──────┬───────┘
                       ↓
                ┌──────────────┐
                │   决策系统    │  四层心智模型（感知→理解→规划→执行）
                │              │  受以上所有层级约束
                └──────┬───────┘
                       ↓
                ┌──────────────┐
                │   记忆系统    │  开本后实时更新的记忆库
                │              │  包含公共/共有/高阶知识
                └──────────────┘
```

**运行时的数据流：**

- **开本前**：基因种子 → 人生记忆 → 品格层 → 行为层。这是一次性生成的，在剧本创作阶段完成。
- **开本后**：行为层 + 品格层 + 人生记忆中的相关记忆 → 共同作为决策系统的约束条件。同时，开本后的实时经历写入记忆系统。

**品格层的运行时作用：**

在决策系统的L3规划层，品格层提供了比五维人格更强的约束：

| 决策步骤 | 品格层的介入 |
| :--- | :--- |
| **生成候选行动** | 过滤掉违反核心道德取向的行动（如正义感极高者不会考虑陷害无辜） |
| **价值冲突解决** | 当多个行动方案对应不同的价值取向时，按价值优先级排序 |
| **自我辩护** | 如果角色的行动背离了自己的道德取向（如诚实者被迫撒谎），角色会产生内部压力，影响后续的情绪状态和言行 |

## 五、总结

Paralls的智能体不再是由几个数字定义的“行为倾向集合”，而是一个**拥有完整的成长历史、内在道德准则和复杂三观**的虚拟人格。

- **基因种子**是起点，决定了角色的出身和天赋
- **人生记忆**是因果链，记录了性格是如何一步步形成的
- **品格层**是道德罗盘，划定了行为的红线与追求
- **行为层**是外在表现，受以上所有层的约束

剧本创作者不再需要手写复杂的人格参数，而是通过设定基因种子和审核模拟结果，来“培育”出有血有肉的角色。而每一个角色的人生记忆，也成为游戏体验的一部分——玩家在与智能体深入对话时，可能会触碰到这些记忆碎片，从而真正理解一个角色的内心。

这才是让Paralls的每个平行世界都“有人味”的基础。
