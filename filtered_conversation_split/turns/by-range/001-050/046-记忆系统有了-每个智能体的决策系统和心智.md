## 智能体决策系统与心智模型

### 一、心智模型架构

每个智能体的心智由四个相互关联的层级构成，每一层处理不同抽象程度的信息。

| 层级 | 名称 | 职责 | 输入 | 输出 |
| :--- | :--- | :--- | :--- | :--- |
| **L1** | 感知层 | 接收并过滤外界刺激 | 环境事件、他人言行、自身状态变化 | 结构化感知数据 |
| **L2** | 理解层 | 解读感知数据的含义，更新信念 | L1输出 + 现有记忆库 | 更新的信念、新推论、新怀疑 |
| **L3** | 规划层 | 基于当前信念和目标，生成行动方案 | L2输出 + 人格参数 + 目标层级 | 候选行动方案（带优先级） |
| **L4** | 执行层 | 选择最优方案，生成具体行为 | L3输出 + 行为模板库 + 语言风格配置 | 具体对话/动作/移动指令 |

---

### 二、L1：感知层

感知层是智能体与游戏世界交互的入口。它决定了智能体能“知道”什么。

**感知输入类型：**

| 输入类型 | 示例 | 是否必然被感知 |
| :--- | :--- | :--- |
| **公开对话** | 清晰区内有人大声说：“凶器是烛台！” | 是，清晰区内所有智能体强制接收 |
| **模糊对话** | 10米外有人在低声交谈，只听到“遗嘱”和“那天晚上” | 是，但内容标记为“模糊” |
| **公开展示物品** | 有人举起一把带血的匕首 | 是，视野内所有智能体强制接收 |
| **直接互动** | 玩家点击智能体，选择“交谈”或“出示物品” | 是 |
| **物理行为** | 看到某人进入书房，或有人从背后靠近 | 是，视野内检测到的人物移动 |
| **环境变化** | 灯光熄灭，窗外闪过黑影 | 是，场景内公共事件 |
| **叙事导演的“冲动”** | 导演发送“你突然想去地下室看看” | 内部感知，仅该智能体收到 |

**感知过滤机制：**
- 不在场者不能感知
- 当前压力值极高时，可能忽略次要感知（如没注意到远处有人在偷看）
- 共情值高的智能体会更关注他人的情绪状态变化

---

### 三、L2：理解层

理解层将感知数据转化为有意义的信念，并更新记忆库。

**核心处理流程：**

```
[感知数据] → [与现有记忆比对] → [更新信念] → [生成推论] → [更新记忆库]
```

**具体处理模块：**

| 处理步骤 | 说明 | 例子 |
| :--- | :--- | :--- |
| **真实性评估** | 判断感知信息是真实的还是他人撒谎/伪装 | 老管家说他昨晚8点在花园→女仆的记忆中8点花园无人→标记为“可疑” |
| **相关性评估** | 这条信息与我的目标/秘密/恐惧相关吗 | 福尔摩斯听到“遗嘱”→高度相关；听到“天气”→低相关 |
| **信念更新** | 将确认信息写入知识记忆，更新相关角色的怀疑值/信任值 | 确认玛丽说谎→对玛丽怀疑值+3 |
| **推论生成** | 基于已有知识进行推理，生成新信念 | 已知“凶手身高低于170cm”+“玛丽是唯一低于170的”→推论“玛丽很可能是凶手” |
| **不确定态管理** | 对无法确认的信息标记为“疑似”，保持模糊 | 听到远处低语中提到“遗产”→标记为“疑似听到关于遗产的讨论” |

**推论的可信度分级：**

| 等级 | 说明 | 对决策的影响 |
| :--- | :--- | :--- |
| **确认** | 有确凿证据支撑 | 可以作为行动的唯一依据 |
| **高度怀疑** | 多条线索指向同一结论，但无直接证据 | 可以作为行动的参考，但不会孤注一掷 |
| **猜测** | 直觉或单一线索指向某个方向 | 只能作为试探性对话的方向 |
| **弱信号** | 仅有微弱的异常感 | 不会主动行动，但会提高对该对象的警惕 |

---

### 四、L3：规划层

规划层是心智模型的核心。它基于当前的信念状态和人格参数，生成行动方案。

**行动动机来源：**

| 动机来源 | 优先级 | 说明 |
| :--- | :--- | :--- |
| **恐惧驱动** | 最高 | 当恐惧层级中的某一项被触发时，采取避险行动（逃跑、销毁证据、说谎） |
| **目标驱动** | 高 | 为达成目标层级中的目标而主动行动（调查、结盟、试探） |
| **社交驱动** | 中 | 基于信任/怀疑值，维护或改善与他人的关系 |
| **好奇驱动** | 低 | 对新信息的探索欲，可在无明确任务时保持活跃 |

**行动方案生成流程：**

```
[当前信念状态] → [识别需要解决的关键问题] → [生成候选行动方案] → [人格过滤] → [优先级排序]
```

**候选行动类型：**

| 行动类别 | 具体行为 | 触发条件 |
| :--- | :--- | :--- |
| **信息收集** | 去某处调查、跟踪某人、询问某人 | 目标驱动或好奇驱动 |
| **信息共享** | 主动找人透露信息、公开展示证据 | 社交驱动（信任值高）或目标驱动（需要结盟） |
| **信息隐藏** | 撒谎、销毁证据、转移怀疑 | 恐惧驱动（保护秘密） |
| **社交操控** | 试探、离间、安抚、威胁 | 社交驱动（改变他人对自己的看法） |
| **被动等待** | 留在原地观察，不主动行动 | 胆量低/压力值高，或等待时机 |
| **应急反应** | 逃跑、呼救、反击 | 突发威胁触发 |

**人格过滤器在规划层的应用：**

| 人格维度 | 对规划的影响 |
| :--- | :--- |
| **胆量** | 低胆量：优先选择“被动等待”或“信息隐藏”；高胆量：优先选择“主动调查”或“公开对峙” |
| **心机** | 低心机：倾向于“直接询问”；高心机：倾向于“旁敲侧击”或“设局试探” |
| **共情** | 低共情：可能牺牲他人来保护自己；高共情：在行动中会考虑对他人情感的影响 |
| **理性** | 低理性：情绪化决策，容易冲动；高理性：冷血计算收益/风险比 |
| **社交** | 低社交：倾向于独自调查；高社交：倾向于找人合作或私下交流 |

---

### 五、L4：执行层

执行层将选定的行动方案转化为具体的行为输出。

**行为输出类型：**

| 输出类型 | 内容 | 对其他系统的影响 |
| :--- | :--- | :--- |
| **对话输出** | 文本内容 + 情绪参数 + 说话音量（公开/耳语） | 触发L2层感知更新、知识图谱更新 |
| **动作输出** | 移动目标点、物品交互指令、肢体动作标签 | 触发L1层环境事件、可能被其他智能体观察到 |
| **状态更新** | 内部情绪标签变化、压力值变化 | 影响下一轮决策 |

**执行层的行为约束：**

- **逻辑过滤器**：当前时间/空间/信息条件下，该行为是否可能
- **一致性检查**：该行为与智能体此前言行是否矛盾（若矛盾，需要给出“圆谎”的解释）
- **叙事导演审核**：该行为是否会导致信息泄露或破坏游戏平衡

### 六、完整决策周期

```
┌─────────────────────────────────────────┐
│                 决策周期                 │
│                                          │
│  [外部刺激/定时触发]                     │
│       ↓                                  │
│  L1 感知层：接收并过滤                   │
│       ↓                                  │
│  L2 理解层：解读、推理、更新信念         │
│       ↓                                  │
│  L3 规划层：基于信念+人格，生成行动方案  │
│       ↓                                  │
│  L4 执行层：输出对话/动作/状态           │
│       ↓                                  │
│  [影响世界，触发新的感知] → 循环         │
└─────────────────────────────────────────┘
```

**决策频率：**
- **被动响应**：收到外部刺激后立即启动决策周期（目标延迟1-3秒）
- **主动行动**：每30-60秒自动评估是否应主动发起行动（如移动、找某人对话）
- **应急反应**：突发威胁（如有人靠近正在销毁证据的自己），立即打断当前计划，紧急决策

### 七、与叙事导演智能体的协作

角色智能体拥有完整的自主决策权。叙事导演只能通过以下方式间接影响：

| 导演手段 | 对心智模型的影响点 | 角色智能体的自主权 |
| :--- | :--- | :--- |
| **发送“冲动”** | 注入到L1感知层，作为内部感知 | 角色在L3规划层决定是否响应此冲动 |
| **环境催化** | 改变L1的感知输入（如制造异响） | 角色自主决定如何解读和响应 |
| **NPC信息告知** | 直接注入到L2理解层，作为“已知事实” | 角色在L3规划层决定如何利用此信息 |

**核心原则：导演催化，角色决定。** 叙事导演不能跳过角色的心智模型直接控制行为。

---

### 八、总结：Paralls的智能体心智系统

| 层级 | 核心功能 | 关键数据结构 |
| :--- | :--- | :--- |
| **L1 感知层** | 接收世界刺激，过滤噪音 | 感知事件列表（含来源、类型、可信度） |
| **L2 理解层** | 解读信息，生成推论，更新信念 | 信念库（含可信度）、推论链、怀疑/信任值 |
| **L3 规划层** | 基于信念和人格生成行动方案 | 候选行动列表（含动机来源和优先级） |
| **L4 执行层** | 输出具体对话/动作/状态 | 对话文本+情绪参数+动作指令+内部状态更新 |

这个心智模型配合我们之前设计的**记忆系统**和**人格数据库**，共同构成了Paralls智能体的完整“灵魂”。每个智能体都拥有：
- **不变的**：人格参数、背景秘密、目标与恐惧层级（剧本定义）
- **变化的**：记忆库、信念状态、情绪状态、社交关系（实时更新）
- **自主的**：基于上述一切，自主决定何时、如何行动

正是这些独立而互动的智能体，让每一局Paralls都成为一个无法复制的平行世界。
