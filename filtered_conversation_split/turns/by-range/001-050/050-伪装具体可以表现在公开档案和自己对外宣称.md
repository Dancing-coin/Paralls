## DeepSeek

明白了。你说的伪装，不是在讨论玩家或智能体“扮演角色”这件事，而是**角色本身在游戏世界里的伪装**。

开本后，所有参与者——无论真人还是AI——都默认成为了他们所选择的角色。他们拿到了一份“公开档案”，这份档案告诉他们“你应该对外宣称你是谁”。但这份档案可能本身就是角色精心构建的伪装。

---

## 一、公开档案：角色对外宣称的身份

每个角色在开本时，系统会向该角色的扮演者（无论玩家还是智能体）提供一份**公开档案**。这是该角色选择对外展示的身份信息。

### 公开档案包含的内容

| 信息项 | 说明 | 是否可被其他角色查阅 |
| :--- | :--- | :--- |
| **姓名** | 角色使用的名字（可能是化名） | 是，所有人可见 |
| **身份/职业** | 对外宣称的社会身份 | 是 |
| **公开背景** | 一段简短的自述经历 | 是，在自我介绍阶段可公开 |
| **与死者的关系** | 对外宣称的与死者的关系 | 是 |
| **案发时的行踪** | 对外宣称的不在场证明 | 是，在询问阶段可陈述 |

### 公开档案的两种形态

| 类型 | 说明 | 例子 |
| :--- | :--- | :--- |
| **真实公开档案** | 角色没有隐藏身份，公开档案就是真实档案 | 福尔摩斯：身份就是侦探，背景真实 |
| **伪装公开档案** | 角色隐藏了真实身份，公开档案是精心构建的假身份 | 艾琳·艾德勒：公开身份是“来自美国的寡妇”，真实身份是“受雇调查此案的私家侦探” |

---

## 二、伪装的具体表现：公开档案与真实档案的差异

伪装不是一个简单的“是否在说谎”的二元判断，而是体现在**公开档案与真实档案之间的结构化差异**上。

### 1. 身份伪装

| 要素 | 公开档案 | 真实档案 |
| :--- | :--- | :--- |
| **姓名** | 化名或假名 | 真名 |
| **职业** | 伪装的职业（如“钢琴教师”） | 真实职业（如“间谍”） |
| **社会阶层** | 伪装的阶层 | 真实出身 |

### 2. 背景经历伪装

| 要素 | 公开档案 | 真实档案 |
| :--- | :--- | :--- |
| **成长经历** | 编造的童年和少年经历 | 真实的人生记忆 |
| **过往事件** | 编造的关键事件 | 真实经历的关键事件 |
| **人际关系** | 虚假的或夸大的与某些人物的关系 | 真实的忠诚和恩怨 |

### 3. 不在场证明伪装

| 要素 | 公开档案 | 真实档案 |
| :--- | :--- | :--- |
| **案发时位置** | 声称在某处，有证人 | 实际在另一处，或无人可证 |
| **案发时行为** | 声称在做某事 | 实际在做另一件事（可能与案件有关） |
| **目击者** | 声称有人可以作证 | 该证人可能被收买、被误导，或根本不存在 |

### 4. 动机伪装

| 要素 | 公开档案 | 真实档案 |
| :--- | :--- | :--- |
| **与死者的关系** | 声称的关系（如“生意伙伴”） | 真实的关系（如“被死者勒索的受害者”） |
| **对案件的立场** | 声称“希望找出真凶” | 实际可能“希望真凶永远不被发现”（因为自己就是真凶，或因为真凶是自己在保护的人） |

## 三、伪装的构建：从人格档案到公开档案

伪装不是随机生成的。每个角色对外宣称的假身份和假信息，都必须从其人格档案中**自然推导**出来。

### 1. 伪装构建的约束条件

| 约束条件 | 说明 |
| :--- | :--- |
| **能力约束** | 角色的心机值、逻辑编织力、情绪控制力决定了伪装的复杂度和可信度。低心机者只能做简单伪装（如只隐瞒姓名），高心机者可以构建完整的假身份 |
| **动机约束** | 伪装的目的必须与角色的目标层级一致。伪装是为了保护秘密、实现目标、还是保护他人？ |
| **经验约束** | 角色的人生记忆中是否有过伪装经验？从未伪装过的角色，其伪装更容易出破绽 |
| **资源约束** | 伪装身份需要相应的物质支撑（假证件、被收买的证人）。剧本可配置资源限制 |

### 2. 伪装深度等级

不同角色根据自身能力和需求，伪装深度不同。

| 深度等级 | 描述 | 典型角色 |
| :--- | :--- | :--- |
| **零伪装** | 公开档案完全真实，无需隐瞒任何事 | 福尔摩斯（不涉案的侦探）、华生（诚实医生） |
| **浅层伪装** | 仅隐瞒一两项关键信息，其余真实 | 老管家（隐瞒案发时曾进入书房，其余背景真实） |
| **中度伪装** | 身份真实，但案发时的不在场证明是伪造的 | 玛丽·萨瑟兰（身份是真实遗孀，但撒谎说案发时在教堂） |
| **深度伪装** | 整个身份都是伪造的 | 艾琳·艾德勒（名字、职业、背景、与死者的关系全部伪造） |

## 四、伪装的洞察：其他角色如何识破

### 1. 公开档案与观察行为的比对

其他角色可以通过比对某人的**公开档案**与**实际观察到的行为**来发现伪装。

| 观察发现 | 伪装破绽 |
| :--- | :--- |
| 某人声称“案发时在花园”，但有人看到他从书房出来 | 不在场证明矛盾 |
| 某人声称是“钢琴教师”，但对钢琴一窍不通 | 职业伪装暴露 |
| 某人声称“与死者初识”，但在对话中说漏了死者的旧事 | 关系伪装暴露 |
| 某人的用词或举止与其声称的社会阶层不符 | 身份伪装暴露 |

### 2. 证据揭露

角色获得的线索和证据可以直接推翻伪装。

| 证据类型 | 揭露内容 |
| :--- | :--- |
| **物证** | 死者的日记中记录了“艾琳·艾德勒”的真实身份和目的 |
| **人证** | 另一个角色声称在案发时间，看到对方从死者房间出来 |
| **矛盾证词** | 两个角色的不在场证明相互矛盾，必有一方在撒谎 |

### 3. 伪装压力导致的破绽

如我们之前讨论，伪装不是无代价的。随着压力积累，伪装者的行为会出现偏离，这些偏离成为洞察的线索。

## 五、在剧本编辑器中的配置

剧本创作者需要为每个角色配置以下与伪装相关的内容：

| 配置项 | 说明 |
| :--- | :--- |
| **真实档案** | 角色的全部真实信息（由基因种子模拟生成，创作者审核） |
| **伪装深度** | 选择：零/浅层/中度/深度伪装 |
| **公开档案** | 角色对外宣称的身份信息。若伪装深度为零，则等于真实档案；若大于零，创作者需手动填写伪装内容，或由系统根据真实档案自动生成 |
| **伪装支撑** | 角色为维持伪装所拥有的资源（如收买证人的能力、伪造的文件、对应的技能） |
| **伪装破绽预设** | 创作者可预设1-2个“天然破绽”，作为线索池的一部分，供玩家推理发现 |

**系统自动生成公开档案（可选）**：当创作者选择“自动生成伪装”时，系统基于真实档案和角色的心机/逻辑编织力参数，自动生成一套合理性和漏洞匹配的伪装档案。

## 六、总结

在Paralls中，伪装不是角色说了什么谎，而是**角色在游戏世界中构建了一个与真实身份平行的虚拟身份**。这个虚拟身份通过公开档案呈现给所有参与者，成为游戏的初始设定。

- **伪装的基础**：角色的基因种子、人生记忆、品格层和人格参数
- **伪装的载体**：公开档案（身份、背景、不在场证明、动机）
- **伪装的深度**：从零到深度，取决于角色的能力和需求
- **伪装的洞察**：通过行为比对、证据揭露和压力破绽来实现

开本时，所有参与者拿到的是各自角色的公开档案。而真实档案只有该角色的扮演者自己知道（如果是智能体，则智能体内部维护真实档案）。这个信息差，正是Paralls平行世界中博弈的基础。
