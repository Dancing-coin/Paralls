## 用户

玩家和智能体都可以选择是否共享信息，对谁分享信息，要么对话来共享，要么带别人去看证据，要么把证据拍下来给别人看。(当然，这就需要有留影石或者照相机录像机的设定了，前者用于没有照相机录像机的年代背景）

## DeepSeek

你说得对，信息共享必须是玩家和智能体的**主动选择**，而不是系统自动广播。这是社交推理游戏的核心乐趣之一——**信息是一种资源，分享信息是一种策略。**

---

### 📨 信息共享机制设计

#### 核心原则

1. **所有信息默认为私有**：玩家发现的线索、智能体知道的秘密，默认只有自己知道
2. **共享是主动行为**：必须通过游戏内可验证的方式，主动选择分享
3. **分享有风险**：分享信息可能暴露自己的身份、意图、位置
4. **可拒绝分享**：智能体可以基于人设拒绝分享，玩家也可以选择隐瞒

---

#### 五种信息共享方式

| 方式 | 操作 | 共享范围 | 限制 |
| :--- | :--- | :--- | :--- |
| **公开对话** | 在空间音频清晰区内说话 | 清晰区内的所有角色 | 可能被模糊区的人偷听到关键词 |
| **私密对话** | 使用耳语模式 | 1米内的指定对象 | 靠近者可偷听，屏幕上会提示“有人靠近” |
| **展示物品** | 手持物品并点击“展示” | 视野内所有角色 | 别人能看到物品外观，但系统不会自动广播物品详情 |
| **带人查看** | 邀请他人跟随自己到某处，指认现场证据 | 跟随者 | 需要物理移动到证据位置 |
| **留影/拍摄** | 使用留影石或相机对目标拍照/录像 | 可交给任何人查看 | 拍摄行为本身可能被目击；留影石有使用次数限制 |

---

#### 留影石 / 相机的设定

| 要素 | 留影石 | 照相机 / 录像机 |
| :--- | :--- | :--- |
| **适用时代** | 古代、仙侠、奇幻背景 | 近代、现代背景 |
| **外观** | 一块发光的灵石，注入法力可记录眼前景象 | 老式相机、拍立得、手机等 |
| **记录方式** | 触碰激活，3秒后记录当前视野内的静态画面 | 快门/录制键，可拍单张或短片 |
| **产出物** | 一张发光的幻象卡片，可交给他人查看 | 一张照片/一段视频文件，可交给他人查看 |
| **使用次数** | 每颗留影石可用1-3次（剧本可配置） | 相机不限次数，但胶卷/存储有限 |
| **可否伪造** | 高阶修士可伪造留影石内容（增加变数） | 暗房技术可伪造照片（增加变数） |
| **可否被破坏** | 可被击碎，内容永久丢失 | 可被销毁、删除 |

**游戏性意义：**
- 留影石/相机是**有限资源**，玩家需要决定何时使用
- 拍摄行为可能**被目击**，暴露自己的调查方向
- 伪造可能性为游戏增加了**欺骗与反欺骗**的博弈层

### 🎬 完整示例：信息如何流转

**情境：** 《血字的研究·变奏》。玩家A（亨利·贝克）在旅馆房间独自探索时，在床底发现了一封烧毁一半的信件。

| 时间 | 行为 | 信息状态 |
| :--- | :--- | :--- |
| **T+0s** | 玩家A在床底发现信件 | 仅玩家A知道信件内容。L3触发：信件特写图浮现在玩家A屏幕上 |
| **T+10s** | 玩家A决定保留信息，暂不公开 | 信息仍在玩家A手中 |
| **T+30s** | 玩家A找到玩家B（艾琳），使用耳语模式：“我找到了一封信，你跟我来。” | 周围其他人只看到两人窃窃私语，但不知道内容 |
| **T+45s** | 玩家A带玩家B到旅馆房间，点击“展示”物品 | 玩家B看到了信件外观和内容。现在两人都知道了 |
| **T+60s** | 玩家B建议拍下来留证。玩家A使用留影石，对信件拍摄 | 留影石次数-1。产出幻象卡片一张 |
| **T+75s** | 福尔摩斯（AI智能体）走进房间，看到两人围在床边 | 福尔摩斯触发好奇心。他走了过来 |
| **T+80s** | 玩家A选择不告诉福尔摩斯，收起信件和留影石 | 福尔摩斯知道两人在隐藏什么，但不知道具体内容 |
| **T+85s** | 福尔摩斯（AI）的人设过滤器判定：心机5，社交6。他没有直接质问，而是说：“看来两位发现了有趣的东西。希望这能帮助我们找到真相。”然后离开 | 福尔摩斯开始用其他方式试探两位玩家 |
| **T+120s** | 投票阶段，玩家A公开出示留影石复制的信件幻象，指控玛丽 | 全员看到证据。玛丽（AI）的恐惧层级被触发 |

### 👥 智能体如何决定是否共享信息

智能体遵循我们之前设定的三道过滤器：

| 过滤器 | 判断逻辑 | 例子 |
| :--- | :--- | :--- |
| **人设过滤器** | 这个角色愿意分享吗？ | 老管家王伯性格谨慎（胆量3），不会主动分享主人的秘密 |
| **逻辑过滤器** | 这个角色知道这件事吗？ | 女仆没有进入过书房，不可能分享书房内的线索 |
| **得失过滤器** | 分享这件事对角色有利吗？ | 如果分享能洗清自己的嫌疑，智能体会主动分享；如果会引火烧身，则闭口不言 |

**智能体的信息共享策略示例：**

| 智能体 | 秘密 | 会主动分享吗？ | 在什么条件下会分享？ |
| :--- | :--- | :--- | :--- |
| 福尔摩斯 | 已破解血字“RACHE”的真正含义 | 不会直接说 | 当有玩家展示出足够的推理能力时，会以引导的方式暗示 |
| 华生 | 发现尸检报告有可疑之处 | 会主动找信任的人说 | 对信任值>7的对象，会私下透露 |
| 玛丽 | 自己是真凶 | 绝不 | 只有当铁证如山、无法辩驳时，才会崩溃认罪 |
| 老管家 | 知道老爷生前修改过遗嘱 | 不会主动说 | 被出示关键证据、或小姐的生命受到威胁时，才会透露 |

### 🎮 信息博弈的深度

这套机制让“信息”本身成为了可交易、可窃取、可伪造的核心资源：

| 玩法深度 | 说明 |
| :--- | :--- |
| **信息不对称** | 不同玩家掌握不同碎片信息，必须通过合作才能拼出全貌 |
| **选择性共享** | 分享什么、对谁分享、何时分享，都是策略决策 |
| **偷听与反偷听** | 空间音频的模糊区制造了信息泄露的风险，玩家需要警惕周围环境 |
| **留影石的策略使用** | 有限次数，何时拍摄、拍摄什么、给谁看，都需要精心规划 |
| **伪造与鉴定** | 技能/能力可引入“鉴定真伪”的玩法，为游戏增加新的博弈维度 |

---

### 💎 总结

信息共享的核心逻辑：**你看到的，只有你知道。你想让别人知道，就得主动去说、去展示、去带路。而每一次分享，都可能暴露你的意图，或让你获得盟友。**

这套机制确保了：
1. 信息获取本身是游戏性的一部分（探索、偷听、逼问）
2. 信息共享是策略性的（选择对象、时机、方式）
3. 智能体不是无脑的信息广播器，而是有保留、有算计的独立角色
4. 留影石/相机为信息留存提供了有限且有风险的途径
