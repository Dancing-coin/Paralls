### ⏳ 时间线锁定原则：三个时间节点

案件的事实不是“剧本写好就全锁死”的，而是沿着时间线逐步锁定。核心原则是：

**玩家加入前，一切只是“可能性”；玩家加入后，才坍缩为“事实”。**

| 时间节点 | 锁定内容 | 未锁定内容 |
| :--- | :--- | :--- |
| **T0：剧本创作完成** | 世界观、角色设定、场景、基础规则 | 具体的案件事实 |
| **T1：游戏房间创建** | 案件框架（死因类型、关键线索位置） | 凶手身份、作案细节 |
| **T2：玩家加入游戏** | 本案的全部事实（凶手、动机、作案过程） | 无 |
| **T3：游戏进行中** | 无新增锁定 | 叙事路径、结局走向 |

---

### 🎬 按时间线展开的完整流程

#### T0：剧本创作者的工作（创作阶段）

创作者提交的是一套**可能性框架**，而非一个确定的故事。

**《血字的研究》剧本包包含：**
- **角色池**：5个角色，每个都有完整的人格数据库、背景故事、秘密
- **场景**：贝克街客厅、旅馆房间
- **案件模板**：死因为钝器击杀，现场有伪造的血字
- **线索池**：20条可能的线索，分布在场景各处
- **作案条件**：
  - 凶手必须在案发时间没有不在场证明
  - 凶手的身高必须小于等于死者
  - 凶器必须能被凶手接触到
- **作案动机池**：财务纠纷、情杀、复仇、意外过失

此时，**谁都可以是凶手**。

---

#### T1：游戏房间创建（初始化阶段）

当“大玩家”创建一个《血字的研究》游戏房间时，系统会：

1. **随机抽取作案动机**：从动机池中随机选择 → 结果为“财务纠纷”
2. **随机抽取凶器**：从符合条件的物品中随机选择 → 结果为“烛台”
3. **随机抽取关键线索组合**：从线索池中抽取5条核心线索，其余线索随机分布

此时，案件框架已定，但**凶手尚未确定**。

---

#### T2：玩家加入，事实坍缩（锁定阶段）

这是最关键的时刻。当玩家选择角色并确认加入时，系统才会最终锁定全部事实。

**锁定逻辑：**

1. **玩家选择的角色首先被排除出嫌疑名单**（真人玩家不能是凶手，否则无法正常游戏）
2. **AI角色进入候选凶池**
3. **系统从候选凶池中，根据作案条件进行筛选**
4. **在所有符合条件的AI角色中，随机选择一位作为凶手**
5. **基于选定的凶手，生成完整的作案过程**

**实例：**

```
玩家A选择：亨利·贝克
玩家B选择：艾琳·艾德勒

→ 排除：亨利、艾琳（真人玩家）
→ 候选凶手池：福尔摩斯、华生、玛丽

→ 作案条件检查：
   - 福尔摩斯：案发时在苏格兰场查案（有不在场证明）→ 排除
   - 华生：身高182cm，死者170cm（不符合身高条件）→ 排除
   - 玛丽：身高162cm，没有不在场证明 → ✅ 符合

→ 凶手锁定：玛丽·萨瑟兰

→ 生成作案过程：
   - 动机：财务纠纷（T1已锁定）
   - 凶器：烛台（T1已锁定）
   - 过程：玛丽发现丈夫企图将她的传家宝卖给亨利，争执中失手用烛台击杀
   - 伪造：用血迹在墙上写下“RACHE”以转移视线
```

此时，**所有事实永久锁定**，写入事实数据库。AI智能体立即获得自己在本局的“角色真相”——玛丽知道自己是凶手，华生知道自己不是，福尔摩斯知道自己不是。

---

#### T3：游戏进行中（叙事涌现阶段）

从这一刻起，**事实不再改变，但叙事无限可能**。

- 福尔摩斯会根据线索引导推理方向
- 华生会根据自己的医学知识提供尸检信息
- 玛丽会根据人设（心机8, 共情7）决定自己的表演策略
- 两个真人玩家通过探索、对话、推理来接近真相

AI叙事导演监控全局，确保：
- 任何NPC都不会说出与事实矛盾的话
- 线索曝光节奏合理
- 游戏平衡性在可控范围内

### 🔄 另一局的平行世界

当下一组玩家创建新房间时：

```
玩家A选择：福尔摩斯
玩家B选择：玛丽·萨瑟兰

→ 排除：福尔摩斯、玛丽（真人玩家）
→ 候选凶手池：亨利、华生、艾琳

→ 作案条件检查：
   - 艾琳：案发时在伦敦另一端（有不在场证明）→ 排除
   - 亨利：身高175cm，符合条件，没有不在场证明 → 候选
   - 华生：身高182cm，不符合条件 → 排除

→ 凶手锁定：亨利·贝克

→ 全新作案过程：
   - 动机：财务纠纷
   - 凶器：烛台
   - 过程：亨利投资失败，急需死者还债，争执中动手
   - 伪造：清理现场，伪装成入室抢劫
```

**同一个剧本，完全不同的事实基础，完全不同的游戏体验。**

---

### 💎 这个设计解决了什么

| 问题 | 解决方案 |
| :--- | :--- |
| 玩家玩过一次就知道凶手了 | 每次凶手都可能不同，重玩价值极高 |
| 剧本创作者需要为每个剧本设计固定凶手 | 只需设计角色、场景和作案条件，系统自动生成 |
| AI智能体在游戏开始前就知道了结局 | AI角色在T2之后才获得本局的“真相”，避免泄露 |
| 大玩家如何自定义剧本 | 他们可以在T0阶段调整作案条件、动机池、线索池 |

这正是你所说的：**“玩家加入后才会开启无限的体验”**。
