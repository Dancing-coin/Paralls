## 一、参与者记忆模型：一个持续更新的私人档案

每个参与者（玩家角色或智能体）维护自己的**个人记忆库**，其中包含：

| 记忆类别 | 内容 | 更新方式 |
| :--- | :--- | :--- |
| **身份记忆** | 我是谁、我的背景、我的秘密、我的人格参数 | 开局时从剧本加载，基本固定（仅情绪状态可动态变化） |
| **事件记忆** | 我亲身经历的所有事件（时间戳+地点+事件描述+涉及人物） | 实时添加，永不删除 |
| **观察记忆** | 我看到/听到的他人言行（谁在何时何地做了什么/说了什么） | 实时添加 |
| **知识记忆** | 我获得的线索、证据、情报（包含知识状态：疑似/确认） | 实时添加，可升级（从“疑似”到“确认”） |
| **社交记忆** | 我对其他每个参与者的信任值、怀疑值、好感度 | 根据互动实时更新 |
| **高阶记忆** | 关于“他人知道什么”的推理（二阶、三阶知识） | 基于观察和推理实时更新 |

## 二、三种知识的动态管理

### 1. 公共知识
**定义**：所有在场者都知道，并且所有人都知道所有人知道。

**形成条件**：在清晰区公开对话、公开展示物品、公共事件发生。

**记忆更新**：事件发生时，系统自动将该知识写入所有在场参与者的记忆库，并标记为“公共知识”。同时，叙事导演的高阶知识图谱会记录：所有在场者都知道此知识，且都知道彼此知道。

### 2. 共有知识
**定义**：多个参与者私下共享了某个信息，但其他人不知道他们共享了。

**形成条件**：耳语、私密展示、带人查看、留影石传递。

**记忆更新**：
- 共享双方的记忆库中，该知识标记为“确认”，并记录“与XX共享”。
- 系统不更新其他参与者的记忆。
- 叙事导演记录此共享关系，但不广播。

### 3. 高阶知识
**定义**：A知道（或不确定）B知道某事。

**形成条件**：A观察到B获取了某信息，或A听到B的对话涉及某信息。

**记忆更新**：
- A的记忆库中会添加一条高阶知识：“[时间]，我观察到B [行为]，因此B [知道/可能知道] X”。
- 如果是不确定状态，标记为“疑似”；如果B后来公开承认，升级为“确认”。
- 叙事导演维护一个全局的高阶知识图谱，供智能体决策时调用。

## 三、叙事导演的记忆管理职责

叙事导演智能体不直接拥有记忆，而是**管理所有参与者的记忆生态**，确保逻辑一致性和故事引导。

### 3.1 记忆一致性管理
- **冲突检测**：当两个参与者的记忆出现矛盾（如A说亲眼看到B在书房，B坚称自己在花园），导演标记为“待解决矛盾”，可作为推理线索。
- **信息泄露防护**：导演检查任何智能体生成对话前，确认其记忆库中是否有权说出该信息。若智能体记忆中没有“确认”或“疑似”的知识，绝不能无中生有。
- **遗忘模拟**（可选）：对于人类玩家，记忆可能模糊。导演可对“疑似”状态的知识，随着时间流逝降低其回忆清晰度（影响智能体在决策时对该信息的依赖度）。

### 3.2 高阶知识管理
- **实时更新**：每当一个参与者观察到另一个参与者获取信息，导演立即更新高阶知识图谱。
- **推理辅助**：智能体在进行决策时，导演会将其高阶知识注入决策上下文。例如，法海知道小青看到自己跟踪她，那么法海的决策会考虑到“小青对我有戒心”。
- **叙事触发**：当形成特定的高阶知识结构（如“真凶意识到侦探已经锁定自己”），导演可触发新事件（如凶手决定铤而走险）。

### 3.3 故事线引导（环境催化 / NPC引导 / 节奏控制）
基于记忆生态的全局状态，导演执行间接干预：

| 引导方式 | 触发条件 | 干预手段 |
| :--- | :--- | :--- |
| **环境催化** | 侦探方缺乏关键线索，讨论陷入僵局 | 导演让某个场景突然传出异响，吸引玩家去探索；或让天气变化，迫使角色聚集到某区域。 |
| **NPC引导** | 某个NPC拥有关键信息，但无合适时机说出 | 导演向NPC发送“冲动”：“你觉得现在可能是向XX坦白的时机了”。NPC的人设过滤器决定是否接受。 |
| **节奏控制** | 推理进度过快或过慢 | 过快时，引入次要事件分散注意力；过慢时，通过NPC对话暗示新方向，或让一个原本中立的物品突然被注意到。 |

**导演的干预永远不直接控制玩家或强行改变事实。** 它只利用环境和NPC的自主决策，来催化故事朝更有戏剧性的方向发展。

## 四、记忆的实时加载与更新流程

```
[事件发生]
    ↓
[事件类型判定]
  - 公共对话/展示 → 知识状态：公开
  - 私密交流 → 知识状态：对共享者“确认”，对他人不可见
  - 独自观察 → 知识状态：“疑似”或“确认”
    ↓
[参与者记忆更新]
  所有相关参与者的记忆库实时追加新条目
    ↓
[高阶知识图谱更新]
  叙事导演计算并更新所有受影响的高阶知识
    ↓
[智能体决策可用性]
  智能体下次决策时，将更新后的记忆库作为上下文注入
```

## 五、总结：Paralls的记忆系统

- **每个参与者**都有一个随游戏进程不断增长的私人记忆库，包含自己的经历、观察、知识和推理。
- **公共、共有、高阶**三种知识形态精确区分，系统严格管控可见性。
- **叙事导演**作为记忆生态的守护者，确保逻辑一致，防止信息泄露，并利用记忆状态引导故事走向。
- 最终，玩家体验到的是一场**信息不对称、记忆私有、推理分层**的深度博弈，每一局都因为记忆的不同而独一无二。
