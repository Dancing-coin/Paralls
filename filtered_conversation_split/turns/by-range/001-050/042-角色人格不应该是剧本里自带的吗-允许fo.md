# 《无限书海》官方产品清单（修正版）

## 产品边界原则

**原则一：人格属于角色，角色属于剧本。**
AI角色的完整人格（五维参数、目标层级、恐惧层级、忠诚度、语言风格）是剧本资产的一部分，由剧本创作者在剧本中定义。官方不单独提供“人格模板库”，而是提供**角色编辑器**，让创作者自己塑造角色。

**原则二：Fork开放的是内容和规则，不是引擎源码。**
官方开源的是**剧本框架和世界观规则**，允许创作者创建自己的平行版本。核心引擎（渲染、音频、AI推理、网络同步）作为技术底座闭源保护。

## 一、玩家端产品

| 产品 | 定位 | 核心交付 |
| :--- | :--- | :--- |
| **游戏客户端** | 玩家体验终端 | 3D场景渲染、空间音频语音、物品交互、信息共享（五种方式+留影石/相机）、L3视觉增强呈现、投票与结算 |
| **官方首发剧本** | 体验标杆 | 《血字的研究·变奏》《白蛇传·浮生》《东方快车谋杀案》《画皮》 |
| **官方游戏服务器** | 体验保障 | 稳定运行官方剧本，示范最佳体验标准 |

## 二、创作者工具

| 产品 | 面向用户 | 核心交付 |
| :--- | :--- | :--- |
| **剧本编辑器** | 剧本创作者 | **角色编辑器**（完整人格参数、目标/恐惧层级、忠诚度地图、语言风格配置）、场景编辑器、案件规则配置器（作案条件池、动机池、线索池）、故事线预览器 |
| **资产创作工具** | 美术/音频创作者 | 角色模型导入器、动画配置器、场景模块编辑器、音频管理器 |
| **剧本Fork与版本管理** | 所有创作者 | 基于已有剧本创建平行版本、版本历史管理、合并冲突解决、权限与归属记录 |

**关于Fork的说明：**
- Fork的是**剧本内容和世界观规则**，不是游戏引擎源码
- 创作者可以基于官方剧本（如《白蛇传·浮生》）创建自己的版本，修改角色设定、案件规则、场景布局、故事走向
- 每个版本在链上记录原作者和所有贡献者的署名
- 商业版本需按智能合约自动分账给上游创作者

## 四、底层AI服务

| 产品 | 定位 | 核心交付 |
| :--- | :--- | :--- |
| **角色智能体引擎** | 驱动单个AI角色 | 运行时加载剧本中定义的人格参数，执行三道过滤器（人设/逻辑/得失），管理动态状态（压力/信任/情绪），驱动自主行为和对话生成 |
| **叙事导演智能体** | 管理全局叙事生态 | 事实数据库维护、叙事一致性检查、动态天平系统、冲突检测与新案件生成、结局判定、高阶知识图谱引擎 |
| **L3视觉增强服务** | 关键时刻视觉强化 | 线索特写、记忆闪回、公共事件渲染、结局CG生成，支持预生成+实时生成，严格遵循可见范围权限 |

**关键修正：**
- 角色智能体引擎是一个**运行时**，它加载的是剧本编辑器产出的**人格配置数据**
- 人格参数不是官方预置的模板，而是每个剧本创作者为自己的角色定义的
- 官方提供的是**定义人格的工具**（角色编辑器），而不是**人格本身**

**核心修正总结：**

1. **人格模板库已移除**。人格是剧本内角色定义的一部分，官方只提供角色编辑器工具，不提供预置人格模板。
2. **Fork已重新定位**。Fork开放的是剧本内容和世界观规则，不是引擎源码。Fork功能并入创作者工具，作为版本管理的一部分。
3. **产品边界清晰**：引擎闭源，剧本开源；官方定义规则框架，创作者填充内容。
