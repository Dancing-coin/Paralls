### 🌌 新的叙事范式：从“破案”到“演案”

传统剧本杀的核心目标是**还原真相**。而你设想的这种模式，核心目标是**创造故事**。

玩家加入后，他们不只是侦探、嫌疑人，更是**潜在的受害者、新的加害者、意外的目击者**。新的凶案不是系统安排的剧情，而是**玩家行为与智能体决策碰撞后自然涌现的结果**。

| | 传统模式 | 你的模式 |
| :--- | :--- | :--- |
| **案件数量** | 1个 | 不限，可能连环发生 |
| **凶手身份** | 预设 | 由冲突实时产生 |
| **玩家角色** | 侦探/嫌疑人 | 任何人都可能在任何时刻转变身份 |
| **叙事驱动** | 剧本 | 玩家行为 + 智能体决策 |
| **AI导演角色** | 守护预设事实 | **管理实时涌现的叙事** |

---

### 🔄 动态案件生成系统

当玩家加入后，AI叙事导演不再只是守护一个预设的谋杀案。它会持续监控所有角色的状态，并在条件满足时，触发新的案件。

**新案件的触发条件：**

| 触发类型 | 条件 | 例子 |
| :--- | :--- | :--- |
| **冲突升级** | 两个角色的目标产生不可调和的矛盾 | 玩家A掌握了玩家B的致命秘密，B决定杀人灭口 |
| **机会涌现** | 一个角色突然获得了作案的机会窗口 | 所有人都在讨论线索，只有玛丽独自留在案发现场 |
| **秘密暴露** | 一个角色的核心秘密即将被揭开 | 华生即将被发现伪造了尸检报告，他可能铤而走险 |
| **意外失控** | 一次本无意致命的冲突，结果失控 | 福尔摩斯与亨利争执时，亨利失手推倒福尔摩斯，后者撞到头部 |

**生成逻辑：**

当AI导演检测到触发条件被满足，它会：

1.  **动机评估**：这个角色，在当下这个情境中，有没有足够的动机去实施新的行动？（调用角色的目标层级和恐惧层级）
2.  **能力评估**：这个角色，在当下的物理空间中，有没有能力完成这个行为？
3.  **人格过滤**：这个人，真的会这么做吗？（调用人格五维参数）
4.  **叙事价值评估**：如果这件事发生，它会让故事变得更有趣吗？还是会毁掉所有人的体验？

只有当所有条件都通过时，新的案件才会发生。

### 🎬 实例：一局《血字的研究》的平行世界

**T0：剧本框架**
和之前一样，创作者提交了角色、场景和可能性框架。

**T1：房间创建**
系统随机抽取动机池、凶器、线索组合。初始案件框架生成：财务纠纷，凶器烛台。

**T2：玩家加入，初始事实坍缩**
玩家A（亨利）和玩家B（艾琳）加入。初始凶手锁定为玛丽。

**T3：游戏开始，初始叙事线启动**
玩家们开始探索、对话、收集线索。AI导演维护着初始案件的逻辑一致性。

**T4：新的冲突涌现**

在探索过程中，玩家B（艾琳）通过非凡的推理能力，不仅接近了玛丽的真相，还意外发现：**玩家A（亨利）其实并非真正的亨利·贝克，他是一个冒名顶替者，真正的亨利早已在海上被杀。**

这个秘密是艾琳角色背景的一部分，但能否被发现，完全取决于游戏过程。

现在，AI导演评估：

-   **动机评估**：亨利（冒名顶替者）的首要目标是保护自己的身份秘密。恐惧层级最高项是“身份被揭穿”。目标层级最高项是“完成对死者遗产的诈骗”。动机极强。
-   **能力评估**：亨利身体强壮，且此刻大家都在分头探索，他有作案能力。
-   **人格过滤**：亨利心机8，胆量7，共情2。他是一个为达目的不择手段的人。符合。
-   **叙事价值评估**：一场全新的、由玩家行为直接引发的谋杀，将把故事带入完全不可预知的方向，远超初始剧本的体验。价值极高。

**T5：新案件坍缩**

AI导演做出决定。它不会直接控制亨利杀人，而是为亨利创造了一个**机会窗口**，并通知扮演亨利的玩家A：**“你注意到，艾琳独自一人在旅馆房间里翻找证据。她离真相只有一步之遥。而且，房间里没有其他人。”**

现在，选择权完全交给了玩家A。他可以选择铤而走险，制造一场“意外”，也可以选择用其他方式（如贿赂、威胁、求助）来应对。

如果玩家A选择行动，那么一起全新的谋杀案就诞生了。死者是玩家B。凶手是玩家A。动机是保护隐藏身份。这是初始剧本中从未设想的道路。

与此同时，关于玛丽的初始案件仍在进行中。但现在，所有人的注意力都可能被这场新的、更令人震惊的案件所吸引。玛丽可能会利用这个混乱，也可能因为恐慌而露出更多马脚。

### 👑 AI导演的新职责：叙事生态的管理者

在这种模式下，AI导演的角色从守护者，变成了**叙事生态的管理者**。它的职责是：

1.  **持续评估冲突**：监控所有角色之间的动态关系，识别潜在的冲突爆发点。
2.  **管理叙事平衡**：确保新案件的涌现不会让故事变成一团乱麻。它会适时抑制一些价值不高的冲突，催化一些能带来精彩发展的冲突。
3.  **维护角色一致性**：确保所有行为——无论是玩家的还是智能体的——都严格符合人设过滤器。
4.  **记录平行世界的历史**：每一局游戏，都是一条独一无二的时间线。AI导演会记录下这条时间线上发生的所有关键事件，最终生成一份“本局故事报告”，作为玩家体验的纪念。

这正如你所说，**原来的主线只是一个平行世界的可能性而已**。而你的游戏，就是一个让无数平行世界得以诞生的引擎。玩家不是在体验一个故事，而是在创造属于他们自己的故事。
