# 第一部分：智能体系统

## 1.1 角色智能体引擎

**职责**：驱动单个AI角色的所有行为，使其成为一个具有独立人格、能够自主决策的虚拟生命。

### 1.1.1 人格数据库

存储和管理每个AI角色的核心人格参数。

| 数据模块 | 内容 | 说明 |
| :--- | :--- | :--- |
| **五维人格参数** | 胆量/心机/共情/理性/社交（各0-10） | 决定角色的行为倾向和决策风格 |
| **目标层级** | 按优先级排序的目标列表 | 高优先级目标覆盖低优先级目标 |
| **恐惧层级** | 按强度排序的恐惧列表 | 恐惧可能使角色做出违背目标的冲动行为 |
| **忠诚度地图** | 对每个其他角色的忠诚度（-10到10） | 决定信息分享意愿和合作倾向 |
| **语言风格配置** | 称谓习惯、句式特征、话题偏好、撒谎特征、情绪表达方式 | 决定角色的对话风格和可被观察的“马脚” |
| **行为禁忌** | 绝对不能做的事项列表 | 宗教信仰、道德底线、身体限制等 |
| **背景记忆** | 角色的完整背景故事和核心秘密 | 角色“知道什么”的基础知识库 |

### 1.1.2 人格过滤器（决策核心）

所有AI角色的行为必须通过三道过滤器的验证。

| 过滤器 | 检查内容 | 不通过时的处理 |
| :--- | :--- | :--- |
| **人设过滤器** | 这个角色“会”这么做吗？ | 生成符合人设的替代行为 |
| **逻辑过滤器** | 这个行为在故事里“合理”吗？（能力/时空/信息逻辑） | 阻止行为，或转移给更合理的角色执行 |
| **得失过滤器** | 这么做对角色自己“有利”吗？（目标层级+恐惧层级计算） | 如无利可图，需有更大的利益或恐惧驱动才会执行 |

### 1.1.3 动态状态管理

跟踪和管理角色在游戏过程中的实时心理变化。

| 状态参数 | 范围 | 影响 | 变化因素 |
| :--- | :--- | :--- | :--- |
| **压力值** | 0-10 | 高压力降低“理性”维度，增加冲动行为概率 | 被质疑、秘密接近暴露、时间紧迫 |
| **信任值** | 针对每个对象 | 影响信息分享意愿和合作倾向 | 对方的言行一致性、是否帮助过自己 |
| **怀疑值** | 针对每个对象 | 影响对他人信息的采信度 | 对方的行为反常、被他人指证 |
| **情绪标签** | 当前主导情绪 | 影响决策偏向和语言风格 | 由事件触发（如被背叛→愤怒） |

### 1.1.4 自主行为系统

AI角色能够主动发起行为，而非仅被动回应。

| 行为类型 | 触发条件 | 例子 |
| :--- | :--- | :--- |
| **自主移动** | 基于目标层级，需要去某处或找某人 | 福尔摩斯决定去旅馆房间重新检查现场 |
| **主动对话** | 基于关系网络和当前局势，有信息需要传达或试探 | 华生主动找信任的玩家私下分享自己的疑虑 |
| **物品交互** | 基于目标或叙事需要，与环境互动 | 玛丽试图在无人时销毁一件可能暴露自己的物品 |
| **观察与跟踪** | 基于怀疑值，对可疑对象进行观察 | 小青跟踪法海，看他是否去挖自己埋的东西 |
| **应急反应** | 突发公共事件时的人设驱动反应 | 听到尖叫时，胆大的角色冲过去，胆小的角色躲起来 |

## 1.2 AI叙事导演系统

**职责**：全局视角的叙事管理者，维护逻辑一致性、游戏平衡和戏剧张力。

### 1.2.1 事实数据库管理

| 模块 | 内容 | 锁定时间 |
| :--- | :--- | :--- |
| **世界观事实** | 时代背景、地点设定、基础规则 | T0（剧本创作时） |
| **角色基础事实** | 姓名、身份、与其他角色的表面关系 | T0 |
| **案件框架** | 死因类型、关键线索分布、作案条件 | T1（房间创建时） |
| **案件核心事实** | 凶手身份、作案过程、动机、凶器 | T2（玩家加入后） |
| **动态生成事实** | 新案件的真凶、过程、动机 | T3（游戏进行中涌现） |

### 1.2.2 叙事一致性维护

| 功能 | 说明 |
| :--- | :--- |
| **逻辑检查** | 确保任何NPC的发言和行为不与事实数据库冲突 |
| **信息泄露控制** | 阻止AI角色说出他们不该知道的信息（通过逻辑过滤器） |
| **时间线管理** | 跟踪所有事件的时间戳，确保不在场证明等逻辑自洽 |
| **矛盾检测** | 当两个角色的说法互相矛盾时，标记为“待解决矛盾”，供玩家推理 |

### 1.2.3 动态天平系统

| 监控维度 | 平衡手段 |
| :--- | :--- |
| **信息分布** | 确保线索不会全部被一方掌握，适度为弱势方创造发现机会 |
| **阵营优势** | 检测是否存在一方必胜的局面，通过NPC行为间接调整 |
| **节奏控制** | 避免游戏进程过快或过慢，通过引入新事件调整节奏 |
| **玩家参与度** | 监控是否有玩家被边缘化，通过NPC主动接触来激活 |

**干预原则：**
- 必须通过符合人设的角色来执行
- 必须符合故事逻辑
- 不能直接改变已锁定的事实
- 干预必须是“不可见的”，玩家感受不到系统之手

### 1.2.4 冲突检测与新案件生成

| 触发条件类型 | 检测内容 | 行动 |
| :--- | :--- | :--- |
| **冲突升级** | 两个角色的目标产生不可调和的矛盾 | 评估是否触发新案件 |
| **机会涌现** | 一个角色获得了作案的机会窗口 | 通知该角色（如果该角色是玩家） |
| **秘密濒临暴露** | 一个角色的核心秘密即将被揭开 | 评估该角色是否会铤而走险 |
| **意外失控** | 本意非致命的冲突导致意外结果 | 生成意外事件 |

**新案件生成流程：**
1. 检测触发条件
2. 动机评估（调用嫌疑角色的目标层级和恐惧层级）
3. 能力评估（物理空间中的可行性）
4. 人格过滤（该角色真的会这么做吗）
5. 叙事价值评估（这会让故事更有趣还是更混乱）
6. 通过后，锁定为新事实，通知相关角色

### 1.2.5 结局判定系统

| 结局类型 | 条件 |
| :--- | :--- |
| **正义伸张** | 投票指认真凶，且关键证据被公开 |
| **真凶逃脱** | 投票未能指认真凶，或真凶成功制造不在场证明 |
| **冤案** | 无辜者被投票定罪 |
| **全员覆灭** | 新案件不断涌现，导致多名角色死亡，真相永远埋藏 |
| **隐藏结局** | 特定的条件组合触发（如发现了超越剧本的世界观秘密） |

## 1.3 知识图谱与高阶知识引擎

**职责**：追踪每个角色“知道什么”以及“知道别人知道什么”。

### 1.3.1 知识状态定义

| 状态 | 定义 | 游戏意义 |
| :--- | :--- | :--- |
| **未知** | 角色完全不知道 | 无 |
| **疑似** | 角色产生了怀疑，但不确切 | 可以进行试探性对话，但不能确认 |
| **确认** | 角色确切地知道了 | 可以将该知识作为推理和行动的确定依据 |
| **公开** | 在公共场合被展示，成为公共知识 | 所有角色的策略都必须基于此事实 |

### 1.3.2 高阶知识追踪

| 阶数 | 定义 | 例子 |
| :--- | :--- | :--- |
| **一阶** | 角色A知道事实X | 艾琳知道“日记本在书架后” |
| **二阶** | 角色A知道“角色B知道事实X” | 艾琳知道“华生看到了我藏日记本” |
| **三阶** | 角色A知道“角色B知道角色A知道事实X” | 华生知道“艾琳知道我看到她藏东西了” |
| **不确定态** | 角色A不确定角色B是否知道事实X | 艾琳不确定“华生是否看清了我藏的是什么” |

### 1.3.3 知识传播规则

| 传播方式 | 知识状态变化 |
| :--- | :--- |
| **公开对话** | 清晰区内所有角色的该知识状态变为“公开” |
| **私密对话** | 仅对话对象的该知识状态变为“确认” |
| **展示物品** | 视野内所有角色的该知识状态变为“确认” |
| **带人查看** | 跟随者的该知识状态变为“确认” |
| **留影石/相机** | 查看留影/照片者的该知识状态变为“确认” |
| **偷听** | 偷听者的该知识状态变为“疑似”或“确认”（取决于距离和清晰度） |

### 1.3.4 知识图谱的AI应用

| 应用场景 | 说明 |
| :--- | :--- |
| **对话内容约束** | AI角色只能说他们“确认”或“疑似”的信息，不能说“未知”的信息 |
| **决策驱动** | AI角色的行为基于他们当前的知识状态和高阶知识 |
| **叙事触发** | 当某个高阶知识形成时（如A意识到B在监视自己），触发新的叙事事件 |
| **平衡检测** | 当一方的知识优势过大时，触发天平系统的干预 |

## 1.4 对话生成系统

**职责**：生成符合人设、情境和当前知识状态的对话。

### 1.4.1 对话生成流程

```
[输入] 玩家发言（语音转文字）
    ↓
[意图解析] 
  - 说话对象是谁？
  - 是在提问、陈述、质疑、撒谎、结盟、闲聊？
    ↓
[人格过滤器检查]
  - 角色会回应吗？
  - 角色知道这些信息吗？
  - 回应这件事对角色有利吗？
    ↓
[知识图谱查询]
  - 角色当前知道什么？
  - 对方知道角色知道什么？（高阶知识）
    ↓
[情绪状态注入]
  - 当前压力值、信任值、情绪标签
    ↓
[对话生成]（LLM调用）
  - 对话文本
  - 情绪参数（用于TTS）
  - 肢体动作标签
    ↓
[叙事导演审核]
  - 是否泄露不该说的信息？
  - 是否需要触发事件？
    ↓
[输出] 语音合成 + 动作指令 + 对话文本（可选字幕）
```

### 1.4.2 对话优化策略

| 策略 | 说明 |
| :--- | :--- |
| **预生成候选回应** | 在玩家说话间隙，预测可能的对话走向，预生成候选回应 |
| **模板缓存** | 高频通用对话使用缓存模板，复杂/关键对话调用LLM |
| **流式输出** | LLM逐token流式返回，TTS边接收边合成 |
| **动作先行** | 决策完成后立即发送动作指令，文本/语音随后到达 |
| **上下文窗口管理** | 将人格参数、知识状态、对话历史打包为结构化上下文，控制token消耗 |

## 1.5 L3视觉增强生成系统

**职责**：在叙事关键节点，生成AI图片/视频来强化沉浸感。

### 1.5.1 触发时机与权限

| 触发时机 | 生成内容 | 可见范围 | 生成方式 |
| :--- | :--- | :--- | :--- |
| **玩家发现关键线索** | 线索物品细节特写 | 仅该玩家 | 实时生成 |
| **玩家触发角色背景回忆** | 角色过去经历的闪回画面 | 仅该玩家 | 实时生成 |
| **AI角色公开讲述某事** | 讲述内容的氛围图/场景图 | 在场所有玩家 | 实时生成 |
| **公共事件发生** | 事件现场的氛围渲染 | 在场所有玩家 | 实时生成 |
| **结局揭晓** | 本局真相还原CG | 全体玩家 | 异步生成 |
| **本局故事报告** | 关键事件插画 | 该局全体玩家 | 异步生成 |

### 1.5.2 预生成策略

| 预生成内容 | 生成时机 | 作用 |
| :--- | :--- | :--- |
| **角色立绘** | 剧本加载时 | 第一印象建立，零延迟 |
| **场景概念图** | 剧本加载时 | 氛围铺垫，零延迟 |
| **通用线索图** | 剧本加载时 | 常见线索的标准化图像，零延迟 |
| **玩家可能触发的高概率回忆** | 后台预测，提前生成 | 降低实时生成压力 |

# 第二部分：游戏系统

## 2.1 游戏客户端系统

### 2.1.1 3D场景渲染系统

| 功能 | 说明 |
| :--- | :--- |
| **场景加载** | 支持多场景切换（如贝克街客厅→旅馆房间） |
| **第一/第三人称切换** | 玩家自由选择视角 |
| **WASD移动** | 标准FPS移动控制 |
| **鼠标旋转视角** | 自由观察 |
| **动态光照** | 煤气灯、壁炉、月光等符合时代设定的光照 |
| **天气与环境效果** | 雨、雾、雪等氛围效果 |

### 2.1.2 空间音频语音系统

| 功能 | 说明 |
| :--- | :--- |
| **清晰区** | 0-N米内，完全听清 |
| **模糊区** | N-M米内，只能听到关键词和情绪 |
| **静默区** | M米外，完全听不到 |
| **耳语模式** | 清晰区缩小至1米，玩家可主动切换 |
| **物理阻挡** | 门/墙降低或完全阻隔声音传播 |
| **环境噪音** | 嘈杂声源附近听觉半径缩短 |
| **偷听提示** | 有人进入耳语清晰区时，耳语双方收到提示 |

### 2.1.3 玩家交互系统

| 交互类型 | 操作 | 说明 |
| :--- | :--- | :--- |
| **物品拾取** | 点击物品 | 获得线索物品，进入个人物品栏 |
| **物品检查** | 物品栏中点击 | 查看物品详情，触发L3视觉增强 |
| **物品展示** | 手持物品+点击“展示” | 视野内所有角色看到物品外观 |
| **物品移交** | 拖拽物品给附近角色 | 物品所有权转移 |
| **留影石/相机** | 使用道具 | 对当前视野拍照/录像，产出留影/照片 |
| **留影/照片查看** | 物品栏中点击 | 查看留影/照片内容 |
| **留影/照片移交** | 拖拽给附近角色 | 分享证据 |
| **门/窗户交互** | 点击门/窗户 | 开关门/窗，影响声音传播 |
| **光源交互** | 点击灯/蜡烛 | 开关光源，影响视觉和氛围 |

### 2.1.4 玩家UI系统

| UI模块 | 功能 |
| :--- | :--- |
| **角色状态栏** | 显示当前角色名称、身份（公开）、状态 |
| **物品栏** | 显示持有的线索、道具、留影石/照片 |
| **对话面板** | 显示附近公开对话的文本字幕、私聊窗口 |
| **投票面板** | 投票阶段显示，选择指认对象 |
| **地图** | 当前场景的简化地图（可配置是否显示） |

## 2.6 信息共享执行系统

**职责**：确保信息共享严格遵守我们之前定义的规则。

| 共享方式 | 系统执行逻辑 |
| :--- | :--- |
| **公开对话** | 清晰区内所有角色的知识状态更新为“公开” |
| **私密对话** | 仅对话对象的该知识状态更新为“确认”；模糊区偷听者更新为“疑似” |
| **展示物品** | 视野内所有角色的该知识状态更新为“确认” |
| **带人查看** | 跟随者到达位置后，该知识状态更新为“确认” |
| **留影石/相机拍摄** | 生成留影/照片物品，占用道具栏 |
| **留影/照片移交** | 接收者的该知识状态更新为“确认” |
| **留影/照片展示** | 同“展示物品” |
| **偷听检测** | 系统持续检测耳语清晰区内是否有非对话参与者，有则触发偷听提示 |
