## MVP产品：代号《书页·血字》

### 🎯 一句话定义

一个**3D沉浸式社交推理游戏**，支持1-2名玩家与多个AI智能体共同参演，在动态演化的谋杀谜案中自由探索、对话、欺骗和推理。

---

### 🎮 核心体验闭环

```
进入3D场景 → 自由探索与对话 → 发现线索与秘密 → 公开/私下交流 → 投票定罪 → 真相揭晓
```

---

### 📖 内置剧本：《血字的研究·变奏》

**故事背景**
1890年，伦敦。著名侦探**福尔摩斯**邀请几位与案件相关的人士，齐聚贝克街221B。一桩扑朔迷离的谋杀案需要今晚了结——死者是一名美国商人，尸体在他的旅馆房间中被发现，墙上用血写着“RACHE”（德语：复仇）。

**游戏设定**
- **时长**：45-60分钟
- **角色**：5名（1-2个真人玩家 + 3-4个AI智能体）
- **场景**：贝克街221B客厅 + 案发现场旅馆房间（两个3D场景，可自由切换）

**角色设定**

| 角色 | 身份 | 类型 | 秘密 |
| :--- | :--- | :--- | :--- |
| **福尔摩斯** | 侦探 | AI智能体 | 已掌握关键线索，但需要有人帮他串联真相 |
| **华生医生** | 医生/助手 | AI智能体 | 私下怀疑福尔摩斯这次判断有误 |
| **玛丽·萨瑟兰** | 死者的遗孀 | AI智能体 | 知道丈夫生前仇家，但隐瞒了自己当晚的行踪 |
| **亨利·贝克** | 死者的商业伙伴 | 真人玩家A | 与死者有财务纠纷，当晚曾与死者争吵 |
| **艾琳·艾德勒** | 神秘女郎 | 真人玩家B | 与死者有秘密往来，真实身份是私家侦探 |

**凶手真相（预设，但可被玩家行为改变）**
真正的凶手是玛丽·萨瑟兰——她发现丈夫企图将她家的传家宝卖给亨利·贝克，在争执中失手杀死了丈夫。墙上的血字是她伪造的。

### 🏗️ 产品功能清单

#### P0：必须有（MVP核心）

**1. 3D场景与基础交互**
- 两个3D场景：贝克街客厅、旅馆房间
- 第一人称/第三人称视角切换
- 基础移动（WASD行走、鼠标旋转视角）
- 可交互物品（点击查看、拾取、使用）
- 基础光照与氛围（煤气灯、壁炉、月光）

**2. 空间音频语音系统**
- 清晰区（5米内）：完全听清
- 模糊区（5-10米）：只能听到关键词和情绪
- 静默区（10米外）：完全听不到
- 耳语模式：清晰区缩小至1米，但可被靠近偷听
- 物理阻挡：关门后语音穿透效果降低

**3. AI智能体系统**
- 每个NPC拥有完整的人格数据库（五维特质、目标层级、忠诚度）
- 支持自然语言对话（文本输入+语音合成输出）
- NPC会自主移动、交互物品、与其他NPC交谈
- NPC会根据玩家行为和对话内容，动态改变态度和行为

**4. AI叙事导演**
- 事实数据库：记录案件真相、线索位置、角色秘密
- 逻辑一致性检查：阻止NPC说出不该知道的信息
- 动态天平系统：监控游戏平衡，适度调整线索曝光节奏
- 结局判定：根据玩家行为动态决定最终结局

**5. 线索与证据系统**
- 每个线索物品可被检查、拾取、展示
- 线索分为：物证（凶器、信件）、人证（NPC证词）、环境线索（血迹、打斗痕迹）
- 线索可在公开讨论中展示给所有玩家

**6. 投票与结局**
- 游戏最后5分钟触发最终投票
- 每个玩家投票指认凶手
- 多种结局：
  - 真凶被定罪
  - 无辜者被冤枉
  - 真凶逃脱
  - 隐藏结局（特定条件触发）

#### P1：重要但可推迟

- 更多剧本（《东方快车谋杀案》等）
- 角色换装与外观定制
- 战绩与成就系统
- 旁观者模式
- 录屏与回放功能
- 好友系统与组队匹配

#### P2：远期规划

- 可视化剧本编辑器
- 玩家自定义规则与角色
- “大玩家”服务器经营系统
- 创作者经济与资产确权
- Fork与二次开发支持

### 🎬 一场典型游戏的全流程

**阶段一：集结（5分钟）**

1. 玩家A（扮演亨利·贝克）和玩家B（扮演艾琳·艾德勒）进入游戏。
2. 福尔摩斯、华生、玛丽三位AI智能体已在场景中。
3. 福尔摩斯开场白：“今晚，我们必须揭开这桩血案的真相。”

**阶段二：自由探索（30分钟）**

1. 玩家A前往旅馆房间，发现一封被烧毁一半的信件（线索）。
2. 同时，玩家B在客厅与玛丽交谈。玛丽（AI）根据人格配置（共情7, 心机8）表现得悲伤但言辞闪烁。
3. 玩家A返回客厅，大声展示信件。福尔摩斯（AI）回应：“这封信的笔迹，与墙上的血字不同——凶手可能不止一人。”
4. 华生（AI）私下找到玩家B，低声说：“福尔摩斯这次似乎过于确信了，我担心他忽略了什么。”（耳语模式）
5. AI叙事导演检测到玩家A的进度过快，决定触发事件：玛丽突然站起来，说要去旅馆房间“再看一眼现场”，并示意她发现了重要线索。
6. 玩家跟随玛丽进入旅馆房间，玛丽从床下拖出一个小盒子（平衡性干预）。

**阶段三：最终讨论与投票（10分钟）**

1. 所有角色回到客厅。福尔摩斯总结线索。
2. 玩家和AI智能体轮流发言，可以展示证据、质疑他人。
3. 投票环节：每人投票指认凶手。
4. 如果多数票指向玛丽，她崩溃认罪，结局“正义伸张”。如果指向错误的人，则真凶逃脱。

### 📊 MVP成功指标

| 指标 | 目标值 | 验证什么 |
| :--- | :--- | :--- |
| 单局平均时长 | 45-60分钟 | 内容量是否合适 |
| AI智能体对话轮次 | 每局≥50轮 | AI是否有足够交互 |
| 玩家主动探索行为 | 每局≥10次物品交互 | 场景是否有探索价值 |
| 结局多样性 | 至少3种不同结局 | 动态叙事是否生效 |
| 玩家留存意愿 | 70%愿意再玩一局 | 核心体验是否吸引人 |

---

### 💎 这个MVP验证了什么

《书页·血字》这个小而精的产品，将验证你宏大构想中最核心的三个假设：

1. **AI能否驱动出足够逼真、有策略性的社交推理体验？**
2. **3D空间交互+空间语音能否创造出文字聊天无法替代的沉浸感？**
3. **动态叙事能否让每一局游戏都产生新鲜感，从而支撑“无限体验”的承诺？**

一旦这三个假设被验证，你就可以带着数据和信心，走向剧本编辑器、创作者生态和IP开放宇宙的下一个阶段。
