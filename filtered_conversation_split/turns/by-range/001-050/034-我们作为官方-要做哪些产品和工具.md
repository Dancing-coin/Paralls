## 用户

我们作为官方，要做哪些产品和工具。

## DeepSeek

作为官方，你需要构建的产品和工具可以分为三大板块：**面向玩家的产品**、**面向创作者的创作工具**、以及**支撑生态运行的后端系统**。以下是完整清单。

---

## 一、面向玩家的产品

这些是玩家直接接触的终端产品，是验证核心体验的载体。

### 1.1 游戏客户端

**定位：** 玩家体验剧本杀的终端应用。

| 功能模块 | 说明 |
| :--- | :--- |
| **账号系统** | 注册/登录、数字钱包绑定、资产查看、战绩记录 |
| **剧本大厅** | 浏览可加入的剧本房间，支持按类型/人数/难度筛选 |
| **角色选择** | 查看可选角色背景简介、人设标签，确认加入 |
| **3D场景交互** | WASD移动、鼠标旋转视角、第一/第三人称切换 |
| **物品交互** | 点击查看、拾取、使用、展示线索物品 |
| **空间音频语音** | 清晰区/模糊区/静默区、耳语模式、物理阻挡、环境噪音 |
| **文本聊天** | 公开讨论、私聊、与NPC对话 |
| **投票与结算** | 投票界面、结局揭晓动画、本局故事报告 |
| **设置** | 音频/视频/语言偏好设置 |

### 1.2 剧本库（官方首发）

**定位：** 展示核心品质、建立玩家信心的官方剧本。

| 剧本 | 类型 | 角色数 | 时长 | 特点 |
| :--- | :--- | :--- | :--- | :--- |
| 《血字的研究·变奏》 | 英式推理 | 5人 | 45-60分钟 | MVP首发，经典推理 |
| 《白蛇传·浮生》 | 东方志怪 | 5人 | 60-75分钟 | 情感冲突+阵营对抗 |
| 《东方快车谋杀案》 | 封闭空间推理 | 6人 | 50-65分钟 | 高玩挑战，群体博弈 |
| 《画皮》 | 恐怖生存 | 4人 | 40-55分钟 | 恐怖氛围，快速开局 |

### 1.3 游戏房间服务

**定位：** 官方运营的高品质游戏服。

- 官方服务器提供稳定的游戏体验
- 承载首发剧本的匹配和运行
- 作为品质标杆，示范“最好的剧本杀体验应该是什么样”

## 二、面向创作者的创作工具

这些是赋能生态、让创作者能够生产内容的工具。是平台区别于传统游戏公司的核心竞争力。

### 2.1 剧本编辑器

**定位：** 让创作者无需代码即可设计完整剧本的可视化工具。

| 编辑模块 | 功能说明 |
| :--- | :--- |
| **角色编辑器** | 创建角色、配置五维人格参数（胆量/心机/共情/理性/社交）、设定目标层级、恐惧层级、忠诚度关系、语言风格 |
| **场景编辑器** | 从官方资产库拖拽搭建3D场景，为物体设置可交互属性、关联线索 |
| **案件规则配置器** | 定义作案条件池、动机池、线索池，设定初始案件生成逻辑 |
| **故事线预览器** | 模拟AI跑完剧本，观察不同变量下的叙事走向，发现逻辑漏洞 |
| **剧本发布面板** | 设置剧本名称、封面、标签、定价、授权范围，一键发布到市场 |

### 2.2 资产创作工具

**定位：** 供美术和音频创作者生产可复用资产的工具链。

| 工具 | 说明 |
| :--- | :--- |
| **角色模型导入器** | 支持导入标准T-Pose/A-Pose的骨骼白模（GLB/FBX格式），自动校验骨骼规范 |
| **动画配置器** | 为角色绑定动作资产，支持引用AI生成的动画（如Kimodo输出） |
| **场景模块编辑器** | 创建新的场景模块（墙壁、家具、道具），定义为可复用的预制件 |
| **音频管理器** | 上传背景音乐、环境音效、角色语音，配置空间音频参数 |

### 2.3 大玩家控制台

**定位：** 面向服务器经营者的管理后台，让他们能够运营自己的剧本杀世界。

| 功能模块 | 说明 |
| :--- | :--- |
| **剧本库管理** | 从官方市场挑选剧本，策展自家服务器的剧本列表 |
| **规则微调面板** | 在官方允许范围内调整：游戏时长、投票规则、线索密度、AI难度 |
| **服务器部署工具** | 一键部署的Docker镜像，包含游戏服务、AI服务、数据库、链交互节点 |
| **服务器状态监控** | 实时查看活跃房间数、玩家在线数、AI负载、异常日志 |
| **GM工具箱** | 以管理员身份进入任意房间，广播公告、触发事件、调解纠纷 |
| **经营分析面板** | 服务器收入统计、剧本流行度排行、玩家留存率、付费转化率 |

### 2.4 Fork开发者工具包

**定位：** 面向深度开发者的技术工具，让他们能够从剧本杀拓展到跑团、派对游戏等全新玩法。

| 工具 | 说明 |
| :--- | :--- |
| **核心框架SDK** | 开源的游戏核心框架，包含规则引擎、AI接口、网络层 |
| **API文档** | 完整的接口文档，供开发者对接自定义系统 |
| **规则引擎插件接口** | 允许开发者编写自定义的玩法规则、阵营系统、胜利条件 |
| **链上资产接口** | 与区块链确权系统对接，确保分叉版本的资产同样受版权保护 |
| **开发测试环境** | 本地化测试沙盒，支持快速迭代 |

## 三、支撑生态运行的后端系统

这些是玩家看不到但决定体验质量的核心系统。

### 3.1 AI服务层

| 系统 | 职责 | 交付物 |
| :--- | :--- | :--- |
| **AI叙事导演** | 全局故事管理、线索曝光节奏控制、动态天平、冲突检测、新案件触发 | API服务 |
| **角色智能体引擎** | 人格驱动对话生成、自主决策、语言风格控制、情绪状态管理 | API服务 |
| **人格过滤器** | 三重验证（人设/逻辑/得失），确保所有行为合规 | 集成于智能体引擎 |
| **语音合成** | 为AI角色生成符合人设的语音 | API服务 |

### 3.2 空间音频服务器

| 功能 | 说明 |
| :--- | :--- |
| **音频空间化** | 根据玩家位置实时计算音频衰减、混响 |
| **介质阻挡计算** | 门/墙对声音的物理阻挡效果 |
| **耳语模式支持** | 私密对话的音频半径动态调整 |
| **环境噪音管理** | 场景内动态声源的管理和混音 |

### 3.3 资产管理与市场系统

| 系统 | 功能 |
| :--- | :--- |
| **资产注册系统** | 创作者上传资产时自动生成内容指纹 |
| **资产市场** | 官方及创作者上传的剧本、角色、场景、机制包展示与交易 |
| **版本管理** | 资产的多版本管理，兼容性检查 |
| **引用追溯系统** | 记录所有资产的引用关系，形成创作家谱树 |
| **评分与评价系统** | 玩家对剧本/资产的评分、评论、推荐 |

### 3.4 区块链确权与分账系统

| 系统 | 功能 |
| :--- | :--- |
| **内容指纹上链** | 资产提交时自动生成哈希并上链存证 |
| **智能合约引擎** | 自动执行收益分配（官方/创作者/引用者按比例分账） |
| **治理代币系统** | 代币发行、空投、投票治理 |
| **版权登记与维权** | 资产版权记录、侵权检测、纠纷仲裁机制 |

### 3.5 数据与运营后台

| 系统 | 功能 |
| :--- | :--- |
| **官方运营后台** | 全平台数据监控、内容审核、用户管理、公告发布 |
| **数据分析平台** | 剧本流行度、玩家行为分析、AI性能监控、收入统计 |
| **反作弊系统** | 异常行为检测、恶意内容过滤、账号安全 |

## 四、优先级路线图

| 阶段 | 核心交付 | 说明 |
| :--- | :--- | :--- |
| **Phase 1** | 游戏客户端 + 《血字的研究》剧本 + AI服务层 + 空间音频服务器 | 验证核心体验闭环 |
| **Phase 2** | 剧本编辑器 + 大玩家控制台 + 资产市场 + 官方剧本扩充 | 赋能第一批创作者 |
| **Phase 3** | 区块链确权系统 + 智能合约分账 + Fork开发者工具 | 开放生态与商业闭环 |
| **Phase 4** | 治理代币 + IP议会 + 多品类扩展（跑团、派对游戏） | 生态自治与持续演化 |

---

**总结：**

官方需要做的，本质上是三件事：

1. **做标杆**：通过高品质的客户端和官方剧本，定义“好的体验是什么样”
2. **做工具**：通过编辑器、控制台、SDK，让创作者能够自己生产内容
3. **做规则**：通过区块链确权、智能合约分账、治理机制，让生态能够自我运转
