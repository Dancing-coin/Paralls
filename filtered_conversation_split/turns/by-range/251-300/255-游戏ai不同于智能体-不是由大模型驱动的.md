## DeepSeek

你的区分非常关键。在《开本》的SLG中，角色实际上分为两类：一是由完整心智模型驱动的**智能体**，用于需要深度交互的关键角色；二是由群体模拟引擎驱动的**游戏AI**，用于大量无需独立人格的背景角色。它们的职责和驱动方式截然不同。

---

## 游戏AI与智能体的分层架构

### 一、明确区分

| | 智能体 | 游戏AI |
| :--- | :--- | :--- |
| **驱动方式** | 完整心智模型（LLM推理 + 人格过滤器 + 记忆系统） | 群体模拟引擎（规则算法 + 状态机 + 统计数据） |
| **数量** | 数十至数百 | 成千上万 |
| **有无独立人格** | 有 | 无——仅作为群体的一个实例 |
| **能否自由对话** | 能 | 不能——仅能返回预设的简短回应或统计描述 |
| **算力消耗** | 高 | 极低 |
| **典型角色** | 国王、贵族、将军、重要商人 | 农民、矿工、基础士兵、普通市民 |

---

### 二、群体模拟如何操控游戏AI

**1. 行为驱动**

群体模拟引擎为每一类游戏AI定义一组**状态机**和**行为规则**，而非独立的智能体推理。

| AI类型 | 行为规则 |
| :--- | :--- |
| **农民** | 白天在田地里劳作（动画循环）→ 傍晚回到住所 → 根据“粮食储备”数据改变动作频率（丰收时动作轻快，饥荒时动作迟缓） |
| **矿工** | 在矿区与矿场之间往返 → 根据“铁矿产出率”改变矿工人数密度 |
| **基础士兵** | 在兵营训练 → 接到行军命令后沿道路移动 → 遭遇敌军时按兵力对比自动结算（无需独立决策） |
| **市民** | 在市场、广场、住所之间走动 → 根据“城市繁荣度”改变外观（繁荣时衣着鲜艳，萧条时衣衫褴褛） |

**2. 视觉呈现**

游戏AI的行为直接通过动画和3D模型表现，由群体模拟数据驱动：

| 群体数据 | 对游戏AI视觉的影响 |
| :--- | :--- |
| **人口数量** | 城市街道上的市民密度 |
| **阶层满意度** | 市民的表情（满足/愤怒/恐惧）和聚集行为（正常行走 vs 聚集抗议） |
| **经济繁荣度** | 市民的服装质量、建筑外观、市场摊位的数量 |
| **战争状态** | 城墙上士兵的数量和紧张程度、城门是否关闭 |

**3. 信息反馈**

玩家不直接与游戏AI对话，而是通过以下方式获取信息：

| 交互方式 | 反馈内容 |
| :--- | :--- |
| **观察** | 玩家在城市中走动，看到农民在劳作、商人在叫卖、士兵在巡逻——这些都是群体模拟驱动的视觉呈现 |
| **统计面板** | 打开政务面板，查看各阶层的人口、满意度、产出等统计数据 |
| **司命生成的微观事件** | “城东的粮食市场今天聚集了抗议的人群——粮价已经连续两周上涨了。” |
| **接触特定代表** | 玩家点击某个市民时，系统从群体模拟中提取该阶层的“平均状态”，生成一句简短的文字反馈：“我是一个铁匠，最近铁矿涨价，生意越来越难做了。”——这**不是智能体对话**，而是基于群体数据的**模板化回应** |

---

### 三、关键交互时才注入智能体

当某个游戏AI因叙事需要变得重要时，系统才将其升级为临时智能体。判断标准由司命根据当前需要决定：该角色是否因玩家主动接触而需要深度对话，是否因剧情发展（如带头抗议的商人）需要独立人格，或者是否拥有影响局势的特殊信息（如目击敌军动向的哨兵）。

当触发升级条件后，系统会即时生成临时人格档案、注入背景记忆，并激活一个轻量级智能体实例进行对话。对话结束后，根据该角色的后续价值决定保留为L2角色还是回收，其行为结果（如被说服）则回流更新到群体模拟数据中。

---

### 四、对SLG整体体验的影响

| 情境 | 玩家的感知 |
| :--- | :--- |
| **日常观察** | 走在城市中，看到市民、士兵、商人在忙碌——这些都是群体模拟驱动的游戏AI，提供沉浸感 |
| **查看统计** | 打开政务面板，看到“农民满意度下降”——这是群体模拟产出的数据 |
| **关键对话** | 与带头抗议的商人代表谈判——这是一个临时注入的智能体，拥有完整的个性和诉求 |
| **战争场景** | 战场上成千上万的士兵冲锋——这是群体模拟驱动的宏观动画，无需每个士兵独立决策 |

---

**一句话总结**：《开本》SLG中的游戏AI由群体模拟引擎驱动——它们没有独立人格，不消耗LLM算力，而是作为群体的可视化呈现。只有在需要深度交互的关键时刻，系统才会从群体中提取代表、注入智能体、进行自由对话。这种分层架构既保证了宏大世界的沉浸感，又控制了算力成本。
