# 《深渊航线》——原创时间循环剧本

## 一、剧本定位

| 维度 | 说明 |
| :--- | :--- |
| **所属平行世界** | UNV-007（近未来悬疑） |
| **题材类型** | 现代 / 悬疑 / 时间循环 |
| **核心玩法** | 时间循环 + 硬核推凶 + 故事还原 |
| **玩家规模** | 5人（2-3真人 + 2-3AI智能体） |
| **难度等级** | 进阶 (⭐⭐) |
| **剧本类型** | 连续剧本包（4-5局） |

## 二、故事背景

2027年，一艘名为“深渊号”的豪华游轮正在进行它的首航——从上海到横滨的48小时旅程。船上共有127名乘客和船员。

凌晨2点17分，游轮在公海上发生爆炸，全船无人生还。

但你醒来了。

你发现自己站在登船的舷梯前，手里握着船票。时钟显示：2027年3月15日，下午3点。距离爆炸，还有11小时17分钟。

你不是唯一一个记得爆炸的人。


## 三、核心机制设计

### 1. 循环规则

| 规则 | 说明 |
| :--- | :--- |
| **循环触发** | 爆炸发生 or 玩家死亡 or 超过11小时 → 自动重置 |
| **记忆保留** | 所有“觉醒者”（玩家和部分AI角色）保留完整循环记忆 |
| **物证保留** | 被藏匿在特定位置（如保险箱、暗格）的物品不随循环重置 |
| **循环次数** | 有限制（如15次），每次循环开始时司命会提示剩余次数 |
| **循环变化** | 每次重置后，部分乘客的座位/行为会随机微调，某些线索的位置会变化 |

### 2. 觉醒机制

并非所有角色都在第一次循环就“觉醒”。

| 觉醒批次 | 角色 | 循环数 | 效果 |
| :--- | :--- | :--- | :--- |
| **第一批** | 你（主角）+ 核心同伴 | 第1次循环 | 完整记忆，可以主动行动 |
| **第二批** | 关键证人 | 第3-5次循环 | 开始产生“既视感”，可能主动找你 |
| **第三批** | 凶手/同谋 | 第8-10次循环 | 意识到自己也在循环中，可能改变策略 |


## 四、角色设定

| 角色 | 身份 | 扮演者 | 核心秘密 |
| :--- | :--- | :--- | :--- |
| **林深** | 调查记者 | 真人玩家A | 上船是为了调查船东公司的非法交易。他发现了船员名单中有三个人的身份是伪造的 |
| **苏晚** | 游轮驻船医生 | AI智能体（可真人） | 她在登船前收到一封匿名信，警告她“不要上这艘船”。她在医务室的保险柜里藏了一份关键证据 |
| **方海** | 游轮安保主任 | AI智能体 | 他曾是刑警，因一次失误被调离。他注意到船上有几个“老面孔”——他们曾在不同的船上出现，用的却是不同的名字 |
| **“幽灵乘客”** | 身份不明 | 真人玩家B | 你在乘客名单上找不到自己的名字。你的船票是伪造的。你上船的真正目的是什么？ |
| **季云** | 船东公司代表 | AI智能体 | 他知道这艘船的真实目的——不是首航，而是运送一批“特殊货物”。他收到指令：不能让任何人发现货舱里的东西 |

## 五、案件框架

| 要素 | 内容 |
| :--- | :--- |
| **核心事件** | 游轮爆炸，全船无人生还 |
| **爆炸原因池** | 定时炸弹 / 货舱危险品泄漏 / 人为引爆 / 意外事故 |
| **动机池** | 灭口（掩盖货舱秘密） / 复仇（针对船东公司） / 恐怖袭击 / 保险欺诈 |
| **真凶候选** | 所有角色平等（包括真人玩家） |
| **隐藏真相** | 货舱里运送的不是普通货物，而是一批军用级炸药——这艘游轮本身就是一个“炸弹”。幕后黑手计划让游轮在公海爆炸，制造“事故”来掩盖之前另一桩罪案的证据 |

## 六、核心冲突

表面上是“找到炸弹客”，但真正的冲突有多层：

- **第一层**：找出是谁触发了爆炸
- **第二层**：发现货舱的秘密，意识到爆炸可能不是意外
- **第三层**：你们之中有人不是“无辜乘客”——有人知道真相但选择沉默
- **第四层**：幕后黑手可能在你们之中，也可能在循环之外

## 七、关键分支点

- 你是否选择相信苏晚？她可能在某个循环中背叛你
- 你是否主动接触“幽灵乘客”？他的真实身份会改变你的策略
- 你是否提前进入货舱？那里有定时炸弹，但也是揭开真相的关键
- 你是否在某个循环中选择“放弃”——不作为，只是等待爆炸来临？这个选择会触发隐藏剧情

## 八、司命的角色：“循环编织者”

| 司命职责 | 说明 |
| :--- | :--- |
| **循环管理** | 每次重置自动恢复世界状态，保留记忆和特定物证 |
| **随机微调** | 每次循环中随机改变部分乘客的行为模式、线索位置，防止“机械重复” |
| **节奏控制** | 当推理陷入僵局，催化某位AI角色“想起”新线索；当进展过快，引入新变数（如某乘客突然对你产生怀疑） |
| **隐藏剧情催化** | 当玩家满足特定条件（如连续三次循环都选择相信苏晚），触发隐藏剧情线——“信任的代价” |
| **真相层次的逐步揭示** | 第1-3次循环：找到炸弹；第4-8次循环：发现货舱秘密；第9-12次循环：揭开幕后黑手；最后3次循环：完美结局 |

## 九、隐藏结局条件

**完美结局**：
- 爆炸被阻止
- 幕后黑手被揭露
- 货舱的秘密被公开
- 所有无辜乘客获救
- “幽灵乘客”的真实身份被揭开——他是国际刑警的卧底，一直在调查船东公司

**隐藏结局**：
- 你发现“循环”的真相——这不是意外，而是一场人为制造的“时间囚笼”。有人在利用循环来掩盖某件事。
- 这个隐藏结局将直接连接到《开本》宇宙的更大世界观：“循环”是司命的一种“实验”，而你在无数循环中的选择，正在被某个更高的存在观察。


## 十、与《开端》的差异化

| 维度 | 《开端》 | 《深渊航线》 |
| :--- | :--- | :--- |
| **场景** | 城市公交车 | 公海豪华游轮——更大的探索空间，更多可交互区域 |
| **人数** | 公交车上十几人 | 全船127人，核心5人 |
| **真相层次** | 找到炸弹客 | 找到炸弹客 → 发现货舱秘密 → 揭开幕后黑手 → 触及循环本身 |
| **玩家目标** | 阻止爆炸 | 阻止爆炸 + 揭露犯罪网络 + 在循环中保护你的同伴 |
| **AI同伴** | — | 苏晚——她可能成为你最信任的盟友，也可能在某个循环中背叛你 |
| **隐藏真相** | 炸弹客的动机 | 游轮本身就是一个巨大的“炸弹”——幕后黑手的计划远超你的想象 |
| **结局** | 完美阻止爆炸 | 完美结局 + 隐藏结局（触及“循环”的更高层真相） |


## 十一、系列扩展可能

《深渊航线》只是这个无限流宇宙的起点。完成本系列后，你作为“觉醒者”将进入下一个任务世界：

- **《时间囚笼》**：你被投入一个不断循环的监狱——这里的囚犯都在循环中，但有人利用循环在“完美犯罪”
- **《神之七日》**：一个与世隔绝的宗教小镇，每七天重置一次。镇民们知道循环的存在，他们利用循环来“净化灵魂”
- **《破壁者》**：你发现所有循环都指向一个幕后组织——他们在用循环做实验。你决定追查到底

**一句话总结**：《深渊航线》不是《开端》的翻版，而是一个全新的、更宏大的时间循环叙事。它拥有更丰富的空间探索、更多层的真相揭示、更深的AI同伴羁绊，以及通往《开本》宇宙更大世界观的隐藏入口。
