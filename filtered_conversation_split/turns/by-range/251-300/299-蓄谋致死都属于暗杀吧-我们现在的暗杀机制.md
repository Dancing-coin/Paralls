## 用户

蓄谋致死都属于暗杀吧 我们现在的暗杀机制包含的还是太浅层

## DeepSeek

你提出的这一点，揭示了我们将所有蓄谋行为笼统归为“暗杀”的设计缺陷。在《开本》中，一个角色夺取另一个角色生命的行为，根据其动机、时机和准备程度，应该被区分为两种截然不同的机制路径：

1.  **预谋杀人 (Premeditated Murder)**：这是剧本预设的、在游戏开始前（T0-T2阶段）凶手就已经策划好的**初始犯罪计划**。它是剧本案件框架的核心组成部分，属于结构性叙事。
2.  **涌现式暗杀 (Emergent Assassination)**：这是我们此前大量讨论的、由角色心智模型和司命在游戏过程中**实时催化**的杀人行为。它是在初始计划之外，因局势变化而被迫做出的极端选择，属于涌现叙事。

下面我将为你详细剖析这两条路径，并重新定义我们“暗杀机制”的完整架构。

### 一、核心区分：计划犯罪 vs 冲动杀人

为了精确描述，我建议将两者在系统内明确区分为“**预谋杀人**”和“**涌现式暗杀**”。

| 特性 | 预谋杀人 (Premeditated Murder) | 涌现式暗杀 (Emergent Assassination) |
| :--- | :--- | :--- |
| **叙事定位** | **结构性叙事**：剧本的初始案件，是故事的起点和核心。 | **涌现叙事**：局势催生的额外案件（案中案），是故事的变数和转折点。 |
| **计划来源** | 由剧本创作者在T0阶段预设的“完整犯罪计划”或“作案条件”。 | 由角色智能体在游戏过程中，为应对危机而**实时生成**的临时计划。 |
| **触发时机** | 游戏开始前（T0-T2）就已经计划好，游戏开始时凶手已做好准备。 | 游戏进行中（T3），由角色心智模型和司命催化触发。 |
| **核心驱动** | **剧本规则**：满足作案条件即可执行。 | **心智模型**：致命动机 + 机会窗口 + 人格过滤。 |
| **精密程度** | **高**。凶手有时间准备凶器、伪造不在场证明、清理痕迹。 | **低**。凶手因情况紧急，通常只能利用手边物品，痕迹明显。 |
| **玩家权限** | 仅凶手玩家（AI或人类）可执行其预设计划。 | 所有满足条件的玩家（人类或AI）都可能成为暗杀者。 |
| **典型案例** | 玛丽·萨瑟兰提前准备好匕首，伪造“RACHE”血字。 | 上校为了帮麦奎因逃脱，临时用烈酒点燃窗帘制造混乱。 |
| **系统设计目的** | 构建剧本的核心谜题，让侦探玩家去破解这个预设的“完美犯罪”。 | 创造“案中案”的戏剧性，让故事因玩家的选择而走向无法预测的方向。 |

### 二、预谋杀人：初始犯罪计划的设计

为了支撑更复杂的“蓄谋”，我们需要在剧本模板的T0设定中，引入一个**“犯罪计划 (Crime Plan)”**的概念，让凶手在游戏开始前就有一套周密的安排。

#### 2.1 犯罪计划 (Crime Plan)

这是一个结构化的JSON对象，定义了凶手在游戏开始前所做的所有准备。

```json
{
  "crime_plan": {
    "perpetrator": "mary", // 凶手角色ID
    "motive": "financial_revenge", // 作案动机
    "weapon": "candlestick", // 凶器
    "preparations": [ // 凶手在案发前做的准备工作
      {
        "action": "forge_alibi", // 伪造不在场证明
        "target_npc": "maid", // 收买女仆作伪证
        "success_rate": 0.8, // 成功率，影响后续司命的逻辑检查
        "failure_consequence": "npc_suspicious" // 失败后，女仆会变得可疑
      },
      {
        "action": "plant_evidence", // 伪造证据
        "target_item": "henrys_dagger", // 将亨利的匕首放在现场附近
        "success_rate": 0.9
      },
      {
        "action": "clean_traces", // 清理痕迹
        "target_area": "hotel_room", // 清理旅馆房间的指纹
        "success_rate": 0.7
      }
    ],
    "intended_narrative": "让亨利成为主要嫌疑人，自己则以悲痛的遗孀身份逃脱" // 凶手期望的剧情走向
  }
}
```

#### 2.2 预设与涌现的协作：司命的逻辑校验

司命在游戏中的事实核心，会在合适的时机（如玩家发现关键证据时）对凶手的“犯罪计划”进行校验。

*   **校验成功**：凶手的计划完美运行，线索指向他预设的方向。
*   **校验失败**：司命会根据成功率判定计划的哪个环节出了纰漏。例如，玛丽收买女仆失败，女仆在压力下主动向波洛坦白，成为破案的关键转折点。

这使得即使是预设的犯罪计划，也充满了涌现叙事的可能。

### 三、更新后的“暗杀机制”完整架构

现在，我们可以完整地定义《开本》的谋杀机制，它包含两条清晰的路径：

### 四、对游戏体验的深化

通过区分这两条路径，谋杀在《开本》中成为了一种富有层次感的策略行为。

*   **对于凶手玩家**：你将拥有一个精心设计的“初始剧本”，体验到实施完美犯罪的操控感。但同时，你必须随时准备应对局势变化。当你的计划出现纰漏，或被人发现秘密时，你可能会面临那个终极的“暗杀弹窗”，体验从“计划者”到“冲动者”的角色转变。
*   **对于侦探玩家**：你的任务从单纯的“谁是凶手”，深化为需要区分“哪些是凶手精心布置的伪装，哪些是冲动留下的破绽”。一个周密的预谋犯罪现场，与一个混乱的涌现式暗杀现场，将提供完全不同的推理路径，挑战你的洞察力。
*   **对于司命**：游戏从一场“即兴表演”，变成了一部“剧本与即兴交织的戏剧”。司命既是剧本严谨的守护者，也是涌现故事的催化剂。它将凶手预设的“犯罪计划”作为一个变量，与实时涌现的冲动行为交织在一起，创造出独一无二的、逻辑自洽的叙事链。

通过这种设计，每一场“谋杀”，无论它是蓄谋已久的冷血复仇，还是千钧一发时的迫不得已，都将成为《开本》世界中一个充满叙事魅力的核心事件。
