## 用户

统一视角需要为每个角色（玩家）的视觉角度做适配吗？呈现在每个玩家屏幕上的一段画面都一个样？

## DeepSeek

在《开本》的沉浸式叙事框架下，**统一视角绝不意味着所有玩家的屏幕上呈现完全相同的画面**。如果这样做，就会把玩家从“角色”变成“观众”，彻底破坏我们一直追求的“有人味的游戏”体验。

统一视角的真正含义是**信息内容的统一**，而非视觉角度的统一。以下是详细的设计规则：

---

## 一、统一视角的核心原则

| 维度 | 统一 | 不统一 |
| :--- | :--- | :--- |
| **信息内容** | ✅ 所有玩家看到的事件经过是一致的 | ❌ |
| **视觉角度** | ❌ | ✅ 每个玩家的画面基于其角色的3D位置、朝向、高度实时计算 |
| **司命的镜头调度** | ✅ 统一的镜头语言——推近、慢动作等宏观指令对所有玩家同步执行 | ❌ |
| **角色化的视觉参数** | ❌ | ✅ 不同角色的身高、位置、状态（醉酒等）会影响其视角画面 |

**一句话总结：统一视角 = 统一的叙事信息 + 角色化的视觉呈现。**


## 二、以“哈伯德太太公开坦白”为例

### 场景设置
- 哈伯德太太站在餐车中央
- 波洛站在餐车前部，面对哈伯德，距离3米
- 玛丽坐在餐车右侧角落的椅子上，距离哈伯德5米
- 麦奎因站在餐车左侧窗边，距离哈伯德4米

### 各角色屏幕上呈现的画面

| 角色 | 画面内容 | 差异原因 |
| :--- | :--- | :--- |
| **波洛** | 正面看到哈伯德太太的面部特写，她颤抖的嘴唇和含泪的眼睛清晰可见 | 波洛的3D位置正对哈伯德，距离3米，身高175cm |
| **玛丽** | 从右侧的侧前方看到哈伯德太太，能看到她的半侧面和颤抖的双手，但面部细节不如波洛清晰 | 玛丽的3D位置在右侧角落，距离5米，身高162cm——女性身高带来的视角差异 |
| **麦奎因** | 从左侧看到哈伯德太太的背影侧面，能看到她颤抖的肩膀，但看不到面部表情 | 麦奎因的3D位置在左侧窗边，距离4米 |

**关键差异**：
- 波洛能看到哈伯德太太眼中的泪水——他是唯一能看到这个细节的人
- 玛丽能看到哈伯德太太的手帕被揉成一团——这个细节波洛因为距离太近反而看不到
- 麦奎因看不到哈伯德太太的面部——他不知道她有多恐惧，只能从声音判断

**但所有人的信息内容是统一的**：
- 哈伯德太太站起来说了什么——所有人都听到了（空间音频）
- 哈伯德太太在颤抖——所有人都能看到（各自的角度）
- 哈伯德太太指向麦奎因——所有人都能看到这个手势（各自的角度）

### 司命的镜头调度（统一指令，角色化执行）

司命发出的统一指令：`在哈伯德太太说话时，镜头缓慢推近至她的面部特写（慢动作，2秒）`。

| 角色 | 实际执行的画面 |
| :--- | :--- |
| **波洛** | 镜头从他的3D位置推近至哈伯德的面部特写——正面的、清晰的特写 |
| **玛丽** | 镜头从她的3D位置推近至哈伯德的侧前方特写——能看到半侧面 |
| **麦奎因** | 镜头从他的3D位置推近至哈伯德的背影侧面——看不到面部 |

**司命的指令是统一的（推近至哈伯德的特写），但每个玩家看到的特写角度不同，取决于其角色的3D位置。**


## 三、特殊情况：司命强制统一构图

在极少数极端高潮时刻，司命可以选择**短暂覆盖角色视角**，强制所有玩家看到同一个精心设计的构图。这种覆盖必须满足以下条件：

| 条件 | 说明 |
| :--- | :--- |
| **戏剧价值极高** | 必须是本局最关键的高潮节点 |
| **覆盖时间极短** | 通常1-3秒，不超过一次深呼吸的时间 |
| **有明确的叙事理由** | 例如“所有人都被某个画面震撼了”——这是角色的自然反应 |
| **覆盖结束后恢复角色视角** | 强制构图后，镜头自然切换回角色视角 |

### 以“麦奎因公开承认身份”为例

**强制覆盖时刻**（2秒）：

| 时间 | 画面 | 视角 |
| :--- | :--- | :--- |
| T+0s | 麦奎因站起来：“我的真名是小约翰·阿姆斯特朗。” | 各自角色视角 |
| T+1s | **强制统一构图**：正面大特写——麦奎因苍白的面容、坚定的眼神、嘴角那丝悲伤的平静 | **所有玩家看到相同的画面** |
| T+3s | 构图自然切换回各自角色视角——波洛微微扬起眉毛，玛丽流下眼泪 | 恢复角色视角 |

**为什么这里可以使用强制统一构图？**

- 这是本局的最高潮——真凶暴露的瞬间
- 持续时间极短（2秒），不会让玩家感到“被剥夺了角色视角”
- 有明确的叙事理由——所有人都被麦奎因的坦白震撼了，这一刻他们忘记了自己是谁，只剩下共同的震惊
- 强制构图的画面是任何角色在物理位置上都无法看到的（正面大特写），这本身就是一种“超越角色感知”的艺术化表达


## 四、角色状态对视角的影响

| 角色状态 | 对视角画面的影响 | 是否对其他玩家可见 |
| :--- | :--- | :--- |
| **高压力** | 画面边缘出现心跳光晕，色彩饱和度略微降低 | 否——这是角色内心状态的视觉化 |
| **醉酒** | 画面出现轻微重影和色偏 | 否 |
| **专注观察** | 画面中央清晰，边缘暗角（隧道视觉） | 否 |
| **身高差异** | 视角高度不同——矮个子的角色需要仰视高个子 | 是——其他玩家可以看到这个角色的头部朝向 |
| **位置差异** | 视角方向不同——角落的角色看到的是事件的全景，中央的角色看到的是特写 | 是——其他玩家可以看到这个角色在看哪里 |


## 五、设计原则总结

| 原则 | 说明 |
| :--- | :--- |
| **统一视角 = 统一信息 + 角色化视觉** | 所有玩家知道“发生了什么”，但每个人看到的角度、细节、氛围不同 |
| **司命的镜头指令是统一的** | 推近、慢动作、景深变化——这些宏观指令对所有玩家同步执行 |
| **但执行结果是角色化的** | 同一个“推近至面部特写”的指令，在不同角色的3D位置上产生不同的画面 |
| **强制统一构图是例外** | 仅用于极高戏剧价值的瞬间，持续时间极短，且有叙事理由 |
| **角色状态影响视角** | 压力、醉酒、专注等状态会影响画面的滤镜和特效 |
| **视角差异本身就是推理线索** | 玩家需要意识到“别人可能看到了我没看到的”——这正是我们设计的高阶知识博弈 |


**一句话总结**：统一视角的实时演算，绝不意味着所有玩家的屏幕显示完全相同的画面。司命发出统一的导演指令，每个角色基于自己的3D位置、朝向、身高、状态获得角色化的视觉呈现。信息内容统一，视觉角度不统一——这才是《开本》在沉浸感与信息博弈之间的完美平衡点。
