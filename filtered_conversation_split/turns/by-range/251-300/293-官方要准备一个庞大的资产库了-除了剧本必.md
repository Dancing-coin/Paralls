## 官方基础资产库：平台基石

基础资产库是平台自带的、所有剧本共用的资产。创作者不需要从零开始，而是像搭乐高一样调用这些基础组件。这是《开本》区别于传统游戏开发的核心优势——**一个剧本的“火烧窗帘”和另一个剧本的“火烧木屋”用的是同一套火焰逻辑和材质变种**。

| 资产大类 | 具体内容 | 用途 |
| :--- | :--- | :--- |
| **材质模板库** | 木材、布料、金属、玻璃、石料、纸张等基础材质的物理属性定义（可燃性、导热性、透水性、坚固度等） | 任何物体挂载材质后自动获得对应的物理规则 |
| **状态变种贴图** | 每种材质的通用状态贴图：`_charring`（焦黑）、`_wet`（潮湿）、`_burned_out`（灰烬）、`_cracked`（裂纹）、`_iced`（结冰） | 物体状态变化时自动切换贴图，无需为每个物体单独绘制 |
| **通用粒子特效** | 火焰、烟雾、水滴、碎片（金属/玻璃/木质）、冷气、电弧等 | 物体状态变化时自动播放对应特效 |
| **破坏模型模板** | 玻璃破碎、木材断裂、金属弯曲的通用几何体变种 | 物体被破坏时替换为对应模型 |
| **交互组件库** | `[可拾取]`、`[可拆解]`、`[可投掷]`、`[可破坏]`、`[可展示]`、`[可燃烧]`、`[可潮湿]`等组件及其属性配置面板 | 策划通过挂载组件即可定义物体的所有交互行为 |
| **角色动作模板** | 拾取、投掷、开门、坐下、躲藏等标准化动画 | 所有角色共享同一套动作，通过IK适配不同体型 |
| **表情形态键库** | 喜怒哀乐惊恐惧 + 撒谎微表情（视线飘忽、嘴唇微颤等） | 所有角色共享表情系统，司命和心智模型自动驱动 |
| **环境状态管理器** | 独立的子系统，负责毫秒级的物理计算（火焰蔓延、流体扩散、物体破碎） | 司命只发高层指令，ESM负责执行，确保延迟可控 |
| **通用音效库** | 脚步声（木地板/石板/草地）、燃烧声、破碎声、门吱呀声、滴水声等 | 所有剧本共用，保证听觉体验的一致性 |
| **角色立绘模板** | 不同时代（古风/民国/现代/科幻）的立绘风格模板 | 创作者上传角色设定后可自动生成风格统一的立绘 |

## 剧本项目资产：创作者的工作台

创作者在制作具体剧本时，主要生产**项目专属资产**，并大量调用和组合**官方基础资产**。

| 项目资产类型 | 说明 | 如何利用基础资产 |
| :--- | :--- | :--- |
| **剧本专属模型** | 列车车厢、贝克街客厅、旅馆房间等特定场景的3D模型 | 场景中的物体挂载基础材质（如“窗帘”挂载`布料`），自动获得燃烧、潮湿等能力 |
| **剧本专属角色** | 福尔摩斯、玛丽、上校等角色的外观模型 | 角色挂载通用表情形态键和动作模板，创作者只需调整外观 |
| **线索物品** | 染血的烛台、烧毁的信件、侦探执照等 | 挂载`[可拾取]`+`[可展示]`+`[可破坏]`等组件，L3特写图可用AI生成 |
| **场景交互配置** | 哪个门可以锁、哪个窗户可以爬、哪个物品是关键线索 | 在编辑器中拖拽组件到物体上，配置属性参数即可 |

## 资产协作流程示例

以创作者制作“列车剧本”中的“可燃烧的窗帘”为例：

1. **场景搭建**：创作者从基础模型库中拖入“维多利亚式窗帘”模型。
2. **材质赋予**：选择材质类型为`布料`。系统自动赋予：可燃性=极高，透水性=高，坚固度=低。
3. **交互挂载**：勾选`[可燃烧]`组件。系统自动关联：燃烧贴图变种`_charring`和`_burned_out`、火焰粒子特效、燃烧音效。
4. **状态机自动生成**：环境状态管理器自动注册该物体的状态转化规则：默认→燃烧（接触火源）→烧毁（持续30秒）。
5. **事件上报自动配置**：物体状态变化时自动向事件总线发送结构化事件，无需手动埋点。

## 官方资产库的持续进化

官方基础资产库不是一次性交付的，而是通过以下方式持续丰富：

| 进化方式 | 说明 |
| :--- | :--- |
| **官方持续开发** | 每个新平行世界发布时，官方会配套制作该世界所需的材质、特效、动作模板 |
| **创作者贡献** | 创作者在市场中出售的高质量资产，官方可收购或签约，纳入基础资产库 |
| **AI辅助生成** | 利用视频生成工作流离线生成新的特效素材（如“魔法阵启动”），存入L3-0原子素材库 |
| **社区Fork进化** | 创作者基于基础材质模板，Fork出变种（如“丝绸”材质继承“布料”但调整参数），丰富材质库 |


**一句话总结**：官方基础资产库是《开本》生态的土壤——提供材质模板、状态变种、通用特效、交互组件、动作模板等底层弹药。创作者在制作剧本时，只需生产专属模型和角色，然后通过挂载材质和组件的方式，让它们自动获得丰富的交互和状态变化能力。这种架构确保了“一次开发，全平台复用”，是《开本》快速扩展剧本宇宙的核心技术保障。
