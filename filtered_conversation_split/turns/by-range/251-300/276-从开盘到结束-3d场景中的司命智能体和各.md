## 全程数据流转总结

| 数据流 | 说明 |
| :--- | :--- |
| **L1→L2（每秒数百条）** | 角色位置更新、物品状态变化、对话事件、微表情触发、环境变化 |
| **L2内部（每角色每秒数次）** | 心智模型决策循环——感知→理解→规划→执行 |
| **L2→L1（每角色按需）** | 对话指令（TTS）、移动指令、动作指令、微表情参数 |
| **L2角色→司命（每次决策后）** | action_report——角色执行了什么行为 |
| **司命内部（按需触发）** | 事实检查（毫秒级）、天平评估（秒级）、干预决策（分钟级） |
| **司命→L2角色（按需）** | impulse（冲动）、fact_reveal（事实披露）、opportunity（暗杀机会） |
| **司命→L1（按需）** | 环境催化指令（天气、灯光、NPC行为） |
| **L2→L3→L1（少数关键节点）** | 视觉增强触发——线索特写生成、呈现 |

**全程算力消耗估算**：
- 5个AI角色×40分钟对话和决策：约200-400次LLM推理
- 其中P2级（云端大模型）占约20%（重要推理），P1/P3（本地小模型）占80%
- 司命的干预和催化：约3-5次大模型推理
- 总成本：约$1-3/局（视模型选型和缓存命中率而定）
