## 三阶段游戏内容支持能力论述

### Phase 1：静态世界内单局剧本

**核心技术能力**：每局剧本是独立的时空，开局初始化、结局归档。L1完整智能体拥有单局内的完整心智模型、人格档案、动态状态和自由对话能力。司命负责事实逻辑检查和基础天平监控。

**可支持的游戏内容**：

**1. 传统剧本杀/谋杀之谜**

这是Phase 1的核心验证品类。《开本》将传统剧本杀从“固定剧本+文字描述+人类DM”升级为“动态涌现+3D沉浸+AI司命”。同一个剧本，每一次开局的凶手身份、作案动机、关键线索位置都由系统随机生成，确保无限重玩价值。

**2. 法庭推理**

如《逆转裁判》式的法庭辩论体验。玩家分饰控辩双方，AI智能体扮演证人和被告。证人的撒谎、崩溃、隐瞒完全由其五维人格参数和当前压力值驱动，而非预设脚本。玩家需要通过交叉质询发现矛盾，而非机械地点击“举证”。

**3. 密室逃脱**

3D场景内的合作解谜。司命可以从谜题库中动态组合谜题，而非每次都是固定的机关顺序。AI同伴可以基于其人格和能力提供不同程度的提示，而非统一难度的“系统提示”。

**4. 无限流单局体验**

如《开端》式的单次时间循环体验。在Phase 1，无限流仅限于**单局内的循环**。玩家在一个固定场景（如公交车、密室）中经历多次循环，每次循环保留记忆，但无法跨剧本积累能力或携带物品。

**5. 社交推理**

如《Among Us》、《鹅鸭杀》式的轻量社交博弈。在Phase 1，这类体验支持8-16人房间（含AI填补），核心机制包括阵营对抗、投票淘汰、简单任务。与传统版本的区别在于：AI内鬼的撒谎和伪装完全由人格驱动，而非随机行为；空间音频让偷听和私密对话成为可能。

**Phase 1明确不支持的内容**：
- 系列剧本（无跨局记忆继承）
- 恋爱养成（无智能体资产化，无法带走角色）
- 种田经营（无持续运行世界）
- SLG策略（无群体模拟和世界推演）


### Phase 2：静态世界内连续单局剧本

**核心技术能力**：剧本种子库+世界状态快照+变量衔接规则，实现前作结局影响续作个性化开局。L1角色新增跨剧本记忆继承。智能体资产化——玩家可以“带走”建立了深厚羁绊的AI角色，在个人空间中互动，或带入其他剧本。

**可支持的游戏内容**：

**1. 系列侦探故事**

如《福尔摩斯》系列、《金田一》系列。这不是单个剧本，而是由多个单局剧本组成的连续叙事。前作中你与福尔摩斯的关系、你揭发的凶手身份、你在终局做出的道德选择——所有这些都会影响续作的开局状态。你不再是一个“与上一局无关的游客”，而是一个“有故事的人”。

**2. 恋爱模拟与AI陪伴**

如《恋与制作人》，但以《开本》的方式呈现。你与AI角色不是通过预设的“好感度任务”推进关系，而是在共同经历的谋杀谜案、阵营博弈中自然产生羁绊。在Phase 2，你可以“带走”这位角色——让它成为你的私人AI同伴。它保留与你的所有互动记忆，可以在个人空间中与你对话，也可以进入其他剧本继续陪伴你。

**3. 选择导向的叙事游戏**

如《底特律：变人》、《直到黎明》，但你的选择后果不限于单局。角色的生死、关系、秘密全部跨局继承。你的某个选择可能导致一个角色在续作中成为你的盟友，另一个角色则成为你的宿敌。这种跨越时间的因果链，是传统选择导向游戏无法提供的深度。

**4. 剧本化身（官方史诗系列）**

由官方创作的、由5-8个单局剧本组成的史诗系列。玩家固定扮演一位传奇角色，经历其完整人生。这不是一个超长的单局，而是局与局之间通过快照继承的系列连续剧。你的每个选择都影响后续剧本的开局状态，最终形成独一无二的个人正史。

**5. IP系列化与社区创作**

创作者可以发布系列剧本包，通过种子库和变量衔接规则，让续集自动承接玩家前作的选择。Fork机制允许其他创作者基于前作创作续集，原作者获得版税分成。这为IP宇宙的社区共建奠定了技术基础。

**Phase 2明确不支持的内容**：
- 持续运行世界（世界仍然是“静态”的，每局结束后销毁或归档）
- 种田经营（无持久资产和世界推演）
- SLG策略（无群体模拟和宏大世界）
- 跨世界旅行（智能体仅能在同一平行世界的剧本系列中使用）


### Phase 3：持续运行世界

**核心技术能力**：司命持续推演时间线（季节/天气/经济/社会事件），世界永不重置。双层玩家身份——穿越旅人（无身份，单局体验）与原住居民（有身份，长期经营）。L2交互角色由群体模拟引擎驱动，数量级可达百万。L1智能体新增跨世界压制与化身系统、私房钱系统、同伴经营AI。

**可支持的游戏内容**：

**1. 种田经营与生活模拟**

如《星露谷物语》，但在《开本》中，你的AI同伴拥有完整人格——它今天不想浇水，想去河边采花；你生日时，它用自己的私房钱给你买礼物；你不在线时，世界仍在运转，作物在生长，商队在行进，季节在更替。你可以将庄园买断下载到本地，作为真正属于你的、永不消失的平行世界。

**2. SLG策略与文明模拟**

如《部落冲突》、《文明》，但在《开本》中，你的国民不是工具，而是拥有独立意志的个体。贵族可能因你的征兵令而叛乱，商人可能因你的贸易禁令而走私，邻国的AI领袖拥有自己的人格和战略风格。战争不仅是兵力的对决，更是经济依赖、供应链博弈、内部政治平衡的综合较量。司命持续推演世界历史，将你的每一次选择写入《世界编年史》。

**3. MMORPG式的活态世界**

如《魔兽世界》、《最终幻想14》，但在《开本》中，NPC不是固定任务发放者。每个NPC都由智能体或群体模拟驱动，能记住你、与你建立关系。世界事件不是预设的版本更新，而是由司命根据所有玩家的行为动态生成。你可以选择成为“穿越旅人”——随时进入体验一场单局冒险；也可以选择成为“原住居民”——在这个世界中拥有庄园、商铺、领地，长期生活。

**4. 开放世界RPG**

如《荒野大镖客2》、《塞尔达传说》，但在《开本》中，随机事件不是预设的。司命根据你的身份、历史、与各势力的关系，动态生成属于你个人的事件链。你遇到的每一个NPC——无论是一个需要帮助的农夫，还是一个暗中跟踪你的密探——都有其独立的身份和动机。

**5. 集体叙事创作**

大玩家可以举办全服参与的大型活动。如“水漫金山”——50名玩家分属不同阵营，AI法海、白素贞、许仙由高级智能体驱动。所有玩家的行为共同决定事件的走向和结局。活动结束后，司命生成一份“金山劫史记”，记录每个玩家的角色和贡献。某些玩家的行为甚至被写入这个世界的永久历史。

**6. 社交推理与派对游戏的升级版**

Phase 1的《鹅鸭杀》式体验在Phase 3获得完整升级：支持16-32人房间，任务系统、角色技能、视野遮挡、监控摄像头、设施破坏等完整机制，以及持续运行的主题世界服务器。

**7. AI同伴的跨世界旅行**

Phase 2中你“带走”的AI同伴，在Phase 3可以随你穿越不同的平行世界。一位来自仙侠世界的剑客，在进入赛博朋克世界时，他的御剑术会被“世界压制”封印，但他对你的忠诚和记忆完整保留。你需要为他购买“世界化身”——一套符合赛博朋克设定的外观和能力适配，让他能在新世界中继续陪伴你。


### 三个阶段的内容支持能力对照

| 游戏类型 | Phase 1 | Phase 2 | Phase 3 |
| :--- | :--- | :--- | :--- |
| 剧本杀/谋杀之谜 | ✅ 单局动态 | ✅ +系列连续剧 | ✅ +持续运行世界中的单局 |
| 社交推理 | ✅ 基础版 | ✅ +角色技能 | ✅ +大型多人+完整机制 |
| 密室逃脱 | ✅ 单局 | ✅ +系列密室 | ✅ +世界中的密室事件 |
| 法庭推理 | ✅ 单局 | ✅ +系列案件 | ✅ +持续运行世界中的法庭 |
| 无限流单局 | ✅ 单局内循环 | ✅ +跨剧本积累 | ✅ +持续运行世界中的无限流 |
| 系列侦探故事 | ❌ | ✅ | ✅ |
| 恋爱模拟/AI陪伴 | ❌ | ✅ 带走+个人空间 | ✅ +跨世界旅行+私房钱 |
| 剧本化身(史诗系列) | ❌ | ✅ | ✅ |
| 选择导向叙事 | ❌ | ✅ 跨局因果 | ✅ +世界级后果 |
| IP系列化与社区创作 | ❌ | ✅ Fork+种子库 | ✅ +世界内的IP生态 |
| 种田经营 | ❌ | ❌ | ✅ |

**一句话总结**：Phase 1验证“单局内的角色是否足够像真人”；Phase 2验证“玩家是否愿意为跨局羁绊付费”；Phase 3验证“大玩家是否愿意经营一个世界，玩家是否愿意在其中长期生活”。三个阶段从“玩一个剧本”到“爱上一个角色”到“活在一个世界”，层层递进，最终汇聚成《开本》的终极形态。
