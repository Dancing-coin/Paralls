## 用户

一个剧本所对应的环境空间，人物以及物品是有限的，交互和变形状态虽多，但也是有限的，因此我们的美术资产需要分多少类？ 以刚才的列车剧本为例

## DeepSeek

以《东方快车》为例，美术资产需要按**功能性层级**进行分类，而不是按传统的“场景/角色/道具”简单划分。核心原则是：**根据物体的可交互性和可变性来决定其资产复杂度**，越“活”的物体需要越多的状态变种。

---

## 美术资产功能性分类体系

### 一、静态装饰资产（零交互，仅视觉）

这类资产不参与任何交互，没有状态变化，制作成本最低。

| 子类 | 列车剧本示例 | 资产内容 |
| :--- | :--- | :--- |
| **远景/天空盒** | 窗外暴风雪远景、雪山、隧道 | 1套动态天空盒（含暴风雪粒子） |
| **固定装饰** | 墙壁浮雕、天花板灯座、壁画、地毯花纹 | 基础贴图/模型，无变种 |
| **小型摆设** | 餐桌上的花瓶（不可拿起）、墙上的时钟 | 基础模型+贴图 |


### 二、可操作资产（有限状态，预设交互）

这类资产有固定的几种状态，通过预设交互切换，状态数量有限且可枚举。

| 子类 | 列车剧本示例 | 状态变种 | 交互方式 |
| :--- | :--- | :--- | :--- |
| **可开关类** | 车厢门、包厢门、列车尾部窗户、窗帘（拉开/拉上） | 开/关（2态） | 点击开关 |
| **可开闭容器类** | 抽屉、行李箱、床头柜、保险箱 | 开/关/锁住（2-3态） | 点击开闭，锁住时需要钥匙 |
| **可点亮类** | 煤油灯、壁灯、蜡烛 | 亮/灭（2态） | 点击开关 |
| **可坐卧类** | 餐车椅子、包厢床铺 | 空/被占用（2态） | 点击坐下/起身 |
| **可锁类** | 包厢门锁、保险箱密码锁 | 锁住/解锁（2态） | 使用钥匙/破解密码 |


### 三、物理响应资产（多状态，环境驱动）

这类资产会响应环境变化（火、水、力），需要多状态变种，是制作成本最高的类别。

| 子类 | 列车剧本示例 | 状态变种 | 触发条件 |
| :--- | :--- | :--- | :--- |
| **可燃烧类** | 窗帘、桌布、床单、纸张、木质家具、车厢壁板 | 正常→焦黑→烧毁残骸（3态）+ 燃烧中粒子特效 | 接触火源 |
| **可潮湿类** | 地毯、布料、木质桌面、纸张 | 正常→潮湿（颜色加深）（2态）+ 水滴粒子 | 接触水源 |
| **可破碎类** | 玻璃窗、酒瓶、花瓶、瓷器、镜子 | 正常→裂纹→破碎几何体（2-3态）+ 碎片粒子 | 物理冲击 |
| **可变形类** | 金属餐盘、门锁、钥匙 | 正常→凹陷/弯曲（2态） | 物理冲击 |
| **可移动类** | 椅子、行李箱、餐车推车、尸体（？） | 位置变化（无状态变种，但需要可移动的物理属性） | 玩家推动/拖拽 |


### 四、可收集/可携带资产

这类资产可以被玩家拾取并放入背包，有独立的世界模型和背包图标。

| 子类 | 列车剧本示例 | 资产内容 |
| :--- | :--- | :--- |
| **线索物品** | 染血的匕首、烧毁的信件、遗嘱草稿、侦探执照 | 世界模型 + 背包图标 + L3特写图 |
| **工具物品** | 钥匙、开锁器、打火机、留影石/相机 | 世界模型 + 背包图标 + 使用动画 |
| **伪装道具** | 假发、化妆品、假证件 | 世界模型 + 背包图标 |
| **消耗品** | 药品、毒药、酒瓶 | 世界模型 + 背包图标 + 使用效果 |


### 五、角色资产

| 子类 | 列车剧本示例 | 资产内容 |
| :--- | :--- | :--- |
| **角色模型** | 波洛、布克、玛丽、上校、哈伯德、麦奎因 | 基础模型 + 服装变种 |
| **表情形态键** | 所有角色 | 喜怒哀乐惊恐惧 + 撒谎微表情 |
| **动作动画** | 所有角色 | 行走/奔跑/坐下/举手/拍桌/拥抱/后退/颤抖等 |
| **角色立绘** | 所有角色 | 预生成立绘 + 情绪变体 |


## 以《东方快车》为例的资产数量估算

| 资产类别 | 子类数量 | 模型/贴图数量（估算） | 状态变种数量 | 总资产条目（估算） |
| :--- | :--- | :--- | :--- | :--- |
| **静态装饰** | 约30件 | 30个基础模型 | 0 | 30 |
| **可操作资产** | 约25件 | 25个基础模型 | 2态×20 = 40 | 65 |
| **物理响应资产** | 约15件 | 15个基础模型 | 平均2.5态×15 = 38 | 53 |
| **可收集物品** | 约15件 | 15个世界模型+15个图标 | 0 | 30 |
| **粒子特效** | — | — | 火焰/烟雾/水滴/碎片等约10套 | 10 |
| **角色资产** | 6人 | 6个角色模型 | 每人约10个表情+20个动作 | 约200 |
| **总计** | — | — | — | **约400条资产条目** |


## 原子化资产与组合

为了减少制作量，我们对物理响应资产采用 **“原子化材质变种 + 通用特效”** 的策略：

| 材质类型 | 涉及物品 | 需要的通用变种 | 特效 |
| :--- | :--- | :--- | :--- |
| **布料** | 窗帘、桌布、床单 | 焦黑贴图、潮湿贴图 | 布料燃烧粒子、布料撕裂粒子 |
| **木材** | 桌椅、壁板、地板 | 焦黑贴图、潮湿贴图、裂纹贴图 | 木柴燃烧粒子、木屑粒子 |
| **玻璃** | 窗户、酒瓶、镜子 | 裂纹贴图 | 玻璃碎片粒子 |
| **金属** | 餐盘、门锁、钥匙 | 凹陷变形贴图 | 金属碰撞火花粒子 |
| **纸张** | 信件、文件、书籍 | 焦黑贴图、潮湿贴图 | 纸张燃烧粒子 |

**这样，15件物理响应资产不需要每件单独制作燃烧特效，而是共享5套材质变种 + 5套粒子特效，通过材质参数调整产生差异化表现。**


**一句话总结**：以列车剧本为例，美术资产需要分为静态装饰、可操作资产、物理响应资产、可收集物品、角色资产五大类，总计约400条资产条目。其中物理响应资产的制作量最大，通过原子化材质变种和通用特效的共享复用，可以有效控制成本。
