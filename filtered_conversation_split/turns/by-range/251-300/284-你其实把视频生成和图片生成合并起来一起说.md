## 图片生成 vs 视频生成：严格区分

| 维度 | 图片生成 | 视频生成 |
| :--- | :--- | :--- |
| **产出物** | 静态图片（PNG/WebP） | 动态视频片段（MP4，2-5秒） |
| **生成时间** | 1-3秒（可实时） | 分钟级（不可实时） |
| **Token消耗** | 中等 | 极高（是图片的10-50倍） |
| **适用场景** | 静态细节、定格瞬间 | 动态回忆、氛围渲染、离线CG |
| **实时性** | 可在游戏内实时触发 | 仅用于异步生成或预生成 |
| **在《开本》中的角色** | 实时增强层 | 离线素材库 |


## 一、图片生成的适用场景（实时可用）

图片生成在《开本》中用于**需要实时呈现的静态细节**——玩家主动触发、有自然停顿、需要清晰视觉信息的时刻。

| 场景 | 说明 | 时机 |
| :--- | :--- | :--- |
| **公开搜证展示** | 玩家点击“展示”按钮，向所有人展示线索物品的细节特写 | 实时触发 |
| **角色立绘** | 查看角色档案时显示，含情绪变体 | 预生成，即时调用 |
| **场景概念图** | 进入新场景时的加载画面 | 预生成，即时调用 |
| **凝神深度观察** | 单人/AI模式下暂停时间，对某物品进行“放大镜”式观察 | 实时触发 |
| **结局CG** | 本局故事报告的封面图 | 异步生成 |


## 二、视频生成的适用场景（仅离线/预生成）

视频生成在《开本》中**绝不用于实时场景**。它的生成时间（分钟级）决定了它只能作为离线素材库，为实时演算提供无法实时渲染的动态素材。

| 场景 | 说明 | 时机 |
| :--- | :--- | :--- |
| **风格化记忆闪回** | 当AI角色讲述往事时，呈现一段非写实风格（油画/水彩/老电影）的2-3秒短片 | **预生成**——剧本创作阶段为关键回忆节点预先生成 |
| **复杂特效素材** | 魔法阵启动、幽灵浮现、时空裂缝等超越实时渲染能力的动态效果 | **预生成**——作为透明通道素材存入原子素材库，供实时演算调用 |
| **动态环境素材** | 暴风雪中的远景、极光流转、火焰特效等作为场景背景板的动态素材 | **预生成**——存入L3-0原子素材库 |
| **玩家纪念短片** | 游戏结束后，为本局故事生成一段精华剪辑 | **异步生成**——无实时要求 |


## 三、为什么视频生成不能用于实时场景？

| 原因 | 说明 |
| :--- | :--- |
| **生成时间不可控** | 视频生成需要分钟级，远超实时交互的3秒硬上限 |
| **Token消耗极高** | 一段2秒视频的Token消耗是图片的10-50倍，实时触发会瞬间耗尽单局配额 |
| **无法交互** | 视频生成后是固定内容，无法自适应玩家当前的装扮、位置、场景状态 |
| **替代方案已存在** | 绝大多数动态场景可通过实时演算实现——对峙、坦白、逃脱等高潮，司命的镜头调度+角色智能体的自主表演，就是最好的“实时视频” |


## 四、视频生成的真正价值：素材库积累

视频生成在《开本》中的核心角色是**为实时演算提供“无法实时渲染”的动态素材**。

```
视频生成（离线/预生成）
    │
    ├── 风格化记忆闪回片段 → 存入种子库 → 游戏内被司命调用（P0完美调用，<100ms）
    ├── 复杂特效素材 → 存入L3-0原子素材库 → 实时演算时叠加在3D场景上
    ├── 动态环境素材 → 存入L3-0原子素材库 → 作为场景背景板实时渲染
    └── 玩家纪念短片 → 异步生成 → 存入玩家个人相册
```

**关键逻辑**：视频生成是“投资”而非“消费”——每次生成都在丰富素材库，让未来的实时演算更强大、更丰富、成本更低。


## 五、在具体剧本中的分工示例

以《东方快车·雪夜杀机》为例：

| 场景 | 使用技术 | 说明 |
| :--- | :--- | :--- |
| 波洛发现伤口线索 | **图片生成**（实时） | 线索特写——静态细节，玩家主动观察 |
| 哈伯德太太坦白 | **实时演算** | 动态事件——毫秒级交互，镜头调度 |
| 麦奎因坦白 | **实时演算** | 动态事件——毫秒级交互，镜头调度 |
| 麦奎因讲述阿姆斯特朗案 | **视频生成**（预生成） | 2-3秒风格化闪回——非写实风格，暗示“回忆” |
| 上校点火逃脱 | **实时演算** | 动态事件——毫秒级交互，动作场面 |
| 暴风雪加剧 | **实时演算**（主）+ **视频生成素材**（辅） | 窗外的暴风雪远景使用预生成的动态素材作为天空盒 |
| 结局CG | **图片生成**（异步） | 静态纪念图，无需动态 |


**一句话总结**：图片生成用于**实时的、静态的、玩家主动触发的细节呈现**；视频生成用于**离线的、动态的、风格化的素材积累**——它绝不参与实时交互，而是作为素材库为实时演算提供弹药。两者在《开本》中分工明确，不可混淆。
