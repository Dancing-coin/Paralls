## 用户

那对于场景中可交互的物体，比如烛台可以被拿起来，可以被拆开，可能摔到地上摔断，这些东西怎么设计，这些交互动作怎么设计？也是需要一个底层资产库以供调用吧？

## DeepSeek

这正是《开本》快速开发不同剧本的核心需求。我们不能让每个剧本的“烛台”都单独写一套交互逻辑，而是要建立一套**可复用的交互组件库 + 原子化动作库 + 状态变种资产库**，让策划像搭积木一样组合出物体的所有交互行为。

---

## 一、核心架构：组件化交互系统

每个可交互物体不是“一个模型+一段代码”，而是**一个模型 + 多个交互组件 + 一个状态管理器**。

```
可交互物体（如“烛台”）
├── 基础属性：名称、描述、材料类型（金属）
├── 交互组件（可组合挂载）
│   ├── [可拾取] → 进入背包
│   ├── [可拆解] → 分解为零件
│   ├── [可投掷] → 投掷后触发碰撞
│   ├── [可破坏] → 受力后碎裂/断裂
│   ├── [可燃烧] → 接触火源后燃烧
│   ├── [可潮湿] → 接触水源后湿润
│   └── [可展示] → 公开展示/私下分享
├── 状态机（由交互组件驱动）
│   ├── 默认态 → 手持态 → 投掷态 → 断裂态 → 燃烧态
│   └── 每个状态对应不同的3D模型/贴图/特效
└── 事件上报（状态变化时向事件总线发送结构化事件）
```

**策划的工作流程**：
1. 放置一个“烛台”模型
2. 挂载`[可拾取]`、`[可拆解]`、`[可投掷]`、`[可破坏]`、`[可展示]`组件
3. 在属性面板中配置每个组件的参数（如投掷伤害=5，破坏所需力度=中等）
4. 完成。无需写代码。


## 二、交互组件库

### 2.1 可拾取 (Pickable)

| 属性 | 说明 | 示例值 |
| :--- | :--- | :--- |
| 拾取动画 | 角色伸手拾取的动画模板 | 单手拾取/双手拾取/弯腰拾取 |
| 背包图标 | 物品在背包中的缩略图 | `icon_candlestick.png` |
| 背包分类 | 放入背包的哪个标签页 | 线索/工具/武器/伪装道具/消耗品 |
| 拾取音效 | 拾取时播放的音效 | 金属碰撞声/布料摩擦声 |
| 是否可丢弃 | 拾取后是否可以放回场景 | true/false |

### 2.2 可拆解 (Deconstructable)

| 属性 | 说明 | 示例值 |
| :--- | :--- | :--- |
| 拆解产物 | 拆解后生成的子物品列表 | `["烛台底座", "蜡烛", "烛台尖刺"]` |
| 拆解工具 | 需要什么工具才能拆解 | 徒手/螺丝刀/锤子 |
| 拆解时间 | 拆解需要多少秒 | 3秒 |
| 拆解技能要求 | 需要什么技能等级 | 无/工程学Lv1 |
| 是否可逆 | 拆解后是否可以组装回去 | true/false |
| 拆解后原物体状态 | 原物体是否消失 | 消失/变为“拆解后的残骸” |

### 2.3 可投掷 (Throwable)

| 属性 | 说明 | 示例值 |
| :--- | :--- | :--- |
| 投掷动画 | 角色投掷的动画模板 | 过肩投掷/低手抛掷 |
| 投掷距离 | 最大投掷距离（米） | 10米 |
| 投掷伤害 | 击中角色时的伤害值 | 5（造成轻伤+淤青） |
| 碰撞音效 | 落地时播放的音效 | 金属落地声/玻璃碎裂声 |
| 破碎条件 | 投掷后是否必定破碎 | 是/取决于落地材质（地毯不碎，石地必碎） |
| 投掷后状态 | 投掷后物体的状态 | 保持原状/破碎/可被重新拾取 |

### 2.4 可破坏 (Breakable)

| 属性 | 说明 | 示例值 |
| :--- | :--- | :--- |
| 破坏方式 | 如何触发破坏 | 投掷/锤击/高处坠落/火烧 |
| 破坏阈值 | 需要多大的力或冲击 | 中等（投掷到硬地面即可） |
| 破坏后产物 | 破坏后生成的碎片/零件 | `["断裂的烛台底座", "弯曲的烛台尖刺"]` |
| 破坏后模型 | 破坏后的3D模型变种 | `candlestick_broken.glb` |
| 破坏粒子特效 | 破坏时播放的特效 | 金属碎片粒子 |
| 破坏音效 | 破坏时播放的音效 | 金属断裂声 |
| 是否可修复 | 破坏后是否可以修复 | 是（需要工具）/否 |

### 2.5 可展示 (Displayable)

| 属性 | 说明 | 示例值 |
| :--- | :--- | :--- |
| 展示动画 | 角色展示物品时的动画 | 高举/手持平伸 |
| 展示语音 | 角色展示时自动说的台词 | “各位，请看这个” |
| L3触发 | 是否触发线索特写生成 | 是（线索物品）/否（普通物品） |
| 展示后状态 | 展示结束后物品的状态 | 回到手中/放回背包 |


## 三、交互动作库

交互动作库定义了一套标准化的角色动画模板，所有可交互物体调用同一套动作，而非每个物体单独制作动画。

### 3.1 手部交互动作

| 动作ID | 动作名称 | 适用场景 | 动画时长 |
| :--- | :--- | :--- | :--- |
| `hand_pickup_one` | 单手拾取 | 小型物品（钥匙、匕首、信件） | 0.5s |
| `hand_pickup_two` | 双手拾取 | 大型物品（烛台、书籍、盒子） | 0.7s |
| `hand_hold_high` | 高举展示 | 公开展示证据 | 循环 |
| `hand_hold_forward` | 手持平伸 | 私下分享证据 | 循环 |
| `hand_throw_overarm` | 过肩投掷 | 投掷物品 | 0.8s |
| `hand_throw_underarm` | 低手抛掷 | 轻抛物品 | 0.5s |
| `hand_open_drawer` | 拉开抽屉 | 容器交互 | 0.6s |
| `hand_open_door` | 推开门 | 门的交互 | 0.8s |
| `hand_strike` | 挥击 | 使用物品攻击 | 0.4s |
| `hand_place` | 放置物品 | 将物品放回场景 | 0.5s |

### 3.2 身体交互动作

| 动作ID | 动作名称 | 适用场景 | 动画时长 |
| :--- | :--- | :--- | :--- |
| `body_sit` | 坐下 | 椅子交互 | 1.0s |
| `body_kneel` | 跪下检查 | 检查地面线索 | 0.8s |
| `body_hide` | 躲藏 | 进入柜子/窗帘后 | 1.2s |
| `body_climb` | 攀爬 | 翻越窗户/障碍物 | 1.5s |
| `body_push` | 推重物 | 移动家具 | 循环 |
| `body_strike` | 重击 | 破坏物品 | 0.6s |


## 四、状态变种资产库

每个物体的每种状态对应一个3D模型变种或贴图变种，状态切换时模型/贴图/特效同步替换。

| 状态类型 | 模型变种命名规则 | 贴图变种 | 特效 |
| :--- | :--- | :--- | :--- |
| **默认态** | `item_name.glb` | 默认贴图 | 无 |
| **手持态** | 使用默认模型 + IK手部绑定 | — | 微弱光晕（金/蓝） |
| **投掷态** | 默认模型 + 物理运动轨迹 | — | 运动模糊 |
| **断裂态** | `item_name_broken.glb` | — | 碎片粒子（金属/玻璃/木质） |
| **燃烧态** | 默认模型 | `_charring` 焦黑贴图 | 火焰粒子 + 烟雾粒子 |
| **烧毁态** | `item_name_burned.glb`（残骸模型） | `_burned_out` 灰烬贴图 | 余烬粒子 |
| **潮湿态** | 默认模型 | `_wet` 深色湿润贴图 | 水滴粒子 |
| **结冰态** | 默认模型 + 冰壳几何体 | `_iced` 霜冻贴图 | 冷气粒子 |


## 五、与事件总线的协同

每次物体状态变化时，状态管理器自动向事件总线发送结构化事件。

```json
{
  "event_type": "item_state_changed",
  "item_id": "candlestick_01",
  "actor_id": "char_player_A",
  "previous_state": "默认态",
  "new_state": "断裂态",
  "trigger_action": "投掷到石地板上",
  "location": {"x": 3.5, "y": 0, "z": 2.1},
  "timestamp": "2026-05-20T19:15:23Z",
  "audible_range": 15.0,
  "visible_to": ["char_B", "char_C"]
}
```

**事件接收方**：
- **角色智能体感知过滤器**：附近AI角色收到“听到金属断裂声”的听觉事件
- **司命**：更新事实核心，评估是否催化叙事
- **L3视觉增强**：若为关键线索被破坏，触发WOW时刻


## 六、策划配置示例

以“烛台”为例，策划在编辑器中的配置面板：

```
物品名称：染血的烛台
基础模型：candlestick_default.glb
材料类型：金属

已挂载组件：
☑ 可拾取 → 单手拾取 | 背包分类：线索 | 可丢弃
☑ 可拆解 → 产物：烛台底座+蜡烛+烛台尖刺 | 徒手 | 3秒 | 不可逆
☑ 可投掷 → 过肩投掷 | 最大距离10m | 伤害5 | 碰撞音效：金属落地
☑ 可破坏 → 投掷到硬地面时碎裂 | 产物：断裂底座+弯曲尖刺 | 破碎模型：candlestick_broken.glb | 不可修复
☑ 可展示 → 公开展示 | L3触发：是 | 展示语音：“各位，请看这个”
```


**一句话总结**：场景中可交互物体的设计采用“组件化交互系统 + 标准化动作库 + 状态变种资产库”三层架构。策划通过挂载`[可拾取]`、`[可拆解]`、`[可投掷]`、`[可破坏]`、`[可展示]`等组件即可定义物体的所有交互行为，无需编写代码。所有交互动作调用同一套角色动画模板，所有状态变化调用同一套模型/贴图/特效变种资产。
