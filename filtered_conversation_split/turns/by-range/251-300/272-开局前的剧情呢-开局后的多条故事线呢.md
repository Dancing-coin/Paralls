## 一、开局前的固定剧情

这是剧本创作时必须写死的部分，是所有变化中的不变基石。

### 1.1 叙事结构

```
[世界背景] → [人物传记] → [关键事件] → [案发前夕] → [当前状态]
```

### 1.2 固定剧情要素

| 模块 | 内容 | 格式 |
| :--- | :--- | :--- |
| **世界背景** | 时代、地域、社会规则、特殊设定 | 叙事短文（500-1000字） |
| **人物传记** | 每个角色的真实背景、人生记忆、核心秘密 | 每人300-500字的叙事 |
| **关键事件** | 导致当前局面的历史事件时间线 | 时间线条目，含时间、事件、涉及角色、影响 |
| **案发前夕** | 开本前24小时内各角色的行踪和互动 | 逐小时的叙事记录 |
| **当前状态** | 开本时所有角色已知的信息 | 结构化JSON，驱动司命初始化 |

### 1.3 《血字的研究》开局前剧情示例

**世界背景**：
> 1890年深秋的伦敦，工业革命的煤烟将城市笼罩在永恒的灰色中。雾都的犯罪率在过去五年中翻了三倍，苏格兰场疲于奔命。在这个时代，财富与贫穷并存——萨瑟兰先生的商业帝国横跨大西洋两岸，而他的雇工们住在东区的贫民窟里。

**玛丽的人生记忆**：
> 玛丽·萨瑟兰出生在伦敦一个体面但日渐衰败的商人家庭。12岁那年，父亲破产，她从女校辍学。18岁时，为了挽救家族的名誉，她被父亲许配给了比她大20岁的富商萨瑟兰先生。婚后的生活并不幸福——丈夫冷漠、控制欲强、从不尊重她的意见。25岁那年，她发现丈夫企图将她母亲留下的传家宝——一串珍珠项链——卖给亨利·贝克，以周转他那摇摇欲坠的生意。这是她唯一的念想，也是她对母亲最后的记忆。那天晚上，他们在旅馆房间爆发了结婚以来最激烈的争吵……

## 二、开局后的多条故事线

这是司命在开本后实时创作的部分。不是写死的剧情分支，而是**通过种子池中的随机元素、分支点触发和司命催化，涌现出的无限叙事变体**。

### 2.1 故事线的构成

一条完整的故事线不是线性剧本，而是由以下要素在运行时组合而成：

```
[初始案件] + [角色策略] + [司命催化] + [玩家选择] = [唯一的故事线]
```

### 2.2 随机元素：开局时的差异之源

| 随机元素 | 来源 | 产生差异的方式 |
| :--- | :--- | :--- |
| **凶手身份** | 从满足作案条件的AI角色中随机选择 | 同一组角色，不同局的凶手不同 → 不同局完全不同的推理方向 |
| **作案动机** | 从动机池中随机选择 | 同一凶手，不同动机 → 不同的秘密需要隐瞒 → 不同的谎言 |
| **凶器** | 从凶器池中随机选择 | 同一案件，不同凶器 → 不同的线索指向 → 不同的搜证重点 |
| **核心线索子集** | 从线索池中随机抽取5-8条 | 同一剧本，不同线索 → 不同的推理路径 |
| **不在场证明** | 部分角色随机决定 | 华生可能有人证明他一直在诊所，也可能无人能证明 |

### 2.3 分支点：玩家选择导致故事分岔

| 分支点 | 玩家选项 | 对故事线的影响 |
| :--- | :--- | :--- |
| **是否公开关键证据** | 私下保留 / 公开讨论 / 向某人展示 | 信息不对称格局改变 → 其他角色的策略改变 → 结局改变 |
| **面对暗杀弹窗** | 执行 / 放弃 | 执行→新案件、新死者、新调查方向；放弃→当前局势继续 |
| **投票时选择谁** | 投票选项 | 直接影响结局 |
| **是否接受司命的冲动** | 遵从 / 忽略 | 遵从→可能发现新线索或暴露自己；忽略→故事线保持当前方向 |
| **是否坦白秘密** | 坦白 / 继续隐瞒 | 坦白→真相大白，但可能失去胜利；隐瞒→维持伪装但压力增加 |

### 2.4 司命催化：系统主动创造的叙事变数

| 催化手段 | 触发条件 | 产生的叙事变数 |
| :--- | :--- | :--- |
| **环境催化** | 推理陷入僵局 / 某一方过于强势 | 新线索浮现、天气变化困住众人、NPC恰好出现在关键地点 |
| **NPC引导** | 某个NPC拥有关键信息但未透露 | NPC主动找玩家私聊、NPC“意外”说漏嘴 |
| **暗杀机会** | 检测到致命动机+信息空窗期+独处窗口 | 弹窗确认→新案件→全新调查方向 |
| **节奏控制** | 进展过快或过慢 | 引入次要事件分散注意力 / 加速讨论推进 |

### 2.5 多结局路径

同一次开本，可能走向以下任一结局：

| 结局 | 典型路径 |
| :--- | :--- |
| **正义伸张** | 关键证据被公开→投票指认真凶 |
| **真凶逃脱** | 真凶成功隐藏证据→嫁祸他人→投票指认无辜者 |
| **冤案** | 无辜者被误导的证据指向→众人被说服→投票指认无辜者 |
| **隐藏结局** | 满足特定条件组合（如发现艾琳的真实身份+玛丽主动坦白+和解） |
| **全员覆灭** | 暗杀连锁→多名角色死亡→真相永远埋藏 |

**一句话总结**：开局前的剧情是编剧写死的“锚”——世界背景、人物传记、历史事件、案发前夕状态；开局后的故事线是司命实时创作的“枝”——通过随机元素（凶手/动机/凶器/线索）、玩家选择（公开/暗杀/投票/坦白）、司命催化（环境/NPC/暗杀机会/节奏）三者相互作用，涌现出无限条独一无二的故事线，最终走向不同的结局。
