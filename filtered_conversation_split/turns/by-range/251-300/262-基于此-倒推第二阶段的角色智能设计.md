# 第二阶段角色智能体设计方案

## 一、核心定位

第二阶段的核心特征是 **“静态世界内连续单局剧本”**——世界本身不持续运行，但局与局之间通过世界状态快照和变量衔接规则继承。因此，第二阶段的角色智能体设计围绕一个关键目标：**验证“跨局羁绊”和“智能体资产化”的可行性，同时为第三阶段的宏大世界模拟做好技术预演。**

与第三阶段相比，第二阶段不需要：
- 百万级群体角色的模拟（L3群体角色在第二阶段不存在）
- 世界持续推演引擎（司命不需要驱动季节、经济、社会变化）
- 双层玩家身份系统（穿越旅人和原住居民的区分在第三阶段才需要）

第二阶段需要重点验证：
- **跨剧本记忆继承**：角色能否在多个单局剧本之间保持记忆连续性？
- **智能体资产化**：玩家能否“带走”剧本中建立羁绊的AI角色？
- **续集个性化承接**：前作结局如何通过快照影响续作开端？


## 二、第二阶段角色分层

| 层级 | 角色类型 | 驱动方式 | 数量级 | 核心特征 |
| :--- | :--- | :--- | :--- | :--- |
| **L1 完整智能体** | 剧本角色（玩家角色、核心NPC）、被带走的AI同伴 | 完整心智模型 (LLM推理 + 人格档案 + 记忆) | 每剧本5-8人 | 独立人格、自由对话、跨剧本记忆 |
| **L2 交互角色** | 剧本中的次要NPC（管家、女仆、卫兵等） | 轻量级智能体 (预设模板 + 有限记忆) | 每剧本数人至十数人 | 有基本身份和有限记忆，可对话但对话深度有限 |
| **L3 程序角色** | 纯功能性NPC（远处路人、一次性线索提供者） | 程序行为树 (无独立人格) | 每剧本数人 | 无独立人格，仅执行预设行为，不可对话 |

**与第三阶段的关键区别**：
- 第二阶段没有L3群体角色（百万级背景角色）。第二阶段的L3是程序角色，数量极少，仅用于填充剧本场景
- 第二阶段的L2交互角色不需要“群体模拟”和“种子档案”——它们由剧本创作者在编辑器中手动配置，而非由系统自动生成
- 第二阶段不需要“按需注入智能体”——因为角色总数少，所有L1和L2角色在剧本开始时就可以初始化


## 三、L1 完整智能体

这是第二阶段的核心角色类型，复用Phase 1的完整心智模型，新增跨剧本能力。

### 3.1 心智模型（与Phase 1相同）

- **L1 感知层**：接收结构化语义事件（视觉、听觉、触觉等），由感知过滤器按角色感官过滤
- **L2 理解层**：解读信息、更新信念、生成推论、更新情绪状态、输出内心独白
- **L3 规划层**：基于动机（恐惧/目标/社交/好奇）生成候选行动，人格过滤，优先级排序
- **L4 执行层**：生成对话文本/情绪参数/动作指令/微表情/小动作

### 3.2 人格档案（与Phase 1相同）

- 基因种子 → 人生记忆 → 品格层（道德取向、价值优先级）→ 行为层（五维人格参数）
- 三重过滤器：人设过滤器 + 逻辑过滤器 + 得失过滤器
- 动态状态：压力值、信任值、怀疑值、情绪标签

### 3.3 第二阶段新增：跨剧本记忆系统

这是第二阶段与Phase 1的最大区别。Phase 1中每局结束记忆清空；第二阶段中，某些角色的记忆会在局与局之间保留。

**记忆类型**：

| 记忆类别 | 内容 | 跨剧本继承方式 |
| :--- | :--- | :--- |
| **身份记忆** | 我是谁、我的背景、我的秘密、我的人格参数 | 始终保留（剧本系列内） |
| **事件记忆** | 我亲身经历的所有事件（时间戳+地点+事件描述+涉及人物） | 按时间线约束保留（续集可见前作，前传不可见未来） |
| **关系记忆** | 我对其他角色的信任值、怀疑值、好感度 | 按快照继承，续集中作为初始关系状态 |
| **高阶记忆** | 关于“他人知道什么”的推理 | 按快照继承 |

**关键约束**：
- 不是所有角色都保留跨剧本记忆。只有被标记为“系列角色”的L1角色才保留
- 跨剧本记忆受时间线约束：续集可以继承前作记忆，前传不能预知未来

### 3.4 第二阶段新增：智能体资产化

这是第二阶段最核心的商业验证点。玩家在剧本结束时，可以“带走”建立了深厚羁绊的AI角色。

**带走条件**：
- 该AI角色与玩家的信任值/好感度达到阈值（如≥7）
- 该角色在结局中存活
- 玩家主动点击“邀请同行”

**带走流程**：
1. 剧本结束后，在结局展示界面，玩家点击“邀请同行”按钮
2. 司命判断关系数据是否达标
3. 若达标，触发“坦白与契约”叙事仪式——玩家向AI角色坦白“穿梭者”身份
4. AI角色基于人格决定是否接受
5. 若接受，该角色的完整人格档案 + 本局关键记忆摘要 + 与玩家的关系数据被打包保存
6. 该角色出现在玩家的个人空间中

**带走后的能力**：
- 可在个人空间中与玩家进行基础对话（基于其人格档案和记忆）
- 可被带入其他剧本（Phase 2支持，但受剧本兼容性限制）
- 可更换外观皮肤

**与第三阶段的关键区别**：
- 第二阶段带走的智能体**仅能在同一平行世界的剧本系列中使用**，不能跨世界旅行
- 智能体的“私房钱”系统在第二阶段**不存在**——这是第三阶段的功能
- 智能体的“跨世界压制”在第二阶段**不存在**——因为不支持跨世界旅行


## 四、L2 交互角色

这是第二阶段为丰富剧本体验而设计的次要NPC。它们不是完整的智能体，但比Phase 1的纯程序NPC更丰富。

### 4.1 核心特征

| 维度 | 说明 |
| :--- | :--- |
| **驱动方式** | 轻量级智能体（预设人格模板 + 剧本定义的知识范围 + 有限对话能力） |
| **人格来源** | 剧本创作者在编辑器中为该角色选择预设人格模板（如“忠厚老仆”、“毒舌女仆”） |
| **知识范围** | 由剧本创作者定义该角色“知道什么”——仅限于其身份应该知道的信息 |
| **对话能力** | 支持基于模板的自由对话，但深度有限。不会主动发起复杂推理 |
| **跨剧本记忆** | 仅在剧本系列内保留少量关键记忆（如“曾被国王赦免”），细节可能模糊 |

### 4.2 技术规格

| 规格 | 说明 |
| :--- | :--- |
| **模型** | 本地小模型（如llama 1-3B），延迟200-500ms |
| **记忆体** | 轻量记忆库（仅存储本剧本内的关键事件和与玩家的互动摘要） |
| **人格模板** | 由剧本创作者在编辑器中选择，而非AI自主生成 |
| **知识范围** | 由剧本创作者手动定义，不自动从事实数据库推理 |

### 4.3 与第三阶段L2的关键区别

| 维度 | 第二阶段L2 | 第三阶段L2 |
| :--- | :--- | :--- |
| **角色来源** | 剧本创作者手动配置 | 群体模拟引擎自动生成 |
| **人格来源** | 预设模板（创作者选择） | trait_seed + 群体共享记忆自动推导 |
| **激活方式** | 剧本开始时初始化 | 玩家接触时按需注入 |
| **跨剧本记忆** | 仅剧本系列内保留少量关键记忆 | 完整个人记忆档案（升格存储+压缩+剧情杀兜底） |
| **数量** | 每剧本数人至十数人 | 数十万至百万级 |


## 五、L3 程序角色

这是第二阶段最简单的角色类型，用于填充场景但不参与复杂交互。

| 维度 | 说明 |
| :--- | :--- |
| **驱动方式** | 程序行为树（预设行为模式，无独立人格） |
| **典型角色** | 远处路人、巡逻卫兵（仅提供背景存在感）、一次性线索提供者（仅提供一条固定信息） |
| **对话能力** | 无可交互对话，或仅返回1-2句预设台词 |
| **配置方式** | 剧本创作者在编辑器中放置角色并选择行为脚本 |


## 六、司命在第二阶段的能力

| 能力 | 说明 |
| :--- | :--- |
| **事实核心** | 时间线管理+逻辑一致性检查（与Phase 1相同） |
| **知识图谱** | 一阶/二阶/三阶知识追踪+不确定态管理 |
| **天平系统** | 线索分布均衡度+阵营胜率预测+玩家参与度+游戏节奏监控 |
| **干预执行器** | 四层干预阶梯（冲动/环境/NPC引导/节奏控制） |
| **暗杀催化** | 动机监测+可玩性评估+条件排列+弹窗确认 |
| **冲突与案件生成器** | 新案件生成流程（动机/能力/人格/叙事价值评估） |
| **种子库管理** | 剧本种子库存储+世界状态快照存储+变量衔接规则配置 |
| **续集承接逻辑** | 读取前作快照→匹配续集分支→注入变量→生成个性化开局 |
| **带走机制管理** | 判断关系数据是否达标、触发坦白与契约叙事仪式、打包保存角色数据 |

**与第三阶段的关键区别**：
- 司命不负责“世界持续推演”（无季节/天气/经济/社会事件模拟）
- 司命不负责“群体模拟引擎”的管理
- 司命不负责“L2按需注入”的时机判断


## 七、技术实现要点

### 7.1 模型规格

| 角色层级 | 模型规格 | 延迟目标 | 并发量 |
| :--- | :--- | :--- | :--- |
| **L1 完整智能体** | 云端大模型(主) + 本地小模型(兜底) | P0: <300ms, P1: <1500ms, P2: <3000ms | 每剧本5-8个L1角色同时运行 |
| **L2 交互角色** | 本地小模型(1-3B参数) | <500ms | 每剧本数人至十数人，按需响应 |
| **L3 程序角色** | 无AI模型，纯程序驱动 | 无需AI推理 | 不限 |

### 7.2 记忆存储

| 记忆类型 | 存储方式 | 体量估算 |
| :--- | :--- | :--- |
| **L1跨剧本记忆** | 结构化的世界状态快照(PostgreSQL) + 向量数据库(语义索引) | 每角色每剧本约100KB-500KB |
| **L2剧本内记忆** | 轻量记忆库(Redis，剧本结束后可选保留) | 每角色约10-50KB |
| **种子库** | PostgreSQL，剧本创作时配置 | 每剧本约1-10MB |


## 八、第二阶段与第一、第三阶段的关系

| 维度 | Phase 1 | Phase 2 | Phase 3 |
| :--- | :--- | :--- | :--- |
| **L1角色** | 单局内完整心智模型 | +跨剧本记忆 +智能体资产化 | +跨世界压制 +私房钱 +同伴经营AI |
| **L2角色** | 不存在 | 轻量级智能体（预设模板+有限记忆） | 群体模拟驱动+按需注入+完整记忆系统 |
| **L3角色** | 基础程序NPC | 程序行为树NPC | 群体角色（百万级，纯群体模拟驱动） |
| **司命** | 单局导演 | 系列导演（种子库+快照+续集承接） | 世界说书人（持续推演+群体管理+L2生命周期） |

**一句话总结**：第二阶段的角色智能体设计，是在Phase 1“单局完整心智模型”的基础上，新增**跨剧本记忆继承**和**智能体资产化**两大核心能力，同时通过L2轻量级智能体丰富剧本体验，为第三阶段的宏大世界模拟做好技术预演。
