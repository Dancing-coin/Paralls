## 用户

一个角色的操作面板有哪些功能区？ 详述，尤其是背包，移动和交互。

## DeepSeek

在《开本》中，角色操作面板需要承载**状态感知、移动控制、交互决策、信息管理**四重核心功能。以下是完整的功能区设计：

## 二、状态栏（左上角常驻）

| 显示项 | 呈现方式 | 说明 |
| :--- | :--- | :--- |
| **角色名** | 文字 | 当前扮演的角色公开名 |
| **压力值** | 进度条+数字(0-10) | 颜色随压力升高从绿→黄→红 |
| **当前情绪** | 动态表情图标+文字 | 紧张😰、冷静😐、恐惧😱、愤怒😠等 |
| **体力/伤势** | 心形图标+颜色 | 满血绿色→受伤黄色→重伤红色 |
| **特殊状态** | 图标标签 | 中毒☠️、醉酒🍷、致幻🌀、出血🩸等 |

**交互方式**：悬停查看详情，点击展开完整状态面板。


## 三、任务与秘密提醒（右上角常驻）

| 显示项 | 说明 |
| :--- | :--- |
| **核心秘密** | 一句话提醒，如“你是真凶，必须隐藏” |
| **当前首要目标** | 从目标层级提取最高优先级目标 |
| **目标完成度** | 可选显示，如“已收集线索 3/7” |

**交互方式**：悬停展开完整目标列表，点击切换追踪目标。


## 四、移动控制（WASD + 姿态切换）

### 4.1 移动方式

| 操作 | 键盘 | 手柄 | 说明 |
| :--- | :--- | :--- | :--- |
| **前进/后退** | W/S | 左摇杆↑↓ | 向前/向后移动 |
| **左移/右移** | A/D | 左摇杆←→ | 向左/向右横向移动 |

### 4.2 移动姿态切换

| 姿态 | 切换键 | 移动速度 | 脚步声 | 被感知距离 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **正常行走** | 默认 | 标准 | 标准 | 标准 | 日常移动姿态 |
| **奔跑** | Shift（按住） | 1.5倍 | 大 | 更远 | 快速移动，但脚步声会暴露位置 |
| **潜行** | Ctrl（按住） | 0.5倍 | 极小 | 更近 | 降低被感知概率，需潜行能力支撑 |
| **蹲伏** | C（切换） | 0.3倍 | 极小 | 更近 | 降低被视觉发现概率，可进入低矮空间 |

### 4.3 特殊移动

| 动作 | 操作 | 条件 | 说明 |
| :--- | :--- | :--- | :--- |
| **跳跃** | 空格键 | 场景允许 | 跳过障碍物 |
| **攀爬/翻越** | 靠近障碍物+空格 | 特定场景（窗户、矮墙） | 翻越障碍物 |
| **游泳** | 进入水中自动切换 | 场景中有水域 | 水中移动 |

### 4.4 移动的沉浸感规则

| 规则 | 说明 |
| :--- | :--- |
| **脚步声** | 不同移动姿态产生不同大小的脚步声，通过空间音频传播 |
| **表面材质音效** | 木地板、石板地、草地、楼梯——不同表面产生不同脚步声 |
| **体力消耗** | 持续奔跑会消耗体力，体力不足时只能行走（若启用体力系统） |
| **碰撞与物理** | 无法穿墙、无法穿过家具。撞倒物品会产生噪音 |


## 五、视角控制

### 5.1 视角旋转

| 操作 | 鼠标 | 手柄 | 说明 |
| :--- | :--- | :--- | :--- |
| **水平旋转** | 鼠标左右移动 | 右摇杆 ← → | 左右看 |
| **垂直旋转** | 鼠标上下移动 | 右摇杆 ↑ ↓ | 上下看 |

### 5.2 视角模式切换

| 模式 | 切换键 | 说明 |
| :--- | :--- | :--- |
| **第一人称** | V / F5 | 沉浸感最强，视野受限，更贴近角色的真实视角 |
| **第三人称（近）** | V / F5 切换 | 可以看到角色模型，适合观察自己的伪装和状态 |
| **第三人称（远）** | V / F5 再切换 | 视野更开阔，适合观察周围环境 |

### 5.3 视角操作

| 操作 | 说明 |
| :--- | :--- |
| **聚焦观察** | 鼠标右键按住或手柄LT，拉近视角，高亮准星对准的可交互物品 |
| **快速回头** | 按特定键（如Z），角色快速180度转身查看身后 |
| **环顾四周** | 按住Alt键，鼠标可自由移动视角但角色朝向不变（观察周围但不暴露朝向变化） |


## 六、交互动作系统

### 6.1 交互准星

屏幕中央始终显示一个准星，对准目标时状态变化：

| 准星状态 | 说明 |
| :--- | :--- |
| **默认（白点）** | 无目标 |
| **高亮（白圈）** | 对准可交互物品 |
| **高亮（绿圈）** | 对准可对话角色 |
| **高亮（红圈）** | 对准可暗杀目标（条件满足时） |
| **高亮（蓝圈）** | 对准可拾取物品 |

### 6.2 交互动作栏（屏幕下方，上下文动态切换）

玩家通过准星对准目标后，交互动作栏显示当前可执行的操作。

#### 对角色可执行的动作

| 动作 | 图标 | 条件 | 说明 |
| :--- | :--- | :--- | :--- |
| **公开交谈** | 🗣️ | 目标在清晰区内 | 发起公开对话，清晰区内所有人都能听到 |
| **耳语** | 🤫 | 目标在耳语范围内(1m) | 发起私密对话，仅对方能听清 |
| **展示物品** | 🫴 | 背包中有物品 | 向对方展示物品，对方可查看详情 |
| **移交物品** | 🤝 | 背包中有可移交物品 | 将物品交给对方 |
| **跟随** | 🚶 | 对方同意 | 自动跟随对方移动 |
| **邀请跟随** | 👆 | 对方在附近 | 邀请对方跟随自己 |
| **观察** | 👁️ | 任何可见角色 | 仔细观察对方，可能发现伪装痕迹、受伤、情绪变化等 |
| **搜身** | ✋ | 特定条件下（如对方失去行动能力或同意） | 查看对方携带的所有物品 |
| **救治** | 🩹 | 自己有医术能力，对方受伤 | 治疗对方的伤势 |
| **攻击/暗杀** | 🔪 | 满足暗杀条件 | 执行暗杀（需二次确认） |
| **唤醒/扶起** | 💪 | 对方昏迷或倒地 | 帮助对方恢复 |

#### 对物品可执行的动作

| 动作 | 图标 | 条件 | 说明 |
| :--- | :--- | :--- | :--- |
| **拾取** | ✋ | 物品可拾取 | 放入背包 |
| **检查/调查** | 🔍 | 物品可交互 | 查看详情，可能触发L3视觉增强（线索特写） |
| **使用** | ▶️ | 物品可使用 | 使用物品（如钥匙开门、毒药投入饮食） |
| **推/拉** | 💪 | 物品可移动 | 移动家具、推开箱子、拉开窗帘 |
| **打开/关闭** | 🚪 | 门、窗、箱子等 | 开关门/窗/容器 |
| **隐藏/躲藏** | 🙈 | 在特定位置（柜子、窗帘后） | 进入隐藏状态，降低被感知概率 |
| **破坏** | 💥 | 物品可破坏 | 破坏物品（如砸碎花瓶、撕毁信件） |
| **修复** | 🔧 | 物品可修复 | 修复被破坏的物品（如拼合撕碎的信件） |

#### 对场景可执行的动作

| 动作 | 图标 | 条件 | 说明 |
| :--- | :--- | :--- | :--- |
| **坐下** | 🪑 | 场景中有可坐位置 | 坐下休息，可能降低压力值 |
| **点燃/熄灭** | 🔥 | 有可点燃/熄灭的光源 | 蜡烛、壁炉、油灯等 |
| **窃听** | 👂 | 靠近门/墙 | 尝试听清另一侧的模糊声音 |
| **标记** | 📌 | 任何位置 | 在地上或墙上留下标记（用于迷宫导航） |
| **攀爬/翻越** | 🧗 | 特定场景（窗户、矮墙） | 翻越障碍物 |

### 6.3 全局行动菜单（可唤出，不依赖准星）

| 全局行动 | 图标 | 说明 |
| :--- | :--- | :--- |
| **呼喊** | 📢 | 大声呼喊，吸引附近所有角色注意，声音传播半径比公开对话更大 |
| **制造噪音** | 💥 | 在当前位置制造噪音（如敲击墙壁、扔东西），用于吸引或误导他人 |
| **留下标记** | 📌 | 在当前位置留下一个隐蔽的标记，只有自己和信任的盟友能看到 |
| **加速移动** | 🏃 | 短暂提高移动速度，但会产生更大脚步声（更容易被他人感知） |
| **潜行移动** | 🥷 | 降低移动速度和脚步声，更难被他人感知（需要潜行能力） |
| **假装受伤** | 🤕 | 伪装受伤状态（可能被医术检查识破） |
| **自首/坦白** | 🏳️ | 公开承认自己的罪行或秘密 |
| **伪装调整** | 🎭 | 进入伪装管理界面，编辑公开档案或调整伪装道具 |
| **查看环境** | 🔭 | 仔细观察当前环境，高亮所有可交互物品 |
| **等待** | ⏳ | 原地等待一段时间，可能用于制造不在场证明或等待时机 |


## 七、背包面板

### 7.1 背包分类标签

| 标签 | 内容 | 说明 |
| :--- | :--- | :--- |
| **全部** | 所有物品 | 默认视图 |
| **线索** | 自己获得的线索物品 | 含发现时间和地点 |
| **工具** | 钥匙、开锁器、留影石、相机等 | 功能性物品 |
| **武器/凶器** | 暗杀工具、毒药等 | 可执行攻击的物品 |
| **伪装道具** | 假发、化妆品、假证件等 | 维持伪装所需的物品 |
| **消耗品** | 药品、毒药、投掷物等 | 使用后消失 |
| **留影/照片** | 拍摄的照片或留影 | 可查看、展示、移交 |

### 7.2 物品交互操作

| 操作 | 说明 |
| :--- | :--- |
| **检查详情** | 查看物品的详细描述、3D旋转查看、L3特写图 |
| **展示** | 公开展示或私下分享给指定角色 |
| **移交** | 将物品交给附近角色 |
| **使用** | 使用物品（开锁、投毒、点燃等） |
| **丢弃** | 将物品放回场景中 |
| **组合** | 与其他物品组合（如绳子+钩子=抓钩） |

**一句话总结**：《开本》的角色操作面板以3D世界为核心，状态栏和任务提醒提供沉浸式感知，移动姿态切换直接影响被感知范围，交互动作栏根据上下文动态变化，背包系统支持物品的分类管理和多种交互操作。所有功能都服务于“让玩家以角色身份自由行动、管理信息、进行社交博弈”的核心目标。
