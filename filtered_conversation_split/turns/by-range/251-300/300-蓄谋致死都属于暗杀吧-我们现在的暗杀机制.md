## 阴谋系统：超越暗杀的蓄意行动机制

### 一、核心定义

阴谋系统是暗杀机制的上位扩展。它涵盖任何**通过环境、间接手段或非致命破坏来达到非法目的**的蓄意行为。

| 行为类型 | 定义 | 示例 | 是否致死 |
| :--- | :--- | :--- | :--- |
| **直接暗杀** | 使用凶器直接攻击目标 | 匕首刺杀、绳索勒杀、钝器击打 | 是 |
| **环境致死** | 利用环境条件间接致死 | 将人锁在冷冻车厢冻死、将人推入冰水中、制造“意外”坠崖 | 是 |
| **间接伤害** | 通过环境破坏或陷阱致伤/致死 | 锯断楼梯扶手导致目标摔伤、在食物中下毒、破坏供暖设备导致目标生病 | 可致死可不致死 |
| **蓄意破坏** | 破坏关键设施或制造混乱以达成非致死目的 | 上校纵火放走凶手、切断电源掩护盗窃、破坏刹车制造混乱 | 通常不致死 |

**核心原则**：所有蓄意行动受同一套触发条件（致命动机、信息空窗期、独处窗口、能力匹配、代价评估）约束，司命统一催化，但执行方式和后果不同。


### 二、环境致死的判定逻辑

环境致死与直接暗杀的核心区别在于：**凶手不直接接触目标，而是利用环境条件作为“凶器”**。

| 环境致死类型 | 触发条件 | 实现机制 | 反制手段 |
| :--- | :--- | :--- | :--- |
| **冷冻致死** | 目标被锁在寒冷环境中（如列车尾部、冰库），无法自行逃脱 | ESM计算目标体温下降速度，当体温降至0时目标死亡 | 目标可用工具破门、大声呼救被他人听到 |
| **窒息致死** | 目标被锁在密闭空间，氧气逐渐消耗 | ESM模拟空气质量下降，体力逐渐衰减 | 目标可尝试破窗、他人可开门 |
| **高处坠落** | 目标被推下或被破坏的栏杆导致坠落 | 即时物理判定：高度 > 致死阈值 → 直接濒死/死亡 | 目标可抓住边缘、他人可拉住 |
| **火灾致死** | 目标被困在燃烧区域，无法逃脱 | ESM计算火焰蔓延速度 + 烟雾伤害 → 体力/体温双重下降 | 目标可找灭火器、他人可救援 |
| **溺水致死** | 目标在水中无法浮起（被按住、被网缠住等） | ESM模拟氧气消耗，体力下降 | 目标可挣扎、他人可施救 |
| **下毒致死** | 目标摄入毒药 | 毒药物品挂载`[可下毒]`组件，定义毒发时间和致死性 | 目标可用解毒剂、医术技能可检测 |

**环境致死的证据链**：

| 证据类型 | 说明 | 示例 |
| :--- | :--- | :--- |
| **环境痕迹** | 凶手为制造环境致死条件而留下的痕迹 | 被破坏的门锁、被锯断的扶手、被撬开的窗户 |
| **物证矛盾** | 现场存在与自然状态不符的物证 | 明明有钥匙却从外面锁上的门、被撕掉的保暖衣物 |
| **时间线矛盾** | 凶手在案发时间无法解释行踪 | 凶手声称在餐车，但有人看到他从尾部车厢回来 |
| **动机证据** | 凶手有杀死目标的动机 | 死者掌握凶手的致命秘密 |


### 三、蓄意破坏的判定逻辑

蓄意破坏与暗杀的核心区别在于：**目的不是杀人，而是制造混乱、协助逃脱、销毁证据或转移嫌疑**。

| 破坏类型 | 触发条件 | 实现机制 | 后果 |
| :--- | :--- | :--- | :--- |
| **纵火** | 行为人有打火机等火源，目标区域有可燃物 | 行为人使用火源，ESM触发燃烧状态机，火焰蔓延 | 制造混乱、吸引注意、掩护他人行动 |
| **切断电源** | 行为人在配电室，有工具 | 行为人破坏电闸，ESM将场景灯光熄灭 | 制造黑暗掩护、阻碍调查、引发恐慌 |
| **破坏设施** | 行为人在目标设施附近，有能力破坏 | 行为人破坏刹车、破坏供暖、破坏通讯设备 | 改变所有人的行动路线、制造时间窗口 |
| **销毁证据** | 行为人持有证据物品，有销毁手段 | 行为人烧毁信件、清洗血迹、砸碎凶器 | 改变信息格局、阻碍推理 |
| **伪造现场** | 行为人持有伪造工具，有创造能力 | 行为人伪造不在场证明、伪造自杀现场、伪造他人指纹 | 转移嫌疑、误导调查 |

**蓄意破坏的证据链**：

| 证据类型 | 说明 | 示例 |
| :--- | :--- | :--- |
| **破坏痕迹** | 行为人执行破坏行为时留下的物理痕迹 | 被砸碎的电闸、窗帘上的打火机指纹、被撬开的设备箱 |
| **目击者** | 行为人在破坏区域附近出现 | 有人看到上校在餐车角落停留过久 |
| **时间线矛盾** | 行为人在破坏发生时无法解释行踪 | 上校声称在包厢休息，但有人看到他在餐车方向 |


### 四、司命对蓄意行动的催化

司命监测的动机范围需要从“致命动机”扩展为**“非法目的动机”**。

| 动机类型 | 检测信号 | 可能触发的蓄意行动 |
| :--- | :--- | :--- |
| **致命动机（灭口/仇恨）** | 目标掌握致命证据/仇恨对象在场 | 直接暗杀、环境致死、间接伤害 |
| **协助逃脱** | 某角色需要离开当前困境 | 蓄意破坏（纵火、切断电源）、伪造现场 |
| **销毁证据** | 某证据即将暴露 | 破坏证据、纵火（烧毁证据所在区域） |
| **转移嫌疑** | 自身怀疑值过高 | 伪造现场、间接伤害（制造新案件转移焦点） |
| **保护他人** | 忠诚度≥8的对象面临威胁 | 蓄意破坏（阻碍调查）、直接暗杀 |

**催化流程**（以“上校纵火放走凶手”为例）：

1. **动机检测**：司命检测到上校的目标层级中“让麦奎因逃脱”优先级最高，且上校有打火机、餐车有可燃物。
2. **可玩性评估**：纵火不会导致一方碾压，且麦奎因逃脱将增加戏剧张力。
3. **条件排列**：司命检测到餐车窗帘在2米范围内，窗帘挂载`[可燃烧]`组件。
4. **弹窗确认**：司命向上校推送蓄意行动机会面板：“麦奎因即将被移交给警方。餐车窗帘是可燃物，你的打火机可以点燃它。火焰将制造足够的混乱，为麦奎因创造逃脱窗口。”
5. **执行**：上校选择点火，ESM触发窗帘燃烧状态机，火势蔓延。司命向所有角色广播火灾事件。麦奎因在混乱中逃脱。


### 五、阴谋系统的完整行动类型

| 行动类型 | 目的 | 手段 | 反制手段 | 后果等级 |
| :--- | :--- | :--- | :--- | :--- |
| **直接暗杀** | 致死 | 凶器攻击 | 本能反应/呼救/反击 | 最高 |
| **环境致死** | 致死 | 利用环境条件 | 破门/呼救/他人救援 | 最高 |
| **间接伤害** | 致伤/致死 | 下毒/陷阱/破坏设施 | 检测/治疗/躲避 | 高 |
| **蓄意破坏** | 非致死 | 纵火/断电/破坏设施 | 灭火/修复/追踪 | 中 |
| **伪造现场** | 非致死 | 伪造证据/伪造不在场证明 | 逻辑推理/物证检测 | 中 |
| **销毁证据** | 非致死 | 烧毁/清洗/砸碎 | 目击/痕迹检测 | 低 |
| **协助逃脱** | 非致死 | 纵火/断电/破坏通讯 | 追踪/封锁 | 中 |


**一句话总结**：阴谋系统是暗杀机制的上位扩展，涵盖直接暗杀、环境致死、间接伤害、蓄意破坏、伪造现场、销毁证据、协助逃脱七种蓄意行动。所有行动受同一套触发条件约束，司命统一催化，但执行方式、反制手段和后果等级不同。这让《开本》中的“犯罪”不再局限于匕首和毒药，而是成为一个与环境、物理和叙事深度绑定的完整体系。
