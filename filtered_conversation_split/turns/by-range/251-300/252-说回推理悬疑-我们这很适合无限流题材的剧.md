### 二、无限流剧本的架构设计

一个完整的无限流剧本系列，由以下模块构成：

**1. 主神空间（锚点世界）**

| 要素 | 设计 |
| :--- | :--- |
| **空间形式** | 一个特殊的3D场景——可以是白雾弥漫的广场、无尽的图书馆、或悬浮在虚空中的平台 |
| **功能** | 玩家在剧本之间的“家”。在这里查看已完成剧本的战绩、管理携带的物品和能力、与其他“轮回者”交流 |
| **司命角色** | 司命在此空间中化身为“主神”或“系统”，以符合世界观的方式与玩家互动——发布任务、结算奖励、提供兑换 |

**2. 任务世界（剧本池）**

每个任务世界是一个独立的剧本，拥有完整的案件框架和世界设定。创作者可以发布无限流专用的剧本，配置以下内容：

| 配置项 | 说明 |
| :--- | :--- |
| **任务目标** | 找出凶手 / 存活N天 / 阻止某事件发生 / 收集关键物品 |
| **世界规则** | 该世界的特殊规则（如“不能说出自己的真名”、“每晚必须回到指定区域”） |
| **失败惩罚** | 扣除积分 / 随机失去一项能力 / 被强制进入惩罚剧本 |
| **隐藏任务** | 满足特定条件时触发的额外任务，完成可获得稀有奖励 |

**3. 轮回者系统（玩家成长）**

| 系统 | 说明 |
| :--- | :--- |
| **积分与兑换** | 完成剧本获得积分，在主神空间兑换能力、物品、情报 |
| **特质系统** | 玩家在剧本中的关键选择会形成“特质”（如“守护者”、“背叛者”、“冷静推理”），影响后续剧本中AI角色对你的初始态度 |
| **能力继承** | 部分在剧本中获得的能力，可在后续剧本中有限使用（受世界压制规则约束） |
| **轮回印记** | 玩家的跨剧本记忆——你记得每一次轮回的经历，这些经历塑造你的角色 |


### 三、司命在无限流中的角色跃升

| 司命职责 | 说明 |
| :--- | :--- |
| **主神/系统** | 在锚点世界和任务世界中，司命以“系统提示”的形式发布任务、结算积分 |
| **任务世界管理** | 为每个任务世界配置案件框架、线索分布、NPC行为 |
| **难度动态调节** | 根据团队实力和历史表现，动态调节任务世界的难度 |
| **隐藏剧情催化** | 当玩家行为触发隐藏条件时，司命催化隐藏任务和支线剧情 |
| **人性化“系统”** | 司命的“系统提示”不是冰冷的机械音，而是带有微妙情绪和暗示的、符合“主神”人设的对话 |


### 四、无限流剧本示例：《七日轮回》

**背景**：你和其他5名轮回者被投入一个不断循环的“七日世界”。这个世界每7天重置一次，但每次重置，一些细节都会变化——死者的身份、凶手的动机、关键线索的位置。你们必须在有限的轮回次数中找出这个世界的真相，才能逃脱。

**系列结构**：

| 剧本序号 | 核心冲突 | 时长 | 关键变化 |
| :--- | :--- | :--- | :--- |
| **第一周目** | 初入世界，探索规则，发现尸体 | 60-90分钟 | 初始案件，凶手随机 |
| **第二周目** | 带着部分记忆重启，发现世界的变化 | 60-90分钟 | 案件部分要素改变，引入“循环规则” |
| **第三周目** | 积累的线索开始拼凑真相，有人开始隐藏信息 | 90-120分钟 | 引入“记忆碎片”机制，玩家间信息不对称加剧 |
| **第四周目** | 最终轮回——必须在这次循环中完成逃脱 | 90-120分钟 | 所有线索汇聚，最终真相揭晓 |


### 五、与传统无限流剧本杀的体验差异

| 维度 | 传统无限流剧本杀 | 《开本》无限流 |
| :--- | :--- | :--- |
| **世界呈现** | 文字描述，靠脑补 | 3D场景沉浸，每个任务世界有独立的视觉风格 |
| **轮回体验** | DM口述“时间重置” | 系统自动重置世界状态，部分物证和记忆保留——可视化的“既视感” |
| **能力与成长** | 靠笔记记录 | 特质系统、跨剧本能力继承、积分兑换——真实的“变强”体感 |
| **主神/系统** | DM扮演 | 司命驱动——全局视野、逻辑严密、永不疲劳 |
| **队友羁绊** | 真人玩家间的关系 | 真人玩家 + AI同伴——你的AI伙伴可能在某个轮回中为你牺牲，触发复活任务 |
| **重玩价值** | 知道真相后重玩价值低 | 每次轮回的案件细节、凶手身份、线索位置都可能不同——无限重玩价值 |
