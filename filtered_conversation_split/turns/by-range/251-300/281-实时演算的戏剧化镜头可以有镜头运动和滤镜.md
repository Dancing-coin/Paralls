## 用户

实时演算的戏剧化镜头可以有镜头运动和滤镜调整，但要不要区分不同角色视角呢？ 还是说进入wow时刻要用统一视角？

## DeepSeek

在《开本》中，WOW时刻的实时演算需要**区分不同角色视角**，但这并非在每个瞬间都对所有人呈现不同画面，而是遵循一套 **“公共事件统一视角 + 私密时刻角色视角 + 关键高潮混合视角”** 的分层规则。

---

## 一、核心原则：视角服务于叙事和博弈

| 原则 | 说明 |
| :--- | :--- |
| **沉浸优先** | 视角切换必须让玩家感觉自己是“角色”而非“观众” |
| **信息博弈** | 不同角色看到的WOW时刻可能不同——这本身就是推理线索 |
| **公共基础** | 所有玩家必须共享关键事件的视觉呈现，确保投票和推理有共同基础 |
| **司命统一调度** | 无论视角如何切换，司命是唯一的镜头导演 |


## 二、三种视角模式

### 2.1 统一视角（公共事件）

**适用场景**：所有人都能亲眼目睹的事件。

| 场景 | 统一视角的呈现方式 |
| :--- | :--- |
| 哈伯德太太公开坦白 | 所有人看到相同的画面——哈伯德站起来，颤抖着说出真相。镜头从波洛的过肩镜头推近至哈伯德的面部特写 |
| 麦奎因公开承认身份 | 所有人看到相同的画面——麦奎因站起来，镜头从全景切至他的面部特写 |
| 上校在餐车点火 | 所有在餐车的人看到相同的画面——火焰从窗帘蔓延，上校扑火，混乱中麦奎因消失 |

**设计理由**：这些是公共知识——所有人都亲眼目睹，是后续推理的共同基础。如果不同人看到不同画面，会导致信息混乱。

### 2.2 角色视角（私密时刻/内心戏）

**适用场景**：只有特定角色能感知到的细节。

| 场景 | 角色视角的呈现方式 |
| :--- | :--- |
| 玛丽与麦奎因的耳语 | **玛丽的视角**：画面边缘出现柔光，麦奎因的嘴唇特写，字幕清晰显示他说的话。**波洛的视角**：他看到玛丽和麦奎因在远处交谈，但听不到内容。画面没有特效，字幕显示“（玛丽和麦奎因在低声交谈）”。**哈伯德的视角**：她根本没注意到这个细节，画面没有变化 |
| 波洛发现伤口线索 | **波洛的视角**：进入短暂的慢动作（子弹时间），镜头推近至伤口细节，画面边缘出现暗角——这是波洛的专注时刻。**其他角色**：他们看到波洛在检查尸体，但没有慢动作特效，也没有细节特写 |
| 哈伯德太太内心的恐惧 | **哈伯德的视角**：她的手帕被反复揉搓的特写，背景的其他角色声音逐渐变模糊，心跳声逐渐增大。**其他角色**：他们看到哈伯德在搓手帕，但没有心跳声，没有模糊化处理 |

**设计理由**：这些是共有知识或高阶知识的基础——不同人的感知差异本身就是推理线索。波洛注意到玛丽和麦奎因在交谈，而哈伯德没注意到——这种信息不对称正是我们设计的核心。

### 2.3 混合视角（关键高潮）

**适用场景**：本局最核心的戏剧高潮，需要多角度呈现。

**以“上校点火，麦奎因逃脱”为例**：

| 时间 | 视角 | 呈现内容 |
| :--- | :--- | :--- |
| T+0s | **统一视角**（餐车内所有人） | 全景：上校走向餐车角落，火焰突然在窗帘上蔓延 |
| T+1s | **统一视角**（餐车内所有人） | 中景：上校用外套扑火，餐车内混乱 |
| T+1.5s | **角色视角**（波洛） | 波洛的视角快速扫视餐车——字幕浮现他的内心独白：“少了一个人。”波洛的视线锁定在麦奎因原本站立的位置——那里已经空了 |
| T+2s | **角色视角**（麦奎因） | 麦奎因的视角——他在列车尾部推开窗户，回头看了一眼餐车方向（他知道上校在为他争取时间），纵身跃入雪幕。慢动作，暴风雪涌入 |
| T+2.5s | **统一视角**（回到餐车） | 火焰已被扑灭，所有人惊魂未定。波洛的视线落在上校身上 |

**设计理由**：混合视角让所有玩家共享事件的公共部分（点火、混乱、火焰被扑灭），同时通过波洛和麦奎因的角色视角，让玩家分别体验“侦探的洞察”和“逃脱者的决绝”。这种切换增强了戏剧张力，同时保持了信息的公共基础。


## 三、视角切换的导演规则

| 规则 | 说明 |
| :--- | :--- |
| **公共事件，统一视角** | 所有人都能亲眼目睹的事件，使用统一视角 |
| **私密感知，角色视角** | 只有特定角色能感知的细节（耳语、内心戏、个人发现），使用角色视角 |
| **关键高潮，混合视角** | 本局最高潮事件，在统一视角中穿插角色视角，但最终回到统一视角 |
| **视角切换的过渡** | 切换视角时使用0.3-0.5秒的淡入淡出或快速镜头摇移，避免生硬跳跃 |
| **司命统一调度** | 无论视角如何切换，司命是唯一的镜头导演。所有视角切换的时机、构图、特效均由司命实时决定 |


## 四、角色视角中的滤镜与特效差异

| 角色状态 | 滤镜/特效处理 |
| :--- | :--- |
| **高压力角色** | 画面边缘出现轻微的心跳光晕，色彩饱和度略微降低 |
| **醉酒/致幻角色** | 画面出现轻微的重影或色偏，声音有回响 |
| **专注观察的角色** | 画面中央清晰，边缘出现暗角（隧道视觉），环境音减弱 |
| **恐惧中的角色** | 画面微微颤抖（手持摄影机效果），呼吸声增大 |
| **悲伤中的角色** | 画面色调偏冷，饱和度降低，背景音乐减弱 |

**关键**：这些滤镜和特效**仅对当前视角的角色生效**。其他角色看不到这些变化——他们只知道这个角色“看起来不对劲”，但无法直接感知其内心状态。这种差异本身就是推理线索。


## 五、与信息博弈的关系

| 信息类型 | 视角设计 | 博弈意义 |
| :--- | :--- | :--- |
| **公共知识** | 统一视角，所有玩家看到相同画面 | 共同推理基础，用于投票和公开讨论 |
| **共有知识** | 私密对话时，对话双方看到相同画面，其他人看到不同画面（或看不到） | 信息不对称——A和B知道某信息，C不知道。C需要通过观察A和B的后续行为来推断 |
| **高阶知识** | A看到B在观察C——A的角色视角中，画面边缘可能高亮B的视线方向 | A知道B在注意C——这是二阶知识。A可以利用这个信息进行策略操作 |


## 六、司命的导演指令格式

```json
{
  "wow_sequence": {
    "id": "seq_confession_habbard",
    "duration": 8.0,
    "camera": {
      "shots": [
        {"time": 0.0, "type": "over_shoulder", "subject": "poirot", "target": "habbard", "transition": "cut"},
        {"time": 1.5, "type": "push_in", "target": "habbard_face", "fov": 25, "duration": 2.0},
        {"time": 4.0, "type": "reaction_cut", "targets": ["mary", "mcqueen", "colonel"], "duration": 1.5},
        {"time": 6.0, "type": "pull_out", "target": "dining_car_wide", "duration": 2.0}
      ],
      "perspective": "unified",
      "perspective_note": "所有人看到相同的画面——哈伯德公开坦白"
    },
    "post_process": {
      "vignette": 0.3,
      "saturation": -0.15,
      "color_grade": "warm_focus_on_habbard"
    },
    "time_dilation": {"start": 1.5, "end": 4.5, "speed": 0.5},
    "audio": {
      "music": "strings_tension_release",
      "sfx": ["heartbeat_slow", "habbard_sob"],
      "ambient": "dining_car_silence"
    }
  }
}
```

**视角字段说明**：
- `perspective: "unified"` → 统一视角，所有玩家看到相同画面
- `perspective: "character"` + `character_id: "poirot"` → 角色视角，仅波洛玩家看到此画面
- `perspective: "mixed"` → 混合视角，在统一视角中穿插角色视角


**一句话总结**：WOW时刻的实时演算需要区分视角——公共事件使用统一视角（所有玩家共享），私密时刻使用角色视角（仅特定角色可见），关键高潮使用混合视角（统一视角中穿插角色视角后回归统一）。司命是唯一的镜头导演，视角切换服务于叙事沉浸和信息博弈的双重目标。
