# 第一阶段角色智能体设计方案

## 一、核心定位

第一阶段的核心是验证 **“智能体驱动的3D动态剧本杀”** 这一核心体验是否成立。世界是静态的，每局剧本独立运行，局与局之间无任何状态继承。因此，第一阶段的角色智能体聚焦于 **“在单局内，角色是否足够像真人？”**，不涉及任何跨局记忆、资产化、群体模拟等高级功能。

## 二、角色分层

| 层级 | 角色类型 | 驱动方式 | 数量 | 核心特征 |
| :--- | :--- | :--- | :--- | :--- |
| **L1 完整智能体** | 所有玩家角色（人类或AI玩家）、核心NPC | 完整心智模型（LLM+人格档案） | 每剧本5-8人 | 独立人格、自由对话、单局内完整记忆 |
| **L2 程序角色** | 背景NPC（管家、女仆、卫兵等） | 程序行为树（无独立人格） | 每剧本数人 | 仅执行预设行为，有限对话 |


### 为什么第一阶段没有L2交互角色？

因为第一阶段的剧本角色数量极少（5-8人），且世界是静态的，不存在“成千上万国民”的需求。所有需要深度交互的角色都直接使用L1完整智能体。L2程序角色仅用于填充场景，不参与推理和自由对话。


## 三、L1 完整智能体（核心）

### 3.1 心智模型（四层架构）

- **L1 感知层**：接收结构化语义事件（视觉、听觉、触觉等），由感知过滤器按角色感官档案过滤。
- **L2 理解层**：解读信息、更新信念、生成推论、更新情绪状态。输出内心独白（仅玩家角色可见）。
- **L3 规划层**：基于动机（恐惧/目标/社交/好奇）生成候选行动方案，由三重过滤器筛选。
- **L4 执行层**：输出对话文本、情绪参数（用于TTS）、动作指令（移动/手势/交互），以及自动微表情和小动作。

**关键限制（第一阶段特有）**：
- **记忆只在单局内保留**：剧本结束后，角色的所有记忆（事件、关系、高阶知识）全部清空。下一局是全新实例。
- **无跨剧本记忆继承**：同一剧本再次游玩时，角色不会记得上一局的内容。
- **无智能体资产化**：玩家无法“带走”AI角色。剧本结束后，角色数据归档但不绑定玩家。

### 3.2 人格档案

- **基因种子 → 人生记忆 → 品格层 → 行为层**：由剧本创作者在编辑器中配置，或使用官方预设模板。
- **五维人格参数**：胆量、心机、共情、理性、社交（0-10）。
- **品格层**：诚实、忠诚、正义感、仁慈、责任感，以及价值优先级。
- **三重过滤器**：人设过滤器（角色“会”这么做吗？）、逻辑过滤器（行为“合理”吗？）、得失过滤器（对角色“有利”吗？）。

**与后期阶段的关键区别**：第一阶段不支持由基因种子自动模拟生成人生记忆，而是由创作者手工填写或选择预设模板。模拟生成功能在第二阶段才引入。

### 3.3 动态状态管理

- **压力值（0-10）**：被质疑、秘密濒临暴露时上升；影响理性程度和冲动行为概率。
- **信任值（针对每个对象）**：影响信息分享意愿和合作倾向。
- **怀疑值（针对每个对象）**：影响指控倾向和信息采信度。
- **情绪标签**：当前主导情绪（紧张、愤怒、悲伤、兴奋等），影响决策偏向和语言风格。

所有状态在单局内实时更新，单局结束后清空。

### 3.4 感知系统

- **结构化语义事件替代截图**：通过事件总线接收L1层上抛的感知事件，由感知过滤器按角色的感官档案过滤。
- **视觉感知**：可见对象列表（含距离、状态、显著特征）。
- **听觉感知**：可听事件列表（含清晰度分级：clear/muffled/distant/barely_audible）。
- **动作阶段化感知**：意图阶段→执行阶段→完成阶段。角色在意图阶段即可反应。
- **本能反应规则引擎**：对P0致命威胁（暗杀意图）走L1规则引擎，延迟<300ms。

**与后期阶段的关键区别**：第一阶段的感知档案由剧本创作者手工定义，不支持复杂的感官模拟（如盲人的回声定位、特殊感官等，除非剧本特殊设计）。

### 3.5 对话生成

- **LLM上下文组装**：人格参数 + 知识图谱切片（角色所知的事实和高阶知识）+ 对话历史摘要 + 当前状态（压力/情绪）+ 感知环境。
- **流式生成**：逐token返回，TTS边接收边合成。
- **动作先行**：决策完成后立即发送动作指令（如点头、皱眉），文本/语音随后到达。
- **模型路由**：P0致命威胁走规则引擎（<300ms）；P1紧急对话走本地小模型（<1500ms）；P2重要对话走云端大模型（<3000ms）。兜底机制：大模型超时→小模型接管；小模型超时→规则引擎预设回应。

**与后期阶段的关键区别**：第一阶段仅支持文本对话和TTS语音输出，不支持AI角色的自主表情和微表情映射（这些在第二阶段引入）。

### 3.6 记忆系统（单局内）

- **事件记忆**：我亲身经历的所有事件（时间戳+地点+事件描述+涉及人物），实时添加，单局结束后清空。
- **观察记忆**：我看到/听到的他人言行（谁在何时何地做了什么/说了什么）。
- **知识记忆**：我获得的线索、证据、情报（含知识状态：疑似/确认）。
- **社交记忆**：我对其他角色的信任值、怀疑值、好感度。
- **高阶记忆**：关于“他人知道什么”的推理（二阶、三阶知识）。

**与后期阶段的关键区别**：所有记忆在单局结束后完全清空，无任何持久化存储。


## 四、L2 程序角色（背景）

| 维度 | 说明 |
| :--- | :--- |
| **驱动方式** | 程序行为树（预设行为模式，无独立人格） |
| **典型角色** | 远处路人、巡逻卫兵、一次性线索提供者 |
| **对话能力** | 无可交互对话，或仅返回1-2句预设台词 |
| **配置方式** | 剧本创作者在编辑器中放置角色并选择行为脚本 |
| **AI算力消耗** | 零 |

**与后期阶段的关键区别**：第一阶段的程序角色非常简单，仅用于填充场景，不参与任何AI推理。第二阶段的L2交互角色会升级为轻量级智能体；第三阶段的L3群体角色会升级为百万级群体模拟。


## 五、玩家角色

玩家角色与AI角色底层使用同一套智能体模型，但L3规划层的方向盘在玩家手中：

- **L1感知层**：系统自动运行，同时玩家通过3D渲染画面和空间音频直接感知世界。
- **L2理解层**：系统自动生成内心独白、冲动、决策建议（供参考），但玩家的大脑独立进行推理。
- **L3规划层**：方向盘交给玩家。玩家决定移动、对话、交互、投票、暗杀等所有主动行为。
- **L4执行层**：主动行为由玩家操作；微表情、小动作、社交距离、语音微表现由系统自动驱动。

**特殊能力（第一阶段已实现）**：
- **凝神**（仅单人/AI模式）：暂停时间，自由观察、拍照、整理笔记。
- **挂机自主模式**：玩家长时间未操作时，L3规划层交还AI自主决策，角色保持鲜活但行为保守。


## 六、司命在第一阶段的能力

| 能力 | 说明 |
| :--- | :--- |
| **事实核心** | 时间线管理（T0→T1→T2→T3），逻辑一致性检查，信息泄露防护 |
| **知识图谱（一阶/二阶）** | 追踪每个角色知道什么，以及A知道B知道什么 |
| **基础天平系统** | 线索分布均衡度监控（仅监控，不主动干预） |
| **案件框架生成** | T1房间创建时从随机池中抽取，T2玩家加入时锁定 |
| **结局判定** | 根据投票结果和关键证据判定结局 |

**与后期阶段的关键区别**：第一阶段司命不主动催化叙事涌现，不执行干预（无天平干预、无暗杀催化、无新案件生成），仅在后台监控逻辑一致性。

## 八、第一阶段角色智能体的技术规格

| 角色层级 | 模型规格 | 延迟目标 | 并发量 | 内存占用 |
| :--- | :--- | :--- | :--- | :--- |
| **L1 完整智能体** | 云端大模型(主) + 本地小模型(兜底) | P0: <300ms, P1: <1500ms, P2: <3000ms | 每剧本5-8个L1角色同时运行 | 每角色约1-4GB |
| **L3 程序角色** | 无AI模型，纯程序驱动 | 无需AI推理 | 不限 | 可忽略 |


## 九、与后期阶段的演进关系

```
Phase 1：单局完整心智模型
    │ 记忆仅单局有效，无继承
    │ L1角色由创作者手工配置
    │ 司命仅做逻辑检查
    │
    ▼
Phase 2：跨局记忆 + 资产化
    │ L1角色新增跨剧本记忆和带走机制
    │ L2交互角色引入（轻量级智能体）
    │ 司命新增主动干预和续集承接
    │
    ▼
Phase 3：宏大世界模拟
    │ L2角色升级为群体模拟驱动+按需注入
    │ L3群体角色引入（百万级）
    │ 司命新增世界持续推演
```

**一句话总结**：第一阶段的角色智能体方案，是统一方案的**最小可行版本**——保留完整的单局心智模型、人格档案、三重过滤器、动态状态、感知系统和模型路由，但移除所有跨局记忆、资产化、群体模拟和司命主动干预功能。这确保了Phase 1能够快速验证核心体验，同时为后续阶段的技术扩展留下清晰的接口。
