## 用户

我们还需要能支持物理属性和化学反应等真实世界存在的基础规则，这有助于剧本符合逻辑的展开和视觉呈现，比如列车上火可能会蔓延到地毯，地毯具备可燃性

## DeepSeek

这正是《开本》从“剧本杀模拟器”迈向“世界模拟器”的关键一步。要实现“火烧窗帘→蔓延到地毯→点燃桌布”这样的连锁反应，我们需要在L1层构建一套**轻量级物理规则引擎**（注意，不是沉重的物理引擎，而是服务于叙事的规则系统）。它同样是独立于司命的专用子系统。

### 一、 核心架构：材料属性 + 规则计算

这套系统的核心逻辑是：**为每个物体赋予基础材料属性，为每种交互定义传播规则，最终由规则引擎计算出确定性的结果。**

*   **原子化材料库（Material Library）**
    我们不需要为“窗帘”和“地毯”分别写一套燃烧逻辑，而是定义通用的材料模板：

| 材料类型 | 可燃性 | 导热性 | 透水性 | 导电性 | 坚固度 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **木材** | 高 | 低 | 中 | 低 | 中 |
| **布料/织物** | 极高 | 极低 | 高（吸收） | 低 | 低 |
| **金属** | 无 | 极高 | 无（不吸收） | 极高 | 极高 |
| **玻璃/陶瓷** | 无 | 低 | 无 | 无 | 低（易碎） |
| **石料/砖块** | 无 | 中 | 低 | 低 | 极高 |
| **肉体/有机物**| 中 | 极低 | 中 | 中 | 极低 |

*   **场景中的物体**：列车上的“木制壁板”、“布料窗帘”、“金属餐盘”等，只需挂载对应的材料组件（如挂载`布料`和`木材`），就自动获得了燃烧、潮湿、破碎等物理规则，无需单独编码。

### 二、 物理规则的传播与计算

这是整个系统的核心。每种状态变化都被视为一种“传播源”，规则引擎负责计算其传播范围。

*   **1. 燃烧系统 (Combustion System)**
    *   **触发**：火源（打火机、壁炉）接触物体。
    *   **属性判定**：规则引擎读取物体的“可燃性”。
    *   **蔓延计算**：如果物体正在燃烧，引擎会以它为球心，检索一定范围内的其他物体。如果范围内的“布料地毯”可燃性为“极高”，则点燃它。
    *   **视觉同步**：引擎根据物体材质加载对应的粒子特效（如布料燃烧的烟雾）。

*   **2. 潮湿与导电系统**
    *   **触发**：水源（水杯打翻）接触物体。
    *   **效果**：布料地毯变为“潮湿”状态，摩擦音效改变。
    *   **联动**：如果潮湿的地毯上掉落了一根断裂的高压电线（剧本特殊设定），规则引擎会判定水导电，对站在上面的角色造成伤害。

*   **3. 破坏与破碎系统**
    *   **判定**：当物体受到物理冲击，引擎计算“冲击力 vs 材料坚固度”。
    *   **结果**：窗户破碎、木门被撞开。玻璃碎片会对附近角色造成划伤，撞开的木门会发出巨响，吸引其他人。

### 三、 实例推演：《东方快车》从打翻水杯到短路火灾

1.  **意外触发**：角色A（AI）在餐车慌乱中碰倒了一个“陶瓷水杯”（材料：玻璃/陶瓷）。
2.  **规则响应**：水杯被打翻，系统触发**潮湿系统**。规则引擎在杯口生成一个水源体积，向桌面蔓延。
3.  **连锁反应**：水流接触“餐桌布”（材料：布料，透水性：高）。桌布状态变为“潮湿”，颜色加深。
4.  **状态反馈**：桌布上的“金属烛台”此时仅被润湿，但因下方有桌布隔离，尚未形成短路条件。
5.  **极端情况**：如果剧本中有特殊道具（如断裂的电线），司命可指令环境状态管理器：判定潮湿的桌布是否同时接触了金属烛台和断裂电线，若满足条件，触发短路火花，进而引燃桌布。

### 四、 技术实现与资源配置

*   **规则引擎与状态机**：由规则程序实现。环境交互的“大脑”是独立于司命运行的轻量级**环境状态管理器 (Environment State Manager)**。它在毫秒级响应材质属性和物理计算。
*   **美术资产**：
    *   **材质模板库**：包含木材、布料等核心材质的焦黑、潮湿、破碎贴图，所有同类物品共享。
    *   **破坏模型**：为门窗、玻璃等制作破碎后的几何体替代模型。
    *   **特效库**：包含燃烧、烟雾、水流、碎片等通用粒子特效。
*   **编辑器支持**：创作者只需为物体选择材质类型，并勾选`[可燃烧]`、`[可破坏]`等行为组件，即可赋予其物理规则。

通过这套“基础规则+材质共享”的系统，《开本》的平行世界就能拥有符合逻辑的物理法则。它无需为每件物品单独编码，而是由系统自动赋予它们真实的交互属性。这个“物理规则大脑”，就是我们刚才命名的**环境状态管理器 (Environment State Manager)**。司命只负责下达高层叙事催化指令，环境状态管理器负责在毫秒级响应并模拟出符合世界逻辑的后果，两者通过事件总线完美协同。
