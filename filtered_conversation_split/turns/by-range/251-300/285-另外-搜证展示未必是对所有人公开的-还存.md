## DeepSeek

在《开本》中，搜证展示分为**公开展示**和**私下分享**两种模式，二者的视觉呈现逻辑完全不同。公开展示强调“仪式感”和“信息同步”，私下分享强调“私密感”和“信息差”。

---

## 一、公开搜证展示：前后步骤与视觉呈现

### 1.1 触发前：玩家的主动操作

**玩家操作**：玩家A在背包中选中线索物品（如“染血的烛台”），点击“展示”按钮。

**即时视觉反馈**：玩家A的角色模型做出“举起物品”的动作（约0.5秒），物品在手中高亮。这是意图阶段的信号——其他玩家看到A举起物品，会意识到“有人要展示证据了”。

### 1.2 展示中：三步视觉呈现

**第一步：广而告之（0-0.5秒）**

| 要素 | 设计 |
| :--- | :--- |
| **公共视觉** | 所有玩家的屏幕中央偏上位置浮现一条轻量通知：“【角色名】展示了一件证据”。通知以半透明背景+简约图标呈现，3秒后自动消失 |
| **音效** | 一声轻微的提示音（如“叮”），引起注意但不打断对话 |
| **空间音频** | 展示者的角色说出预设台词（如“各位，请看这个”），通过空间音频传播，清晰区内所有人都能听到 |

**第二步：物品浮现（0.5-1.5秒）**

| 要素 | 设计 |
| :--- | :--- |
| **公共视觉** | 所有玩家的屏幕中央偏下位置，物品的3D模型以旋转动画从下往上浮入，最终定格。物品周围有微弱的金色光晕，表明这是“正在被展示的重要物品” |
| **背景处理** | 3D场景略微变暗（约20%亮度降低），形成自然的视觉聚焦 |
| **字幕** | 物品名称和简短描述（如“染血的烛台——上面有明显的血迹和毛发”）以字幕形式出现在物品下方 |

**第三步：细节呈现（1.5-3秒）——L3视觉增强触发**

| 要素 | 设计 |
| :--- | :--- |
| **司命判定** | 戏剧价值=8（关键证据公开）→触发L3图片生成 |
| **L3策略** | P1微调生成——以预生成的“烛台”底图微调（含血迹和毛发细节），预估1.2秒 |
| **公共视觉** | 一张清晰的线索特写图以画中画形式淡入，覆盖在物品3D模型上方。特写图比3D模型展示更多细节（指纹、纤维、刻痕） |
| **呈现时长** | 图片持续显示4秒后自动淡出，玩家可点击图片放大查看，或点击关闭提前收起 |
| **自动归档** | 图片自动保存至所有玩家的笔记面板，绑定到对应线索条目 |

### 1.3 展示后：回归自然

| 要素 | 设计 |
| :--- | :--- |
| **视觉恢复** | 背景亮度恢复，物品3D模型以缩小动画回到展示者手中，金色光晕消失 |
| **展示者角色** | 展示者的角色模型放下手臂，回归自然姿态 |
| **笔记更新** | 所有玩家的笔记面板中，该线索条目新增“已被公开展示”标记，以及对应的特写图片 |

### 1.4 公开展示的完整时间线

| 时间 | 事件 | 视觉呈现 |
| :--- | :--- | :--- |
| T-0.5s | 玩家A点击“展示” | A的角色举起物品 |
| T+0s | 广而告之 | 通知浮现+提示音+A的台词 |
| T+0.5s | 物品浮现 | 3D模型旋转浮入+背景变暗+字幕 |
| T+1.5s | L3触发 | 线索特写图淡入（P1微调，1.2秒生成） |
| T+2.7s | 特写呈现 | 图片全清晰显示，持续4秒 |
| T+6.7s | 展示结束 | 图片淡出+背景恢复+物品回到手中+笔记更新 |


## 二、私下分享搜证：前后步骤与视觉呈现

### 2.1 触发前：玩家的主动操作

**玩家操作**：玩家A在背包中选中线索物品，点击“私下分享”，选择目标角色B。

**即时视觉反馈**：玩家A的角色模型做出“将物品藏在手中”的动作，手部靠近身体，物品被手掌遮挡。这是意图阶段的信号——其他玩家可能注意到A在“藏东西”，但看不到是什么。

### 2.2 分享中：仅双方可见

**第一步：私密邀请（0-0.5秒）**

| 要素 | 设计 |
| :--- | :--- |
| **A的视角** | A的屏幕中央浮现一条提示：“你向【角色B】展示了【染血的烛台】” |
| **B的视角** | B的屏幕中央浮现一条提示：“【角色A】向你展示了一件证据”，同时A的角色模型在B的画面中高亮（微弱光晕） |
| **其他角色** | 无任何通知。他们只能看到A和B似乎有互动（A靠近B、A的手在B面前做了某个动作），但不知道具体内容 |
| **空间音频** | A使用耳语模式对B说：“你看这个”——仅B能听清内容，其他人在模糊区只能听到有耳语声 |

**第二步：物品呈现（0.5-1.5秒）——仅B可见**

| 要素 | 设计 |
| :--- | :--- |
| **B的视角** | 物品的3D模型在B的屏幕中央浮入，周围有微弱的蓝色光晕（区别于公开展示的金色），表明这是“私下分享” |
| **A的视角** | A看到自己手中持有物品，但不会看到浮入动画——因为A已经在背包中看过这个物品 |
| **其他角色** | 无变化。他们看到A和B似乎在交谈，但看不到任何物品 |
| **字幕** | 仅B的屏幕显示物品名称和描述 |

**第三步：细节呈现（1.5-3秒）——仅B可见**

| 要素 | 设计 |
| :--- | :--- |
| **司命判定** | 戏剧价值=6（私下分享，不如公开展示重要）→触发L3图片生成 |
| **L3策略** | P1微调或P2实时生成（视配额余量） |
| **B的视角** | 线索特写图仅对B呈现，以画中画形式淡入 |
| **A的视角** | A看不到特写图——A已经在背包中看过 |
| **其他角色** | 无变化 |
| **自动归档** | 特写图仅保存至B的笔记面板 |

### 2.3 分享后：信息差形成

| 要素 | 设计 |
| :--- | :--- |
| **B的笔记更新** | B的笔记面板中，该线索条目新增“由【角色A】私下分享”标记，以及对应的特写图片 |
| **A的笔记更新** | A的笔记中，该线索条目新增“已私下分享给【角色B】”标记 |
| **其他角色的感知** | 其他玩家可能通过观察A和B的后续行为，推断他们共享了信息——这正是高阶知识博弈的基础 |
| **司命的知识图谱** | 更新——`B_knows(clue_X)`，`A_knows(B_knows(clue_X))`，其他人`not_know(B_knows(clue_X))` |

### 2.4 私下分享的完整时间线

| 时间 | 事件 | A的视角 | B的视角 | 其他人视角 |
| :--- | :--- | :--- | :--- | :--- |
| T-0.5s | A点击“私下分享” | 选择目标B | — | 看到A在操作 |
| T+0s | 私密邀请 | 提示“已向B展示” | 提示“A向你展示”+A高亮 | 看到A靠近B |
| T+0.5s | 物品呈现 | 手持物品 | 3D模型浮入+蓝色光晕 | 看到A和B交谈 |
| T+1.5s | L3触发 | — | 特写图淡入 | — |
| T+2.7s | 特写呈现 | — | 图片清晰显示 | — |
| T+6.7s | 分享结束 | 物品收好 | 图片淡出+笔记更新 | 看到A和B结束交谈 |


## 三、视觉区分：公开 vs 私下

| 维度 | 公开展示 | 私下分享 |
| :--- | :--- | :--- |
| **通知范围** | 所有玩家收到通知 | 仅双方收到通知 |
| **物品光晕** | 金色（公共信息） | 蓝色（私密信息） |
| **语音模式** | 公开对话 | 耳语模式 |
| **L3特写可见范围** | 所有人可见 | 仅接收方可见 |
| **笔记更新范围** | 所有人更新 | 仅双方更新 |
| **展示者动作** | 高举物品，身体朝向众人 | 手持物品靠近身体，身体朝向接收方 |
| **背景变化** | 全局略暗（所有人聚焦） | 无变化（其他人无感知） |


**一句话总结**：公开展示强调“仪式感”——通知、光晕、全局聚焦、所有人同步获取信息；私下分享强调“私密感”——无全局通知、耳语模式、仅接收方可见特写、其他人只能通过观察推断发生了什么。两者的视觉设计差异，本身就是信息博弈的一部分。
