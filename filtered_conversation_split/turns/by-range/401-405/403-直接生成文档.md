# 《开本 / Paralls》完整项目计划书

## 一、产品定位与核心愿景

### 1.1 产品名称
**开本 / Paralls**

### 1.2 核心定义
智能体驱动的3D沉浸式动态叙事平台。首款产品形态为多人动态剧本杀，玩家与AI智能体共同参演谋杀谜案，通过自由探索、实时对话、空间互动来影响剧情走向。

### 1.3 核心承诺
**同一个剧本，每一次游戏都不同。**

### 1.4 核心创新
- 从“固定剧本”到“动态涌现叙事”
- 从“文字描述”到“3D世界实时交互”
- 从“人类DM主持”到“AI司命+角色智能体”
- 从“一次性体验”到“无限平行世界”

### 1.5 世界观总称
**开本宇宙** —— 所有平行世界的集合体。每个平行世界拥有唯一编号（如UNV-001），是一个完整且自洽的世界观框架。一个平行世界可以容纳无数个剧本，每个剧本都是该世界某段时空中的一个故事切片。


## 二、三阶段演进路线

### Phase 1：核心体验验证
**核心问题**：AI驱动的动态剧本杀能否让玩家感受到“那个AI角色真的在骗我，而且它骗得有道理”？

**核心交付**：
- 动态案件生成、人格驱动AI、司命实时导演、3D空间音频社交
- 首个剧本《血字的研究·变奏》，智能体轻量带走，小世界基础
- 支持8种核心目标（追凶、逃脱、生存、守护、复仇、嫁祸、逃脱（空间）、坦白）
- 11种特殊人群（调查者、隐匿者、操控者、守护者、记录者、伪装者、逃脱者、审判者、生存者、复仇者、阴谋家）
- 证据链系统完整闭环、玩法系统通用化、离线时间线补全

### Phase 2：跨局叙事与创作者生态
**核心问题**：连续单局能否让AI羁绊产生长期情感价值？创作者工具能否引爆内容供给？

**核心交付**：
- 种子库系统、续集承接、跨剧本记忆、智能体资产化
- 伪装系统完整版、暗杀能力体系、知情人网络
- 系列侦探故事、恋爱模拟、剧本化身（官方史诗系列）
- 剧本编辑器开放、大玩家服务器上线、AI同伴带入新剧本

### Phase 3：世界生态与宏大叙事
**核心问题**：永续运行的世界能否成为真正的“第二人生”？UGC生态能否自我造血？

**核心交付**：
- 持续运行世界、双层玩家身份、资产经营、跨世界旅行
- 种田经营、SLG策略、MMORPG式活态世界、开放世界RPG
- 世界编辑器、大玩家主题世界、AI势力管理
- 小世界完整版（小镇生态、多同伴共存、场景化商店）


## 三、核心AI系统

### 3.1 角色智能体
**完整心智模型**：基因种子 → 人生记忆 → 品格层 → 行为层 → 四层决策系统（L1感知→L2理解→L3规划→L4执行）→ 记忆系统

**五维人格参数**：胆量、心机、共情、理性、社交（各0-10）

**品格层**：诚实、忠诚、正义感、仁慈、责任感 + 价值优先级

**人格过滤器（三重验证）**：人设过滤器 → 逻辑过滤器 → 得失过滤器

**动态状态**：压力值、信任值、怀疑值、情绪标签

**特殊人群分类**：11种核心人群由三个正交维度（行为性质、社会关系、信息立场）唯一确定

### 3.2 司命（Siming）
**核心定位**：开本运行时核心智能体，集编剧与导演于一身的世界主宰，实时创作并改写剧本。

**技术架构**：Harness编排框架 + 大模型(LLM) + 规则程序(Rule Engine)

**五个子系统**：
- 事实核心：事实锁定时间线管理、逻辑一致性检查
- 天平系统：实时监测游戏态势，防止碾压性优势或僵局
- 冲突与案件生成器：检测角色间动态冲突，条件满足时生成新案件
- 高阶知识图谱引擎：维护所有参与者的知识状态
- 干预执行器：四层干预阶梯（冲动/环境/NPC引导/节奏）

**干预四原则**：间接、不可见、逻辑自洽、公平

### 3.3 感知系统
**核心原则**：智能体不截图，接收结构化语义事件流。通过感知过滤器按角色感官档案过滤，与人类玩家完全同源计算。支持视觉、听觉、触觉、热感等多感官，盲人角色视觉禁用但听觉增强。动作的意图阶段即可感知并反应（本能反应<300ms）。

### 3.4 模型路由
**三层架构**：
- L1规则引擎（50-150ms）：处理本能反应、威胁响应
- L2本地小模型（200-800ms）：处理常规对话、兜底回应
- L3云端大模型（800-3000ms）：处理复杂推理、策略规划

**硬上限**：P0致命300ms / P1紧急1500ms / P2重要3000ms / P3普通2500ms


## 四、核心游戏机制

### 4.1 案件与真相系统
- 事实锁定时间线：T0（剧本创作）→T1（房间创建）→T2（玩家加入）→T3（游戏中）
- 案件框架随机生成：死因池、动机池、凶器池、作案条件
- 凶手候选：所有角色平等（真人玩家和AI智能体均可）
- 真相不可变，但通往真相的路径无限

### 4.2 信息博弈系统
- **空间音频**：清晰区/模糊区/静默区/耳语模式，物理阻挡和偷听机制
- **三种知识形态**：公共知识、共有知识、高阶知识（A知道B知道X）
- **信息共享方式**：公开对话、耳语、展示物品、带人查看、留影石/相机
- **知情人网络**：固定/动态NPC知情人，反制策略（收买/威胁/灭口）

### 4.3 暗杀与阴谋系统
- **暗杀触发**：致命动机+信息空窗期+独处窗口+能力匹配+代价评估
- **暗杀能力**：L0-L4，由角色人生记忆决定
- **阴谋系统**：涵盖环境致死、蓄意破坏、伪造现场、销毁证据等
- **共谋机制**：多人协作的阴谋，信任门槛，背叛机制

### 4.4 证据与痕迹系统
- **物品流转追踪器**：记录所有物品的拾取/移交/丢弃历史
- **接触痕迹管理器**：记录指纹/唾液/纤维，支持基于观察技能的可见性判定
- **生物痕迹管理器**：记录血迹/毛发/皮屑，与ESM联动管理状态变化
- **ESM环境状态管理器**：管理物体物理状态变化（烧毁/破碎/潮湿/氧化）


## 五、AI陪伴与小世界

### 5.1 羁绊建立
在剧本中共同经历事件，自然涌现信任与依赖。带走机制需满足信任值/好感度阈值，通过玩家主动邀请、司命判断关系、人格过滤器决策、坦白与契约的完整叙事仪式。

### 5.2 小世界
- **画风设定**：可消费、可切换，可与AI同伴捆绑销售
- **小镇生态**：智能体居民、季节节日、随机事件、居民关系网络
- **场景化商店**：家具、服装、道具散落在小镇商铺中，沉浸式购物
- **生物成长**：植物和动物的阶段式成长，点云过渡视觉呈现
- **离线时间线补全**：登录时司命瞬间补全离线期间的关键事件

### 5.3 跨世界旅行
携带AI同伴进入新剧本，能力受世界压制，记忆完整保留。需要购买“世界化身”进行外观和能力适配。

## 七、技术架构

### 7.1 三层架构
- **L1 确定性空间层**（Godot 4.x + Steam Audio）：3D渲染、物理、空间音频、事件埋点
- **L2 智能体交互层**（Python + LLM + 小模型）：角色智能体、司命、对话生成、模型路由
- **L3 视觉增强层**（图片/视频生成API + 实时演算）：线索特写、记忆闪回、结局CG

### 7.2 事件总线
WebSocket直连+内存队列+NATS的混合架构。硬实时控制走内存直连（纳秒级），实时交互走WebSocket（毫秒级），高吞吐推送走NATS Core，持久化指令走NATS JetStream。

### 7.3 数据基础设施
PostgreSQL（事实库、用户数据）、Redis（状态缓存）、Milvus/Pinecone（向量记忆索引）、MinIO/S3（资产存储）
