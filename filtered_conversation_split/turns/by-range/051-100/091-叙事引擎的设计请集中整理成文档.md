# 叙事引擎 (Narrative Engine) 设计文档

## 一、核心定位

叙事引擎是 **Paralls（开本）运行时核心智能体**，是“无限书海”得以动态运转的心脏。它在世界观中被称为 **“书页守护者” (Keeper of the Page)**。

| 维度 | 说明 |
| :--- | :--- |
| **系统身份** | 运行时唯一拥有全局视野的智能体，独立于角色智能体运行 |
| **权限等级** | 高于角色智能体（可向角色发送消息），但**不直接控制玩家** |
| **核心使命** | 维护事实逻辑、催化叙事涌现、守护游戏平衡 |
| **行动原则** | 间接、不可见、逻辑自洽、公平 |
| **世界观化身** | 书页守护者——每一本书页的秩序与戏剧张力的守护意识 |

---

## 二、内部架构

叙事引擎由 **五个子系统** 构成，协同工作：

```
┌─────────────────────────────────────────────┐
│              叙事引擎 (Narrative Engine)      │
│                                              │
│  ┌──────────┐ ┌──────────┐ ┌──────────────┐ │
│  │ 事实核心 │ │ 天平系统 │ │ 冲突与案件   │ │
│  │          │ │          │ │ 生成器       │ │
│  └────┬─────┘ └────┬─────┘ └──────┬───────┘ │
│       │             │              │         │
│  ┌────┴─────────────┴──────────────┴───────┐ │
│  │           高阶知识图谱引擎              │ │
│  └────────────────┬───────────────────────┘ │
│                   │                          │
│  ┌────────────────┴───────────────────────┐ │
│  │           干预执行器                    │ │
│  │  (冲动发送 / 环境催化 / NPC引导 / 节奏) │ │
│  └────────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

### 2.1 事实核心 (Fact Core)

- **职责**：存储并守护游戏中所有不可变事实与已锁定事实。
- **功能**：
  - **事实锁定时间线管理**：严格遵循 T0（剧本创作）→ T1（房间创建）→ T2（玩家加入）→ T3（游戏中）的锁定流程。
  - **逻辑一致性检查**：任何角色言论、行为与事实库冲突时，标记并阻止该行为。
  - **矛盾记录**：当两个角色说法矛盾时，标记为“待解决矛盾”，成为潜在推理线索。
  - **信息泄露防护**：确保角色智能体不能说出其未知的信息。
- **写权限**：仅叙事引擎拥有对事实库的写权限。

### 2.2 天平系统 (Balance System)

- **职责**：实时监测游戏态势，防止出现碾压性优势或僵局。
- **监测指标**：
  - **线索分布均衡度**：关键线索是否过度集中于某一方。
  - **阵营胜率预测**：基于当前已揭露事实模拟投票结果。
  - **玩家参与度**：是否有玩家被边缘化（长时间无交互/无新信息）。
  - **游戏节奏**：推理进度过快或过慢。
- **输出**：失衡警报 + 干预建议，发送给干预执行器。

### 2.3 冲突与案件生成器 (Conflict & Case Generator)

- **职责**：检测角色间动态冲突，并在条件满足时生成新案件。
- **触发条件检测**：
  - **目标冲突**：两个角色的目标层级产生不可调和矛盾。
  - **机会窗口**：某个角色获得作案机会（独处、凶器在旁）。
  - **秘密濒临暴露**：角色的核心秘密即将被揭穿，可能铤而走险。
- **生成流程**：
  1. 动机评估（调用角色的目标/恐惧层级）
  2. 能力评估（物理空间中的可行性）
  3. 人格过滤（该角色真的会这么做吗？）
  4. 叙事价值评估（是否让故事更有趣而非更混乱）
  5. 通过后锁定为新事实

### 2.4 高阶知识图谱引擎 (Higher-Order Knowledge Engine)

- **职责**：维护所有参与者“知道什么”以及“知道别人知道什么”的动态模型。
- **数据结构**：
  - 节点：游戏中的事实。
  - 边：角色对事实的知识状态（未知/疑似/确认/公开）。
  - 高阶边：A知道B知道X，A不确定B是否知道X 等。
- **实时更新**：每次对话、展示、目击事件都触发图谱更新。
- **推理接口**：角色智能体决策时，可调用图谱获取其视角下的高阶知识。

### 2.5 干预执行器 (Intervention Executor)

- **职责**：将天平系统的失衡警报转化为具体干预行动。
- **干预阶梯**（由弱到强）：
  - **Lv1 智能体冲动**：向符合逻辑的NPC发送模糊冲动（如“你突然想去地下室看看”）。
  - **Lv2 环境催化**：改变场景状态（如风吹开窗帘露出线索、天气突变困住众人、灯光故障制造阴影）。
  - **Lv3 NPC引导**：向NPC发送“确凿信息”（如唤醒其本应知道的记忆），推动故事。
  - **Lv4 节奏控制**：触发新事件延长或缩短游戏阶段，引入新的公共事件打破僵局。
- **审核机制**：所有干预方案需通过**干预原则过滤器**（见第五章），通过后才能执行。

## 三、干预原则过滤器

所有干预行为在发送前，必须通过四重原则检查：

| 原则 | 检查内容 | 不通过示例 |
| :--- | :--- | :--- |
| **间接性** | 是否直接控制玩家？ | 强制玩家移动、禁用玩家选项、替玩家做决定 |
| **不可见性** | 是否会被玩家感知为“系统干预”？ | 弹出系统提示、凭空出现物品、无世界观解释的巧合 |
| **逻辑自洽** | 是否有合理的故事内解释？ | 让胆小如鼠的NPC去挑战凶手、让完全不懂医术的角色诊断死因 |
| **公平性** | 是否偏袒某一方？ | 在凶手即将暴露时删除证据、只为一方的暗杀创造机会 |

## 四、与角色智能体的协作协议

叙事引擎与角色智能体通过 **事件总线** 通信，遵循严格的消息协议。

| 消息方向 | 消息类型 | 说明 |
| :--- | :--- | :--- |
| 引擎 → 角色 | `impulse` (冲动) | 模糊的行为倾向，如“你开始怀疑XX”。角色自主决定是否响应，是否执行由人格过滤器判断 |
| 引擎 → 角色 | `fact_reveal` (事实披露) | 告知角色其本应知道的事实（如“你当时确实在走廊听到了争吵”） |
| 引擎 → 角色 | `opportunity` (机会提示) | 暗杀等高风险行为的机会窗口信息（见第六章） |
| 引擎 → 角色 | `state_query` (状态查询) | 请求角色当前心理状态，用于天平评估 |
| 角色 → 引擎 | `action_report` (行为报告) | 角色执行任何交互后上报，供引擎更新事实和知识图谱 |
| 角色 → 引擎 | `request_intervention` (请求干预) | 角色陷入困境时可请求建议（仅限AI角色，且引擎不一定响应） |

**核心原则：引擎只催化，不控制。角色的所有行为最终由其自身的心智模型决定。**

## 五、自监控与动态调节

叙事引擎具备自监控能力，防止自身过度干预。

| 监控指标 | 阈值 | 过载处理 |
| :--- | :--- | :--- |
| **干预频率** | 每10分钟不超过3次Lv2+干预 | 暂停主动干预，进入观察模式 |
| **玩家困惑度** | 玩家重复搜索同一区域、对话中出现大量疑问词 | 适当增加Lv1冲动引导 |
| **AI负载** | 引擎CPU/API调用延迟超标 | 降低干预精度，只保留事实一致性检查 |
| **暗杀频率** | 单局游戏暗杀催化（含未遂）超过2次 | 暂停暗杀机会排列，进入冷却 |

## 六、暗杀催化机制

### 6.1 催化原则

叙事引擎是暗杀的 **主动催化者**，遵循 **“只要不破坏游戏可玩性，监测到符合逻辑的动机，就开始指引”** 的原则。

| 前提 | 检测方式 | 说明 |
| :--- | :--- | :--- |
| **符合逻辑的动机** | 监测角色的目标层级/恐惧层级/人生记忆 | 仇恨、灭口、自保、保护他人、秘密濒临暴露 |
| **不破坏游戏可玩性** | 天平系统评估暗杀后果 | 不导致一方碾压性优势或游戏过早结束 |

### 6.2 动机监测清单

| 动机类型 | 检测信号 | 强度判定 |
| :--- | :--- | :--- |
| **仇恨** | 人生记忆中存在对某角色的仇恨事件 | 仇恨对象在场即触发 |
| **灭口** | 某角色掌握了指向自己的关键证据 | 证据暴露风险越高，动机越强 |
| **自保** | 自己被怀疑值持续上升，即将被指认 | 怀疑值≥7时动机激活 |
| **保护他人** | 忠诚度≥8的对象面临威胁 | 威胁越紧迫，动机越强 |
| **秘密濒临暴露** | 核心秘密被他人掌握且即将公开 | 公开倒计时越短，动机越强 |

**当任一动机强度达到阈值，引擎将该角色标记为“潜在暗杀者”。**

### 6.3 可玩性评估（催化前必检）

| 评估维度 | 不通过条件 | 处理 |
| :--- | :--- | :--- |
| **阵营平衡** | 暗杀发生后，某一方胜率预测超过90% | 不催化 |
| **玩家体验** | 目标是唯一掌握关键线索的玩家，暗杀后将导致推理链断裂 | 不催化，或先催化其他事件补充线索 |
| **节奏控制** | 游戏开始不足10分钟，或距投票不足3分钟 | 不催化 |
| **频率控制** | 同一角色已被催化过2次暗杀 | 不催化 |

### 6.4 催化流程

```
[引擎持续扫描]
    │
    ├── 检测到符合逻辑的动机 ✅
    ├── 可玩性评估通过 ✅
    │
    ▼
[催化阶段一：条件排列]
    │ 环境催化 → 创造独处空间
    │ NPC引导 → 调离目击者
    │ 信息延迟 → 延长证据空窗期
    │ 空间巧合 → 提供隐蔽路径
    │
    ▼
[催化阶段二：指引推送]
    │ 向潜在暗杀者推送暗杀机会面板
    │ 告知条件状态、风险、窗口时间
    │
    ▼
[催化阶段三：弹窗确认]
    │
    ├── [ 执行暗杀 ] → 暗杀启动 → 阶段化感知 → 后果链
    └── [ 放弃 ] → 同目标同动机不再催化
```

### 6.5 弹窗确认机制

暗杀条件就绪时，向扮演者弹出（仅自己可见）：

```
┌──────────────────────────────────────────┐
│  ⚠️ 暗杀机会                              │
│                                          │
│  目标：玛丽·萨瑟兰                       │
│  位置：书房（独处）                       │
│  动机：玛丽掌握了你的致命证据，尚未公开   │
│  窗口：约2分钟（管家将在2分钟后巡视）     │
│  风险：中等（厨房后门无人，但隔壁有仆人） │
│  你的暗杀能力：L2（可徒手勒杀）           │
│                                          │
│  [ 执行暗杀 ]    [ 放弃 ]               │
└──────────────────────────────────────────┘
```

- 弹窗出现时游戏不暂停，窗口时间继续流逝。
- 超时未操作默认放弃。
- 放弃后，同目标同条件不再弹窗。

### 6.6 催化后的克制机制

| 克制手段 | 说明 |
| :--- | :--- |
| **冷却期** | 一次暗杀催化后（无论执行与否），引擎进入冷却 |
| **防御催化** | 连续催化偏向同一方时，为劣势方催化防御条件（如让管家提前巡视） |
| **上限控制** | 单局总暗杀事件（含初始案件）不超过3起 |
| **复盘透明** | 游戏结束后的故事报告中，玩家可看到引擎催化了哪些机会，但不暴露未触发的暗杀 |

## 七、运行时位置

叙事引擎不直接与客户端交互，所有消息经由事件总线。它与角色智能体处于同一层级，但拥有对事实库和知识图谱的独占写权限。

```
┌─────────────────────────────────────┐
│            游戏客户端 (Godot)        │
└──────────────┬──────────────────────┘
               │ 事件流
┌──────────────▼──────────────────────┐
│           事件总线                   │
└──┬──────┬──────┬──────┬─────────────┘
   │      │      │      │
   ▼      ▼      ▼      ▼
┌────┐ ┌────┐ ┌────┐ ┌─────────────┐
│玩家│ │AI  │ │AI  │ │ 叙事引擎    │
│    │ │角色│ │角色│ │ (核心智能体)│
└────┘ └────┘ └────┘ └─────────────┘
```

## 八、创作者可配置参数

在大玩家控制台或剧本编辑器中，可调节叙事引擎的以下参数：

| 参数 | 说明 | 可选值 |
| :--- | :--- | :--- |
| **干预强度** | 控制引擎主动催化的程度 | 轻度（仅逻辑检查）/ 中度（平衡调控）/ 重度（主动催化冲突） |
| **暗杀催化开关** | 是否允许引擎催化暗杀机会 | 开启 / 关闭 |
| **节奏偏好** | 倾向快节奏还是慢节奏 | 偏快 / 平衡 / 偏慢 |
| **结局偏好** | 是否倾向某种结局类型 | 无偏好 / 倾向悲剧 / 倾向正义 |
| **动态知情人敏感度** | NPC目击可疑行为的基准概率 | 低 / 中 / 高 |
