## 用户

我们将支持多少种类型和难度等级的剧本杀？

## DeepSeek

我们不是简单罗列一个固定的类型列表，而是设计一套**多维度、可组合的分类体系**。创作者可以像搭积木一样，从不同维度中勾选标签，组合出独一无二的剧本类型。同一个剧本也可以同时拥有多个标签。

## 二、具体说明

### 推理流派 (4种)

| 类型 | 说明 |
| :--- | :--- |
| **本格** | 逻辑至上，注重写实，所有手法在现实中理论上可实现 |
| **变格** | 包含科学无法解释的元素，如鬼怪、穿越、魔法 |
| **新本格** | 世界观或背景是变格的，但核心杀人手法和逻辑链是本格的 |
| **叙诡** | 叙述性诡计，利用信息差或文本结构误导玩家 |

### 核心玩法 (8种)

| 类型 | 核心乐趣 | Paralls增强 |
| :--- | :--- | :--- |
| **硬核推凶** | 破解复杂手法和逻辑链 | 3D现场还原、L3视觉增强 |
| **故事还原** | 拼凑碎片信息，还原故事全貌 | 关系网络图、时间线视图 |
| **阵营对抗** | 分属不同阵营进行博弈 | 空间音频、伪装系统、暗杀机制 |
| **情感沉浸** | 体验角色的情感冲突和抉择 | 人生记忆闪回、人格驱动NPC |
| **恐怖惊悚** | 恐怖氛围和紧张感 | 3D场景、动态光影、声音陷阱 |
| **机制对抗** | 小游戏改变资源或线索获取 | 可交互场景、物品系统 |
| **欢乐轻松** | 诙谐幽默，轻松社交 | 棋牌等轻量社交模块 |
| **立意深思** | 围绕深刻主题展开 | 品格层、动态结局、故事报告 |

### 题材背景 (10种)

古风 / 民国 / 现代 / 未来科幻 / 奇幻仙侠 / 西方古典 / 日式 / 克苏鲁/怪诞 / 赛博朋克 / 架空世界

### 世界动态性 (3种)

| 等级 | 说明 | 叙事引擎介入 |
| :--- | :--- | :--- |
| **线性叙事** | 故事有明确的主线和结局方向 | 轻度，仅维护逻辑一致性 |
| **分支叙事** | 玩家行为会导向不同结局分支 | 中度，管理分支逻辑 |
| **涌现叙事** | 新案件和新故事线完全由玩家行为触发 | 重度，主动催化冲突 |

### 空间交互深度 (3种)

| 等级 | 说明 |
| :--- | :--- |
| **静态场景** | 场景为背景，可移动但无可交互物品 |
| **可交互场景** | 大量可拾取、检查、使用的物品 |
| **动态机关场景** | 含迷宫、密道、密室、机关等复杂空间机制 |

### 伪装与博弈深度 (3种)

| 等级 | 说明 |
| :--- | :--- |
| **轻度** | 简单身份隐藏，无伪装道具系统 |
| **中度** | 完整伪装系统，含公开/真实档案和伪装道具 |
| **重度** | 中度基础上增加知情人网络和灭口机制 |

### 特殊机制 (可多选，7种)

时间循环 / 多重时间线 / 暗杀机制 / 角色特殊状态（中毒、致幻等）/ 动态阵营切换 / 盲凶模式 / PvPvE混合

### 难度等级 (3种)

| 等级 | 适合人群 | 特征 |
| :--- | :--- | :--- |
| **新手 (⭐)** | 零基础玩家、社交型玩家 | 规则简单、线索明显、时长较短(45-60min)、高引导 |
| **进阶 (⭐⭐)** | 有经验的玩家 | 机制适中、需一定推理、时长60-90min |
| **烧脑 (⭐⭐⭐)** | 硬核推理爱好者 | 逻辑复杂、线索隐蔽、允许高自由度涌现叙事、时长90-120min+ |

## 四、总计

| 分类维度 | 可选数量 |
| :--- | :--- |
| 推理流派 | 4种 |
| 核心玩法 | 8种 |
| 题材背景 | 10种 |
| 世界动态性 | 3种 |
| 空间交互深度 | 3种 |
| 伪装与博弈深度 | 3种 |
| 特殊机制 | 7种（可多选） |
| 难度等级 | 3种 |

**可组合出的独特剧本类型：理论上数万种。** 这确保了Paralls平台上的剧本杀体验具有无限的多样性和可扩展性，让每个创作者都能找到自己的表达方式，让每个玩家都能找到适合自己的剧本。
