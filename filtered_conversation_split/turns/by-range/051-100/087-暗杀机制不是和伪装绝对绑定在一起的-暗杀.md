## 暗杀机制的正确定位

### 一、暗杀的触发条件（非伪装绑定）

暗杀不是玩家想杀谁就杀谁，而是系统检测到以下条件同时满足时，才会向扮演者开放暗杀选项：

| 触发条件 | 说明 | 示例 |
| :--- | :--- | :--- |
| **致命动机** | 角色目标层级或恐惧层级中，存在必须让对方消失的理由 | 仇恨（对方是杀父仇人）、灭口（对方掌握了关键证据）、自保（对方即将揭露自己） |
| **信息空窗期** | 对方掌握的证据尚未公开，或对方尚未将信息传递给其他人 | 玩家A发现玩家B掌握了自己是凶手的证据，但B还未公开 |
| **独处窗口** | 目标当前处于可被暗杀的空间位置（独处、深夜、无人区域） | 深夜走廊无人、对方独自在书房 |
| **能力匹配** | 角色具备执行暗杀的能力等级（L1-L4） | 老管家有街头经验(L2)，富家千金完全不会(L0) |
| **代价评估** | 暗杀失败或暴露的代价，小于不暗杀的代价 | 不杀对方，自己必然暴露；杀对方，可能有一线生机 |

**只有当上述条件全部满足时，系统才会向该角色的扮演者推送暗杀任务指引。**

---

### 二、暗杀作为“迫不得已”的叙事事件

| 触发路径 | 说明 |
| :--- | :--- |
| **仇恨驱动** | 角色人生记忆中埋藏的复仇目标，在游戏中相遇，仇恨值达到阈值 |
| **证据危机** | 自己的不利证据被他人掌握，且对方尚未公开，存在信息空窗期 |
| **秘密濒临暴露** | 自己的核心秘密即将被揭穿，灭口是最后的保护手段 |
| **连锁反应** | 前一案件调查逼近自己，为掩盖第一案而制造第二案 |
| **保护他人** | 高忠诚度/高共情者，为保护在意的人而暗杀威胁者 |
| **意外冲突** | 原本只是想威胁或质问对方，但冲突升级导致失控 |

**每一次暗杀都应该是故事的关键转折点，是角色被逼到绝境时的最终选择，而非一个随意的游戏操作。**

### 四、暗杀的配套支撑系统（保持不变）

| 系统 | 说明 |
| :--- | :--- |
| **暗杀能力等级 (L0-L4)** | 由角色人生记忆决定，控制可用暗杀方式和痕迹控制 |
| **暗杀条件判断** | 动机 + 信息空窗期 + 独处窗口 + 能力 + 代价 五重判定 |
| **阶段化感知** | 意图阶段即推送 `action_intent` 事件，目标可即时本能反应 |
| **本能反应规则** | P0致命威胁走L1规则引擎，300ms内本能反应 |
| **痕迹生成系统** | 暗杀必然留下物证、时间线矛盾和潜在目击者 |
| **叙事引擎介入** | 监控暗杀后果，管理连锁反应，防止一边倒，生成新的调查方向 |

---

**总结：暗杀机制是独立的叙事事件触发系统，由致命动机、信息空窗期、独处窗口、能力匹配、代价评估五重条件共同驱动。它不与伪装绑定，而是任何角色在极端压力下都可能面临的“迫不得已”的选择。**
