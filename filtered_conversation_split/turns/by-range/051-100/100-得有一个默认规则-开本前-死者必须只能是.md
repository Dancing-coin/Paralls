## 用户

得有一个默认规则，开本前，死者必须只能是npc（首先，局内参与者分为玩家和npc，玩家包括人类玩家和智能体玩家，npc包括智能体npc和程序npc），局内发生暗杀才会导致玩家死亡，更倾向于让npc死亡。 局内必须有多个npc增强体验，npc可以是智能体驱动也可以是纯程序驱动，可以由剧本经营者也就是大玩家设置，但剧本本身会有硬性规则，有些npc对体验的重要程度必须使用智能体驱动。

## DeepSeek

# 开本 (Paralls) 默认规则：死者与参与者管理


## 一、参与者分类

开本世界中的所有参与者，分为两大类别：

```
开本参与者
├── 玩家（可扮演角色，可被暗杀死亡）
│   ├── 人类玩家
│   └── 智能体玩家
│
└── NPC（不可被初始案件设为死者，不可被暗杀）
    ├── 智能体NPC（由人格系统驱动）
    └── 程序NPC（由简单规则/脚本驱动）
```

| 参与者类型 | 定义 | 可否扮演角色 | 可否成为初始死者 | 可否被暗杀 |
| :--- | :--- | :--- | :--- | :--- |
| **人类玩家** | 真人通过客户端参与 | ✅ | ❌ | ✅ |
| **智能体玩家** | AI驱动的角色扮演者 | ✅ | ❌ | ✅ |
| **智能体NPC** | AI驱动的非玩家角色，有完整人格 | ❌ | ✅ | ❌ |
| **程序NPC** | 简单规则驱动的非玩家角色 | ❌ | ✅ | ❌ |

**关键区分**：
- **玩家**（人类/智能体）= 可扮演剧本中的主要角色，参与投票和推理，可能成为暗杀目标
- **NPC**（智能体/程序）= 不扮演主要角色，提供线索、服务、氛围，不可被暗杀


## 二、初始案件死者规则（开本前锁定）

### 核心规则：死者必须只能是NPC

| 规则项 | 说明 |
| :--- | :--- |
| **死者身份** | 只能是智能体NPC或程序NPC |
| **不可为玩家** | 人类玩家和智能体玩家均不可成为初始死者 |
| **锁定时间** | T1（房间创建）随机生成死因、凶器后，T2（玩家加入）从NPC中随机选择死者并锁定 |

### 规则目的

- 保证所有真人玩家从开局就能参与游戏，不会“开场即退场”
- 保证所有智能体玩家能全程参与推理和博弈
- 让NPC承担叙事铺垫的功能


## 三、局内死亡规则

### 3.1 暗杀导致死亡

局内死亡仅由**暗杀机制**触发。暗杀由司命催化机会、扮演者确认执行。

| 暗杀目标 | 结果 | 说明 |
| :--- | :--- | :--- |
| **人类玩家** | 该玩家角色死亡，玩家可进入旁观模式或退出 | 死亡后无法继续参与投票和行动 |
| **智能体玩家** | 该智能体角色死亡，退出游戏 | 该角色不再参与后续推理 |
| **NPC**（智能体/程序） | 不可被暗杀 | NPC不参与暗杀目标池 |

**暗杀限制**：
- 单局暗杀事件（含未遂）不超过3起
- 同一角色被催化暗杀机会不超过2次
- 司命在催化前评估可玩性，避免关键玩家被暗杀导致游戏崩溃

### 3.2 非暗杀死亡

| 死亡类型 | 说明 | 可否发生 |
| :--- | :--- | :--- |
| **初始案件死者** | 开本前的谋杀案 | ✅ 仅NPC |
| **暗杀** | 局内发生的谋杀 | ✅ 目标可为玩家或NPC |
| **意外死亡** | 陷阱、机关、中毒等 | ✅ 剧本特殊机制可支持，目标优先NPC |


## 四、NPC配置规则

### 4.1 NPC数量要求

每个剧本必须配置**最低NPC数量**，以增强叙事深度和游戏体验。

| 剧本玩家数 | 最低NPC总数 | 其中最低智能体NPC数 |
| :--- | :--- | :--- |
| 4-5人本 | 不少于3个 | 不少于1个 |
| 6-7人本 | 不少于4个 | 不少于2个 |
| 8人以上本 | 不少于5个 | 不少于2个 |

### 4.2 NPC驱动方式

| 驱动方式 | 说明 | 适用场景 |
| :--- | :--- | :--- |
| **智能体驱动** | 拥有完整人格档案、记忆系统和自主决策能力 | 关键线索提供者、知情人、嫌疑人、红鲱鱼 |
| **程序驱动** | 由简单规则/脚本/状态机控制，无自主推理能力 | 服务员、路人、功能性角色（如“管家巡视”的执行者） |

### 4.3 硬性规则：必须使用智能体驱动的NPC

以下NPC类型**必须使用智能体驱动**，不可降级为程序NPC：

| 必须智能体驱动的NPC类型 | 原因 |
| :--- | :--- |
| **知情人NPC** | 掌握关键信息，需要根据局势决定是否透露、对谁透露 |
| **嫌疑人NPC** | 需要应对玩家质询，生成符合人设的谎言或辩解 |
| **动机相关NPC** | 与死者有复杂恩怨，需要表现出真实的情感反应 |
| **可被收买/威胁的NPC** | 需要基于自身人格得失计算，决定是否接受交易 |
| **故事线关键NPC** | 其行为直接影响主线推进，需要动态决策 |

### 4.4 大玩家可配置项

大玩家在经营服务器时，可在以下范围内调整NPC配置：

| 可配置项 | 范围 | 限制 |
| :--- | :--- | :--- |
| **程序NPC数量** | 可增加 | 不可减少至低于剧本最低要求 |
| **智能体NPC数量** | 可增加（将程序NPC升级为智能体） | 不可将硬性规定的智能体NPC降级 |
| **NPC外观/名称** | 可修改 | 不可修改其核心功能和知情信息 |


## 五、与现有系统的关系

### 5.1 与事实锁定的关系

| 时间节点 | 死者相关 | NPC相关 |
| :--- | :--- | :--- |
| **T0** | 死者身份不锁定 | NPC列表、类型、驱动方式全部锁定 |
| **T1** | 死因、凶器随机生成 | - |
| **T2** | 从NPC池中随机选择死者并锁定 | - |
| **T3** | 新案件死者可为玩家或NPC | 动态NPC可能因目击而成为新案件死者 |

### 5.2 与暗杀机制的关系

- 暗杀目标池包含所有玩家（人类和智能体），不包含NPC
- NPC是暗杀的“知情人”和“目击者”，而非暗杀目标
- 初始死者（NPC）的死亡是暗杀的叙事引子

### 5.3 与司命的关系

- 司命在T1为初始案件从NPC中随机选择死者
- 司命在T3监测暗杀动机时，不将NPC纳入暗杀目标池
- 司命在催化暗杀机会时，评估暗杀玩家是否破坏可玩性


## 六、总结

| 规则 | 内容 |
| :--- | :--- |
| **初始死者** | 必须只能从NPC（智能体NPC或程序NPC）中选择 |
| **局内暗杀死者** | 可为人类玩家或智能体玩家，不可为NPC |
| **NPC最低数量** | 按剧本玩家规模配置，不少于3-5个 |
| **硬性智能体NPC** | 知情人、嫌疑人、动机相关者必须使用智能体驱动 |
| **大玩家权限** | 可增加NPC数量、升级驱动方式，不可降级或减少核心NPC |
