## 用户

剧本杀有多少种类型

## DeepSeek

剧本杀的分类方式多种多样，一个剧本通常也混合了多种类型标签。目前主要有以下几个维度的分类方式：

### 🧠 按推理流派分类
这主要看剧本中的世界观设定和核心诡计的逻辑基础。

*   **本格本**：以逻辑至上，注重写实，所有案件手法在现实中理论上可以实现[reference:0]。
*   **变格本**：包含科学无法解释的元素，如鬼怪、穿越、魔法等，常有恐怖、荒诞的描写[reference:1][reference:2]。
*   **新本格本**：世界观或故事背景是变格的（有超自然设定），但核心杀人手法和逻辑链是本格的[reference:3][reference:4]。
*   **叙诡本**：全称“叙述性诡计”，利用文本结构或信息差误导玩家，直到最后才揭晓真相[reference:5]。

### 🎯 按核心玩法分类
这是当下最主流的分类方式，决定了游戏的核心乐趣[reference:6][reference:7]。

*   **硬核本**：推理难度高，以破解复杂手法和逻辑链为唯一目的[reference:8]。
*   **还原本**：重在拼凑碎片信息，还原整个故事真相，而不仅仅是找出凶手[reference:9]。
*   **阵营本**：玩家分属不同阵营进行对抗，考验社交与博弈能力[reference:10]。
*   **情感本**：重情感沉浸，人物情感丰富，主打感人故事[reference:11]。
*   **恐怖本**：通过剧本、搜证环节或NPC演绎渲染恐怖惊悚氛围[reference:12]。
*   **机制本**：在游戏中加入小游戏，改变玩家资源或线索获取方式[reference:13][reference:14]。
*   **欢乐本**：情节诙谐幽默，充满笑点和轻松设定，适合朋友聚会[reference:15]。
*   **立意本**：围绕深刻的人生哲理或社会议题展开，引发玩家思考[reference:16]。

### 📱 按游戏形式分类
这决定了“怎么玩”。

*   **线上剧本杀**：通过APP用语音交流，方便快捷[reference:17]。
*   **线下剧本杀**：在实体店由DM主持游戏，体验更好[reference:18]。
    *   **桌面剧本杀**：玩家围坐一桌，通过纸本阅读和卡牌搜证[reference:19]。
    *   **实景/沉浸式剧本杀**：在主题房间内角色扮演，玩家可换上服装，体验更沉浸[reference:20]。

### 📦 按剧本规格分类
这主要涉及商业运营和销售模式[reference:21][reference:22]。

*   **盒装本**：所有剧本店都可购买，价格最亲民[reference:23]。
*   **城市限定本（城限）**：一个城市只授权给3-4家店铺，内容品质通常更高[reference:24]。
*   **独家本**：一个城市仅授权一家店铺，最具稀缺性，常配合定制化演绎[reference:25]。

### 📖 按题材背景分类
这是故事的外衣，决定了时代背景和故事风格[reference:26][reference:27]。

*   **按年代分**：古风、民国、现代、未来、架空等[reference:28][reference:29]。
*   **按地域/风格分**：中式、日式、欧式、美式等[reference:30]。
*   **按内容分**：校园、武侠、科幻、宫斗、谍战、IP衍生等[reference:31][reference:32]。

### 🌟 按用户阶段/难度分类
*   **新手本**：流程简单，适合零基础玩家[reference:33][reference:34]。
*   **进阶本**：有一定复杂度，需要玩家具备基本的推理能力[reference:35]。
*   **烧脑/高阶本**：逻辑复杂，线索繁多，是硬核玩家的选择[reference:36]。

### 🔧 其他特殊分类
*   **封闭本 vs 开放本**：封闭本的流程和结局是固定的；开放本则允许玩家通过决策影响剧情走向[reference:37]。
*   **明凶本 vs 盲凶本**：明凶本中凶手玩家明确知道自己的身份；盲凶本中凶手玩家初始也可能不知道自己是凶手，需和其他玩家一起推理。
*   **PVP vs PVE**：PVP侧重玩家间对抗（如阵营本、推凶）；PVE侧重玩家合作对抗剧本机制（如一同破解密室机关）。

### 💎 总结
一个成熟的商业剧本，通常会融合多种分类标签以制造更丰富的游戏体验。例如：
*   **一个经典的情感本可能融合了：** `古风` (题材) + `情感` (核心玩法) + `还原` (辅助玩法) + `变格` (推理流派) + `新手` (难度) + `城市限定` (规格)。
*   **一个典型的硬核推理本可能融合了：** `欧式` (题材) + `硬核` (核心玩法) + `本格` (推理流派) + `烧脑` (难度) + `盒装` (规格)。

### 🤔 这对我们构建"Paralls"有何启示？
我们的目标不是复制传统剧本杀的分类，而是去定义新的维度。我们提供的工具箱让创作者可以自由组装以下Paralls专属标签：

| 基础维度 | 说明 |
| :--- | :--- |
| **题材时代** | 古风、民国、现代、未来、奇幻、科幻等 |
| **核心玩法** | 推凶、还原、阵营、情感沉浸、机制对抗、合作生存等 |
| **推理流派** | 本格、变格、新本格、叙诡、时空诡计等 |
| **玩家规模** | 小型（4-5人）、中型（6-7人）、大型（8人以上） |

| Paralls专属维度 | 说明 |
| :--- | :--- |
| **世界动态性** | **线性**（叙事导演轻度介入） vs **涌现**（叙事导演重度介入，AI动态生成剧情） |
| **智能体交互深度** | **辅助**（NPC仅提供线索） vs **核心**（NPC有独立人格，是故事关键） |
| **空间交互类型** | **静态**（场景仅作背景） vs **动态**（场景含大量可交互机关、迷宫、密室） |
| **伪装与博弈深度** | **轻度**（简单身份隐藏） vs **重度**（完整的伪装系统、知情人与灭口机制） |
| **特殊机制** | 时间循环、多重时间线、记忆碎片、角色状态（中毒、致幻）等 |
| **PvX模式** | PvP（玩家对抗）、PvE（合作对抗环境）、PvPvE（混合） |

这套分类体系是Paralls剧本编辑器的骨架，它将帮助创作者在海量可能性中找到方向，组合出前所未有的剧本杀体验。
