## 为什么打斗不是必要的

### 1. 打斗与核心体验的矛盾

Paralls的核心体验是**社交推理与动态叙事**。打斗的加入会引入几个难以调和的矛盾：

| 矛盾 | 说明 |
| :--- | :--- |
| **打断叙事节奏** | 打斗是一个实时对抗事件，会把所有人的注意力从对话、推理、探索中强行拉走，变成“谁打赢了”的结果导向 |
| **引入数值对抗** | 一旦有打斗系统，能力等级对比、环境修正、结果判定都会变成数值游戏。这与我们追求的“人格驱动决策”和“叙事涌现”在体验上割裂 |
| **破坏社交推理** | 打斗结果直接决定生死，可能让一个精心构建的推理链条因为一次打斗失败而瞬间断裂。被武力碾压的玩家体验极差 |
| **难以优雅融入世界观** | 大多数剧本杀的时代背景（维多利亚伦敦、南宋临安）不鼓励正面武力冲突。打斗会破坏时代氛围和沉浸感 |

### 2. 暗杀已经足够

暗杀机制已经覆盖了暴力行为的核心需求：

| 暗杀的特点 | 为什么适合Paralls |
| :--- | :--- |
| **是策略，不是反应** | 暗杀需要计划、时机、能力匹配，是一次深思熟虑的选择，而非即时反应的对抗 |
| **推动叙事而非中断叙事** | 暗杀的结果是“有人死了”，这本身就是新的谜题，推动所有人进入新一轮的调查和推理 |
| **保留悬念** | 暗杀可能成功、可能留下痕迹、可能被目击。即使成功，凶手是谁仍是谜。这与打斗不同——打斗暴露身份，暗杀隐藏身份 |
| **符合故事逻辑** | 在剧本杀的叙事框架中，“有人在暗中下手”比“两人当众互殴”更符合悬疑推理的氛围 |

### 3. 被攻击方的策略空间

没有打斗系统，不意味着被暗杀者毫无反抗之力。被攻击方的策略空间是：

| 阶段 | 策略 |
| :--- | :--- |
| **暗杀发生前** | 察觉到有人对自己有杀意（通过高阶知识、他人警告），可以主动避开独处场合、寻求他人保护、或先发制人揭露对方 |
| **暗杀进行中** | 如果发现有人靠近自己且意图可疑，可以大声呼救、逃跑、躲藏。这些行为增加暗杀者的目击风险和计时压力 |
| **暗杀发生后（幸存或死后）** | 即使被暗杀死亡，角色生前留下的日记、线索、与其他人的对话记录，仍可能在死后发挥影响，帮助其他角色找出真凶 |

这种策略空间是**社交性的、叙事性的**，而非数值对抗性的，与Paralls的核心体验完全一致。

## 暗杀系统的简化版

去掉打斗后，暗杀系统可以简化为：

```
[暗杀触发] → [能力检查] → [场景检查] → [暗杀计时] → [目击判定] → [结果]
```

| 结果 | 条件 |
| :--- | :--- |
| **完全成功** | 计时完成，无人目击。目标死亡，凶手未知 |
| **成功但有目击风险** | 计时完成，有人进入模糊区。目击者获得“疑似”信息 |
| **被中断** | 计时未完成，有人进入清晰区。目标受伤或逃脱，凶手暴露 |

被攻击方在暗杀计时期间的应对是**社交性的**（呼救、逃跑、躲藏），而非武力反击。

---

## 结论

打斗对Paralls来说是一个多余的、甚至有害的机制。它引入的数值对抗和实时冲突会破坏我们精心构建的社交推理和动态叙事体验。

**只保留暗杀，是更优雅、更聚焦的选择。** 暗杀作为“隐藏的暴力”，完全符合剧本杀的悬疑氛围。
