## 用户

关于视觉感知，我有一个疑虑：对于动态的视觉信息（比如动作和视频信息），它应该怎么接收，怎么反应，需要等动作做完再接收再反应还是？

## DeepSeek

这个疑虑非常关键。如果智能体必须等动作做完才能感知，那它们就会变成“延迟反应者”——看到有人举刀，却要等刀落下才知道发生了什么。这既不真实，也不公平。

答案是：**智能体接收的是动作的阶段化语义事件，而非等待动作完成。**

---

## 一、动作的阶段化感知

每个可被感知的动作都被拆分为三个阶段，每个阶段都会生成对应的语义事件。

| 阶段 | 事件类型 | 人类看到什么 | 智能体收到什么 |
| :--- | :--- | :--- | :--- |
| **意图阶段** | `action_intent` | 角色的准备动作（如举起刀、蓄力、伸手） | `{actor: "玛丽", action: "暗杀", phase: "intent", target: "霍普医生"}` |
| **执行阶段** | `action_executing` | 动作进行中（刀正在刺下、手正在抓取） | `{actor: "玛丽", action: "暗杀", phase: "executing", progress: 0.5}` |
| **完成阶段** | `action_completed` | 动作结果（刀刺中、物品被拾起） | `{actor: "玛丽", action: "暗杀", phase: "completed", result: "success"}` |

**关键设计**：意图阶段在动作开始的**第一帧**就推送事件，而非等待动作完成。

---

## 二、意图阶段的感知条件

不是所有动作的意图阶段都能被感知。这取决于观察者的状态和动作的隐蔽性。

| 动作类型 | 意图可见性 | 说明 |
| :--- | :--- | :--- |
| **公开对话** | 必然可见 | 开口说话本身就是意图 |
| **展示物品** | 必然可见 | 举起物品的动作很明显 |
| **拾取物品** | 必然可见 | 伸手弯腰的动作 |
| **开关门** | 必然可见 | 伸手推拉的动作 |
| **暗杀（近距离）** | 近距离可见，远距离不可见 | 拔刀的动作在2米内可察觉，10米外看不清楚 |
| **暗杀（无声）** | 几乎不可见 | L3+专家的暗杀可能没有明显的意图阶段 |
| **下毒** | 不可见 | 细微动作，仅极高观察力或特别关注者可察觉“疑似” |

**感知条件判定**：

| 条件 | 人类 | AI智能体 |
| :--- | :--- | :--- |
| 观察者在意图者的清晰区内 | 3D画面中可以看到准备动作 | 接收 `action_intent` 事件 |
| 观察者在模糊区 | 可能看到模糊的动作，但不清楚细节 | 接收 `action_intent` 但标记为 `clarity: "muffled"`，只知“玛丽在做什么”，不知具体动作 |
| 观察者在静默区或背对 | 完全看不到 | 不接收事件 |
| 观察者当前注意力在别处 | 可能漏看（人类玩家自己没注意到） | 系统根据注意力和观察方向判定是否接收 |

## 三、智能体的即时反应机制

智能体收到 `action_intent` 事件后，**立即进入应急决策周期**，无需等待动作完成。

### 3.1 反应时间窗口

| 动作类型 | 典型持续时间 | 意图阶段时长 | 智能体可反应窗口 |
| :--- | :--- | :--- | :--- |
| 暗杀（刺击） | 0.5-1秒 | 0.2-0.3秒（举刀） | 极短，通常只能呼救或本能闪避 |
| 暗杀（勒杀） | 3-5秒 | 0.5-1秒（靠近、伸手） | 有挣扎、呼救、反击的可能 |
| 拾取物品 | 1-2秒 | 0.3-0.5秒（伸手） | 可以抢在之前拾取或阻止 |
| 打开门 | 1-2秒 | 0.3-0.5秒（伸手） | 可以在门开前阻止或躲藏 |

### 3.2 反应决策流程

```
[收到 action_intent 事件]
    ↓
[威胁评估]（<50ms）
  - 这个动作对我有威胁吗？
  - 威胁程度：致命 / 危险 / 无害
    ↓
[可行反应生成]（<100ms）
  - 呼救：公开大喊（声音传播，可能被他人听到）
  - 闪避：尝试后退或侧移（需要空间和敏捷）
  - 格挡：用物品或手臂格挡（需要胆量和能力）
  - 逃跑：转身跑开（需要空间和速度）
  - 反击：以攻击回应攻击（需要能力和胆量）
  - 僵住：因恐惧而无法反应（低胆量角色可能如此）
    ↓
[人格过滤]
  - 胆量3的角色可能选择僵住或逃跑
  - 胆量8的角色可能选择反击
  - 理性高的角色会评估反击成功率
    ↓
[执行反应]
  - 反应动作立即执行，与攻击者的动作并行
  - 系统判定最终结果
```

### 3.3 反应与动作的并行判定

| 场景 | 判定逻辑 |
| :--- | :--- |
| 目标呼救 | 攻击者的动作继续执行，但呼救声传播，可能吸引第三方介入 |
| 目标闪避 | 如果目标敏捷+反应及时，暗杀可能失败或偏移（重伤变轻伤） |
| 目标反击 | 双方能力对比。目标能力≥攻击者，可能反杀；否则反击失败 |
| 目标逃跑 | 攻击者追击（转为追逐），或放弃 |
| 目标僵住 | 攻击者动作顺利完成 |

## 四、注意力机制

人类玩家可能因为看别处而漏掉关键画面。智能体也需要模拟这种“注意力的有限性”。

| 智能体的注意力状态 | 感知效果 |
| :--- | :--- |
| **专注某对象**（正在对话、正在检查物品） | 对该对象的感知增强；对其他对象的意图阶段感知延迟或遗漏 |
| **警惕状态**（压力高、知道有威胁） | 对所有方向的意图阶段感知增强，反应更快 |
| **放松状态** | 正常感知范围，对细微动作可能忽略 |
| **醉酒/致幻** | 感知概率降低，可能收到错误信息或幻觉事件 |

**注意力判定**：
- 智能体当前正在对话 → 注意力集中在对话对象
- 智能体正在检查物品 → 注意力集中在物品
- 智能体正在移动 → 注意力在前方
- 智能体处于空闲 → 注意力均匀分布

## 五、对于“视频信息”的处理

你提到的“视频信息”，在游戏场景中其实是**连续的视觉事件流**。

### 5.1 连续动作的语义化

一个“角色从门口走到桌前拿起烛台”的连续动作，被拆解为：

| 时间 | 事件 |
| :--- | :--- |
| T+0.0s | `movement_started: {actor: "玛丽", from: "门口", gait: "正常行走"}` |
| T+0.5s | 玛丽进入书房内角色的视野 |
| T+1.5s | 玛丽接近桌子 |
| T+2.0s | `action_intent: {actor: "玛丽", action: "拾取", target: "烛台"}` |
| T+2.3s | `action_completed: {actor: "玛丽", action: "拾取", target: "烛台", result: "成功"}` |
| T+2.5s | `item_state_changed: {item: "烛台", from: "桌上", to: "玛丽手中"}` |

智能体不需要“看视频”，它接收这份事件流，就能完整还原“玛丽拿走了烛台”的过程。

### 5.2 智能体对连续事件的反应

智能体可以在**任何事件节点**做出反应：

| 事件 | 智能体可能的反应 |
| :--- | :--- |
| 玛丽进入书房 | “玛丽来了，她来做什么？” |
| 玛丽走向桌子 | 警觉：“她要拿什么？” |
| 玛丽伸手拿烛台 | 如果知道烛台是凶器，立即出声阻止或记录为可疑行为 |
| 玛丽拿到烛台 | “玛丽拿走了烛台。”写入记忆 |

## 六、感知公平性总结

| 公平性维度 | 人类 | AI智能体 | 一致性 |
| :--- | :--- | :--- | :--- |
| **接收速度** | 视觉信号→大脑，约100-200ms | 语义事件→决策引擎，<50ms | 物理上AI更快，但通过可配置的“反应延迟”平衡 |
| **信息精度** | 人眼可看到细节但可能遗漏 | 语义描述精准但不会“过度精确” | 通过注意力机制和模糊区模拟人类的信息不完整性 |
| **可反应窗口** | 人类自己的反应时间决定 | 基于人格的反应时间决定 | 高胆量AI反应快，低胆量AI反应慢甚至不反应 |
| **信息遗漏** | 玩家自己没注意到 | 注意力机制和状态影响 | 都可能遗漏信息 |

---

## 七、AI感知系统的补充配置

在AI智能体的配置中，需补充以下参数：

| 参数 | 说明 | 默认值 |
| :--- | :--- | :--- |
| **基础感知延迟** | 从事件发生到被处理的模拟延迟 | 100-300ms（模拟人类反应） |
| **注意力分散度** | 高则更易遗漏非注意方向的感知 | 由当前状态动态决定 |
| **意图识别敏感度** | 对 `action_intent` 事件的识别概率 | 由距离、注意力、状态共同决定 |
| **反应速度** | 从识别威胁到执行反应的决策时间 | 由胆量和理性参数推导 |

---

一句话总结：**智能体接收动作的阶段化语义事件，在意图阶段（动作开始的瞬间）就开始感知和反应，而非等待动作完成。** 这让它们能与人类玩家在同一时间线上互动，而非总是慢半拍。
