## 玩家默认交互面板

### 设计原则

| 原则 | 说明 |
| :--- | :--- |
| **常驻可见** | 核心信息始终在屏幕上，无需额外操作即可查看 |
| **按需展开** | 详细内容通过点击或快捷键展开，不遮挡主视野 |
| **可关闭增强** | 所有辅助功能（变声器、润色、辅助面板）均可一键关闭 |
| **角色代入优先** | 信息呈现方式符合角色视角，避免“游戏UI感”过重 |

### 二、各模块详细设计

#### 2.1 角色状态栏（常驻，左上角）

始终可见，显示当前角色的基本信息。

| 显示内容 | 说明 | 交互 |
| :--- | :--- | :--- |
| **角色姓名** | 公开身份的名字 | 点击可展开完整档案 |
| **公开身份** | 一行简述（如“庄园管家”） | - |
| **当前压力值** | 可视化进度条（0-10），仅自己可见 | 悬停显示压力来源 |
| **当前情绪标签** | 如“紧张”、“冷静”、“恐惧”，仅自己可见 | 悬停显示情绪影响说明 |

**完整档案面板（点击姓名展开，居中弹窗）**：

| 分区 | 内容 |
| :--- | :--- |
| **基础信息** | 姓名、年龄、职业、外貌描述、3D形象预览 |
| **公开背景** | 对外宣称的经历（可编辑，如有伪装） |
| **角色能力** | 暗杀能力等级、特殊技能列表 |
| **秘密与目标** | 核心秘密（仅自己可见）、目标层级 |
| **关系网络** | 对其他角色的真实态度（仅自己可见） |
| **伪装状态** | 当前伪装深度、伪装道具清单及持有情况 |

**关键设计**：
- 档案中的“公开背景”部分，如有伪装，玩家可以直接在此编辑
- 秘密与关系网络**永远仅自己可见**，不会因误操作泄露
- 伪装道具清单显示每个道具的当前状态（在手中/在房间某处/已被发现）

---

#### 2.2 快捷交互栏（动态，屏幕中下方）

根据玩家当前可交互的对象，动态显示可用动作。

| 动作按钮 | 触发条件 | 效果 |
| :--- | :--- | :--- |
| **交谈** | 附近有其他角色 | 进入公开对话状态 |
| **耳语** | 附近有特定角色 | 进入耳语模式，清晰区缩小至1米 |
| **查看** | 准星对准可互动物品 | 打开物品详情面板 |
| **拾取** | 准星对准可拾取物品 | 物品进入背包 |
| **使用** | 手持物品或面对机关 | 使用当前物品或触发机关 |
| **展示** | 手持物品 | 向视野内所有角色展示该物品 |
| **移交** | 手持物品+附近有角色 | 将物品交给指定角色 |
| **拍摄** | 持有留影石/相机 | 记录当前视野画面 |
| **暗杀** | 满足暗杀条件 | 进入暗杀计时（仅有能力者可见此按钮） |
| **跟随** | 对准角色 | 请求跟随该角色移动 |

**动态显示规则**：
- 不满足条件的动作**不显示**（如无暗杀能力者永远看不到“暗杀”按钮）
- 高风险动作（如“暗杀”）在按钮旁有微弱的警告色
- 玩家也可在设置中关闭高风险动作的显示

---

#### 2.3 背包面板（底部，可展开）

常驻显示最近获得的1-2件物品，点击展开完整背包。

**完整背包面板（点击展开，居中弹窗）**：

| 分区 | 内容 |
| :--- | :--- |
| **线索物品** | 所有已获得的线索，点击可查看详情、展示、移交 |
| **伪装道具** | 维持伪装所需的道具，标注当前状态（携带/已藏匿/已丢失） |
| **凶器相关** | 任何可能被判定为凶器的物品 |
| **留影/照片** | 拍摄的照片或留影石幻象，可查看、展示、移交 |
| **普通物品** | 其他拾取的物品 |
| **消耗品** | 毒药、药品等使用后消失的物品（如有） |

**物品交互选项（右键或长按物品）**：
- 查看详情
- 展示给周围人
- 移交给他（选择附近角色）
- 使用（如适用）
- 丢弃/藏匿（需选择位置，有时间代价）

---

#### 2.4 语音与润色状态栏（底部，常驻）

| 显示内容 | 说明 | 交互 |
| :--- | :--- | :--- |
| **语音状态指示器** | 当前是否在发言（绿点/红点） | - |
| **变声器开关** | ✅ 开 / ❌ 关 | 点击切换。关闭时语音使用原声 |
| **文字润色开关** | ✅ 开 / ❌ 关 | 点击切换。关闭时消息以原文发送 |

**变声器详细设置（点击变声器图标展开）**：

| 设置项 | 说明 |
| :--- | :--- |
| **开关** | 一键开关 |
| **当前变声方案** | 显示系统自动配置的方案（如“老年男性-威严”） |
| **试听** | 点击可试听自己变声后的效果 |
| **强度调节** | 滑块调节变声程度（微妙 → 极端） |

**文字润色详细设置（点击润色图标展开）**：

| 设置项 | 说明 |
| :--- | :--- |
| **开关** | 一键开关 |
| **润色强度** | 轻度（仅修正语气词）/ 中度（调整句式） / 重度（完全改写为角色语言风格） |
| **预览** | 发送前预览润色后的文本 |
| **本次发送不润色** | 快捷按钮，仅跳过当前消息的润色 |

---

#### 2.5 辅助面板入口（底部，与设置并列）

点击“辅助面板”按钮后展开一个独立窗口，包含所有辅助模块。

**辅助面板窗口（可拖动、可调整大小）**：

| 标签页 | 内容 | 说明 |
| :--- | :--- | :--- |
| **玩法指引** | 动态规则书 + 当前阶段说明 | 根据游戏进程高亮相关规则 |
| **信息整理** | 线索笔记 + 时间线视图 + 关系网络图 | 玩家可手动拖拽连线整理逻辑 |
| **决策参考** | 基于当前局势的行动建议 | 仅提供选项方向，不替玩家做决定 |
| **任务追踪** | 角色目标清单 + 完成进度 | 显示目标的优先级 |

**辅助面板的独立性**：
- 每个标签页可单独关闭
- 整个辅助面板可通过一键关闭
- 关闭后不影响任何游戏功能，仅移除辅助信息的显示

---

#### 2.6 特殊状态提示（屏幕中央偏上）

当角色受到特殊状态影响时，短暂显示提示。

| 状态 | 提示方式 |
| :--- | :--- |
| **中毒** | 屏幕边缘泛绿，持续10秒后淡化为细微色调 |
| **致幻** | 视野偶尔出现轻微扭曲，听到不存在的声音 |
| **醉酒** | 移动操作有微小延迟，视野轻微模糊 |
| **PTSD触发** | 屏幕短暂闪回战争画面（L3视觉增强），伴随心跳声 |
| **被发现伪装** | 屏幕边缘泛红，压力值进度条闪烁 |
| **被跟踪/监视** | 偶尔听到身后有脚步声，但转身无人 |

这些提示是**沉浸式的感官反馈**，而非弹窗文字，让玩家通过体验感受状态变化，而非通过阅读知晓。

| `R` | 切换文字润色开关 |

### 四、设置面板

玩家可通过`Esc`打开设置，自定义以下内容：

| 设置类别 | 具体选项 |
| :--- | :--- |
| **变声器
