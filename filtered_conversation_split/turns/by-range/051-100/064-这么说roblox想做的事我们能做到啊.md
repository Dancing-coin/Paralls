## DeepSeek

你说到了一个关键的区分点。Paralls和Roblox确实都在做“让玩家创造游戏”这件事，但我们的底层逻辑和最终形态完全不同。

Roblox是想做**所有游戏的平台**，而Paralls是想做**所有“有人味的游戏”的平台**。

---

## Roblox能做什么，我们不能做什么

Roblox的核心是**物理引擎 + 通用开发工具**。它给开发者的是一个空白的沙盒，你可以用它做射击游戏、赛车游戏、模拟经营、跑酷——任何你能用代码和模型搭建出来的东西。

这是Roblox的优势，也是它的边界。它不做“人”，它只做物理。

| Roblox的能力 | Paralls能吗 | 说明 |
| :--- | :--- | :--- |
| 赛车游戏 | ❌ 不适合 | 核心是物理模拟和操作手感，不是角色驱动的叙事。我们没有物理引擎优势 |
| 跑酷游戏 | ❌ 不适合 | 核心是关卡设计和操作精度，不是社交推理和人格博弈 |
| 射击竞技 | ❌ 不适合 | 核心是枪械手感和平衡性，不是叙事涌现 |
| FPS对战 | ❌ 不适合 | 同上 |
| 音乐节奏游戏 | ❌ 不适合 | 核心是音频同步和操作反馈 |

**Paralls不是“所有游戏的平台”，而是“叙事驱动的社交游戏平台”。** 任何核心乐趣在于**物理操作、实时反应、纯数值对抗**的游戏类型，都不适合我们的基础设施。

---

## Paralls能做什么，Roblox做不好什么

我们的基础设施是为**角色自主行为、社交博弈、动态叙事**而生的。这些是Roblox的通用工具无法直接提供的东西。

| Paralls的能力 | Roblox能吗 | 说明 |
| :--- | :--- | :--- |
| 智能体驱动的无限剧本杀 | ❌ | Roblox没有人格系统、知识图谱、叙事导演。开发者需要手动编写所有对话和行为树 |
| 人格驱动的SLG | ❌ | Roblox的AI势力是预设策略树，不会因人格参数而自主改变战略风格 |
| 动态叙事RPG | ❌ | Roblox的NPC是固定的对话树，不会根据玩家行为和自身人格涌现新剧情 |
| 社交推理（狼人杀/鹅鸭杀） | 勉强可以 | 但社交部分完全依赖真人玩家，AI无法参与博弈。我们的人格AI可以填补角色空缺 |
| 动态跑团 | ❌ | 需要AI主持人能即兴叙事，这是LLM+人格系统的强项，不是物理引擎的强项 |

**我们的护城河不是“什么游戏都能做”，而是“有人的游戏才能做”。**

---

## 正确的定位：叙事社交游戏的模板化平台

Paralls不是Roblox，也不是Steam创意工坊。我们是：

**一个提供“角色驱动、叙事涌现、社交博弈”基础设施的游戏在线搭建平台。大玩家基于官方或社区模板，修改参数、替换资产、调整规则，创造自己的平行世界。**

我们的模板不是“空白的游戏引擎”，而是**已经包含了人格AI、知识图谱、叙事导演、空间音频等系统的半成品游戏**。大玩家做的不是“开发”，而是“改造”。

| 模板类型 | 官方提供什么 | 大玩家可以改什么 |
| :--- | :--- | :--- |
| **剧本杀模板** | 完整的角色系统、案件框架、伪装机制、搜证系统 | 角色设定、案件规则、场景布局、线索设计、时代背景、新增机制 |
| **跑团模板** | AI主持人、角色创建系统、检定规则、动态叙事引擎 | 世界观设定、规则系统、职业/种族、怪物图鉴、模组剧情 |
| **SLG模板** | 阵营系统、人格驱动的AI决策、资源管理、战争框架 | 势力划分、科技树、地图布局、武将设定、事件表 |
| **社交推理模板** | 阵营对抗、空间音频、投票系统、任务系统 | 角色能力、胜利条件、地图设计、任务内容、特殊机制 |
| **棋牌模板** | 牌局规则引擎、AI牌手人格、社交牌桌 | 具体玩法规则、牌面设计、筹码系统、锦标赛赛制 |

---

## 大玩家的操作：基于模板的“改造”，而非“从零开发”

| 大玩家的操作 | 说明 |
| :--- | :--- |
| **选择模板** | 从官方模板库中选择一个基础模板（如“本格推理剧本杀模板”） |
| **Fork模板** | 创建自己的版本，链上记录来源 |
| **修改角色** | 在角色编辑器中调整人格参数、背景故事、秘密、能力 |
| **替换场景** | 从资产市场选择或上传自己的3D场景 |
| **调整规则** | 在允许范围内修改案件生成规则、投票机制、时间限制 |
| **添加机制** | 从机制库中勾选额外机制（如“时间循环”、“迷宫”、“暗杀”） |
| **配置智能体** | 调整叙事导演的干预强度、AI角色的自主程度 |
| **测试模拟** | 用AI自动跑完剧本，观察叙事走向和逻辑漏洞 |
| **发布上线** | 发布到自己的服务器，开始经营 |

**大玩家不需要写代码。** 他们在编辑器中调整的是参数、选项、资产，而非编写游戏逻辑。所有游戏逻辑都由Paralls的底层引擎驱动。

## 平台边界：我们承载的是“叙事驱动的社交游戏”

总结来说，Paralls理论上可以承载：

| 可承载 | 不可承载 |
| :--- | :--- |
| 剧本杀（本格/变格/阵营/情感/机制/恐怖） | FPS射击游戏 |
| 跑团（D&D/COC/原创规则） | 赛车竞速游戏 |
| 社交推理（狼人杀/鹅鸭杀/阿瓦隆） | 硬核动作游戏 |
| 策略博弈（棋牌/SLG/战棋） | 音乐节奏游戏 |
| 叙事RPG（剧情驱动/动态世界） | 纯物理模拟游戏 |
| 密室逃脱（合作解谜） | 体育竞技游戏 |
| 派对游戏（轻量社交/欢乐对抗） | 格斗对战游戏 |
| 模拟经营（人格AI驱动的NPC生态） | 弹幕射击游戏 |

**我们的边界是：核心乐趣必须来自“角色之间的互动、博弈和叙事”，而非“物理操作或数值对抗”。**

---

## 一句话总结

Roblox给你一个**空白的物理世界**，让你从头搭建一切。

Paralls给你一个**已经活着的角色世界**，让你改造他们的人生，创造属于你的平行世界。

我们是“角色驱动的叙事社交游戏平台”，不是“通用游戏引擎”。而这个看似更窄的定位，恰恰是我们在AI时代最深的护城河——因为“有人味的游戏”，Roblox做不了，Steam创意工坊做不了，只有我们，从第一天起就在为角色的灵魂而设计一切。
