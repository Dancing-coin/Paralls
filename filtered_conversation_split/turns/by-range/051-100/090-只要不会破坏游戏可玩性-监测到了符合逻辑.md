---

## 叙事引擎暗杀催化原则

### 一、催化的两个前提

| 前提 | 检测方式 | 说明 |
| :--- | :--- | :--- |
| **符合逻辑的动机** | 检测角色的目标层级/恐惧层级/人生记忆中是否存在暗杀动机 | 仇恨、灭口、自保、保护他人、秘密濒临暴露 |
| **不破坏游戏可玩性** | 天平系统评估暗杀发生后是否会导致一方碾压性优势或游戏过早结束 | 若会破坏平衡，引擎不催化 |

**当两个前提同时满足，引擎即可主动催化。**

---

### 二、动机监测清单

引擎持续扫描所有角色的以下动机信号：

| 动机类型 | 检测信号 | 强度判定 |
| :--- | :--- | :--- |
| **仇恨** | 人生记忆中存在对某角色的仇恨事件 | 仇恨对象在场即触发 |
| **灭口** | 某角色掌握了指向自己的关键证据 | 证据暴露风险越高，动机越强 |
| **自保** | 自己被怀疑值持续上升，即将被指认 | 怀疑值≥7时动机激活 |
| **保护他人** | 忠诚度≥8的对象面临威胁 | 威胁越紧迫，动机越强 |
| **秘密濒临暴露** | 核心秘密被他人掌握且即将公开 | 公开倒计时越短，动机越强 |

**当任一动机强度达到阈值，引擎将该角色标记为“潜在暗杀者”。**

---

### 三、可玩性评估

催化前，天平系统必须通过以下检查：

| 评估维度 | 不通过条件 | 处理 |
| :--- | :--- | :--- |
| **阵营平衡** | 暗杀发生后，某一方胜率预测超过90% | 不催化，等待局势变化 |
| **玩家体验** | 目标如果是唯一掌握关键线索的玩家，暗杀后将导致推理链彻底断裂 | 不催化，或先催化其他事件补充线索 |
| **节奏控制** | 游戏刚开始不足10分钟，或距投票不足3分钟 | 不催化 |
| **频率控制** | 同一角色已被催化过2次暗杀 | 不催化，防止过度 |

---

### 四、催化流程

```
[引擎持续扫描]
    │
    ├── 检测到符合逻辑的动机 ✅
    ├── 可玩性评估通过 ✅
    │
    ▼
[催化阶段一：条件排列]
    │
    │ 环境催化：创造独处空间
    │ NPC引导：调离目击者
    │ 信息延迟：延长证据空窗期
    │ 空间巧合：提供隐蔽路径
    │
    ▼
[催化阶段二：指引推送]
    │
    │ 向潜在暗杀者推送暗杀机会面板
    │ 告知条件状态、风险、窗口时间
    │
    ▼
[催化阶段三：弹窗确认]
    │
    ├── [ 执行暗杀 ] → 暗杀启动
    └── [ 放弃 ] → 同目标同动机不再催
```

---

### 五、引擎催化与角色自主的平衡

| 引擎做什么 | 引擎不做什么 |
| :--- | :--- |
| 检测动机，标记潜在暗杀者 | 不替角色决定是否暗杀 |
| 排列条件，创造机会窗口 | 不强制触发暗杀 |
| 推送指引，提供信息支持 | 不绕过弹窗确认 |
| 管理后果，生成新调查链 | 不为暗杀者消除痕迹 |

---

### 六、催化后的克制机制

| 克制手段 | 说明 |
| :--- | :--- |
| **冷却期** | 一次暗杀催化后（无论执行与否），引擎进入冷却，短时间内不催化新暗杀 |
| **防御催化** | 如果连续催化偏向同一方，引擎会为劣势方催化防御条件（如让管家提前巡视） |
| **上限控制** | 单局游戏总暗杀事件（含初始案件）不超过3起，防止变成大逃杀 |
| **复盘透明** | 游戏结束后的故事报告中，玩家可以看到“幕后花絮”——引擎催化了哪些机会，但不暴露未触发的暗杀 |

---

**总结：叙事引擎是暗杀的主动催化者。只要检测到符合逻辑的动机，且催化不会破坏游戏可玩性，引擎就应主动排列条件、推送指引、弹窗确认。但它永远只创造机会，不替角色扣下扳机。**
