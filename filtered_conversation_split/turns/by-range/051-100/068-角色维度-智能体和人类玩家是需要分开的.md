## DeepSeek

你说得对。角色维度虽然同时涵盖智能体和人类玩家，但两者的系统处理方式、自由度、可配置项有本质区别。不能混为一谈。

---

## 角色维度的分拆

在Paralls的角色编辑器中，创作者需要分别定义三类配置：

| 配置类别 | 适用对象 | 说明 |
| :--- | :--- | :--- |
| **通用角色配置** | 所有角色（无论智能体还是人类玩家） | 定义角色的基础身份、人格档案、关系网络 |
| **智能体专属配置** | 仅AI智能体 | 定义AI的决策风格、自主行为、伪装执行策略 |
| **人类玩家专属配置** | 仅人类玩家 | 定义玩家的目标指引、OOC监控、可操作范围 |

---

### 一、通用角色配置（所有角色共享）

这部分是角色的“骨架”，无论谁来扮演，角色本身的事实不变。

| 配置项 | 说明 |
| :--- | :--- |
| **基础信息** | 姓名、身份、年龄、外貌描述、3D模型绑定 |
| **角色背景** | 公开背景（所有人可见）、真实背景（仅自己可见） |
| **核心秘密** | 必须隐藏的真相 |
| **固定阵营** | 好人方 / 凶手方 / 中立 |
| **目标层级** | 按优先级排序的角色目标（开本时系统告知扮演者） |
| **恐惧层级** | 按强度排序的角色恐惧（开本时系统告知扮演者） |
| **品格层** | 道德取向（诚实/忠诚/正义感/仁慈/责任感）、价值优先级、自我认知 |
| **行为层** | 五维人格参数（胆量/心机/共情/理性/社交） |
| **语言风格** | 称谓习惯、句式特征、话题偏好、撒谎特征 |
| **关系网络** | 与其他角色的固定关系类型和强度 |
| **能力配置** | 暗杀能力等级、特殊技能 |
| **伪装配置** | 伪装深度、公开档案、伪装道具清单、固定知情人 |

**关键设计**：这些配置在开本时，无论该角色是智能体还是人类玩家扮演，系统都会向扮演者提供。人类玩家看到的是一份“角色说明书”，智能体则将配置加载为决策约束。

---

### 二、智能体专属配置（仅AI角色）

这部分定义了AI如何“扮演”这个角色——即如何基于通用配置进行自主决策。

| 配置项 | 说明 | 例子 |
| :--- | :--- | :--- |
| **自主程度** | AI主动发起行为的频率和积极性（被动/适中/活跃） | 高自主度：管家会主动巡视、主动找人交谈 |
| **决策风格** | 在人格参数约束下，AI偏好哪种决策模式 | 保守型：优先自保；激进型：优先实现目标；摇摆型：易受情绪影响 |
| **伪装执行策略** | AI如何管理自己的伪装 | 主动维护（定期检查伪装道具）、被动反应（只在被质疑时应对）、破罐破摔（压力高时可能放弃伪装） |
| **知情人行为** | 当AI角色知道他人秘密时，如何行动 | 守口如瓶、待价而沽、主动告密、暗中威胁 |
| **压力响应曲线** | 不同压力值下AI行为的变化模式 | 线性崩溃、阈值跳跃（压力7前保持正常，7后突然失态）、反向镇定（压力越高越冷静） |
| **社交偏好** | AI更倾向于与哪类角色互动 | 偏好高信任者、偏好同阵营、偏好孤立者、无偏好 |
| **对抗响应** | 被指控或攻击时的应对策略 | 强硬否认、转移话题、反指控、博取同情、沉默 |

**运行时**：这些配置决定了智能体在决策系统（L1-L4）中的行为倾向。同一个通用角色配置，搭配不同的智能体专属配置，会产生完全不同的AI表现——一个“懦弱的管家”和一个“狡猾的管家”，其通用配置可能相同（都是管家身份），但智能体专属配置的“决策风格”和“对抗响应”差异巨大。

---

### 三、人类玩家专属配置（仅人类玩家角色）

这部分不是“控制”玩家，而是**引导玩家入戏，并监控OOC行为**。

#### 1. 游玩指引

| 配置项 | 说明 |
| :--- | :--- |
| **角色目标提示** | 开本时向玩家展示的核心目标和次级目标，帮助玩家快速入戏 |
| **秘密保护提示** | 提醒玩家哪些秘密是绝对不能暴露的 |
| **技能使用提示** | 如果角色有特殊技能，提示在何种时机使用可能有效 |
| **伪装建议** | 对于有伪装深度的角色，系统在开本时提供“建议如何维持伪装”的游玩指导 |
| **暗杀任务指引** | 如果角色有暗杀能力且局势可能触发暗杀，系统在适当时机提供时机建议 |

#### 2. OOC监控与引导

| 配置项 | 说明 |
| :--- | :--- |
| **OOC检测强度** | 该角色对OOC行为的容忍度（严格/适中/宽松），由服务器或剧本配置 |
| **语言风格偏离检测** | 系统检测玩家发言是否与角色的语言风格配置严重偏离（如古人角色使用网络用语） |
| **信息违规拦截** | 检测玩家是否发送元信息（“你是AI吗”、“我看了攻略”），自动拦截并提示 |
| **OOC评分** | 系统对该玩家的实时OOC评分，供GM查看 |
| **OOC引导** | 当玩家持续轻度OOC时，系统通过环境NPC的反应进行软引导（如NPC表现出困惑），而非直接惩罚 |

#### 3. 人类玩家的特殊自由（智能体没有的）

| 自由项 | 说明 |
| :--- | :--- |
| **战略偏离权** | 玩家可以选择不完全按照角色人格行动（如胆小的角色选择勇敢揭发），这是策略的一部分，不被视为OOC |
| **编辑公开档案** | 玩家可以编辑和修改自己的公开档案（智能体的公开档案由系统根据伪装配置自动维护） |
| **销毁/转移证据** | 玩家可以主动销毁或藏匿伪装道具、凶器等证据 |
| **拒绝分享信息** | 玩家可以始终拒绝透露自己知道的信息，无需经过人格过滤器 |
| **主动灭口** | 玩家可以选择暗杀知情人（智能体是否暗杀由心智模型决策，不能由创作者预设） |

#### 4. 特殊玩家类型配置（可选）

| 玩家类型 | 说明 |
| :--- | :--- |
| **普通玩家** | 标准游玩体验，拥有上述所有自由和OOC监控 |
| **新手玩家** | 更详细的游玩指引，更宽松的OOC检测，额外的提示系统 |
| **GM玩家** | 拥有部分GM权限，可以以特定角色身份介入游戏，调节纠纷或催化剧情 |

---

**核心设计原则：**

- **通用配置**是角色的“灵魂”，决定了角色是谁。无论谁来扮演，角色的事实不变。
- **智能体配置**是AI的“表演指导”，决定了AI如何基于通用配置进行自主决策。
- **人类玩家配置**是玩家的“入戏引导”和“边界守护”，给玩家自由的同时，确保体验不崩坏。

人类玩家可以偏离角色人格（战略选择），但会被OOC系统标记；智能体不能偏离角色人格（被人格过滤器强制约束），但可以通过智能体配置表现出不同的表演风格。这种不对称，正是Paralls“人与AI共演”的魅力所在。
