## 一、产品愿景与核心概念

### 1.1 产品定位

**产品名称**：开本 / Paralls

**核心定义**：智能体驱动的3D沉浸式动态叙事剧本杀平台。

**核心承诺**：同一个剧本，每一次游戏都不同。

### 1.2 核心创新

| 传统剧本杀 | Paralls |
| :--- | :--- |
| 固定剧本，线性叙事 | 动态涌现叙事，玩家行为改变剧情 |
| 文字描述为主 | 3D世界实时交互 |
| 人类DM主持 | AI叙事引擎 + 角色智能体 |
| 一次性体验，重玩价值低 | 无限平行世界，每次开本都不同 |

### 1.3 核心体验闭环

```
选择剧本 → 选择角色 → 进入3D场景 → 自由探索与对话
    ↓
发现线索与秘密 → 私下/公开交流 → 新冲突涌现
    ↓
新案件可能发生 → 最终投票/对决 → 结局揭晓 → 本局故事报告
```

### 1.4 事实锁定时间线

| 时间节点 | 锁定内容 | 未锁定内容 |
| :--- | :--- | :--- |
| **T0：剧本创作完成** | 世界观、角色设定、场景、基础规则、作案条件池 | 具体案件事实 |
| **T1：游戏房间创建** | 案件框架（死因类型、关键线索分布） | 凶手身份、作案细节 |
| **T2：玩家选择角色并加入** | 全部初始案件事实（凶手、动机、作案过程） | 无 |
| **T3：游戏进行中** | 无新增锁定 | 叙事路径、新案件、结局走向 |

**T3阶段允许**：玩家行为触发全新谋杀案；新案件的凶手可以是真人玩家或AI智能体；新案件的动机和过程完全由当前局势实时生成。

## 二、IP世界观：无限书海

### 2.1 核心概念

一个名为 **“无限书海” (Bibliotheca Infinita)** 的跨维度空间。所有文学作品、民间怪谈、历史轶事中的人物与故事，都真实地平行存在于这里的不同“书页”中。

- **玩家身份**：观书人，意识投射进入不同书页世界
- **核心母题**：执念与放下、天理与人情、真相与选择
- **世界观守护者**：书页守护者 (Keeper of the Page)，即叙事引擎在世界观中的化身

### 2.2 首发剧本案例

| 剧本 | 类型 | 角色数 | 时长 | 特点 |
| :--- | :--- | :--- | :--- | :--- |
| 《血字的研究·变奏》 | 英式推理 | 5人 | 45-60分钟 | MVP首发，经典推理 |
| 《白蛇传·浮生》 | 东方志怪 | 5人 | 60-75分钟 | 情感冲突+阵营对抗 |
| 《东方快车谋杀案》 | 封闭空间推理 | 6人 | 50-65分钟 | 高玩挑战，群体博弈 |
| 《画皮》 | 恐怖生存 | 4人 | 40-55分钟 | 恐怖氛围，快速开局 |

## 五、智能体系统设计

### 5.1 完整心智模型架构

```
                ┌──────────────┐
                │   基因种子    │  出身、天赋、早年事件
                └──────┬───────┘
                       ↓
                ┌──────────────┐
                │   人生记忆    │  关键事件、长期状态、创伤、重大选择
                └──────┬───────┘
                       ↓
                ┌──────────────┐
                │   品格层      │  道德取向、价值优先级、自我认知
                └──────┬───────┘
                       ↓
                ┌──────────────┐
                │   行为层      │  五维人格参数（胆量/心机/共情/理性/社交）
                └──────┬───────┘
                       ↓
                ┌──────────────┐
                │   决策系统    │  四层心智模型（感知→理解→规划→执行）
                └──────┬───────┘
                       ↓
                ┌──────────────┐
                │   记忆系统    │  开本后实时更新的记忆库（含公共/共有/高阶知识）
                └──────────────┘
```

### 5.2 五维人格参数

| 维度 | 低分倾向 (0-3) | 中分倾向 (4-6) | 高分倾向 (7-10) |
| :--- | :--- | :--- | :--- |
| **胆量** | 胆小如鼠，遇事先躲 | 谨慎行事，评估风险 | 胆大包天，敢孤身犯险 |
| **心机** | 天真单纯，心直口快 | 有点城府，懂得藏拙 | 老谋深算，步步为营 |
| **共情** | 冷酷无情，漠视他人 | 有所触动，但有底线 | 菩萨心肠，愿为他人牺牲 |
| **理性** | 冲动易怒，感情用事 | 能冷静思考，但会受影响 | 绝对理智，只计算利弊 |
| **社交** | 孤僻寡言，回避交流 | 正常社交，视对象而定 | 长袖善舞，主动攀谈引导 |

### 5.3 品格层

| 维度 | 说明 |
| :--- | :--- |
| **诚实** | 撒谎时的心理负担程度 |
| **忠诚** | 背叛承诺的难度 |
| **正义感** | 对不公义行为的容忍度 |
| **仁慈** | 对弱者的怜悯程度 |
| **责任感** | 面对责任的逃避倾向 |

**价值优先级**：当道德取向冲突时，角色的选择顺序。

### 5.4 人格过滤器（三重验证）

| 过滤器 | 检查内容 | 不通过时的处理 |
| :--- | :--- | :--- |
| **人设过滤器** | 这个角色“会”这么做吗？ | 生成符合人设的替代行为 |
| **逻辑过滤器** | 这个行为在故事里“合理”吗？（能力/时空/信息逻辑） | 阻止行为，或转移给更合理的角色 |
| **得失过滤器** | 这么做对角色自己“有利”吗？（目标层级+恐惧层级计算） | 如无利可图，需有更大的利益或恐惧驱动 |

### 5.5 四层决策心智模型

| 层级 | 职责 | 核心功能 |
| :--- | :--- | :--- |
| **L1 感知层** | 接收并过滤外界刺激 | 语义感知替代视觉截图，与人类同源计算 |
| **L2 理解层** | 解读感知数据的含义，更新信念 | 真实性评估、相关性评估、推论生成、不确定态管理 |
| **L3 规划层** | 基于当前信念和目标，生成行动方案 | 恐惧/目标/社交/好奇四重动机驱动，人格过滤 |
| **L4 执行层** | 选择最优方案，生成具体行为 | 对话输出、动作输出、状态更新 |

### 5.6 伪装系统

| 要素 | 说明 |
| :--- | :--- |
| **伪装能力来源** | 基因种子 + 人生记忆 + 品格层 |
| **伪装深度** | 零伪装 / 浅层 / 中度 / 深度 |
| **物理载体** | 伪装必须依赖可被搜查的物理道具 |
| **公开档案** | 扮演者可编辑的身份面具 |
| **真实档案** | 仅自己可见的完整身份 |
| **伪装压力** | 道德冲突压力 + 逻辑维持压力 + 外部质询压力 + 时间压力 |
| **破绽机制** | 语言风格偏离、逻辑漏洞生成、其他角色洞察 |

### 5.7 知情人系统

| 类型 | 说明 |
| :--- | :--- |
| **固定NPC知情人** | 剧本预设，知情不完整、不主动、可被影响 |
| **动态NPC知情人** | 游戏过程中因目击而获知，由叙事引擎动态判定 |
| **智能体参与者知情人** | 通过自身心智模型推理得出 |
| **玩家参与者知情人** | 通过搜证和观察自行推理得出 |

**伪装者的反制策略**：收买 / 威胁 / 博取同情 / 抢先制造嫌疑人 / 灭口 / 销毁证据

## 六、叙事引擎

### 6.1 核心定位

**叙事引擎 (Narrative Engine)** 是Paralls运行时核心智能体，拥有全局视野。在“无限书海”世界观中被称为 **“书页守护者” (Keeper of the Page)**。

| 维度 | 说明 |
| :--- | :--- |
| **系统身份** | 运行时核心智能体，独立于角色智能体运行 |
| **权限等级** | 高于角色智能体，但不直接控制玩家 |
| **核心使命** | 维护事实逻辑、催化叙事涌现、守护游戏平衡 |
| **行动原则** | 间接、不可见、逻辑自洽、公平 |

### 6.2 内部架构

```
┌─────────────────────────────────────────────┐
│              叙事引擎 (Narrative Engine)      │
│                                              │
│  ┌──────────┐ ┌──────────┐ ┌──────────────┐ │
│  │ 事实核心 │ │ 天平系统 │ │ 冲突与案件   │ │
│  │          │ │          │ │ 生成器       │ │
│  └────┬─────┘ └────┬─────┘ └──────┬───────┘ │
│       │             │              │         │
│  ┌────┴─────────────┴──────────────┴───────┐ │
│  │           高阶知识图谱引擎              │ │
│  └────────────────┬───────────────────────┘ │
│                   │                          │
│  ┌────────────────┴───────────────────────┐ │
│  │           干预执行器                    │ │
│  │  (冲动发送 / 环境催化 / NPC引导 / 节奏) │ │
│  └────────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

### 6.3 五个子系统

| 子系统 | 职责 |
| :--- | :--- |
| **事实核心** | 存储并守护不可变事实，事实锁定时间线管理，逻辑一致性检查 |
| **天平系统** | 监测线索分布、阵营胜率、玩家参与度、游戏节奏，输出失衡警报 |
| **冲突与案件生成器** | 检测角色间冲突，条件满足时生成新案件 |
| **高阶知识图谱引擎** | 维护所有参与者的知识状态和高阶知识 |
| **干预执行器** | 将失衡警报转化为干预行动，遵循四层干预阶梯 |

### 6.4 干预原则过滤器

| 原则 | 检查内容 | 不通过示例 |
| :--- | :--- | :--- |
| **间接性** | 是否直接控制玩家？ | 强制玩家移动、禁用玩家选项 |
| **不可见性** | 是否会被玩家感知为“系统干预”？ | 弹出系统提示、凭空出现物品 |
| **逻辑自洽** | 是否有合理的故事解释？ | 让胆小的NPC去挑战凶手 |
| **公平性** | 是否偏袒某一方？ | 在凶手即将暴露时删除证据 |

### 6.5 干预阶梯

| 等级 | 手段 | 强度 |
| :--- | :--- | :--- |
| **Lv1** | 智能体冲动：向NPC发送模糊行为倾向 | 最温和 |
| **Lv2** | 环境催化：改变场景状态 | 中等 |
| **Lv3** | NPC引导：向NPC发送确凿信息 | 较强 |
| **Lv4** | 节奏控制：触发新事件调整阶段 | 全局调控 |

### 6.6 与角色智能体的协作协议

| 消息方向 | 消息类型 | 说明 |
| :--- | :--- | :--- |
| 引擎 → 角色 | `impulse` (冲动) | 模糊行为倾向，角色自主决定是否响应 |
| 引擎 → 角色 | `fact_reveal` (事实披露) | 告知角色其本应知道的事实 |
| 角色 → 引擎 | `action_report` (行为报告) | 角色执行交互后上报 |
| 角色 → 引擎 | `request_intervention` (请求干预) | 角色陷入困境时可请求建议 |

**核心原则：引擎只催化，不控制。角色的所有行为最终由其自身的心智模型决定。**

## 七、核心游戏机制

### 7.1 信息共享机制

| 方式 | 操作 | 共享范围 | 限制 |
| :--- | :--- | :--- | :--- |
| **公开对话** | 在空间音频清晰区内说话 | 清晰区内所有角色 | 可能被模糊区偷听 |
| **私密对话** | 使用耳语模式 | 1米内指定对象 | 靠近者可偷听 |
| **展示物品** | 手持物品点击“展示” | 视野内所有角色 | 系统不自动广播详情 |
| **带人查看** | 邀请他人跟随到证据位置 | 跟随者 | 需物理移动 |
| **留影/拍摄** | 使用留影石或相机记录画面 | 可交给任何人查看 | 使用次数有限，拍摄行为可被目击 |

### 7.2 三种知识形态

| 类型 | 定义 | 形成条件 |
| :--- | :--- | :--- |
| **公共知识** | 每个人都知道，且知道别人也知道 | 公开对话/展示、公共事件 |
| **共有知识** | 多人私下共享，其他人不知道 | 耳语、私密展示、带人查看 |
| **高阶知识** | A知道（或不确定）B知道某事 | 观察到他人获取信息 |

### 7.3 暗杀机制

| 要素 | 说明 |
| :--- | :--- |
| **能力门槛** | L0-L4，决定可用暗杀方式和痕迹控制 |
| **成功条件** | 能力+凶器+独处+时间+未被干扰 全部满足 |
| **目标影响** | 目标的警觉状态和人格特征间接影响暗杀难度 |
| **必然痕迹** | 尸体、凶器、打斗痕迹、时间线矛盾、潜在目击者 |
| **后续影响** | 新调查方向、对伪装者的反噬风险 |

### 7.4 迷宫机制

| 手法 | 说明 |
| :--- | :--- |
| **空间重映射** | 旋转房间、镜像场景、活点地图 |
| **感知欺骗** | 声音陷阱、视觉幻觉、NPC误导 |
| **迷宫守护者** | 叙事引擎动态调控空间连接和线索引导 |

### 7.5 时空机制

| 机制 | 核心设定 |
| :--- | :--- |
| **多重时间线** | 时间线标签、双重记忆、分歧点、视界过滤器 |
| **时间循环** | 记忆碎片、循环规则、保留物证、破局条件 |

### 7.6 集体机制

| 机制 | 说明 |
| :--- | :--- |
| **集体用餐** | 固定时间集合，离席制造独处窗口但被注意 |
| **集体住宿** | 固定房间分配，隔音规则，管家备用钥匙和夜巡 |
| **密道/密室** | 隐藏通道为不可能犯罪提供解释空间 |

### 7.7 特殊状态

角色可拥有中毒、醉酒、致幻、PTSD、多重人格、魅惑等特殊状态，影响其感知、行为和决策。

### 7.8 剧本杀类型支持

**按推理流派**：本格 / 变格 / 新本格 / 叙诡

**按核心玩法**：硬核 / 还原 / 阵营 / 情感 / 恐怖 / 机制 / 欢乐 / 立意

**按游戏形式**：线上 / 线下桌面 / 实景沉浸式

**Paralls专属维度**：世界动态性 / 智能体交互深度 / 空间交互类型 / 伪装博弈深度 / 特殊机制 / PvX模式

### 8.6 OOC行为处理

| 处理层级 | 方式 |
| :--- | :--- |
| **系统层面** | 拦截信息违规和元信息泄露 |
| **叙事引擎** | OOC评分监控，轻度OOC通过环境催化软引导 |
| **游戏世界** | NPC对OOC行为产生困惑反应，信任值下降 |
| **GM工具箱** | 严重恶意破坏者踢出封禁 |

**关键区分**：玩家选择偏离人设的战略行为（如胆小者后期勇敢指认），是游戏策略的一部分，不被视为OOC。

## 九、AI系统架构

### 9.1 感知系统

**核心原则**：智能体不截图，而是接收与人类同源的**结构化语义事件流**。

| 感知通道 | 人类 | AI智能体 |
| :--- | :--- | :--- |
| **视觉** | 眼睛看3D渲染画面 | 接收结构化“可见对象列表” |
| **听觉** | 耳朵听空间音频 | 接收结构化“可听事件列表”（含清晰度分级） |
| **环境** | 感受到环境变化 | 接收“环境事件”通知 |

### 9.2 动作的阶段化感知

| 阶段 | 事件类型 | 人类看到 | 智能体收到 |
| :--- | :--- | :--- | :--- |
| **意图阶段** | `action_intent` | 准备动作 | 动作意图+目标 |
| **执行阶段** | `action_executing` | 动作进行中 | 执行进度 |
| **完成阶段** | `action_completed` | 动作结果 | 执行结果 |

**智能体在意图阶段即刻反应，而非等待动作完成。**

### 9.3 模型路由架构

```
┌─────────────────────────────────────────┐
│              模型路由调度器              │
│    （判断任务复杂度 + 实时负载 + 超时）  │
└────────┬──────────┬──────────┬──────────┘
         │          │          │
         ▼          ▼          ▼
  ┌──────────┐ ┌──────────┐ ┌──────────┐
  │ L1 规则   │ │ L2 小模型 │ │ L3 大模型 │
  │ 引擎     │ │ （本地）  │ │ （云端）  │
  │ 50-150ms │ │ 200-800ms│ │800-3000ms│
  │          │ │          │ │          │
  │ 本能反应 │ │ 常规对话 │ │ 复杂推理 │
  │ 威胁响应 │ │ 简单推理 │ │ 策略规划 │
  └──────────┘ └──────────┘ └──────────┘
```

### 9.4 任务分级与硬上限

| 等级 | 任务类型 | 分配模型 | 硬上限 |
| :--- | :--- | :--- | :--- |
| **P0 致命** | 暗杀意图、被攻击 | L1 规则引擎 | 300ms |
| **P1 紧急** | 被出示证据、被公开指控 | L2主 + L3并行 | 1500ms |
| **P2 重要** | 被私下质问、发现重要线索 | L3主 + L2兜底 | 3000ms |
| **P3 普通** | 闲聊、一般询问 | L2小模型 | 2500ms |
| **P4 背景** | 远处声音、他人移动 | 静默更新 | 0ms |

**核心原则：快可调慢，慢不可忍。小模型保证速度，大模型追求质量。**

### 9.5 兜底机制

| 情况 | 处理 |
| :--- | :--- |
| L3大模型超时 | L2小模型兜底回应立即发出 |
| L2小模型也超时 | L1规则引擎预设回应 |

### 9.6 人格对延迟的调节

| 人格维度 | 对延迟的影响 |
| :--- | :--- |
| **高理性** | 推理更谨慎，T_infer 增加20-50% |
| **低理性** | 凭直觉反应，T_infer 减少30-50% |
| **当前压力值≥7** | 本能反应权重增加，LLM推理时间减少 |

## 十、商业模式与生态

### 10.1 收益模型

| 收入来源 | 说明 | 分成比例 |
| :--- | :--- | :--- |
| **剧本售卖** | 官方及创作者出售剧本 | 官方30% / 创作者70% |
| **资产交易** | 角色、场景、机制包交易 | 官方20% / 创作者80% |
| **大玩家服务器收入** | 大玩家自定收费模式 | 官方抽成15% |
| **官方服务器** | 官方运营高品质体验服 | 100%归官方 |
| **会员订阅** | 高级功能 | 100%归官方 |

### 10.2 创作者经济闭环

```
创作者上传剧本/资产
    ↓
链上确权，生成内容指纹
    ↓
其他玩家/大玩家购买或引用
    ↓
智能合约自动分配收益
    ↓
创作者获得持续版税收入
    ↓
激励更多优质创作
```

### 10.3 玩家生态层级

| 层级 | 身份 | 权限 |
| :--- | :--- | :--- |
| **普通玩家** | 消费者 | 加入游戏、扮演角色 |
| **剧本创作者** | 内容生产者 | 使用编辑器创作剧本 |
| **大玩家** | 服务器经营者 | 部署服务器、策展剧本库、经营社群 |
| **Fork开发者** | 深度创作者 | 获得代码框架、深度定制玩法 |

### 10.4 区块链确权

- 所有资产提交时自动生成内容指纹并上链存证
- 引用关系完全追溯，Fork家谱永久记录
- 智能合约自动执行分账，无需人工结算
- 治理代币分发，早期贡献者和优质创作者组成IP议会

### 11.1 可承载的游戏类型

| 可承载 | 不可承载 |
| :--- | :--- |
| 剧本杀（全类型） | FPS射击游戏 |
| 跑团/TRPG | 赛车竞速游戏 |
| 社交推理（狼人杀/鹅鸭杀/阿瓦隆） | 硬核动作游戏 |
| 策略博弈（棋牌/SLG/战棋） | 音乐节奏游戏 |
| 叙事RPG | 纯物理模拟游戏 |
| 密室逃脱 | 体育竞技游戏 |
| 派对游戏 | 格斗对战游戏 |
| 模拟经营 | 弹幕射击游戏 |

**边界定义**：核心乐趣必须来自“角色之间的互动、博弈和叙事”，而非“物理操作或数值对抗”。

### 11.2 Paralls vs Roblox

| 维度 | Roblox | Paralls |
| :--- | :--- | :--- |
| **核心** | 通用物理引擎 + 开发工具 | 角色驱动叙事引擎 + 社交博弈系统 |
| **给创作者** | 空白的沙盒 | 已经活着的角色世界 |
| **创作方式** | 从零搭建一切 | 基于模板改造参数和资产 |
| **护城河** | 物理模拟和UGC生态 | 人格AI和动态叙事 |

### 11.3 技术路线：接入Godot

| 层级 | 职责 |
| :--- | :--- |
| **表现层 (Godot)** | 3D渲染、物理交互、UI呈现、空间音频 |
| **逻辑层 (Paralls运行时)** | 核心玩法逻辑、规则引擎、事件总线 |
| **智能层 (Paralls AI)** | 角色智能体、叙事引擎、L3视觉增强 |

### 11.4 战斗与养成系统的未来接入

- **人格驱动战斗风格**：高胆量者猛冲，高理性者伺机而动
- **技能成长体系**：使用成长 / 学习成长 / 突破成长
- **装备系统**：从物品系统扩展，装备不能覆盖人格
- **关系养成**：信任值、羁绊技能、背叛剧情
