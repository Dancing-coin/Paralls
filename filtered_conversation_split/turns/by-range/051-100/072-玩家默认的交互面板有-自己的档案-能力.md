## 用户

玩家默认的交互面板有：自己的档案，能力，交互动作选择，自己的背包面板灯，你来完善一下，辅助面板，变声器和文字润色也要放进来但辅助面板和文字润色可关闭。

## DeepSeek

以下是Paralls玩家默认交互面板的完整设计方案。

---

## Paralls 玩家交互面板设计

整体设计原则：
- **沉浸优先**：所有UI元素采用半透明暗色底，不遮挡3D场景核心视野。
- **模块化**：面板由多个独立模块组成，玩家可自由拖拽位置、调整大小。
- **常驻与可关闭区分**：核心操作模块常驻，辅助与增强模块可随时关闭。

---

### 一、默认布局总览

```
┌─────────────────────────────────────────────────────────────┐
│  [角色档案]  [能力]  [交互动作]  [背包]  [变声器]  [文字润色] │  ← 底部常驻工具栏
│                                                             │
│                                   ┌─────────────────────┐   │
│                                   │   辅助面板 (可关闭)   │   │
│                                   │  [玩法指引]          │   │
│                                   │  [信息整理]          │   │
│                                   │  [决策面板]          │   │
│                                   │  [任务指引]          │   │
│                                   └─────────────────────┘   │
│                                                             │
│  ┌─────────────────────┐                                    │
│  │   背包面板 (展开)    │                                    │
│  │   物品列表...       │                                    │
```

默认位置：底部常驻工具栏位于屏幕下方中央，辅助面板位于右侧，背包展开时位于左侧或右侧，所有面板可自定义位置。

### 二、底部常驻工具栏

此工具栏始终可见，提供最核心的角色信息和操作入口。

| 模块 | 图标/入口 | 功能 | 点击行为 |
| :--- | :--- | :--- | :--- |
| **角色档案** | 角色头像剪影 | 显示当前角色的**公开身份**（姓名、职业）和**角色简介**。悬停可预览，点击展开完整档案面板。 | 展开完整档案面板（可查看自己的真实档案，仅自己可见） |
| **能力** | 能力图标（如匕首、手、气泡） | 显示当前角色的**特殊能力**（如暗杀L2、开锁、医术）和**可用行动**（如“尾随”、“搜查”）。 | 展开能力详细列表，可查看每个能力的描述和当前可用性 |
| **交互动作** | 手型图标 | 显示当前可执行的**场景交互动作**：<br>- 拾取/使用物品<br>- 打开/关闭门<br>- 展示物品<br>- 拍摄（留影石/相机）<br>- 耳语模式切换<br>- 暗杀（如果条件满足） | 展开交互动作轮盘或列表，点击执行 |
| **背包** | 背包图标 | 显示当前持有的**物品数量**。点击展开完整背包面板，查看线索、道具、留影石/照片等。 | 展开背包面板 |
| **变声器** | 麦克风图标（绿色常亮） | 显示变声器**已启用**状态。点击可查看当前变声参数（如“转换为老年男性”），但**不可关闭**。 | 查看变声详情，无关闭选项 |
| **文字润色** | 羽毛笔图标 | 显示文字润色**开启/关闭**状态。点击切换开关。 | 切换润色开关，改变图标颜色（绿色开/灰色关） |

**设计细节：**
- 所有图标采用简洁线条风格，悬浮时有文字标签。
- 能力、交互动作、背包面板展开时，其他面板自动半透明以避免遮挡。
- 变声器图标旁有微小文字“强制”，表示不可关闭。

### 三、辅助面板（可关闭模块）

辅助面板默认显示在屏幕右侧，是一个可折叠的垂直标签页容器。玩家可在**设置**中完全关闭此面板，或使用快捷键`F1`随时呼出/隐藏。

| 标签页 | 核心功能 | 内容 |
| :--- | :--- | :--- |
| **玩法指引** | 动态规则书 | 根据当前游戏阶段（自由探索、讨论、投票），高亮显示相关规则。例如，探索阶段显示“如何搜证”、“如何对话”；投票阶段显示“投票规则”、“平票处理”。 |
| **信息整理** | 侦探白板 | 包含：<br>- **线索与笔记**：拖拽连线，构建逻辑关系。<br>- **时间线视图**：可视化展示已知事件。<br>- **关系网络图**：动态显示角色关系（固定+动态变化），仅展示自己已知的信息。 |
| **决策面板** | 行动灵感 | 基于当前局势和角色人格，生成几个符合人设的行动选项，如“质问 XX 关于烛台的事”、“私下找 YY 结盟”。玩家选择后不会自动执行，仅作为提示。 |
| **任务指引** | 角色目标追踪 | 清晰列出角色的**目标层级**（按优先级排序），并标注完成进度。同时常驻显示自己的**核心秘密**，防止遗忘。 |

**关闭方式：**
- 设置中关闭：打开游戏菜单 → 选择“界面” → 关闭“辅助面板”。
- 快捷键：`F1` 快速隐藏/显示。

### 四、背包面板

点击底部工具栏的背包图标后展开，默认在屏幕左侧或右侧显示。

| 分类标签 | 内容 | 操作 |
| :--- | :--- | :--- |
| **全部** | 所有物品按获得时间排序 | 点击物品查看详情 |
| **线索** | 搜集到的物证、文件、照片等 | 查看详情、展示（拖拽到场景中或选择“展示”按钮）、标记为关键 |
| **道具** | 伪装道具、凶器、留影石/相机等 | 使用、装备、展示 |
| **笔记** | 自己记录的文本信息 | 编辑、删除、展示 |

**特殊物品操作：**
- **展示物品**：拖拽物品到场景中，或右键选择“展示”，则角色在3D世界中举起该物品，周围角色可见。
- **留影石/相机**：点击使用，进入拍摄模式，画面框定后记录。拍摄的照片/幻象会作为新物品出现在背包中。

### 五、文字润色开关

位置：底部常驻工具栏右侧，羽毛笔图标。

| 状态 | 图标样式 | 说明 |
| :--- | :--- | :--- |
| **开启** | 绿色羽毛笔 | 所有发出的文本消息将自动润色为符合角色人设的语言风格 |
| **关闭** | 灰色羽毛笔（带斜线） | 发出的文本消息保持原始输入，不进行润色 |

**快捷操作：**
- 在聊天输入框旁边，也有一个临时切换按钮，可以在发送当前消息时临时开启/关闭润色，而不改变全局默认设置。
- 快捷键：`Ctrl+R` 快速切换全局开关。

---

### 六、变声器状态面板

玩家**不可关闭**变声器，但可以查看当前状态。

点击底部工具栏的变声器图标后，弹出一个小窗口：

| 信息项 | 内容 |
| :--- | :--- |
| **启用状态** | 强制启用（绿色指示灯常亮） |
| **当前变声参数** | 基于角色设定自动配置，如：“性别：男，年龄：60+，性格：沉稳，声线：低沉沙哑” |
| **测试语音** | 可以点击“测试”按钮，说一句话，听到自己变声后的效果（仅自己可听） |

**为什么强制：**
- 保护AI智能体的身份不被识别。
- 确保所有玩家声线符合角色设定，维护全局沉浸感。

---

### 七、全局设置（自定义UI）

玩家可在游戏菜单→“界面”中，自定义交互面板：

| 设置项 | 选项 |
| :--- | :--- |
| **辅助面板** | 开 / 关 |
| **文字润色默认状态** | 开 / 关 |
| **背包默认位置** | 左侧 / 右侧 |
| **UI透明度** | 滑块 0-100% |
| **工具栏位置** | 底部 / 顶部 / 左侧 / 右侧 |
| **快捷键自定义** | 为各个面板指定快捷键 |

---

这套交互面板设计，既保证了玩家在复杂机制下获得足够支持，又通过可关闭性和灵活的布局，尊重了不同玩家的沉浸偏好。所有辅助都只是工具，最终的选择和表达，永远属于玩家自己。
