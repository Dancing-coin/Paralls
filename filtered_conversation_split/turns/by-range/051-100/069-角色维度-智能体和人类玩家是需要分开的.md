## DeepSeek

你说得对。我之前的理解有偏差——把“智能体专属配置”理解成了“智能体需要不同的能力或权限”。实际上：

**智能体和人类玩家扮演的是完全相同的角色。他们有相同的权限、相同的信息获取能力、相同的行动自由。唯一的区别是：人类的“大脑”在肉身里，智能体的“大脑”在服务器上。**

因此，角色维度应该这样修正：

---

## 角色维度的正确结构

### 共同部分：角色档案（所有扮演者共享）

无论该角色最终由人类还是智能体扮演，以下内容完全相同：

| 配置项 | 说明 |
| :--- | :--- |
| **基础信息** | 姓名、身份、外貌、3D模型 |
| **人格档案** | 基因种子、人生记忆、品格层、行为层（五维人格+语言风格） |
| **剧本定位** | 阵营、核心秘密、目标层级、恐惧层级、忠诚度地图 |
| **能力配置** | 暗杀能力等级、特殊技能 |
| **伪装配置** | 伪装深度、公开档案、真实档案、伪装道具、固定知情人 |
| **关系网络** | 与其他角色的固定关系、关系强度、可见性 |

**关键原则：角色是什么样的人，由角色档案决定，不由扮演者是谁决定。**

---

### 区分部分：扮演者类型配置

| 配置项 | 人类玩家 | AI智能体 |
| :--- | :--- | :--- |
| **记忆系统** | 玩家自己的大脑 | 系统维护的记忆库（事件记忆、观察记忆、知识记忆、社交记忆、高阶记忆） |
| **决策系统** | 玩家自己的大脑 | 系统运行的心智模型（感知→理解→规划→执行） |
| **人格约束** | 无强制约束（可能出现OOC，由OOC机制处理） | 强制通过人格过滤器（人设/逻辑/得失三重验证） |
| **信息获取** | 通过游戏客户端接收感知信息 | 通过L1感知层接收结构化感知数据 |
| **行动输出** | 玩家通过客户端操作 | 系统自动生成对话、动作、状态更新 |
| **压力/情绪** | 玩家自己感受 | 系统计算并影响决策 |

**关键原则：人类和智能体的区别不在于“能做什么”，而在于“怎么做决策”。**

---

### 权限完全一致

| 权限 | 人类玩家 | AI智能体 |
| :--- | :--- | :--- |
| **移动** | ✅ 自由移动 | ✅ 自主移动 |
| **对话** | ✅ 自由发言 | ✅ 自主生成对话 |
| **物品交互** | ✅ 拾取、使用、展示 | ✅ 拾取、使用、展示 |
| **信息共享** | ✅ 五种共享方式 | ✅ 五种共享方式 |
| **暗杀** | ✅ 满足条件可执行 | ✅ 满足条件可执行 |
| **伪装管理** | ✅ 编辑公开档案、管理道具 | ✅ 编辑公开档案、管理道具 |
| **投票** | ✅ 自由投票 | ✅ 基于人格和当前信念投票 |
| **被怀疑/被指控** | ✅ | ✅ |
| **被暗杀** | ✅ | ✅ |
| **说谎/欺骗** | ✅ | ✅ |

**关键原则：在游戏世界中，人类和智能体是平等的参与者。没有人因为是AI而拥有特权，也没有人因为是AI而被限制。**

---

### 角色扮演者匹配

| 配置项 | 说明 |
| :--- | :--- |
| **扮演者类型** | 该角色由谁扮演：仅人类 / 仅AI / 二者可选 |
| **最少人类玩家数** | 剧本要求的最少真人玩家数量（确保推理体验） |
| **AI接管规则** | 如果人类玩家掉线或中途退出，AI是否自动接管该角色 |

**典型配置：**
- 5人本：2个真人玩家（凶手候选排除）+ 3个AI智能体（真凶从中产生）
- 6人本：3个真人玩家 + 3个AI智能体
- 全AI测试模式：所有角色由AI扮演，用于创作者预览剧本

---

### 编辑器中的人类玩家指引

当剧本标记某角色“可由人类玩家扮演”时，编辑器需要为该角色的扮演者提供指引：

| 指引内容 | 说明 |
| :--- | :--- |
| **角色简介** | 你是谁，你的公开身份 |
| **你的秘密** | 你必须隐藏的真相 |
| **你的目标** | 你希望达成的结果 |
| **你的关系** | 你对其他角色的真实态度 |
| **你的能力** | 你可以做什么（暗杀能力、特殊技能） |
| **伪装建议** | 如果你需要伪装，系统建议你如何操作 |
| **关键记忆** | 你开本前知道的关键信息（仅你自己知道） |

**这些指引是建议，不是强制。人类玩家可以选择遵循，也可以选择偏离（OOC机制处理）。**

### 修正后的角色维度结构

```
┌─ 二、角色维度
│
├─ 共同部分：角色档案（所有扮演者共享）
│   ├─ 基础信息（姓名/身份/外貌/3D模型）
│   ├─ 人格档案（基因种子/人生记忆/品格层/行为层）
│   ├─ 剧本定位（阵营/秘密/目标/恐惧/忠诚度）
│   ├─ 能力配置（暗杀能力/特殊技能）
│   ├─ 伪装配置（伪装深度/公开档案/道具/知情人）
│   └─ 关系网络（固定关系/强度/可见性）
│
├─ 区分部分：扮演者类型
│   ├─ 人类玩家
│   │   ├─ 记忆：自己的大脑
│   │   ├─ 决策：自己的大脑
│   │   ├─ 约束：无强制（OOC机制处理）
│   │   └─ 指引：角色简介/秘密/目标/关系/能力/伪装建议/关键记忆
│   │
│   └─ AI智能体
│       ├─ 记忆：系统维护的记忆库
│       ├─ 决策：心智模型（L1-L4）
│       ├─ 约束：人格过滤器强制执行
│       └─ 输出：系统自动生成
│
└─ 权限：完全一致（移动/对话/物品/信息共享/暗杀/伪装/投票）
```

**一句话总结：角色是角色，扮演者是扮演者。角色定义了“这是一个什么样的人”，扮演者决定了“谁来驱动这个人的行为”。人类用大脑驱动，AI用系统驱动，但他们在游戏世界中的权限和可能性完全相同。**
