## 暗杀机制在分类体系中的定位

### 一、暗杀与伪装深度的绑定

暗杀是**重度伪装**的自然延伸。我们将其定义为三个深度等级：

| 伪装与博弈深度 | 暗杀机制 | 说明 |
| :--- | :--- | :--- |
| **轻度** | ❌ 不可用 | 简单身份隐藏，无伪装道具，无暗杀 |
| **中度** | ❌ 不可用 | 完整伪装系统，但仅限于信息博弈 |
| **重度** | ✅ 可用 | 中度基础上，增加知情人网络和灭口机制 |

**只有当剧本启用“重度伪装与博弈”时，暗杀机制才会被激活。**

---

### 二、暗杀与特殊机制的协同

暗杀作为一级核心机制，与其他特殊机制的兼容关系如下：

| 特殊机制 | 与暗杀的兼容 | 说明 |
| :--- | :--- | :--- |
| **暗杀机制** | — | 核心机制，重度和涌现叙事默认开启 |
| **时间循环** | ✅ 高度协同 | 暗杀→循环重置→保留记忆碎片→利用信息差再次暗杀或阻止暗杀 |
| **多重时间线** | ✅ 高度协同 | 不同时间线的角色可暗杀不同目标，产生时间悖论线索 |
| **动态阵营** | ✅ 高度协同 | 暗杀可触发阵营切换（如目睹盟友被暗杀后叛变） |
| **角色特殊状态** | ✅ 高度协同 | 中毒、致幻等状态影响暗杀能力和风险判定 |
| **盲凶模式** | ✅ 可协同 | 真凶玩家不知道自己身份时，可能无意中触发暗杀条件 |
| **PvPvE** | ✅ 高度协同 | 暗杀目标是玩家或AI，产生连锁反应 |

---

### 三、暗杀与世界动态性的关系

| 世界动态性 | 暗杀行为 | 叙事引擎角色 |
| :--- | :--- | :--- |
| **线性叙事** | 通常不启用暗杀 | — |
| **分支叙事** | 可启用，暗杀触发预设分支 | 管理分支逻辑，不主动催化新暗杀 |
| **涌现叙事** | 默认启用，暗杀可触发新案件链 | 主动检测冲突，催化暗杀机会，管理连锁反应 |

---

### 四、支持暗杀的完整配套系统

| 系统 | 说明 |
| :--- | :--- |
| **暗杀能力等级 (L0-L4)** | 由角色人生记忆决定，控制可用暗杀方式和痕迹控制 |
| **暗杀条件判断** | 能力 + 凶器 + 独处窗口 + 时间 + 未被干扰 |
| **阶段化感知** | 意图阶段即推送 `action_intent` 事件，目标可即时反应 |
| **本能反应规则** | P0致命威胁走L1规则引擎，300ms内本能反应 |
| **痕迹生成系统** | 暗杀必然留下物证、时间线矛盾和潜在目击者 |
| **叙事引擎介入** | 监控暗杀后果，管理连锁反应，防止一边倒 |
| **知情人系统** | 动态目击判定，信息传播链，伪装者反制策略 |
