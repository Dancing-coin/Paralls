## 智能体模型反应速度模型

### 一、延迟的构成

智能体从感知到执行反应的总延迟，由以下部分构成：

| 延迟阶段 | 说明 | 典型时间 |
| :--- | :--- | :--- |
| **感知接收延迟 (T_perceive)** | 语义事件从Godot推送至AI服务端的网络延迟 | 50-100ms |
| **上下文组装延迟 (T_context)** | 拉取人格、记忆、知识图谱、对话历史等上下文数据 | 100-300ms |
| **模型推理延迟 (T_infer)** | LLM进行决策推理的耗时 | 500-3000ms（取决于复杂度） |
| **人格过滤延迟 (T_filter)** | 三道过滤器校验 | 50-150ms |
| **执行延迟 (T_exec)** | 将决策指令发送回Godot并开始执行 | 50-100ms |

**总延迟 = T_perceive + T_context + T_infer + T_filter + T_exec**

典型范围：750ms 到 3650ms。

---

### 二、延迟的分级处理

不是所有事件都需要完整走完LLM推理。根据事件紧急程度分级处理：

| 事件类型 | 处理方式 | 典型延迟 | 说明 |
| :--- | :--- | :--- | :--- |
| **致命威胁**（暗杀意图被感知） | 本地快速规则引擎 | 150-300ms | 不经过LLM，使用预置的“本能反应”规则 |
| **重要事件**（发现关键线索、被质问） | LLM推理（高优先级） | 1000-2000ms | 完整推理，但队列最前 |
| **普通事件**（看到某人移动、听到闲聊） | LLM推理（普通优先级） | 2000-3500ms | 正常排队 |
| **背景噪声**（远处脚步、风吹草动） | 忽略或规则引擎 | 0-100ms | 不占用LLM资源 |

---

### 三、本能反应规则引擎（本地快速通道）

对于致命威胁，智能体使用预置的**本能反应规则**，不经过LLM。

| 威胁类型 | 人格参数 | 本能反应 |
| :--- | :--- | :--- |
| 近距离暗杀意图 | 胆量 ≥ 7 | 反击或闪避 |
| 近距离暗杀意图 | 胆量 4-6 | 呼救或逃跑 |
| 近距离暗杀意图 | 胆量 ≤ 3 | 僵住或尖叫 |
| 被出示关键证据 | 心机 ≥ 7 | 冷静否认 |
| 被出示关键证据 | 心机 ≤ 3 | 慌乱、语无伦次 |
| 发现尸体 | 胆量 ≥ 7 | 靠近检查 |
| 发现尸体 | 胆量 ≤ 3 | 尖叫、后退、逃跑 |

**规则引擎的优点**：
- 延迟极低（150-300ms），接近人类本能反应时间
- 不依赖LLM可用性，不会“卡住”
- 反应符合人格，但模式有限

**规则引擎的局限**：
- 只能处理预定义的威胁类型
- 无法生成复杂对话
- 可能被玩家识别出“模式化”

**LLM接管**：本能反应执行后，LLM会在1-2秒内生成更复杂的后续行为（如详细解释、策略调整），覆盖或补充本能反应。

---

### 四、人格对延迟的调节

智能体的“思考速度”不是固定的，由其人格参数动态调节。

| 人格维度 | 对延迟的影响 |
| :--- | :--- |
| **高理性** | 推理更谨慎，T_infer 增加20-50% |
| **低理性** | 凭直觉反应，T_infer 减少30-50% |
| **高胆量** | 对威胁的反应阈值更高，不易触发本能反应，但一旦触发决策更快 |
| **低胆量** | 对威胁的反应阈值更低，更易触发本能反应 |
| **高心机** | 决策前会考虑更多变量（如别人会怎么想），T_infer 增加 |
| **当前压力值** | 压力 ≥ 7：本能反应权重增加，LLM推理时间减少（冲动决策） |

---

### 五、延迟的自然感模拟

为了让智能体的延迟不显得“机械”，引入人类化的变异因子：

| 变异因子 | 说明 |
| :--- | :--- |
| **随机抖动** | 每次推理延迟 ± 10-20% 随机波动 |
| **认知负荷** | 如果智能体同时需要处理多个事件，延迟增加 |
| **疲劳效应** | 游戏进行时间越长，延迟略微增加（模拟疲劳） |
| **打断效应** | 如果智能体正在说话时被新事件打断，可能需要额外时间重新组织 |

---

### 六、并行处理能力

人类可以一边听一边思考。智能体也需要支持并行处理。

| 处理模式 | 说明 |
| :--- | :--- |
| **主任务** | 当前正在执行的动作（如对话、移动） |
| **背景监控** | 对环境中非紧急事件的持续感知，不中断主任务 |
| **中断处理** | 致命威胁打断当前主任务，优先处理 |

**技术实现**：
- 感知接收和上下文组装是独立的，不阻塞LLM推理
- LLM推理支持流式输出，边生成边执行
- TTS合成与LLM推理并行，流式开始播放

---

### 七、延迟透明度给玩家

玩家观察智能体时，会看到自然的“思考停顿”：

| 情境 | 玩家观察到的行为 |
| :--- | :--- |
| 智能体被质问 | 短暂停顿（500-1500ms），眼神可能移开或皱眉，然后回答 |
| 智能体发现线索 | 走近、弯腰查看、停顿、然后说话或做出反应 |
| 智能体被突然攻击 | 立即反应（本能），然后短暂停顿后做出后续行为 |
| 智能体正在思考复杂问题 | 可能喃喃自语、踱步、或请求对方“稍等，让我想想” |

---

### 八、完整反应时间线示例

场景：玩家A突然从背后靠近智能体玛丽，意图暗杀。

| 时间 | 事件 | 延迟 |
| :--- | :--- | :--- |
| T+0ms | 玩家A进入暗杀范围，开始暗杀动作 | - |
| T+50ms | Godot推送 `action_intent` 事件至AI服务 | T_perceive |
| T+100ms | AI服务识别为“致命威胁”，触发本能反应规则 | 50ms |
| T+120ms | 规则引擎根据玛丽人格（胆量3）判定：僵住+尖叫 | 20ms |
| T+170ms | 执行指令发送回Godot | T_exec |
| T+200ms | 玛丽在3D世界中僵住并发出尖叫 | - |
| T+500ms | LLM推理完成，生成后续行为：“救命！有人要杀我！”（边后退边哭） | T_infer（与本能反应并行） |
| T+700ms | 后续行为开始执行 | - |

**在这个时间线中**：
- 玛丽的本能反应在200ms内完成，与人类的本能反应时间（150-300ms）一致
- LLM推理在500ms完成，补充了更复杂的后续行为
- 玩家感受到的是一个连贯的、符合人设的反应

---

### 九、延迟的配置参数

在剧本编辑器或大玩家控制台中，可调整以下参数：

| 参数 | 说明 | 默认值 |
| :--- | :--- | :--- |
| **基础推理延迟** | LLM推理的基础耗时 | 1500ms |
| **本能反应启用** | 是否启用本地规则引擎 | 开启 |
| **人格延迟影响** | 人格参数对延迟的调节幅度 | 开启 |
| **随机抖动幅度** | 延迟的随机波动范围 | ±15% |
| **最大并发推理** | 同时进行LLM推理的最大数量 | 房间内AI角色数 |

---

一句话总结：**智能体的反应延迟是系统刻意模拟的，不是技术缺陷。它由基础延迟 + 人格调节 + 分级处理 + 随机抖动共同决定，且致命威胁有本地快速通道保证即时反应。玩家感受到的不是“AI卡了”，而是“这个角色在思考”。**
