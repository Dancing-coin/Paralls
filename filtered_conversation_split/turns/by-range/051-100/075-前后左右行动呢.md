## 移动与控制系统

### 一、移动方式

#### 1.1 基础移动（键盘 / 手柄左摇杆）

| 操作 | 键盘 | 手柄 | 说明 |
| :--- | :--- | :--- | :--- |
| **前进** | W | 左摇杆 ↑ | 向前移动 |
| **后退** | S | 左摇杆 ↓ | 向后移动 |
| **左移** | A | 左摇杆 ← | 向左横向移动 |
| **右移** | D | 左摇杆 → | 向右横向移动 |

#### 1.2 移动姿态切换

| 姿态 | 切换键 | 移动速度 | 脚步声 | 被感知距离 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **正常行走** | 默认 | 标准 | 标准 | 标准 | 日常移动姿态 |
| **奔跑** | Shift（按住） | 1.5倍 | 大 | 更远 | 快速移动，但脚步声会暴露位置 |
| **潜行** | Ctrl（按住） | 0.5倍 | 极小 | 更近 | 降低被感知概率，需潜行能力支撑 |
| **蹲伏** | C（切换） | 0.3倍 | 极小 | 更近 | 降低被视觉发现概率，可进入低矮空间 |

#### 1.3 特殊移动

| 动作 | 操作 | 条件 | 说明 |
| :--- | :--- | :--- | :--- |
| **跳跃** | 空格键 | 场景允许 | 跳过障碍物、跳过沟壑 |
| **攀爬/翻越** | 靠近障碍物+空格 | 特定场景（窗户、矮墙、栅栏） | 翻越障碍物 |
| **攀爬梯子** | 靠近梯子+W/S | 场景中有梯子 | 上下梯子 |
| **游泳** | 进入水中自动切换 | 场景中有水域 | 水中移动 |

### 二、视角控制

#### 2.1 视角旋转

| 操作 | 鼠标 | 手柄 | 说明 |
| :--- | :--- | :--- | :--- |
| **水平旋转** | 鼠标左右移动 | 右摇杆 ← → | 左右看 |
| **垂直旋转** | 鼠标上下移动 | 右摇杆 ↑ ↓ | 上下看 |

#### 2.2 视角模式切换

| 模式 | 切换键 | 说明 |
| :--- | :--- | :--- |
| **第一人称** | F5 或 V | 沉浸感最强，视野受限，更贴近角色的真实视角 |
| **第三人称（近）** | F5 或 V 切换 | 可以看到角色模型，适合观察自己的伪装和状态 |
| **第三人称（远）** | F5 或 V 再切换 | 视野更开阔，适合观察周围环境 |

#### 2.3 视角操作

| 操作 | 说明 |
| :--- | :--- |
| **聚焦观察** | 鼠标右键按住或手柄LT，拉近视角，高亮准星对准的可交互物品 |
| **快速回头** | 按特定键（如Z），角色快速180度转身查看身后 |
| **环顾四周** | 按住Alt键，鼠标可自由移动视角但角色朝向不变（观察周围但不暴露朝向变化） |

### 三、操作与交互

#### 3.1 交互准星

屏幕中央始终显示一个准星（可设为点、十字或圆），对准目标时：

| 准星状态 | 说明 |
| :--- | :--- |
| **默认** | 无目标 |
| **高亮（白）** | 对准可交互物品 |
| **高亮（绿）** | 对准可对话角色 |
| **高亮（红）** | 对准可暗杀目标（条件满足时） |
| **高亮（蓝）** | 对准可拾取物品 |

#### 3.2 交互操作

| 操作 | 键盘 | 手柄 | 说明 |
| :--- | :--- | :--- | :--- |
| **主交互** | E 或鼠标左键 | A（Xbox）/ ×（PS） | 执行默认交互（对话、拾取、使用） |
| **副交互** | F 或鼠标右键 | B（Xbox）/ ○（PS） | 打开该目标的完整交互动作菜单 |
| **取消/关闭** | Esc | B（Xbox）/ ○（PS） | 关闭面板、取消操作 |

---

### 四、操作与移动的沉浸感规则

| 规则 | 说明 |
| :--- | :--- |
| **脚步声** | 不同移动姿态产生不同大小的脚步声，通过空间音频传播。奔跑声大、潜行声小 |
| **表面材质音效** | 木地板、石板地、草地、楼梯——不同表面产生不同脚步声 |
| **体力消耗** | 持续奔跑会消耗体力，体力不足时只能行走（若启用体力系统） |
| **门/窗操作** | 开关门/窗需要动画时间，开关门的声音可被附近角色听到 |
| **碰撞与物理** | 无法穿墙、无法穿过家具。撞倒物品会产生噪音 |
| **摔倒** | 从高处跳下或奔跑时被绊倒可能受伤，产生噪音 |

这套完整的移动和控制系统确保了：
- **直觉操作**：符合3D游戏通用操作习惯，新玩家快速上手
- **沉浸感**：移动姿态影响脚步声和被感知范围，移动本身就是策略
- **策略深度**：奔跑赶路还是潜行接近，每个选择都有风险和收益
- **全平台支持**：同时覆盖键鼠和手柄，适配PC和主机
- **无缝衔接**：移动、视角、交互三者切换流畅，不打断游戏节奏
