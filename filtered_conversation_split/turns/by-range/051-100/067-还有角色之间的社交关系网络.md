## DeepSeek

你提醒得对。角色之间的社交关系网络不是一个独立的维度，而是**贯穿所有维度的血液**——它既影响案件生成、又驱动智能体决策、还被伪装系统所利用、最终决定叙事走向。

在Paralls中，社交关系网络需要包含三层：

---

## 社交关系网络的三层结构

### 第一层：固定关系（开本前锁定，创作者设定）

这些关系是故事的基石，由创作者在编辑器中逐对设定。

| 关系类型 | 说明 | 例子 |
| :--- | :--- | :--- |
| **血缘关系** | 父母/子女/兄弟姐妹/远亲 | 格雷先生与已故的父亲 |
| **婚姻/恋爱关系** | 夫妻/恋人/前任/暗恋 | 埃莉诺与已故丈夫 |
| **职业关系** | 上下级/同事/主仆/雇佣 | 格雷先生与管家莫里斯 |
| **恩仇关系** | 救命恩人/仇敌/背叛者/被背叛者 | 霍普医生被格雷救过 |
| **秘密关系** | 只有当事双方知道的隐藏关系 | 莫里斯与旧同伙的通信 |
| **利益关系** | 商业合作/债务/勒索 | 温斯顿想骗取埃莉诺的财富 |

**设定方式**：创作者在角色编辑器中，为每一对角色选择关系类型和关系强度（-10到+10）。部分关系可设为“隐藏”，不写入公开档案，仅当事角色自己知道。

---

### 第二层：动态关系（游戏中实时更新，由系统驱动）

这些关系随游戏进程不断变化，是所有智能体决策的重要输入。

| 动态参数 | 初始值来源 | 变化方式 | 影响 |
| :--- | :--- | :--- | :--- |
| **信任值** | 固定关系强度 + 人格忠诚度 | 言行一致→上升；发现撒谎→下降；被帮助→上升 | 影响信息分享意愿、合作倾向 |
| **怀疑值** | 案件线索指向 + 初始印象 | 发现矛盾证据→上升；证人指证→上升；被成功解释→下降 | 影响指控倾向、调查方向 |
| **好感度** | 固定关系强度 + 人格共情 | 友善互动→上升；冒犯/威胁→下降；共情共鸣→上升 | 影响私下交流意愿、保护倾向 |
| **恐惧值** | 对方能力+ 人格胆量 | 被威胁→上升；对方展示武力→上升；获得保护→下降 | 影响是否服从、是否告密、是否逃跑 |
| **依赖度** | 角色能力互补 + 局势需求 | 需要对方技能→上升；找到替代方案→下降 | 影响结盟意愿、背叛成本 |

**更新机制**：事件总线捕获所有角色互动事件，自动更新相关参数。叙事导演实时监控，确保参数变化在逻辑上合理。

---

### 第三层：关系网络的结构属性

不是所有关系都是平等的。关系网络还具有结构属性：

| 结构属性 | 说明 | 游戏影响 |
| :--- | :--- | :--- |
| **小团体/派系** | 多个角色因共同利益或秘密形成的小团体 | 公开讨论时抱团投票，私下结盟对抗其他团体 |
| **孤立者** | 与所有其他角色关系都薄弱的角色 | 最容易成为替罪羊，也最有动机铤而走险 |
| **核心枢纽** | 与多数角色有强关系的角色 | 死亡或背叛会产生最大的连锁反应，是暗杀的高价值目标 |
| **三角关系** | 三个角色之间的复杂关系（如A喜欢B，B喜欢C，C恨A） | 天然的情感冲突场，叙事导演最喜欢催化的结构 |
| **秘密共享链** | A知道B的秘密，B知道C的秘密，但A不知道C | 信息博弈的高级形态，可以利用高阶知识进行策略操作 |

---

## 关系网络在系统中的作用

### 1. 案件生成时

| 利用方式 | 说明 |
| :--- | :--- |
| **动机生成** | 系统从固定关系中提取可能的作案动机（如“A对B有旧仇”可生成复仇动机） |
| **不在场证明生成** | 关系强的角色更可能互相作证（如“管家为主人作证”） |
| **凶手候选排除** | 如果死者与某角色有极强正向关系（如母亲对子女），该角色在初始案件中可能被排除凶手候选 |

### 2. 智能体决策时

| 利用方式 | 说明 |
| :--- | :--- |
| **信息分享对象选择** | 智能体优先向信任值高、好感度高的角色分享信息 |
| **指控对象选择** | 智能体倾向于指控怀疑值高的角色，但会避免指控恐惧值高的角色（怕报复） |
| **结盟对象选择** | 智能体优先与信任值高、依赖度高的角色结盟 |
| **伪装策略** | 智能体可能利用关系网络，将嫌疑引向与自己关系薄弱的角色 |

### 3. 叙事导演调控时

| 利用方式 | 说明 |
| :--- | :--- |
| **冲突催化** | 导演检测到“三角关系”结构，主动创造让三人同处一室的场景 |
| **平衡干预** | 如果某角色被完全孤立（孤立者），导演可能让另一个角色发现与其的共同利益，创造新的关系连接 |
| **新案件触发** | 当关系网络中的紧张度达到临界值（如A对B的怀疑值+恐惧值超过阈值），导演评估是否触发“灭口”事件 |
| **结局走向** | 关系网络的重组（从敌对到和解、从信任到背叛）成为结局CG的重要素材 |

## 补充进七维体系

社交关系网络不作为独立维度，而是**以“关系网络”为名，贯穿并补充到现有维度中**：

```
Paralls 剧本杀世界搭建维度（修正版）

┌─ 一、世界观与时代维度
│   └─ ...
│
├─ 二、角色维度
│   ├─ ...
│   ├─ 能力配置
│   ├─ 伪装配置
│   └─ 关系网络 【新增：角色间固定关系定义】
│       ├─ 血缘/婚姻/职业/恩仇/秘密/利益关系
│       └─ 关系强度（-10到+10）+ 可见性（公开/隐藏）
│
├─ 三、案件与叙事维度
│   ├─ 案件生成规则池
│   │   └─ 关系网络驱动 【新增：从关系生成动机和不在场证明】
│   └─ ...
│
├─ 四、场景与空间维度
│   └─ ...
│
├─ 五、规则与机制维度
│   └─ ...
│
├─ 六、AI智能体与导演维度
│   ├─ 角色智能体
│   │   └─ 关系网络感知 【新增：动态关系参数作为决策输入】
│   ├─ 叙事导演
│   │   └─ 关系网络催化 【新增：检测关系结构，催化冲突】
│   └─ ...
│
└─ 七、体验与呈现维度
    └─ 结局生成
        └─ 关系网络演变 【新增：关系网络的变化作为结局叙事素材】
```

**核心：创作者设定固定关系的种子，系统让这些关系在游戏中动态生长。最终，关系网络的演变本身就成为玩家体验中最深刻的部分——谁背叛了谁，谁保护了谁，谁在最后一刻选择了谁。这是Paralls“有人味的游戏”最直接的体现。**
