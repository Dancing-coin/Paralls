## 用户

我觉得得有一个默认规则，开本前，死者必须是npc，局内发生暗杀才会导致玩家死亡。

## DeepSeek

这个设计非常关键。它解决了一个核心体验问题：**玩家不应该在开本时就被“判死刑”**。

---

## 默认规则：初始死者锁定为NPC

| 规则项 | 说明 |
| :--- | :--- |
| **初始案件死者** | 必须是NPC（AI智能体），不能是真人玩家 |
| **局内暗杀死者** | 可以是真人玩家，也可以是AI智能体 |
| **玩家死亡后果** | 该玩家角色在游戏中死亡，但仍可以旁观视角观看游戏进程，或退出房间 |

---

## 这条规则解决的体验问题

| 问题 | 解决方案 |
| :--- | :--- |
| 开本后玩家发现自己已死亡，全程无事可做 | 初始死者锁定为NPC，所有真人玩家都能参与游戏 |
| 玩家因“被选为死者”而感到不公平 | 任何真人玩家都不会在开本时被随机牺牲 |
| 暗杀机制过于温和，缺乏真正代价 | 局内暗杀可以杀死真人玩家，暗杀行为有真实的后果 |
| 被暗杀的玩家体验断裂 | 可切换至旁观模式，或观看本局故事报告 |

---

## 这条规则对系统的影响

### 1. 初始案件生成（T2锁定）

在T2玩家选择角色并加入后，系统锁定初始案件的凶手和死者：

| 锁定项 | 规则 |
| :--- | :--- |
| **死者** | 从AI角色中随机选择（排除真人玩家） |
| **凶手** | 从AI角色中随机选择（排除真人玩家），满足作案条件 |

**原因**：初始案件的凶手也不应是真人玩家。真人玩家在开本时如果已经是凶手，会破坏“所有人都能参与推理”的体验。真人玩家可以在T3游戏进行中通过暗杀成为新案件的凶手，但初始案件的责任应完全由AI承担。

### 2. 局内暗杀死者

| 死者类型 | 触发方式 | 后果 |
| :--- | :--- | :--- |
| **AI智能体** | 司命催化 → 弹窗确认 | 该AI角色从游戏中移除，新案件生成 |
| **真人玩家** | 司命催化 → 弹窗确认 | 该玩家角色死亡，切换至旁观模式，新案件生成 |

### 3. 玩家死亡后的体验

| 选项 | 说明 |
| :--- | :--- |
| **旁观模式** | 可以自由切换视角，观察其他角色的行为，但无法互动、无法说话 |
| **本局故事报告** | 可以提前查看已解锁的故事片段 |
| **退出房间** | 可以离开游戏房间，加入其他房间或进入匹配队列 |
| **留遗言（可选）** | 部分剧本可启用“遗言机制”，死者可以留下最后一句话作为线索 |

---

## 这条规则对司命的影响

| 催化类型 | 说明 |
| :--- | :--- |
| **初始案件催化** | 司命在T2锁定初始案件时，强制排除所有真人玩家作为死者和凶手候选 |
| **局内暗杀催化** | 司命催化暗杀时，目标可以是真人玩家或AI智能体，不区分对待 |
| **平衡考量** | 司命在催化以真人玩家为目标的暗杀时，需更严格地通过可玩性评估（真人玩家被暗杀后体验断裂风险更高） |

---

## 这条规则对暗杀弹窗的影响

当暗杀目标是真人玩家时，弹窗增加额外提示：

```
┌──────────────────────────────────────────┐
│  ⚠️ 暗杀机会                              │
│                                          │
│  目标：查尔斯·温斯顿（真人玩家）          │
│  ...                                     │
│                                          │
│  ⚠️ 注意：目标是真人玩家。执行暗杀将导致  │
│  该玩家角色永久死亡，玩家将切换至旁观模式。│
│  此行为会产生严重的游戏内后果。           │
│                                          │
│  [ 执行暗杀 ]    [ 放弃 ]               │
└──────────────────────────────────────────┘
```

---

这条规则确保了所有真人玩家在开本时都站在同一起跑线上，而局内暗杀则保留了真实的代价和戏剧张力。
