## 一、默认常驻HUD

### 1.1 状态栏（左上角）

| 显示项 | 呈现方式 | 说明 |
| :--- | :--- | :--- |
| **角色名** | 文字 | 当前扮演的角色公开名 |
| **压力值** | 进度条+数字(0-10) | 颜色随压力升高从绿→黄→红 |
| **当前情绪** | 动态表情图标+文字 | 紧张😰、冷静😐、恐惧😱、愤怒😠等 |
| **体力/伤势** | 心形图标+颜色 | 满血绿色→受伤黄色→重伤红色 |
| **特殊状态** | 图标标签 | 中毒☠️、醉酒🍷、致幻🌀、出血🩸等 |

### 1.2 任务与秘密提醒（右上角）

| 显示项 | 说明 |
| :--- | :--- |
| **核心秘密** | 一句话提醒，如“你是真凶，必须隐藏” |
| **当前首要目标** | 从目标层级提取最高优先级目标 |
| **目标完成度** | 可选显示，如“已收集线索 3/7” |

### 1.3 小地图/方位指示（右上角边缘，可关闭）

| 显示项 | 说明 |
| :--- | :--- |
| **当前场景名** | 如“贝克街客厅” |
| **简化地图** | 显示房间布局和出口方向 |
| **附近角色光点** | 仅显示清晰区内的其他角色位置（模糊区和静默区不显示） |
| **自己的朝向** | 箭头指示 |

**设计原则**：小地图不显示静默区和模糊区的角色，维持信息不对称。玩家只能“看到”身边的人。

## 二、交互动作系统

### 2.1 交互动作栏（屏幕下方，上下文动态切换）

玩家通过准星对准目标或点击目标后，交互动作栏显示当前可执行的操作。

#### 2.1.1 对角色（玩家或AI）可执行的动作

| 动作 | 图标 | 条件 | 说明 |
| :--- | :--- | :--- | :--- |
| **公开交谈** | 🗣️ | 目标在清晰区内 | 发起公开对话，清晰区内所有人都能听到 |
| **耳语** | 🤫 | 目标在耳语范围内(1m) | 发起私密对话，仅对方能听清 |
| **展示物品** | 🫴 | 背包中有物品 | 向对方展示物品，对方可查看详情 |
| **移交物品** | 🤝 | 背包中有可移交物品 | 将物品交给对方 |
| **跟随** | 🚶 | 对方同意 | 自动跟随对方移动 |
| **邀请跟随** | 👆 | 对方在附近 | 邀请对方跟随自己 |
| **观察** | 👁️ | 任何可见角色 | 仔细观察对方，可能发现伪装痕迹、受伤、情绪变化等 |
| **搜身** | ✋ | 特定条件下（如对方失去行动能力或同意） | 查看对方携带的所有物品 |
| **救治** | 🩹 | 自己有医术能力，对方受伤 | 治疗对方的伤势 |
| **攻击/暗杀** | 🔪 | 满足暗杀条件 | 执行暗杀（需二次确认） |
| **唤醒/扶起** | 💪 | 对方昏迷或倒地 | 帮助对方恢复 |

#### 2.1.2 对物品可执行的动作

| 动作 | 图标 | 条件 | 说明 |
| :--- | :--- | :--- | :--- |
| **拾取** | ✋ | 物品可拾取 | 放入背包 |
| **检查/调查** | 🔍 | 物品可交互 | 查看详情，可能触发L3视觉增强（线索特写） |
| **使用** | ▶️ | 物品可使用 | 使用物品（如钥匙开门、毒药投入饮食） |
| **推/拉** | 💪 | 物品可移动 | 移动家具、推开箱子、拉开窗帘 |
| **打开/关闭** | 🚪 | 门、窗、箱子等 | 开关门/窗/容器 |
| **隐藏/躲藏** | 🙈 | 在特定位置（柜子、窗帘后） | 进入隐藏状态，降低被感知概率 |
| **破坏** | 💥 | 物品可破坏 | 破坏物品（如砸碎花瓶、撕毁信件） |
| **修复** | 🔧 | 物品可修复 | 修复被破坏的物品（如拼合撕碎的信件） |

#### 2.1.3 对场景可执行的动作

| 动作 | 图标 | 条件 | 说明 |
| :--- | :--- | :--- | :--- |
| **坐下** | 🪑 | 场景中有可坐位置 | 坐下休息，可能降低压力值 |
| **点燃/熄灭** | 🔥 | 有可点燃/熄灭的光源 | 蜡烛、壁炉、油灯等 |
| **窃听** | 👂 | 靠近门/墙 | 尝试听清另一侧的模糊声音 |
| **标记** | 📌 | 任何位置 | 在地上或墙上留下标记（用于迷宫导航） |
| **攀爬/翻越** | 🧗 | 特定场景（窗户、矮墙） | 翻越障碍物 |

### 2.2 留影石/相机专用动作

| 动作 | 说明 |
| :--- | :--- |
| **拍照** | 使用留影石或相机，记录当前第一人称视角画面 |
| **查看相册** | 打开已拍摄的照片列表 |
| **展示照片** | 向他人展示某张照片 |
| **删除照片** | 销毁某张照片 |

### 2.3 行动功能菜单（全局行动）

除了上下文交互，玩家还有一个全局行动菜单，可以通过快捷键唤出，包含不需要对准目标即可执行的动作。

| 全局行动 | 图标 | 说明 |
| :--- | :--- | :--- |
| **呼喊** | 📢 | 大声呼喊，吸引附近所有角色注意，声音传播半径比公开对话更大 |
| **制造噪音** | 💥 | 在当前位置制造噪音（如敲击墙壁、扔东西），用于吸引或误导他人 |
| **留下标记** | 📌 | 在当前位置留下一个隐蔽的标记，只有自己和信任的盟友能看到 |
| **加速移动** | 🏃 | 短暂提高移动速度，但会产生更大脚步声（更容易被他人感知） |
| **潜行移动** | 🥷 | 降低移动速度和脚步声，更难被他人感知（需要潜行能力） |
| **假装受伤** | 🤕 | 伪装受伤状态（可能被医术检查识破） |
| **自首/坦白** | 🏳️ | 公开承认自己的罪行或秘密 |
| **伪装调整** | 🎭 | 进入伪装管理界面，编辑公开档案或调整伪装道具 |
| **查看环境** | 🔭 | 仔细观察当前环境，高亮所有可交互物品 |
| **等待** | ⏳ | 原地等待一段时间，可能用于制造不在场证明或等待时机 |

## 十、总结

完整的玩家交互界面方案覆盖了：

- **常驻HUD**：状态、任务、小地图
- **上下文交互**：对角色、物品、场景的完整动作
- **全局行动**：呼喊、制造噪音、潜行、伪装调整等主动行动
- **信息管理**：背包、档案、笔记推理
- **辅助系统**：可关闭的指引和建议
- **沉浸设置**：强制变声器、可选文字润色
- **语音系统**：公开/耳语切换、状态指示
- **特殊机制**：时间、迷宫、暗杀等专用界面

这套体系确保了玩家可以在3D世界中自如行动、管理信息、进行社交博弈，同时保留了完整的沉浸感和策略深度。
