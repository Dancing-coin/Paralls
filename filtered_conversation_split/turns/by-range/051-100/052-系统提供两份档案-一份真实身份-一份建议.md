## 用户

系统提供两份档案，一份真实身份，一份建议伪装身份（属于游玩指导），参与者可以编辑档案再展示。伪装后，真实身份可能会在搜证中被揭露出来，但参与者在一开始就必须对这些有知情权，所以他们可以在游戏里去选择销毁证据或者灭口npc。 该服务器可以自行选择外貌和性别是否可以隐藏的，必须使用道具伪装，该道具的存在，是很难被销毁的知识（多个npc知道或者多个关键搜证里存在，或者以记录形式存在但销毁这种证据非常消耗时间等机制）。

你说得对。伪装不能是凭空存在的“设定”，它必须有**物理载体**。这既增加了游戏的真实感，也为伪装者创造了有意义的策略选择：是冒险销毁证据，还是承受被揭露的风险？

## 一、开本时两份档案的分发

开本时，系统向每位参与者（玩家或智能体）提供两份档案：

### 真实身份档案（仅自己可见）

| 内容 | 说明 |
| :--- | :--- |
| **完整身份** | 真实姓名、职业、出身、社会阶层 |
| **人生记忆摘要** | 关键事件、创伤、执念的来源 |
| **核心秘密** | 必须隐藏的真相（可能是凶手身份，也可能是其他秘密） |
| **真实不在场证明** | 案发时实际在做什么 |
| **伪装所需道具清单** | 当前角色为维持伪装所持有的道具及其位置（见下文） |

### 建议伪装身份档案（扮演者可编辑）

| 内容 | 说明 |
| :--- | :--- |
| **建议公开身份** | 系统根据真实档案和伪装深度自动生成的假身份说明书 |
| **可编辑权限** | 扮演者可以修改、隐藏、增删任意条目 |
| **游玩指导** | 系统附注的“伪装建议”（如“你的假身份是XX，建议你重点隐藏以下信息...”） |

---

## 二、伪装必须有物理道具支撑

伪装不是口头声明就生效的。外貌伪装和身份伪装必须依赖具体的道具。这些道具是**物理存在于游戏世界中的物品**，可以被搜查、被发现、甚至被销毁。

### 伪装道具的类型

| 伪装需求 | 对应道具 | 例子 |
| :--- | :--- | :--- |
| **外貌伪装** | 假发、面具、化妆品、染剂、义肢、束胸/垫肩、服装 | 男性伪装成女性需要假发+束腰+化妆品 |
| **声音伪装** | 变声器（现代背景）、特制喉部贴片、药物 | 老人伪装成年轻人需要压制沧桑感 |
| **身份伪装** | 假证件、假信件、伪造的身份信物 | 冒充贵族需要伪造的族徽戒指 |
| **职业伪装** | 道具服装、专业工具、行业黑话笔记 | 伪装成医生需要医疗包和拉丁文药方本 |
| **不在场证明伪装** | 伪造的车票/船票、被收买的证人 | 被收买的证人本身也是一种“活道具” |

### 外貌伪装的特殊规则

| 规则项 | 说明 |
| :--- | :--- |
| **服务器可配置** | 大玩家在创建服务器时，可以选择是否启用“外貌/性别可隐藏”规则。关闭状态下，外貌和性别是公共知识 |
| **启用时必须有道具** | 如果启用外貌伪装，角色的外貌伪装必须绑定一件或多件特定道具（如“假发”+“束腰”）。没有道具，伪装无效 |
| **道具可被破坏/移除** | 伪装道具可以被其他角色搜查、没收、损坏。一旦道具被移除，外貌伪装当场失效 |
| **道具佩戴有代价** | 佩戴伪装道具可能需要额外时间（如“需要5分钟化妆”），或影响行动能力（如“戴假发在追逃时可能脱落”） |

## 三、伪装道具的存在与销毁难度

伪装道具不是可以轻易消灭的证据。它们的存在被**多重记录**，销毁成本极高。

### 道具存在的多重记录

| 记录方式 | 说明 | 销毁难度 |
| :--- | :--- | :--- |
| **物理道具本身** | 道具是场景中的实物，藏在某处或被伪装者随身携带 | 可以销毁，但需要时间+工具+不被发现 |
| **NPC记忆** | 多个NPC知道此道具的存在。如假发店的老板记得“有位先生来买过女士假发” | NPC是人，灭口一个可能引来更大怀疑；灭口多个几乎不可能 |
| **关键搜证记录** | 剧本配置时，道具被写入线索池。即使道具被销毁，线索仍可能指向它曾存在过（如“抽屉里有一张假发店的收据”） | 收据可以被烧，但烧毁行为可能被目击 |
| **时间消耗机制** | 彻底销毁某类证据需要超长时间（如“焚毁一本日记需要5分钟持续操作”），期间可能被任何人撞见 | 无法在公开活动时间完成，必须找“独处机会” |

### 销毁证据的策略风险

| 行动 | 风险 |
| :--- | :--- |
| **销毁物理道具** | 需要独处时间+工具，行动期间可能被目击；道具消失本身可能引人怀疑（“你的假发怎么突然不见了？”） |
| **灭口知情人** | 可能触发新案件，引入全新的调查方向；灭口失败则直接暴露 |
| **销毁文书证据** | 需要时间，可能被撞见；烧毁的残骸可能仍被发现 |

## 四、参与者对伪装证据的处理策略

参与者从一开始就知道自己的伪装依赖哪些道具、哪些NPC知情。他们可以主动选择：

| 策略 | 操作 | 风险 |
| :--- | :--- | :--- |
| **提前销毁** | 在游戏初期，趁他人不注意时销毁关键道具 | 销毁行为本身可能被目击；道具消失可能引发时间线矛盾 |
| **转移藏匿** | 将道具从原位置转移到更隐蔽的地方 | 转移过程可能被目击；新藏匿点仍可能被搜出 |
| **收买/威胁知情人** | 找到知道道具存在的NPC，通过交易或威胁让他们闭嘴 | NPC可能假装同意，转身告密；或NPC因此对你产生更高怀疑 |
| **抢先自曝** | 主动部分公开伪装（如“我确实戴了假发，但不是因为我是凶手，而是因为...”） | 部分坦诚可能缓解压力，但也可能引火烧身 |
| **不作为** | 不处理道具，寄希望于无人发现 | 一旦被搜出，伪装当场瓦解 |

---

## 五、伪装被揭露的后果

当关键伪装道具被发现，或知情人当众揭发时：

| 揭露程度 | 后果 |
| :--- | :--- |
| **道具被发现** | 与该道具有关的伪装条目当场失效，其他角色对该伪装者的怀疑值上升 |
| **NPC当众揭发** | 公开对话中，NPC说出“我看到XX在案发前去过假发店”。该信息成为公共知识 |
| **真实身份完全暴露** | 伪装者的真实档案被公开，所有伪装失效。此时伪装者可能选择坦白、逃跑、或做出极端行为 |

## 六、总结

在Paralls中，伪装是：

- **有物理载体的**：外貌伪装必须依赖可被搜查的道具
- **可被销毁但代价高昂的**：道具被多重记录（NPC记忆+搜证线索+时间消耗），彻底消除痕迹几乎不可能
- **扮演者全程知情的**：开本时就知道伪装依赖哪些道具、哪些人知情，可以自主制定策略
- **充满策略选择的**：销毁还是保留、转移还是冒险，都是真实的博弈
- **可配置的**：服务器经营者可以决定是否启用外貌伪装，适配不同时代背景的剧本

这让伪装不再是轻飘飘的“设定声明”，而是一场围绕真实物证展开的、充满紧张感的猫鼠游戏。
