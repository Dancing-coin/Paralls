## 用户

所以暗杀无视数值，只看凶手是否有暗杀能力？

## DeepSeek

暗杀不是“无视数值”，而是**不用数值对抗**。两者的区别是：

- **数值对抗**：攻击方攻击力 vs 防御方防御力，数值高的赢。这是打斗系统的逻辑，我们不要。
- **条件判断 + 风险判定**：是否满足暗杀条件？执行过程中有哪些风险？这是暗杀系统的逻辑。

---

## 一、暗杀的核心判断：能力门槛 + 风险链条

### 1. 能力门槛：不是二元开关

暗杀能力来源于角色的人生记忆，但能力本身是有**等级**的。等级不决定“暗杀是否成功”，而是决定**“你能执行多复杂的暗杀”**和**“你留下的痕迹有多明显”**。

| 能力等级 | 能执行的暗杀方式 | 痕迹控制 |
| :--- | :--- | :--- |
| L0 无能力 | 不可主动执行暗杀 | - |
| L1 基础 | 徒手勒杀、使用随手可得的钝器 | 痕迹明显，容易被法医线索锁定 |
| L2 熟练 | 刀具刺击、绳索勒杀、基础下毒 | 痕迹有所控制，但仍会留下关键物证 |
| L3 专家 | 无声暗杀、精准致命、复杂下毒 | 痕迹极少，但仍有时间线矛盾 |
| L4 大师 | 几乎无声无息，可制造“意外死亡”假象 | 痕迹极少，但无法消除所有逻辑线索 |

**门槛的意义**：L0角色想暗杀，系统直接不允许。L1角色可以暗杀，但方式受限，痕迹明显。L3角色暗杀更干净，但仍逃不过时间线矛盾的追查。

### 2. 暗杀成功与否的判断：条件是否满足

暗杀不是“掷骰子”决定的，而是**条件是否全部满足**：

| 条件 | 判断方式 |
| :--- | :--- |
| **能力条件** | 角色能力 ≥ 暗杀方式所需最低等级 |
| **凶器条件** | 暗杀方式需要的凶器是否在手中或可触及 |
| **独处条件** | 目标是否在暗杀者可接近的范围内，且无其他人在清晰区 |
| **时间条件** | 暗杀所需时间是否 ≤ 可用的独处时间窗口 |
| **干扰条件** | 目标是否察觉到异常（由目标的心智状态决定，见下文） |

**满足全部条件 → 暗杀成功。任一条件不满足 → 暗杀无法执行或被中断。**

---

## 二、目标的状态影响：不是数值对抗，而是风险调节

目标不是木桩。目标的人格和当前状态会影响暗杀的风险，但不构成数值对抗。

### 1. 目标的警觉状态

| 目标状态 | 对暗杀的影响 |
| :--- | :--- |
| **毫无防备** | 正常执行暗杀，计时按标准时间 |
| **有所警惕**（知道自己可能被盯上，或当前压力值高） | 目标会更频繁地观察周围，或避免独处。这增加暗杀者寻找独处窗口的难度，或缩短可用的时间窗口 |
| **高度警觉**（已知有人要杀自己，或刚刚躲过暗杀） | 目标可能主动待在公共区域、结伴行动。暗杀者几乎找不到独处窗口 |

### 2. 目标的人格对暗杀风险的影响

这不是目标在“抵抗”暗杀，而是**目标本身的行为特征影响了暗杀的难度**。

| 目标人格 | 对暗杀的影响 |
| :--- | :--- |
| **高胆量** | 即使知道有危险，可能仍会独自调查，给暗杀者可乘之机 |
| **低胆量** | 一有风吹草动就躲起来或找人结伴，暗杀窗口缩短 |
| **高心机** | 可能察觉到暗杀者的意图，设下陷阱（如假装独处，实际埋伏了目击者） |
| **高理性** | 会冷静分析威胁来源，提前转移关键证据或告知信任的盟友，暗杀的动机可能提前暴露 |
| **高社交** | 倾向于与多人待在一起，独处时间极少 |

这些不是数值对抗，而是**目标自主行为对暗杀条件的间接影响**。

### 3. 暗杀中的“意外”——风险判定

即使所有条件都满足，暗杀过程中仍可能出现意外。这不是随机数决定的，而是由**叙事导演根据当前局势**进行的动态风险判定：

| 意外类型 | 触发条件 | 结果 |
| :--- | :--- | :--- |
| **被第三者目击** | 暗杀计时期间，有其他角色意外经过（由导演根据角色的移动路线和场景连接关系判定） | 目击者获得“疑似”或“确认”信息 |
| **目标发出声响** | 目标在暗杀过程中挣扎、呼救（由目标胆量和环境判定） | 附近角色可能听到模糊声响 |
| **凶器意外破损** | 临时使用的凶器不够坚固 | 暗杀方式被迫改变，时间延长，痕迹增多 |

**核心：意外不是随机数，而是由导演基于逻辑推演的风险事件。** 暗杀者越谨慎（选择更隐蔽的时间地点、使用更可靠的凶器），意外越少。

---

## 三、总结：暗杀的成功逻辑

| 要素 | 作用 | 是否数值对抗 |
| :--- | :--- | :--- |
| **凶手能力等级** | 决定可用的暗杀方式和痕迹控制程度 | 否，是门槛和后果的标尺 |
| **条件满足** | 独处、凶器、时间全部满足才可执行 | 否，是条件判断 |
| **目标状态** | 影响独处窗口和暗杀者策略选择 | 否，是目标自主行为的影响 |
| **意外风险** | 导演基于逻辑推演的动态事件 | 否，是叙事逻辑的延伸 |

**暗杀不是数值对抗，而是一场逻辑推演。** 它依赖于暗杀者的能力、时机选择、环境利用，以及目标的自主行为所产生的连锁反应。这完全符合Paralls追求的“叙事涌现”而非“数值碾压”。
