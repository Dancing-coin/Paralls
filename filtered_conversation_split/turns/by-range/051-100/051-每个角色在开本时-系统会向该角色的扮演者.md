## 用户

每个角色在开本时，系统会向该角色的扮演者（无论玩家还是智能体）提供一份公开档案，该角色的扮演者可以选择编辑修改或隐藏档案信息，这是该角色选择对外展示的身份信息。 但一旦你的伪装获得了影响游戏平衡的优势，叙事导演就会开始微操智能体产生些许怀疑冲动，微操环境变化等等。

## DeepSeek

你说得对，这是伪装系统的最后一块拼图。扮演者拥有编辑公开档案的自由，但这份自由不是无限的——当伪装带来的优势开始破坏游戏平衡时，叙事导演会以符合世界观的方式，微妙地推动世界做出反应。

## 一、公开档案：扮演者可控的身份面具

开本时，系统向每位扮演者（玩家或智能体）提供一份初始公开档案。这份档案是基于角色的真实档案和伪装深度自动生成的**建议版本**。

### 扮演者对公开档案的控制权

| 操作 | 说明 | 限制 |
| :--- | :--- | :--- |
| **编辑** | 修改公开档案中的任意条目（姓名、职业、背景、不在场证明等） | 修改后的内容不能违反事实数据库中的公共事实 |
| **隐藏** | 将某些条目标记为“不公开”，其他角色查看时显示为“未知” | 不能隐藏所有人都必然知道的信息（如外貌、性别） |
| **选择性公开** | 在游戏过程中，选择性地向特定对象透露被隐藏的信息 | 一旦公开，该信息对该对象变为“确认”状态 |
| **版本管理** | 扮演者可以随时修改自己的公开档案（模拟“圆谎”） | 每次修改都会被记录，频繁修改可能在他人追问下露出破绽 |

### 初始公开档案的生成

| 伪装深度 | 初始公开档案的内容 |
| :--- | :--- |
| **零伪装** | 公开档案 = 真实档案。扮演者无编辑需求，但可以选择隐藏某些无关紧要的信息 |
| **浅层伪装** | 公开档案中仅1-2项与真实档案不同（如案发时行踪），其余真实 |
| **中度伪装** | 身份真实，但不在场证明和部分背景经历为虚构 |
| **深度伪装** | 整份公开档案都是伪造的，扮演者拿到的是一个完整的“假身份说明书” |

**关键设计**：无论伪装多深，扮演者始终知道自己角色的**真实档案**。公开档案是他们主动选择展示给世界的面具。

## 二、伪装优势与叙事导演的反制

这是你提出的核心机制。当伪装行为让某一方获得了破坏游戏平衡的优势时，叙事导演必须介入。

### 1. 什么是“影响游戏平衡的优势”

叙事导演持续评估游戏双方或多方的胜率。当以下情况出现时，判定某一方获得了失衡优势：

| 优势类型 | 具体表现 | 检测指标 |
| :--- | :--- | :--- |
| **信息垄断** | 某一方掌握的关键线索远超另一方，且该方利用伪装阻止信息扩散 | 线索分布严重不均，弱势方超过一定时间未获得有效新信息 |
| **嫌疑完全转移** | 真凶通过完美伪装将所有嫌疑成功转移到无辜者身上，无人质疑真凶 | 真凶的怀疑值持续为零，而无辜者的怀疑值持续上升 |
| **不在场证明完美闭环** | 真凶构建的不在场证明无懈可击，且所有可质疑的线索都已被其销毁或掩盖 | 导演检测到所有指向真凶的逻辑路径都已被切断 |
| **阵营一边倒** | 好人阵营或凶手阵营即将获得不可逆转的必胜局面 | 胜率预测超过阈值 |

### 2. 叙事导演的反制手段

当检测到失衡优势时，导演按以下阶梯逐步升级干预：

**第一阶梯：智能体冲动（最温和）**

导演向相关智能体发送模糊的“怀疑冲动”。

| 目标智能体 | 冲动内容 | 效果 |
| :--- | :--- | :--- |
| 对伪装者信任值高的智能体 | “你突然觉得XX最近的言行有些不对劲，但你无法确切说出哪里不对” | 该智能体对伪装者的信任值微幅下降，开始更仔细地观察 |
| 对伪装者已有怀疑的智能体 | “你对XX的怀疑挥之不去，你觉得他可能在隐藏什么” | 该智能体更倾向于主动试探伪装者 |
| 掌握部分线索但未连起来的智能体 | “你隐约觉得手头的线索似乎指向一个你还没想到的方向” | 该智能体开始重新审视已有线索 |

**智能体是否响应冲动，由其人格过滤器自主决定。** 高理性者可能会压制冲动，低理性者可能会立即行动。

**第二阶梯：环境催化（中等强度）**

导演通过场景变化，创造让伪装暴露的机会。

| 催化方式 | 具体表现 | 效果 |
| :--- | :--- | :--- |
| **遗留痕迹** | 伪装者曾声称从未进入的书房，突然被人发现地上有与他鞋底纹路一致的泥土 | 制造新的物证，挑战伪装者的说辞 |
| **巧合相遇** | 伪装者声称案发时独自在某处，但导演安排另一个智能体恰好在那个时段经过附近 | 制造潜在的目击者 |
| **物品浮现** | 一件被伪装者藏匿或忽略的线索物品，因环境变化（如“风吹开窗帘，露出桌下的一封信”）而被发现 | 打破信息垄断 |
| **天气突变** | 暴雨把所有人困在同一个空间内，迫使伪装者长时间处于被观察状态 | 增加伪装维持的压力 |

**第三阶梯：NPC引导（较强干预）**

导演向关键NPC提供“确凿信息”，推动故事走向。

| 引导方式 | 内容 | 前提条件 |
| :--- | :--- | :--- |
| **记忆唤醒** | 导演告知某个智能体：“你突然想起，那天晚上你确实看到XX从死者的房间方向过来，只是当时你没在意” | 该智能体在逻辑上当时确实可能在场 |
| **信息确认** | 导演告知某个智能体：“你刚才在走廊上，确实听到了书房里的争吵声中有XX的声音” | 该智能体确实在感知范围内 |
| **线索串联** | 导演向高理性智能体发送一个“启发”：“你把最近几天看到的几件反常小事串起来，突然意识到它们都指向同一个人” | 该智能体确实收集到了这些信息碎片 |

**第四阶梯：节奏控制（全局调控）**

当上述手段仍不足以恢复平衡时，导演进行全局节奏调整。

| 调控方式 | 说明 |
| :--- | :--- |
| **延长讨论阶段** | 在伪装者即将完美逃脱时，导演触发一个次要事件，延长游戏时间，给予好人阵营更多翻盘机会 |
| **强制公开环节** | 在规则允许范围内，触发一个“公开辩论”或“最后陈述”环节，要求每个角色当众自辩 |
| **新冲突引入** | 如果伪装者优势过大，导演可能触发一个新事件（如发现第二个隐藏的证据），打破现有局势 |

### 3. 干预的不可见原则

导演的所有反制手段必须遵循：

| 原则 | 说明 |
| :--- | :--- |
| **不可见** | 不能让玩家感觉到是“系统在帮我”或“系统在整我” |
| **逻辑自洽** | 所有干预必须有合理的世界观解释（风吹开窗帘，而非凭空出现线索） |
| **人设符合** | 所有通过智能体的干预，必须经过该智能体的人设过滤器 |
| **可被忽略** | 导演的冲动和催化，智能体和玩家都可以选择不响应。干预是“机会的创造”，而非“命运的强制” |

## 三、玩家伪装的特殊处理

玩家编辑公开档案的自由度高于智能体，但同时也面临更复杂的后果。

### 玩家伪装的风险

| 风险 | 说明 |
| :--- | :--- |
| **逻辑漏洞** | 玩家自编的伪装可能与其他事实矛盾，在后续游戏中被其他玩家发现 |
| **压力累积** | 虽然玩家不会像智能体那样自动计算压力值，但长时间维持复杂伪装本身就是一种心理负担 |
| **其他玩家的质疑** | 其他玩家通过观察和推理，可能主动识破伪装 |
| **导演反制** | 当玩家的伪装过于完美、破坏了游戏平衡时，导演同样会启动反制机制 |

### 叙事导演对玩家伪装的反制

与对智能体的反制逻辑相同，但导演更倾向于通过**环境催化**和**向其他智能体发送冲动**来间接施压，而非直接干预玩家行为。

---

## 四、总结

在Paralls中，伪装是一场动态的、有代价的博弈。

- **扮演者拥有编辑公开档案的自由**，可以主动塑造自己的身份面具
- **伪装获得优势时，叙事导演启动反制**，通过智能体冲动、环境催化、NPC引导逐步升级干预
- **干预永远是间接的、不可见的、可被抵抗的**，它创造机会而非强加结果
- **玩家和智能体的伪装受同一套系统约束**，但玩家的自由度更高，风险也更高

这套机制确保：伪装是强大的策略工具，但不是无解的必胜法门。每一个完美的谎言，都在暗中承受着世界本身的反作用力。这正是Paralls追求的动态叙事平衡——不是强制公平，而是让每一次欺骗都充满风险和戏剧张力。
