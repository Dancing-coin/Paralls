## 用户

玩家默认的交互面板有：自己的档案，能力，交互动作选择，自己的背包面板等，还有什么你来想想，来完善一下。然后辅助面板，变声器和文字润色也要放进来但辅助面板和文字润色可关闭。

## DeepSeek

好的，我来为Paralls设计一套完整的玩家交互界面方案。核心原则：**信息私有、操作直觉、沉浸优先、辅助可选**。

## 一、默认交互面板（始终可用）

### 1.1 状态栏

屏幕角落常驻，显示角色当前的核心状态。

| 显示项 | 说明 |
| :--- | :--- |
| **角色名** | 当前扮演的角色姓名（公开名） |
| **压力值** | 0-10，直观显示（如进度条或颜色变化） |
| **当前情绪** | 文字标签（如“紧张”、“冷静”、“恐惧”） |
| **体力/伤势** | 若有暗杀或战斗机制，显示身体状态 |
| **特殊状态** | 中毒、致幻、醉酒等状态图标 |

### 1.2 任务与秘密提醒

屏幕另一角常驻，仅自己可见。

| 显示项 | 说明 |
| :--- | :--- |
| **核心秘密** | 一句简短的秘密提醒（如“你就是真凶”） |
| **当前首要目标** | 从目标层级中提取当前最高优先级目标 |
| **任务进度** | 可选，如“已收集线索 3/7” |

### 1.3 交互动作栏

动态显示当前可执行的交互动作，根据所选目标和情境变化。

| 动作 | 触发条件 | 说明 |
| :--- | :--- | :--- |
| **交谈** | 选中一个角色 | 打开对话界面，可选公开/耳语 |
| **展示物品** | 选中一个角色+背包中有物品 | 向对方展示物品 |
| **移交物品** | 选中一个角色+背包中有可移交物品 | 将物品交给对方 |
| **使用物品** | 选中背包中的物品 | 使用或检查物品 |
| **拾取** | 准星对准可拾取物品 | 拾取到背包 |
| **暗杀** | 满足暗杀条件时 | 执行暗杀（需确认） |
| **拍照/留影** | 持有留影石或相机 | 记录当前画面 |
| **开门/关门** | 对准门 | 开关门 |
| **隐藏/躲藏** | 在特定位置 | 进入隐藏状态 |

### 1.4 快捷功能栏

屏幕底部常驻，点击打开对应面板。

| 图标 | 面板 | 说明 |
| :--- | :--- | :--- |
| 🎒 | **背包** | 查看和管理持有的物品、线索、留影石/照片 |
| 📋 | **我的档案** | 查看自己的公开档案和真实档案 |
| 📝 | **笔记与推理** | 信息整理面板（见下方） |
| ❓ | **辅助面板** | 玩法指引+决策建议（可关闭） |
| ⚙️ | **设置** | 变声器、文字润色、音频/视频等设置 |

## 三、我的档案面板

分两个标签页，仅自己可见。

### 3.1 公开档案（对外展示的身份）

| 内容 | 说明 |
| :--- | :--- |
| 姓名、身份、职业 | 对外宣称的信息 |
| 公开背景 | 可被其他角色查阅的自述 |
| 与死者关系 | 对外宣称的关系 |
| 案发时行踪 | 对外宣称的不在场证明 |

**操作**：玩家可以**编辑**公开档案（修改伪装内容），或选择**隐藏**某些条目。

### 3.2 真实档案（仅自己可见）

| 内容 | 说明 |
| :--- | :--- |
| 完整身份信息 | 真实姓名、职业、背景 |
| 人生记忆摘要 | 关键事件、创伤、执念 |
| 核心秘密 | 必须隐藏的真相 |
| 真实不在场证明 | 案发时实际在做什么 |
| 伪装道具清单 | 维持伪装所需的物品及位置 |
| 固定知情人 | 知道自己秘密的NPC和角色 |
| 暗杀能力等级 | L0-L4，可用的暗杀方式 |
| 特殊技能 | 开锁、医术、法术等 |

## 四、笔记与推理面板

玩家的私人侦探白板，所有内容仅自己可见。

| 功能模块 | 说明 |
| :--- | :--- |
| **自由笔记** | 可输入文字、标记时间戳 |
| **线索列表** | 自动记录自己获得的所有线索，支持手动添加备注和标签 |
| **时间线视图** | 将已知事件按时间排列，支持手动添加和拖拽调整 |
| **关系网络图** | 可视化显示自己视角下的角色关系，支持手动添加连线、标注 |
| **嫌疑人评分** | 对自己怀疑的角色进行标记和评分，辅助理清思路 |
| **证据链构建** | 将多条线索拖拽连接，形成推理链。若逻辑正确，系统可给出微弱提示（可选） |

## 五、辅助面板（可关闭）

此面板默认开启，但玩家可在设置中**一键关闭**。

| 辅助模块 | 功能 | 关闭后的影响 |
| :--- | :--- | :--- |
| **玩法指引** | 根据当前阶段显示相关规则提示 | 玩家需自行记忆规则 |
| **机制速查** | 悬停在任何特殊机制上时显示解释 | 玩家需自行理解机制 |
| **决策建议** | 基于局势生成几个符合人设的行动选项（仅参考） | 玩家完全自主决策 |
| **行为后果预估** | 高风险行动（如暗杀）的简要后果提示 | 玩家需自行评估风险 |

**设计原则**：辅助面板提供的是“信息支持”，而非“答案”。它不告诉玩家“凶手是谁”或“你应该选什么”，只帮助玩家理解规则和整理已知信息。

| 设置项 | 说明 | 默认状态 |
| :--- | :--- | :--- |

| **文字润色** | 开启/关闭。关闭后消息以原文发送 | 开启 |
| **辅助面板** | 开启/关闭 | 开启 |
| **字幕显示** | 是否显示附近对话的文字字幕 | 开启 |
| **音频设置** | 主音量、语音音量、环境音量 | - |
| **视频设置** | 画质、分辨率、亮度 | - |
| **操作设置** | 移动灵敏度、反转视角、快捷键 | - |
| **语言** | 界面语言选择 | 跟随系统 |

## 九、面板互斥与层叠规则

| 规则 | 说明 |
| :--- | :--- |
| **全屏面板** | 背包、档案、笔记、辅助、设置——打开时覆盖游戏画面，可拖动和调整大小 |
| **半透明悬浮** | 状态栏、任务提醒、交互动作栏——始终半透明浮在游戏画面上，不遮挡核心视野 |
| **可同时打开** | 笔记和背包可同时打开（方便对照线索） |
| **快捷键** | 每个面板都有快捷键，支持手柄和键盘操作 |

---

这套交互界面确保了：
- **沉浸感**：核心信息常驻但低调，不打断3D世界的体验
- **可操作性**：所有交互动作用最简单的操作触发
- **信息管理**：笔记面板成为玩家的第二大脑，但所有内容私有
- **辅助可选**：新手可依赖辅助上手，老手可关闭追求纯粹体验
- **强制沉浸**：变声器不可关闭，确保所有人声线统一，智能体语音无法被区分
