## 用户

灭口 那打斗或者暗杀机制怎么设计？

## DeepSeek

在Paralls中，打斗和暗杀不是“战斗系统”，而是**叙事系统的一部分**。它们必须符合我们一直以来的设计原则：能力约束、逻辑自洽、代价高昂、可被侦破。

---

## 一、核心设计原则

| 原则 | 说明 |
| :--- | :--- |
| **不是所有人都会打斗** | 打斗/暗杀能力由角色的基因种子和人生记忆决定，而非每个角色都拥有 |
| **不是所有地方都能打斗** | 打斗/暗杀受场景约束（是否有凶器、是否会被目击、是否有足够时间） |
| **打斗/暗杀必有痕迹** | 任何暴力行为都会产生物证和潜在目击者，无法完美消除 |
| **打斗/暗杀推动叙事** | 暴力行为不是游戏的终点，而是新调查的起点 |

---

## 二、能力约束：谁能打、谁能暗杀

### 1. 角色能力的来源

角色是否具备打斗或暗杀能力，由其人生记忆决定。

| 能力来源（人生记忆） | 具体能力 | 典型角色 |
| :--- | :--- | :--- |
| **军事/武术训练** | 正面打斗、快速制服 | 退伍军人、武术家 |
| **街头生存经验** | 偷袭、使用简易凶器 | 街头混混、江湖浪人 |
| **狩猎/解剖经验** | 暗杀、精准致命攻击 | 猎人、医生（知道哪里最致命） |
| **间谍/特工训练** | 无声暗杀、下毒 | 间谍、刺客 |
| **无任何相关经验** | 无法执行有意识的暴力行为 | 普通富家小姐、老迈管家 |

### 2. 能力等级

| 等级 | 名称 | 打斗 | 暗杀 | 防御/闪避 |
| :--- | :--- | :--- | :--- | :--- |
| L0 | 无能力 | 不可执行 | 不可执行 | 基本为零 |
| L1 | 基础 | 可能打不过，容易受伤 | 成功率低，极易留下痕迹 | 可能躲闪几下 |
| L2 | 熟练 | 可与同级抗衡 | 成功率中等，能控制痕迹 | 能有效防御同级 |
| L3 | 专家 | 可靠地击败低级别 | 成功率高，痕迹控制好 | 能闪避多数攻击 |
| L4 | 大师 | 压制多数对手 | 几乎无声无息 | 极难被击中 |

---

## 三、场景约束：何时何地能打斗/暗杀

暴力行为不是任何时刻都能触发的。叙事导演和场景规则共同约束。

### 1. 通用约束

| 约束条件 | 说明 |
| :--- | :--- |
| **必须在同一场景** | 攻击者和目标必须处于同一个3D场景中 |
| **必须有凶器或徒手能力** | 徒手攻击需要L1+，使用凶器需要凶器在可触及范围内 |
| **必须有时间窗口** | 不能有其他角色在清晰区内（暗杀）或至少不能有能阻止的角色（打斗） |
| **必须满足物理距离** | 靠近目标到一定范围 |

### 2. 暗杀的特殊约束

| 约束 | 说明 |
| :--- | :--- |
| **独处窗口** | 目标必须处于攻击者的模糊区或清晰区内，且无其他目击者 |
| **环境掩护** | 场景中有遮挡物、黑暗角落、噪音环境等，降低被他人感知的概率 |
| **时间足够** | 从接近到完成暗杀再离开，所需的时间必须在剧本阶段时间限制内 |

### 3. 打斗的特殊约束

| 约束 | 说明 |
| :--- | :--- |
| **触发条件** | 可以是主动发起，也可以是被发现后被迫反击 |
| **可被中断** | 打斗进行时，若有其他角色进入清晰区，打斗可能被中断或目击 |

---

## 四、暗杀机制

暗杀是伪装者最极端的知情管理策略，也是最危险的一种。

### 1. 暗杀流程

```
[触发暗杀意图]
  → [能力检查]：角色能力等级是否 ≥ 目标能力等级（或目标无防备）
  → [场景检查]：是否有独处窗口、是否有凶器、是否在可执行时间
  → [执行暗杀]：开始一个计时器（暗杀所需时间）
  → [目击风险]：计时期间，叙事导演持续检测是否有其他角色进入感知范围
  → [结果判定]：成功/失败/被中断
```

### 2. 暗杀所需时间

| 暗杀方式 | 所需时间 | 条件 |
| :--- | :--- | :--- |
| **徒手勒杀** | 15-30秒 | L1+，力量足够 |
| **刀具刺击** | 3-5秒 | L1+，刀具在手 |
| **钝器击打** | 5-10秒 | L1+，钝器在手 |
| **下毒** | 不需要当场执行 | L2+，需要先获取毒药并投入目标饮食中 |

### 3. 暗杀结果

| 结果 | 条件 | 后果 |
| :--- | :--- | :--- |
| **完全成功** | 计时完成，无人目击 | 目标死亡，攻击者未被发现。但物证仍在（尸体、凶器、痕迹） |
| **成功但被听/看到** | 计时完成，但有角色在模糊区或短暂进入清晰区 | 目标死亡，但目击者获得“疑似”或“确认”信息 |
| **被中断** | 计时未完成，有人进入清晰区 | 目标受伤但未死，或攻击被阻止。攻击者暴露 |
| **反击** | 目标能力高于攻击者 | 攻击可能被反制，攻击者自己受伤或死亡 |

### 4. 暗杀必然留下的痕迹

| 痕迹类型 | 内容 | 可否消除 |
| :--- | :--- | :--- |
| **尸体** | 死者的死亡方式（勒杀痕迹、刀伤） | 可移动，但移动尸体本身会产生新痕迹 |
| **凶器** | 凶器上可能有指纹、毛发 | 可销毁，但如我们之前讨论，销毁需要时间和独处 |
| **打斗痕迹** | 挣扎留下的家具位移、血迹、布片 | 可清理，但需要大量时间 |
| **时间线矛盾** | 暗杀者在某个时间段无法解释行踪 | 不可消除，只能编造谎言 |
| **潜在目击者** | 暗杀前后经过附近的人 | 不可消除，只能通过收买或威胁来管理 |

## 五、打斗机制

打斗可能是主动发起，也可能是暗杀失败或被发现后的被迫反击。

### 1. 打斗流程

```
[打斗触发]
  → [能力对比]：攻击方能力等级 vs 防御方能力等级
  → [环境修正]：是否有凶器、地形优势、当前压力值影响
  → [打斗计时]：打斗持续一定时间
  → [目击风险]：打斗产生噪音，导演增大清晰区范围，吸引其他角色
  → [结果判定]
```

### 2. 能力对比判定

| 对比 | 结果倾向 |
| :--- | :--- |
| 攻击方 > 防御方2级以上 | 快速压制，防御方重伤或死亡 |
| 攻击方 > 防御方1级 | 攻击方优势，但需要一定时间，防御方可拖延等救援 |
| 同等级 | 僵持，双方均可能受伤，打斗时间较长 |
| 攻击方 < 防御方 | 攻击方可能被反制 |

### 3. 环境修正因素

| 因素 | 修正 |
| :--- | :--- |
| 攻击方持有凶器，防御方徒手 | 攻击方能力临时+1 |
| 攻击方从背后偷袭 | 攻击方第一击必中，防御方第一反应为挣脱而非反击 |
| 狭窄空间 | 高能力者的优势被缩小 |
| 黑暗环境 | 双方命中率均下降，打斗时间延长，增加被目击风险 |
| 攻击方当前压力值极高 | 能力临时-1（慌乱影响发挥） |

### 4. 打斗结果

| 结果 | 条件 | 后果 |
| :--- | :--- | :--- |
| **攻击方完胜** | 能力碾压或偷袭成功 | 防御方死亡/失去行动能力，攻击方轻伤或无伤 |
| **攻击方惨胜** | 能力略高但防御方反抗 | 防御方死亡，但攻击方受伤（留下物证：血迹、伤痕） |
| **双方受伤** | 能力相当或环境复杂 | 双方均受伤，打斗可能因第三方介入而中断 |
| **攻击方被反杀** | 防御方更强 | 攻击方死亡或重伤 |
| **被中断** | 第三方进入清晰区 | 打斗暂停，或第三方加入 |

## 六、暴力行为的后续影响

暗杀或打斗发生后，叙事导演立即启动以下流程：

### 1. 公共事件广播

| 事件 | 传播范围 | 传播方式 |
| :--- | :--- | :--- |
| **尸体被发现** | 发现者 → 清晰区内所有人 → 通过公开对话扩散 | 发现者的反应（尖叫、呼喊）成为公共知识 |
| **打斗噪音** | 打斗发生时的巨大噪音，将打斗发生位置的清晰区范围临时扩大50%，附近角色即使不在视线内也可能听到 | 听到者获得模糊或确认信息 |
| **有人失踪** | 如果目标被暗杀且尸体被隐藏，在规定时间未出现在公开场合时，其他角色可能注意到其缺席 | 由导演检测，可能触发搜索行动 |

### 2. 新的调查方向

暴力行为必然引入新的调查方向：

| 新方向 | 内容 |
| :--- | :--- |
| **法医线索** | 死亡方式、凶器类型、死亡时间——指向有能力执行此类暴力的角色 |
| **时间线重建** | 所有角色在案发时间的行踪被重新审视，不在场证明被重新验证 |
| **动机推理** | 谁有动机灭口此人？此人知道谁的秘密？ |
| **痕迹比对** | 攻击者身上可能留下的伤痕、衣物破损、血迹——成为可被观察和搜证的物证 |

### 3. 对伪装者的反噬风险

| 风险 | 说明 |
| :--- | :--- |
| **暴露武力能力** | 如果伪装者声称“我是一个弱女子”，但死者死于专业手法，伪装直接破裂 |
| **新增嫌疑人身份** | 灭口行为让伪装者从“可能知道什么”变成“可能做了什么”，嫌疑等级跃升 |
| **触发连环暴露** | 为了掩盖灭口，伪装者可能需要销毁更多证据、威胁更多知情人，最终陷入无法控制的连锁反应 |
| **心理压力陡增** | 灭口行为（尤其对于高共情/高诚实角色）带来巨大的心理压力，影响后续的行为表现 |

## 七、叙事导演的角色

在暴力系统中，叙事导演的职责是：

| 职责 | 说明 |
| :--- | :--- |
| **目击者判定** | 在暗杀/打斗计时期间，实时检测是否有其他角色进入感知范围 |
| **痕迹生成** | 根据暴力行为的具体方式，自动生成对应的物证线索 |
| **时间线记录** | 将暴力事件写入事实数据库，用于后续逻辑校验 |
| **平衡监控** | 如果暴力行为让某一方完全失去悬念（如好人方核心侦探被暗杀），导演会通过其他方式提供补救线索 |
| **新叙事线生成** | 暴力行为不是终点，导演将其作为新剧情的起点，推动故事进入下一阶段 |

---

## 八、总结

Paralls中的打斗和暗杀机制，核心原则是：

- **暴力是极端手段，不是默认选项**：只有具备相应能力的角色才能执行，且代价极高
- **暴力必然留下痕迹**：完美犯罪在物理上是不可能的，痕迹成为新的调查方向
- **暴力推动叙事，而非终结叙事**：灭口不是“解决问题”，而是“制造新的问题”
- **导演管理后果，不阻止行为**：暴力行为可以发生，但后果必须被忠实记录和传播

这套机制确保：选择暴力是角色的自由，但承受暴力带来的连锁反应，也是角色逃不掉的宿命。
