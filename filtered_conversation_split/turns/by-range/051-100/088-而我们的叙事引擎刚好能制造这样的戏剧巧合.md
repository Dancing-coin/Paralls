## 叙事引擎与暗杀机制的协作

叙事引擎是暗杀的“机会创造者”，而非“暗杀指令下达者”。它的职责是**排列组合出暗杀条件可能同时满足的时机**，然后将选择权完全交给角色。

---

### 一、叙事引擎的催化逻辑

叙事引擎持续监控所有角色的状态，当检测到以下“紧张态势”时，会尝试催化暗杀条件：

| 紧张态势 | 引擎催化手段 | 暗杀条件被满足 |
| :--- | :--- | :--- |
| 角色A的致命证据被角色B掌握，但B尚未公开 | 引擎通过环境催化，让A恰好发现B独自前往偏僻区域 | 致命动机 + 信息空窗期 + 独处窗口 同时出现 |
| 角色A与角色B存在深仇，但始终没有独处机会 | 引擎向NPC发送冲动，让NPC在特定时间离开B身边 | 致命动机 + 独处窗口 被创造 |
| 角色A的核心秘密即将被B揭露 | 引擎通过节奏控制，延长B公开证据前的犹豫时间 | 信息空窗期 被延长 |

**关键原则**：引擎只负责让条件“恰好同时存在”，不负责决定角色是否行动。角色是否按下暗杀按钮，由其自身的心智模型或玩家决定。

### 三、叙事引擎催化暗杀的具体手法

| 手法 | 示例 |
| :--- | :--- |
| **环境催化** | 暴雨让所有人提前回房，唯独目标因故滞留在书房 |
| **NPC引导** | 管家“恰好”在关键时刻叫走了目标身边的同伴 |
| **节奏控制** | 公开讨论阶段被推迟，给暗杀者留出行动时间窗口 |
| **信息延迟** | 目标掌握了证据但尚未公开——引擎通过让目标犹豫（若目标是AI）或让其他事件打断（若目标是玩家），延长信息空窗期 |
| **空间巧合** | 走廊灯光“恰好”熄灭一盏，制造隐蔽的接近路径 |

---

### 四、叙事引擎的克制原则

引擎催化暗杀时，同样受四重干预原则约束：

| 原则 | 在暗杀催化中的体现 |
| :--- | :--- |
| **间接** | 引擎不直接告诉角色“去杀XX”，只创造条件和发送模糊提示 |
| **不可见** | 玩家感受不到“系统在帮我制造暗杀机会”，只觉得“时机恰好” |
| **逻辑自洽** | 所有催化都有合理的世界解释（暴风雨、NPC有理由离开、灯光故障合理） |
| **公平** | 引擎不会为某一方反复创造暗杀机会，也不会在劣势方即将暗杀时强行破坏 |

### 五、一个完整的戏剧巧合案例

**情境**：《白蛇传·浮生》中，许仙（玩家）掌握了法海（AI）私下收集的妖物证据，正准备在晚餐时公之于众。法海的目标是阻止此事。

1. **紧张态势检测**：天平系统发现，许仙一方即将获得碾压性优势。许仙掌握的证据一旦公开，法海的秘密暴露，游戏可能过早结束。

2. **引擎催化**：
   - 引擎向小青（AI，法海的敌对者，但此刻不在场）发送冲动，让她在晚餐前“恰好”在走廊叫住许仙，询问关于白素贞的事。
   - 许仙被拖住数分钟。信息空窗期被延长。

3. **暗杀条件满足**：法海发现许仙被拖住，而许仙独自一人站在走廊尽头，周围无人。法海有能力(L3)，有动机，有独处窗口。

4. **暗杀任务推送**：系统向法海的扮演者（若是AI则为法海智能体）推送暗杀指引。

5. **选择权在扮演者**：法海可以选择铤而走险，也可以选择放弃，用其他方式应对。

---

### 六、叙事引擎在暗杀事件后的职责

一旦暗杀发生（或未遂），叙事引擎立即接管后果管理：

- 事实核心记录新案件
- 痕迹生成系统产生物证
- 目击者判定（动态知情人）
- 高阶知识图谱更新（谁看到了什么）
- 天平系统重新评估局势
- 必要时催化新的冲突或调查方向

---

**总结：叙事引擎是暗杀戏剧的“时机编排者”，通过环境催化、NPC引导、节奏控制、信息延迟、空间巧合等手法，让暗杀条件恰好同时存在。但它从不替角色做决定——选择是否扣下扳机的，永远是角色自己。**
