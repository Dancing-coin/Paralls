## 用户

知情人分为npc和参与者（智能体或人），你来想想怎么设计机制能照顾整体玩家体验

## DeepSeek

在Paralls中，知情人机制是伪装博弈的核心。它不能成为“谁有知情人谁就必胜”的简单游戏，也不能让伪装者因知情人的存在而毫无胜算。一套好的知情人机制，应该创造出**多维度的策略选择**，让每一方都有操作空间。

---

## 一、知情人分类与知情内容

| 知情人类型 | 身份 | 知情内容 | 知情方式 |
| :--- | :--- | :--- | :--- |
| **固定NPC知情人** | 由剧本创作者预设的NPC | 知道伪装道具的某个关键信息（如假发店老板记得有人买过女士假发） | 剧本配置时写入NPC的记忆库 |
| **动态NPC知情人** | 游戏过程中因感知而获知的NPC | 无意中目击伪装者的异常行为（如看到伪装者销毁道具） | 由叙事导演根据L1感知层判定，注入NPC记忆 |
| **智能体参与者知情人** | 其他AI角色 | 通过观察或线索，推论出伪装者的真实身份或道具存在 | 智能体自己的心智模型推理得出 |
| **玩家参与者知情人** | 其他真人玩家 | 同上，由玩家自己推理或发现 | 玩家在游戏中搜证、观察得出 |

---

## 二、NPC知情人的设计

### 1. 固定NPC知情人的平衡设计

固定NPC知情人由创作者预设。为避免成为“剧情杀”，需遵循以下规则：

| 设计原则 | 说明 |
| :--- | :--- |
| **知情不完整** | 一个NPC只会知道伪装拼图的一小块，不足以单独揭露整个伪装。例如，假发店老板只知道“有人来买过假发”，但不知道买主是谁，也不知道买主现在的伪装身份 |
| **知情不出卖** | NPC不会无缘无故主动揭露。除非被直接询问、威胁，或受到人格驱动的影响 |
| **知情可被影响** | 伪装者可以通过收买、威胁、博取同情等方式，改变NPC的行为（是守口如瓶还是告密） |
| **数量有限** | 每个伪装者的固定知情人不超过2-3个，避免伪装被无数眼睛盯着 |

**NPC的人格对知情行为的影响：**

| NPC人格倾向 | 行为表现 |
| :--- | :--- |
| 高胆量+高正义感 | 被询问时可能直接揭露 |
| 低胆量+高自私 | 可能被收买，或害怕报复而不敢说 |
| 高心机 | 可能以此信息为筹码，进行交易 |
| 高共情 | 如果伪装者博取同情，可能选择沉默 |

### 2. 动态NPC知情人的触发

叙事导演在游戏中动态判定NPC是否目击了什么。这创造了意外和紧张感。

| 触发条件 | 判定逻辑 | 知情内容 |
| :--- | :--- | :--- |
| 伪装者在NPC的感知范围内进行可疑行动 | 导演根据NPC的感知范围、当时注意力、环境光线等判定是否“目击” | 标记为“疑似看到XX在做什么”，而非确认 |
| NPC与伪装者在事件中擦肩而过 | 导演随机判定，概率与伪装者的行为莽撞程度成正比 | 模糊的感知，不足以确认，但NPC的怀疑值上升 |

**动态知情的缓冲机制**：即使NPC被判定为“目击”，导演也不会立即让NPC跑出去喊叫。NPC会先进行自己的心智模型决策：是害怕、是好奇、还是去找信任的人商量？

## 三、参与者作为知情人的设计

### 1. 智能体参与者知情人

当智能体通过自己的心智模型推断出某人的伪装时，它的行为受其完整人格档案约束。

| 智能体人格 | 可能的反应 |
| :--- | :--- |
| 高正义感+高胆量 | 可能当众揭发 |
| 高心机+低胆量 | 可能私下告知自己信任的人，或利用此信息要挟伪装者 |
| 高共情 | 如果理解伪装者的苦衷，可能选择帮忙隐瞒 |
| 高理性 | 在没有确凿证据前，不会轻举妄动，而是继续收集证据 |
| 低理性+高胆量 | 可能在证据不足时就冲动揭发，结果自己反而被质疑 |

**智能体的揭示方式：**

| 方式 | 效果 |
| :--- | :--- |
| **公开揭发** | 在清晰区大声说出，形成公共知识 |
| **私下告知** | 使用耳语模式告诉特定对象，形成共有知识 |
| **暗示引导** | 不直接说破，而是通过引导性提问让其他人自己发现 |
| **交易要挟** | 私下找到伪装者，要求某种交换条件才保密 |

### 2. 玩家参与者知情人

玩家通过自己的推理或观察发现他人伪装时，拥有完全的行动自由。

**为保护整体体验，系统提供以下引导：**

| 引导机制 | 说明 |
| :--- | :--- |
| **证据链提示** | 当玩家推理接近真相时，系统（通过L3视觉增强）可能会浮现某些线索图片，帮助玩家整理逻辑，但不直接给出结论 |
| **伪装的“合理怀疑”边界** | 系统确保即使玩家完全猜中真相，也必须通过搜证或NPC证词来“实证化”。没有实证的指控在投票环节说服力有限 |
| **反伪装策略空间** | 伪装者同样有销毁证据、收买NPC的空间，这让知情玩家面临“我现在揭发会不会被反杀”的博弈 |

---

## 四、叙事导演的全局平衡调控

叙事导演监控所有知情人和伪装之间的动态，确保体验不过快或过慢。

### 1. 知情传播速度控制

| 问题 | 调控手段 |
| :--- | :--- |
| 知情传播过快（伪装刚开局就崩） | 导演让某些关键知情人恰好因故缺席公开讨论，或让知情NPC先找伪装者私下对峙而非公开揭发 |
| 知情传播过慢（全桌无人察觉伪装） | 导演向某个可能知情的NPC发送“冲动”，使其更主动地接触其他参与者；或通过环境催化让新线索浮现 |

### 2. 伪装者与知情人的动态平衡

| 态势 | 导演干预 |
| :--- | :--- |
| 伪装者被多个知情人围剿，毫无反抗之力 | 导演减少新知情人的生成，给伪装者销毁证据或干扰调查的机会窗口 |
| 伪装者通过灭口/销毁消灭了所有知情路径，即将完美逃脱 | 导演创造一个新的动态知情人（符合逻辑的），或让某个已被“处理”的知情人留下遗言/日记 |

### 3. 保护体验的底线

| 保护对象 | 底线 |
| :--- | :--- |
| 伪装者 | 不能在游戏早期（如前10分钟）就被完全揭穿，必须至少有一次反击或逃脱的机会 |
| 好人方 | 即使伪装者极其高明，在游戏后期（投票前）必须至少有一条可操作的真实线索存在 |
| 所有玩家 | 任何伪装揭露都必须有**物理证据或可信NPC证词**支撑，不能仅靠“我猜的”来定罪 |

## 五、伪装者的知情管理策略

伪装者面对知情人时，不是被动等死，而是有多种策略可选。

| 策略 | 操作 | 风险/收益 |
| :--- | :--- | :--- |
| **收买** | 找到知情人，用金钱、利益交换让对方沉默 | 对方可能假装同意，或事后反水 |
| **威胁** | 找到知情人的弱点，逼迫其沉默 | 可能触发知情人的恐惧，使其向更信任的人求助 |
| **博取同情** | 向知情人坦白部分真相，解释自己的苦衷 | 高共情者可能被打动；低共情者会利用此信息 |
| **抢先制造另一个嫌疑人** | 将线索引向他人，让知情人的信息指向别人 | 需要高超的逻辑编织力 |
| **灭口** | 直接让知情人“消失” | 可能触发新案件，吸引更多调查；灭口失败直接暴露 |
| **销毁证据** | 在知情人揭露前，将关键道具销毁 | 如我们之前所述，销毁难度极高，且可能被目击 |

---

## 六、总结

Paralls的知情人机制，核心是**信息不对称的精细调控**，而非单方面的揭露或保护。

- **NPC知情人**：知情不完整、不主动，可被影响，由导演动态管理
- **参与者知情人**：行为由其人格或自由意志决定，系统仅提供推理辅助
- **叙事导演**：控制传播速度，确保每局都有悬念，不会过早暴露也不会无解
- **伪装者**：拥有丰富的反制策略，知情人的存在不是终结，而是新博弈的开始

这套机制确保：知情人是伪装博弈的精彩变量，而非破坏平衡的定论。每个参与者都在“我知道什么、别人知道什么、我能做什么”的复杂网络中，做出属于自己的选择。
