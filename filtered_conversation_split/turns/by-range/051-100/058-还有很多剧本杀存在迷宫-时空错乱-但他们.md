## 用户

还有很多剧本杀存在迷宫，时空错乱，但他们都是通过文字描述和既定的剧本故事线来实现的，我们可以怎么设计？

## DeepSeek

传统的文字式迷宫和时空错乱，依赖于玩家手动记笔记和DM口述来维持信息差。但在Paralls的3D沉浸式世界里，我们可以把这些概念从“文字描述”升级为**可交互的空间机制**和**可被系统执行的时间规则**。

这不再是让玩家去“读”一个迷宫，而是让他们“身处”一个由系统驱动的、逻辑严密的时空谜题之中。

---

### 🗺️ 一、迷宫机制：空间的不确定性

Paralls的迷宫不一定是物理上的墙，而是通过**空间连接的重映射**和**感知的欺骗**来制造混乱。

#### 1. 空间重映射

**核心概念**：同一个3D场景在服务器端有多个不同的“拓扑地图”。玩家的物理位置不变，但他们感受到的空间连接关系被动态改变。

**实现方式**：

| 手法 | 说明 | 体验案例 |
| :--- | :--- | :--- |
| **旋转房间** | 场景中的某个区域，当玩家独自进入后，他身后的门会连接到另一个房间。但他视觉上察觉不到任何变化（因为门都一样），只有当他试图原路返回时，才会发现进入了错误的地方。 | 玩家A进入“书房”，穿过房间去开对面的门，却发现自己回到了“大厅”。此时，玩家B从原来的门进入书房，发现A“凭空消失”了。 |
| **镜像场景** | 两个完全相同的房间，通过隐藏的通道连接。 | 玩家A在“左侧客房”搜查，玩家B在“右侧客房”。他们以为自己在不同房间，但通过脚步声和语音的模糊感知，又隐约觉得对方就在自己附近，营造出一种诡异的“似曾相识感”。 |
| **活点地图** | 玩家持有的地图会动态变化，只有满足特定条件（如多人同时观察、特定时间）时，地图才会显示真实的通路。 | 玩家们各自手持地图残片，必须聚在一起才能拼凑出正确的路径，迫使他们在迷宫中分散和集合。 |

#### 2. 感知欺骗

利用我们的空间音频和视觉系统，制造信息差。

| 手法 | 说明 | 体验案例 |
| :--- | :--- | :--- |
| **声音陷阱** | 利用空间音频模拟声音来源。在迷宫中，玩家听到的脚步声、呼救声可能来自完全错误的方向，引导他们走向死路或陷阱。 | 玩家C听到隔壁传来玩家D的耳语，以为他在墙那边，于是绕路去找，结果发现那只是系统播放的录音，真正的D在另一头。 |
| **视觉欺骗** | 利用镜面、透明屏、全息投影（视世界观而定）制造虚假的通道或遮挡真实的门。 | 一个看似是死路的镜子，在特定光线下（如闪电）会映出背后的通道，需要玩家互动解开。 |
| **NPC误导** | 一个因恐惧或人格影响而迷路的NPC，会给出错误的方向指引，但他们自己坚信不疑。 | 玩家遇到一个惊慌失措的管家，他指着一个方向说“怪物在那边！”，实际上那边是悬崖。玩家是否选择相信？ |

#### 3. 动态调控：迷宫守护者

叙事导演智能体可以扮演“迷宫守护者”的角色。

-   **职责**：实时监控玩家在迷宫中的位置、压力和推理进度。
-   **干预**：
    -   **引导**：当玩家团队完全迷失方向时，导演可能让某个NPC恰好出现在正确路线的分岔口，或让墙上出现微弱的标记（暗示“有人来过”）。
    -   **施压**：当玩家进度过快时，导演可以动态改变空间连接（如让一扇本该打开的门锁死），引导他们探索新的区域，或触发新的幻觉事件，增加紧张感。

### ⏳ 二、时空错乱机制：时间的非线性体验

这比迷宫更复杂。Paralls可以构建一个**多重时间线**或**时间循环**的剧本，并由系统强制执行其规则。

#### 1. 基础规则架构：多重时间线

**概念**：剧本设定存在A、B两个（或多个）平行时间线，因某个事件（如谋杀）纠缠在一起。部分角色可能来自时间线B。

**角色设定**：

-   **时间标签**：每个角色在开本时，真实档案里会有一个隐藏的“时间线标签”（如 `A` 或 `B`）。
-   **双重记忆**：来自时间线`B`的角色，拥有**两套开本前记忆**：一套是他自己时间线的记忆，另一套是当前时间线`A`的“历史”。他会发现现实与他的一些记忆不符。
-   **分歧点**：所有人必须找出导致时间线分裂的“分歧事件”是什么。

**机制体验**：

-   **搜证**：同一个场景的同一件物品，来自不同时间线的玩家会看到不同的内容。玩家A看到桌上有一封“遗书”，而玩家B看到的则是“情书”。这是颠覆性的信息差。
-   **对话**：当两个玩家发现对同一件事的记忆截然不同时，会产生强烈的戏剧冲突。他们需要推理出不是“谁在撒谎”，而是“我们来自不同的现实”。
-   **破局**：玩家需要通过比对彼此对历史的记忆，找出分歧点，并做出选择来修复时间线，或选择更偏爱的那个现实。

#### 2. 基础规则架构：时间循环

**概念**：剧本设定整个游戏流程为一个时间循环，在特定条件（如谋杀发生）下会重置。所有参与者保留部分或模糊的记忆。

**机制体验**：

-   **开局即二周目**：游戏开始时，所有AI和玩家角色都被告知一件事：“你有一种强烈的既视感，仿佛今天已经经历过。”这意味着所有人都背负着“上次循环”的碎片记忆。
-   **记忆碎片系统**：系统为每个角色预生成一套“上周目关键记忆”。这些记忆以碎片形式存在，通常是模糊的印象，比如“你对这个人有莫名的恐惧”或“你记得灯下有一滩血”。在搜证或对话中，这些碎片可以被触发和确认。
-   **循环规则**：当游戏中的关键谋杀或死亡事件发生后，经过固定时间，世界会“重置”。所有角色的物理位置回到起点，但：
    -   **保留物证**：少数被藏起来的物品不会重置，依然存在。
    -   **保留记忆**：参与者保留本循环的所有记忆。
    -   **保留死亡**：在上个循环死亡的角色，在新循环开场就处于“失踪”或“已死亡”状态，无法再被扮演。
-   **破局**：玩家必须利用“保留的物证”和“累积的记忆”，找到阻止谋杀再次发生的方法，才能打破循环。

#### 3. 系统的核心支持：感知与记忆控制

要实现这些，Paralls的系统需要提供以下核心功能：

| 功能 | 说明 |
| :--- | :--- |
| **视界过滤器** | 服务器根据玩家的角色标签（如“时间线A”），渲染不同的物品状态。这是实现“同一物品，不同人看到不同内容”的基础。 |
| **记忆注入** | 叙事导演智能体可以在特定时间，向特定角色的记忆库中注入“闪回”或“既视感”信息。这些信息可以是真实线索，也可以是干扰项。 |
| **世界状态回滚** | 时间循环中，系统自动记录并回滚所有非保留物品的位置和状态，但可以保留特定的“锚点物品”。 |
| **逻辑一致性检查** | AI实时检查玩家的推理，当玩家将A时间线的动机与B时间线的证据联系起来时，AI可以标记为“逻辑矛盾”，并在他们后续搜证时提供微妙的提示，引导他们发现真相。 |

---

### 💎 总结

在Paralls里，迷宫和时空错乱不再是需要玩家脑补的文字设定，而是**可被系统实现的游戏机制**。它们通过3D空间重映射、玩家视界过滤器、记忆注入等技术，创造了无与伦比的信息差和沉浸感。

这比任何现有的剧本杀形式都更接近电影级的时空叙事体验，也正是Paralls追求的那种“无限涌现”的平行世界。
