## 用户

机关呢？剧本杀都很多类型，很多特殊机制和推理悬疑设定，你来盘点。

## DeepSeek

在Paralls的3D世界里，机关和特殊机制不再是文字描述，而是**看得见、摸得着、可被系统强制执行和推理**的游戏玩法。

这些机制可以被归纳为几个大类：

---

### ⚙️ 一、物理与机械机关

这些是传统的“动手”机关，但在Paralls中它们变成了场景里的真实交互。

#### 1. 空间类机关

| 机关类型 | 实现方式 | 体验案例 |
| :--- | :--- | :--- |
| **密门/暗道** | 场景中存在玩家视觉上无缝融入墙体的隐藏门。触发方式可以是按动特定的书、旋转烛台、或同时按下两个开关。 | 玩家A和玩家B必须根据古籍线索，在书房的钟楼敲响午夜钟声的同时，站在特定地砖上，才能打开通往地下室的密道。 |
| **旋转/滑动墙壁** | 整个房间或走廊的墙壁可以程序化地移动。 | 触发机关后，书房的整面书架墙180度旋转，将原本在书架前交谈的玩家A卷入背后的密室，而外侧的玩家B只看到一面空墙。 |
| **活板门** | 地板上存在陷阱门，踩中会掉落到下层。 | 在走廊追逐时，凶手触发机关，让追逐者掉入地下酒窖，摔伤并暂时被困。 |

#### 2. 机械与物件类机关

| 机关类型 | 实现方式 | 体验案例 |
| :--- | :--- | :--- |
| **锁与钥匙谜题** | 复杂的多级锁，需要特定的钥匙、密码或序列。密码可以散落在不同玩家的线索中。 | 一个宝箱需要三位不同角色的家族戒指同时插入才能打开，迫使他们必须协商或偷窃。 |
| **隐藏的武器机关** | 伪装成日常用品的杀人武器。 | 一把看似普通的雨伞，按下机关后会弹出毒针；一个音乐盒，发条上满后会在特定时间发射子弹。 |
| **环境陷阱** | 利用环境元素制造的陷阱。 | 松动的栏杆、涂了毒药的酒杯、被做了手脚的吊灯（可被人为触发坠落）。 |

#### 3. 感官类机关

利用我们的空间音频和视觉特效来制造迷幻感。

| 机关类型 | 实现方式 | 体验案例 |
| :--- | :--- | :--- |
| **声音陷阱** | 利用空间音频在特定位置播放录音、模拟异响或混淆方位。 | 玩家在迷宫中被远处的“救命”声吸引，跑到声源处却发现是墙上的一个发声装置，而真正的求救者在相反方向。 |
| **视觉幻觉** | 利用镜面、光影、烟雾制造视觉错误。 | 布满镜子的房间，玩家在里面看到多个自己的倒影，难以分辨哪个是真人，哪个是镜子，隐藏的门就在镜子的反射盲区中。 |
| **致幻毒气** | 场景中可以填充“毒气”（视觉特效），影响玩家的屏幕视野（如扭曲、色偏）和听觉，制造混乱，但不能控制其行动。 | 凶手在地下室释放了致幻气体，所有进入的玩家视野开始扭曲，听到了不存在的低语，彼此间的信任降到冰点。 |

---

### 🧠 二、剧情与逻辑机制

这些是“核诡”和“设定”，直接作用于玩家的推理。

#### 1. 身份与关系诡计

| 机制类型 | 设计原理 | Paralls实现 |
| :--- | :--- | :--- |
| **叙述性诡计** | 通过文本或旁白误导玩家对身份、时间、地点的认知。 | 系统通过对某个玩家隐藏关键档案、发送误导性的任务提示或回忆闪回，使其从内心建立错误的认知。 |
| **身份核诡** | 有人冒充、顶替了某人；或一人分饰多角。 | 这完全符合我们的**伪装系统**。玩家A的“真实档案”里可能写着“你其实是死者的私生子，冒用了现在这个身份”。这需要依赖伪装道具和知情人机制来维持。 |
| **血缘/宿命关系** | 角色之间存在隐藏的血缘关系或前世宿命。 | 开本前，由**人生记忆模拟系统**为两个角色生成一段共同的、但双方都不知道的过去。在游戏中，通过搜证（如发现信物）或AI角色回忆来揭示。 |

#### 2. 不在场证明与犯罪手法诡计

| 机制类型 | 设计原理 | Paralls实现 |
| :--- | :--- | :--- |
| **时间诡计** | 改变时钟、混淆案发时间。 | 凶手打碎了一个花瓶，把钟拨慢了一小时，然后离开。系统会记录花瓶的破碎时间和真实的游戏世界时间。侦探可以调查“打碎的花瓶”这个物证，发现其状态异常，进而推理出时间被篡改。 |
| **不可能犯罪** | 密室杀人、足迹消失。 | 这正是**迷宫和时空错乱机制**的用武之地。利用密道、旋转墙来制造“密室”；利用“两个相同的房间”让凶手瞬间“消失”。 |
| **远程/延时机关** | 凶手不在现场时，通过机关杀人。 | 凶手将一块肉放在一触即发的弩箭机关前，算准时间，当饿犬进入房间吃肉时触发弩箭，射杀死者。系统计算凶器轨迹、冰块融化时间，玩家可以反向推理出机关原理。 |

### 🌌 三、高级叙事架构机制

这些是Paralls作为3D智能体平台所独有的“超能力”，传统剧本杀难以实现。

#### 1. 视角与感知类机制

| 机制类型 | 实现方式 | 体验案例 |
| :--- | :--- | :--- |
| **视界过滤** | 不同角色看到的世界不同。 | 在“多重时间线”剧本中，玩家A看到的是案发前的现场，玩家B看到的是案发后的现场。他们必须通过对话来拼凑出时间线。 |
| **记忆闪回** | 系统主动向特定玩家播放3D场景动画或图片。 | 玩家A走到花园的井边时，系统突然让他“闪回”到儿时在此溺水的记忆（AI生成的短视频）。这是他个人独有的线索。 |
| **角色能力** | 某些角色有特殊能力，如“开锁”、“验尸”、“精神分析”。 | 扮演医生的玩家，可以进入一个特殊的“验尸”互动界面，通过系统生成的3D尸体模型和线索，推断死因和凶器。 |

#### 2. 玩家对抗与博弈机制

| 机制类型 | 实现方式 | 体验案例 |
| :--- | :--- | :--- |
| **明凶/盲凶** | 凶手自己知道/不知道自己是凶手。 | **盲凶本**：系统不告诉凶手玩家他是凶手，他只觉得自己有嫌疑。当他搜证时，会逐渐发现指向自己的证据，从内心产生恐惧和挣扎。 |
| **动态阵营** | 玩家的阵营和目标在游戏中会因行为而改变。 | 一个玩家初始是好人，但当他被凶手抓住把柄或受到巨大利益诱惑时，系统会给他一个新任务：“帮凶手隐瞒真相，你将获得额外奖励”。他是否选择叛变？ |
| **PvPvE** | 玩家之间对抗，同时还要对抗环境/系统。 | 在密室中，玩家们不仅要找出谁偷了宝石，还要协作解开谜题，否则整个房间会在30分钟内被水灌满。 |

---

### 🔧 四、系统支持与动态调控

这些机制不是独立的剧本设定，而是要求系统提供底层的、可配置的功能。

| 系统功能 | 支持机制 | 说明 |
| :--- | :--- | :--- |
| **状态管理系统** | 中毒、醉酒、PTSD、幻觉、**多重人格**、魅惑、**狼人化** | 角色可以拥有状态，这些状态会影响他们的感知、行为甚至胜利条件。 |
| **触发器系统** | 所有机关类机制 | 创作者在编辑器中放置“触发器”（如按钮、感应区），并设置触发条件（如同时站人、持有物品）和结果（开门、播放声音）。 |
| **视界管理** | 视角类诡计、多重时间线 | 系统根据角色标签和进度，决定该玩家能看到哪些物体、收到哪些信息。 |
| **记忆库API** | 记忆闪回、记忆篡改 | 叙事导演可以调用API，向特定角色的记忆库里安全地插入或修改一条“开本前记忆”或“上周目记忆”。 |

---

### 💎 总结：可配置的机制库

Paralls的剧本编辑器，最终应提供一个**可配置的机制库**，创作者可以像搭积木一样，为他们的剧本勾选和组合这些悬疑设定：

| 机制类别 | 具体选项 |
| :--- | :--- |
| **空间** | 密室、迷宫、暗道、密室、旋转墙、镜像房间 |
| **时间** | 时间循环、多重时间线、时间诡计（钟表、定时装置） |
| **身份** | 伪装、叙述性诡计、身份顶替、双重记忆 |
| **物理** | 机械锁、延时机关、毒气、陷阱、隐藏武器 |
| **感官** | 声音陷阱、视觉幻觉、记忆闪回 |
| **博弈** | 盲凶、动态阵营、PvPvE、角色能力 |

这些机制通过Paralls的3D引擎、AI智能体和事件总线协同工作，将传统剧本杀停留在纸上的精彩设定，变成了可交互、可推理、可涌现的沉浸式体验。
