## 我们的基础设施，本质上是“角色驱动”

我们已经构建的核心模块：

| 模块 | 已实现 | 对战斗/养成的天然支持 |
| :--- | :--- | :--- |
| **人生记忆** | 基因种子→模拟人生→生成性格和技能 | 技能等级、战斗经验、训练背景——这些已经在人生记忆里了 |
| **人格档案** | 品格层+行为层+动态状态 | 战斗风格（激进/保守）、士气、恐惧反应——这些都是人格的延伸 |
| **状态系统** | 压力值、情绪标签、中毒、PTSD | 体力值、受伤状态、Buff/Debuff——结构完全一致 |
| **能力等级** | 暗杀L0-L4，痕迹控制 | 战斗L0-L4、潜行、医术、开锁——同样的等级体系，扩展即可 |
| **场景系统** | 3D空间、可交互物品、机关 | 地形优势、掩体、陷阱——场景已经可以被交互，只是交互方式需要扩展 |
| **事件总线** | 所有行为都被记录和广播 | 战斗事件（攻击、受伤、击杀）天然就是事件总线上的消息 |
| **叙事导演** | 动态调控平衡、管理叙事节奏 | 战斗难度调控、Boss行为管理、剧情战斗的叙事编排 |

**核心洞察：我们一直在构建的，不是“剧本杀引擎”，而是一个“角色在3D世界中自主行动”的通用框架。** 剧本杀只是这个框架上运行的第一个玩法。

---

## 接入战斗系统：需要增加什么

在现有基础上，增加战斗系统主要需要以下模块：

### 1. 战斗技能树（从人生记忆中提取）

我们已有的暗杀能力等级体系，可以直接扩展为通用战斗技能：

| 技能维度 | 来源 | 说明 |
| :--- | :--- | :--- |
| **近战能力** | 军事训练、武术修行、街头斗殴经验 | 从人生记忆中的相关事件提取 |
| **远程能力** | 狩猎、射箭训练、现代射击训练 | 同上 |
| **潜行能力** | 间谍训练、盗贼经验 | 暗杀能力可直接映射 |
| **防御/闪避** | 军阵训练、敏捷天赋、实战经验 | 从人生记忆和胆量/理性参数推导 |
| **特殊技能** | 法术（变格本）、机关术、毒术 | 由基因种子中的天赋和特殊经历决定 |

### 2. 战斗决策模式（从人格档案中提取）

战斗不是“最优解计算”，而是**人格的延伸**。这是我们的核心优势。

| 人格维度 | 战斗风格 |
| :--- | :--- |
| **高胆量+低理性** | 鲁莽冲锋，不顾伤亡 |
| **高胆量+高理性** | 冷静判断，伺机而动 |
| **低胆量** | 优先自保，倾向撤退或远程攻击 |
| **高心机** | 佯攻、设陷阱、偷袭 |
| **高共情** | 可能不忍痛下杀手，优先制服而非击杀 |
| **高忠诚度（对某人）** | 会为保护忠诚对象而舍身 |

**这不是预设的AI行为树，而是从人格参数实时涌现的战斗风格。** 每次战斗都因参与者的性格而不同。

### 3. 战斗与叙事的融合（叙事导演的扩展职责）

叙事导演在战斗中的作用，不是当裁判算伤害，而是**管理战斗的戏剧性**：

| 导演职责 | 说明 |
| :--- | :--- |
| **难度调控** | 如果战斗对玩家方过于碾压，导演可通过环境事件（如“突然的余震让Boss失去平衡”）创造反转机会 |
| **剧情战斗** | 关键战斗不是纯数值对决，而是有叙事条件的（如“必须先破解机关才能伤到Boss”） |
| **后果管理** | 战斗不是终点。死亡、受伤、武器损坏——这些后果成为新的叙事素材 |

## 接入养成系统：需要增加什么

养成系统的核心是**角色的成长可以被系统化记录和呈现**。我们的基础设施已经为此打下了基础。

### 1. 技能成长体系

| 成长方式 | 实现 |
| :--- | :--- |
| **使用成长** | 使用某项技能越多，熟练度越高。事件总线记录所有技能使用，自动累积经验 |
| **学习成长** | 找到“武功秘籍”、“导师NPC”，通过学习事件解锁新技能或提升等级 |
| **突破成长** | 特定事件触发——如濒死体验、重大情感冲击——解锁隐藏能力或跨越等级上限 |

### 2. 装备与道具系统

我们已有的物品系统（线索、伪装道具、凶器）可以直接扩展：

| 装备类型 | 影响 |
| :--- | :--- |
| **武器** | 攻击力、攻击方式、特殊效果 |
| **防具** | 防御力、特殊抗性 |
| **饰品/法宝** | 人格参数临时修正、状态免疫、特殊技能 |
| **消耗品** | 药品（恢复、解毒）、投掷物、卷轴 |

**关键设计原则：装备不能覆盖人格。** 一把神剑可以让一个胆量3的人变胆量8吗？不能。它应该增强已有的能力，而非改写人格本身。

### 3. 角色关系养成

这是我们已经有的东西——信任值、怀疑值、忠诚度。养成系统只是让这些关系的变化更具可操作性：

| 养成行为 | 影响 |
| :--- | :--- |
| **送礼/帮助** | 目标对行动者的信任值上升 |
| **并肩战斗** | 双方信任值大幅上升，可能解锁“羁绊技能” |
| **背叛/欺骗** | 信任值骤降，可能触发特殊剧情（复仇、决裂） |

## 接入后的多品类扩展

有了战斗和养成，Paralls可以承载的游戏类型大幅扩展：

| 游戏类型 | 在现有基础上叠加什么 |
| :--- | :--- |
| **生存推理** | 剧本杀+战斗（有限资源、可被杀、可反击） |
| **江湖角色扮演** | 剧本杀+养成+战斗（长期角色成长、门派系统、多人江湖世界） |
| **密室逃脱合作** | 机关系统+养成（角色有不同特长，需合作破解） |
| **Roguelike探索** | 迷宫机制+战斗+随机生成（每次进入地图不同，角色可能死亡） |
| **策略战棋** | 战斗+阵营机制（多角色同时指挥，棋盘式战斗） |

---

## 总结

我们之前说“暂不做打斗”，是**聚焦**，不是**限制**。

Paralls的基础设施——人格驱动的决策、人生记忆塑造的能力、事件总线记录的一切、叙事导演管理的戏剧张力——这些不是为剧本杀定制的，而是为**“角色在3D世界中真实地活着”**而设计的。

当未来我们决定接入战斗和养成时，它们会无缝地融入这套体系，而不是作为一个割裂的“战斗模块”被硬塞进来。角色在战斗中表现出的风格、在养成中建立的羁绊，都会成为叙事的一部分，被记忆系统记录，被知识图谱追踪，被叙事导演催化。

这正是Paralls作为平台的真正潜力——它不止是一个剧本杀工具，而是一个**角色驱动的叙事世界引擎**。
