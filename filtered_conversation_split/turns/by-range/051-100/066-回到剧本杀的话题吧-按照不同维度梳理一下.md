## 一、世界观与时代维度

这是剧本的“地基”，决定了所有后续设计的基本规则。

### 1.1 时代背景

| 配置项 | 说明 | 例子 |
| :--- | :--- | :--- |
| **时代** | 具体的历史时期或架空时代 | 维多利亚时代、南宋、近未来赛博朋克 |
| **地域** | 故事发生的地理位置和文化背景 | 伦敦东区、临安城、太空殖民地 |
| **科技水平** | 可用工具和技术的上限 | 蒸汽机时代（有火车但无电话）、信息时代（有手机和监控） |
| **社会规则** | 当时的法律、阶级、道德规范 | 贵族特权、男女有别、教会权力 |

### 1.2 特殊世界规则

| 配置项 | 说明 | 例子 |
| :--- | :--- | :--- |
| **超自然设定** | 是否存在魔法、妖怪、超能力 | 《白蛇传》中有法术和妖力 |
| **特殊物理规则** | 是否有时空异常、异空间 | 时间循环、迷宫、镜像世界 |
| **世界观秘密** | 整个世界的隐藏真相，可能贯穿多个剧本 | “无限书海”本身就是跨维度空间 |

### 1.3 剧本在“无限书海”中的位置

| 配置项 | 说明 |
| :--- | :--- |
| **书页编号** | 该剧本在无限书海中的唯一标识 |
| **与其他书页的关系** | 是否与官方其他剧本共享世界观、角色可跨剧本出现 |
| **是否为系列作品** | 是否有续集、前传、外传 |

## 二、角色维度

这是剧本的“灵魂”，所有角色——无论玩家还是AI——都在此定义。

### 2.1 角色基础信息

| 配置项 | 说明 |
| :--- | :--- |
| **姓名/化名** | 角色的公开姓名和真实姓名（如伪装） |
| **身份/职业** | 公开身份和真实身份 |
| **外貌描述** | 年龄、身高、发色、特征 |
| **3D模型绑定** | 关联的角色模型资产 |

### 2.2 角色人格档案

| 层级 | 配置项 | 说明 |
| :--- | :--- | :--- |
| **根基层** | 基因种子 | 出身、天赋、早年关键事件 |
| **根基层** | 人生记忆 | 由基因种子模拟生成，记录性格形成的关键事件 |
| **品格层** | 道德取向 | 诚实、忠诚、正义感、仁慈、责任感（各0-10） |
| **品格层** | 价值优先级 | 当道德冲突时，哪个价值最高 |
| **品格层** | 自我认知 | 如何看待自己，理想自我，核心创伤，执念 |
| **行为层** | 五维人格 | 胆量、心机、共情、理性、社交（各0-10） |
| **行为层** | 语言风格 | 称谓习惯、句式特征、话题偏好、撒谎特征 |

### 2.3 角色在剧本中的定位

| 配置项 | 说明 |
| :--- | :--- |
| **扮演类型** | 真人玩家 / AI智能体 / 二者可选 |
| **初始阵营** | 好人方 / 凶手方 / 中立 |
| **核心秘密** | 必须隐藏的真相 |
| **目标层级** | 按优先级排序的角色目标 |
| **恐惧层级** | 按强度排序的角色恐惧 |
| **忠诚度地图** | 对每个其他角色的忠诚度（-10到10） |

### 2.4 角色能力

| 配置项 | 说明 |
| :--- | :--- |
| **暗杀能力** | L0-L4，决定可用的暗杀方式和痕迹控制 |
| **特殊技能** | 开锁、医术、验尸、法术、话术等 |
| **知识领域** | 角色擅长或了解的领域（可影响搜证效率或推论准确度） |

### 2.5 伪装配置

| 配置项 | 说明 |
| :--- | :--- |
| **伪装深度** | 零伪装 / 浅层 / 中度 / 深度 |
| **公开档案** | 对外展示的身份信息 |
| **真实档案** | 仅自己可见的真实身份 |
| **伪装道具清单** | 维持伪装所需的物理道具及其初始位置 |
| **固定知情人** | 预设知道伪装秘密的NPC（最多2-3人） |

## 三、案件与叙事维度

这是剧本的“引擎”，决定了故事的动态生成方式。

### 3.1 固定历史（开本前已锁定）

| 配置项 | 说明 |
| :--- | :--- |
| **死者信息** | 姓名、身份、与各角色关系 |
| **案发前事件** | 开本前24-48小时内，各角色的行踪和行为 |
| **固定人际关系** | 角色之间早已存在的恩怨、秘密协议 |
| **世界状态** | 天气、道路状况、特殊事件（如暴风雨封路） |

### 3.2 案件生成规则池

| 配置项 | 说明 |
| :--- | :--- |
| **死因池** | 可选死因列表（中毒、窒息、刀伤等） |
| **动机池** | 可选动机列表（灭口、劫财、复仇等） |
| **凶器池** | 可成为凶器的物品列表 |
| **作案条件** | 凶手必须满足的客观条件（如身高≤死者、无不在场证明） |
| **不在场证明配置** | 每个角色在案发时的位置和行为，以及可作证的人 |

### 3.3 线索系统

| 配置项 | 说明 |
| :--- | :--- |
| **线索池** | 20-30条线索，分为核心线索（必出现）和干扰线索（随机） |
| **线索类型** | 物证、人证、环境痕迹、时间线矛盾 |
| **线索分布** | 每条线索的初始位置（场景+具体物品） |
| **线索关联** | 每条线索指向哪个动机、凶器或嫌疑人 |

### 3.4 结局条件

| 配置项 | 说明 |
| :--- | :--- |
| **正义伸张** | 触发条件（真凶被投票+关键证据公开） |
| **真凶逃脱** | 触发条件（投票错误+关键证据未被发现） |
| **冤案** | 触发条件（无辜者被投票定罪） |
| **隐藏结局** | 触发条件（特定条件组合，如发现世界观秘密） |

---

## 四、场景与空间维度

这是剧本的“舞台”，决定了玩家能在哪里做什么。

### 4.1 场景基础

| 配置项 | 说明 |
| :--- | :--- |
| **场景列表** | 所有可进入的场景名称和描述 |
| **场景连接** | 场景之间的连接关系（门、走廊、楼梯、密道） |
| **场景资产** | 关联的3D场景模型 |

### 4.2 集体机制

| 配置项 | 说明 |
| :--- | :--- |
| **集体用餐** | 是否启用、时间、地点、缺席后果 |
| **集体住宿** | 是否启用、房间分配、隔音规则、钥匙管理 |
| **集体活动** | 其他强制或半强制的集体时刻（下午茶、教堂礼拜） |

### 4.3 可交互物品

| 配置项 | 说明 |
| :--- | :--- |
| **普通物品** | 可拾取、查看的场景物品 |
| **线索物品** | 关联线索的物品 |
| **伪装道具** | 维持伪装所需的物品 |
| **凶器候选** | 可能成为凶器的物品 |
| **机关物品** | 可触发的机关（开关、暗门、陷阱） |

### 4.4 特殊空间机制

| 配置项 | 说明 |
| :--- | :--- |
| **迷宫规则** | 是否启用空间重映射、旋转房间、镜像场景 |
| **密道/密室** | 隐藏通道的入口、出口、触发方式 |
| **感知欺骗** | 声音陷阱、视觉幻觉、镜面干扰 |

---

## 五、规则与机制维度

这是剧本的“操作系统”，定义了游戏怎么玩。

### 5.1 基础规则

| 配置项 | 说明 |
| :--- | :--- |
| **玩家数量** | 总角色数、最少/最多真人玩家数 |
| **游戏时长** | 预计总时长、各阶段时长 |
| **阶段划分** | 自由探索→讨论→投票→结局（可自定义） |
| **投票规则** | 匿名/公开、权重、平票处理 |

### 5.2 特殊机制（可多选）

| 机制类型 | 说明 |
| :--- | :--- |
| **时间循环** | 启用后需配置循环次数、保留内容、打破条件 |
| **多重时间线** | 启用后需配置时间线数量、分歧事件、角色标签 |
| **迷宫** | 启用后需配置空间重映射规则 |
| **暗杀** | 启用后需配置可用暗杀方式、目击风险参数 |
| **伪装系统** | 启用后需配置伪装深度、道具要求 |
| **角色状态** | 中毒、致幻、醉酒、PTSD——影响感知和行为 |
| **角色能力** | 开锁、验尸、法术——特殊交互选项 |
| **动态阵营** | 游戏中阵营可改变，需配置触发条件和后果 |

### 5.3 信息规则

| 配置项 | 说明 |
| :--- | :--- |
| **信息共享方式** | 公开对话、耳语、展示物品、带人查看、留影石/相机 |
| **留影石/相机** | 是否启用、使用次数、是否可伪造 |
| **外貌伪装** | 是否启用、是否需要道具支撑 |

---

## 六、AI智能体与导演维度

这是剧本的“导演”，决定了动态叙事和智能体行为。

### 6.1 角色智能体配置

| 配置项 | 说明 |
| :--- | :--- |
| **自主程度** | AI角色主动行动的频率和积极性 |
| **伪装执行** | AI角色如何管理自己的伪装（保守/激进） |
| **知情人行为** | 作为知情人时，AI角色的揭露倾向 |
| **压力响应** | 高压力时AI角色的行为变化幅度 |

### 6.2 叙事导演配置

| 配置项 | 说明 |
| :--- | :--- |
| **干预强度** | 轻度（仅逻辑检查）/ 中度（平衡调控）/ 重度（主动催化冲突） |
| **节奏偏好** | 偏快（推动调查）/ 偏慢（给更多自由探索时间） |
| **新案件生成** | 是否允许游戏过程中涌现新案件 |
| **结局偏好** | 是否倾向某种结局类型（如偏向悲剧/喜剧） |

### 6.3 动态知情人配置

| 配置项 | 说明 |
| :--- | :--- |
| **目击概率** | NPC目击可疑行为的基准概率 |
| **信息传播速度** | 知情信息在NPC之间传播的速度 |
| **导演介入阈值** | 什么程度的失衡触发导演干预 |

---

## 七、体验与呈现维度

这是剧本的“包装”，决定了玩家感受到的氛围。

### 7.1 视觉风格

| 配置项 | 说明 |
| :--- | :--- |
| **美术风格** | 写实/油画/赛博朋克/水墨等 |
| **光影基调** | 明亮/昏暗/闪烁/冷暖色调 |
| **L3视觉增强** | 何时触发AI生成图片/视频（线索特写、回忆闪回、结局CG） |

### 7.2 音频风格

| 配置项 | 说明 |
| :--- | :--- |
| **环境音效** | 雨声、风声、壁炉噼啪、钟表滴答 |
| **背景音乐** | 各场景的氛围音乐 |
| **音效事件** | 雷声、尖叫、门吱呀、钟声 |

### 7.3 难度与标签

| 配置项 | 说明 |
| :--- | :--- |
| **推理难度** | 新手/进阶/烧脑 |
| **剧本标签** | 本格/变格/情感/阵营/恐怖/机制/欢乐/还原 |
| **推荐玩家类型** | 社交型/推理型/沉浸型/对抗型 |

│   └─ 在无限书海中的位置（书页编号/系列关系）

---

这七个维度构成了Paralls剧本编辑器的基础架构。创作者在编辑器中逐层配置，最终产出一份完整的、可被Paralls引擎驱动运行的剧本。这份剧本不是一个写死的故事，而是一个**定义了角色、规则和可能性的“叙事生成器”**——每一次开本，都是一次独一无二的平行世界。
