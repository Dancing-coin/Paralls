# 《雾隐庄园》剧本案例

## 一、世界观设定

| 设定项 | 内容 |
| :--- | :--- |
| **时代** | 1926年深秋，英国乡村 |
| **地点** | “雾隐庄园”，一座与世隔绝的私人庄园，现改为小型豪华酒店 |
| **特殊状态** | 连续三日的暴风雨导致山洪冲毁道路，所有人与外界隔绝至少48小时 |
| **设施布局** | 一楼：大厅、餐厅、书房、厨房。二楼：6间客房，走廊两侧各3间，共用一个楼梯。阁楼：储藏室。地下室：酒窖、锅炉房 |
| **集体用餐规则** | 每晚19:00准时在餐厅共进晚餐，由管家主持。早餐8:00。缺席者将引来所有人的询问 |
| **住宿规则** | 每位角色分配到二楼的一间固定客房。房间可上锁，但管家有备用钥匙 |

## 三、案件框架

### 初始案件（T1随机，T2锁定）

| 要素 | 内容 |
| :--- | :--- |
| **死者** | 埃莉诺·韦克菲尔德（在第二晚至第三日凌晨被发现死亡） |
| **死因池** | 中毒、窒息、利器刺伤（T1随机 → 本局：窒息） |
| **动机池** | 灭口、劫财、私人恩怨（T1随机 → 本局：灭口） |
| **凶手候选** | 所有L1+的AI角色（排除真人玩家埃莉诺） → 本局凶手锁定：霍普医生 |

**作案过程（T2锁定）**：
霍普医生无意中听到了埃莉诺与外界联络的对话片段，意识到她可能是间谍。他担心埃莉诺会调查格雷先生并发现他的战争秘密，决定在深夜下手。他利用医学知识，在埃莉诺的房间里用枕头使其窒息，并伪造了“心脏病发作”的假象。

## 四、暗杀任务指引

埃莉诺（玩家A）在游戏中有自己的秘密任务。如果她察觉到霍普医生正在威胁她的计划，她可能选择先下手为强。

### 埃莉诺的暗杀任务指引（开本时仅自己可见）

**你的暗杀能力**：L3。你可使用以下方式：
- **下毒**：需要获取毒药（你的行李中藏有一小瓶氰化物），投入目标的饮食中。饮食在集体用餐时最易接触。
- **无声暗杀**：需要独处窗口和利器（可从厨房获取刀具）。

**当前任务优先级**：
1. 保护自己的间谍身份不被揭穿
2. 找到上级接头人（你怀疑是史密斯先生或莫里斯）
3. 如果霍普医生成为威胁，可考虑暗杀

**系统提供的暗杀建议时机**：
- 集体用餐时，所有人的注意力集中在餐桌，厨房有一段无人时间——适合下毒
- 深夜12点后，走廊无人。如果你确认目标已回房间，可用备用钥匙（你已偷配）进入——适合无声暗杀

## 五、集体机制的设计

### 1. 集体用餐机制

| 规则 | 说明 |
| :--- | :--- |
| **时间** | 每晚19:00、早8:00，所有角色被召集到餐厅 |
| **缺席后果** | 若有人缺席，管家会前往其房间查看。如果房间无人或不应门，所有人会开始搜索 |
| **座位安排** | 每天由管家安排座位，相邻的人更容易私下交谈 |
| **用餐时长** | 约30-45分钟，期间厨房空无一人 |
| **上菜流程** | 管家或帮厨上菜。如果有人中途离席去“洗手间”，有5-10分钟的独处窗口 |

**游戏性价值**：
- 用餐是公共知识更新的集中时刻。所有公开对话在此发生
- 离席制造的独处窗口是暗杀或秘密行动的机会，但离席本身会被所有人注意到
- 餐后所有人一起回房间，这段时间是确认某人是否进入他人房间的观察窗口

### 2. 集体住宿机制

| 规则 | 说明 |
| :--- | :--- |
| **房间分配** | 二楼6间房。房间1-3在走廊左侧：格雷、莫里斯、史密斯。房间4-6在走廊右侧：埃莉诺、温斯顿、霍普 |
| **隔音效果** | 相邻房间可听到隐约声响，但对门房间完全听不到 |
| **门锁** | 每扇门可从内反锁。管家有备用钥匙，存放在一楼厨房的钥匙柜中。钥匙柜的每次开启会发出轻微的叮当声，一楼大厅可隐约听到 |
| **夜巡** | 管家在每晚23:00会巡视一次走廊，确认所有房门关闭。此时走廊有短暂目击风险 |
| **密道** | 格雷先生知道一条从自己房间通向书房壁炉后的密道。密道入口移动时会发出石墙摩擦的声音 |

**游戏性价值**：
- 深夜12点至凌晨6点是最长的独处窗口期，也是暗杀的主要时机
- 相邻房间的模糊听觉为目击/感知创造了可能性
- 备用钥匙的存放位置和声音线索，为钥匙被偷用提供可追踪的痕迹
- 密道的存在为不可能犯罪提供了解释空间

## 六、游戏流程示例

### 第一晚

| 时间 | 事件 | 玩家行动示例 |
| :--- | :--- | :--- |
| 19:00 | 集体晚餐。所有人初次见面。史密斯先生试探埃莉诺的身份。霍普医生沉默寡言 | 埃莉诺注意到史密斯对她的身份有异常兴趣；温斯顿试图亲近埃莉诺 |
| 20:00 | 餐后自由时间。众人在大厅喝白兰地 | 埃莉诺趁所有人不注意，短暂离开去了厨房，熟悉刀具位置 |
| 21:30 | 众人陆续回房间 | 霍普医生在走廊与埃莉诺擦肩而过，听到了她房间内隐约的“发报机声音” |
| 22:00 | 霍普医生以“拿一本书”为由进入书房，实际在壁炉后听到了更多埃莉诺与外界的联系片段 | 霍普医生的怀疑值大幅上升 |
| 23:00 | 管家夜巡 | - |
| 深夜 | 埃莉诺使用偷配的钥匙进入书房（假身份需求），但发现有人来过。她察觉到威胁 | 埃莉诺的压力值上升，系统提示“你感觉有人在暗中观察你” |

### 第二日

| 时间 | 事件 | 玩家行动示例 |
| :--- | :--- | :--- |
| 8:00 | 早餐。霍普医生试探性地问埃莉诺“昨晚睡得好吗”，语气异样 | 埃莉诺的高心机让她察觉到霍普的异常。她决定在午餐时下毒 |
| 10:00 | 自由探索。史密斯在书房发现了密道的移动痕迹（灰尘被擦过） | 史密斯将此记录为线索 |
| 12:00 | 午餐。埃莉诺以上洗手间为由短暂离席，潜入厨房，将氰化物放入为霍普准备的汤中。她返回时，温斯顿注意到她“去了有点久” | 温斯顿获得模糊感知，但对埃莉诺信任值仍高，暂时没有追问 |
| 12:30 | 用餐。霍普喝下毒汤 | 霍普在回房间后毒发身亡 |
| 13:00 | 管家发现霍普医生未出席下午茶，前去查看，发现其尸体 | 公共事件触发：所有人集合，史密斯开始调查 |

### 后续发展

| 事件 | 说明 |
| :--- | :--- |
| **调查开始** | 史密斯先生（侦探）开始询问所有人的不在场证明。埃莉诺需要解释午餐期间的离席 |
| **线索浮现** | 厨房丢失一把刀具（埃莉诺之前藏起的，但被莫里斯意外发现并放回）。密道痕迹被发现。霍普房间中有格雷先生战争时期的旧照片 |
| **嫌疑转移** | 格雷先生因为PTSD发作，在质问下无法清晰回忆自己的行踪，被部分人怀疑。莫里斯为了保护格雷，开始悄悄销毁某些证据 |
| **埃莉诺的伪装压力** | 温斯顿提到“埃莉诺午餐时离开比较久”，埃莉诺压力值上升。她需要编造更复杂的谎言 |
| **结局走向** | 如果埃莉诺被查出，她可能面临指认。如果她成功嫁祸给格雷或莫里斯，则可能逃脱。史密斯先生的侦探能力成为关键变量 |

## 七、本剧本的核心机制展示

| 机制 | 在剧本中的体现 |
| :--- | :--- |
| **角色状态** | 格雷的PTSD、霍普的负罪感、埃莉诺的间谍直觉——这些状态影响角色行为，创造不确定性 |
| **暗杀任务指引** | 埃莉诺获得系统提示：下毒时机在集体用餐、无声暗杀在深夜走廊。这些提示基于场景机制和角色状态生成 |
| **集体用餐** | 为下毒提供了可操作的独处窗口；离席行为可被观察到，成为后续推理的线索 |
| **集体住宿** | 相邻房间的隐约声响、管家的备用钥匙和夜巡、密道的存在——这些构成了暗杀的时间、空间和痕迹网络 |
| **伪装与知情人** | 埃莉诺的间谍身份是伪装核心。史密斯先生是逐渐接近真相的知情人。霍普成为知情人后被灭口 |
| **导演平衡干预** | 当埃莉诺的伪装因温斯顿的一句话而受到威胁时，导演通过让莫里斯主动销毁证据（出于保护格雷的动机）来间接分散调查方向，让天平不至于过早倾斜 |

---

这个剧本展示了Paralls的复杂本可以如何运转：集体机制为暗杀创造了条件，角色状态和任务指引为玩家提供策略方向，而所有行为的痕迹都被记录，成为后续社交推理的素材。暗杀不是孤立的行动，而是整个叙事生态中自然涌现的一环。
