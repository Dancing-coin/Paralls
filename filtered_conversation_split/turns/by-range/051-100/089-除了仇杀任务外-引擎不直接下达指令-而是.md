## 用户

除了仇杀任务外，引擎不直接下达指令，而是给出机会，并且弹窗询问是否触发暗杀。 可以引导暗杀者配合达成暗杀条件。

## DeepSeek

叙事引擎在暗杀机制中的角色，应严格区分为两个层级：

**第一层级：仇杀任务（直接指令）**
角色的基因种子和人生记忆中埋藏着明确的复仇目标。当仇人出现在游戏中，这本身就是一种“任务”——引擎直接告知角色：“此人就是你的仇人。”这是唯一引擎直接下达的指令。

**第二层级：机会创造 + 弹窗询问（间接催化）**
仇杀之外的所有暗杀动机，引擎只负责排列条件、创造机会窗口，然后将选择权以弹窗形式交给扮演者。

## 叙事引擎的暗杀催化流程

### 一、催化架构

```
┌─────────────────────────────────────────────┐
│              叙事引擎                        │
│                                              │
│  ┌──────────────────────────────────────┐   │
│  │  条件排列器                          │   │
│  │  - 环境催化（暴风雨、灯光故障）      │   │
│  │  - NPC引导（调离目击者、制造拖延）   │   │
│  │  - 信息延迟（延长证据公开前的空窗期） │   │
│  │  - 空间巧合（创造独处通道）          │   │
│  └──────────────┬───────────────────────┘   │
│                 │ 条件就绪                   │
│                 ▼                            │
│  ┌──────────────────────────────────────┐   │
│  │  引导系统                            │   │
│  │  - 向潜在暗杀者推送环境提示          │   │
│  │  - 告知当前条件满足状态              │   │
│  │  - 弹窗询问是否触发暗杀              │   │
│  └──────────────────────────────────────┘   │
└─────────────────────────────────────────────┘
```

---

### 二、引擎对暗杀者的条件引导

引擎在排列好暗杀条件后，会向潜在暗杀者发送引导信息，帮助其把握时机。

| 引导类型 | 内容 | 呈现方式 |
| :--- | :--- | :--- |
| **机会提示** | “你注意到XX独自在书房，他掌握的证据一旦公开你将暴露。” | 屏幕边缘浮现半透明提示 |
| **条件状态** | “独处窗口：✅ | 信息空窗期：✅ | 逃离路径：厨房后门无人” | 暗杀面板中的条件清单 |
| **风险预警** | “管家将在3分钟后巡视走廊，窗口有限。” | 计时器提示 |
| **配合建议** | “你可以从厨房后门接近，那里灯光已熄灭。” | 半透明路径指示 |

**关键原则**：引擎只提供信息和机会，不替扮演者做决定。

---

### 三、弹窗询问机制

当所有暗杀条件就绪时，系统向扮演者弹出暗杀确认窗口：

```
┌──────────────────────────────────────────┐
│  ⚠️ 暗杀机会                              │
│                                          │
│  目标：玛丽·萨瑟兰                       │
│  位置：书房（独处）                       │
│  动机：玛丽掌握了你的致命证据，尚未公开   │
│  窗口：约2分钟（管家将在2分钟后巡视）     │
│  风险：中等（厨房后门无人，但隔壁有仆人） │
│                                          │
│  你的暗杀能力：L2（可徒手勒杀，或使用随身匕首） │
│                                          │
│  [ 执行暗杀 ]    [ 放弃 ]               │
└──────────────────────────────────────────┘
```

**弹窗规则**：
- 弹窗仅该扮演者可见
- 弹窗出现时游戏不暂停，窗口时间继续流逝
- 若超时未操作，默认放弃
- 放弃后，同目标同条件不会再次弹窗（防止骚扰）

---

### 四、引擎对智能体和人类玩家的统一处理

| 维度 | 人类玩家 | AI智能体 |
| :--- | :--- | :--- |
| **条件催化** | 相同 | 相同 |
| **引导信息** | 弹窗呈现 | 事件推送至L1感知层 |
| **决策方式** | 玩家点击按钮 | 心智模型自主决策 |
| **决策约束** | 无强制（OOC机制处理） | 人格过滤器强制执行 |

**对于AI智能体**：引擎推送暗杀机会事件后，智能体走完整的四层心智模型（感知→理解→规划→执行）。人格过滤器会验证：
- 人设过滤器：这个角色会暗杀吗？
- 逻辑过滤器：暗杀在物理上可行吗？
- 得失过滤器：暗杀的代价是否小于不暗杀的代价？

只有三层全部通过，智能体才会执行暗杀。

---

### 五、引擎催化暗杀的克制原则

| 原则 | 在暗杀催化中的体现 |
| :--- | :--- |
| **不强制** | 弹窗永远提供“放弃”选项 |
| **不偏袒** | 引擎也会为被暗杀者催化防御条件（如让管家提前巡视） |
| **不过度** | 同一角色在一次游戏中，暗杀弹窗不超过2次 |
| **逻辑自洽** | 所有催化（天气、NPC行为、灯光）都有世界内解释 |

### 六、暗杀条件检测与弹窗的完整链路

```
[扮演者角色：暗杀者]
    │
    │ 角色存在致命动机（仇恨/证据危机/秘密濒临暴露）
    │
    ▼
[叙事引擎：条件排列器]
    │
    │ 环境催化 → 独处窗口
    │ NPC引导 → 调离目击者
    │ 信息延迟 → 延长空窗期
    │ 空间巧合 → 隐蔽接近路径
    │
    ▼
[条件检测器]
    │
    │ ✅ 致命动机  ✅ 信息空窗期  ✅ 独处窗口
    │ ✅ 能力匹配  ✅ 代价评估通过
    │
    ▼
[弹窗询问]
    │
    │ 向暗杀者推送暗杀机会面板
    │
    ├── [ 执行暗杀 ] → 暗杀启动 → 阶段化感知 → 后果链
    └── [ 放弃 ] → 条件重置，同目标不再弹窗
```

---

**总结：叙事引擎是暗杀的“机会编排者”，而不是“暗杀指令下达者”。仇杀任务除外，引擎从不直接告诉角色“去杀XX”，而是通过环境催化、NPC引导、信息延迟、空间巧合排列出暗杀条件同时满足的时机，然后以弹窗形式询问扮演者是否行动。选择权永远在扮演者手中。**
