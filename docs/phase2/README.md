# docs/phase2 目录结构

## 定位

- `Phase 2`：跨局叙事与创作者生态阶段。
- `core = Phase 2 必做`。

## 目录分层

- `core`
  - 跨剧本记忆继承与世界快照
  - 创作者工具链（内部稳定版 / 对外受控开放）
  - 创作者与大玩家权限体系（可执行版本）
  - 扩展 ESM 规则库与环境动态系统
  - L4/L5 中与创作者生态直接相关的核心能力
- `expansion`
  - 面向 Phase 3 的持续世界预备能力
  - 高成本增强能力与实验能力

## 维护规则

- 进入 `phase2/core` 的能力，必须在 `docs/consolidation/04-Phase映射表.md` 标记为 Phase 2 必做。
- 若能力仍存在显著不确定性，默认先放 `phase2/expansion`。
