# docs/phase0 目录结构

## 定位

- `phase0 = 预验证 demo 轨`，不等于 `Phase 1 core`。
- 这里只承载“进入 Phase 1 完整闭环开发前，必须跑通的最小技术与交互验证”。
- `phase0` 文档大量引用 `phase1/core` 作为系统设计真源，不重复承载完整架构细节。
