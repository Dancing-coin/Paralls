## 一、核心体验验证类（多智能体社交推理）

| 项目名称 | 简介 | 参考价值 | 许可证 |
| :--- | :--- | :--- | :--- |
| **LieGraph** | 基于LangGraph的多智能体社交推理框架，让6个AI智能体自主玩“谁是卧底”游戏。每个智能体具备独特个性和动态身份推断能力 | 验证AI角色在社交推理中的自主博弈能力；人格驱动的策略差异与《开本》五维人格参数理念高度契合。LangGraph的工作流设计对司命编排多智能体交互有直接参考价值 | MIT |
| **llm-werewolf** | 开源的多LLM狼人杀模拟项目，不同AI模型分别扮演村民或狼人角色，通过自然语言交互进行推理和欺骗 | 提供了多模型博弈的完整框架，可直接复用其角色分配和回合管理逻辑 | 开源 |
| **wolfcha** | AI驱动的狼人杀/黑手党社交推理游戏，每个玩家均由顶尖LLM（如DeepSeek、Qwen、Gemini）控制，具备双层AI角色扮演和实时交互能力 | 验证了多模型竞技场在社交推理中的可行性；为《开本》AI智能体的模型选型提供参考 | 开源 |
| **AI海龟汤聊天室** | 开源多人推理游戏项目，AI全自动主持海龟汤游戏，支持房间系统、自定义题库、多人实时互动 | 为《开本》的“AI司命主持”模式提供技术参考，尤其是房间管理、题库管理和AI主持人的交互设计 | 开源 |


## 二、AI与智能体技术类

| 项目名称 | 简介 | 参考价值 | 许可证 |
| :--- | :--- | :--- | :--- |
| **NitroGen** (NVIDIA+Stanford) | 通用游戏智能体基础模型，在超过1000款游戏、累计4万小时的游戏视频上训练而成。纯视觉输入+通用动作空间，具备跨游戏零样本泛化能力 | 验证了AI通过视觉感知在多样化游戏环境中自主操作的可行性，其“感知-决策-动作”范式与《开本》角色智能体L1-L4心智模型一致 | 开源 |
| **Vox Deorum** | 面向《文明V》的混合LLM架构，LLM负责宏观战略推理，子系统执行战术部署。经过1408局完整游戏验证，AI文明存活率约97.5% | 与《开本》SLG玩法中“司命宏观叙事+群体模拟引擎微观执行”的分层架构理念一致。大模型处理外交谈判等自然语言交互，传统AI执行战斗逻辑 | 开源 |
| **Lumine** (字节跳动) | 3D开放世界通才型智能体开源方案，通过视觉-语言模型以每秒5帧处理原始像素，精确输出键鼠动作。在《原神》中完成5小时主线剧情，并零样本泛化至《鸣潮》《崩坏：星穹铁道》 | 展现AI在复杂3D环境中进行长时间任务规划和执行的潜力，为《开本》角色智能体在3D场景中的自主探索、对话、任务完成等行为提供技术思路 | 开源 |
| **Game-TARS** | 通用游戏智能体基础模型，统一键盘-鼠标动作空间，预训练超过500B tokens。在《我的世界》开放任务和网页3D游戏中表现接近人类水平 | 在开放世界环境中的通用问题解决能力有显著突破，为《开本》在多个不同平行世界中实现统一的AI交互范式提供了潜在技术路径 | 开源 |
| **Revac_8** | 面向社交推理游戏的AI智能体，专为MindGames Arena的社交推理赛道设计，能在不确定、信息不完全和有意误导的环境中进行策略性推理和淘汰决策 | 为《开本》中复杂高压情境（如“全员嫌疑人”）下的AI角色决策提供专门的推理框架参考 | 学术开源 |
| **LangGraph** | 用于构建有状态、多角色交互应用的开源框架，通过图结构建模实现多角色协同工作，支持状态持久化和人机交互 | 可作为编排《开本》中司命与多个角色智能体之间复杂交互逻辑的参考框架。其状态图（StateGraph）概念与司命的游戏阶段管理高度一致 | 开源 |
| **Generative Agents** (斯坦福AI小镇) | 让25个AI智能体在虚拟小镇中长期自主运行，有工作、社交、组织活动，运行时间远超1小时 | 验证了长时间AI自主行为的可行性，为《开本》Phase 3的小镇生态和AI同伴长期陪伴提供参考 | 学术开源 |


## 三、游戏引擎与开发创作工具

| 项目名称 | 简介 | 参考价值 | 许可证 |
| :--- | :--- | :--- | :--- |
| **Godot Engine** | 功能完善的MIT协议开源3D/2D游戏引擎，拥有活跃的社区、丰富的教程和快速迭代的特性，支持多平台导出 | 《开本》L1确定性空间层的首选引擎，负责3D场景渲染、物理碰撞、空间音频等核心功能 | MIT |
| **UniGen** | MLLM驱动的零代码3D游戏开发多智能体框架，可自动化游戏开发流程，将专业开发门槛降至自然语言描述。相比传统开发流程提速90% | 为《开本》的“资产创作工具”和“快速世界搭建”提供长期愿景参考。未来创作者或可通过描述性语言快速生成剧本所需的3D场景和交互逻辑 | 学术开源 |
| **Narrat Engine** | 开源叙事游戏引擎，使用简单的脚本语法即可创建互动叙事RPG。内置技能系统、物品库存和任务系统，适合制作视觉小说、互动小说等类型 | 其简洁的叙事脚本语法和内置的RPG系统，可作为《开本》剧本创作工具的底层叙事引擎参考，尤其在对话树、分支剧情管理方面 | MIT |
| **Roseblox** | 专为AI辅助3D游戏开发设计的友好型引擎，致力于解决传统引擎对AI代码生成不友好的问题，采用“免构建”设计理念 | 其设计理念与《开本》降低创作者门槛的目标一致，可作为Godot之外的一个备选技术方案或参考架构 | 开源 |
| **Word2Minecraft** | 利用大语言模型将结构化故事（主角目标、反派挑战、环境设定）转化为可玩游戏关卡。系统首先生成叙事，再将其转化为具有空间和游戏性约束的3D关卡 | 故事→场景的自动化生成逻辑，与《开本》剧本种子库到3D场景的转换流程相似，对司命自动生成场景布局有参考价值 | 开源 |

## 五、专项技术方案

| 项目名称 | 简介 | 参考价值 | 许可证 |
| :--- | :--- | :--- | :--- |
| **Steam Audio** | Valve开发的开源、跨平台空间音频工具包。支持物理遮挡、混响、HRTF渲染等高级特性，能够模拟声音沿走廊、绕过角落、穿过门窗的多路径传播 | 可直接集成到Godot引擎中，为《开本》的空间音频系统提供技术支撑，实现声音博弈的核心玩法（清晰区/模糊区/静默区/耳语模式） | Apache 2.0 |
| **WebRTC + Opus** | 成熟的实时通信开源协议和高效语音编码器。Opus支持宽比特率范围，可在受限网络和高质量立体声之间灵活适配 | 可构成《开本》实时语音通信的技术基础，支持清晰区/模糊区/静默区的分级传输和耳语模式 | 开源 |
| **llama.cpp** | 高效的C++推理框架，支持在消费级硬件上运行开源大语言模型。支持AVX2/AVX-512、ARM NEON等现代指令集，以及1.5-bit到8-bit的量化方法 | 可作为《开本》模型路由中L2本地小模型的推理引擎，实现低延迟兜底和隐私保护。支持从服务器到手机的多平台部署 | MIT |
| **Whisper (OpenAI)** | 开源语音识别模型，支持多语种、流式处理、静音检测。端到端设计直接将音频输入转换为文本输出 | 可作为《开本》语音转文本（STT）的核心引擎，支持玩家语音输入和AI角色对话的实时转录 | MIT |
| **Milvus** | 全球首个开源向量数据库项目，支持十亿级向量搜索、毫秒级延迟。提供多种索引类型（IVF、HNSW、ANNOY、DiskANN），支持跨模态检索 | 可用于存储和检索角色人生记忆、对话历史的语义索引，支持《开本》的记忆系统和知识图谱 | Apache 2.0 |
| **NATS JetStream** | 云原生消息系统，支持持久化和高吞吐的消息传递。Core NATS提供轻量级发布/订阅模型，JetStream扩展提供持久化流能力 | 可作为《开本》事件总线的核心组件，处理异步推理、持久化事件和跨服务解耦通信 | Apache 2.0 |
| **Grafana + Prometheus** | 开源监控和告警系统，Grafana用于可视化仪表盘，Prometheus负责指标收集和告警 | 用于《开本》系统健康监控、AI调用统计、异常告警 | AGPLv3 / Apache 2.0 |

## 七、对《开本》三阶段的分层支撑

| 阶段 | 主要参考项目 | 核心价值 |
| :--- | :--- | :--- |
| **Phase 0（原型）** | LieGraph、llm-werewolf、wolfcha、AI海龟汤聊天室 | 快速搭建多智能体社交推理原型，验证AI角色自主博弈能力。直接Fork LieGraph替换为剧本杀案件框架 |
| **Phase 1** | Godot、Steam Audio、WebRTC+Opus、llama.cpp、Whisper、NobodyWho、TextArena | 验证核心闭环：用Godot搭建3D沉浸基础，用Steam Audio实现空间音频博弈，用llama.cpp+Whisper实现本地AI对话和语音交互 |
| **Phase 2** | NitroGen、Lumine、Game-TARS、LangGraph、Milvus | 增强AI能力和创作工具：引入更智能的感知能力，用LangGraph参考优化司命编排，用Milvus构建记忆系统 |
| **Phase 3** | Vox Deorum、GDGS、Generative Agents、NATS JetStream | 构建宏大世界：用Vox Deorum的混合架构实现SLG的AI势力管理，用GDGS实现点云过渡，用Generative Agents驱动小镇生态 |


**一句话总结**：《开本》有约20个可直接参考的开源项目，覆盖多智能体博弈、通用游戏AI、游戏引擎、空间音频、本地推理、语音识别、向量数据库、消息中间件等全部核心技术领域。Phase 0可直接Fork LieGraph快速搭建原型；Phase 1的核心技术栈（Godot+Steam Audio+llama.cpp+Whisper）均为成熟开源方案；Phase 2-3的前沿能力（智能感知、宏大世界模拟、点云过渡）也均有学术开源项目可供参考。
