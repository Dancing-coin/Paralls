# docs/phase3 目录结构

## 定位

- `Phase 3`：持续运行世界与完整生态阶段。
- `core = Phase 3 必做`。

## 目录分层

- `core`
  - 持续世界运行底座
  - 完整生态治理与跨世界规则体系
  - 完整商业与资产循环闭环
  - 群体模拟与长期世界演化机制
- `expansion`
  - 实验性机制
  - 高风险/高成本前瞻能力

## 维护规则

- `phase3/core` 文档应明确前置依赖来自 `phase1/phase2/core` 的哪些能力。
- 对于会反向影响低阶段边界的改动，必须先回填 consolidation 再调整下游文档。
