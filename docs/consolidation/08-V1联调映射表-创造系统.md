# 08-V1联调映射表-创造系统

## 状态

- 状态：V1 最小可验证映射（联调前冻结）
- 来源：`406-450` 创造能力族（当前已产出 `406-437`）中的 V1 可联调最小集（以 `D104-D108` 为入口）
- 目标：把文档协议映射到实现层最小接口、最小存储与最小指标

## 1. 范围

本表只覆盖：

- 蓝图导入请求/响应
- 映射同步事件
- 冲突审核工单
- 审计记录
- Phase 1 验收指标的统计口径

不覆盖：

- 分库分表与高阶索引优化
- 复杂权限继承模型
- BI 报表体系

## 2. 事件名与通道映射（V1）

| 事件名 | 方向 | 通道 | 说明 |
| :--- | :--- | :--- | :--- |
| `wb.import.requested.v1` | Client/Tool -> Runtime | 可靠通道 | 蓝图导入请求 |
| `wb.import.validated.v1` | Runtime -> Orchestrator | 可靠通道 | 校验结果返回（通过/拒绝/待审核） |
| `wb.import.instantiated.v1` | Runtime -> Bus | 实时通道 | 实例化完成事件 |
| `wb.import.failed.v1` | Runtime -> Bus | 可靠通道 | 实例化失败与回滚结果 |
| `wb.mapping.synced.v1` | Runtime -> Bus | 实时通道 | 映射同步完成 |
| `wb.mapping.conflict_detected.v1` | Runtime -> Review | 可靠通道 | 冲突检测与工单创建触发 |
| `wb.review.ticket_opened.v1` | Review -> Bus | 可靠通道 | 冲突工单已创建 |
| `wb.review.ticket_closed.v1` | Review -> Bus | 可靠通道 | 冲突工单已闭环 |
| `wb.audit.logged.v1` | Any -> Audit | 可靠通道 | 审计记录入库事件 |

口径约束：

- 命名采用 `wb.<domain>.<action>.v1`
- 需要重放/追责的事件统一进可靠通道
- 仅影响前端表现的实例状态变化可走实时通道

## 4. 最小接口动作（V1）

| 动作 ID | 输入 | 输出 | 失败码来源 |
| :--- | :--- | :--- | :--- |
| `wb.import.validate_and_run` | 导入请求协议字段 | 导入响应协议字段 | `E_AUTH_DENIED` 等 V1 错误码 |
| `wb.mapping.sync` | 映射同步事件字段 | `event_id` + `conflict_flag` | `E_CONFLICT_REVIEW` |
| `wb.review.open_ticket` | `related_event_id` + `conflict_type` | `ticket_id` | `E_CONFLICT_REVIEW` |
| `wb.review.close_ticket` | `ticket_id` + `decision` | 闭环结果 | 无（业务校验失败返回通用错误） |
| `wb.audit.write` | 审计字段 | `audit_id` | `E_RUNTIME_FAILURE` |

说明：

- 动作 ID 先冻结语义，不强绑 HTTP/RPC 形态
- 具体 transport 由实现层决定，但字段和结果口径必须一致

## 5. 指标统计口径（V1）

### 5.1 非法导入拦截率

- 指标名：`wb_illegal_import_block_rate`
- 分子：被判定 `E_AUTH_DENIED`、`E_DEP_MISSING`、`E_DEP_VERSION`、`E_WORLD_CONSTRAINT` 的非法请求数
- 分母：全部非法导入请求数
- 目标：`100%`

### 5.2 合法导入成功率

- 指标名：`wb_legal_import_success_rate`
- 分子：合法请求中 `status=accepted` 且实例化成功数
- 分母：全部合法导入请求数
- 目标：`>=95%`

### 5.3 实例化回写成功率

- 指标名：`wb_instance_writeback_success_rate`
- 分子：`wb.import.instantiated.v1` 后回写成功数
- 分母：实例化执行总数
- 目标：`>=99%`

### 5.4 自动合并成功率

- 指标名：`wb_auto_merge_success_rate`
- 分子：无需开工单即可完成合并的冲突事件数
- 分母：同层且无权限冲突的可自动合并事件总数
- 目标：`>=90%`

### 5.5 冲突工单闭环时长

- 指标名：`wb_ticket_close_p95_minutes`
- 样本：`P1/P2` 工单
- 计算：`closed_at - opened_at` 的 `P95`
- 目标：`<=30 分钟`

### 5.6 审计记录完整率

- 指标名：`wb_audit_completeness_rate`
- 分子：具备必填字段（`audit_id/request_id/operator_id/world_id/action/result/created_at`）的记录数
- 分母：全部审计记录数
- 目标：`100%`

## 6. 联调通过条件（V1）

- 事件链路可在测试环境完整跑通：请求 -> 校验 -> 实例化/拒绝 -> 审计
- 任一拒绝路径都能落地 `error_code` 与 `audit_id`
- 冲突路径必须生成工单，不允许静默覆盖
- 指标可按上述分子/分母自动统计，不依赖人工补录
