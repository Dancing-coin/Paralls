# 11-当前待办总表

## 状态

- 状态：项目级统一待办总表（第二轮清洗版）
- 作用：统一汇总全仓文档中的待办、后续动作、延后项、Phase 1 不做项、Phase 2/3 预留项，以及当前线程明确新增但暂不执行的后续任务

## 1. 使用规则

本总表按五类事项汇总：

1. `当前待办`
2. `M1-M2 实现待办`
3. `Phase 1 不做`
4. `Phase 2/3 预留`
5. `结构维护项`

每条事项统一字段：

- `事项`
- `归属模块`
- `阶段`
- `优先级`
- `依赖`
- `下一步动作`
- `是否阻塞 Phase 1`
- `来源文档`
- `状态`
- `备注`

状态枚举统一为：

- `pending`
- `in_progress`
- `deferred`
- `blocked`
- `done`

优先级枚举统一为：

- `P0`：直接阻塞当前主线
- `P1`：强相关，宜尽快处理
- `P2`：重要但不阻塞当前实现
- `P3`：长期预留或维护收尾
