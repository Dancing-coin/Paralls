# 02-模块来源索引

## 说明

本文件用于记录每个模块的主要来源轮次、补充轮次、明显过时轮次和整理注意事项。

使用规则：

- `主证据轮次`：整理该模块时必须优先精读
- `补证轮次`：用于补全边界、例子或实现细节
- `明显过时轮次`：只能用于理解演进，不可直接采用
- 处理任何目标轮次时，必须同时检查前后相邻序号文件；如果同一议题仍在延续，就继续向外扩展，直到议题边界清晰为止
- 当相邻轮次对同一议题给出修订时，以更晚轮次为准，并在目标文档中写清覆盖关系
- 如与 `01-决策总表.md` 有差异，以后者中更新更晚、覆盖关系更明确的结论为准
- 核心文档体系是否需要新增，另见 `05-core文档体系检查.md`
