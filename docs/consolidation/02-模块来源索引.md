# 02-模块来源索引

## 说明

本文件用于记录每个模块的主要来源轮次、补充轮次、明显过时轮次和整理注意事项。

使用规则：

- `主证据轮次`：整理该模块时必须优先精读
- `补证轮次`：用于补全边界、例子或实现细节
- `明显过时轮次`：只能用于理解演进，不可直接采用
- 如与 `01-决策总表.md` 有差异，以后者中更新更晚、覆盖关系更明确的结论为准
