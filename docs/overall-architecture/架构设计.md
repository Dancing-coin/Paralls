## L1 确定性空间层

**定位**：世界的一切“看得见、摸得着”的东西。提供3D世界的实时渲染、物理模拟、空间音频和玩家交互。

**技术底座**：Godot 4.x + Steam Audio + WebRTC + GDGS

### L1.1 交互系统族

- **空间音频系统**：清晰区/模糊区/静默区、物理阻挡、耳语模式、偷听机制

- **变声器与文字润色**：强制变声器、可选AI文字润色
- **捏脸系统**：Blend Shape形态键、种族模板、体型调节

- **事件埋点模块**：所有玩家交互行为向L2上抛结构化事件

## L2 智能体交互层

**定位**：世界的“逻辑、生态和故事”。驱动所有AI角色的行为和全局叙事逻辑，是《开本》的灵魂。

**技术底座**：Python + LLM + llama.cpp + NATS + PostgreSQL + Redis + Milvus

### L2.1 AI核心引擎族

#### 子系统：角色智能体引擎

职责：

- 承载角色 `L1-L4` 心智链路与行动决策。
- 在角色私有信息边界内完成理解、记忆、规划、表达。

孙系统：

- Per-Character 感知过滤器：按角色感官档案与状态过滤候选感知事件，输出角色专属感知事件。
- 感知接入器：接收过滤后的角色感知事件，不直接接收原始世界事件。
- 理解与记忆器：沉淀事件、观察、知识、社交与高阶记忆。
- 规划与执行器：输出行为候选与执行意图。

边界：

- 不直接编译候选感知事件（该职责属于可感知信息编译层）。
- 不绕过事件总线直接读取跨层原始流。

#### 子系统：可感知信息编译层（L2）

职责：

- 将原始世界事件编译为多感官候选感知事件。
- 为后续角色私有裁剪提供统一候选输入。

孙系统：

- 通道编译器：视觉/听觉/嗅觉/热感/触觉拆分。
- 上下文融合器：光照、噪音、遮挡、环境参数融合。
- 阶段标签器：`intent/execute/complete` 语义标注。

边界：

- 不做角色私有裁剪。
- 不替代 Per-Character 感知过滤器。

#### 子系统：对话生成系统

职责：

- 组装对话上下文并执行流式文本生成与人格过滤。
- 输出可回写 `L1` 的语言行为数据。

孙系统：

- 上下文组装器
- 文本生成器
- 人格一致性过滤器
- TTS 适配器

#### 子系统：司命（叙事引擎）

职责：

- 维护单局叙事节奏、公平性与冲突催化。
- 输出 `impulse/fact_reveal/opportunity` 高层消息。

孙系统：

- 事实核心
- 天平系统
- 冲突与案件生成器
- 高阶知识图谱引擎
- 干预执行器

边界：

- 不直接控制玩家动作。
- 不替代角色自主决策与 `ESM` 物理执行。

#### 子系统：司命子智能体

职责：

- 分担司命高并发任务，承担场景化催化与校验执行。

孙系统：

- 环境催化子智能体
- `L3` 调度子智能体
- 冲突检测子智能体
- 平衡管理子智能体

#### 子系统：Harness 编排框架

职责：

- 管理司命及其子智能体任务分级、队列、兜底与延迟控制。

孙系统：

- 任务分级器
- 队列管理器
- 兜底降级器
- 时延守卫器

#### 子系统：模型路由调度器

职责：

- 执行 `P0-P4` 任务分级与三层模型分配。
- 在超时/拥塞场景下执行回退与兜底。

孙系统：

- 任务分级器（`P0-P4`）
- 路由决策器（性能/成本/时延）
- 超时回退器（降级与兜底）


### L2.2 玩法机制引擎族

- **案件与真相系统**：事实锁定时间线(T0-T3)、案件框架随机生成、线索系统、多重结局判定
- **信息博弈系统**：三种知识形态管理、五种共享方式、高阶知识追踪、偷听与反偷听
- **伪装系统**：公开档案vs真实档案、伪装深度、物理道具支撑、伪装压力与破绽
- **知情人网络**：固定/动态NPC知情人、参与者知情人、反制策略
- **暗杀与阴谋系统**：暗杀五重条件、环境致死、蓄意破坏、共谋与背叛
- **证据与痕迹系统**：物品流转追踪器、接触痕迹管理器、生物痕迹管理器、证据可视化
- **投票与结局系统**：投票机制、多重结局条件判定、结局叙事生成


### L2.3 目标与身份系统族

- **核心目标系统**：8种核心目标的分配与管理
- **多层目标结构**：个人目标→共同目标→动态目标的三层嵌套
- **动态阵营系统**：明面/暗面/固定/动态阵营的形成与瓦解、派系分化
- **特殊人群分类**：11种核心人群的角色设计语法


### L2.4 叙事与生态引擎族

- **剧本种子库**：可能性模块集合（角色池/动机池/线索池/结局条件），每次开本后反哺
- **续集承接逻辑**：世界状态快照+变量衔接规则，前作结局影响续作个性化开局
- **世界快照系统**：记录世界的阶段性状态，支持离线时间线补全和跨世界映射
- **世界映射引擎**：场景连接关系管理、跨世界数据同步、资产版权追溯
- **AI陪伴羁绊系统**：羁绊建立、带走机制、坦白与契约、关系终局
- **小世界小镇生态**：智能体居民、季节节日、随机事件、居民关系网络
- **生物成长系统**：动植物阶段式成长、AI同伴照料
- **离线时间线补全**：登录时司命瞬间补全离线期间的关键事件
- **小世界多同伴共存**：修罗场、心意值、关系模式、角色兼容性管理
- **场景化商店**：家具/服装/道具散落在小镇商铺中，沉浸式购物



## L3 视觉增强层

**定位**：世界的“高光时刻”。在叙事关键节点叠加高质量视觉内容，增强沉浸感和情绪感染力。

**技术底座**：图片生成API + 视频生成API + Godot实时演算 + GDGS

### L3.1 生成与渲染系统族

- **WOW时刻导演**：司命镜头调度、实时演算、慢动作、滤镜切换、粒子特效协同
- **图片生成服务**：线索特写、角色立绘、建筑效果图、生物图鉴、纪念照的生成与缓存
- **视频生成服务（离线）**：生物生态纪录片、建筑漫游视频、结局CG的异步生成
- **点云过渡渲染系统（L3部分）**：管理点云端点快照、触发过渡、与ESM和司命协同


### L3.2 视觉障眼法系统族

#### 子系统：视觉障眼法系统

职责：

- 在无中间态数据或形变跨度过大时，用粒子爆发、结茧/能量场、沙化/光化、全息投影等手段掩盖模型切换。

孙系统：

- 障眼法模板调度器：根据场景类型与性能预算选择障眼法模板。
- 镜头节奏控制器：协调镜头节奏，降低状态切换突兀感。
- 回退策略执行器：在渲染失败或预算不足时执行可降级表现方案。

边界：

- 不替代点云过渡系统的连续插值职责。
- 不改写世界事实状态与业务判定。

#### 子系统：点云过渡系统

职责：

- 在存在可用中间态时执行点云连续形变过渡，保证状态转场连贯。

孙系统：

- 端点快照管理器：管理过渡前后端点状态快照。
- 中间态插值器：执行端点之间的连续插值与形变生成。
- 预算感知降级器：在预算紧张时调整细节密度与帧级开销。

边界：

- 不负责无中间态场景的视觉掩盖（该职责属于视觉障眼法系统）。
- 不参与叙事触发判定。

#### 子系统：高光编排系统

职责：

- 编排记忆闪回、证据镜头、结局高光等关键表现段落。

孙系统：

- 触发条件判定器：判定何时触发高光表现。
- 素材与时间线编排器：组织素材并排布时间线。
- 表现状态回写器：向上层回写表现执行状态。

边界：

- 不替代司命叙事决策。
- 不改写事实链路。

#### 子系统：小世界画风系统

职责：

- 管理画风设定包、建筑风格与季节基调的切换消费。

孙系统：

- 画风包管理器：维护画风资源包与版本。
- 场景风格应用器：把画风参数应用到场景对象。
- 季节基调控制器：调度季节级色调与氛围参数。

边界：

- 不替代资产经济系统做结算。
- 不改写底层物理状态。



## L4 商业运营层

**定位**：支撑《开本》生态的经济循环。从大玩家经营到创作者变现，从玩家消费到资产交易。

**技术底座**：Web服务 + Docker + Kubernetes + 区块链 + 支付系统

### L4.1 大玩家经营系统族

- **大玩家控制台**：剧本库策展、规则微调、一键部署、服务器监控、GM指令舱、经营分析
- **GM指令舱**：大玩家与司命对话讨论决策，建议剧情走向、调整NPC行为
- **影院模式引擎**：灵活策展、多题材轮换、追逐热点、服务取胜
- **主题世界模式引擎**：深度绑定单一世界观、独占内容管理、IP壁垒构建
- **双层玩家身份管理**：穿越旅人（无身份）vs 原住居民（有身份）的权限和名额管理


### L4.2 资产与经济系统族

- **资产市场**：剧本/角色/场景/皮肤/智能体模板/建筑蓝图的展示、交易、众筹
- **区块链确权系统**：内容指纹上链、引用追溯、Fork家谱记录、IPFS存储
- **智能合约分账引擎**：多级分成配置、实时自动分账、分账记录透明可查
- **大玩家算力套餐**：月度订阅/按量付费的AI算力销售
- **云游戏服务**：为硬件不达标玩家提供云端渲染和AI推理


### L4.3 创作者经济系统族

- **创作者收益中心**：剧本销售/订阅收入、资产交易收入、众筹收入、Fork授权收入的统一管理
- **Fork与版本管理**：基于已有剧本/世界创建平行版本，链上记录贡献者署名
- **推荐算法**：剧本推荐、大玩家推荐、资产推荐、流量扶持
- **双轨邀请制**：KOL流量变现、玩家自来水裂变



## L5 平台治理层

**技术底座**：安全服务 + 合规框架 + 数据分析 + 社区治理

### L5.1 安全与合规系统族

- **反作弊与安全系统**：服务端权威验证、AI行为异常检测、客户端防篡改、举报与处理
- **数据隐私与合规**：数据收集范围管理、玩家数据删除权、AI记忆隐私保护
- **内容审核系统**：UGC内容的自动化+人工审核、违规内容下架


### L5.2 用户运营系统族

- **新手引导系统**：沉浸式教程剧本《旅人初临》
- **成就与赛季系统**：跨世界成就、世界内收藏、赛季通行证
- **匹配系统**：8种匹配模式（纯真人/纯AI/混合/携友/携AI等）
- **匹配服务**：跨服匹配撮合、AI填补、组队邀请
- **意向志愿系统**：玩家角色选择权与知情权的平衡机制


### L5.3 生态治理系统族

- **治理代币与IP议会**：代币发行、贡献者空投、投票治理
- **创作者扶持与评级**：创作者成长路径、质量评级、官方投资/收购优质IP
- **大玩家评级与流量分配**：大玩家服务质量评级、流量倾斜机制、新大玩家冷启动扶持


### L5.4 创作工具系统族

- **剧本编辑器**

  - 使用者：创作者
- **资产创作工具**
  - 核心职责：角色模型导入、动画配置、场景模块编辑、音频管理
  - 使用者：创作者
- **生物编辑器**
  - 核心职责：基因模板设计、器官组件组装、行为参数调节
  - 使用者：创作者
- **物件编辑器**
  - 核心职责：蓝图化组装、材质绑定、属性配置
  - 使用者：创作者
- **世界编辑器**
  - 核心职责：地形编辑、场景拼接、生态配置、法则定义
  - 使用者：大玩家/创作者



## L6 跨层基础设施层

**定位**：连接各层、提供数据持久化和通用服务的底层基础设施。

**技术底座**：WebSocket + NATS + PostgreSQL + Redis + Milvus + MinIO + IPFS

### L6.1 通信与数据系统族

- **事件总线**：L1↔L2↔L3↔L4↔L5跨层消息路由中枢
- **数据持久化层**：PostgreSQL（事实库、用户数据）、Redis（状态缓存）、Milvus（记忆索引）、MinIO（资产存储）、IPFS（链上存储）


### L6.2 平台基础服务系统族

#### 子系统：房间与状态管理

职责：

- 管理房间创建/加入/销毁、角色锁定、状态同步与断线重连。

孙系统：

- 房间会话管理器：维护房间生命周期与会话上下文。
- 角色状态锁定器：管理角色占位、锁定与释放。
- `T0-T3` 坍缩协调器：协调事实坍缩阶段与状态切换。

边界：

- 不替代匹配系统的策略决策。
- 不直接改写叙事事实判定。

#### 子系统：持久化与存档（L6）

职责：

- 提供单局快照、断线自动存档、离线补全支撑所需的数据能力。

孙系统：

- 事实数据存储（PostgreSQL）：持久化事实与结构化业务数据。
- 状态缓存（Redis）：承载实时状态缓存与短期同步数据。
- 资产对象存储（MinIO）：存放资产与大对象文件。
- 存档与恢复服务：管理存档写入、读取与恢复流程。

边界：

- 不替代业务层规则判定。
- 不承担消息路由职责。

#### 子系统：AI测试工具

职责：

- 自动模拟剧本运行并输出测试报告与逻辑漏洞检测结果。

孙系统：

- 仿真场景驱动器：驱动测试用角色与场景状态推进。
- 测试回放器：回放测试轨迹并支持问题复现。
- 报告生成器：聚合指标与异常输出测试报告。

边界：

- 不直接写入生产事实链路。
- 不替代线上运行时调度。

#### 子系统：事件总线

职责：

- 作为跨层消息路由中枢，承载广播/单播/组播与优先级分流。

孙系统：

- 路由器（广播/单播/组播）：按订阅关系分发消息。
- 优先级调度器（`P0-P3`）：按优先级调度消息发送顺序。
- 通道分流器（实时/可靠）：按可靠性与时延要求路由到不同通道。

边界：

- 不做角色逻辑推理。
- 不做证据判定与事实解释。

#### 子系统：证据链系统

职责：

- 管理“产生-流转-接触-生物痕迹-矛盾比对”的证据闭环。

孙系统：

- `Item Flow Tracker`：追踪物品全生命周期流转。
- `Contact Trace Manager`：记录接触链与传播链。
- `Bio Trace Manager`：管理生物痕迹记录与匹配。
- 司命事实核心比对接口：向司命提供证据比对输入。

边界：

- 不替代司命进行全局叙事裁定。
- 不独立进行角色动机推理。



## 跨层协同：体素建造的完整协作链

以“玩家在自己的领地中建造一座建筑”为例，展示六层如何协同工作：

- 玩家在领地中放置方块
  - 层级：L1
  - 归属系统族：交互系统族
  - 执行内容：体素建造的3D交互界面接收玩家操作，渲染实时预览
- L1通过事件埋点上报建造事件
  - 层级：L1→L6→L2
  - 归属系统族：事件总线
  - 执行内容：结构化事件通过事件总线广播
- 校验建造权限和材料
  - 层级：L2
  - 归属系统族：叙事与生态引擎族
  - 执行内容：校验玩家是否在自己的领地内、是否有足够的材料
- 扣减材料并记录建造日志
  - 层级：L2
  - 归属系统族：叙事与生态引擎族
  - 执行内容：消耗玩家背包中的材料，记录建造日志
- 广播建造完成事件
  - 层级：L2→L6→L1
  - 归属系统族：事件总线
  - 执行内容：司命催化建造动画，AI同伴感知建筑变化
- 建筑完成后可导出蓝图
  - 层级：L1→L5
  - 归属系统族：创作工具系统族
  - 执行内容：玩家将建筑保存为蓝图，上传至资产市场
- 蓝图在市场中交易
  - 层级：L4
  - 归属系统族：资产与经济系统族
  - 执行内容：蓝图定价、售卖、智能合约分账
- 蓝图数据持久化存储
  - 层级：L6
  - 归属系统族：数据持久化层
  - 执行内容：蓝图数据存入PostgreSQL和IPFS



## 跨层协同：物件组装的完整协作链

以“玩家在匠造工作台组装一把剑”为例：

- 玩家打开匠造工作台
  - 层级：L1
  - 归属系统族：交互系统族
  - 执行内容：显示零件库、蓝图网格、预览界面
- 玩家拖拽零件到网格上
  - 层级：L1
  - 归属系统族：交互系统族
  - 执行内容：实时渲染零件在网格上的位置和旋转
- L1上报组装操作
  - 层级：L1→L6→L2
  - 归属系统族：事件总线
  - 执行内容：结构化事件通过事件总线广播
- 校验零件匹配和配方
  - 层级：L2
  - 归属系统族：叙事与生态引擎族
  - 执行内容：校验零件组合是否满足合成配方、计算最终属性
- 广播组装完成事件
  - 层级：L2→L6→L1
  - 归属系统族：事件总线
  - 执行内容：司命催化组装完成特效，AI同伴发表评论
- 物件数据存入玩家存档
  - 层级：L6
  - 归属系统族：数据持久化层
  - 执行内容：组装完成的物件存入玩家本地存档
