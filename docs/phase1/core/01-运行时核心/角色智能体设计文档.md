# 角色智能体设计文档

## 0. 架构视图（系统 / 子系统 / 孙系统）

### 0.1 总体架构设计

角色智能体是 `L2` 的角色级决策系统，运行在“感知输入 -> 心智处理 -> 行为输出”的四层闭环中。

系统边界：

- 输入边界：默认不直接消费全局原始事件流
- 感知链路：`原始世界事件 -> 可感知信息编译层 -> Per-Character 感知过滤器 -> 角色感知事件`
- 输出边界：行为意图可回写；物理结算必须由 `ESM` 执行

### 0.2 系统分解

#### 0.2.1 子系统：人格档案系统

职责：维护“基因种子 -> 人生记忆 -> 品格层 -> 五维人格”形成链。  
孙系统：人格初始化器、档案持久器、动态修正器。

#### 0.2.2 子系统：四层心智系统

职责：执行 `L1/L2/L3/L4` 连续决策闭环。  
孙系统：感知接入器、理解推理器、规划器、执行表达器。

#### 0.2.3 子系统：三重过滤系统

职责：按人设/逻辑/得失对候选行为做约束与否决。  
孙系统：人设过滤器、逻辑过滤器、得失过滤器。

#### 0.2.4 子系统：记忆与知识系统

职责：管理事件/观察/知识/社交/高阶记忆与知识状态。  
孙系统：记忆分池器、知识态更新器、高阶知识关系器。

#### 0.2.5 子系统：动态状态系统

职责：承接 `ESM` 物理状态结果并转化为主观行为偏置。  
孙系统：状态解释器、临界行为触发器、恢复与衰减器、会话参与状态子模块。

#### 0.2.6 子系统：伪装与自主行为系统

职责：执行公开档案/真实档案双层机制与挂机保守接管。  
孙系统：伪装管理器、自主行为调度器、回归同步器。

### 0.3 核心接口约束

- 输入：角色感知事件、司命高层消息、状态变化事件
- 输出：行为意图、对话内容、社交动作、内心提示候选
- 非职责：直接改写世界物理状态、越权获取全局原始事件

## 1. 设计目标与非目标
### 1.1 设计目标

本文档用于冻结《开本》角色智能体的统一底层、人格生成逻辑、运行时心智模型、伪装与动态状态系统，以及它与玩家投影角色的关系。

本文档不展开：

- 事件总线的底层消息字段
- 司命的全局叙事职责
- 剧本模板字段级配置

### 1.2 非目标
本节采用阶段收束口径，完整延后能力见第 9 节。

## 2. 核心定位与统一底层

角色智能体是《开本》中角色层面的统一运行时实例。

它负责回答的不是“该说哪句台词”，而是：

- 这个角色感知到了什么
- 这个角色如何理解这些信息
- 这个角色当前想做什么
- 这个角色最终会怎么说、怎么动、怎么伪装、怎么崩溃

### 2.1 系统身份

- 所属层级：`L2`
- 本体：角色级智能体实例
- 服务对象：AI 扮演角色、玩家投影角色、后续阶段的轻量级交互角色

### 2.2 核心原则

- 角色与人类玩家权限在世界规则内保持同源
- 角色行为由人格、记忆、状态和当前感知共同决定
- 司命只能催化，不控制角色最终行为
- 角色的“不理智”是设计结果，不是噪音


### 2.3 统一底层

所有剧中角色共享同一套四层心智结构：

- `L1` 感知
- `L2` 理解
- `L3` 规划
- `L4` 执行

### 2.4 两种驾驶模式

统一底层之上，有两种高层控制模式：

#### AI 角色

- `L1-L4` 全自动运行
- 角色自主生成决策和行为

#### 玩家投影角色

- `L1` 和 `L2` 仍自动运行
- `L3` 的方向盘主要交给玩家
- `L4` 中主动行为由玩家控制，自动生理与表现层行为由系统补全

补充边界：

- 这里的“`L1/L2` 仍自动运行”不等于系统替玩家看世界、替玩家做推理
- 玩家真正的视觉、听觉、理解、怀疑、判断，发生在系统外的人脑中
- 系统内的 `L1` 负责维持“剧中角色按其站位与状态应感知到什么”
- 系统内的 `L2` 负责维持“剧中角色基于这些输入会出现什么主观状态、内心独白和人格惯性”
- 玩家与系统这两条线是并行关系，不是系统内 `L1/L2` 对玩家真实认知的替代关系

因此更准确的说法是：

- 玩家角色存在“真实人脑认知链”和“剧中角色补全链”两条并行回路
- 前者保证玩家自由与真实思考
- 后者保证角色人格连续性、沉浸感和挂机承接能力

### 2.5 旅人与剧中角色的边界

当前必须明确区分：

- 旅人：玩家本人，拥有 Paralls ID、跨世界资产、穿梭和凝神等 Meta 能力
- 剧中角色：旅人在当前世界中的意志投影，是一个角色智能体实例

因此：

- 角色智能体指的是“剧中角色”，不是“旅人”
- 玩家是在驾驶角色智能体，而不是替代角色智能体存在


玩家角色虽然握着方向盘，但仍依赖角色智能体自动补全下列能力：

- 微表情
- 小动作
- 社交距离调整
- 语音微表现
- 内心独白提示
- 决策建议
- 挂机自主模式

当前采用的边界：

- 这些机制主要由角色自身的 `L2` 和 `L4` 驱动
- 司命只在“冲动”注入时直接影响玩家投影角色

玩家接管边界应明确写成：

- 玩家不接管 `L1/L2` 的底层运行
- 玩家主要接管主动 `L3` 决策与主动 `L4` 执行
- 系统补全的是玩家无法直接操纵的生理、本能、潜意识和表现层

### 2.6 三类玩家侧内心提示

当前必须把三类输出拆开：

- 内心独白：来自 `L2` 的推论、怀疑、情绪和信念变化
- 冲动：来自司命注入后被角色层承接的模糊倾向
- 决策建议：来自 `L3` 候选行动的排序结果

共同规则：

- 默认仅玩家自己可见
- 都不是强制指令
- 都服务于“让玩家理解角色此刻为什么会这样想”

### 2.7 自动补全不是纯表现层特效

自动补全层不只是给角色脸上挂一个表情。

它同时承担：

- 让角色的身体语言持续与内部状态一致
- 让玩家感知到角色自身的人格惯性和压力变化
- 在挂机时把角色维持为保守但连贯的活体

因此，自动补全层应被视为角色智能体的运行时一部分，而不是前端润色插件

### 2.8 透明替身原则

对于玩家投影角色，系统可以存在自动补全层，但不应让玩家主观上觉得“自己和替身是两个人”。

这意味着：

- 系统不应把角色补全层包装成需要玩家主动训练的外置替身
- 玩家看到的应是自己在驾驶角色，而角色的本能、微动作、情绪泄露和保守挂机反应被自然补齐
- 司命若要收集玩家倾向，也应通过自然场景中的提问、回忆和互动完成，而不是跳出成显式训练流程

### 2.9 场景切换不换脑

从剧本内角色到带回后的小世界角色，当前不采用“切模式就换一套陪伴脑”的理解。

当前采用：

- 被带回的小世界角色，仍然是同一个人格形成链下的角色实例
- 她对新世界的接纳、理解、主动提问、关系确认，仍建立在原人格、原关键记忆摘要和原关系结果之上
- 小世界只是同一角色底层运行的场景切换，不是另起一套只会陪聊的壳体

Phase 1 的实现边界同时必须写清：

- 结局后只保留轻量快照，不保留完整长期运行态
- 这份快照至少要足以支撑人格延续、关键记忆摘要、关系结果和基本世界观接纳过程
- 因此 Phase 1 的小世界承接是“同一角色的压缩续接”，不是“把旧角色丢弃后新建一个陪伴 persona”

## 3. 人格形成链

角色智能体的人格不是一组静态标签，而是一条可追溯的形成链。

### 3.1 基因种子

作为最上游输入，至少包含：

- 出身
- 天赋
- 早年关键事件
- 时代 / 地域背景

### 3.2 人生记忆

记录“角色为什么变成现在这样”，包含：

- 关键事件
- 长期生活状态
- 关键人物
- 重大选择
- 核心创伤

### 3.3 品格层

品格层负责角色的内在道德与价值边界。

核心维度包括：

- 诚实
- 忠诚
- 正义感
- 仁慈
- 责任感

除此之外，还需要：

- 价值优先级
- 自我评价
- 理想自我
- 执念

### 3.4 五维人格层

这是行为层的直接倾向输出，核心维度为：

- 胆量
- 心机
- 共情
- 理性
- 社交

当前采用规则：

- 五维人格不是源头，是映射结果
- 理智不是默认值，理性只是五维中的一个维度

### 3.5 目标与恐惧

除人格本体外，角色还需要：

- 目标层级
- 恐惧层级
- 关系偏好
- 核心秘密

它们共同决定角色在局中的行为方向。

### 3.6 会话相关人格参数（v0.1 最小集）

当前需要从人格档案中先冻结一组“会话相关长期参数”，用于影响偷听、接近、加入、隐私保护、被排斥时的反应和会话中的发言风格。

边界规则：

- 这里只放长期倾向和能力参数
- 不放任何当前会话运行态
- 不直接决定成员资格、高阶知识真值或具体知识状态

当前建议的 `Phase 1` 最小集为：

- `base_hearing_sensitivity`：基础听觉敏感度
- `speech_discrimination_under_noise`：噪音下语音分辨能力
- `whisper_capture_ability`：捕捉耳语与压低声音内容的能力
- `social_openness`：对他人接近和加入对话的默认开放程度
- `privacy_sensitivity`：对私密边界与偷听风险的敏感程度
- `stranger_join_tolerance`：对陌生人自然加入会话的容忍度
- `talk_initiative`：主动开口、插话、发起话题的倾向
- `public_speaking_comfort`：在公开场景发言的舒适度
- `deception_control`：在对话中维持伪装和控场的能力
- `anti_eavesdrop_habit`：反偷听习惯，如降声、换位、收紧对话圈
- `pressure_escape_bias`：高压力下转向回避、离开、退开的倾向
- `trust_threshold_for_private_talk`：把别人纳入私密对话所需的信任门槛

这些参数当前主要作用于：

- Per-Character 感知过滤器
- 会话参与状态子模块
- `L2` 理解层
- `L3` 规划层
- `L4` 执行层

但它们不得直接决定：

- 会话成员资格是否成立
- 某条信息的最终知识状态
- 司命高阶知识图谱持有的全局真值

## 4. 四层心智模型

### 4.1 L1 感知层

职责：

- 接收结构化世界事件
- 过滤噪音与越界信息
- 形成角色“此刻应该知道什么”的输入

输入来源：

- 角色专属视觉事件
- 角色专属听觉事件
- 角色专属嗅觉 / 热感 / 触觉事件
- 直接互动结果
- 司命高层消息，如 `impulse`、`fact_reveal`、`opportunity`

约束：

- 不在场不能感知
- 被遮挡、距离过远、状态异常会影响感知质量
- 本层默认不直接消费全局原始世界事件流
- 本层只负责“收到什么”和“感知质量如何”，不负责解释含义

### 4.2 L2 理解层

职责：

- 解释感知结果
- 更新信念
- 评估真实性、相关性和风险
- 生成推论与不确定态
- 更新情绪、压力、信任、怀疑等状态

这是角色“内心独白”和“我现在怎么想”的来源层。

关键边界：

- 可以怀疑、确认、误解，但不能直接替代 `L3` 做行动选择
- 对玩家投影角色而言，本层仍应持续运行，用于生成内心独白、冲动承接和状态更新

### 4.3 L3 规划层

职责：

- 基于动机和当前状态生成候选行动
- 在候选行动间做优先级排序
- 调用三重过滤器做筛选

动机来源主要包括：

- 恐惧驱动
- 目标驱动
- 社交驱动
- 好奇驱动

关键边界：

- `L3` 是“我要做什么”的产生层，不是“我现在如何表现”的输出层
- 对 AI 角色而言，本层全自动运行
- 对玩家投影角色而言，系统可生成候选行动、冲动和决策建议，但主动方向盘主要交给玩家

### 4.4 L4 执行层

职责：

- 生成具体对话
- 生成移动、观察、交互等动作
- 驱动微表情、小动作、站位和语音表现

对玩家角色而言：

- 玩家决定主动行为
- 系统自动补全角色的生理与表现层反馈

关键边界：

- 主动行为与自动表现必须拆开
- 主动行为包括移动、对话、交互、投票、暗杀等直接操作
- 自动表现包括微表情、小动作、社交距离、语音微表现、压力导致的生理泄露

## 5. 三重过滤器与决策约束

所有高风险或关键行为都必须经过三重过滤。

### 5.1 人设过滤器

问题：

- 这个角色“会不会”这样做

作用：

- 防止 OOC
- 防止所有角色被压成同一套最优解

### 5.2 逻辑过滤器

问题：

- 这个行为在时空、能力、信息条件下是否成立

作用：

- 防止超知行为
- 防止物理不可能行为

### 5.3 得失过滤器

问题：

- 这么做对角色自己是否值得

作用：

- 将目标、恐惧、代价和收益拉进同一决策框架

### 5.4 执行顺序与否决机制

当前采用明确的串行否决链：

1. 人设过滤器先判断“这个角色会不会这么做”
2. 逻辑过滤器再判断“这个行为在当前时空和信息条件下是否成立”
3. 得失过滤器最后判断“这样做是否值得”

边界规则：

- 任一层否决，当前候选行动直接丢弃
- 这条链不仅约束 AI 角色自主行为，也约束挂机模式下的系统代打行为
- 对玩家投影角色，系统生成的决策建议必须先过这条链
- 司命注入的冲动也只能成为候选倾向，不能绕过过滤器直接落地成行为

## 6. 感知与记忆链路

### 6.1 感知路线

当前采用结构化语义事件流，而不是截图 + 多模态视觉主路。

原因：

- 更公平
- 更低延迟
- 更低成本
- 更可解释

### 6.2 可感知信息编译层与感知过滤器

先由可感知信息编译层把原始世界事件编译为候选感知事件，再由角色私有感知过滤器裁剪：

- 编译层负责：多感官通道拆分、阶段化标签、候选事件标准化
- 过滤器负责：按角色感官档案、距离、遮挡、朝向、状态、注意力做私有裁剪

### 6.3 感知过滤器

每个角色独立拥有感知过滤器，用于决定：

- 看见什么
- 听见什么
- 对哪些异常更敏感
- 在高压力或特殊状态下忽略什么

它至少应考虑：

- 距离
- 遮挡
- 当前朝向
- 感官档案差异
- 角色状态异常

这条线路对应的是“同源不同路”原则：

- 人类玩家通过渲染画面、空间音频和交互反馈感知世界
- AI 角色通过同一份世界状态计算后的结构化语义事件感知世界
- 两者共享同一套可见 / 可听 / 可交互边界，而不是 AI 额外拥有截图全知视角

### 6.4 阶段化感知与本能反应

当前不能把感知实现成“动作做完后统一广播结果”。

至少应区分：

- 意图阶段：角色产生明显行动前兆
- 执行阶段：动作正在发生
- 完成阶段：动作已经落地并产生结果

关键要求：

- 角色在意图阶段即可收到威胁信号
- 致命级威胁走规则引擎直通路径，而不是等待完整 LLM 回合
- 本能反应目标是 `300ms` 量级，用于支撑躲闪、僵住、呼救、反击等即时反馈

### 6.5 记忆类型

单局内至少需要维护五类记忆：

- 事件记忆：角色亲历了什么，含时间、地点、参与方和结果
- 观察记忆：角色看到或听到他人做了什么、说了什么
- 知识记忆：角色已获得的线索、证据、情报及其可信度状态
- 社交记忆：角色对每个对象的信任、怀疑、好感和风险判断
- 高阶记忆：角色对“谁知道什么”的层级推理

这些记忆不能混成一个统一文本池。

原因：

- 对话生成需要不同检索切片
- 推理和撒谎需要区分“我知道”和“我看见了”
- 结局快照只应抽取其中一部分

### 6.6 知识状态

对单条信息至少支持：

- 未知
- 疑似
- 确认
- 公开

这与司命和信息共享系统的知识模型保持一致。

同时，角色记忆还必须支持高阶知识关系，例如：

- 我知道某人知道了什么
- 我知道某人不知道我已经知道了什么
- 我不确定某人到底看到了多少

### 6.7 会话相关记忆落位

当前不新增一套平行“对话记忆系统”，而是把一场会话拆入既有五类记忆：

- 事件记忆：记录会话何时发生、何时加入、何时退出、是否出现靠近、排斥、转移地点等关键转折
- 观察记忆：记录“我实际听到了什么、看到了什么”，并严格从 `heard_from_ts` 开始裁切
- 知识记忆：记录“我因此知道了什么”，且不得把模糊偷听直接写成确认事实
- 社交记忆：记录“我因此更信任谁、更怀疑谁、谁在排斥我、谁默许我在场”
- 高阶记忆：记录“我知道别人知道我在场”“我怀疑他们不知道我听到了多少”这类主观高阶关系

边界规则：

- 听到不等于理解
- 观察记忆不自动等于知识记忆
- 加入对话不补发更早历史内容
- 高阶记忆是角色主观层，不等于司命持有的全局真值

### 6.8 生命周期边界

当前 Phase 1 采用“单局完整、跨局不继承”的默认边界：

- 单局内五类记忆完整运行
- 剧本结束后不保留完整运行态记忆
- 若触发轻量带走，只抽取人格摘要、关键记忆摘要和关系结果形成快照

### 6.9 与 ESM 的解释边界

角色智能体不负责计算物理世界本身。

当前采用：

- ESM 负责所有可交互实体的物理状态执行，其中也包括角色作为具身实体时的基础体征 / 身体状态结算
- 角色智能体的 `L1` 负责接收经过感知过滤后的相关环境事件
- 角色智能体的 `L2` 负责解释“这意味着什么”，例如把“窗帘燃烧”理解为威胁、异常、证据或逃生信号
- 当 `ESM` 结算角色的伤势、体温异常、中毒、醉酒、缺氧、行动受限、濒死等物理状态后，角色层负责承接这些结果，并将其转化为主观感受、判断偏向和行为变化

因此：

- 角色智能体可以基于物理状态变化进行推理
- 但不能替代 ESM 执行物理模拟
- 文档中不得再写成“角色智能体生成物证”或“ESM负责推理证据意义”
- 也不得再把“角色是否濒死 / 死亡”写成单纯由司命或角色心智主观判定的结果

### 6.10 与事件总线的消息边界

角色智能体与事件总线之间，当前必须区分三层对象：

- 原始世界事件：由 `L1`、`ESM`、交互系统、空间音频等上抛的精确结构化事件
- 角色感知事件：由 Per-Character 感知过滤器基于可感知信息编译层候选事件生成，送入角色 `L1`
- 司命高层消息：由司命发送给角色的高层催化或事实揭示消息

当前采用：

- 角色智能体默认不直接订阅“全局原始世界事件流”
- 角色 `L1` 的标准输入，是过滤后的角色专属感知事件
- 司命发给角色的消息，属于高层附加输入，不等于世界感知本身

因此：

- 角色看到的世界天然带有位置、遮挡、感官差异和状态偏差
- 角色不会因为事件总线存在，就获得超出其物理可知范围的信息
- 司命也不能借消息总线直接把一个低层动作命令塞进角色执行层

### 6.11 司命回写的边界

司命对角色的影响，要在消息接口层被严格收束。

当前允许的典型类型：

- `impulse`：一种模糊冲动或倾向
- `fact_reveal`：一种高层事实揭示
- `opportunity`：一种“你注意到某个机会”的提示

当前不允许：

- 直接下发“去点燃窗帘”“现在就撒谎”“立刻逃跑”这类低层动作指令
- 绕过 `L2` 理解层和 `L3` 规划层，直接改写 `L4` 执行结果
- 绕过三重过滤器把司命意图强行落地成角色行为

换言之：

- 司命可以改变角色面对的叙事张力
- 但不能取消角色的自主解释与自主决策

## 7. 动态状态与自主行为

角色不是静态人格对象，而是持续变化的状态体。

### 7.1 状态分层

当前采用两层状态结构：

- 物理执行状态：由 `ESM` 结算并上报
- 心智解释状态：由角色智能体 `L2` 解释、维护并传给 `L3/L4`

其中，物理执行状态至少包括：

- 受伤 / 疼痛 / 行动受限
- 中毒 / 醉酒 / 致幻等异常身体状态
- 体温异常、缺氧、窒息、溺水等环境致伤结果
- 濒死 / 死亡等生存结算结果

心智解释状态至少包括：

- 压力值
- 信任值
- 怀疑值
- 当前主导情绪
- 对疼痛、寒冷、醉意、毒发、濒死感的主观理解与应对倾向

这意味着：

- “身体发生了什么”优先由 `ESM` 决定
- “我怎么理解这件事、我现在慌不慌、我会不会硬撑或求救”由角色层决定

在此之外，当前补充第三类短时运行态：

- 会话参与状态：由角色层维护“我此刻是否只是偷听、是否已被纳入、是否被排斥、我是从何时开始听到这段会话”

会话参与状态不属于人格档案，也不属于长期关系判断；它是高频变化、强上下文依赖的运行态。

### 7.2 会话参与状态子模块

归属：`动态状态系统 -> 会话参与状态子模块`

职责：

- 维护角色在当前会话中的参与态
- 承接由司命高阶知识图谱确认后的成员资格变化
- 为 `L2/L3/L4` 提供“我此刻是否在场、是否暴露、是否被接纳、是否该沉默或接话”的运行时输入

建议状态枚举：

- `overhearer`
- `candidate_member`
- `passive_member`
- `active_member`
- `excluded`
- `rejoin`

建议最小字段族：

- 当前主会话引用
- 当前参与状态
- `heard_from_ts`
- `member_from_ts`
- 隐私压力
- 暴露风险
- 最近排斥信号状态

边界规则：

- 听见不等于加入
- 沉默者可以是成员
- 偷听成功不自动获得成员资格
- 成员资格依赖空间接入事实、司命确认的互相知晓以及未被排斥三件事共同成立

### 7.3 字段分层表（角色侧冻结）

会话相关字段在角色智能体侧必须继续分层，避免把总线公共信封、司命确认结果、角色本地运行态和记忆沉淀混成一份状态包。

#### 角色本地会话状态字段

以下字段属于角色本地运行态，应由“会话参与状态子模块”维护，而不是作为总线公共信封共享：

- `primary_conversation_id`
- `conversation_role_state`
- `heard_from_ts`
- `member_from_ts`
- `knowledge_confirm_level`
- `privacy_pressure`
- `exposure_risk`
- `exclusion_signal_state`
- `join_path`
- `speech_entitlement`
- `attention_focus_in_conversation`
- `active_conversation_refs`

这层回答的是：

- 我现在在这场会话里是什么身份
- 我从何时开始听到
- 我是否觉得自己已被纳入
- 我此刻有多暴露、敢不敢开口

#### 记忆沉淀字段

以下内容不应放进短时运行态，而应拆入既有五类记忆：

- 会话发生时间、地点、参与方变化
- 我实际听到的片段、关键词、情绪和语气
- 我因此确认或怀疑的知识
- 我对相关角色信任 / 怀疑 / 威胁感的变化
- 我认为别人知道什么的主观高阶关系

这层回答的是：

- 这场会话结束后，我记住了什么

#### 不应出现在角色本地会话状态中的字段

以下内容不应直接放在角色本地会话状态模块中：

- 全局高阶知识真值
- 其他角色完整知识图谱
- 整段对话完整公共原文历史
- 由 `L1` 才能确认的底层物理事实原始流

边界强调：

- 角色本地会话状态只保存“我此刻在会话里处于什么位置”
- 记忆系统保存“这场会话结束后我沉淀了什么”
- 司命持有的全局高阶知识真值不直接下放为角色本地状态

### 7.4 当前冻结的状态链

工程上应采用一条稳定映射链：

- `L1 / 交互系统 / 环境系统` 产生精确世界事件
- `ESM` 结算物理后果，更新角色具身状态
- 事件总线把相关结果送入可感知信息编译层，再进入 Per-Character 感知链路
- 角色 `L2` 把这些结果解释为疼痛、危险、虚弱、暴露、可利用机会或证据意义
- `L3` 读取解释后的状态，改变行动倾向
- `L4` 将这些状态映射到微表情、小动作、站位、语音参数和具体行为

因此：

- `ESM` 决定角色是否真的受伤、变冷、醉酒、中毒、失去行动能力
- 角色层决定角色是否嘴硬、慌乱、强撑、求救、迁怒、撒谎或突然坦白

### 7.5 濒死与死亡判定链

`297-298` 给出了“角色状态不是单一情绪条”的重要素材，但其中把司命直接纳入生存判定的说法，必须被 `302-304` 与 `400` 的后续边界覆盖。

当前采用：

- 濒死 / 死亡首先是物理结算结果，不是纯叙事判词
- `ESM` 根据伤势、缺氧、失温、中毒、火灾、坠落等物理与体征条件，结算角色是否进入濒死或死亡
- 角色 `L2` 负责把这一结果解释为恐惧、求生、麻木、遗憾、崩溃或最后的执念
- 司命只能在该结果已成立后，围绕其产生后续叙事催化、信息扩散和冲突再分配

运行时应至少区分：

- 存活：角色完整参与常规心智循环
- 濒死：角色进入受限决策态，行动能力、表达能力和感知能力可被显著压缩
- 死亡：角色停止常规主动决策，不再作为正常行动主体运行

死亡之后：

- 角色不再继续正常 `L3` 规划与 `L4` 主动执行
- 遗体、残留状态和相关痕迹由 `ESM + 证据链相关系统` 继续管理
- 死者生前的记忆、关系和说法只作为已存在信息资产继续被他人发现、讨论或验证

### 7.6 Phase 1 的状态范围收束

`297-298` 中曾展开过较完整的生理 / 生存状态网络，但 `400` 之后不能把它整体误写成 Phase 1 当前必做项。

当前 Phase 1 需要优先冻结的是与悬疑叙事和环境博弈直接强相关的状态：

- 受伤与行动受限
- 中毒 / 醉酒 / 致幻等会直接改变可玩性的异常状态
- 失温、火灾、缺氧、溺水等环境致伤 / 致死链
- 濒死 / 死亡结算及其表现后果

而以下内容当前只保留为可扩展方向，不应默认写成 Phase 1 的完整持续系统：

- 长周期饥饿 / 口渴 / 代谢模拟
- 长康复周期与复杂后遗症
- 跨天级的完整生理生活维持系统

### 7.7 临界行为

当状态突破临界值时，角色可能：

- 崩溃坦白
- 逃跑
- 冲动伤害
- 自保性撒谎
- 极端沉默
- 因失温、疼痛、醉意或毒发而做出不理性的短时应激反应

这些行为不应视为异常，而应视为状态驱动的合理结果。


### 7.8 伪装的本质

伪装不是“说一句谎”，而是角色在世界内构建了一套与真实身份并行的对外版本。

### 7.9 公开档案与真实档案

角色至少区分：

- 真实档案
- 公开档案

伪装就体现在两者的差异上，例如：

- 身份伪装
- 经历伪装
- 不在场证明伪装
- 动机伪装

### 7.10 伪装能力来源

由以下因素共同决定：

- 人生记忆中的欺骗经验
- 品格层中的诚实倾向
- 五维人格中的心机、理性、共情
- 当前压力状态

### 7.11 伪装压力

伪装会积累压力，压力越高：

- 语言越容易偏离
- 小动作越容易暴露
- 逻辑维持越困难
- 崩溃或极端行为概率越高

### 7.12 破绽来源

破绽主要来自：

- 用词和句式偏离
- 行为习惯异常
- 时间线矛盾
- 空间矛盾
- 信息自相矛盾


角色智能体必须能发起而非只响应行为。

主要行为类型包括：

- 自主移动
- 主动对话
- 物品交互
- 跟踪与观察
- 信息共享
- 信息隐藏
- 社交操控
- 应急反应

关键要求：

- 角色要有自己的节奏和偏好
- 不需要被玩家点到才“活”

### 7.13 自主行为的输出范围

自主行为不仅包括开口说话，还包括：

- 主动靠近或回避某人
- 围绕目标进行观察、试探、跟随
- 主动共享或刻意隐瞒信息
- 在高压力下寻找角落、出口或庇护位置
- 在关系足够稳定时主动建立合作

### 7.14 挂机自主模式

当玩家持续未操作达到阈值后，当前采用“保守接管”：

- `L1/L2/L4` 持续运行
- `L3` 的方向盘临时交还系统
- 行为目标从“推进个人战略”切换为“维持角色鲜活且避免玩家后悔”

允许：

- 基础移动
- 观察环境
- 简短被动回应
- 保守自保

不允许：

- 主动推进关键对话
- 主动展示或使用关键物品
- 暗杀或其他不可逆高风险行为
- 替玩家完成关键博弈决策

### 7.15 回归同步

玩家回归后应立即完成三件事：

- 交还主动控制权
- 生成挂机期间简报
- 将挂机期间经历同步写入角色记忆

这样做的目标是保证叙事连续，而不是让系统替玩家“继续玩下去”

### 7.16 运行时主循环

角色智能体不是被点名才醒来的“对话盒子”，而是在整局中持续循环运行。

典型主循环包括：

- 接收本角色此刻可感知的结构化事件
- 更新记忆、情绪、压力、怀疑和关系状态
- 生成观察、靠近、回避、试探、分享、隐瞒、搜查等候选行动
- 通过三重过滤器排序并选择当前动作
- 将对话、移动、交互、微表情和语音参数输出到执行层
- 把关键行动结果写回事件总线，并供司命和其他角色继续感知

这也是为什么角色智能体必须被视为运行时演员，而不是静态角色档案。

## 8. 接口契约

后续任何文档提到角色智能体，都应默认采用以下口径：

- 角色智能体不是黑盒对话器，而是四层心智结构
- AI 角色与玩家投影角色统一底层，只是驾驶模式不同
- 玩家真实认知发生在人脑中；系统内 `L1/L2` 负责角色连续性与主观补全，不替代玩家思考
- 玩家自由不等于系统退场；系统仍持续补全角色的表现与潜意识层
- 深层沉浸机制主要由角色自身 `L2/L4` 驱动，司命只负责冲动式催化
- 角色智能体是角色级决策核心，不是对话壳
- 五维人格不是源头，而是上游人生与品格的映射结果
- 所有关键行为都受三重过滤器约束
- 旅人不是角色智能体，剧中角色才是
- Phase 1 的角色智能体不是缩水版 NPC，而是单局完整版
- 单局记忆至少拆为事件、观察、知识、社交、高阶五类
- 感知采用“结构化语义事件 + 可感知信息编译层 + Per-Character 感知过滤器 + 阶段化感知链路”
- 角色默认接收过滤后的感知事件，而不是全局原始事件流
- 司命回写角色的只能是高层消息，不能直接控制低层动作
- 带走后的小世界角色仍是同一角色底层的压缩续接，不是新建陪伴壳体
- 挂机模式是保守接管，不是停机，也不是自动代玩通关

## 9. Phase 1 范围与延后项

### 9.1 Phase 1

当前采用口径：

- 单局完整版角色智能体已进入 Phase 1
- 具备完整人格档案、四层心智模型、三重过滤器、动态状态、结构化感知和单局记忆
- 玩家投影角色也走统一底层
- 结局后允许为轻量带走机制保存角色快照和关系结果

已经在 Phase 1 前置的角色层深度能力还包括：

- 微表情与小动作自动驱动
- 社交距离自动调节
- 内心独白提示
- 决策建议
- 挂机自主模式

当前不进入 Phase 1 的：

- 完整跨剧本长期记忆继承
- 完整资产化与跨剧本复用
- 大规模群体角色模拟
- 跨世界压制与同伴经营 AI

不再采用 `263` 中的以下窄化理解：

- “Phase 1 角色局结束即彻底归零，连轻量带走后承接都没有”
- “司命在角色层只做后台监控，不承担完整单局导演职责”
- “微表情、小动作、内心独白、决策建议、挂机模式只是后续增强”

### 9.2 Phase 2

主要新增：

- 跨剧本记忆继承
- 智能体资产化
- 系列剧本中的续集承接
- 轻量级交互角色扩展

### 9.3 Phase 3

主要新增：

- 群体模拟层
- 按需注入角色
- 跨世界压制
- 同伴经营 AI
- 更宏观的角色生命周期管理


当前不在本文件冻结范围内：

- 玩家 Meta 身份系统的完整产品设计
- 凝神能力的完整交互稿
- Phase 3 群体模拟算法细节
- 角色智能体经济系统与私房钱机制
- 记忆遗忘、错误记忆、长期心理健康、梦境与人格成长等更长周期演化细节

### A.2 冻结结论

- 角色智能体是完整自主角色驱动核心，不是普通 NPC、对话树或简单行为树
- 人格采用“基因种子 → 人生记忆 → 品格层 → 五维人格 → 决策系统”单向推导

- AI 角色与玩家投影角色共享同一套底层心智结构，区别只在高层决策权归属
- 玩家角色不是“完整 AI 对等运行”也不是“纯手动壳体”，而是“玩家大脑 + 系统自动补全层”的混合驾驶模式
- 玩家真实的感知、理解、推理与主动决策发生在系统外的人脑中；系统内 `L1/L2` 对玩家角色的意义是维持剧中角色状态连续性与第一人称补全，不是替代玩家思考
- 角色智能体默认不直接消费全局原始事件流，而是消费“可感知信息编译层 + Per-Character 感知过滤器”处理后的角色专属感知事件
- 内心独白、司命冲动、决策建议是三类不同来源，不能混成一个“提示层”
- 挂机不是停机，也不是代打通关，而是保守自主接管
- Phase 1 采用“单局完整版角色智能体 + 轻量陪伴后承接”的口径，不退回到早期过窄版本
- 剧本内角色、带走后的小世界角色、后续承接态沿用同一人格与心智底层；Phase 1 只保留轻量快照，不保留完整长期运行态

当前采用：

- 再映射出品格层和人格层
- 最后由这些约束运行时决策

- `224-227` 再把玩家真实感知 / 理解、系统自动补全、剧中角色实例三者拆清
- `320` 说明这一自动补全层在体验上必须保持透明，不能让玩家觉得自己在操作另一个替身

  - 感知接入器
  - Per-Character 感知过滤器
  - 本能反应规则引擎（致命威胁快速路径）
- `L2` 理解层：
  - 真实性评估
  - 相关性评估
  - 推论生成
  - 信念更新
  - 不确定态管理
- `L3` 规划层：
  - 动机驱动引擎
  - 候选行动生成器
  - 三重过滤器
  - 优先级排序器
- `L4` 执行层：
  - 语音通道
  - 表情通道
  - 动作通道
  - 社交距离通道
  - 生理状态通道

说明：

- 该补充仅细化“怎么分工”，不改变“统一底层 + 两种驾驶模式”的主口径

### C.2 被感知输出面补充（L4 五通道）

补充“角色行为输出面”的固定口径：

- 五通道并行输出，共同反映同一时刻内部状态
- 通道间允许参数耦合，但不得相互覆盖掉主决策
- 上抛层面保持原始事实语义，不把主观解释混入 `L1` 上抛事件

执行边界：

- `L4` 输出表现
- `L1` 渲染与上抛事实
- `L2/L3` 仍是解释和决策层

### C.3 动态状态与社交参数补充

补充可执行但不冲突的状态参数口径：

- 压力值
- 信任值 / 怀疑值
- 主导情绪
- 异常状态（醉酒、中毒、失温、缺氧等）

这些参数的职责保持不变：

- 物理发生与结算由 `ESM` 决定
- 角色层负责把结算结果转化为主观理解与行为倾向

### C.4 感知闭环补充

补充运行时闭环：

`他者行为输出（L4） -> L1 原始感知事实上抛 -> 编译层候选事件 -> Per-Character 私有裁剪 -> 角色感知事件 -> 角色理解与规划`

边界强调：

- 角色默认消费“私有感知事件”，而非“全局原始事件流”
- 司命回写仍只能是高层消息，不直控低层动作
