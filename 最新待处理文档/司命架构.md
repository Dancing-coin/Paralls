## 三、Harness 编排框架

Harness是司命的“大脑中枢”，负责所有任务的分级、排队、兜底和延迟控制。

### 3.1 任务分级器

| 优先级 | 事件类型 | 延迟上限 | 处理通道 | 执行者 |
| :--- | :--- | :--- | :--- | :--- |
| **P0 致命** | 暗杀条件检测、暗杀弹窗推送、致命威胁响应 | <50ms | P0直连通道（内存队列） | 规则程序 |
| **P1 紧急** | 事实核心记录、知识图谱更新、天平基础评估、L1/L3预设联动 | <200ms | P1规则通道 | 规则程序 |
| **P2 重要** | 干预决策、冲突分析、L3调度（戏剧价值评估）、结局预测 | <3000ms | P2 LLM通道 | 大模型 + 规则校验 |
| **P3 普通** | 环境催化决策、氛围渲染、非关键视觉增强 | <5000ms | P3降级通道 | 大模型/丢弃 |

### 3.2 队列管理器

| 孙系统 | 核心职责 |
| :--- | :--- |
| **抢占管理器** | P0任务跳过所有队列，直接插入执行。多P0任务按时间戳排序 |
| **优先级队列** | P1/P2/P3分级排队。同优先级按时间戳FIFO。P2任务可被更高优先级的P2任务插队 |
| **过期丢弃器** | 检测消息TTL。若消息在队列中停留超过TTL，自动丢弃，不再投递 |

### 3.3 兜底降级器

| 孙系统 | 核心职责 |
| :--- | :--- |
| **LLM超时回退器** | LLM推理超过硬上限时，降级为规则程序兜底。P2超时→使用预设简化方案；P3超时→直接丢弃 |
| **规则兜底策略库** | 存储所有可降级任务的预设简化方案。如“若LLM无法在3秒内生成干预决策，则随机选择一个弱势方AI发送模糊冲动” |

### 3.4 时延守卫器

| 孙系统 | 核心职责 |
| :--- | :--- |
| **延迟监控器** | 持续监控每个任务的端到端延迟。P0>50ms→告警；P2>3000ms→触发降级 |
| **熔断触发器** | 连续3次LLM超时→自动熔断，所有P2/P3任务降级为规则程序兜底，直到LLM恢复 |


## 四、五个核心子系统

### 4.1 事实核心

| 维度 | 说明 |
| :--- | :--- |
| **核心职责** | 存储并守护游戏中所有不可变事实与已锁定事实 |
| **事实锁定时间线管理** | T0（剧本创作）→T1（房间创建）→T2（玩家加入）→T3（游戏中）四阶段事实锁定流程 |
| **逻辑一致性检查** | 所有角色言行与事实库比对，矛盾时标记并阻止。运行方式：规则程序，<50ms |
| **矛盾记录** | 两个角色说法矛盾时，标记为“待解决矛盾”，成为推理线索 |
| **信息泄露防护** | 确保角色智能体不能说出其未知的信息 |
| **证据链比对** | 比对物品流转追踪器、接触痕迹管理器、生物痕迹管理器与角色声称，标记时间线矛盾 |
| **写权限** | 仅司命拥有对事实库的写权限 |

### 4.2 天平系统

| 维度 | 说明 |
| :--- | :--- |
| **核心职责** | 实时监测游戏态势，防止出现碾压性优势或僵局 |
| **监测指标** | 线索分布均衡度（关键线索是否过度集中于某一方）；阵营胜率预测（基于已揭露事实模拟投票结果）；玩家参与度（是否有玩家被边缘化）；游戏节奏（推理进度过快或过慢） |
| **运行方式** | P1规则通道（数值计算）+ P2 LLM通道（叙事评估） |
| **输出** | 失衡警报 + 干预建议，发送给干预执行器 |

### 4.3 冲突与案件生成器

| 维度 | 说明 |
| :--- | :--- |
| **核心职责** | 检测角色间动态冲突，条件满足时生成新案件 |
| **检测类型** | 目标冲突（两个角色的目标层级产生不可调和矛盾）；机会窗口（某角色获得作案机会——独处、凶器在旁）；秘密濒临暴露（角色的核心秘密即将被揭穿） |
| **生成流程** | 动机评估（调用角色的目标/恐惧层级）→ 能力评估（物理空间中的可行性）→ 人格过滤（该角色真的会这么做吗？）→ 叙事价值评估（是否让故事更有趣而非更混乱）→ 通过后锁定为新事实 |
| **运行方式** | P1规则通道（检测）+ P2 LLM通道（评估） |

### 4.4 高阶知识图谱引擎

| 维度 | 说明 |
| :--- | :--- |
| **核心职责** | 维护所有参与者“知道什么”以及“知道别人知道什么”的动态模型 |
| **数据结构** | 节点（游戏中的事实）；边（角色对事实的知识状态：未知/疑似/确认/公开）；高阶边（A知道B知道X、A不确定B是否知道X） |
| **知识传播规则** | 公开对话/展示→清晰区内所有角色标记为“公开”；私密对话/耳语→仅对话对象标记为“确认”；带人查看→跟随者标记为“确认”；偷听→偷听者标记为“疑似” |
| **运行方式** | P1规则通道（<100ms） |
| **推理接口** | 角色智能体决策时，可调用图谱获取其视角下的高阶知识 |

### 4.5 干预执行器

| 维度 | 说明 |
| :--- | :--- |
| **核心职责** | 将天平系统的失衡警报转化为具体干预行动 |
| **四层干预阶梯** | Lv1 智能体冲动（向NPC发送模糊行为倾向）；Lv2 环境催化（改变场景状态）；Lv3 NPC引导（向NPC发送确凿信息）；Lv4 节奏控制（触发新事件调整游戏阶段） |
| **干预原则过滤器** | 间接性（是否直接控制玩家？）；不可见性（是否会被玩家感知为“系统干预”？）；逻辑自洽性（是否有合理的故事内解释？）；公平性（是否偏袒某一方？） |
| **运行方式** | 原则过滤：P1规则通道；干预决策：P2 LLM通道 |
