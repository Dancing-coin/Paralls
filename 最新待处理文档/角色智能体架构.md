## 二、人格档案（静态核心）

人格档案是角色智能体的“出厂设置”，定义了角色是谁、为什么会这样、以及能做什么。它在剧本加载时从配置中读取，运行时基本不变。

| 层级 | 内容 | 说明 |
| :--- | :--- | :--- |
| **基因种子** | 出身、天赋、早年关键事件 | 人格的起点，由创作者在编辑器中配置 |
| **人生记忆** | 由基因种子模拟生成的完整成长经历——关键事件、长期状态、创伤、重大选择 | 记录性格是如何一步步形成的 |
| **品格层** | 道德取向（诚实/忠诚/正义感/仁慈/责任感，各0-10）；价值优先级（当道德取向冲突时的选择顺序）；自我认知（如何看待自己、理想自我、核心创伤、执念） | 为角色划定行为的“红线”和“最高追求” |
| **行为层** | 五维人格参数（胆量/心机/共情/理性/社交，各0-10）；语言风格配置（称谓习惯、句式特征、话题偏好、撒谎时的特征、情绪表达方式）；行为禁忌（绝对不能做的事项列表） | 决定“怎么做” |
| **能力定义** | 暗杀能力等级（L0-L4）；特殊技能（开锁、医术、法术等）；知识领域（角色擅长或了解的领域） | 角色能做什么 |
| **表现映射规则** | 撒谎特征（如华生：耳朵红、语句断断续续）；紧张特征（如华生：手指在裤缝上摩擦）；愤怒特征；开心特征 | 驱动L4执行层的自动化表现 |


## 三、心智模型（四层决策架构）

心智模型是角色智能体的“运行时引擎”，驱动角色从感知到行动的完整决策链。

### 3.1 L1 感知层

**核心职责**：接收外界刺激，按角色的生理限制和认知能力进行私有化筛选，生成角色专属的感知事件。

#### 感知接入器

| 维度 | 说明 |
| :--- | :--- |
| **核心职责** | 接收`可感知信息编译层`输出的候选感知事件，作为感知过滤器的统一输入 |
| **输入来源** | L2 可感知信息编译层（通道编译器→上下文融合器→阶段标签器→跨通道融合器） |
| **输入内容** | 多感官候选感知事件（含融合感知事件），不直接接收原始世界事件 |
| **输出目标** | Per-Character 感知过滤器 |

#### Per-Character 感知过滤器

| 维度 | 说明 |
| :--- | :--- |
| **核心职责** | 按角色的感官档案筛选候选感知事件，生成角色专属感知事件 |
| **关键设计** | 每个角色实例独立运行，保证信息不对称的真实性 |
| **感官档案管理器** | 存储角色的视觉范围、听觉灵敏度、触觉范围、热感范围、嗅觉范围、特殊感官（回声定位、灵力感知等）。盲人角色的视觉档案直接禁用 |
| **空间范围检测器** | 检测感知事件的发生位置是否在角色的该感官范围内。不在范围→丢弃。门/墙遮挡→衰减 |
| **状态修正器** | 根据角色当前状态修正感知精度。醉酒→感知延迟+模糊化；致幻→可能生成虚假感知；专注→非注意方向感知减弱 |
| **注意力分配器** | 模拟人类注意力的有限性。对话中→注意力集中在对话对象；检查物品→注意力集中在物品；空闲→注意力均匀分布 |
| **专属感知生成器** | 将通过所有筛选的事件，转化为角色可理解的自然语言描述，输出给感知接入器→L2理解层 |

#### 本能反应规则引擎

| 维度 | 说明 |
| :--- | :--- |
| **核心职责** | 对P0致命威胁（暗杀意图）进行<300ms的本能反应 |
| **触发条件** | 感知过滤器接收到`action_intent`（意图阶段）事件 |
| **反应类型** | 反击/闪避/呼救/逃跑/僵住——由人格参数（胆量、理性）决定 |
| **技术实现** | 纯规则引擎，不经过LLM推理，硬实时 |


### 3.2 L2 理解层

**核心职责**：解读感知信息的含义，更新信念，生成推论。

| 组件 | 核心职责 |
| :--- | :--- |
| **真实性评估** | 对方的话可信吗？是谎言还是误会？通过交叉比对已有知识和微表情信号来判断 |
| **相关性评估** | 这条信息与我的目标/秘密/恐惧相关吗？相关度越高，注意力权重越大 |
| **推论生成器** | 基于已有知识和新信息，推论出新结论。如“华生手上沾了红墨水→他刚才在书房写东西” |
| **信念更新器** | 将确认信息写入知识记忆，更新信任值/怀疑值 |
| **不确定态管理器** | 对无法确认的信息标记为“疑似”。如“我隐约听到隔壁有人在争吵——不确定是谁” |
| **内心独白生成器** | 输出角色视角的第一人称思考。如“华生的手上有红墨水……他刚才说自己在休息。”——仅人类玩家可见 |


### 3.3 L3 规划层

**核心职责**：基于当前信念和目标，生成候选行动方案，经过人格过滤后选定最优方案。

#### 动机驱动引擎

| 动机来源 | 优先级 | 说明 | 示例 |
| :--- | :--- | :--- | :--- |
| **恐惧驱动** | 最高 | 当恐惧层级中的某一项被触发时，采取避险行动 | 秘密濒临暴露→逃跑/销毁证据/灭口 |
| **目标驱动** | 高 | 为达成目标层级中的目标而主动行动 | 找出真相→搜证/质问/结盟 |
| **社交驱动** | 中 | 基于信任/怀疑值，维护或改善与他人的关系 | 与盟友分享信息、对敌人保持距离 |
| **好奇驱动** | 低 | 对新信息的探索欲，在无明确任务时保持活跃 | 独自探索未去过的房间 |

#### 候选行动生成器

基于当前信念和人格，生成多个可能的行动方案。如被质问时：①撒谎否认 ②部分坦诚 ③转移话题 ④反质问对方。

#### 三重过滤器

| 过滤器 | 检查内容 | 不通过示例 |
| :--- | :--- | :--- |
| **人设过滤器** | 这个角色“会”这么做吗？ | 胆小如鼠的管家不会主动挑战凶手 |
| **逻辑过滤器** | 这个行为在故事里“合理”吗？（能力/时空/信息逻辑） | 不知道书房在哪的人不能说“我去过书房” |
| **得失过滤器** | 这么做对角色自己“有利”吗？（目标层级+恐惧层级计算） | 如果撒谎的代价比坦诚更大，角色会选择坦诚 |

#### 优先级排序器

对通过过滤器的方案，按动机优先级（恐惧>目标>社交>好奇）和预期收益进行排序。

#### 决策建议输出器

为人类玩家提供“如果由AI自主决策会怎么选”的参考。可关闭。


### 3.4 L4 执行层

**核心职责**：将选定的行动方案转化为具体的行为输出。五个通道在同一帧内并行下发，所有通道的参数来自L2理解层和L3规划层的统一内部状态。

#### 语音通道

| 维度 | 说明 |
| :--- | :--- |
| **驱动方式** | TTS参数注入（情绪标签、撒谎意图、压力值） |
| **下发参数** | 语速（加快/减慢）、声调（升高/降低）、停顿模式（正常/断续）、音量（正常/耳语/呼喊）、气息（平稳/急促/颤抖） |
| **对应的上抛器** | 听觉事实上抛器 |

#### 表情通道

| 维度 | 说明 |
| :--- | :--- |
| **驱动方式** | 形态键混合（Blend Shapes） |
| **下发参数** | 基础表情：喜怒哀乐惊恐惧（形态键权重0-1）；微表情：耳朵红、眼神飘移、嘴唇微颤（叠加在基础表情上）；眼神：注视/回避/长时间注视（IK眼球追踪） |
| **对应的上抛器** | 视觉事实上抛器（微表情子类） |

#### 动作通道

| 维度 | 说明 |
| :--- | :--- |
| **驱动方式** | 骨骼动画（Animation Tree） + IK逆向运动学 |
| **下发参数** | 大动作：行走/奔跑/坐/站/挥手/拍桌/拥抱（由L3规划层主动决策）；小动作：绞手指/整理袖口/撩发/抖腿（由情绪标签和压力值自动触发）；手势：指向/招手/握拳（由对话内容和情绪驱动） |
| **对应的上抛器** | 视觉事实上抛器（小动作子类）、角色状态事实上抛器 |

#### 社交距离通道

| 维度 | 说明 |
| :--- | :--- |
| **驱动方式** | 空间行为参数（信任值/怀疑值/好感度） |
| **下发参数** | 距离：亲密(0-1.5m)/社交(1.5-3m)/疏远(3m+)；身体朝向：正面/侧身/背对；眼神接触：注视/回避/长时间凝视；特殊行为：挡在他人面前、跟随、躲避 |
| **对应的上抛器** | 社交距离与空间行为上抛器 |

#### 生理状态通道

| 维度 | 说明 |
| :--- | :--- |
| **驱动方式** | 粒子特效 + 着色器 + 骨骼微动 |
| **下发参数** | 发抖（骨骼抖动，幅度与寒冷/恐惧正相关）；出汗（皮肤着色器调整，压力>5时触发）；面色潮红/苍白（着色器调整）；呼吸起伏（骨骼微动，频率与压力值正相关）；嘴唇发紫（着色器调整，体温过低时触发） |
| **对应的上抛器** | 生理状态事实上抛器 |


## 四、记忆系统（动态存储）

记忆系统是所有经历的持久化存储，随游戏进程不断增长。

| 记忆类型 | 内容 | 更新方式 |
| :--- | :--- | :--- |
| **事件记忆** | 我亲身经历的所有事件（时间戳+地点+事件描述+涉及人物） | 实时添加，永不删除 |
| **观察记忆** | 我看到/听到的他人言行（谁在何时何地做了什么/说了什么） | 实时添加 |
| **知识记忆** | 我获得的线索、证据、情报（含知识状态：疑似/确认） | 实时添加，可升级（从“疑似”到“确认”） |
| **社交记忆** | 我对其他每个参与者的信任值、怀疑值、好感度 | 根据互动实时更新 |
| **高阶记忆** | 关于“他人知道什么”的推理（二阶、三阶知识） | 基于观察和推理实时更新 |


## 五、动态状态管理

角色的实时状态，直接影响行为决策。

| 状态参数 | 范围 | 影响 | 变化因素 |
| :--- | :--- | :--- | :--- |
| **压力值** | 0-10 | 高压力降低“理性”维度，增加冲动行为概率，触发撒谎特征 | 被质疑、秘密接近暴露、时间紧迫 |
| **信任值** | 针对每个对象（-10到10） | 影响信息分享意愿和合作倾向 | 对方的言行一致性、是否帮助过自己 |
| **怀疑值** | 针对每个对象（0-10） | 影响对他人信息的采信度 | 对方的行为反常、被他人指证 |
| **情绪标签** | 当前主导情绪（紧张/愤怒/悲伤/兴奋等） | 影响决策偏向和语言风格 | 由事件触发（如被背叛→愤怒） |
| **特殊状态** | 中毒/醉酒/致幻/PTSD等 | 影响感知精度、行为倾向、决策质量 | 由物品使用或事件触发 |

## 八、人类玩家与AI角色的区别

人类玩家的角色在底层使用**同一套架构**，唯一的区别在于：

| 层级 | AI角色 | 人类玩家 |
| :--- | :--- | :--- |
| **L1 感知层** | 系统自动运行感知过滤器 | 系统自动运行感知过滤器，同时玩家通过3D渲染画面和空间音频直接感知世界 |
| **L2 理解层** | 系统自动生成内心独白和推论 | 系统自动生成内心独白和推论提示，但玩家的大脑独立进行推理 |
| **L3 规划层** | AI自主决策 | **方向盘交给玩家**。系统生成决策建议和冲动（可关闭），由玩家自主决定 |
| **L4 执行层** | AI自动执行 | 玩家主动操作移动、对话和交互。微表情、小动作、社交距离、语音微表现仍由系统自动驱动 |
| **特殊能力** | — | 凝神能力（单人/AI模式下暂停时间）、挂机自主模式（长时间未操作时L3交还AI） |


## 九、与司命的协作接口

角色智能体通过**事件总线**与司命协作，接口是双向的：

**司命 → 角色智能体**：
- `impulse`（冲动）：模糊的行为倾向，如“你开始怀疑XX”。角色自主决定是否响应
- `fact_reveal`（事实披露）：告知角色其本应知道的事实
- `opportunity`（机会提示）：暗杀等高风险行为的机会窗口信息

**角色智能体 → 司命**：
- `action_report`（行为报告）：角色执行任何交互后上报
- `request_intervention`（请求干预）：角色陷入困境时可请求建议，仅限AI角色，且司命不一定响应

**核心原则**：司命只催化，不控制。角色的所有行为最终由其自身的心智模型决定。


**一句话总结**：角色智能体由人格档案（静态核心）、四层心智模型（L1感知层→L2理解层→L3规划层→L4执行层，五个并行下发通道）、记忆系统（动态存储）、动态状态管理和能力组件构成。感知过滤器是L1感知层内部的私有组件，确保每个角色只感知到其感官范围内、符合其生理限制的信息。L4执行层的五个通道在同一帧内并行下发，所有参数来自统一的内部状态，确保复合表现的一致性和同步性。人类玩家与AI角色共享同一套架构，唯一的区别在于L3规划层的“方向盘”归属。
