### 1.2 L1 部分：感知事实上抛器（八类）

**归属**：L1 确定性空间层 → 交互系统族 → 客户端交互系统

**核心职责**：将3D物理世界中的所有可感知现象，转化为结构化的事件数据，提交给事件总线。这是整个感知链路的起点。

#### 视觉事实上抛器

| 维度 | 说明 |
| :--- | :--- |
| **监听内容** | 角色视野范围内所有可见对象的状态变化 |
| **上报字段** | 对象ID、对象类型、对象名称、相对位置、距离、显著特征（如“面色苍白”、“右手有血迹”）、光照条件、遮挡状态 |
| **触发条件** | 对象进入/离开视野、对象状态变化（受伤、倒地、持有物品变更）、对象外观变化（服装更换、血迹出现） |

#### 听觉事实上抛器

| 维度 | 说明 |
| :--- | :--- |
| **监听内容** | 角色听觉范围内所有声音事件 |
| **上报字段** | 声源ID、声源名称、声音类型、原始内容（如果是对话）、声源位置、与听者的距离、方向、物理遮挡情况、环境噪音水平 |
| **触发条件** | 任何角色或物体发出声音 |

#### 触觉事实上抛器

| 维度 | 说明 |
| :--- | :--- |
| **监听内容** | 角色触觉范围内的物理接触和振动事件 |
| **上报字段** | 接触源ID、接触类型（轻拍/碰撞/推搡/握手/触摸物品）、接触位置（身体部位或物品位置）、接触力度、表面材质触感（粗糙/光滑/冰冷/温热） |
| **触发条件** | 角色主动触摸物品、被其他角色触碰、感受到地面振动 |

#### 热感事实上抛器

| 维度 | 说明 |
| :--- | :--- |
| **监听内容** | 角色热感范围内的温度异常源 |
| **上报字段** | 热源ID、热源类型（人体/火焰/热饮/壁炉/冷源）、温度强度、距离、方向、是否被物体遮挡 |
| **触发条件** | 角色进入热源的热感范围、热源温度变化 |

#### 嗅觉事实上抛器

| 维度 | 说明 |
| :--- | :--- |
| **监听内容** | 角色嗅觉范围内的气味源 |
| **上报字段** | 气味类型（血腥味/香水/烟雾/药物/腐败/食物）、气味强度、来源方向、距离、是否被气流影响 |
| **触发条件** | 气味源产生、角色进入气味扩散范围、气流方向变化 |

#### 生理状态事实上抛器

| 维度 | 说明 |
| :--- | :--- |
| **监听内容** | 角色自身或他人可被观察到的生理状态变化 |
| **上报字段** | 状态类型（发抖/出汗/脸色苍白/呼吸急促/踉跄）、状态强度、可被观察到的部位（面部/手部/全身）、触发原因（寒冷/恐惧/受伤/醉酒） |
| **触发条件** | 角色生理状态参数超过阈值（体温过低、压力过高、伤势加重） |

#### 社交距离与空间行为上抛器

| 维度 | 说明 |
| :--- | :--- |
| **监听内容** | 角色之间因社交关系变化而产生的空间行为变化 |
| **上报字段** | 行为类型（靠近/远离/挡在中间/回避眼神/长时间注视）、涉及的角色、距离变化、朝向变化、持续时间 |
| **触发条件** | 角色之间的信任值/怀疑值/好感度发生变化，或角色心智模型主动调整社交距离 |

#### 角色状态事实上抛器

| 维度 | 说明 |
| :--- | :--- |
| **监听内容** | 角色自身的行为和状态变化 |
| **上报字段** | 行为类型（坐下/起身/奔跑/潜行/晕倒/死亡）、位置变化、姿态变化、持有的物品变化 |
| **触发条件** | 角色执行任何改变自身状态的动作 |


### 1.3 L2 部分：可感知信息编译层

**归属**：L2 智能体交互层 → AI核心引擎族

**核心职责**：将L1上报的原始感知特征，编译为多感官候选感知事件，为后续角色私有裁剪提供统一输入。

#### 通道编译器

| 维度 | 说明 |
| :--- | :--- |
| **输入** | 八类上抛器的原始事件 |
| **输出** | 归入视觉、听觉、触觉、热感、嗅觉五个感官通道的编译后事件 |
| **编译逻辑** | 纯视觉事件→视觉通道；纯听觉事件→听觉通道；需要分流的（如生理状态）→按表现类型分流（发抖→视觉；牙齿打颤→听觉） |

#### 上下文融合器

| 维度 | 说明 |
| :--- | :--- |
| **输入** | 通道编译器输出的编译后事件 |
| **输出** | 融合了环境参数的感知事件 |
| **融合参数** | 光照条件（明亮/昏暗/黑暗）、遮挡状态（无遮挡/半遮挡/全遮挡）、环境噪音水平、气流方向、距离衰减 |

#### 阶段标签器

| 维度 | 说明 |
| :--- | :--- |
| **输入** | 上下文融合器输出的事件 |
| **输出** | 标注了行为阶段的事件 |
| **标签类型** | `intent`（意图阶段：举刀、蓄力、伸手）、`execute`（执行阶段：刀正在刺下、手正在抓取）、`complete`（完成阶段：刀刺中、物品被拾起） |

#### 跨通道融合器

| 维度 | 说明 |
| :--- | :--- |
| **输入** | 阶段标签器输出的事件流 |
| **输出** | 跨通道融合感知候选事件（如“撒谎综合症”、“威胁态势感知”） |

**跨通道融合器的孙系统**：

-   **时间窗口管理器**：设定融合时间窗口（如500ms内的多个事件视为“同时发生”），窗口内的事件进入融合队列。
-   **空间关联检测器**：检测多个事件是否发生在同一空间区域（如同一角色、同一房间），关联的事件才能融合。
-   **融合规则引擎**：存储可配置的融合规则——每条规则定义：需要哪些通道的事件、融合阈值、融合后的感知类型。规则由剧本创作者在编辑器中配置，而非写死在代码中。
-   **置信度计算器**：基于融合事件的通道数量和质量，计算融合感知事件的置信度（单一感官=疑似，双重感官=可信，三重及以上=确认）。
-   **融合事件生成器**：将满足规则的事件组合，编译为融合感知候选事件，提交给Per-Character感知过滤器。


### 1.4 L2 部分：Per-Character 感知过滤器

**归属**：L2 智能体交互层 → AI核心引擎族 → 角色智能体引擎（内部组件，非独立子系统）

**核心职责**：按角色的感官档案筛选候选感知事件，生成角色专属感知事件。每个角色实例独立运行，保证信息不对称的真实性。

| 孙系统 | 核心职责 |
| :--- | :--- |
| **感官档案管理器** | 存储角色的视觉范围、听觉灵敏度、触觉范围、热感范围、嗅觉范围、特殊感官（回声定位、灵力感知等）。盲人角色的视觉档案直接禁用 |
| **空间范围检测器** | 检测感知事件的发生位置是否在角色的该感官范围内。不在范围→丢弃。门/墙遮挡→衰减 |
| **状态修正器** | 根据角色当前状态修正感知精度。醉酒→感知延迟+模糊化；致幻→可能生成虚假感知；专注→非注意方向感知减弱 |
| **注意力分配器** | 模拟人类注意力的有限性。对话中→注意力集中在对话对象；检查物品→注意力集中在物品；空闲→注意力均匀分布 |
| **专属感知生成器** | 将通过所有筛选的事件，转化为角色可理解的自然语言描述（如“你看到华生医生走进了书房。他面色苍白，右手似乎有血迹。”），输出给感知接入器 |

### 2.2 内部状态参数（唯一源头）

所有外在表现的源头，是角色心智模型在那一刻的统一内部状态。

| 状态参数 | 来源 | 数据类型 | 影响的外在表现通道 |
| :--- | :--- | :--- | :--- |
| **情绪标签** | L2 理解层 | 枚举（紧张/恐惧/愤怒/悲伤/兴奋/平静） | 表情（基础表情）+ 语音（TTS情绪参数）+ 动作（情绪化动作） |
| **压力值** | L2 理解层 | 0-10 | 微表情（撒谎特征）+ 小动作（紧张动作）+ 生理状态（出汗、呼吸）+ 语音（语速、声调） |
| **撒谎意图** | L3 规划层 | 布尔值 | 微表情（撒谎特征触发）+ 小动作（撒谎动作）+ 语音（撒谎语音特征） |
| **信任值/怀疑值** | L2 理解层 | -10到10 | 社交距离（靠近/远离）+ 身体朝向（正面/侧身/背对）+ 眼神（注视/回避） |
| **暗杀意图** | L3 规划层 | 布尔值 | 角色状态（拔出武器）+ 移动姿态（潜行）+ 表情（冷酷） |


### 2.3 人格档案中的表现映射规则

每个角色在人格档案中定义了独特的表现映射规则。当内部状态参数超过阈值时，对应的外在表现自动触发。

| 规则类型 | 触发条件 | 驱动方式 | 示例（华生的人格档案） |
| :--- | :--- | :--- | :--- |
| **撒谎特征** | 撒谎意图=true + 压力值>3 | 心机值影响触发强度——心机越高，特征越不明显 | 耳朵红（压力>5时触发）、语句断断续续、眼神短暂飘移 |
| **紧张特征** | 情绪=紧张 + 压力值>4 | 压力值正相关——压力越高，表现越明显 | 手指在裤缝上摩擦、呼吸略快、手心出汗 |
| **开心特征** | 情绪=开心 | 高社交值者表现更外放 | 眼睛微眯、嘴角上扬、身体轻轻晃动 |
| **愤怒特征** | 情绪=愤怒 + 压力值>6 | 胆量值影响愤怒表达方式——高胆量者直接对抗，低胆量者压抑 | 眉头紧锁、嘴唇抿紧、音量略微增大 |


### 2.4 L4 执行层的 5 个并行下发通道

#### 语音通道

| 维度 | 说明 |
| :--- | :--- |
| **驱动方式** | TTS参数注入（情绪标签、撒谎意图、压力值） |
| **下发参数** | 语速（加快/减慢）、声调（升高/降低）、停顿模式（正常/断续）、音量（正常/耳语/呼喊）、气息（平稳/急促/颤抖） |
| **对应上抛器** | 听觉事实上抛器 |

#### 表情通道

| 维度 | 说明 |
| :--- | :--- |
| **驱动方式** | 形态键混合（Blend Shapes） |
| **下发参数** | 基础表情：喜怒哀乐惊恐惧（形态键权重0-1）；微表情：耳朵红、眼神飘移、嘴唇微颤（叠加在基础表情上）；眼神：注视/回避/长时间注视（IK眼球追踪） |
| **对应上抛器** | 视觉事实上抛器（微表情子类） |

#### 动作通道

| 维度 | 说明 |
| :--- | :--- |
| **驱动方式** | 骨骼动画（Animation Tree） + IK逆向运动学 |
| **下发参数** | 大动作：行走/奔跑/坐/站/挥手/拍桌/拥抱（由L3规划层主动决策）；小动作：绞手指/整理袖口/撩发/抖腿（由情绪标签和压力值自动触发，从人格档案的动作库中选择）；手势：指向/招手/握拳（由对话内容和情绪驱动） |
| **对应上抛器** | 视觉事实上抛器（小动作子类）、角色状态事实上抛器 |

#### 社交距离通道

| 维度 | 说明 |
| :--- | :--- |
| **驱动方式** | 空间行为参数（信任值/怀疑值/好感度） |
| **下发参数** | 距离：亲密(0-1.5m)/社交(1.5-3m)/疏远(3m+)；身体朝向：正面/侧身/背对；眼神接触：注视/回避/长时间凝视；特殊行为：挡在他人面前、跟随、躲避 |
| **对应上抛器** | 社交距离与空间行为上抛器 |

#### 生理状态通道

| 维度 | 说明 |
| :--- | :--- |
| **驱动方式** | 粒子特效 + 着色器 + 骨骼微动 |
| **下发参数** | 发抖（骨骼抖动，幅度与寒冷/恐惧正相关）；出汗（皮肤着色器调整，压力>5时触发）；面色潮红/苍白（着色器调整）；呼吸起伏（骨骼微动，频率与压力值正相关）；嘴唇发紫（着色器调整，体温过低时触发） |
| **对应上抛器** | 生理状态事实上抛器 |


## 三、感知系统与行为系统的闭环协作

感知系统（输入）和行为系统（输出）通过L1感知事实上抛器、L6事件总线、L2可感知信息编译层和Per-Character感知过滤器形成完整闭环：

```
[被感知方：角色B]
    │
    ▼
[L2 内部状态参数] → [L4 5个并行通道下发] → [L1 5个表现通道渲染]
    │
    ▼
[被感知方的所有外在表现——语音、表情、动作、社交距离、生理状态]
    │
    ▼
[感知方：角色A]
    │
    ▼
[L1 八类感知事实上抛器捕获原始感知特征] → [L6 事件总线分发]
    │
    ▼
[L2 可感知信息编译层：通道编译 → 上下文融合 → 阶段标签 → 跨通道融合]
    │
    ▼
[L2 Per-Character 感知过滤器：私有筛选 → 生成专属感知]
    │
    ▼
[角色A 感知接入器 → 理解与记忆器 → L3规划层 → 做出回应]
    │
    ▼
[角色A的回应通过其L4执行层下发，成为新的被感知事实]
    │
    └──────────────────────→ [回到起点：角色B现在成为感知方]
```


**一句话总结**：《开本》的感知系统是跨层系统，横跨L1（八类感知事实上抛器）、L6（事件总线）、L2（可感知信息编译层及其跨通道融合器、Per-Character感知过滤器），负责将物理世界转化为每个角色专属的感知信息。角色行为系统以L4执行层的5个并行下发通道（语音、表情、动作、社交距离、生理状态）为核心，由心智模型的统一内部状态参数驱动，通过人格档案中的表现映射规则，确保每个角色的外在表现都是其内在状态的忠实反映。两者通过事件总线形成完整闭环，共同构成《开本》信息不对称和社交博弈的技术基石。
